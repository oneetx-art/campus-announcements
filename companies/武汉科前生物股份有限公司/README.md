## 公司
性质:民企 · 行业:医疗/医药/生物

武汉科前生物股份有限公司成立于2001年，是一家专注于兽用生物制品研发、生产、销售及动物防疫技术服务的上市企业，公司是国家发改委首批授予的“国家高技术产业化示范工程”重点高新技术企业、湖北省首批创新型试点企业、武汉市民营制造业50强及湖北省疫苗市场排名第一。在国内非强制免疫猪用疫苗100强，连续7年（2020年-2026年），公司在上海证券交易所科创板挂牌上市。公司建立了国内领先、教授专家领衔、博士硕士为主的研发技术队伍，以打造“中国动物疫苗民族品牌”为己任，以实现“满足养殖户需求”的科前梦为目标，始终秉承“创新、创造、创业”和“人才立企、科技强企、产业兴企”的理念，践行“科技创造价值，科前回报社会”的使命。
