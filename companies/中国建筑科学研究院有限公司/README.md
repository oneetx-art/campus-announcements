## 公司
性质:央国企 · 行业:房地产业/建筑业

中国建筑科学研究院有限公司（原中国建筑科学研究院，简称“中国建研院”）成立于1953年，是国务院国资委直属的科技型中央企业。经过70多年的发展，形成了以科研、标准、咨询、规划设计、施工监理、检测认证、材料装备以及软件与信息化等服务为基础的全产业链大融合格局，为城乡建设提供系统解决方案。
