## 公司
性质:民企 · 行业:耐用消费品

九阳创立于1994年，是品质小家电领导品牌、中国载人航天“太空厨房”研制单位，于2008年深交所上市、2020年销额破百亿。现有员工近3000人。三十余年来，九阳秉承健康、创新的核心DNA，打造了“三大厨房”：家庭厨房、太空厨房、公益厨房。九阳有数亿级的产品在为用户的“家庭厨房”提供生活便利；有太空科技打造的“太空厨房”在为航天员改善太空饮食造质；有上千所“公益厨房”在为乡村孩子解决营养就餐问题。近年来，九阳创新拓展清洁电器和家居电器，推出了银河系列洗地机等产品，开启了从厨房到全屋的全面升级，引领悦享健康的家庭生活方式。
