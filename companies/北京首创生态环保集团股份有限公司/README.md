## 公司
性质:央国企 · 行业:能源/化工/环保

北京首创生态环保集团股份有限公司成立于1999年，是北京市国资委所属环保旗舰上市公司（股票代码：600008.SH）。连续22年被评为“中国水业十大影响力企业”，连续13年被评为“中国固废十大影响力企业”，入选国务院国资委“双百企业”名单。截至2024年末，公司水处理能力达2733万吨/日，生活垃圾处理能力达到1498万吨/年，累计实施63个水环境项目，70余个大气环境综合治理项目，600余项节能降碳服务。业务覆盖“水、固、气”环保全产业链，服务国内29个省（自治区、直辖市）170余座城市超1亿人，资产规模超1100亿元，居A股上市环保企业之首。
