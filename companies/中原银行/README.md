## 公司
性质:其他 · 行业:金融业

中原银行2014年12月在河南省郑州市成立，2017年7月在香港联交所主板挂牌上市，2022年5月经中国银保监会批准，正式吸收合并洛阳银行、平顶山银行及焦作中旅银行。全行资产突破1.3万亿，员工人数超1.8万名，获2024年《财富》中国上市公司500强、2025年全球银行1000强第152位等荣誉
