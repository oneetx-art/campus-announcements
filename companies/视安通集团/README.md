## 公司
性质:民企 · 行业:通信/电子/半导体

广东视安通智慧显控股份有限公司及其全资子公司广东视安通实业有限公司，分别位于粤港澳大湾区的核心城市深圳和东莞。两家公司内部相互配套、协同紧密，均为国家级高新技术企业及市专精特新企业。自2003年成立以来，始终专注于彩色液晶显示模组、电容触控显示模组、智慧显控模块等产品的研发、生产和销售。产品广泛应用于数码电子、智能安防、工业控制、汽车电子等领域。如今，公司已成为中小尺寸彩色液晶显示行业的龙头企业，并于2022年完成股份制改造，为未来发展奠定了坚实的基础。
