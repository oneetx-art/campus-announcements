西安近代化学研究所是我国最大的含能材料科研中心，主要从事含能材料、爆炸与燃烧科学、有机化学、应用化学、高分子材料、分析测试技术的研究开发，是以应用化学为主的科研、试制综合性研究所。依托研究所技术实力，建有氟氮化工新材料国家重点实验室、国家含能材料产品质量检验检测中心、含能材料全国重点实验室等一批在国家和行业有重要影响力的创新实验室和研究测试平台，现有中国工程院院士1人，国家级人才40余人，享受国务院政府特殊津贴专家55人，省级人才40余人，各专业领域专家百余人。
