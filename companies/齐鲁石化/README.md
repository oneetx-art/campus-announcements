## 公司
性质:央国企 · 行业:能源/化工/环保

齐鲁石化始建于1966年，位于山东省淄博市，占地21.63平方公里，经过多年建设发展，已成为全国最大的硫磺、全国第一的干法熄焦生产基地、中国石化第一家实现原油管输企业、全国最大的合成橡胶生产基地、中国第一家隔膜法烧碱生产企业。作为国内最大炼化企业之一，在国家能源产业中发挥着重要作用。
