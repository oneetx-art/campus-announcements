## 公司
性质:民企 · 行业:IT/互联网/游戏

星纵物联科技有限公司（以下简称“星纵”）是专业的数字感知产品提供商，专注于智能物联网设备的研发、生产与销售。星纵品牌（Milesight）诞生于2011年，以“让每一次感知，都能直抵世界的力量”为品牌使命，运用前沿的物联网与人工智能技术，为客户提供高效、节能、可靠的智能物联网产品，助力数字化建设，实现万物互联。
