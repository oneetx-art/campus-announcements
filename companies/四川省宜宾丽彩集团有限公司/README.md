## 公司
性质:央国企 · 行业:快速消费品

四川省宜宾丽彩集团有限公司（以下简称丽彩集团）成立于2004年6月，是丽彩集团宜宾五粮液集团有限公司投资组建的全资子公司。丽彩集团坚定以“一站式包装服务”为核心，现“酒包装为特色”系列产品，印刷技术协会副理事长单位、四川省包装联合会副理事长单位、龙企年鉴“殊荣”。公司先后获得企业技术中心两个，拥有行业龙头企业“荣誉奖牌”。
