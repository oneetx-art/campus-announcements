## 公司
性质:民企 · 行业:医疗/医药/生物

北京新云医疗科技有限公司（简称新云医疗）创立于2016年，是一家集研发、生产、销售为一体的创新型医疗器械企业。公司总部位于北京丰台区国家丽泽金融区，在江苏张家港建有3200㎡的研发生产基地和生产工厂，公司核心产品NewMild智能云贴是国内首个获批上市的智能疼痛管理产品。公司以团队为核心的研发团队，致力于为人类免除疼痛提供产品和服务。
