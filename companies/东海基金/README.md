## 公司
性质:民企 · 行业:金融业

东海基金管理有限公司成立于2013年2月25日，是中国证监会批准设立的第78家公募基金管理公司，公司总部位于上海。东海基金管理有限公司以“专注以资产配置的卓越驱动，聚焦价值与品质”为品牌理念，坚持“信、诚、精、博”的价值观，坚持战略一体和科技金融双轮驱动的战略要求，打造以绝对收益为目标、以大类资产配置为特色的国内领先、以投资者利益为先，以员工及股东挖掘为特色的权益品牌。
