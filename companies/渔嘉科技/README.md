## 公司
性质:民企 · 行业:农林牧渔

渔嘉科技成立于2021年，总部位于有“水产养殖黄金地带”之称的广东江门，公司主要业务涵盖普通鱼料、特种鱼料、虾料和动保系列；高效整合构建苗种、饲料、动保、养殖设备、流通等完善的产业链；是一家集生产、研发、销售的高科技创新型水产饲料综合型公司，致力于成为世界级生态营养引领者。目前旗下属四家公司，分别为——江门市渔嘉生物科技有限公司、广东渔嘉生物科技有限公司、湛江市渔嘉科技有限公司、江门市渔乐生物技术有限公司。
