## 公司
性质:央国企 · 行业:机械/制造业

中航航空电子有限公司是世界500强企业中国航空工业集团有限公司的成员单位之一，隶属于中航机载系统有限公司。公司主要致力于建成国内一流的机载任务系统研发中心，推动机载任务系统和训练评估系统关键技术发展，装备涉及航电任务系统、航空声纳、训练评估、通信导航等专业领域。公司位于北京市朝阳区，地铁直达周边商场、餐饮、医院等配套齐全，工作生活便利。
