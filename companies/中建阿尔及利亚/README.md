## 公司
性质:央国企 · 行业:房地产业/建筑业

自1982年起深耕阿尔及利亚，是中国建筑集团践行国家“走出去”战略的先行者，是中国建筑业走出国门的排头兵。公司积极推进国际化布局，在欧洲、非洲、中国三地设有7家子公司，其中欧洲设有3家子公司，共计170+名员工。业务横跨北非、欧洲、亚洲三大洲，立足阿尔及利亚，辐射法国、西班牙、突尼斯等环地中海国家，项目遍欧亚非。业务覆盖住房、交通、新能源等16个领域，累计落地项目遍布阿尔及利亚各省，在环地中海地区投资建设城镇具有重要影响力。
