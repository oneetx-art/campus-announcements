## 公司
性质:央国企 · 行业:能源/化工/环保

广西水利电力建设集团有限公司（以下简称广西水电集团）成立于2000年11月，隶属于中国能源建设集团投资有限公司，是一家以“新能源+水电”为主，投建营一体化，为社会和客户提供一体化系统解决方案、产品和服务的电力企业集团。广西水电集团目前拥有6家分公司、4家全资子公司、3家控股子公司、3家参股公司。
