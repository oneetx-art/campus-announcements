## 公司

福建省汽车工业集团有限公司（简称“福汽集团”）是福建省属国有企业，成立于1992年，是福建省汽车工业核心企业，也是较完整的汽车企业集团。产品资源丰富，产业链较完整。具备轿车、MPV、皮卡、轻客、客车、重卡等轻客整车，旗下拥有金龙汽车、东南汽车、福建奔驰等控股参控股企业。
