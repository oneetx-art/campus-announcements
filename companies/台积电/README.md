## 公司
性质:合资 · 行业:通信/电子/半导体

台积电成立于1987年，开创了专业集成电路制造服务商业模式，专注生产由客户所设计的芯片。台积电（中国）有限公司2003年成立，位于上海市松江经济技术开发区内，是台积电独资设立的子公司。台积电（南京）有限公司2016年成立，位于南京浦口经济开发区，是台积电独资设立的子公司。
