## 公司
性质:央国企 · 行业:房地产业/建筑业

北京交科公路勘察设计研究院有限公司是交通运输部公路科学研究院（中路高科交通科技集团有限公司）的全资企业，前身为1973年国内成立的首家交通工程研究机构——交通部公路科学研究所道室（后更名为交通工程研究室）。历经五十余年发展，公司现已发展为以公路工程、市政工程、岩土工程、建筑与环境景观、科研咨询为核心业务的综合性勘测设计咨询单位。公司目前在湖南、湖北、广东、广西、云南、四川、福建、新疆及甘肃省设立了九家分公司。
