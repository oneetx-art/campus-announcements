## 公司
性质:央国企 · 行业:房地产业/建筑业

中建七局第二建筑有限公司是中国建筑第七工程局有限公司旗下全资子公司，成立于1952年，注册资本金5.51亿元，是安徽省第十、十一、十二届文明单位，合肥市第十三届文明单位。业务范围涵盖房屋建设工程、基础设施建设工程、机电安装工程等领域，具备多种资质，‘十四五’期间将加速融入长三角城市群和都市圈建设。
