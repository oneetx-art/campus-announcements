## 公司
性质:央国企 · 行业:能源/化工/环保

中国化工橡胶有限公司（简称“橡胶公司”）是中国中化旗下全球领先的轮胎和橡胶品制造商，在全球5个国家设有8家工厂，8个全球研发机构，产品销往全球160多个国家和地区。公司始终秉承科技创新、品牌引领的理念，推动国际化建设，奋力打造世界一流综合性橡胶轮胎企业。公司主要从事消费用轮胎（包括轿车和SUV轮胎、摩托车轮胎、自行车轮胎等）、工业用轮胎（包括卡客车轮胎、工程机械轮胎、农用车辆轮胎等）和橡胶输送带等产品的研发、生产、销售和服务。公司持有倍耐力（PIRC.MI）和风神轮胎股份有限公司（600469.SH）等知名轮胎上市公司股份，拥有Promenton Tyre Group S.R.L.和青岛橡六输送带有限公司等非上市企业。
