## 公司
性质:民企 · 行业:汽车制造/维修/零配件

普天单向器有限公司建立于1983年，总部坐落于美丽的海滨城市浙江省玉环市，现有三个生产基地和一个研发中心，员工人数1000余人。普天公司，四十余年精耕于单向离合器、传动件，新能源电机轴、汽车空调压缩机轴等核心零部件的研发、生产、销售，目前已发展成为亚洲地区的单向器行业龙头企业，是亚太区研发、生产、销售等综合实力最强的单向器OE配套企业。
