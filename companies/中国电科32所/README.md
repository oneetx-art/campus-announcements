## 公司
性质:事业单位 · 行业:教育/培训/科研

中国电子科技集团公司第三十二研究所创建于1958年，位于上海市嘉定区，是国家定点的嵌入式计算机研制与开发基地，是国内自主可控基础软件、嵌入式系统、网络通信核心芯片、软件测评及系统集成等领域的总体单位和牵头单位，是全国首批建立博士后科研工作站的单位之一，也是博士学位授予单位，目前已培养研究生500余名。自成立以来，先后成功研制中国计算机发展史上有标志性的多台计算机，填补国内多项空白，为我国国防建设和国民经济建设作出了突出贡献。
