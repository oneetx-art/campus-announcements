## 公司
性质:央国企 · 行业:检测/认证

中汽认证中心有限公司成立于1998年，是经国家认证认可监督委员会（CNCA）及中国合格评定国家认可委员会（CNAS）批准的首批从事强制性产品（CCC）认证机构之一，在品牌公信力和业务资质等方面具有先发优势。中汽认证及其全资子公司中联认证主要提供强制性产品认证、自愿性产品认证、管理体系认证（质量／环境／职业健康／能源）、服务认证以及评价诊断核查类业务等。公司可开展6大类强制性产品认证以及机动车辆、安全附件产品的一般工业产品认证9类、城市轨道交通装备产品-城市轨道交通车辆国推自愿性认证及节能环保汽车认证共计11大类约100余种产品；还可开展碳排放管理体系认证、温室气体核查认证、碳足迹核查认证、企业标准管理体系及合规管理体系，批发业和零售业服务认证、保养和修理服务认证等业务。 深度参与汽车/摩托车产业合规全流程，成为行业认证领域的专业专家； 完善的应届生培养体系：一对一导师带教+定制化培训课程，快速实现从校园到职场的蜕变； 广阔的职业发展空间：纵向可晋升为认证技术专家/项目管理负责人，横向可拓展至合规咨询、技术研发等多元方向； 与行业顶尖企业客户深度对接，积累优质人脉与行业资源 。
