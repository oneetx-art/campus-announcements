## 公司
性质:央国企 · 行业:机械/制造业

北京全路通信信号研究设计院集团有限公司（中国通号研究院集团）成立于1953年，是国资委直属中央企业-中国通号（股票代码:688009.SH，03969.HK）下属全资企业。公司是中国最大的轨道交通控制系统研究设计的专业机构，是一家从事轨道交通通信信号系统方案提供，现已成为中国轨道交通安全控制和信息技术领域集“标准编制、设计咨询、科研开发、装备制造、集成交付、试验验证、建设监理”为一体的领先企业，为用户提供轨道交通全产业链、全专业链、全业务定制化系统解决方案。
