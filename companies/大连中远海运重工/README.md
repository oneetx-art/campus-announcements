## 公司
性质:央国企 · 行业:机械/制造业

大连中远海运重工有限公司位于北方环渤海湾的重要一环大连，隶属于中远海运重工有限公司，是中国远洋海运集团的骨干企业。公司于1992年9月成立，1997年10月正式营业，是中国北方重要的船舶与海洋工程修理、改造和建造基地之一。公司已通过国家高新技术企业、技术中心双国家级认定。已成功运营智能工厂、5G工业试点等数字化转型特色工厂项目。公司率先通过船舶行业智能制造成熟度三级认证，并在2023年1月取得高级能效船型三级认证和两化融合3A认证。公司占地面积85万平方米，岸线3200米，拥有14座多档次大型船坞、55台具备装船机、油船、散货船等多类型船舶的修理改装能力，多用途纸浆、LNG运输船、滚装船、超深水海工船型、累计交付了150余艘。在深海领域，累计交付两型海上石油生产储卸船（FPSO）12艘，被誉为“中国第一FPSO改装工厂”。
