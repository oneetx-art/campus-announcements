## 公司
性质:事业单位 · 行业:房地产业/建筑业

清华大学建筑设计研究院（THAD）成立于1958年，为国内知名建筑设计机构。作为建筑学院、土木学院等院系教学、科研和实践相结合的教学基地，采用“清华大学深厚广博的学术、科研和教学资源，积极用精心设计、创作精品、超越自我、创建一流”的奋斗目标，设计水平在中国名列前茅。现有工程设计人员1300余人，其中中国科学院、中国工程院院士5人，全国、国家勘察设计级优秀设计并建成的工程已获得国际、国家、省部优级。业务设计奖八百余项，位居全国建筑设计机构前列。
