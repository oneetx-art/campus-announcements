## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁广州工程局集团（原第一工程有限公司）是世界500强中国铁建股份有限公司的全资三级子公司，同时也是中铁广州局集团在广东深圳地区唯一的全资子公司，总部位于广州市南沙区。公司业务覆盖广东、海南、江西、福建、江苏、浙江、上海、云南等十余个省市自治区，参建了广深港高铁、沪苏通铁路、甬舟铁路、郑济高铁、南京长江大桥、四川雅康高速泸定大渡河特大桥、城际轨道交通工程、温州至瑞安城际铁路、南京地铁6号线、南京仙林大道、阜阳双清湾大桥、海口综保区电子产业园、济南浪潮产业园、海口高新区无人机基地、盐城大丰体育教育服务中心、濮阳新型产业园、扬州邵伯码头、新荆江旅游航道、盐城大丰海港等项目。
