性质:央国企 · 行业:机械/制造业

中国电气装备集团科学技术研究院有限公司（以下简称“研究院”）于2022年6月在上海市静安区注册成立，注册资本10亿元，是中国电气装备的一级研发机构。研究院定位于集团公司科技创新工作的战略性、引领性力量，为集团公司科技发展战略规划、产业公司科技发展新兴产业培育提供支撑与决策依据。
