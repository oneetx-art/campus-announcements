## 公司
性质:央国企 · 行业:金融业

作为国务院确定试点的首批银行系金融租赁公司，招银金融租赁有限公司于2008年4月在上海正式开业，目前注册资本180亿元，由招商银行全资持有。十七载砥砺奋进，招银金租传承招商血脉、海辽精神、蛇口基因、三创力量，始终秉持“质量为本、效益优先、规模适度、结构合理”的经营理念，积极践行“服务实体、装备未来”的初心和使命。招银金租围绕“专业化、国际化、数字化”发展战略，坚持价值创造，深耕航空、航运、设备三大业务板块，打造以新能源、新基建、新科技、新出行、新智造、新材料为核心的“六新”产业金融体系，为实体经济注入金融活水，推动经济社会高质量发展。
