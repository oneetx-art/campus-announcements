## 公司
性质:民企 · 行业:IT/互联网/游戏

启辰科技成立于2013年5月，是深耕中国教育考试服务赛道的领军企业。秉承“人工智能赋能教育考试”的核心理念，持续推进教育考试智能化升级。主要产品与服务涵盖考试专用装备、命题数字资源加工、命题素材与题库建设、命题查重、AI辅助命题、数据智化考务等，为教育部考试院、各省级考试院及各类教育机构提供智能化服务。
