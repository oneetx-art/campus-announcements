## 公司
性质:民企 · 行业:智能硬件

北京零重空间技术有限公司（又称零重力实验室，以下简称公司）成立于2017年01月，是国家高新技术企业、北京市“专精特新”中小企业、中关村高新技术企业。同时也是多个商业航天创新联盟理事单位之一，曾入选投资界硬科技榜全国50强。公司主营业务为从事卫星整星的研制与在轨交付、微纳卫星组部件的研发与销售，以及遥感数据应用服务。在卫星自动化生产线、低成本制造及核心组部件等方向处于行业领先地位。目前已实现多次在轨交付任务，逐步构建成产业链完备的高频、多源、智能化的时空数据服务生态体系。在国内多个城市、县级地区开展了高频遥感数据监测服务。
