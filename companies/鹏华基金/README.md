## 公司
性质:民企 · 行业:金融业

鹏华基金管理有限公司成立于1998年12月22日，公司总部位于深圳市福田中心区，是经中国证监会批准成立的最早的十家基金管理公司之一，被誉为基金行业‘老十家’。股东由国信证券股份有限公司、意大利欧利盛资本资产管理股份公司（Eurizon Capital SGR Sp.A.）、深圳市北融信投资发展有限公司组成。鹏华基金历经市场洗礼，穿越牛熊周期，资产管理规模逾1.3万亿。坚持研究发现价值，坚守基本面投资之道，公司核心竞争力不断提升。我们致力于打造顶尖人才梯队，筑巢引凤、汇聚英才、精益赋能、共筑辉煌。鹏华未来将以更加开放的姿态，拥抱变化，探索未知，携手新星力量，共赴资产管理的新征程。
