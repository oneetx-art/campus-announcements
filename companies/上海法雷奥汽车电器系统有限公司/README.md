## 公司
性质:合资 · 行业:汽车制造/维修/零配件

上海法雷奥汽车电器系统有限公司是由上海汽车集团股份有限公司（SAIC MOTOR）下属华域汽车系统股份有限公司和法国法雷奥集团（VALEO）合资组建的国内规模最大的汽车电机生产企业。公司主营产品包括传统内燃机用的12V发电机与起动机、48V-iBSG、FMR、DCDC、TCU和新能源汽车用高压电压缩机定转子，为上汽大众、上汽通用、一汽大众、北京奔驰、东风日产、吉利汽车、上汽通用五菱、广汽乘用车、长安福特、长城汽车、比亚迪、宝马汽车等40余家主机厂提供配套。公司连续十五年保持国内汽车电机行业龙头地位，连续4年跻身上海市工业企业纳税百强，致力于成为国内领先，国际一流的汽车电机企业。
