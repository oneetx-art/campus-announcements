## 公司
性质:央国企 · 行业:IT/互联网/游戏

天津市测绘院有限公司（原天津市测绘院，简称“天津测绘院”）始建于1952年，是一家以基础测绘、测绘工程和地理信息服务为主的专业化大型国有高新技术企业。作为行业内一流国企，天津测绘院践行“辅助政府决策、参与城市管理、服务社会大众”核心理念，致力于天津市全市域基础测绘地理信息和1:500大比例尺地形（含持续更新），天津市测绘地理信息空间基准框架（全市域地理信息要素快速和高程系统）建设运维、天津市地理信息要素快速获取与融合处理、智能化应用及测绘地理信息产品定制服务，为国情普查、自然资源调查监测、城市规划及国土管理、生态及农业管控、应急救灾、数字天津、智慧园区及数字孪生等专题专项提供二维三维一体的整套测绘地理信息数据基座及智能化应用解决方案，为水利、交通、能源、城管、技防、安防等数十个领域的测绘时空信息应用提供全方位专业技术支撑。
