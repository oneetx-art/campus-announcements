## 公司
性质:民企 · 行业:农林牧渔

华昱控股是一家专注食品投资控股公司，定位为中国肉类产业链运营商和中国生鲜供应链服务商，拥有众品、东方伊盾、华源供应链等品牌，主要产品和服务包括生鲜肉、肉制品、预制菜和调味品，以及冷链仓储、农产品批发、新零售、肉类进出口贸易等服务。公司在全国7个生猪屠宰加工基地、3个肉制品加工基地和5个冷链物流基地、1个农批市场。生猪加工能力800万头/年，肉制品综合加工能力25万吨/年。
