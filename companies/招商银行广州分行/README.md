## 公司
性质:央国企 · 行业:金融业

招商银行广州分行成立于1994年6月21日，是招商银行在华南地区设立的第一家分行。成立以来，广州分行持续承担招商银行“因势而变，因您而变”的经营理念，开拓创新、锐意进取，从成立之初6个网点、134名员工、总资产15.11亿元的小银行发展成为总资产逾4300亿元、网点81家、员工超过3300人、存贷款规模及资产质量等关键指标位居属地股份制银行前列、在区域市场具有较强影响力的金融机构，在广州地区赢得了良好口碑。
