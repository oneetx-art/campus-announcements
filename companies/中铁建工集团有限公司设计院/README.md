## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁建工集团有限公司设计院（简称中铁建工设计院）始建于1953年，前身是铁道部设计局厂房设计事务所，现隶属于世界500强的中国中铁股份有限公司的全资子公司——中铁建工集团有限公司。中铁建工设计院是集工程规划、设计、全过程咨询、EPC总承包管理、项目全过程设计及其他专业技术服务于一体的建筑行业甲级设计院，服务领域涵盖：城市规划、策划咨询、民用建筑设计、工业建筑设计、室内装饰设计、园林景观设计、建筑智能化系统工程设计、BIM设计、基坑及地基处理、复杂结构设计等领域。
