## 公司
性质:央国企 · 行业:金融业

四川天府商业保理有限公司成立于2021年12月，由四川金控集团联合多家省属和地方国企共同出资设立，注册资本20亿元，主体信用评级AA+，为全国保理专业委员会副主任单位，荣获省委金融工委“先进基层党组织”称号和“天府金融先锋”优秀党建案例称号。公司坚持“助融强链、服务实体”为己任，围绕“一体两翼”核心企业产业链上下游中小企业，为其提供全流程、定制化的金融解决方案，切实缓解中小企业应收账款回收慢、回款难问题，确保供应链产业链稳定安全，助力实体经济发展。
