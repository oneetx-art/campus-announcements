## 公司
性质:央国企 · 行业:快速消费品

光明食品集团成立于2006年8月8日，以服务保障上海城市发展为己任，聚焦两大核心主业，构建“4+6+2”产业和管理体系。两大核心主业为食品产业与供应链、城市食品保障服务与资产经营管理。集团拥有20家二级子公司，遍及全国各地近千家企业，拥有10家实体海外企业，分布于香港及境外欧洲、亚洲、美洲、大洋洲，拥有五家中国A股上市公司和一家新西兰主板上市公司，拥有20个老字号品牌、上海知名品牌91个（境内外部分知名品牌代表）。
