## 公司
性质:央国企 · 行业:能源/化工/环保

核电运行研究（上海）有限公司（简称“运行研究院”）位于上海浦东塘桥地区，成立于2019年9月。公司隶属于中国核电集团有限公司（简称“中核集团”），为其旗下二级单位中国核电电力股份有限公司（简称“中国核电”）全资子公司。公司定位为核电科研技术服务与数字化转型总体院，以数智化为牵引的核电运行业绩提升技术方案供给者和组织者，致力于系统推进核电运营业绩提升，使之更安全、更可靠、更经济、更环保、更智能。
