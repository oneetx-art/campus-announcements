## 公司
性质:央国企 · 行业:机械/制造业

中国航天科工集团三十一研究所创建于1957年，专业从事冲压、涡扇、火箭、组合及新型发动机的设计研发和生产制造，是集预研、设计、试验为一体的综合性研究所，拥有一流的研发能力、完善的研制生产体系和世界领先的航空发动机试验装备保障，拥有冲压发动机技术领域重点实验室等国家重要创新平台，是我国空天动力领域的核心优势单位，承担过国防科工局、国家自然基金委等科研项目。
