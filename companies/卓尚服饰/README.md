## 公司
性质:民企 · 行业:快速消费品

卓尚服饰（杭州）有限公司始于1997年，注册资本4800万美元，总部坐落于杭州钱塘区，20万㎡现代化园区承载全链条业务，是国内女装领域集时尚设计、柔性制造、品牌运营及全渠道零售于一体的标杆企业。品牌矩阵多元覆盖，旗下3COLOUR（三彩）、IBUDU（伊布都）、LEISURE（丽雪）等知名品牌，精准匹配轻奢、通勤等不同消费场景。线下布局超1000家门店，辐射全国30余省市；线上构建全域经营生态，在天猫、京东开设官方旗舰店，抖音、快手布局直播电商，年复合增长率超30%。作为“杭派女装”领军者，公司斩获“中国驰名商标”“中国十大热门女装品牌”等权威认证，主导参与多项行业标准制定，在柔性供应链与时尚设计领域树立行业标杆。
