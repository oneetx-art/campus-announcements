## 公司
性质:央国企 · 行业:房地产业/建筑业

中国建筑国际集团（股票代码：03311.HK，中文简称“3311”或“集团”）于1979年在香港成立，是中国建筑集团有限公司的上市子公司，是香港地区最大的承建商之一，也是中国内地领先的城市综合投资运营商。中国建筑国际践行“科技+”战略，把行业转型机遇，深度聚焦装配式建筑、智慧幕墙、绿色建筑、城市更新等领域，全力打造“产品+技术+服务”的科技型工程公司，努力打造成为国际一流的“科技、投资、建筑、资产运营”综合企业集团。
