## 公司
性质:其他 · 行业:金融业

中保保险资产登记交易系统有限公司（以下简称中保登公司）于2017年3月经原中国保险监督管理委员会批准设立，是上海保险交易所的控股子公司。中保登公司负责建设和运营的中保保险资产登记交易系统，作为国务院保险监督管理机构认可的资产登记交易平台，为保险资产管理业提供发行、登记、托管、交易、结算、信息披露以及相关信用增进和质押融资等服务。
