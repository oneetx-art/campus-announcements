## 公司
性质:民企 · 行业:贸易/批发/零售

浙江杉迪进出口股份有限公司成立于2008年，从传统外贸起步，现已发展为科技型跨境电商企业。2020年疫情后，公司迅速开拓跨境电商业务，在AMAZON细分品类中斩获第一、第二名，荣膺浙江省跨境电商出口知名品牌，跻身萧山区2022年度十佳跨境电商行列。公司以技术为驱动，运用数字技术赋能产品开发、生产、营销等环节。通过外贸（TOB）与跨境（TOC）双轨并行，借助DTC品牌出海传递爱与美好实现员工价值，推动全员经营，为社会发展贡献力量。公司荣获杭州海关“A类管理企业”“杭州市信息化应用试点企业”“杭州出口名牌”等诸多荣誉。
