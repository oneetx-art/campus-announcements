## 公司
性质:民企 · 行业:医疗/医药/生物

植恩生物成立于2001年4月，是一家集医药研发、生产、销售和健康服务为一体的国家高新技术企业，公司专注于构建药品全生命周期管理服务体系，通过“产品（服务）+平台+交易服务”的方式，构建生物医药产业集群。以MAH上市许可持有人为核心，提供CDMO、交易促进、企业技术中心、国家专精特新“小巨人”企业。公司已获评国家技术发明奖、国家先进制造业技术中心、国家地方联合工程研究中心等国家级荣誉；获得重庆市生物医药药物专利主链企业、重庆市博士后科研工作站、重庆市新药设计工程技术研究中心、重庆市手性药物工程技术研究中心、创新药物先导药物筛选技术工程研究中心等多项市级荣誉。了解更多信息，请访问官网www.zoin.bio
