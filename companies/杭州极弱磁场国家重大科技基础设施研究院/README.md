杭州极弱磁场国家重大科技基础设施研究院（以下简称“研究院”）位于杭州高新区（滨江），成立于2020年12月，是中国科学院院士房建成任首席科学家，浙江省、杭州市、滨江区三级政府支持建设的新型研发机构（事业单位）。研究院依托“极弱磁场国家重大科技基础设施”，在房建成院士的带领下，建设研究型高水平大学科研教育研究和学术机构，优化科研资源配置，建立学科交叉、优势互补、共同发展的平台，重点开展重大科研项目。
