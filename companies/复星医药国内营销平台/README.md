## 公司
性质:民企 · 行业:医疗/医药/生物

复星医药（股票代码：600196.SH，02196.HK）成立于1994年，是一家植根中国、创新驱动的全球化医药健康产业集团，业务涵盖制药、医疗器械、医学诊断、医疗健康服务等众多领域。集团以"4IN"战略（创新、国际化、智能化、整合）为指引，秉持"持续创新、乐享健康"的理念，致力于成为全球领先的医疗创新整合者。复星医药国内营销平台是复星医药面向患者和终端，全力打造的全渠道、生态化的商业化平台。业务主要涵盖实体肿瘤、血液肿瘤、自身免疫性疾病、心血管、消化、慢性肾病等领域。
