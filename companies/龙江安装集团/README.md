## 公司
性质:央国企 · 行业:房地产业/建筑业

黑龙江省建筑安装集团有限公司（简称龙江安装集团）前身为始建于1952年的国家建工部直属工程局第二工程处，经多年发展，集团已发展成为集投资、施工、建设、运营、房地产等为一体的大型国有专业化集团，现有15家权属、5家一体区域公司，员工2000余人，各级管理和专业生产技术人员近800人，企业总资产120亿元，年施工生产能力130余亿元。
