## 公司
性质:民企 · 行业:金融业

凯丰投资成立于2012年，是国内最具代表性的宏观策略资产管理公司之一，公司在深圳、上海、香港等地设有办公室。秉持“极精微，致广大”的投资理念，公司始终致力于通过基于产业链的细节研究和基于安全边际的比较研究，构建多资产、多市场、多工具的投资组合，力求在全球市场挖掘超额收益，为客户获取长期稳健的回报。凯丰投资已获百余项海内外行业大奖，囊括金牛奖、金阳光奖、英华奖、金长江奖、新财富等行业权威奖项。公司持有中国证券投资基金业协会、中国期货业协会和中国证券业协会会员资格，并投资深圳私募基金协会副会长单位、深交所证券投资基金委员会委员单位及深圳私募基金业协会证券专委会主任委员单位。
