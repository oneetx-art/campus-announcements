## 公司
性质:民企 · 行业:IT/互联网/游戏

金桥信息（603918.SH）成立于1994年，2015年5月公司在上交所上市，总部位于上海市徐汇区漕河泾高新技术园区。在北京、广州、重庆、武汉、济南、合肥、成都、昆明、杭州、深圳设有分公司，南京、天津、沈阳、西安、郑州、长沙等地设有办事处。公司现有员工约700人。公司成立以来始终致力于开发各类信息系统及其行业解决方案及服务，始终坚持用科技创新打造自己的核心竞争力，引领国内信息系统行业的技术发展。公司28年来已形成完整的业务体系，服务范围较广，包括政务、司法、教育、企业、金融、卫健等，业务覆盖全国。公司被最高人民法院确定为智慧法院中长期发展战略规划在智慧执行方向上的牵头单位。由公司承建的GIS可视化实战系统（智慧执行APP）已覆盖全国100%的法院。
