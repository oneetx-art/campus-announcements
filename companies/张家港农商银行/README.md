## 公司
性质:其他 · 行业:金融业

张家港农村商业银行于2001年11月27日正式挂牌，是全国首家由农信社改制组建的地方性股份制商业银行。2007年，加快推进体制创新，谋求上市和跨区域发展。2017年1月24日正式挂牌上市（股票代码002839），成为全国首批上市农商行。
