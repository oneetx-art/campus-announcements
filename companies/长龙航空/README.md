## 公司
性质:民企 · 行业:交通/物流/仓储

浙江长龙航空2011年4月19日成立，是省委省政府明确的、省市区三级政府共同持股的浙江省唯一主型骨干基地航空公司，省属国企、民营经济总部型企业、准航空公共服务型企业。截至目前，机队规模74架，开通覆盖全国并通达日韩、东南亚、中亚、欧洲等国际（地区）航线100余条，运输旅客1300万人次，2020年，构建以杭州为中心的“全球12小时”交通圈。围绕航空产业链，组建浙江长龙集团，投资成立飞机维修、航空再制造、教育科技、信息技术、进出口、SPV等公司，投资92.8亿元建设总部基地，总建设用地676.2亩，创新智能维修保障基地及国际航空再制造中心已开工建设，将打造成国际加惠型智慧型的全球一站式航空维修创新示范基地，加快推动航空运输、临空智造、航空货运三大产业协同发展，“三个百亿”产值，打造千亿级航空产业大平台。
