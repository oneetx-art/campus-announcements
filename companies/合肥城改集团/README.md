## 公司
性质:央国企 · 行业:房地产业/建筑业

合肥城改投资建设集团前身系1983年成立的长江路、金寨路沿街改造指挥部，后更名为合肥市城市改造工程指挥部办公室，2006年改制组建为国有独资集团公司，是合肥市国资委重点监管企业，公司注册资本12.5亿元，具备一级房地产开发资质，主营房地产开发投资与建设、城市服务与运营、城市更新、保障性住房建设与运营、物业与城市精细化管理、市政园林建设与维护、存量资产盘活运营、文化体育与旅游等业务，目前共有子企业41家，集团围绕立足合肥深耕合肥的发展理念，积极参与城市建设和微更新改造，充分彰显国有企业的使命担当
