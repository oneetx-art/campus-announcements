## 公司
性质:民企 · 行业:交通/物流/仓储

中州航空应运而生中国经济的蓬勃发展和国家打造自主可控的国际供应链体系战略而生。2016年6月完成工商注册（注册资金6亿元），2019年2月获批筹建，2020年1月获颁《大型公共航空运输企业经营许可证》，2020年4月获颁《航空承运人运行合格证》，2020年5月正式开航。2022年8月，中州航空整体迁移落户中国最大的经济特区和自由贸易港—海南，成为海南省首家全货运主基地航空公司。中州航空管理机制高效，整个团队拥有扎实的安全运行管理能力与成熟的运行品质管理能力。公司现有员工700余人，已投入运行B737F、B777F全货机10余架，货运总量超60万吨，可为客户提供定制化全链条物流增值服务。
