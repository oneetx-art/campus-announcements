## 公司
性质:民企 · 行业:能源/化工/环保

力勤资源成立于2009年，总部坐落于美丽的东海之滨——浙江宁波，于2022年在香港主板上市（股票代码02245.HK）。我们是一家镍全产业链服务商，在镍产品的生产及贸易领域都取得了完整领先地位，掌握了产品火法及湿法冶炼在内的全球镍先代生产工艺，是最早在印尼同时布局火法与湿法项目的中国企业之一。我们完成了对镍产业链环节的垂直整合，业务涵盖了上游镍产品贸易、冶炼生产、销售在内的多个产业环节，产品广泛地应用于新能源、不锈钢等下游领域。
