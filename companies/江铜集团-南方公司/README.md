## 公司
性质:央国企 · 行业:能源/化工/环保

江西铜业集团有限公司简称江铜集团，成立于1979年，属国有企业，是我国有色金属行业大型集团企业，连续12年跻身《财富》世界500强，2025年排名165位；主营业务包含铜、金、银、铅、锌、钴等多金属矿业开发，以及矿业相关贸易、金融、新材料、装备制造、数字经济等。江铜集团南方公司旗下包含两家核心企业，江铜铜业深圳国际投资控股有限公司为集团全资子公司，位于深圳市福田区大中华国际金融中心；江西铜业清远有限公司位于清远市清城区石角镇，以废杂铜等为原料生产加工阴极铜，年产能达20万吨
