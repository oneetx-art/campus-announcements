## 公司
性质:民企 · 行业:医疗/医药/生物

科伦创立于1996年，现已形成由科伦药业、川宁生物、科伦博泰构成的“品”字型架构运营平台，总市值超千亿。科伦积极推进“三发驱动·创新增长”战略，输液领域已具备高端制造和新型材料双重赢利能力，占据了技术创新和质量标杆的战略高地；凭借成熟的发酵技术和强大的产业化平台，公司稳固抗生素主业基本盘并持续优化升级产业结构，全面进军合成生物学领域；在研发创新方面，公司专注于创新药物的研发，成功搭建了享有国际技术的ADC研发平台内涵药物研发、创新型小分子药和生物技术药物等高科技平台，开启创新研发和全球化的新征程。
