## 公司
性质:民企 · 行业:房地产业/建筑业

中济通设计集团有限公司成立于2020年1月，双总部管理。业务范围涵盖工程设计、咨询（创优报奖、智慧工地、品质工程咨询、安全咨询、方案编制、科研课题、工程检测、水运监理）、施工（养护、机电、交安和码头施工）三大业务板块。公司拥有“国优奖”、“李春奖”、“水运优质工程奖”、“扬子杯”评审专家，部省级“平安百年品质工程”和“平安工程”考评专家领衔的100余人专业技术团队。公司拥有设计、科研、建设、施工等多领域的优秀人才，梯队架构完整，汇集清华、同济、东南、重大、重庆交大等高校毕业的博士、硕士和中高级职称人员80余名。2022年完成合同额1.5亿元，2023年合同额2亿元，2024年完成合同额2.5亿元，计划五年内成为行业的“独角兽”企业。
