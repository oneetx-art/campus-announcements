## 公司
性质:民企 · 行业:教育/培训/科研

广州科奥信息技术股份有限公司（简称“科奥股份”）作为科研服务创新生态领导者，成立于2014年，以习近平总书记提出的“要办好一流学术期刊和各类学术平台，加强国内国际学术交流”为发展纲领，深入践行国家“十四五”规划提出的“构建国家科研论文和科技信息高端交流平台”方针，以“人工智能+大数据”双轮驱动，构建一流科研学术服务生态，持续推动科研范式变革与科研服务数字化转型。目前，已累计服务高校和科研院所3000余所，与众多国际头部学术出版机构深度合作，服务用户超300万人次，支持国际学术会议5300余场，国内外合作知名专家学者5万余名，实现自然科学、工程技术、社会科学等学科专业覆盖85%以上，形成覆盖科研全生命周期的一站式服务体系。
