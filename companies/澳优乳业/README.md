## 公司
性质:民企 · 行业:快速消费品

澳优乳业于2003年9月在湖南长沙成立，2009年10月8日在香港联交所上市，是首家在香港上市的婴幼儿配方奶粉企业。从事高端乳品及营养食品的研发、生产和销售，拥有完整产业链条，产品销售至60多个国家和地区，员工4000余人，旗下有多个品牌。
