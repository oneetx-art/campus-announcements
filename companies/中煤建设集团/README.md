## 公司
性质:央国企 · 行业:能源/化工/环保

中煤建设集团有限公司（简称中煤建设集团）是中国中煤能源集团有限公司全资子公司，业务包括矿山建设、生产运营、煤炭洗选、安装运维、建筑施工及工程造价咨询、光伏组件加工、支护材料生产、物流仓储等，可全链条提供能源综合服务。拥有3个矿山工程施工总承包特级资质、18个施工总承包壹级资质、23个施工总承包贰级资质、37个专业承包施工资质、2个煤炭行业甲级资质、2个造价咨询甲级资质，是我国煤炭建设行业领军企业。业务涉及矿山、建筑、电力等领域，国内遍布晋陕蒙新等27个省区，占据国内冻结市场70%份额，年洗选运营产量近4亿吨；积极实施走出去战略，先后承揽了土耳其、孟加拉、摩洛哥、蒙古、越南、印度、南非等国家和地区20多项矿山建设项目，在土耳其的建井市场份额达60%以上。中煤建设集团坚定专精特新发展方向，突出增强企业核心功能、提高核心竞争力，大力实施科技创新战略。参与煤炭无人化开采数智技术全国重点实验室建设，建有省级企业技术中心4个、省级技术创新研究中心3个、省级双创示范基地1个、高新技术企业3家、专精特新中小企业2家、专精特新小巨人企业1家。近年来，获国家级科技进步奖4项、省部级科技进步奖150余项；主…
