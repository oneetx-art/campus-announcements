## 公司
性质:央国企 · 行业:房地产业/建筑业

中国航空集团建设开发有限公司（简称“建开公司”）于2003年7月2日正式成立，系中国航空集团公司（简称“中航集团”）的全资子公司。中航集团是特大型国有航空运输集团公司，也是中国唯一载旗飞行的航空运输企业。建开公司围绕中航集团战略目标，采取市场化运作机制，开展涵盖工程建筑、物业租赁及管理、酒店运营管理、资产运营管理在内的相关业务。建开公司总部位于北京，所涉及业务分布于成都、上海、重庆、广州、武汉、大连、呼和浩特等地。
