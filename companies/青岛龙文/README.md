## 公司

青岛龙文教育咨询有限公司（简称：青岛龙文）成立于2010年4月，前身是龙文教育集团在青岛的直营分支机构（龙文教育集团为A股上市公司）。公司于2015年8月在青岛胶南设立直营第一家综合性成长中心。青岛龙文始终坚持“教育是一项良心工程”的核心理念，以助力学子快速提升升学成绩，用科学方法点燃梦想之灯为己任。
