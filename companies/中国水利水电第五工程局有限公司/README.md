## 公司
性质:央国企 · 行业:房地产业/建筑业

中国水利水电第五工程局有限公司（以下简称公司）是世界500强企业——中国电建集团（股份）公司优势骨干成员企业，是具有对外承包经营权的大型综合性中央企业，国家高新技术企业、国家五一劳动奖状、全国文明单位及全国青年文明号等荣誉获得企业，连续18年获评“四川省百强企业”。公司拥有水利水电施工总承包特级，水利行业设计甲级，市政公用工程、建筑工程、机电安装工程、电力工程总承包一级等40余项资质，职工6700余人。公司年市场营销额超500亿元，年施工能力超300亿元，是国家“一带一路”倡议、“美丽中国”建设的践行者，是新能源和清洁能源建设的主力军。
