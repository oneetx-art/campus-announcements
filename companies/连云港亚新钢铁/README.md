## 公司
性质:民企 · 行业:能源/化工/环保

连云港亚新钢铁有限公司成立于2009年，位于“一带一路”交汇点、新亚欧大陆桥东方桥头堡——江苏省连云港市。公司总投资约30亿元，员工2800余人，其中专业技术及研发人员近1000人，是一家集烧结、球团、炼铁、炼钢、轧钢、运输、仓储、深加工于一体的现代化钢铁企业。近年来，公司积极引进国内外先进技术设备，与多家科研机构开展合作，持续推动企业向高端化、智能化、绿色化方向转型升级，为适应公司快速发展需要，现面向全国高校招聘优秀应届毕业生加入我们的管培生计划，共同谱写钢铁事业新篇章。
