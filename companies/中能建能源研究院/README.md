## 公司
性质:央国企 · 行业:能源/化工/环保

中能建（北京）能源研究院有限公司是中国能源建设集团投资有限公司设立的全资子公司，于2021年9月15日成立，是中国能源建设集团有限公司唯一的以全生命周期研究为核心方向的技术平台，主要为能源投资提供全生命周期智力支持和技术支撑。研究院承载“研究驱动、创造价值”的发展理念，全面推进“12345”发展战略，即围绕能源电力1个核心，培育“科技创新、数智转型”2种能力，聚焦“电力研究、电力气象、电力交易”3大领域，打造“战略研究、产业策划、资产运营、科创创谷”4大智库，拓展“投资咨询、工程咨询、产碳咨询、科技应用”5大作用，招聘“碳电业务、聚焦推动科技创新与产业创新的深度融合，新能源与人工智能的有机结合，运检+培育预测+电碳交易+智慧投资人+智能建造+智慧运维+气象预测+碳电交易，构建“投资咨询+虚拟电厂”新业态的企业与电力综合智慧平台。
