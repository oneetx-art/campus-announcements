## 公司
性质:央国企 · 行业:机械/制造业

航天物联网技术有限公司成立于2017年，是以航天科技集团物联网技术应用研究院为创新平台的国家级高新技术企业。公司聚焦军事智能化、低空基础设施、企业数字化、民口生态集成转化等领域，形成军事物联网、军事信息化系统建设、数据工程、泛在智联、企业数字化转型、民口产品生态六大业务方向，是国内最早开展航天物联网技术研究和应用的单位之一，秉承“以航天智慧产品为客户创造价值”的企业使命，致力于打造物联网领域国内领先、国际一流的高科技公司。
