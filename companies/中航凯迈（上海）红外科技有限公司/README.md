## 公司
性质:央国企 · 行业:机械/制造业

中航凯迈（上海）红外科技有限公司（简称“中航红外”）是中国空空导弹研究院控股子公司，主要从事民用红外探测器及红外光学研发生产，年产值近10亿元。公司建有红外探测器技术航空科技重点实验室、河南省探测器工程技术研究中心等，拥有优秀的人才和技术基础。技术人员中20余人博士，110余人硕士，90%以上研究生占比。
