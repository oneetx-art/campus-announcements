## 公司
性质:央国企 · 行业:房地产业/建筑业

中建交通华北公司成立于2018年11月，总部位于天津市南开区。近三年来，公司发展进入了快车道，公司规模持续扩大，经营质量稳步提升，企业可持续发展能力不断增强。公司深耕东北区域，积极融入京津冀协同发展与粤港澳大湾区建设，合同额实现逐年攀升，初步形成了布局东北、京津冀、江浙沪、粤港澳及海南的区域布局。在人才引进、培养和激励，为企业注入了强劲活力探索创新，汇聚大量优秀青年人才机制方面，公司不断探索创新，汇聚大量优秀范围广泛涵盖公路、市政、房建、工业厂房及基建等多个领域。
