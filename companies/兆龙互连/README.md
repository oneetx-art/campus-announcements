## 公司
性质:民企 · 行业:通信/电子/半导体

兆龙互连（SZ.300913）创建于1993年，是专业从事数据线缆、专用线缆和连接产品设计，制造与销售的高新技术企业，是中国通信标准化协会全权会员、数据电缆国家标准起草单位。产品远销全球100多个国家和地区，广泛运用于大型数据中心、云计算、人工智能、工业自动化、轨交机车、海工船舶、机器人、机器视觉、医疗器械、新能源、智能安防、智能楼宇、智慧城市等领域的数据传输与连接。公司现有员工2000余人，总部位于浙江省德清县，建筑面积约16万平方米，在上海、北京、杭州、深圳等多个城市设有分子公司，台北设办事处。公司于2023年在泰国新设生产基地，LONGTECK INTERCONNECT (THAILAND) CO.,LTD.，即龙腾互连（泰国）有限公司，位于泰国东部经济走廊（EEC）的春武里府。
