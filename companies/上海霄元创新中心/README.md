## 公司
性质:事业单位 · 行业:教育/培训/科研

上海霄元创新中心是上海市成立的新型研发机构（事业单位），致力于打造太空领域突破型、引领型、平台型一体化的国家战略科技力量，主要从事太空领域战略性、前瞻性、基础性重大科学问题研究和关键技术攻关，推动形成基于大数据、大模型、大算力的智能化科研范式。上海霄元创新中心自成立以来，积极引进国内外顶尖学者、青年才俊和专业管理人才，汇聚了一批本领域核心人才，多人担任国家/省部级重点工程项目专家。单位位于上海市闵行区梅锦镇核心区，由15幢楼宇组成独立园区，建筑面积6.95万平方米，地理位置优越，交通便利，环境优美。
