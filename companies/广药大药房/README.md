## 公司
性质:央国企 · 行业:医疗/医药/生物

广药大药房（广东）有限公司（国有企业）是世界500强企业“广药集团”旗下核心药品零售企业，由广州医药股份有限公司全资控股，已连续4年被中国医药商业协会评为全国药品零售行业百强，最新排名第27位。公司现有70多家门店，覆盖了全广东省20个地级市，线上商城入驻天猫、京东、美团、饿了么等平台；专注经营新特药、慢病用药、罕见病用药等DTP产品，以及品类齐全的OTC产品、特殊医学食品、营养保健品、医疗器械和医学美容产品等，常备SKU达18000个，为患者提供专业的药物外配和全病程跟踪的MTM（药物治疗管理）服务。
