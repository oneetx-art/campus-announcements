## 公司
性质:央国企 · 行业:通信/电子/半导体

成都四威高科技产业园有限公司（简称：四威高科）成立于2001年，位于四川省成都市高新区，是中国电子科技集团公司第二十九研究所全资子公司。公司主要业务为机电产品与智造服务，核心产品包括技保指控产品、热控产品、电子化学件产品、光电与互联产品及军工电子零部件，服务对象涵盖航空、航天、船舶、兵装、电子等十大军工企业及下属配套企业，年营业规模超9亿元。公司占地面积200余亩，现有职工500余人，拥有国家高新技术企业、国家级技能大师工作室、省企业技术中心、省专精特新企业等创新平台。曾获全国总工会模范职工之家称号，员工累计获得国务院政府特殊津贴、中华技能大奖、省劳动模范、省突贡专家、成都工匠等荣誉百余人次。
