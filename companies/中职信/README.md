## 公司
性质:民企 · 行业:财务/审计/税务

广东中职信会计师事务所（特殊普通合伙）于2008年10月底成立，2020年6月完成改制，成为首批在财政部、证监会完成备案的46家会计师事务所之一。成立16年来，坚持党建引领、坚持诚信经营、坚持一体化管理、坚持“三个不做”、坚持专业分工、坚持质量优先、坚持多元融合、坚持智能审计、坚持廉洁从业、坚持服务取胜。在鉴证、增信、增值服务等方面积累了丰富的经验和良好的口碑。全国百强事务所，目前在深圳、成都、昆明、海口、郑州、东莞、佛山、江苏设有分支机构，2023年4月与澳门惟世事务所签订联营协议，中职信（香港）于2024年1月成立。
