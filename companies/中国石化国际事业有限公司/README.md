## 公司
性质:央国企 · 行业:能源/化工/环保

中国石化国际事业有限公司成立于1983年，系中国石化全资子公司，是我国改革开放后成立较早的国际贸易公司之一。2009年4月，中国石化物资装备部、国际事业有限公司、物装（北京）公司3家单位重组整合，实行一套机构、三块牌子，履行中国石化'物位管理部、中央采购部、国际贸易归口'管理组织职能，对物资供应工作实施归口管理，统一实施生产建设所需大宗、通用、重要物资的集团化采购，经营化工辅料酒煤炭、材料、设备及部分炼化产品等国际贸易业务。本部设有15个部室，境内在北京、上海、天津、重庆、南京、武汉、宁波、湛江、大连等城市设有12家子公司，并依托现有境内机构设立9个招标中心；境外在美国、日本、在德国、俄罗斯、阿联酋等国家设有9家子公司或办事机构。
