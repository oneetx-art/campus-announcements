## 公司
性质:央国企 · 行业:机械/制造业

中国航空工业集团有限公司是由中央管理的国有大型企业，经营范围涵盖航空武器装备、军用运输类飞机、直升机、机载系统、通用航空、航空研究、飞行试验、航空供应链与军贸、专用装备、汽车零部件、资产管理、金融、工程建设等产业。中国航空工业集团公司西安航空计算技术研究所（简称中国航空工业集团计算所）创建于1958年，出身于中国科学院，是高安全、高可靠的嵌入式计算机及电子信息系统解决方案的提供商。经过60多年的发展，建成了新型技术预研、型号研制、产品批产、维护保障等完整的专业体系，为我国航空武器装备的发展做出了突出贡献，是国内嵌入式计算机和嵌入式基础软件领域的领军单位。
