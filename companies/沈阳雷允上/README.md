## 公司
性质:民企 · 行业:医疗/医药/生物

沈阳雷允上药业有限责任公司前身是沈阳药科大学制药厂，始建于1958年，经过近60年的不断努力与发展，现已成为一家集科研、生产、销售为一体的现代化股份制高科技制药企业。2011年加入中国远大医药健康集团，2014年并入远大旗下的雷允上药业集团，为谋求企业整体发展，加快产业发展步伐，中国远大集团和沈阳药科大学共同决定将企业整体南迁到辽宁本溪“中国药都”，同年通过了新版GMP。
