## 公司
性质:民企 · 行业:医疗/医药/生物

康诺亚生物医药科技（成都）有限公司是一家专注于创新生物药研发和生产的综合性生物制药公司，提供更具世界范围竞争力、高质量、可负担的医疗方法。创始团队成员均为国际生物制药行业顶尖专家，具有世界级科技成果转化和卓越的国内外产业化经验。公司于2016年成立，总部设于成都，在北京、上海、武汉、南京、广州、济南多地设有分支机构，现有员工超过1600人，2021年在香港联合交易所主板上市（香港联交所代码：02162）。
