## 公司
性质:民企 · 行业:通信/电子/半导体

中国航天科工二院二十三所成都航天博目电子科技有限公司，注册地位于成都市金牛区，在北京设有分公司。公司聚拢集团优势资源，以装备技术需求为牵引，开展射频微系统技术和产品的研发配套，在西南区域着力打造开放式硅基先进封装工艺线和GaN射频工艺线。航天博目以“建设成一流的射频微系统IDM企业”为目标，开展业务包括：微系统与模组研制、高端射频模拟芯片研制、“氮化镓+硅基封装集成”工艺制造服务，为发挥国资央企战略支撑作用、履行强军使命贡献坚实力量。
