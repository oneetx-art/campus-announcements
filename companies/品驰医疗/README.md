## 公司
性质:民企 · 行业:医疗/医药/生物

品驰医疗创立于2008年，是“神经调控国家工程研究中心”的组成单位，与清华大学、众多临床医院紧密合作，建立起“产学研医”协同创新模式。品驰医疗创立以来，先后承担了多项国家重点研发计划、国家科技支撑计划、北京市重大科技专项计划等课题取得了众多完全自主知识产权的研究成果。先后获得了系列脑起搏器、迷走神经刺激器、骶神经刺激器和脊髓刺激器产品注册证并上市销售，打破了美国公司在神经调控产品领域的垄断。
