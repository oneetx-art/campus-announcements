## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

广西旅游发展集团有限公司（简称“广旅集团”）是2014年由广西城建投资集团和广西旅游投资集团合并重组成立的自治区政府直属大型国有独资企业。自成立以来，广旅集团坚定不移贯彻落实自治区党委、政府构建“三地两带一中心”文旅产业发展新格局的部署，整合广西旅游资源，做大做强广西旅游业。广旅集团以“文旅、康养、城建”为三大主业，涵盖“文旅、康养、城建、科技、金融、实业”六大业务板块，是广西旅游行业中旅游业态最完整、产业链条最长、资本实力最雄厚的大型国有企业。
