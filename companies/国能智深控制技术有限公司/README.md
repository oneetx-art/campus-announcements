## 公司
性质:民企 · 行业:机械/制造业

国能智深控制技术有限公司成立于2002年，是国家能源集团下属的国有控股高科技企业。公司智能管控系统广泛应用于电力、水泥、钢铁、石油、化工、新能源等行业，形成了10+全国行业市场，是国家专精特新“小巨人”企业，国家“新一代”和“核安全”系统的“双示范”企业，牵头创建世界一流智能电厂双示范工程，承担国家工信部重点产业的“工控主”任务。2025年，国能智深公司拥有正式员工451人，其中博士人员占比47.5%。
