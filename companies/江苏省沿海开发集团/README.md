## 公司
性质:央国企 · 行业:房地产业/建筑业

江苏省沿海开发集团有限公司是江苏省政府为实施沿海开发战略于2010年批准成立的省属国有企业，由江苏省国资委履行出资人职责，是省级综合性沿海开发投资主体平台，注册资本80亿元，总资产152亿元，净资产113亿元。集团贯彻落实省委省政府向海发展、向海图强的发展部署，坚持高起点高标准高水平，深耕沿海、打通江海、产业联动、绿色发展，打造江苏沿海核心战略开发平台与高质量发展引擎，全力服务沿海开发建设。集团坚持人才强企战略，广纳贤才，才尽其用，持续优化人才队伍结构
