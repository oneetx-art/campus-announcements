## 公司
性质:央国企 · 行业:房地产业/建筑业

世源科技工程有限公司成立于2003年，是中国电子工程设计院股份有限公司为追求“科技型企业、集团化管理、国际工程子公司”的企业发展目标，整合工业板块资源改制创建的全资中央企业。公司聚焦平板显示、半导体、生命科学、数据中心等国家战略新兴产业，积极拓展水处理、节能环保、产品制造、微振动、电子化学品等专项工程及增值服务，为高科技领域工程建设提供规划咨询、工程设计、工程管理、工程总承包等全方位、全过程、一体化的综合解决方案。公司总部设于北京，在上海、合肥、西安、成都、武汉、深圳、厦门等多地设有分支机构，形成了围绕京津冀、长三角、粤港澳大湾区、长江经济带等主要城市群的全国性服务网络。
