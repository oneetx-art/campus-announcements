## 公司
性质:央国企 · 行业:金融业

中国邮政储蓄银行是中国领先的大型零售银行，定位服务“三农”、城乡居民和中小企业。2019年邮储银行全面完成“股改—引战—A、H两地上市”三步走改革路线图，拥有优异的资产质量和显著的成长潜力。山东省分行2007年12月28日正式挂牌成立，下辖二级分行16家、一级支行131家。自成立以来，在各级政府、金融监管部门以及社会各界的关心和支持下，始终坚持以客户为中心，自觉承担“普之城乡，惠之于民”的社会责任，资产规模达到1.4万亿元，为山东经济社会发展做出了积极的贡献。
