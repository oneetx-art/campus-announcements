## 公司
性质:央国企 · 行业:机械/制造业

中国航发哈尔滨东安发动机有限公司始建于1948年，是国家“一五”期间156项重点建设工程之一，是新中国首批六大航空企业之一，是以研制生产航空动力、航空机械传动系统和航空机电产品为主的航空制造企业，现有职工5000余人，占地面积120万平方米。公司先后荣获国务院、行业和地方授予的各种荣誉称号，荣获全国五一劳动奖状、全国文明单位、全国绿化模范单位、全国企业文化建设优秀单位、军工文化建设十佳单位、全国文化示范单位、全国质量效益型先进企业等荣誉称号。
