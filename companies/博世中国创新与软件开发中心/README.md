## 公司
性质:外企 · 行业:汽车制造/维修/零配件

博世中国创新与软件开发中心（Bosch China Innovation and Software Development Campus，以下简称BCSC）成立于2020年4月，是博世集团全球四大软件开发中心之一。BCSC总部设立于苏州及中国中心城市，辐射南京、无锡等创新合作单位。自创立以来，BCSC聚焦智能化、电子与软件领域的未来创新技术突破与解决方案，核心业务涵盖智能驾驶、智能座舱、智能网联、车载计算平台、自动驾驶、大数据、嵌入式软件架构等。现服务客户涵盖国内主流汽车及零部件制造商，同时与国内高校、科研院所开展三维建设，在无锡、南京、成都、苏州、上海建有研发中心，目前，中心已聚集500+人，人均研发经验超5年，累计申请60+项自主知识产权，未来将持续在软件开发、智能驾驶、新能源领域深耕，打造人才培养、技术创新的核心阵地。
