## 公司
性质:央国企 · 行业:贸易/批发/零售

厦门建发通商有限公司是一家以供应链运营为主的现代服务型企业。公司成立于2011年11月，注册资金5000万元，为厦门建发股份有限公司（股票代码：600153）旗下全资子公司，隶属消费品集团。建发通商主要经营服装、纺织品、建材、家电、机电设备与配件、食品等消费品的进出口贸易。公司以“开拓新价值，让更多人过上更有品质的生活”为使命，以“整合资源，创造增值”为品牌核心价值，为客户提供供应链运营服务。
