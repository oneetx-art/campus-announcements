## 公司
性质:合资 · 行业:机械/制造业

华晨宝马汽车有限公司成立于2003年5月，是宝马集团和华晨汽车集团控股有限公司共同设立的合资企业（宝马集团持股75%），业务涵盖整车及零部件在中国的研发、采购、生产、销售和售后服务。华晨宝马沈阳生产基地，是宝马全球生产网络中规模最大的生产基地。现有员工2万余人，~460家本土供应商。
