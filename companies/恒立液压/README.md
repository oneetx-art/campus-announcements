## 公司
性质:民企 · 行业:机械/制造业

江苏恒立集团于1990年创办，总部位于江苏常州。恒立30多年的创新发展，恒立液压从液压油缸制造发展成为集液压油缸、液压泵阀、液压马达、线性传动、精密铸件及子控制元件等系列产品研发、制造于一体的大型综合性企业，也是中国液压行业的龙头企业。产品遍及工程机械、港口机械、能源开采、隧道掘进机、工业制造、农业机械等诸多行业。公司注册资本13.4亿元，SH601100，在上海交所A股上市（证券代码：00600）。公司先后在国内投资建立恒立股份（油缸厂）、恒立液压科技（气动阀）、恒立铸造智能七大先进制造基地，并出资并购上海立新、德国德柏林InLine、日本本部精工三大品牌和工厂，还在海外成立日本、美国、墨西哥、印尼、巴西、西班牙等制造及销售服务公司，积极开拓海外市场，公司处于快速发展阶段，现诚邀你的加入！
