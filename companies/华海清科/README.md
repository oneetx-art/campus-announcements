## 公司
性质:民企 · 行业:通信/电子/半导体

华海清科股份有限公司（简称“华海清科”，股票代码：688120）是一家拥有核心自主知识产权的高端半导体装备制造商。公司主要产品包括CMP装备、减薄装备、划切装备、湿法装备、离子注入装备、边缘抛光台、晶圆再生、关键耗材与维保服务，打造“装备+服务”的平台化战略布局。公司第三代半导体装备已广泛应用于集成电路、先进封装、大硅片、功率半导体、MEMS、Micro LED等制造工艺。
