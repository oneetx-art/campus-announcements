## 公司
性质:民企 · 行业:IT/互联网/游戏

北京并行科技股份有限公司（简称：并行科技）成立于2007年，总部坐落于北京，专注算力服务十九载，已服务数万客群，于2023年11月登陆北交所（股票代码：920493）。并行科技以HPC和AI技术优势及海量算力资源池为依托，打造了并行AI智算云、并行MaaS平台、并行智造云、并行超算云、设计仿真云、算力调度平台、算力运营服务等产品，为人工智能、智能制造、教育科研、生命科学、地球科学等领域提供专业的算力解决方案。
