## 公司
性质:央国企 · 行业:交通/物流/仓储

山东海洋集团是经山东省人民政府批准设立的省属大型国有企业，2010年9月成立，注册资本50亿元，总部设在济南市，拥有8家一级权属企业，布局现代远洋运输物流、现代海洋渔业、海上工程服务等多个涉海产业领域，是具有行业影响力的综合性海洋产业集团，致力于打造现代海洋产业投资控股集团
