## 公司
性质:央国企 · 行业:能源/化工/环保

云南云内动力集团有限公司是由1956年成立的原云南内燃机厂改制成立的国有控股有限责任公司，并于2014年1月完成工商注册登记变更为现名。公司是国有大一型企业，是国家重点扶持的512家企业之一。企业规模：经过60多年的发展，通过资源整合、招宣业务、全面发展，做大做实等一系列战略规划，公司目前拥有昆明云内动力股份有限公司、成都云内动力有限公司、遂宁云内动力机械制造有限公司、昆明客车制造有限公司、云南凯瑞特科技有限公司、苏州图南汽车制造有限公司、云南云内动力机械制造有限公司等多家子公司。
