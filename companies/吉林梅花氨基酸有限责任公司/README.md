## 公司
性质:民企 · 行业:医疗/医药/生物

梅花集团公司成立于2002年，2010年在沪市A股上市(SH.600873)，目前职工规模近1.3万人，是合成生物学全球氨基酸发酵领域的龙头企业。多年来通过卓越稳定的产品质量以及诚信的口碑建立了良好的市场形象，打造了行业内知名的“梅花”品牌，连续3年营业收入近300亿元，持续领跑全球氨基酸行业。2021年，公司发布“致力于成为合成生物学的领军企业”这一新的战目标；2024年，在新加坡设立全球总部，开展国际产业投资和技术合作，国际化战略正式开启。吉林梅花氨基酸有限责任公司是梅花生物科技集团在白城设立的全资子公司，于2017年8月注册成立，聚焦饲料级氨基酸、食品添加剂等产品的研发与制造。
