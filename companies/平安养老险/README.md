## 公司
性质:民企 · 行业:金融业

平安养老险于2004年12月在上海成立，是国内首家专业养老险公司。公司拥有遍布全国的服务网络和优秀的专业团队，设立35家分公司。平安养老险聚焦养老主业，以“国内领先的养老金融服务机构”为目标，推动养老与健康管理融合，助力国家积极应对老龄化战略。公司积极响应国家建设多层次养老保障体系的号召，深入探索养老三支柱建设。公司经营企业年金受托、企业年金投资、职业年金受托、职业年金投资及其他委托管理等业务。截至2024年末，公司管理的企业年金受托及投资资产净值8557.93亿元。
