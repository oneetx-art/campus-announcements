## 公司
性质:央国企 · 行业:金融业

天津渤海轻工投资集团有限公司（简称“渤轻集团”）是市国资委直接监管的企业集团，以轻工先进制造及品牌运营、资产管理与运营为主业，控、参股企业中拥有多个中华老字号和津门老字号，与中粮可口可乐、韩国LG电子等大型国际国内公司合作打造了一批具有较强影响力的合资企业。目前，渤轻集团聚焦主责主业，狠抓传统制造产业转型升级，大力推进“老字号”品牌振兴发展，深化拓展合资合作，积极培育战略性新兴产业，全力打造“品牌引领、轻重结合、守正创新、员工幸福、高质发展”的轻工产业投资集团。
