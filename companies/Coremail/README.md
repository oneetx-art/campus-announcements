## 公司
性质:民企 · 行业:通信/电子/半导体

Coremail始创于1999年，专注电子邮件技术及服务，先后推出自主可控的全新邮件系统、邮件客户端、安全网关等产品，目前拥有超过10亿终端用户。经过26年的深入研发和完善，系统技术成熟，性能稳定高效，是众多知名企业及政校高校搭建邮件服务器系统及企业邮箱的首选方案。公司总部设立于广州，在北京、上海、深圳、武汉、成都、西安、南京、杭州、香港、泰国曼谷等地均设有分支机构。
