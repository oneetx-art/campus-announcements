## 公司
性质:民企 · 行业:机械/制造业

江苏长虹智能装备股份有限公司成立于1989年，是从事汽车工厂的规划和设计，汽车及轨道交通领域的涂装、总装、焊装生产线的设计、制造、安装、调试和售后服务的国家高新技术企业。公司占地面积22万平方米，建筑面积12万平方米，注册资本7902万元，员工600余人。长虹智能坚持以“长虹智造，助力客户，造福人类”为使命，用完善的技术、精湛的工艺和优质的服务持续为客户创造更大的价值和效益，努力实现“为全球汽车行业提供创新度、智能化和高性价比的智造装备”的愿景。
