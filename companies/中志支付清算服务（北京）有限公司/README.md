## 公司
性质:央国企 · 行业:IT/互联网/游戏

中志支付清算服务（北京）有限公司是中国人民银行清算总中心的全资子公司，于2013年8月8日在京注册成立。主要承担中央银行会计核算数据集中系统（ACS）、数字供应链金融服务平台（DSPP）、金融机构对账服务平台（IARS）的建设、运营与管理，积极践行“金融为民、支付利民”服务理念。
