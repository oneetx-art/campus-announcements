## 公司
性质:央国企 · 行业:房地产业/建筑业

中国江苏国际经济技术合作集团有限公司（简称“中江国际集团”）于1980年经国务院批准成立，是全国最早获批对外经营权的8家综合性国有外经企业之一，也是我省唯一一家冠以“中国”字号、以工程承包为核心业务、全球市场布局的省属国有企业。经过多年发展，集团已在全球四十多个国家和地区设立常驻机构，在100多个国家和地区开展外经贸业务，连续31年入选美国《工程新闻记录》（ENR）评定的“全球250家最大国际承包商”，多年荣获中国服务业企业500强、中国建筑业竞争力200强。
