## 公司
性质:民企 · 行业:能源/化工/环保

潮州华丰（集团）股份有限公司创立于1998年，是以液化石油气（LPG）、液化天然气（LNG）、成品油、化工品、新能源、科研为主营业务的“科技+实业” 是国企企业集团，拥有LNG进口、加工及销售牌照。所属华丰华能国际船舶代理有限公司于2006年在新加坡上市，是潮州第一家海外上市公司。拥有全国最大LPG进口、加工及储存能力，拥有6万吨级、2万吨级专用码头、 12万立方米的大型冷冻液库。
