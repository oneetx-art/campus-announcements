## 公司
性质:民企 · 行业:机械/制造业

广东康德威电气股份有限公司成立于2003年，位于东莞市东坑镇，毗邻松山湖高新技术开发区，是一家专业从事配电变压器、高低压成套开关设备、智能化配网设备的研发、制造、销售于一体的国家高新技术企业。康德威是国家高新技术企业、国家级重点“小巨人”企业和省级“专精特新”企业，公司同时是全国变压器标准化技术委员会委员。公司产品主要包括油浸式电力变压器、干式电力变压器、组合式变压器等，产品获KEMA、ASTA等国际认证，业务遍布全国及海外多个地区。
