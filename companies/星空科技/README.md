## 公司
性质:民企 · 行业:通信/电子/半导体

智慧星空（上海）工程技术有限公司是一家致力于提供半导体、泛半导体等行业领域创新装备相关技术和服务的公司，国家高新技术企业、专精特新企业。主要产品包括光刻设备、自动键合设备、纳米压印设备、光学检测设备、芯片位置测量设备等高端智能装备。公司以研发高端制造设备，实现产业化为使命，以精密机械、精密光电、精密运动、精密控制以及系统设计和集成技术为核心，技术技能涵盖系统设计、系统软件和集成等多学科领域。
