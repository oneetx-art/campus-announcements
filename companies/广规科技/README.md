## 公司
性质:央国企 · 行业:房地产业/建筑业

广东城乡规划设计研究院科技集团股份有限公司（以下简称“广规科技”）成立于1958年，是全国首批200家本出工程勘察专业资质单位，拥有城乡规划设计、土地规划、国土空间规划编制等高级人才300余人，具备城乡规划（国土空间规划）编制、建筑行业（建筑工程）、市政行业（道路工程）、风景园林工程设计、测绘（工程测量、地理信息系统工程）、工程咨询（城市规划、建筑、市政公用工程）等6个甲级资质和资信，业务市场遍布全国20余个省（自治区、直辖市）。
