## 公司
性质:央国企 · 行业:能源/化工/环保

国网青海省电力公司是国家电网有限公司的全资子公司，以建设运营电网为核心业务，承担看保障安全、经济、清洁、可持续的电力供应的基本使命，先后建成青藏联网、青新联网、玉树联网、果洛联网、青豫特高压等重大标志性工程，连续多年保持“青海企业50强”前三名。青海电网位于西北电网中西部，是东接甘肃、南联西藏、西引新疆和直通中原的交直流混联电网，是西北电网骨干网架的重要组成部分。当前，青海省清洁能源装机占比及新能源装机占比均位居全国之首，两个千万千瓦级清洁能源基地全面建成，是当之无愧的国家清洁能源发展“桥头堡”。国网青海电力作为省内能源行业的龙头企业，在多能互补、新能源大数据、全清洁能源供电等领域独树一帜，加快构建以新能源为主体的新型电力系统，保持清洁能源装机、新能源装机占比“双第一”，率先实现新能源装机和发电量“双主体”，建成并优化升级国内首个清洁能源和绿色算力调度中心，完成全国首次、青海首笔跨国网经营区域绿电交易，正朝着建成国网首批新型电力系统省级示范区，助力青海率先实现碳达峰、碳中和的宏伟目标加速前进。
