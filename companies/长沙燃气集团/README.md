## 公司
性质:央国企 · 行业:能源/化工/环保

长沙市燃气实业有限公司（以下简称“长沙燃气集团”）起源于1987年，经长沙市人民政府批准，于1992年6月18日注册成立，前身为长沙市燃气总公司，是湖南省燃气行业的龙头企业，也是湖南商会长沙清洁湖能源制造化气的历史创造者与建设者。三十余年来，公司完成制气工程建设运营、管道燃气建设、天然气引入、引资合营、企业整体改制、非燃股权减持等一系列重要工作，逐步发展成为一家现代市属国有企业。
