## 公司
性质:合资 · 行业:贸易/批发/零售

施德瑞亚洲有限公司是一家源自于中国的国际工程公司，聚焦于海外基础设施、油气、新能源、矿山、水等领域的工程项目。为项目提供设计、采购、制造、施工及项目管理等一站式服务。公司于2008年在香港注册成立，总部位于上海，目前在欧洲、南北美洲、澳洲、中东北非、东南亚等地有二十余家海外子公司。落实项目遍布八十余个国家。
