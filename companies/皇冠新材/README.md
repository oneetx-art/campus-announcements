## 公司
性质:民企 · 行业:机械/制造业

皇冠新材创始团队90年代初进入胶粘新材料领域，2000年创立公司。专注于研发、生产工业级、电子级胶粘材料及功能性薄膜，为轻工业、家用注电、汽车制造、新能源电池、消费电子、智能物联等行业提供粘接解决方案。集团拥有中山、江门、苏州、湖州和越南五个生产基地，掌握核心技术和精密涂布工艺，国内外设立16个销售办事处，产品销往30多个国家和地区。皇冠荣获“中国名企”、“专精特新”等60余项荣誉，赢得社会、合作伙伴以及同行的广泛认可和赞誉。皇冠新材致力于成为行业技术先行者，打造国际品牌。
