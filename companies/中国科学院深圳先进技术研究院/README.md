## 公司
性质:事业单位 · 行业:教育/培训/科研

中国科学院深圳先进技术研究院（简称“深圳先进院”）由中科院、深圳市人民政府和香港中文大学于2006年共同建立，是中科院深圳院区（筹）的核心科研机构。依托于深圳先进院，中科院深圳理工大学（筹）于2020年12月成立，已纳入广东省高校设置“十四五”规划。
