## 公司
性质:央国企 · 行业:农林牧渔

江苏省农垦集团有限公司是江苏省人民政府出资设立的大型省属商业一类企业，注册资本金33亿元，经营业绩连续多年稳居全国农垦省属企业前列。经过74年的改革发展，江苏农垦建成以现代农业为核心，以医药健康、房地产及相关投资为支撑的一二三产融合发展的产业体系。集团拥有直属企业单位40个，其中农场企业18个，直属全资（控股）企业16个，派出机构6个。3家企业获评“全国文明单位”，3家企业荣获“江苏省省长质量奖”，整合资源组建江苏省农垦农业发展股份有限公司。
