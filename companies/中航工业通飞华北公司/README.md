## 公司
性质:央国企 · 行业:机械/制造业

中航通飞华北飞机工业有限公司，简称中航工业通飞华北公司，是中国航空工业集团有限公司所属骨干企业，是中国通用飞机有限责任公司的核心成员单位，是国内领先的通用飞机专业化主机厂。公司坐落于河北省石家庄市，占地面积901亩，厂房设施14万平方米，拥有200米跑道A1类通用机场一座。公司以通用飞机研发制造为核心业务，具有丰富的通用飞机研发、制造、适航、维修的经验和能力；具有机加、钣金、钳焊、复合材料加工、表热处理以及级机部装、总装、试飞等综合能力。公司是省级飞机装 中心、省工业企业A级研发机构、河北省认证，取得国家国防科工局颁发的《计量认可证书》，拥有自营进出口经营权资格。
