## 公司
性质:央国企 · 行业:金融业

国泰君安期货有限公司是国泰海通证券股份有限公司全资子公司，服务期货和衍生品客户的重要金融机构，中国期货和衍生品市场创新发展的见证者、参与者和引领者。公司注册资本55亿元，营业收入、净利润、客户数量、客户权益总额、市场份额等经营指标连续多年位列期货行业第一梯队，各业务均保持行业领先的发展态势。公司多次荣获期货行业评选的优秀会员白金奖、中国最佳期货公司、最佳金融期货服务奖等荣誉称号和奖项。公司总部位于上海，在上海、北京、深圳、杭州等地设有20余家分公司，同时，拥有遍布各地的400余家证券IB营业部，业务网络覆盖全国。公司在境内、境外分别拥有国泰君安风险管理有限公司和国泰君安期货（新加坡）有限公司等2家全资子公司。公司及全资子公司能够为各类客户提供商品期货经纪、金融期货经纪、期货交易咨询、资产管理、场外衍生品、期现业务、跨境衍生品等综合金融服务。
