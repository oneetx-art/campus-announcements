## 公司
性质:央国企 · 行业:房地产业/建筑业

北方爆破科技有限公司成立于1997年，是兵器工业集团民爆产业国际化的重要运营平台，也是一家具备现场混装炸药技术、爆破设计及施工一体化服务能力的高新技术企业，公司具有矿山工程施工总承包一级资质及爆破作业一级资质。2021年7月20日，北方爆破公司正式成为江南化工的全资子公司。北方爆破科技有限公司牢记“国之大者”，始终坚持一体化、国际化发展战略，加快创新驱动发展，持续推进资源整合，着力构建国内、国际双循环发展新格局，已形成穿爆一体化服务、矿山总承包、销爆三大主营业务。目前，公司国内业务已覆盖北京、辽宁、内蒙古、陕西、湖北、新疆、西藏等区域；国际化业务已实现纳米比亚、刚果（金）、蒙古、塞尔维亚、利比里亚、圭亚那、缅甸等国家的产业布局。
