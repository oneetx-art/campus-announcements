## 公司
性质:央国企 · 行业:通信/电子/半导体

中通服网盈科技有限公司始建于2008年，隶属于中国电信集团下属的上市公司中国通信服务有限公司，2015年1月注册为独立法人，注册资本2.6亿元。公司总部设于江苏省南京市，下设15个分公司及若干管理和业务部门，服务范围覆盖江苏省全域（全部县区），并延伸到北京、河北等其他26个省（直辖市、自治区）。公司资质类型全面，业务范围广泛，以通信维护、渠道运营、工程建设、系统集成、话务服务为依托，不断创新突破，实现在大数据、物联网、招标代理、数字传媒等领域的成功拓展。近年来，公司先后获得国家级高新技术企业、江苏省文明单位、南京市总部企业等荣誉称号；多个项目荣获江苏省优秀信息通信施工奖项；连续5年荣膺国家商务部中国服务外包领军企业百强企业称号。
