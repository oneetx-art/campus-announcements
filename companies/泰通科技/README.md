## 公司
性质:民企 · 行业:通信/电子/半导体

南京泰通科技股份有限公司（简称“泰通科技”），股票代码：832602，成立于2001年，总部坐落南京市雨花台区，注册资本1.5亿元，是国家级高新技术企业和国家级专精特新小巨人企业。2015年在新三板创新层挂牌。建有30,000㎡产业园区，拥有近300名员工。二十多年来，泰通科技专业从事高铁/铁路无线通信信息（ICT）、信号控制（CTCS）、物联网与人工智能系统装备（AIoT）的研发、集成、制造、销售与服务。依靠自主创新，拥有自主知识产权近500项，其中发明专利近30项，参与原铁道部与国铁集团的标准制定近20项，是中国GSM-R无线通信系统四大供应商之一，也是国铁集团新一代无线通信系统（5G-R）参研单位之一。公司为青藏铁路、川藏铁路、贵南高铁、郑西高铁等国内多项国家重点工程及雅万铁路、中老铁路等海外铁路建设项目提供了无线通信系统设备、物联网及灾害监测系统设备。在国家“一带一路”和“发展新质生产力”的战略指引下，泰通科技将紧抓国铁集团《新时代交通强国铁路先行规划纲要》和《数字铁路规划》的发展机遇，致力于成为智能铁路的创新引领者！
