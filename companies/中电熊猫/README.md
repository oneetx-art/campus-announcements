## 公司
性质:央国企 · 行业:通信/电子/半导体

南京中电熊猫信息产业集团有限公司（以下简称中电熊猫）是中央企业——中国电子信息产业集团有限公司（以下简称中国电子）控股的国有大型电子信息产业集团公司，资源兴5月，为整合南京地区电子企业的资源，振兴南京老电子工业基地，复兴“熊猫”民族品牌，推动南京电子信息产业转型升级，中国电子与江苏省、南京市联合重组南京地区7个原部属企业，成立了中电熊猫。
