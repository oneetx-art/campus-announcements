## 公司
性质:央国企 · 行业:金融业

宁波金融资产管理股份有限公司成立于2017年2月，经宁波市人民政府批准设立，由中国银保监会核准公告，开展辖内金融企业不良资产批量收购处置业务的资产管理公司。公司自成立以来，始终秉承依法合规、安全稳健的经营理念，坚守“服务于区域金融风险化解，服务于困境企业帮助扶持，服务于实体经济转型升级”的使命，坚持市场化、法治化、专业化原则，根植宁波、深耕浙江，以不良主业为核心，着力发展不良债权经营和特殊机遇投资等业务，稳步拓展业务布局和经营触角，已先后在福州、南京、广州等地设立异地业务团队，保持了健康快速的发展态势。未来，公司将持续深耕不良主业，积极创新业务模式，打造价值发现、价值修复、价值提升的精业务能力，坚定不移推进“区域深耕、价值创造和持续发展”的发展目标，力争成长为具有核心竞争力的国内领先精品特殊资产管理公司。
