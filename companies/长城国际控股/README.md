## 公司
性质:央国企 · 行业:金融业

中国长城资产（国际）控股有限公司成立于1993年1月，是中国长城资产管理股份有限公司在香港的全资子公司，旗下拥有长城环亚控股有限公司、长城环亚资产管理有限公司、长城环亚（深圳）国际投资有限公司。长城国际控股长期致力于不良资产经营，业务范围主要为不良资产收购处置、实质性重组业务、牌照公司业务三大方向，围绕问题资产、问题企业，聚焦银行不良贷款处置、问题企业救助、房地产风险化解、资本市场风险化解等领域，综合运用不良资产收购处置、实质性重组等手段，为客户提供定制化一揽子金融服务。
