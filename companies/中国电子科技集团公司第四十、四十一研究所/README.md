## 公司
性质:央国企 · 行业:机械/制造业

中国电子科技集团公司第四十、四十一研究所是我国专业接插件继电器与电子测试技术研究所。1968年成立于陕西凤县，1982年迁建安徽蚌埠，1991年在山东青岛建立分所。承担了“电子测试技术重点实验室”等专业机构，在本领域权威机构中担任重要角色。以电子测试测量、计量技术研究等为主责，拥有专业团队和完备体系，完成科研成果2200余项，多项获国家和省部级奖，主持制定国际标准5项，产品应用于多个重要领域，为我国信息产业发展做贡献，还发展智慧消防等业务，创造良好社会效益和经济效益。
