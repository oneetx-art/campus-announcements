## 公司
性质:央国企 · 行业:能源/化工/环保

厦门钨业股份有限公司成立于1998年，前身为厦门氧化铝厂，1992年整体改制为厦门钨业股份有限公司，1998年开始生产钨制品，1997年厦门钨业、三特公司及上海、福建、浙江、湖南等省区市近百家企业，在深圳证券交易所上市。厦门金鹭特种合金有限公司是厦门钨业股份有限公司旗下的骨干企业，成立于1989年，是世界行业公司钨钢制品与日本原特科合资的中外合资企业。公司拥有从粉末、碳化钨粉、硬质合金到切削刀具的完整产业链，是世界知名的钨粉、碳化钨粉供应商及出口商；是高品质硬质合金及精密切削工具的制造商和服务商。
