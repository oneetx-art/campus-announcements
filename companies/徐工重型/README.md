## 公司
性质:央国企 · 行业:机械/制造业

徐州重型机械有限公司是徐工集团的核心企业，简称徐工重型，1963年生产出中国第一台汽车起重机。目前，已连续23年稳居中国工程起重机行业第一位，是我国工程起重机行业的开创者、引领者、发展者。产品出口145个国家和地区，主机国内市场占有率超过40%，创造了全球最大吨位3000吨级轮式起重机出口记录，也是唯一一家通过德国及欧盟整车型式认证的中国制造商。
