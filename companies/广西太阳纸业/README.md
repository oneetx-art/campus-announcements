## 公司
性质:民企 · 行业:快速消费品

山东太阳纸业股份有限公司（简称：太阳纸业；股票代码：002078）在创立于1982年，是全球领先的跨国林浆纸一体化集团企业，2006年在深圳证券交易所上市，为山东省造纸产业“链主”企业。公司位列世界造纸三十强、中国造纸十强，是全球先进的林浆纸一体化企业。公司近年来获得“国家科技进步一等奖、二等奖”和“中国工业大奖表彰奖”等多项国家级和省级奖项。作为行业龙头企业，公司连年荣获“世界造纸百强企业”“中国造纸工业十强企业”“中国民营企业500强”等多项全国大奖。
