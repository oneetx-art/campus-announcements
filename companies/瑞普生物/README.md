## 公司
性质:民企 · 行业:医疗/医药/生物

瑞普生物股份有限公司（股票代码：300119.SZ）创立于1998年，是全球领先的动物保健品制造商和动物疫病解决方案提供商，是中国A股市场第一家专注于兽药领域的上市公司。瑞普生物现旗下共有20家分子公司，拥有通过新版兽药GMP验收的生产基地10座，《2020年动物保健产业排名》瑞普生物荣登全球动保行业“中国第一、全球TOP15”；并被评选为“亚洲、澳洲、非洲最佳动保公司”；荣获第四届的“中国隐形冠军”殊荣。累计已获得《新兽药注册证书》116个，获得国家科技进步二等奖2项。是中国集生物制品、药物原料、药物制剂、饲料添加剂四位一体的中国规模较大、产品种类齐全的动物保健品的生产与服务商。
