## 公司
性质:民企 · 行业:通信/电子/半导体

惠州市隆利科技发展有限公司属深圳市隆利科技子公司（股票代码：300752，2007年有限公司成立）于2021年在惠州自建厂区，是专业从事LED背显显示屏研发、生产和销售的国家高新技术企业，产品广泛用于手机通讯、计算机、工业控制、车载、医用显示等领域，在中国LED背光行业中处于领先地位，公司凭借自身实力，荣获国家高新技术企业、广东省工程技术研究中心、深圳五百强企业、深圳知名品牌、龙华区工业百强和纳税百强企业等荣誉。公司现有员工近2500余名，实现了全产业链高度自动化生产，企业凭借核心技术与京东方、天马、华星光电、深超光电、信利光电、晶鼎光电、合力泰、华为、三星、小米、OPPO、vivo等企业建立了长期合作的伙伴关系。
