## 公司
性质:民企 · 行业:机械/制造业

长陆智造（股票代码839226）成立于2004年，总部位于广东珠海市，2016年在新三板上市。公司致力于提供智能工厂自动化与信息化综合解决方案，包括：智能化测控仪器仪表和针对流程工业的柔性生产控制、生产运营、设备维保，生产制造MES等系统产品，以及流程工厂的生产线智能化成套装备。业务涉及化工、食品、粮油饲料、建材、建筑与路桥施工、有色、冶金、能源、环保、橡塑、新材料等流程工业领域。产品销售区域除了国内市场，还远销东南亚、中东、俄罗斯等海外地区。长陆在珠海和合肥拥有两大生产研发制造基地，在全国各地设有分支机构。
