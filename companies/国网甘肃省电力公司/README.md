## 公司
性质:央国企 · 行业:能源/化工/环保

国网甘肃省电力公司是国家电网有限公司的全资子公司，承担着甘肃省14个市（州）电网建设、运营和发展任务，为甘肃地方经济社会发展提供安全持续可靠的电力保障。公司现有5个职能型事业部、9家业务支撑单位、14家地市级供电企业、80家县供电公司和1家原集体平台企业，用工4万人，服务客户超1000万户。甘肃电网位于西北电网中心，是西电东送的重要通道、西北电力交换的枢纽，与新疆、青海、宁夏、陕西联网运行，电网最高电压等级±1100千伏，骨干网架为750/330千伏。甘肃自有2条特高压输电线路一+800千伏酒泉至湖南、+800千伏陇东至山东，过境昌吉至古泉、青海至河南、哈密至郑州、哈密至重庆、宁夏至湖南5条特高压，通过21回750千伏线路与周边省份相联。全省总装机1.07亿千瓦，其中新能源装机7062万千瓦，占比约66%，新能源发电量占比约40%，装机占比和发电量占比均居全国前列，是典型的“绿色电网”。近年来，公司高度重视人才培养工作，不断完善新员工关怀培养、员工成长成才等机制，建立行政职务、职员职级、专家人才等各类员工成长通道，深入推进高端人才引领工程、青年人才托举工程、电力工匠塑造工程等人才培养措…
