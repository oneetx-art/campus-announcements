## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁二十局始建于1949年，前身为中国人民解放军铁道兵第十师，后为建字0029部队。1984年集体转业并入铁道部，2000年归属中央企业工委管理，2003年归属国务院国资委管理，为中国铁建股份有限公司全资子公司。中铁二十局驻地陕西省西安市，现有员工约1.5万人，其中高级职称2600余人，注册资质师1500余人。集团拥有各类资质92项，其中总承包资质64项（公路、铁路、房建、市政等为“七特七甲”），桥梁、隧道、铁路电务和勘察等专业承包资质110项，铁道、公路、建筑等注册资质设计资质32项。
