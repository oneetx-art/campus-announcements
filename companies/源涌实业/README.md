## 公司
性质:民企 · 行业:贸易/批发/零售

浙江源涌实业有限公司成立于2012年，总部位于浙江宁波，目前在上海、杭州、绍兴、淮安等地设有分公司或子公司。公司实业与产业投资并进，横跨新材料、新能源、大宗商品等领域，公司经营业绩连年稳步增长，连续多年入选浙江省服务业百强、宁波大宗商品百强企业。公司深耕大宗商品领域十余年，主营PTA、MEG、PET、FDY、DTY等聚酯产品、（PP PE PS）等聚合物以及（甲醇、纯苯、苯乙烯等）液体化工、工业燃料油等大宗商品，为客户提供全流程服务体系，在聚酯产业形成成套规模优势。
