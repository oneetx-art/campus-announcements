## 公司
性质:央国企 · 行业:机械/制造业

中国航天科技集团有限公司第四研究院第四十一研究所，地处陕西西安，始建于1964年，为原国防部五院批准设立的我国第一个固体火箭发动机设计研究所，是我国第一批重点统筹建设保军单位，拥有固体推进全国重点实验室，是集团公司航天动力技术研发中心的依托单位。经过六十多年的发展，四十一所已成为我国历史最久、规模最大、实力最强、种类最齐全的固体火箭发动机设计研究所，主要承担我国导弹及宇航运载领域固体火箭发动机研制及重大预先研究任务，有力支撑了我国国防装备和航天事业的发展
