## 公司
性质:央国企 · 行业:房地产业/建筑业

武汉百瑞景物业服务有限公司成立于2008年4月，是世界五百强企业中国中铁旗下、素有“建成国家队”美誉的中铁大桥局之子公司——武汉地产公司的核心下属企业，是一家专业化、市场化的物业综合服务企业。作为央企红色物业，百瑞景物业如今服务业态已全面覆盖城市综合体、高层住宅、商业街区、高校、写字楼、医院及产业园区等多元场景，是武汉大学、湖北大学等知名高校的物业服务商。公司连续4年荣获“中国物业服务百强企业”、连续5次荣获“武汉物业服务企业综合实力50强”，经过多年的苦心耕耘，公司已然跻身武汉市知名物业品牌，致力于成为湖北省乃至全国物业管理行业的知名品牌企业。
