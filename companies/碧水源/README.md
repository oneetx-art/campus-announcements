## 公司
性质:央国企 · 行业:能源/化工/环保

碧水源（300070.SZ）创办于2001年，是一家集膜材料研发、膜设备制造、膜工艺应用于一体的高科技环保企业，目前已发展成为全球一流的膜技术和水务企业，首创“MBR+DF双膜新水源工艺”，实现污水资源化，解决缺水地区的水危机，为城市生态环境建设提供整体解决方案。2020年，中央企业、全球领先的特大型基础设施产业集团——中国交建集团完成对公司的战略控股，碧水源成为央企控股的高科技环保企业。
