## 公司
性质:央国企 · 行业:金融业

日照银行成立于2004年12月28日，前身是日照市商业银行，是一家由国有股份、企业法人股份及自然人股份共同组成的具有独立法人资格的股份制商业银行。2004年实现本外币一体化经营，与50多个国家和地区的500多家银行建立了代理行关系。2006年引进南京银行作为战略投资者，开创全国城商行之间战略合作的先河。2009年更名日照银行，设立首家分行青岛分行。2010年以来，先后在济南、临沂、潍坊、济宁、枣庄、威海、烟台、聊城设立14家分行，设立271个信用社保安10个社区支行。
