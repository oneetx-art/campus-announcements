## 公司
性质:央国企 · 行业:金融业

华安期货有限责任公司（以下简称“公司”）成立于1995年5月，是华安证券股份有限公司（股票代码：600909）全资子公司。公司具备从事商品期货经纪、金融期货经纪、期货投资咨询和资产管理业务资格，注册资本金为人民币10亿元。公司是国内较早成立的期货公司之一，秉承“敬业、严谨、协同、进取”的核心价值观，以“红色领航、五色驱动”党建品牌引领业务高质量发展。围绕服务实体经济的宗旨，形成以期货经纪业务为主体、以风险管理和资产管理为两翼的业务格局，立足高起点，塑造投资新文化，致力于构建以塑造品质为核心，在业内具备持续竞争力和持久影响力的期货公司。
