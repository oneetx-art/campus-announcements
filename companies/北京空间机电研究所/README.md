## 公司

北京空间机电研究所隶属于中国航天科技集团有限公司中国空间技术研究院，成立于1958年8月，从探空火箭技术研究起步，先后从事过运载火箭总体技术、卫星总体技术以及载人飞船总体技术研究，是我国最早从事空间技术研究的单位之一。
