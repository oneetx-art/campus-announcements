## 公司
性质:央国企 · 行业:金融业

中国信达资产管理股份有限公司（简称“中国信达”）成立于2010年6月，其前身为1999年4月成立的中国信达资产管理公司，是国务院批准设立的国内第一家金融资产管理公司。2013年12月，中国信达在香港联合交易所主板挂牌上市（股票代码01359.HK），成为首家登陆国际资本市场的中国金融资产管理公司。
