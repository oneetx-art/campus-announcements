## 公司
性质:民企 · 行业:快速消费品

麻辣王子，正宗麻辣辣条传承者，健康辣条开创者，辣条行业第一地方标准起草单位。公司成立于2000年。2002年，进入辣条行业，致力于传承正宗辣条麻味、推进辣条天然健康。2009年，推出麻辣王子正宗辣条，传承辣条发源地正宗辣条的麻辣味，深受年轻人喜爱。2014年，麻辣王子原料升级，选用天然面粉、非转基因菜籽油，开启辣条行业健康新纪元。2016年，麻辣王子包装升级，升级为皇冠红色包装，采用独立小包装，干净卫生，方便分享，在中国中部农博会、中国糖酒会2次卖断货。2018年，麻辣王子又一次原料升级，辣条行业首家不加糖精、甜蜜素、安赛蜜、纽甜、阿斯巴甜、化学色素，引领行业向健康发展迈进了一大步。2019年4月，麻辣王子推出“微麻微辣”口味，让正宗辣条有了“很麻很辣”、“微麻微辣”2种口味，让消费者对正宗辣条麻味有了更多选择。2020年1月，麻辣王子不加防腐剂，让产品更健康。2020年10月，麻辣王子与平江职校共建中国首个辣条专业班，拉开辣条行业人才培养序幕。2020年10月，麻辣王子联合平江县食品行业协会打造中国首个辣条博物馆，向大众展示辣条的起源、发展、原料、工艺、车间等，受到消费者广泛好评，得…
