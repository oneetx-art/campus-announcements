## 公司
性质:民企 · 行业:金融业

易方达基金是一家综合性资产管理公司。公司成立于2001年，依托资本市场，通过专业化运作，为境内外各类投资者提供综合性资产管理解决方案。公司坚守客户利益至上原则，坚持做值得各方长期托付的、负责任的公司。截至2025年二季度末，易方达基金及下属机构资产管理规模超3.6万亿元，服务广大个人投资者及社保基金、企业年金和职业年金、银行、保险价值、境外央行及养老金等机构投资者。
