## 公司
性质:央国企 · 行业:通信/电子/半导体

产投三佳（安徽）科技股份有限公司成立于2000年4月，注册资本15843万元，下辖四个全资实体子公司和两个专业工厂。前身是原电子工业部所属三个军工厂，2002年1月登陆上海证券交易所，现为合肥产投集团旗下精密制造领域重要企业。主营半导体集成电路封装模具及设备等，拥有省级企业技术中心等技术创新平台，推进半导体封装设备自动化、智能化研发。
