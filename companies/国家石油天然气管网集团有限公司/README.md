## 公司
性质:央国企 · 行业:能源/化工/环保

国家石油天然气管网集团有限公司（简称国家管网集团）成立于2019年12月9日，是国务院国有资产监督管理委员会监管的国有重要骨干企业，总部设在北京。主要从事油气干线管网及储气调峰等基础设施的投资建设和运营，负责干线管网互联互通及第三方管道联通，负责全国油气管网运行调度，定期向社会公开剩余输管能力和LNG接收站加工能力，实现基础设施向用户公平开放。
