## 公司
性质:央国企 · 行业:政府/机构/组织

黑龙江交易集团有限公司是经黑龙江省政府批准设立的国有独资企业集团，由省国资委代表省政府履行出资人职责，是黑龙江一级要素交易平台，承载政府管理经济的市场化工具、优化资源配置的要素市场、落实源头防腐的阳光平台三大职能。集团构建了要素交易、阳光招标、上市培育、招才汇智四位一体战略发展格局，形成了体系健全、主业集中、功能完备的产业结构，获得多项行业权威资质认证，业务涵盖各类要素交易、中介服务、融资服务、产业研发招才引智等，业务覆盖黑龙江全省，市场延伸至域外，是东北地区一流、全国具有较强影响力的综合性集团公司
