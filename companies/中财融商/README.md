## 公司
性质:民企 · 行业:金融业

中财融商资本（私募管理人登记编号：P1015578）创立于2015年春，是一家由中央财经大学精英校友发起成立的专业基金管理公司，服务范围覆盖“募、投、管、退”全流程。成立10年来，公司已构建起北京总部、上海、四川、内蒙古、陕西、江苏、山西、浙江、安徽、广东、海南、江西和山东12家分支机构共同组成的业务架构，目前在管基金超60支，累计管理规模超500亿元，并成功投出了新能源、新材料、智能制造、数字经济、低空经济、大消费等领域的上百个项目，致力于成为国内领军级政府投资基金管理公司。
