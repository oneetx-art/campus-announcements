## 公司
性质:民企 · 行业:IT/互联网/游戏

魔方工作室群（英文名：MoreFun Studios），是腾讯IEG（互动娱乐事业群）四大工作室群之一，成立于2010年，工作室群下设有多个工作室，如玉、魔镜三大工作室。魔方工作室拥有多个全球顶级IP项目，包括《火影忍者》手游、《暗区突围》、《暗区突围：无限》、《洛克王国》、《洛克王国：世界》、《舞人之卜》等多个《王牌战士》等，在动作、射击、RPG、休闲等多个游戏品类赛道均有发力。
