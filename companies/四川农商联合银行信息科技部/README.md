## 公司
性质:其他 · 行业:金融业

四川农商联合银行由四川省农村信用社联合社改制而成，2024年1月挂牌开业，注册资本220亿元，承担四川省农村信用社联合社对全省农商银行的管理职能，是独立企业法人监管部门许可的经营机构，具有独立法人资格的地方性银行金融机构。已发展为业务规模大、网点覆盖面广、员工数量多的银行系统。截至2025年10月底，总资产规模2.6万亿元，农商银行48家，网点4700余个，干部员工近4万名。是四川重要金融力量。近年实施“智联银行”建设，推进数字化转型。建成“三地四中心”多活数据中心，是西南地区标准化水平高、处理能力强的现代银行基础搭建。构建“蜀信云”平台，分布式IT架构，行业领先的分布式架构私有云。数字化转型动力不断增强，是国家发改委确定的“数字化转型伙伴行动”两家省级农信机构之一。
