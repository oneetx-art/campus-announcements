## 公司
性质:民企 · 行业:通信/电子/半导体

Sencore创立于1951年，总部位于美国南达科他州苏瀑市，是全球领先的视频信号处理与传输技术公司，在欧洲、拉美、中东及亚太设有分支结构。公司与伟乐科技同属集团体系，专注产品研发与全球市场拓展，由伟乐科技提供制造支持，形成完整的技术与产业链。75年来，我们深耕广播电视、IPTV及专业视听领域，服务希尔顿、迪士尼等国际企业，深度支撑世界杯、欧洲杯等顶级赛事直播。产品与服务覆盖全球150多个国家和地区、2000余家运营商、5亿用户。以创新为核心驱动力，我们持续布局AV over IP、智能化、超高清等前沿方向，以专业技术与行业级支持能力，帮助全球客户实现高质量内容传输。
