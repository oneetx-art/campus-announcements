## 公司
性质:民企 · 行业:农林牧渔

广东海大集团股份有限公司是以科技为主导的中国农业龙头企业，目前业务涵盖饲料、种苗、动物疫苗、智慧养殖、食品加工等现代农业全产业链。2024年，海大集团保持稳健发展，实现营业收入1146亿元，归母净利润45亿元。2025年上半年营业收入达588.31亿元，同比增长12.50%。
