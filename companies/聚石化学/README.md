## 公司
性质:民企 · 行业:能源/化工/环保

广东聚石化学股份有限公司（股票代码688669）成立于1999年，2021年登陆科创板，是一家把“绿色”写进DNA的新材料高新技术企业。总部坐落于广东清远国家高新区，集团拥有十余个生产基地，分布在广东、湖南、湖北、安徽、江苏、上海、越南、尼日利亚、安哥拉等，集团总人数3000多人，清远总部800多人，研发人员占比约16%。公司已形成了上下游产业链布局，主营业务有：无卤阻燃剂、增强增韧复合材料、高性能改性工程塑料、无卤环保高性能电缆料、高强度复合矿光板、透气膜、降解膜、发泡板材、多聚磷酸、液态石油气、钙钛矿光伏材料、水解制氢等。公司产品广泛应用于新能源汽车、轨道交通、绿色家电、医疗卫材、循环包装等“双碳”赛道。
