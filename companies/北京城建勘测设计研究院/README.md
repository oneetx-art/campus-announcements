## 公司
性质:央国企 · 行业:房地产业/建筑业

北京城建勘测设计研究院有限责任公司成立于1952年，是为1953年开始的华北地区铁路工程建设而设立。历经60余年的发展，现已成为集测绘地理信息、城市轨道交通、工程建设、生态环境、地质勘查、智能设备研发与制造、智慧城市建设等多元产业协调发展的国家高新技术企业，也是我国轨道交通及城市建设领域极具强大竞争实力的大型综合勘测设计企业。
