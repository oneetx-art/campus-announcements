## 公司
性质:央国企 · 行业:医疗/医药/生物

天津红日药业股份有限公司成立于1996年，2009年成为全国首批创业板上市企业，是国资委下属国有控股企业。本次招聘涉及旗下五家子公司：天津红日康仁堂药品销售有限公司是公司全资子公司；湖州展望药业是全资子公司，为国内药用辅料龙头企业，获评国家专精特新小巨人企业；北京超思电子从事医疗产品研发生产销售，营销网络覆盖全球百余个国家和地区；天津超思医疗器械具备完整产业链，血氧仪年产能可达2000万只；甘肃佛慈红日是合资成立的中药生产企业，为甘肃省农业产业化重点龙头企业
