## 公司
性质:央国企 · 行业:能源/化工/环保

广东省能源集团西南（贵州）电力投资有限公司（以下简称“西南公司”）成立于2012年10月11日，由广东省能源集团有限公司独资组建成立，是广东省能源集团有限公司在广东省外注册成立的二级投资管理平台。西南公司坚持“立足西南，以长江经济带省区为重点，其他区域作为有益补充”的板块战略发展思路，坚持以清洁能源为主，多种能源供应和服务并举，由早期的煤层气发电、风电发展为集风电、光伏、煤层气、抽水蓄能、电力销售、储能等综合能源业务开发及投资为一体的重要平台企业，业务布局从贵州延伸到湖南、河北、河南、陕西、江苏、安徽、云南、四川、西藏等15个省份。截至目前，贵州公司共有正式员工540余人，管理三级实体业务单位8家，全资或控股（含间接控股）公司80余家，控股贵州黔粤电力有限责任公司46.7%股权，参股贵州北盘江电力股份有限公司23%股权，资产总额超264亿元，新能源发电项目已投产装机规模突破3000MW，贵阳抽水蓄能项目（装机1500MW）已顺利开工，计划于2029年实现全部机组投产发电。
