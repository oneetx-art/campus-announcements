中国航空工业集团雷达所成立于1970年，是国家唯一机载雷达专业研究所，总部坐落于无锡，设有研发中心、生产试验基地，是集机载雷达与航空电子设备技术研究、产品研制、生产、试验和服务为一体的科技先导型研究所。
