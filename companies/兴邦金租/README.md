## 公司
性质:民企 · 行业:金融业

前海兴邦金融租赁有限责任公司（简称“兴邦金租”）是深圳前海唯一一家全国性法人金融租赁公司，是深圳金融总部企业、前海总部企业。成立8年来，兴邦金租始终坚持绿色发展理念，着力打造绿色租赁、融资租赁、车辆租赁、科技租赁“四位一体”产品体系，提供“融资+融物+融智”综合服务，凭借专业的服务能力与深度参与渠道，在业内树立了良好口碑，以金融租赁服务精准参与粤港澳大湾区“五大文章”。
