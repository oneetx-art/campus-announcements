## 公司
性质:民企 · 行业:通信/电子/半导体

深圳市一博科技股份有限公司（简称“一博科技”）成立于2003年3月，国家高新技术企业。深圳创业板上市公司，股票代码：301366。一博科技专注于高速PCB设计、SI/PI仿真分析等技术服务，并为研发样机及批量生产提供高品质、短交期的PCB制板与PCBA生产服务。致力于打造一流的硬件创新平台，加快电子产品的硬件创新进程，提升产品质量。作为全球高速PCB设计的领军企业，一博科技致力于向客户提供高速PCB设计、SI仿真分析、PI仿真、EMC设计、PCBN生产、焊接加工和物料提供的一站式硬件创新解决方案，提升产品品质，缩短客户研发周期。
