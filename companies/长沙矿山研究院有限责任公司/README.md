## 公司
性质:央国企 · 行业:能源/化工/环保

长沙矿山研究院有限责任公司位于风景秀丽的岳麓山下、湘江之畔，1956年按照“我国第一个、十二年科技发展规划”进行组建，以“矿业报国、专业强国”为初心使命，归属中国五矿集团有限公司直接管理，拥有国家级和省部级科研平台16个，享有“中国金属采矿第一院”的盛誉，曾在原国家部委管理的800多家科研院所中综合实力排名第16位。承担采矿科研、矿山安全、检测实验、设计咨询、矿山充填、海洋探采、防水治水、矿山地灾治理与生态修复、智能装备/系统、选矿药剂、工程服务等领域综合实力具备领先水平。
