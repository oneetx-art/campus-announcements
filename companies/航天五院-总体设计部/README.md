## 公司
性质:央国企 · 行业:机械/制造业

中国航天科技集团有限公司第五研究院总体设计部成立于1968年8月，是我国组建成立最早、总体领域最多、专业技术最齐全的航天总体设计单位，是五院重大工程任务抓总研制核心单位，载人航天、空间站科学与深空探测等宇航总体任务的经营管理主体，承担总体技术发展的责任主体。目前，总体设计部正围绕体系性经略太空，确立了一体两化 三轴四域 五链耦合顶层发展战略，全力打造量身航天崭新生态。本年度暑期实习招募高校优秀学子走进航天城，深度参与技术与业务形态的系统性变革，笃定与航天苍穹的凌云之志，和我们一起奔赴星辰大海。
