## 公司
性质:央国企 · 行业:机械/制造业

中煤张家口煤矿机械有限责任公司为中国中煤能源集团有限公司的全资子公司，始建于1923年，是新中国成立后我国最早生产煤矿机械产品的三大煤机制造企业之一，也是我国第一台链板式输送机和第一台使用圆环链可变弯曲刮板输送机的诞生地。公司先后荣获煤炭工业科技创新示范单位、煤机行业科技创新领军企业等多项荣誉称号，获得国家科技进步一等奖等多个奖项，入选国务院国资委科改示范企业名单和工信部绿色工厂目录
