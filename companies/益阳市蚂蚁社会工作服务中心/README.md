## 公司
性质:社会组织 · 行业:政府/机构/组织

益阳市蚂蚁社会工作服务中心（简称蚂蚁社工）是一家非营利性、非政府性的专业社工服务机构。益阳市蚂蚁社会工作服务中心于2019年1月23日在益阳市市民政局注册登记为民办非企业单位（慈善组织）。同时具备社工资质和志愿服务资质，拥有免税资格、公益性税前扣除资格、公开募捐资格。机构先后通过益阳市民政局评估被评定为5A级社会组织。2022年后被评为益阳市两新领域“标杆党组织”“先进基层党组织”，获得湖南省学雷锋四个一百优秀志愿服务组织、益阳市优秀志愿服务组织、益阳市先进社会组织等多项荣誉称号，2024年获批“第二批农工党党中央社会服务基地”。
