## 公司
性质:事业单位 · 行业:医疗/医药/生物

上海市第十人民医院（同济大学附属第十人民医院）历史百年风雨洗礼，于1993年成为卫生部首批“三级甲等”综合性医院。医院坐落于上海中心城区静安区，形成“一院多区”协同发展格局。重点学科不仅是国家临床重点专科与9个上海市重点学科的扎堆儿聚集地，更有院士工作站。作为上海市重点临床专科能级提升单位为首批国家癌症中心、急性胸痛救治、肠道微生态治疗、泌尿系肿瘤创新、胃肠肿瘤微创诊疗等领域形成显著特色。
