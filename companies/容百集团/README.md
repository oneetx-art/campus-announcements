## 公司
性质:民企 · 行业:能源/化工/环保

容百集团成立于2013年，是一家高科技新能源材料行业的集团公司，由中韩两支均拥有二十余年锂电池正极材料行业成功创业经验的团队共同打造。旗下主要包括北京容百自新能源科技股份有限公司（简称“容百科技”，股票代码：688005.SH）。容百科技是全球三元正极材料龙头企业，连续多年全球销量领先，部客率先实现订货。公司现已转型为“正极材料产业整体解决方案架构者”，聚焦新能源材料全生命周期服务，覆盖研发创新、智能制造为材料协同、资源循环利用四大核心领域，为汽车、储能及3C电子产业升级。
