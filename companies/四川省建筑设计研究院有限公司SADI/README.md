## 公司
性质:央国企 · 行业:房地产业/建筑业

四川省建筑设计研究院有限公司（简称“省建院公司”，英文缩写“SADI”）成立于1953年，是西南地区成立早、专业全、规模大的建筑设计企业之一。公司以“建筑设计为龙头，工程总承包、工程监理、数字技术、造价咨询、工程管理与咨询、岩土工程、教学体系与创意设计等”的全过程业务链为基础，运营设计行业龙头企业，业务板块覆盖建筑、市政、运营等领域，形成策划、规划、咨询、勘察、设计、施工管理、造价、监理、智慧建造等全过程一体化服务能力。综合实力位居全国省级设计院第一梯队。
