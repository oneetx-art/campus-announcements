## 公司
性质:央国企 · 行业:房地产业/建筑业

清远市公路勘察规划设计院有限公司创建于1988年，原为清远市公路局直属单位，2020年12月由公益三类事业单位改革为国有企业，是清远市国有资产投资集团有限公司下属子公司。公司经营范围包括建设工程勘察、设计，工程造价咨询业务等，拥有多个工程专项资质，可承接公路、市政公用专业规划咨询等业务。
