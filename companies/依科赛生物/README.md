## 公司
性质:民企 · 行业:医疗/医药/生物

依科赛生物（ExCell Bio）成立于2013年，总部位于上海，生产布局于苏州太仓、南美乌拉圭及意大利米兰，是一家专注于生命科学领域的高新技术企业，致力于为全球生物制药客户提供全方位生物制药和细胞治疗领域全产业链服务，聚焦无血清培养基、胎牛血清及鉴定试剂三大核心产品的研发与解决方案。公司通过治疗、基础科研研发领域国际标准的产品与解决方案，与领先的生物医药企业、科研院校、医疗机构等客户共同推进生物医药基础研究迈向国际行业发展，是中国首家国际血清行业协会（ISIA）中国会员单位、2025福布斯&沙利文中国生物制药&细胞治疗行业领军企业。
