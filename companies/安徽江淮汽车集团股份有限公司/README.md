## 公司
性质:央国企 · 行业:汽车制造/维修/零配件

江淮汽车始建于1964年，是全球化综合型汽车企业集团，产品涵盖全系列商用车、乘用车等，有四大核心板块。在新能源和智能化领域成果显著，推进与大众、华为、蔚来等合作。产品远销130多个国家和地区，出口超150万辆，有27个全球生产基地及超5000家全球用户中心。
