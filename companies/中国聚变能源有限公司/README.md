## 公司
性质:央国企 · 行业:能源/化工/环保

中国聚变能源有限公司（简称“中国聚变”）是中核集团依托核工业西南物理研究院（简称“西物院”）新组建的跟商业理化公司，是集团公司直属二级单位，代管西物院。中国聚变定位为全球聚变能源开发的引领者、我国聚变产业商业化的国家队和创新主体、央企聚变未来能源产业的实施主体、中核集团聚变及相关业务的投融资平台和控股股东。中国聚变由中核集团作为控股股东，联合中国融通资产管理有限公司、上海未来能源创新科技有限公司、中国核能电力股份有限公司、浙江浙能电力股份有限公司、国家绿色发展基金股份有限公司、四川蜀道聚能碳减排有限公司等优秀央国企产业资本和地方政府基金共同出资设立。中国聚变注册资本150亿元。
