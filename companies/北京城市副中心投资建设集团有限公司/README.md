## 公司
性质:央国企 · 行业:政府/机构/组织

北京城市副中心投资建设集团有限公司（简称北投集团）是北京市国资委出资成立的特殊功能类国有独资企业，注册资本100亿元，资产总额1530亿元。集团秉承“经营城市”理念，围绕“城市投融资、建设与综合运营，保障性住房投融资与建设运营”两大主业，着力打造“投资建设、城市运营、金融服务、保障房”四大业务板块，业务领域涉及土地整理、城市基础设施建设、区域配套服务设施投资建设运营、保障房投资建设运营、绿色能源、金融服务，为首都功能提升与副中心高质量发展提供综合支撑。
