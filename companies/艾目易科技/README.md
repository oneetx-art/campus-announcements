## 公司
性质:民企 · 行业:智能硬件

广州艾目易科技有限公司（简称艾目易）是一家聚焦手术机器人核心部件与解决方案的高科技企业，致力于推动手术机器人核心部件国产化，实现手术机器人自主创新。公司创始团队均来自外科手术光学定位系统和电磁定位系统的核心团队，开发了骨科、神经科等手术机器人核心部件，已广泛应用于手术机器人产品于医疗、科研等领域。公司核心技术团队拥有丰富的手术机器人研发经验，涵盖光学、电磁、机械电子、计算机视觉、机器人控制算法等多个专业领域，核心成员毕业于哈工大、清华、北航、华南理工、香港理工等国内外知名院校。
