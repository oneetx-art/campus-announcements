## 公司
性质:民企 · 行业:农林牧渔

安佑生物科技集团股份有限公司，主要以饲料研发、生产为核心业务，产品涵盖猪饲料、水产饲料、禽饲料和反刍饲料，其中以猪饲料为主导产品，包括乳猪系列、肉猪系列、种猪系列等产品。在立足主业的基础上，公司向上下游延伸并开发出替抗、功能性饲料原料和添加剂等相关产品，依托丰富的饲料产品矩阵，公司向下游客户提供精准营养方案、饲养技术管理、疫病防控技术和智能养殖设备等下沉式的综合服务。
