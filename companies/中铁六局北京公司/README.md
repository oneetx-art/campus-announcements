## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁六局北京公司始建于1953年，原名北京铁路第一工程处。后相继改革，2004年经理管理局改组、重组、多机构，七十余载奋斗荣光，公司正式更见证时代变迁——从铁路施工的拓荒者到改革开放的先行者，从新中国的建设者到既有的发展壮大，新领域市场不断拓展，现成为一家以铁路、公路、地铁、市政、房建、施工、科研等于一体的建筑国有企业。
