## 公司
性质:央国企 · 行业:能源/化工/环保

聚变新能（安徽）有限公司成立于2023年5月，注册资本145亿，股东涵盖安徽省与合肥市国有平台、中央企业、社会资本等，是我国核聚变能商业化的重要实施主体平台之一。公司聚焦新型能源技术开发、设备集成与工程技术服务等核心领域，致力于整合资本、技术、人才、知识产权等创新要素，按照“紧凑型聚变实验装置（BEST）-聚变工程示范堆（CFEDR）-首个商业聚变堆”三步走战略，系统布局实验研究、工程示范及商业化应用的全链条发展路径，同时牵头组建安徽省聚变产业联合会，联合近200家成员单位协同构建世界级聚变能源产业集群，致力于打造国际一流的聚变发电工程公司，并产出一批具有国际影响力的原创性科研成果。
