## 公司
性质:民企 · 行业:贸易/批发/零售

宁波渠成集团有限公司始创于2005年，是一家研发、营销、创意设计及供应链管理，拥有多类国内及海外子公司的企业。集团业务范围覆盖全球100多个国家和地区。集团不仅为海外客户提供数千种货架产品，也为其提供、人资工学、品牌视觉等赋能服务，以及家居产品服务产品。具备的海外市场线上和线下的客户服务中心与品牌服务对部，并设立多个海外仓做依托强大的供应链与数字化服务能力，2024年，集团正式为东莞跨境电商城，成功开辟新增长。集团针对国际市场打造了自主品牌北公湖Bratteli、Hummartion，引领健康办公生活新潮流。2023年，集团跨境电商平台渠成家居在欧洲打造了三个品牌群在欧洲。三个品牌在国内主流电商平台均设有品牌官方旗舰店。
