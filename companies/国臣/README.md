## 公司
性质:民企 · 行业:能源/化工/环保

南京国臣自2005年成立以来，始终专注于电能质量改善、供电可靠性提升、新能源高效利用及用电能效优化，致力于为客户提供完整的配电解决方案与系列产品。公司是国家高新技术企业、江苏省专精特新中小企业，并承担多项国家重点研发计划应用示范项目，公司已取得国家专利授权80多项、发表高水平学术论文80多篇，参编专著5部，参订国家标准、行业标准及团体标准20多项，获省部级以上科技进步奖10余项，曾获CDP28能源转型变革者奖、中国技术市场协会金桥奖等多项重要荣誉。公司产品涵盖电力电子变换器、保护测控装置、暂降治理系统及厂站直流系统等核心设备，均通过国家级检测认证，广泛应用于电力、石油化工、制药、半导体、绿色建筑等行业，市场覆盖国内并延伸至“一带一路”沿线地区。公司还与众多高校合作成立研究院，为科研和技术队伍持续注入新的活力，欢迎广大毕业生加入！
