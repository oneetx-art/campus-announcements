## 公司
性质:民企 · 行业:教育/培训/科研

百分教育集团于2008年在江门起步，历经17年发展，已成为大型综合性教育集团，并立志成为最具有影响力受人尊敬的教育服务机构。集团旗下拥有百分百高中辅导、百分百初中辅导、百分百小学辅导、百分百素质教育、百分百学生饭堂、百分百新景程，为高中生提供全科学习服务，全国布局有多个高中品牌；致力于中小学课外辅导，在江门、佛山、肇庆、阳江、福建龙岩等地开设校区。目前，全集团拥有全职员工1300多名，55个综合校区，以优质教学服务于千万万学子。
