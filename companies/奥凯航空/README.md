## 公司
性质:民企 · 行业:交通/物流/仓储

奥凯航空于2005年3月成立于北京，注册地为北京市大兴区，经营地址位于天津市空港经济区，注册资金33亿元，系CCAR-121部公共航空运输企业，为新中国第一家投入运营的民营航空公司，现有机队规模21架，在天津、长沙、西安、南宁4个城市建有航空运营基地，运营国内外航线60余条，通达国内50多个航点，包括22个省会城市和直辖市；运营国际航线10余条，主要覆盖日韩和东南亚地区，累计运送旅客超6400万人次。
