性质:央国企 · 行业:房地产业/建筑业

扬州建工控股集团有限公司是扬州市属国有大型建筑产业链集团公司，注册资本30亿元，信用评级AA+，2024年资产总额545.19亿元，营收247.76亿元。集团聚焦“建筑业、房地产开发、城市更新与运营”三大主业，旗下拥有江苏华建、扬建集团、华建地产、宜居集团、金融集团等5家二级子企业集团，管理146家控（参）股公司，市场布局覆盖粤港澳大湾区、长三角经济带、京津冀和成渝经济圈等热点区域，以及新加坡等海外市场。
