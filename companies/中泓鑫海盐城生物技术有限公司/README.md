## 公司
性质:民企 · 行业:农林牧渔

中泓鑫海盐城生物技术有限公司成立于2001年，是一 家从事水产饲料添加剂研发、生产和销售为一体的高科技企业。公司是国家高新技术企业、江苏省民营科技企业，并建立了盐城市工程技术研究中心。公司拥有高度专业化的研发、销售、服务团队，多年来一直致力于水生物及水生环 境的健康发展，公司常年与全国各大水产科研院所密切合作，与多所知名高校及业内著名专家教授合作研发，现有中草药制剂、保健添加剂、微生态制剂、底质水质改良剂等300多种动保产品。
