## 公司
性质:民企 · 行业:机械/制造业

深圳华星恒泰泵阀2009年成立，是中国首家微型泵阀企业、国家级高新技术及专精特新“小巨人”企业。13年专注智能流体控制微型泵阀研发，拥有190多项专利（39发明专利），多款产品行业领先。技术达国际领先，服务全球知名品牌。公司主要业务为电推泵、隔膜泵、蠕动泵、电阀等高精度微型泵阀产品的生产与销售，主要应用于清洁类机器人、智慧农业无人机、智慧商用车雨刮等。公司立足国内（广东深圳、东莞、江苏苏州、中国香港），布局海外（越南平阳），形成了国内国际双循环的战略性产业布局。
