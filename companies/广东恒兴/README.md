## 公司
性质:民企 · 行业:农林牧渔

广东恒兴(恒兴集团、恒兴股份)创立于1991年，是农业产业化国家重点龙头企业。三十多年来，恒兴以“恒农兴邦”为使命，以“提高人类生活品质”为愿景，现已发展出一条完整的水产品产业链，业务板块包括种苗繁育、饲料营销、水产贸易、水产养殖、食品加工、智慧渔业、水产交易平台等，并拓展投资了金融、港口、地产等业务。恒兴在广东、广西、海南等地以及越南、印度尼西亚等国家均有产业布局，年营业额超过210亿元。
