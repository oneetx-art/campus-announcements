## 公司
性质:央国企 · 行业:能源/化工/环保

海南核电有限公司隶属于世界500强中国核工业集团有限公司，由中国核能电力股份有限公司（股票代码：601985）控股。海南核电是国家于海南省建设重点项目和海南省“能源一号”工程，厂址位于海南省昌江县海尾镇塘兴村。海南核电基地总装机容量为382.5万千瓦，现已建成一期工程两台65万千瓦核电机组，AP1000目前正在建设一台12.5万千瓦的“玲龙一号”（ACP100）全球首堆示范工程。自1、2号机组投产以来，海南核电年发电量约100亿度，有效解决了海南省的地域性缺电问题，是海南自贸港建设重要的“核动力”绿色引擎和能源保供“压舱石”。
