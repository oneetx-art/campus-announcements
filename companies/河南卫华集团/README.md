## 公司
性质:民企 · 行业:机械/制造业

卫华集团有限公司始创于1988年，总部位于河南省长垣市，现有员工8000余人，2024年销售收入289.16亿元。是以起重机为主业的大型现代企业集团，目前拥有4个现代化生产制造基地，7个研发中心，业务涵盖工业起重机、港口起重机、海工装备、散料输送设备、智能仓储设备、智能停车设备等多个领域，是我国起重行业产销量最大、产品种类最全、品牌影响力最强、最具竞争力的现代化企业集团。
