## 公司
性质:民企 · 行业:通信/电子/半导体

光科芯图(北京)科技有限公司成立于2022年5月18日，位于北京经济技术开发区，注册资本3.55亿。由集成电路领域知名专家联合国内知名半导体设备企业及投资机构共同发起设立。主要股东包括亦庄国投、红山科技、兴橙资本等。团队成员以毕业于国内外名校的博士、硕士研究生为主。公司面向半导体产业生产制造需求，采用自主研发的创新性技术，开展新型曝光设备研发、生产和销售。先后荣获了“中关村高新技术企业”“专精特新中小企业”“创新型中小企业”等资质。
