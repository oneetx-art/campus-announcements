## 公司
性质:民企 · 行业:快速消费品

青莲食品于2001年成立于浙江嘉兴，是农业产业化国家重点龙头企业，农村产业融合典型龙头企业，公司聚焦高品质猪肉供应与服务，以消费者需求为核心出发点，完成从源头到餐桌的黑猪全产业链布局。现有员工2400余人，年产值70亿，旗下拥有膳博士、太湖黑、芬享家、猪星球等核心品牌，并通过青莲生猪产业研究院及国家级院士工作站，开展数字化青育种、黑猪精准营养等前沿技术研究，助力中国地方猪产业发展。
