## 公司
性质:央国企 · 行业:机械/制造业

航天能源隶属于中国航天科技集团有限公司，是上市公司航天智造（股票代码：300446）核心全资单位，坐落于中国“酒城”、国家级卫生城市和全国文明城市——四川省泸州市，到重庆半小时，到成都两小时，飞机、高铁等交通便捷。经过30多年的发展，公司依托深厚的航天技术底蕴，先后推动实现了海洋油田射孔装备国产化、高端完井装备国产化以及陆地油田页岩油分段射孔万米深井作业成功，客户涵盖了中石油、中石化、中海油等大型油气公司。公司产品出口美国、加拿大、中亚、东南亚等20多个国家和地区，在业内建立了市场和技术领先地位，多项关键技术达到国际领先、公司积极进行强军首责，开发多类项目，军民融合技术成果转化成效显著。公司依托航天技术，利用自身技术优势，主动融入低空经济等现代化产业体系，未来发展极具空间。
