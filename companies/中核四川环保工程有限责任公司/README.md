## 公司
性质:央国企 · 行业:能源/化工/环保

中核四川环保工程有限责任公司（简称‘八二一’）作为我国核安全环保事业的主力军，以‘核安天下·绿铸未来’为发展愿景，矢志践行‘让八二一成为人类利用核能不可或缺的一部分，打造世界一流核安全环保科技型企业’奋斗目标，在人类逐梦发展核事业进程中，提供核能与核技术的绿色核安全保障。公司被认定为四川省高新技术企业与首批四川省‘揭榜挂帅’单位，荣获国家四〇四高技术企业、四川川核环保装备工程技术研究中心等，获得核工业集团突出贡献集体、全国文明单位等荣誉。
