## 公司
性质:民企 · 行业:能源/化工/环保

广东邦固化学科技有限公司（简称“邦固化学”）成立于1999年，是一家专注于涂层材料研发、生产与销售的技术企业。公司注册资本1.08亿元，总投资超过4亿元，占地面积6.5万平方米，是广东省专精特新企业、省高新技术企业。公司具备材料制备等多个广东省重点企业技术平台，积极与中国科学院、华南理工大学、中山大学等科研机构开展产学研合作，持续推动技术突破与产业化应用。围绕学生的综合素质、专业、诚信、创新的企业理念，致力于为客户提供稳定、优质的产品，公司已获评“广东省产学研示范基地”。
