## 公司
性质:民企 · 行业:能源/化工/环保

广东宇新能源科技股份有限公司（股票代码002986）成立于2009年10月，下设全资子公司惠州宇新化工有限责任公司和控股子公司惠州宇新新材料有限公司、惠州博科环保新材料有限公司。公司依托大亚湾石化区和惠州新材料产业园的区位优势，专注于以液化石油气（LPG）为原料的有机化工产品工艺研发与生产，是华南地区规模最大且技术先进的碳四深加工企业之一，拥有全球单套规模最大的顺酐装置、丁酮装置及全国最大的乙酸仲丁酯（SBAC）装置、醇醚装置。通过先进工艺和自有专利技术生产清洁能源、基础化工品、催化剂和新材料产品，主要产品包括顺酐催化剂、铜系催化剂、MTBE、SBAC、顺酐、异丙醇、丁酮、乙醇等。
