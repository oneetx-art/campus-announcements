## 公司
性质:央国企 · 行业:机械/制造业

贵阳航发精密铸造有限公司始建于1965年，是创新研发、产品试验、批片精密生产为一体的专业化公司，拥有省级企业技术中心，是一家国防军工央企，现隶属于中国航发北京航空材料研究院。经过几代人的不断努力和付出，公司在航空发动机机匣叶片的材料研发、生产等方面形成了专业优势，已成为国内航空发动机机匣叶片专业化制造中心，肩负着国家航空发动机机匣精密生产制造、商业及为复装航空涡轮叶片提供优质涡轮叶片的重任及使命。
