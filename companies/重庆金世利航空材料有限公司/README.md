## 公司
性质:民企 · 行业:机械/制造业

重庆金世利航空材料有限公司成立于2016年，是一家重庆本地企业。公司主要从事航空、航天、舰船、核电等领域高端合金材料的研发、生产和销售。现已建成国际先进的全流程生产线，集成全球稀缺装备国内唯一万吨级整体电极挤压机、12吨真空熔炼炉及4500吨快锻机组，实现从铸锭熔炼、精密锻造到型材挤压的全链条自主可控，具备年产5000吨钛合金铸锭及3000吨航空级棒材/锻件能力。
