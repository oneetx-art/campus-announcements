## 公司
性质:央国企 · 行业:能源/化工/环保

国核铀业发展有限责任公司是世界500强国家电投集团所属二级单位，办公地点位于北京市海淀区中关村核心地带，是我国三大天然铀专营企业之一，也是国家高新技术企业，国家原子能机构“核技术应用研发中心”。负责国家电投集团核燃料供应保障，核技术应用与核环保等核能转型升级项目的投资开发和专业化管理，以及境内外铀资源投资开发与专业化管理。子公司分布在北京、重庆、江苏无锡、山东海阳，其中4家入选国家高新技术企业，1家入选国资委“科改示范”企业，2家入选地方政府雏鹰企业。
