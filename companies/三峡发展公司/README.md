## 公司
性质:央国企 · 行业:机械/制造业

长江三峡技术经济发展有限公司（以下简称“三峡发展公司”）成立于1998年，是中国长江三峡集团有限公司的全资子公司。三峡发展公司具有市政公用工程总承包一级资质以及多项监理咨询甲级资质，具备工程建设、投资、运营一体化管理以及全过程咨询服务能力，可在水利水电、新能源、生态环保、城市基础建设等领域提供高质量的综合性服务。近年来，三峡发展公司实施多元化经营战略布局，大力发展监理咨询、检验检测、承包业务等，业务规模不断扩大，业务覆盖国内近30个省（自治区、直辖市）。
