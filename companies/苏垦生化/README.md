## 公司
性质:民企 · 行业:能源/化工/环保

江苏省农垦生物化学有限公司，源于1996年，作为国有企业江苏省农垦集团全资子公司，以经销的方式分销跨国企业产品；2003年成功私有化后，在南京成立行业领先的生产基地，开始有产品的品牌化，成为行业内建立供应链供应商；2019年，由服务型企业转型为创新驱动的品牌运营商，成立上海和日本创新中心，专注新原药/新材料创新，并逐步开拓海外市场。截止2025年，苏垦生化荣获全国农药行业制剂销售TOP100，是一家迅速扩张和成长的公司。
