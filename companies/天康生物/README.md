## 公司
性质:民企 · 行业:医疗/医药/生物

天康生物股份有限公司创立于1993年，2006年在深圳证券交易所上市，是新疆兵团国有控股上市公司。业务涵盖饲料及优质饲料原料、生猪养殖及食品加工、动物医药生物制品三大主业，下设饲料、食品养殖、制药、蛋白油脂、农产品、农牧担保六大业务单元。2024年度营业收入171亿元。
