## 公司
性质:央国企 · 行业:农林牧渔

中国牧工商集团有限公司（简称“中牧集团”）成立于1982年，四十多年来，中牧集团以服务“三农”为己任，以引领畜牧业、产业、服务美好生活为使命，以建成世界一流农牧企业为愿景，目前已发展成为生产经营、贸易服务、科技开发和投融资为一体的现代化农业大中央企业。主要生产经营有：畜禽种业、健康养殖、动物疫苗和兽药、饲料添加剂、肉食品加工等。
