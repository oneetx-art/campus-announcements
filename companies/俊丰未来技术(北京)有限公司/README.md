## 公司
性质:民企 · 行业:通信/电子/半导体

俊丰未来技术(北京)有限公司成立于2020年11月19日，坐落于北京市中关村新兴产业前沿技术研究院，在南通、吉林两地均有子公司。公司自成立以来一直致力于电子专用材料的研发、生产、销售及技术服务，是一家基于贵金属晶体合成，为表面处理和半导体行业贡献高品质合金及表面处理技术、有机体结合价值的新材料、封装密封材料、PEEK钛矿、导电材料等，主营产品包括钙钛矿、分子电材料、涵盖光伏、消费电子、医疗、被动元器件等领域。
