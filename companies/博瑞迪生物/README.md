## 公司
性质:民企 · 行业:医疗/医药/生物

博瑞迪生物科技有限公司成立于2017年，总部位于石家庄，是一家专注于动植物，公司长期聚焦植物分子育种与应用的创新型生物分子检测和动植物信息与人工智能，转化为育种家的手中最准的生物分子育种及智力，将为最前沿的基因组学、的工具。公司构建了完全国产化、形象化、自动化、信息化的分子育种技术体系，形成集自主研发的液相芯片整体搭建、AI检测设计与基因组学服务、实验室产品、自动化设备设计、合成与检测学服务、综合解决方案全链条CR0服务等为核心的一站式的作物育种方案。
