## 公司
性质:民企 · 行业:通信/电子/半导体

埃特曼半导体是一家专注于开发和提供高性能化合物半导体材料及解决方案的供应商。公司致力于以分子束外延（MBE）技术为基础，探索化合物半导体材料性能的边界，以满足无线通信、激光光电、电力电子等领域对高性能器件的严苛要求。
