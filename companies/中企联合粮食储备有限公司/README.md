## 公司
性质:央国企 · 行业:农林牧渔

中企联合粮食储备有限公司是经国资委批准组建，中储粮集团与中粮集团开展股权合作的专业化粮食仓储服务公司，中储粮集团、中粮集团持股比例分别为51%、49%，由中储粮集团控股。公司的主要任务是服务国家宏观调控，落实中央储备收购、轮换、销售、动用等具体任务以及国家委托的政策性任务。主要经营范围为：粮油仓储服务；粮食收购；货运代理；食品销售（仅销售预包装食品）；初级农产品收购；谷物销售；豆及薯类销售；货物进出口。
