## 公司
性质:民企 · 行业:教育/培训/科研

方田教育于2014年创立，致力于中小学学生全面成长的综合性教育。目前拥有国际学科教育、素质教育、软件研发、图书出版等多个业务板块，现有1000多名员工。学生规模在11年内实现了每年100人次至20万人次的增长，覆盖合肥、芜湖、马鞍山、安庆、南京、杭州、上海、重庆、成都、深圳、中国香港、新加坡十二个城市。已经帮助近50万学生在学习习惯、学习方法和学习成绩上取得了长足的进步。我们希望用科技改变学习，让每个学生都享受到优质教育。
