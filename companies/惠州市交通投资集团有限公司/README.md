## 公司
性质:央国企 · 行业:交通/物流/仓储

惠州市交通投资集团有限公司成立于2012年，是惠州市委、市政府为整合全市交通国有交通企业，优化资源配置，推动重点交通项目建设，促进惠州由交通大市向交通强市迈进，授权惠州市国资委组建的大型国有独资项目公司，集团资产总额超千亿，企业主体信用评级AAA，是惠州市首家AAA评级的国企。2024年获评惠誉BBB国际评级，是粤东地区首家获三大国际评级（惠誉评级）的国有企业；并同时获评中诚信亚太Ag国际评级，也是中诚信亚太授予全国地市级交通投资企业的最高评级，也是授予广东省内国企的最高评级。旗下各级全资、控股企业共52家，在册员工近4500人。业务覆盖高速公路、干线公路、轨道交通、客运站场、矿产开采、智慧停车、新能源（光储充）、物流运输等的投资、建设与管理。
