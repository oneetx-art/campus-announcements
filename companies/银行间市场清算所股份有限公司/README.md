## 公司
性质:央国企 · 行业:金融业

银行间市场清算所股份有限公司（简称上海清算所）为中国人民银行所属企业，系金融基础设施运营机构，是银行间市场合格中央对手方和中央证券存管机构。上海清算所先后获得欧盟、英国、香港等国家和地区跨境监管认证，是唯一获得上海市市长质量奖、第四届中国质量奖荣誉的金融机构，也是首批荣获“亚洲风险奖”的境内金融基础设施运营机构。
