## 公司
性质:央国企 · 行业:通信/电子/半导体

中国电子信息产业集团有限公司第六研究所于1965年1月19日经国务院国防工业办公室批准成立，是我国最早从事电子技术应用系统研究、开发的重点院所之一，自1999年起直属于中国电子。是计算机科学与技术、软件工程两个一级学科全日制硕士学位授权单位，建有工业控制系统信息安全技术国家工程研究中心。中国信息安全研究院有限公司成立于2012年2月，是中国电子的全资二级机构，主要从事战略发展、产业研究、数字科技、网信测评、网络安全、高新电子等业务，是国家级双创示范基地，建有国家级多类科研平台。
