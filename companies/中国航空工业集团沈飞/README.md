## 公司
性质:央国企 · 行业:机械/制造业

中国航空工业集团有限公司（简称“中国航空工业集团”）是中央直接管理的国有特大型企业和我国航空工业骨干企业，经营范围涵盖航空武器装备、运输类飞机、通用飞机、直升机、机载系统、航空科研、飞行试验、专用装备、汽车零部件、工程建设等产业领域，下辖100余家成员单位，员工近40万人。沈阳飞机工业（集团）有限公司（简称“中国航空工业集团沈飞”）隶属于中国航空工业集团，是以航空产品制造为核心主业，集科研、生产、试验、试飞、服务保障为一体的大型现代化飞机制造企业，拥有沈飞民用飞机、沈飞民品工业、沈飞企管、吉林航空维修等所属公司，是中国航空工业集团骨干企业之一。
