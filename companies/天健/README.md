## 公司
性质:民企 · 行业:咨询

天健会计师事务所成立于1983年12月，是我国首批具有A+H股企业审计资质的全国性大型专业会计审计中介服务机构。综合实力连续位列全国内资所前茅，全球前二十强。天健拥有包括A股、B股、H股上市公司、大型央企、国企、外商投资企业等在内的固定客户7,000余家，其中上市公司客户764家，占全国市场份额的13%，位列全国前二。2021年至2023年期间，天健三年合计IPO过会家数240家、已发行家数254家以及在会数量三项指标均蝉联全国第一。
