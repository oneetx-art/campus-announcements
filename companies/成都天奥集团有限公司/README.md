## 公司
性质:央国企 · 行业:通信/电子/半导体

成都天奥集团有限公司成立于1997年9月，是中国电子科技集团有限公司下属中电天奥有限公司的全资控股的高科技企业。公司位于成都市高新西区，占地面积200余亩，现有员工1150余名，年营业额4.5亿元。公司主要从事智慧边海防、数据智能和情报信息系统应用与服务，拥有智慧边海防、数据智能、智慧电磁3条产品线、2个分公司、1个省级企业技术中心、35项专利、43项软件著作。
