## 公司
性质:民企 · 行业:新能源

内蒙古通威高纯晶硅有限公司成立于2017年8月，是通威股份旗下永祥股份在包头投资设立的子公司，位于包头市昆都仑区金属深加工园区内。公司拥有国内一流技术专家和化工新能源管理团队，是专业从事高纯晶硅（多晶硅、单晶硅、电子级多晶硅）研究、开发、生产、销售及光伏发电项目的开发、建设、维护、经营管理和技术咨询的高科技型企业，公司致力于发展清洁能源，打造高纯晶硅及光伏产业的行业标杆。
