## 公司
性质:民企 · 行业:能源/化工/环保

久立集团股份有限公司（简称“久立集团”）创建于1987年，总部位于浙江省湖州市，是以特种合金材料研发制造为核心的高端装备材料制造商。久立集团拥有久立特材（股票代码：002318）及久立钢构、久立电气、嘉翔精密等多家控股或全资子公司，形成“材料研发—精深加工—高端制造”的全产业链布局。久立集团及旗下子公司拥有高新技术企业、国家技术创新示范企业、国家知识产权示范企业，中国合格评定国家认可委员会CNAS实验室、博士后工作站和省级重点企业研究院等荣誉。
