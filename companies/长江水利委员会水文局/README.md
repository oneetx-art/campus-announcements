## 公司
性质:事业单位 · 行业:政府/机构/组织

长江委水文局隶属于水利部长江水利委员会，是正局级公益一类事业单位，总部位于湖北省武汉市，所属8个（重庆、宜昌、荆州、襄阳、武汉、南京、上海、昆明）水文水资源勘测局（水环境监测中心）分布上、长江委水文局是国家流域水文和江河流域水土、治理、开发和管理等开展流域水情网站建设、水文水资源监测、水环境监测评价、河道水库测绘、水资源调查、评价和环境监理评价、水文水资源规划、水文自动测报、河道泥沙演变研究等工作的专业水文机构。
