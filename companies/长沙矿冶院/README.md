## 公司
性质:央国企 · 行业:教育/培训/科研

长沙矿冶研究院有限责任公司（简称长沙矿冶院）始建于1955年，是世界500强企业中五矿集团有限公司（以下简称中国五矿）所属开发与新能源材料的重要科技研发平台，先后隶属于中国科学院、国防科工委、冶金工业部、国务院国资委。
