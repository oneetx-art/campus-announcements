## 公司
性质:央国企 · 行业:能源/化工/环保

武汉烽火富华电气有限责任公司（以下简称“烽火富华”）是2008年10月由烽火科技集团发起成立，智慧能源领域产品与解决方案提供商。公司注册在武汉东湖新技术开发区，注册资本壹亿壹仟捌佰万元。公司深耕智慧能源电力变换及储能领域十多年，致力于将信息通信技术、传感技术、储能技术、微电网能量管理与电力电子技术进行融合，面向智慧能源领域提供先进的数字能源产品及服务。公司主要产品有：储能系统系列产品、新能源汽车充电桩系列产品、智能成套电气系列产品、智慧多功能杆系列产品、多能互补充裕微电网系统、智慧建筑集成管理平台、建筑能耗管理系统等。公司具有一流的项目市场开拓和准入资质，可提供产品和项目的研发、设计、制造、安装、运维服务等一站式解决方案。公司是国家级专精特新“小巨人”企业、“高新技术企业”、湖北省“制造业单项冠军”、湖北省“守合同、重信用”企业、武汉市“千企万人”企业、武汉市“金种子”企业、东湖高新区“3551人才”企业、拥有省级技术平台2个（湖北省企业技术中心、湖北省中小企业技术中心），市级技术平台1个（武汉市优秀企业研究中心）。
