## 公司
性质:民企 · 行业:金融业

鹿秀投资，是一家专业的私募证券基金管理公司，成立于2016年。目前在管资产规模40亿元，累计投资规模150亿左右。策略包含一级基本面量化策略、二级量化选股策略、投资理念、专业机构投资者及高净值人群，提供定制化的资产配置方案。鹿秀投资于2017年获得证券类私募基金管理人资质，2022年取得基金业协会普通会员资格，2023年取得资管投资资格，2024年取得QDLP（跨境投资）资格。
