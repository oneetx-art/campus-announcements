## 公司
性质:央国企 · 行业:房地产业/建筑业

深圳市城市规划设计研究院股份有限公司（简称“深规院”，英文缩写“UPDI”），是中国规划设计行业的领军机构，专注于提供城市实践解决方案。起步于1990年，长期全方位参与深圳城市规划建设，助力深圳从南海渔村发展成为全球标杆城市。业务延伸至东莞、中东部等新兴城市。
