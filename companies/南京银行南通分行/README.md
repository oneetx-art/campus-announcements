## 公司
性质:央国企 · 行业:金融业

南京银行成立于1996年2月8日，是全国20家系统重要性银行之一，是一家具有独立法人资格的股份制商业银行和上市银行，实行一级法人经营管理体制。南京银行坚持发展为要，是最早引进战略投资者的中资银行之一和全国第一家在主板上市的城商行，位列英国《银行家》杂志公布的全球1000家大银行第86位，历年来在国内外银行业各类奖项评比中屡获殊荣。南京银行南通分行成立于2009年12月19日，深耕区域发展多年，依托优质金融服务体系，已实现南通地区各县市网点全覆盖，存贷款规模在本地43家银行金融机构中排名前列。南通分行始终汇聚专业人才队伍，秉持“专业、专注、专营”的服务原则，在金融创新与服务实体经济领域持续发力。
