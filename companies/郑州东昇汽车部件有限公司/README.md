## 公司
性质:民企 · 行业:汽车制造/维修/零配件

郑州东昇汽车部件有限公司成立于2010年10月，是广州东昇机械有限公司全资子公司，主营业务为汽车零部件研发、设计与制造。涵盖车身、底盘、新能源汽车电池、发动机、电器盒、悬挂、转向、刹车系统等汽车主要模块，具有智能化、数字化的先进生产线。公司致力于为客户提供高价值解决方案，是长城汽车、蜂巢能源、东风日产、日产中国的核心战略合作伙伴之一，产品不仅供应国内主流车企，更交付北美、欧洲、亚洲、非洲等全球21个国家和地区。公司以创新为基石，为推动世界汽车产业的科技进步做出贡献。
