## 公司
性质:民企 · 行业:能源/化工/环保

万普隆能源股份有限公司由万人计划入选者潘军（中关村高聚工程创业领军人才、国家科技进步二等奖获得者）于2009年在北京创立，2021年5月迁址重庆，是国家和中关村高新技术企业，是一家致力于通过对“地质、工程、排采”等环节的综合诊断与分析，以充分释放气井的产气潜力为目标，从“一体化”角度制定“一井一策”的整体解决方案。凭借着自主研发的定量化、智能化生产管理系统和高精度的成套智能控制装备，对低压低产低效老气井、间开气井或长停气井提供增产解决方案，根据增产效果支付技术服务费，全风险的提供精细排采生产管理服务，实现对老旧气井提升产量和提高效益的专业技术服务公司
