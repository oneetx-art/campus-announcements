## 公司
性质:民企 · 行业:汽车制造/维修/零配件

浙江银轮机械股份有限公司是一家专业研发、制造和销售各种热交换器的民营股份制企业，成立于1999年，2007年上市，总部位于浙江省天台县，是我国热交换器行业龙头企业，高新技术企业，技术创新示范企业，首家民营上市公司、行业标准“组长级”起草单位和国家第一批制造业单项冠军培育企业，同时也是浙江省“雄鹰”企业，拥有全省唯一的省级汽车零部件双创示范基地，是我国汽车、工程机械及内燃机零部件领域最具影响力的民族品牌，连续二十多年保持换热器行业产销量国内领先。
