## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

南网传媒公司是中国南方电网有限责任公司所属的专业子公司，成立于2010年9月，公司设在广州，与南方电网公司新闻中心实行'两块牌子、一套人马'管理，是南方电网公司新闻宣传和品牌建设、企业文化主阵地和专业化支撑机构，以'传播党的声音、擦亮南网品牌、弘扬企业文化、传媒智库、媒体技术服务、新闻宣传、品牌文化、为职媒智库，承担南方电网空间信息等业务，拥有南方电网网站、南方微能源'杂志，运营南方电网公司促进基金和金微传播微信，承担广东省南网文化艺术馆网站、南方电网工作，是国家高新技术企业、广东省'专精特新'企业、广东省互联网联合会副会长单位。
