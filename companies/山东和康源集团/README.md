## 公司
性质:民企 · 行业:农林牧渔

山东和康源集团成立于2009年3月，总部设在山东省济南市。是一家从事种禽种苗养殖为主导的大型养殖企业，主要从事种禽种苗养殖与繁育、商品养殖、饲料生产、肉鸭屠宰与食品加工、国际贸易等业务。目前拥有分子公司30余家，分布于山东、江苏、河北、内蒙古等地，销售收入近50亿元。
