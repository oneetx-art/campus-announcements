## 公司
性质:事业单位 · 行业:教育/培训/科研

西安航天动力试验技术研究所隶属于中国航天科技集团有限公司第六研究院，成立于1955年，是一家主要从事液体火箭发动机试验和试验技术研究的科研事业单位，承担着我国深空探测、登月航天工程载人航天、载人航天、超大推力、新型液体火箭发动机的研制试验任务，为我国航天发射任务和航天工程的实施，提供坚实的动力保障。
