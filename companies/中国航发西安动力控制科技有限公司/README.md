## 公司
性质:央国企 · 行业:机械/制造业

中国航发西安动力控制科技有限公司始建于1955年，是中国第一家航空发动机控制级产品研制生产企业，隶属于中国航空发动机集团有限公司。公司主营业务为航空发动机燃油与控制系统研制与生产及其衍生业务。目前，公司在航空动力控制领域形成了集设计、制造、验证、研发、技术服务“四位一体”“厂所合一”的专业体系，具备控制、机械、液压、电子等多专业综合科研能力，拥有国家级企业技术中心、博士后科研工作站。
