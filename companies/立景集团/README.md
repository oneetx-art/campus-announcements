## 公司
性质:民企 · 行业:通信/电子/半导体

立景创新集团是全球前三大摄像头模组公司。集团总部位于广州，在东莞、江西、苏州、深圳、台湾、韩国、越南等地设立研发及生产运营基地，扎根各种影像科技产品近二十年，现有职工超过2万人，拥有强大的研发团队。产品涵盖手机摄像模组、桌上型PC/携带型笔电摄像模组、车载摄像模组、激光雷达、运动相机、无人机、AR/VR、VCM马达、打印机/扫描仪等产品。我们拥有世界知名的合作伙伴：微软、华为、荣耀、惠普、联想、亚马逊、影石、ASUS、OPPO、DELL、Intel、Canon、Kodak、Fujifilm、Panasonic等。
