## 公司
性质:民企 · 行业:能源/化工/环保

元利化学集团股份有限公司，成立于2003年2月，是上海市证券交易所主板上市公司（股票代码603217）。集团总部位于潍坊市昌乐县，公司拥有潍坊昌乐、重庆涪陵、潍坊昌邑、内蒙古兴安盟（在建）四个生产基地，下设山东元利科技、重庆元利科技、潍坊元利新材、欧洲元利等多家全资子公司。
