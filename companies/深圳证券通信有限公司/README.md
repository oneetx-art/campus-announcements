## 公司
性质:民企 · 行业:IT/互联网/游戏

深圳证券通信有限公司（简称深证通）是深圳证券交易所所属金融科技企业，成立于1993年，主要承担深圳证券市场交易结算通信，支持深交所核心技术系统建设，为金融机构提供数据中心、深证云、金融数据交换平台等金融科技服务，建设并运营中国证券期货业南方信息技术中心等职责，是国家高新技术企业、重点软件企业。
