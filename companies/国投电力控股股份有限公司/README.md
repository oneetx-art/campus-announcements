## 公司
性质:央国企 · 行业:能源/化工/环保

国投电力控股股份有限公司（简称国投电力），是国家开发投资集团有限公司的控股企业，涉及水电、火电、光伏、陆上风电、海上风电、储能、售电等领域，项目分布于中国24个省、市、自治区以及“一带一路”沿线、OECD沿线的4个国家。国投电力始终秉持稳健经营和绿色发展的理念，自2002年上市以来，实现了令人瞩目的跨越式发展，成为中国效率最高、效益最好的综合能源公司之一，也是中国第三大水电上市企业，以及国内第二家荣获伦敦证券交易所绿色经济标志的伦交所上市中国企业。二十三年间，国投电力系统内从水电、火电扩展到清洁能源为主、水火风光并济的化，形成以清洁能源为主、水火风光电等综合能源投资运营商，拥有优质高效的业务资产、境内外全面广泛的业务布局。
