## 公司
性质:民企 · 行业:能源/化工/环保

三棵树创立于2002年，始终关注人类美好生活和家居健康，工程领域打造绿色建材一站式集成系统，零售领域主笔“七位一体”产品+马上住服务体系，2016年登录A股证券主板上市，2019年上榜胡润中国民营企业500强榜单，中国涂料品牌第一，全球建筑涂料第一，2025年第19次登世界品牌大会“中国500最具价值品牌排行榜”，全国布局莆田、上海、广州、北京4大中心；全国14大生产基地；全资及控股36家公司，莆田生态工业园、四川生态工业园、安徽生态工业园被评为国家级“绿色工厂”，千人研发团队、4大研发平台、6大研发中心，聘任诺贝尔化学奖得主麦安瑟·莫滕森为技术顾问，ESG评级获得“AA”级，A股涂料细分赛道排名第一，入选ESG优秀实践案例
