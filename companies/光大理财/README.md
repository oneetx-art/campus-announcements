## 公司
性质:央国企 · 行业:金融业

光大理财有限责任公司成立于2019年9月，是股份制银行中首批获准筹建、首家获准开业、首家成立的银行理财子公司。通过自2004年推出国内首支人民币理财产品以来，通过投资模式的不断创新和投资管理能力的持续提升，保持良好的品牌效应和市场影响力，引领国内银行理财市场。2004年至2024年末，光大银行理财业务累计发行理财产品超47万亿元，为投资者创造收益超5000亿元，2021年，光大理财以优异的责任担当荣获2021年度全国金融五一劳动奖状。
