## 公司
性质:民企 · 行业:IT/互联网/游戏

北京道亨软件股份有限公司（简称“道亨软件”）系北京恒华伟业科技股份有限公司全资子公司，公司成立于2013年，位于中关村国家自主创新示范区西绒线。道亨软件坚持“独立研发、自主可控”的技术路线，专注于数字化、智能化技术在电力能源领域的应用与推广，积累了2D/3D图形建模、多源海量数据融合计算、电气及结构计算与仿真等核心技术。依托自主BIM技术平台，公司产品及服务涵盖工程勘测、设计、制造、施工、运维全生命周期，客户包括国家电网、南方电网、中国电建、中国能建等大型央企集团及其下属电力勘察设计企业，主要产品智能设计软件市场规模与客户覆盖率长期保持行业前列水平。
