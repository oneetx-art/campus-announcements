## 公司
性质:央国企 · 行业:房地产业/建筑业

中国建筑第八工程局有限公司（以下简称“中建八局”）是世界500强企业——中国建筑股份有限公司的全资子公司，始建于1952年，企业发展综合实力位居国内同级次建筑企业前列，是国家住建部颁发的新房屋建筑工程施工总承包特级资质企业，以投资、建造、运营为核心业务，始终活跃在中国经济建设的前沿，参与了一大批国家和地方的重点工程、城市地标和民生工程建设。
