## 公司
性质:央国企 · 行业:能源/化工/环保

中广核达胜加速器技术有限公司是中国广核集团下属中广核核技术发展股份有限公司的全资子公司，成立于2007年5月。公司主要从事辐照加速器研发与制造、核电配套高端制造、无损检测装备及核心零部件研发与制造等业务。公司是国内领先的工业电子加速器研发制造企业，产品覆盖低、中、高能区，是国内拥有电子加速器类型、结构形式、型号较全的公司之一。
