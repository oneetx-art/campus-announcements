## 公司
性质:民企 · 行业:通信/电子/半导体

全志科技（AllwinnerTechnology）成立于2007年，是卓越的智能应用处理器SoC、高性能模拟器件和无线互联芯片设计厂商。总部位于中国珠海，在深圳、西安、上海、成都、横琴、广州、香港等地设有研发中心或分支机构，2015年于深交所创业板上市，股票代码300458。产品广泛适用于工业控制、智慧汽车、智慧家电、机器人、智慧安防、网络机顶盒、智能硬件、平板电脑、虚拟现实以及电源模拟器件、无线通信模组、智能物联网等多个产品领域。
