## 公司
性质:央国企 · 行业:教育/培训/科研

雄安国创中心科技有限公司位于雄安新区启动区科创中心，是由雄安新区管理委员会作为核心发起单位，联合6家央企共建单位成立的一家区属国有企业。雄安国创公司是京津冀国家技术创新中心雄安中心的运营主体，是支撑雄安建设的战略科技力量，着力打造自主创新和原始创新重要策源地，搭建一流创新平台，围绕产业链部署创新链，建设京津冀协同创新共同体，推动具有前瞻性的创新试点示范项目在雄安落地，未来要打造成为雄安新区的技术创新中心、成果转化中心、企业孵化中心。
