## 公司
性质:民企 · 行业:机械/制造业

重庆山外山血液净化技术股份有限公司成立于2001年，是一家集血液净化设备、血液净化耗材、血透中心智能管理系统和连锁血液透析中心于一体的国家高新技术企业，为全球肾脏病和危重症患者提供血液净化整体解决方案。公司是中国血液净化行业的龙头企业、国家标准和行业标准起草单位，同时也是中国血液净化行业唯一科创板上市企业（“山外山”，股票代码：688410）。山外山公司拥有多个国家级科技创新平台，先后荣获“国家科学技术进步奖二等奖”等多项国家级奖项，被评为“国家技术创新示范企业”。公司通过了ISO13485:2016质量管理体系认证，系列产品获得欧盟CE认证。山外山公司产品已销往国内外数千家医疗机构，出口至全球100余个国家和地区，实现市场装机数万台，服务全球数十万名肾病患者。
