## 公司
性质:央国企 · 行业:机械/制造业

中船航海科技有限责任公司（以下简称“中船航海”）是中国船舶集团有限公司下属（历史于2014年由上海航海仪器有限公司与中国船舶工业系统工程研究院导航自动化专业共同组建，是我国船舶导航自动化领域的主要科研生产企业，业务聚焦船舶导航自动化领域，目前形成了以系统集成、信息产品、卫星导航、光学惯导、船舶自动化为主的产业结构。中船航海总部位于上海，在北京、西安为分别设立研发中心和研发生产基地，获国家专精特新“小巨人”企业、“上海市高新技术企业”“上海市专精特新企业”“科技小巨人”“上海市知识产权管理试点企业”“花园单位”、精神文明单位等称号，荣获省、部二、三等奖30余项，拥有有效专利300余项（其中发明专利200余项），有软件著作权100余项。
