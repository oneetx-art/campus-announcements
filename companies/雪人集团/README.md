## 公司
性质:民企 · 行业:机械/制造业

福建雪人集团股份有限公司创建于2000年，于2011年在深圳证券交易所上市（股票代码：002639），是一家以热管理技术为核心的高端装备制造企业，是国家制造业单项冠军示范企业、国家绿色制造示范企业。雪人集团致力于氢能源、工业制冷、清洁能源以及氢能动力四大领域全球供应商的产品、技术以及服务。
