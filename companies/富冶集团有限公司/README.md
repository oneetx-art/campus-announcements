## 公司
性质:民企 · 行业:能源/化工/环保

富冶集团有限公司始建于1958年，是浙江省最早成立的有色金属企业，是长三角地区集矿产铜生产、稀贵金属提炼、多金属回收于一体的，拥有世界一流技术装备的现代化大型铜有色金属集团。集团总部位于“天下佳山水、古今推富春” 美誉的浙江富阳和鹿鼎城——杭州富阳。旗下拥有浙江江铜富冶和鼎铜业有限公司、江西环宇、安徽城鑫矿业有限公司、浙江浩富置业有限公司、深圳科技有限公司、江西和立环保科技有限公司、公司、上海富冶国际贸易有限公司及富冶（香港）国际贸易有限公司等多家控股子公司。
