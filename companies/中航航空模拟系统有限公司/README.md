## 公司
性质:央国企 · 行业:机械/制造业

中航航空模拟系统有限公司（简称“中国航空工业集团模拟器”）于2020年成立于上海，作为中国航空工业集团有限公司与上海市政府战略合作机载公司“三中心一总部”的项目之一，是集团公司推动模拟装备专业发展的战略举措。公司定位于中国航空工业集团在航空模拟装备领域的专业化产业平台，秉承“忠诚奉献、自力更生、艰苦奋斗、勇攀高峰”的新时代航空报国精神，聚焦航空模拟仿真技术，承担高等级飞行、任务、训练模拟装备研制、生产及模拟训练培训等业务，提供面向用户需求的一体化解决方案，打造标准化和体系化的产品，力争成为技术先进、市场领先、具有国际竞争力的航空模拟系统装备行业领导者。
