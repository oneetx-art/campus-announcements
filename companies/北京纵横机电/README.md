北京纵横机电科技有限公司是中国铁道科学研究院集团有限公司的全资子公司，成立于1988年，2008年正式搬迁到北京市海淀区中关村永丰科技创新基地，占地90亩，现有员工约1100人，产值70多亿，是国家高新技术企业、北京市企业技术中心和北京制造标杆工厂，拥有完备的技术创新体系、先进的工程转化平台和世界领先的试验验证能力，专注于轨道交通移动装备的制动、牵引、网络、安全监测及新材料等核心关键系统的技术创新和产业化发展，可提供适配不同车型不同速度等级的系列化模块化核心控制系统产品，作为轨道交通车辆系统集成供应商，以服务轨道交通为己任，以重大项目为主线，广泛结交国内外合作伙伴，用先进轨道交通技术服务中国乃至世界各国人民，践行绿色发展使命
