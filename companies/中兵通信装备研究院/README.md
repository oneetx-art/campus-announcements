## 公司
性质:事业单位 · 行业:教育/培训/科研

中兵通信装备研究院成立于2017年5月，由中国兵器科学院、中兵通信科技股份有限公司和地方政府共建，是中兵通信科技股份有限公司的创新平台和科研机构，主要办公地点位于武汉市东湖高新技术开发区（中国光谷）山湖北路1号和北京市丰台区总部基地海鹰路6号院，武汉办公区建筑面积6000平方米，北京办公区建筑面积2200平方米，目前现有科研人员200余人，具有省市、市级人才技术带头人、优秀专家及兵器专业技术带头人15余人，获得省、市、集团级工匠称号100余人，是中国兵器工业集团唯一的军用通信系统研发平台。目前主要从事宽带自组网、超短波通信、卫星通信、数据链、弹载数据链、潜水（声速）通信及通信车的研制开发，研制的多跳地、海、空超短波电台已经成为我军的关键和特种作战的科研骨干。产品广泛应用于陆、海、空等军兵种以及航空、航天、民航、公安和森林消防等领域。先后与清华大学、北京理工大学、西安电子科技大学等进行了不同层次的合作，与陆军工程大学成立了军事航空通信联合实验室，与华中科技大学共建了联合实验室。
