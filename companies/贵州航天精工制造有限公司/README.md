## 公司
性质:央国企 · 行业:机械/制造业

贵州航天精工制造有限公司始建于1968年，是中国航天科工集团有限公司航天精工股份有限公司下属的集高、中端紧固件、橡胶件研发、制造、检测、销售、服务为一体的高新技术企业。现有职工700余人。建厂50余年来，一直为航空、航天、船舶、兵器、燃气轮机等领域配套特种紧固件和橡胶件，年产量约6000万件（套）。
