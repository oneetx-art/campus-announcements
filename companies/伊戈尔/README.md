## 公司
性质:民企 · 行业:能源/化工/环保

伊戈尔1999年成立，是深圳证券交易所上市公司。公司聚焦能源、信息行业，应用电力电子技术，向全球市场提供产品、解决方案及服务。主要产品有能源类的新能源变压器；信息类的箱变、中压直流供电系统、数据储能微网；信息类的精密配电变压器、特种变压器；铜锌铝的车载电源、车载开关电源、LED应用于光伏、风电、配电、工控、数据中心、通讯、照明、储能、汽车等领域。在全球范围内，公司已建成十二个全面推行数智化制造的分布基地，在建两个；建立了五个研发中心；设立了销售各大洲的销售分支及售后服务机构，构建起“全球造，销全球”的宏伟蓝图。
