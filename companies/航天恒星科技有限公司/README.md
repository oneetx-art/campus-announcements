## 公司
性质:央国企 · 行业:机械/制造业

航天恒星科技有限公司（航天五院五〇三所）是中国航天科技集团有限公司卫星应用的主要支撑单位，是中国东方红卫星股份有限公司（股票代码600118）的控股子公司，坐落于北京中关村环保科技示范园，旗下拥有多家分子公司。公司荣获“中国自主创新科技企业奖”、“航天技术应用产业先进单位”、中央国家自主创新示范区“千百十工程”重点培育企业等荣誉称号，是国资委确定的国家中央企业岗位分红权激励试点单位之一。公司现有员工2400余人，其中硕士、博士人员达50%以上；先后有四位院士在作业工作，获“万人计划”、享受政府特殊津贴人员、学科科技委专家等国家级、省部级专家20余名，研究生指导教师30余名。公司建立了从骨干人才到专家的人才培养机制。具有完整的员工培育体系，设有国家信息与通信工程、软件工程一级学科硕士学位授权点及博士后科研工作站，并且为员工打造多元化的发展通道。
