## 公司
性质:合资 · 行业:能源/化工/环保

扬子石化-巴斯夫有限责任公司（简称“扬巴公司”）是由中国石化和巴斯夫以50:50的股比合资兴建的一体化石化基地。公司正式成立于2000年，占地242公顷，2005年正式投入商业运营，并先后于2011年、2014年、2023年完成了三轮大型扩建。到目前为止，双方母公司累计投资约390亿人民币。为满足农业、建筑、电子、制药、卫生、汽车和化学制造等多个行业快速增长的需求，公司设计年产生产74万吨的乙烯装置为龙头，总计300万吨装置，每年为中国市场生产约300万吨高质量的化学品和聚合物。扬巴公司所有的装置均践行巴斯夫的“一体化”理念并采用世界先进的技术以节约原料和能源，降低销售和物流成本，充分发挥协同效应。扬巴公司2024年实现销售额约204亿元人民币，截止年底共有2164名员工。
