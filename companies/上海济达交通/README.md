## 公司
性质:民企 · 行业:IT/互联网/游戏

上海济达交通科技有限公司成立于2013年，位于上海浦东新区，是上海济通汽车技术有限公司、德国大陆集团（Continental）、德国博世（BOSCH）及德国ESSEN Auto Group共同投资的技术型企业。济达交通提供ITS、车联网和ADAS解决方案及服务，自2015年成立以来，济达交通一直致力于智能交通、自动驾驶与车路协同领域的研究，将数字孪生、智慧管理、路侧管控、智能车机、自动驾驶等100多项业内领先的技术应用于产品，为客户提供优质的解决方案。公司以智能驾驶的核心技术为基础，不断研发智能交通技术及产品，并于近年实现产业化，也为行业培养了众多研发人才。
