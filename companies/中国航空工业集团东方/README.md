## 公司
性质:央国企 · 行业:机械/制造业

陕西东方航空仪表有限责任公司（简称：中国航空工业集团东方）隶属于中航机载系统有限公司，是研制和生产航空仪表飞行控制系统以及扭矩工具、检测仪器等系列产品的国有军工骨干航空企业。公司总部位于汉中，2015年9月在西安成立分公司（西安研发中心），形成了“西安研发、汉中生产”的战略格局。公司主要从事直升机飞控系统、光纤捷联航姿系统、北斗卫星定位系统/惯导系统、MEMS捷联航姿系统、陀螺仪表、微特电机及传感器等航空军用产品以及扭矩工具、检测仪器、智能检测系统等非航空民品的研制和生产。
