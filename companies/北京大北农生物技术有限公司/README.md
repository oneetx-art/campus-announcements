## 公司
性质:民企 · 行业:医疗/医药/生物

北京大北农生物技术有限公司成立于2010年11月，是专注于玉米、大豆等主要农作物生物技术产品研发的国家高新技术企业，目标是智创农业生物技术领军企业，致力于作物效益、营养健康和可持续发展，搭建国际一流科研平台，创建工程化生物育种研发体系，旗下丰脉®品牌有多个产品获批相关证书，国际布局领先，坚持农业科技创新，保障国家粮食安全。
