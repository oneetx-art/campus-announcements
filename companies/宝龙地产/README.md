## 公司
性质:民企 · 行业:房地产业/建筑业

宝龙集团于1990年在澳门创立。宝龙产业经营不断拓展，持续深化“双核双翼”业务布局，形成商业、地产、创新、酒店、商办等多元产业协同发展的格局。旗下宝龙地产自2003年起专注开发运营综合性商业地产项目，2009年在香港成功上市（股票代码：HK.1238）。旗下宝龙商业于2019年在香港上市（股票代码：HK.9909）。地产集团目前在长三角、粤港澳大湾区、海西经济区等区域打造了近300个高品质物业项目。商业项目涵盖宝龙一城、宝龙城、宝龙广场三大产品系列，住宅项目涵盖从中高档商品房到别墅等各类业态。截至目前，宝龙集团有万余名员工活跃在海内外200多家公司，并连续十七年获得“中国房地产百强企业”、连续十一年获“中国商业地产公司品牌价值TOP10”等荣誉。
