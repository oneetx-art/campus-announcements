## 公司
性质:央国企 · 行业:检测/认证

建研院检测中心有限公司（以下简称“检测中心”）源于1989年成立的中国建筑科学研究院建筑工程检测中心，2021年6月成为中国建研院下属独立法人企业，2022年12月改制为中国建研院控股子公司。作为我国建设工程检测与认证行业的标杆企业，肩负着国家建筑工程质量检验的核心和国家化学建筑材料测试中心（建工测试部）的重要职责，先后参与和承担“十一五”、“十二五”及“十三五”“十四五”等国家重大“50余项课题，主编国家及行业标准50余项，拥有有效专利50余项，获省部级以上科技奖励30余项，与美国、德国、马来西亚、澳大利亚、一带一路沿线国家代表积极开展检验检测、认证认可技术交流；牵头住房城乡建设部质量评定工程技术创新中心、绿色节能检测技术北京市工程实验室等省部级科技平台，承担中国合格评定国家认可委员会（CNAS）工程建设与建材专业委员会、中国土木工程学会的具体工作。检测中心主要开展地基基础、建筑结构、建筑节能、建筑消防、装饰装修、桥梁道、轨道道交通等建设工程产品及材料的检验检测、监测、质量评估、技术咨询、建设工程质量检测领域能力验证、仪器设备、软件研发、职业技能等级培训及《工程质量》杂志编辑出版等工…
