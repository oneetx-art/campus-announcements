## 公司
性质:民企 · 行业:农林牧渔

江苏好润生物产业集团股份有限公司创建于2012年，2018年升级为集团公司，是一家专注于水产生态健康养殖领域，集科研、生产、销售、技术服务于一体的集团化公司。集团总部位于泰州市海陵区国家现代农业园区红旗大道1号，现有职工总数2000+人。集团及旗下子公司业务覆盖水产苗种、饲料、渔药、技术服务、成蟹养殖、水产品深加工及电子商务等，目前已构建了以河蟹为典型代表的完整的水产领域全产业链商业模式。
