南昌高新招商集团有限责任公司（简称“南昌高新招商集团”）成立于2020年8月，是隶属于南昌国家高新技术产业开发区管理委员会的国有企业。集团目前有7家一级子公司，主要聚集“产业招商投资、城市运营服务、园区建设运营、文旅商旅融合”四大多元化业务体系，集团资产目前已超800亿元。
