## 公司
性质:民企 · 行业:医疗/医药/生物

贝瑞基因成立于2010年5月，于2017年8月在国内A股主板上市（股票代码：000710）。公司总部设在北京，并在北京、青岛、福州、香港等地设立医学检验实验室，在北京、杭州、福建建有试剂和基因测序仪的生产基地。公司在福建有数字生命产业园，该园区是国内为数不多汇集了研发、检测、生产、治疗全流程的基因技术产业集群。
