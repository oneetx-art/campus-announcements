## 公司
性质:央国企 · 行业:房地产业/建筑业

中国能建建筑集团有限公司成立于1952年，是世界500强特大型能源建设央企中国能建头部企业，总部位于安徽省合肥市。公司践行”四个革命、一个合作“能源安全新战略、”30·60“目标、”一带一路“倡议等国家重大战略，聚焦能源电力和房屋建筑”两大主业“，业务遍布国内31个省份和海外24个国家，建成了一大批精品电力工程，累计装机规模位居行业前列，创造了一系列列高、最优、最优质工程纪录，并获”国优金奖“”鲁班奖“等省部级以上优质工程奖210余项。
