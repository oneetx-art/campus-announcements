## 公司
性质:央国企 · 行业:机械/制造业

航天科工惯性技术有限公司是由中国航天科工集团发起成立的高新技术企业，隶属中国航天科工集团第三研究院，注册资金2.03亿。公司主要从事惯性传感器、电路、电源、能源管理系统、测控设备和安全监测系统的研制和生产。产品广泛应用于“神舟”系列、“嫦娥”“天宫”等载人航天工程，配套多型国防装备；安全监测系统成功应用于地质灾害、桥梁健康、矿山大坝等领域，构建了“天空地”一体化的智慧安全监测网络。
