## 公司
性质:民企 · 行业:能源/化工/环保

天能始创于1986年，从丽水水电修理摊起步，致力于成为全球领先的绿色动力能源解决商，探索产业生态，攻坚“碳达峰、碳中和”目标。构建了“资源再生-电池制造-循环利用”产业链，形成与产业同构的产业生态链。目前，天能销售收入超2000亿元，位列中国企业500强第127位，中国民营企业500强第27位，动力电池出货量连续多年全球第一，位居中国轻工业电池行业十强第1位，浙江省百强企业第9位。
