## 公司
性质:民企 · 行业:耐用消费品

安吉尔是全球科技高端净饮水专家，1997年品牌所在企业正式成立，1988年研制出第一台净水器，1993年研制出第一台饮水机，累计深耕净水领域37年，累计获得了1000+项国家专利，几乎囊括净水行业的所有核心技术。凭借专业的品牌形象、领先的科技实力、过硬的产品品质、完善的服务体系，安吉尔赢得海内外万千家庭的选择。同时，安吉尔还众多餐饮、公共办公、医疗领域头部企业的合作伙伴。累计入驻北京首都国际机场、上海浦东国际机场、深圳宝安国际机场等53个国家级重点工程项目。在“全球科技领先的净饮水专家”战略方向指引下，2024年，安吉尔在新加坡设立海外总部，并正式进军美国、印尼等东南亚市场，与北美、中东的重要伙伴达成战略合作，全球化布局全面提速。
