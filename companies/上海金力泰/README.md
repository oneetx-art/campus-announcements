## 公司
性质:民企 · 行业:能源/化工/环保

上海金力泰化工股份有限公司成立于1993年，是集研发、生产、销售和服务于一体的国内高性能涂料领军企业，荣获国家高新技术企业、“专精特新”企业、上海科技小巨人企业、上海质量金奖、上海市认定企业技术中心、中国汽车涂料名牌奖等多项荣誉称号，产品广泛应用于乘用车、商用车、工程机械、工业部件以及建筑幕墙的防护与装饰，是中国唯一以汽车OEM原厂漆为主营业务的上市企业（股票代码：300225）。同时，公司已连续多年位列中国汽车涂料榜单TOP10，其中自主品牌排名第一名，并在中国商用车涂料市场份额第一。
