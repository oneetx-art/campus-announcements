## 公司
性质:央国企 · 行业:交通/物流/仓储

中国土木工程集团有限公司（简称中国土木），前身为铁道部援外办公室，1979年成立，总部位于北京，是最早进入国际市场的四家外经企业之一，隶属“世界500强”中国铁建。业务遍及110+国家和地区，连续20年入选全球最大250家国际承包商百强。业务涵盖：工程承包、设计咨询、铁路运营、境内外投融资、自贸区开发、房地产、矿业、进出口贸易、酒店旅游等。海外首创：坦赞铁路、土耳其安伊高铁、尼日利亚阿卡铁路、亚吉铁路。近年来，中国土木积极融入“国内国际双循环”，打造投营管一体化业务格局，提供基础设施“一站式”解决方案。
