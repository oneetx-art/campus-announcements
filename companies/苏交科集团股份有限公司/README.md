苏交科集团股份有限公司（简称“苏交科”）成立于1978年，2012年深交所挂牌上市，成为工程咨询行业第一家上市公司；2016年战略并购西班牙EPTISA，成功布局全球市场，成为中国咨询“走出去”最强独立第三方。如今，苏交科已发展成为拥有130多个子公司、7000余名员工，业务覆盖全球60多个国家的科型企业。
