## 公司
性质:民企 · 行业:能源/化工/环保

唐山瑞丰钢铁（集团）有限公司成立于2002年，位于河北唐山，是一家集烧结、炼铁、炼钢、轧钢于一体的大型民营钢铁企业，具备中宽带钢专业生产基地及核心供应商，具备钢材500万吨配套生产能力，主要产品为热轧窄带和热轧卷板，公司主营产品为热轧中宽带，河北省著名商标，“宏瑞”牌带钢获中国驰名商标、河北省著名商标、“河北省名牌产品”称号，公司荣获国家高新技术企业、国家级绿色工厂、环保绩效A级企业、省单项冠军企业、省、无废工厂等称号，并多年蝉联中国企业500强、中国制造业企业500强。
