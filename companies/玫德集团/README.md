## 公司
性质:民企 · 行业:机械/制造业

玫德集团创立于1961年，深耕流体输送领域，是全球领先的智能制造与解决方案专家。目前已发展为以流体输送产品及服务为主的现代化、多元化跨国企业集团，销售遍布全球140多个国家和地区，年营收超200亿元。目前已形成跨区域、多基地、全球化发展格局，拥有济南、临沂、泰安、威海、鹤壁、肇庆、淄博、泰国、越南、波兰10个海内外生产基地，23家数字化工厂，15个海外国家代表处（海外五大洲拟建19个海外代表处），占地3.9平方公里，员工超14000人，其中海外员工2000余人。集团是百余项国家和行业标准的起草者，国家级企业技术中心和博士后科研工作站，拥有900余项专利，100余项国家/行业标准制定权，荣获中国轻工业百强企业、中国玛钢管件生产基地龙头企业、中国绿色铸造示范企业、全国守合同重信用企业和工信部制造业单项冠军军等40余项荣誉。
