## 公司
性质:央国企 · 行业:交通/物流/仓储

深圳巴士集团股份有限公司成立于1975年，经过50年发展，成为以公共交通为主业，以新能源充电桩建设运营、旅游运输、广告传媒、场站建设、物业管理、智慧交通等业务为支撑的全牌照一体化公交产业集团。深圳巴士集团是全球最大的纯电动公交运营企业和出租车运营企业，全球城市公交电动化发展的绿色低碳典范，国际公共交通联合会（UITP）巴士委员会中国第一个执行委员，深圳市直流设备总功率排名第一的充电运营服务商。近年来，荣获“第63届国际公共交通峰会最高荣誉奖”“全国质量标杆”“全国和谐劳动关系示范企业”“全国企业管理现代化创新成果一等奖”“国务院国资委国企数字化转型优秀案例”“中国电子学会科学技术奖一等奖”等多项荣誉。
