## 公司
性质:民企 · 行业:医疗/医药/生物

浙江昂利康制药股份有限公司（股票代码：002940）是一家集医药中间体、原料药和药物制剂为一体，以心血管类、口服用头孢类、癫痫类和库痛群类药品为特色的医药上市企业。公司于2001年改制成立，2023年度跻身中国医药工业（化药企业）百强。是浙江省重点企业研究院，设有省级企业技术中心、院士专家工作站、外国专家工作站、博士后工作站等科研平台。
