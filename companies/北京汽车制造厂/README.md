## 公司
性质:央国企 · 行业:汽车制造/维修/零配件

北京汽车制造厂成立于1951年，是新中国第二家汽车企业。在73年的历史中，北京汽车制造厂总共经历了三个阶段，创造了汽车工业史上的多个第一。2020年心向未来，续写传奇，北京汽车制造厂全国重组，落户青岛，投资152亿打造青岛总部基地，同步建成发动机、车桥、车架等核心零部件工厂，是一家集越野车、轻型车、乘用车、改装车的全资质整车制造企业。
