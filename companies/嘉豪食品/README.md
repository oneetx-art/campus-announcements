## 公司
性质:外企 · 行业:快速消费品

广东嘉豪食品有限公司成立于1994年，是一家集研发、生产、销售为一体的中餐调味品企业，2018年9月被华宝国际全资收购，成为了华宝国际旗下的全资子公司之一。公司拥有“劲霸”、“嘉豪”、“詹王”、“金蝉”、“三番”、“凉拌大师”六个品牌，主要品类包括：芥辣、鸡汁、鸡精、鸡粉、肉汁、果浆、调味汁等，销售网络遍布全国，核心品牌“劲霸”，是调味品餐饮渠道的强势品牌。劲霸鸡汁、劲霸青芥辣等已经成为业内知名的产品，拥有很高的美誉度，备受中国千万厨师群体的信赖和认可。公司是《芥末酱》、《牛肉汁调味料》国家行业标准准一起草单位，是《鸡汁调味料》行业标准起草单位，拥有多项核心发明专利，并与江南大学建立产学研合作关系，并成立“东方风味研究中心”。
