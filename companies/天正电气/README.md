## 公司
性质:民企 · 行业:机械/制造业

天正始创于1990年，精耕行业30余年，于2020年主板上市，是国内低压电气行业龙头企业。天正荣获国家科技进步奖、国家卓越级智能工厂、国家级绿色工厂、浙江省未来工厂等荣誉。天正拥有研究院认定企业技术中心、CNAS实验室、省级重点企业研究院、博士后工作站等科研载体，产品覆盖配电电器、终端电器、控制电器等领域，为新能源、电力、通讯、建筑等行业提供高品质的产品和解决方案。
