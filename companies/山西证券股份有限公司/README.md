## 公司
性质:央国企 · 行业:金融业

山西证券股份有限公司成立于1988年，是全国首批证券公司之一，属国有控股性质。经过三十多年的发展，已成为作风稳健、经营稳定、管理规范、业绩良好的证券公司。经营范围基本涵盖了所有的证券领域，分布于财富管理、企业金融、资产管理、FICC、权益、国际业务等板块。设有分公司21家，营业部97家，期货营业网点22家，遍布全国各地，形成了以国内主要城市为前沿，重点城市为中心，覆盖山西、面向全国的业务发展框架，为300余万客户提供全面、优质、专业的综合金融服务。
