## 公司
性质:民企 · 行业:通信/电子/半导体

维泛智能成立于2025年5月，孵化自北京大学类脑芯片实验室，是国内首家专注原生机器人大小脑融合一体芯片研发的硬科技企业，聚焦具身智能国产化核心算力攻关，已获得数亿元重轮种子轮融资，获得多家国家级地方产业基金及产业链头部企业联合投资认可。公司现有团队超百人，核心团队深耕半导体与AI领域多年，骨干成员均来自IBM、华为、腾讯等行业龙头企业，拥有二十余年高端芯片架构研发经验，技术团队兼具类脑计算与通用芯片设计双重积累。公司自主打造BiGPU类脑启发式融合架构，构建适配机器人的全国产化大小脑全栈计算技术体系，统一软硬件指令集与开发工具链，兼顾超高算力、超低功耗与主流AI生态兼容性，破解人形与具身机器人算力、能效、成本难以兼顾的行业痛点。产品方案可全面适配人形机器人、移动机器人、工业机器人、无人机等多类智能装备，为科研研发、工业制造、商业服务、特种作业等场景提供底层核心算力支撑
