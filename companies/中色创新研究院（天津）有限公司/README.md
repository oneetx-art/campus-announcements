## 公司
性质:央国企 · 行业:能源/化工/环保

中色创新研究院（天津）有限公司是中国有色矿业集团有限公司在国家加快实施创新驱动发展战略的大背景下，深入贯彻落实习近平总书记对中国有色集团三次重要指示批示精神，全面落实京津冀协同发展战略，围绕国务院国资委“9+6”战略布局，深入实施以科技创新为引领的“1+4”发展战略，面向国家重大战略需求和有色金属产业现实而建设的专业特色鲜明、研究领域聚焦的首个集中创新研发机构，也是中央企业在天津建设成立的第一家集团创新型研究机构。
