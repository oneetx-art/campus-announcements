## 公司
性质:事业单位 · 行业:教育/培训/科研

深圳先进光源研究院是深圳市委市政府贯彻落实“双区驱动”和创新驱动发展国家重大战略、支撑大湾区综合性国家科学中心建设的公益性科研事业单位，面向国民经济主战场和世界科技前沿，承担“世界一流、深圳特色”的标志性、稀缺性先进光源等重大科研基础设施和重大科研平台的建设运营任务。研究院位于大湾区综合性国家科学中心核心承载区的光明科学城大科学装置集群核心区内，实验室及装置总建筑面积超过35万平方米。研究院下设加速器技术中心、超导低温技术中心、超快激光技术中心、光束线技术中心、物质科学研究中心、通用技术中心、建安工程技术中心、科学仪器工程中心等8大技术中心，以先进光源装置建设为核心目标任务，围绕关键技术突破，培育科技创新能力，开展技术转化和产业化研究，实现重大科技基础设施“沿途下蛋”，满足国家重大需求、实现颠覆性技术突破、解决产业核心技术难题。
