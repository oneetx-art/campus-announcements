## 公司
性质:民企 · 行业:咨询

恒诚信集团始创于2000年，是国内造价咨询与财务审计领域的标杆型综合性企业集团。造价咨询多年稳居全国行业前十、电力行业首位，并连续获评全国AAA级重点信用企业；会计师事务所亦位列全国百强。集团下设北京恒诚信工程咨询有限公司、北京恒诚信会计师事务所（特殊普通合伙）、恒诚信国际工程咨询有限公司三家独立法人公司，实行集团化管理模式。业务覆盖全过程造价咨询、工程项目管理、工程监理、工程设计、招标代理、会计审计、财务咨询等全产业链。集团在北京、上海、天津、济南、海南、成都、深圳等核心城市布局30余家分公司，汇聚1300余名行业精英，项目足迹遍布全国并拓展至海外。
