## 公司
性质:合资 · 行业:汽车制造/维修/零配件

上汽通用汽车有限公司成立于1997年6月12日，由上海汽车集团股份有限公司、通用汽车公司共同出资组建而成。历经多年发展，公司已构建起以浦东金桥、烟台东岳、武汉分公司为核心的生产基地布局，以泛亚汽车技术中心、安徽广德等试验基地为支柱的本土研发体系，具备从燃油车到新能源汽车的完整定义、开发和试验能力。旗下别克、雪佛兰、凯迪拉克三品牌产品矩阵全面覆盖从高端豪华到经济型的各梯度市场。
