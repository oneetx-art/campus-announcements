## 公司
性质:央国企 · 行业:机械/制造业

北京电力设备总厂有限公司（BPEG），隶属于中国能源建设集团有限公司，始建于1952年，是电力行业骨干设备制造商，国有大型一类企业，地跨北京、河北、新疆等地，本部设在北京市房山区良乡。公司以“服务电力，造福职工”为企业理念，始终致力于打造研发、设计、制造、服务一体化的国际能源装备公司，快速发展新型电力系统的关键设备（电力电子方向、智慧能源设备等高灵活性智能装备，强力发展特高压电网装备、电厂灵活性改造服务，稳步发展大型电站辅机设备、工程总承包服务、备品配件与检修维护服务，形成了“发电、电网、智慧城市、轨道交通、冶金、建材、煤炭、化工”并举的产品格局。公司拥有领先的制造优势和突出的技术占有率，具有和一批国内自主知识产权的重大市场装备产品，产品和服务遍布国内所有省市自治区和行政特区，公司具有国内领先的制造优势和突出的技术占有率。
