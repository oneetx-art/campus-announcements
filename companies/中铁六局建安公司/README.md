## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁六局集团建筑安装工程有限公司（简称“建安公司”）于2013年12月16日正式挂牌成立，隶属于中铁六局集团有限公司，拥有房屋建筑工程总承包特级和钢结构工程、钢构工程设计甲级资质，是一支以房屋建筑、钢构吊装加工安装、机电安装和装饰装修工程为主的专业化施工企业。建安公司先后荣获鲁班奖2项，中国土木工程詹天佑奖2项，全国市政金杯1项，全国优秀绿色施工2项，北京市政工程金杯10项，住建部获奖工程10项，省级优质工程18项，国家级新奖项11项，国家级发明专利37项，国家级工法3项和省部级工法142项，股份公司及以上奖项101项，发明专利、实用新型专利及进步奖16项，参编国家、行业地方标准达30项以上，科技进步奖6项，集团公司科技进步奖3项，多次获得全国优秀企业、中国优秀诚信企业、全国建筑业AAA级信用企业、荣登信用等级、质量信誉等级证书等荣誉称号。
