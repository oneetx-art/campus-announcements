## 公司
性质:民企 · 行业:通信/电子/半导体

槟城集团成立于1999年，是专业应用电路解决方案商，是一家专注于防雷、防静电、防静电磁等电路保护设计以及防护元器件研发、生产与销售的高新技术企业。产品包括陶瓷气体放电管（GDT）、半导体放电管（TVS）、半导体放电管（TSS）、热敏保护管（ESD）、压敏电阻（Zener）、金属氧化物压敏电阻（MOV）、复合器件（SPD）等，是通过国际环保体系认证为全球“百企”之一。
