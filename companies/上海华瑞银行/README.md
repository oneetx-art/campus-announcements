## 公司
性质:其他 · 行业:金融业

上海华瑞银行是植根上海国际金融中心的法人银行，由上海均瑶（集团）有限公司联合沪上10余家民营企业发起，2014年9月26日获原中国银监会筹建批复。2015年1月27日获开业批复，5月23日正式开业。上海华瑞银行以“立徳惟新，百年华瑞”为发展愿景，秉承“服务实体经济，服务微小大众”使命初心，坚持“聚焦普惠金融，建设独具特色的数字化智慧银行”的战略定位，致力于成为一家基业长青的百年银行。
