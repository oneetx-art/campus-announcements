## 公司
性质:央国企 · 行业:能源/化工/环保

有研粉未新材料股份有限公司（简称：有研粉材）是由中国有研科技集团有限公司控股的上市央企（股票代码：688456），专业从事有色金属粉体材料的设计、研发、生产和销售。公司业务分为四个板块，包括锡基金属粉体材料、微电子焊接材料、3D打印用粉体材料和电子浆料，产业分布在北京、安徽、重庆、山东、英国、泰国等地。
