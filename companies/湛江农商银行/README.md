## 公司
性质:其他 · 行业:金融业

湛江农村商业银行股份有限公司（简称湛江农商银行）于2019年10月30日由湛江市原麻章、赤坎、坡头、东海4家农信联社合并组建而成，是一家具有独立法人资格的总行级地方性股份制商业银行。成立以来，湛江农商银行始终坚持党建引领，坚持以人民为中心的价值取向，坚持深化改革、防范风险两条主线，坚守“相伴、相信、相成长”的使命，践行客户导向、正直诚信、稳健发展、协同成长的价值观，奋力实现成为“湛江当地的主要银行”的愿景目标。截至2025年12月31日，湛江农商银行资产规模为379.23亿元，从业人员937名，营业网点68个，服务范围遍布湛江市区所辖城乡海岛，是湛江市营业网点最多、从业人员最多、金融服务覆盖面最广的银行业金融机构，是名副其实的“湛江人自己的银行”。
