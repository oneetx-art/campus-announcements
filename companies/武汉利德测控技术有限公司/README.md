## 公司
性质:民企 · 行业:机械/制造业

武汉利德测控技术有限公司（简称“武汉利德”）成立于1993年，是国家开发投资集团旗下神州高铁技术股份有限公司（股票代码：SZ000008）的全资子公司，注册资金1.2亿元，是武汉市洪山区制造业规上企业。公司主要产品为高铁长钢轨加工成套装备、基础设施养护中型机械化智能化装备、铁路货运智能化监测装备、铁路货运计量检测监测装备、物流装备自动化及信息管理系统等，为轨道交通运营维护客户提供智能化、专业化的产品和系统解决方案。
