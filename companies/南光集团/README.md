## 公司
性质:央国企 · 行业:政府/机构/组织

南光(集团)有限公司是唯一一家总部设在澳门的国务院国资委直属中央企业。自1949年成立以来，南光集团始终坚持“用最好的回报社会”的企业宗旨，依托区位优势，抢抓市场机遇，推进改革重组，产业链不断延伸，形成了以下四大主业：公用事业与基础民生服务、文化旅游及相关技术服务、城乡建设运营、商贸物流服务。立足“十五五”，南光集团坚持“根植澳门、融入内地、拓展海外”战略布局，秉持“南光+”合作发展策略，以“服务国家、回报社会、成就员工”为战略使命，推进现代一流企业建设。
