## 公司
性质:央国企 · 行业:机械/制造业

中船九江海洋装备（集团）有限公司是中国船舶集团有限公司二级单位，是中国船舶集团“改革先行先试单位”和“机电装备产业集聚区”。公司总部设3个大部，下设中船精机（1354研究所）、中船航力、电子军工（中船消防、中船航仪）、内装事业部（江西中船）、中船航海（中船九江）5个事业部；拥有九江精达、中船精密等11个事业部下属企业及7家高技术企业，3家星级酒店，“专精特新”小巨人1家/企业，7家江西“专精特新”中小企业，1个博士后科研工作站，4个省级工程技术研究中心，7个省级企业技术中心。2022年，公司营业收入突破100亿元，利润总额超过1亿元，实现职工人均工资增长10%，荣获江西省五一劳动奖状，获评集团公司重大工程工作暨基层党建工作先进单位。
