## 公司
性质:民企 · 行业:快速消费品

开润集团创办于2005年，于2016年A股上市，也是中国箱包行业首家A股上市公司。始终坚持“让出行更美好”的使命，致力于成为受尊敬的世界级创新型消费品公司。开润积极推进全球化生产和布局，总部位于中国上海，在中国安徽、中国印度、中国台湾、日本、新加坡、越南等地均设有办事处。业务分为B2B代工制造和B2C自有品牌两个板块。在B2B业务板块，开润以先进的研发能力和出众的原创设计享誉业内，是Nike、adidas、Puma、优衣库、VFC集团、迪卡侬、惠普、Dell等全球知名运动/休闲品牌的全球TOP战略合作伙伴。在B2C业务板块，开润于2015年与小米达成合作，运营其箱包品牌，并成立自有品牌“90分”，旗下多款产品获得行业重量级奖项。开润将高效、迅速、灵活的反应能力和跨界思维较好地应用于传统制造业，同时公司持续深化供应链管理，不断革新产品设计与技术品质，探索自在出行的更多可能。
