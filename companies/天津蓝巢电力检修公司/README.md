## 公司
性质:央国企 · 行业:能源/化工/环保

天津蓝巢电力检修有限公司是中国能源建设集团天津电力建设有限公司的全资子公司，属于国有企业，通过国家及天津市高新技术企业认证。公司成立于2004年5月，注册资本金1亿元，年营业收入近30亿元，是国有电力维护检修龙头企业之一。公司以内外电力检修运营服务为主体，建立集设备安装、维护、运行检修与技术服务为一体的国际能源综合服务商。公司主营及涵盖火力发电、核能发电、水力发电、光伏发电、垃圾发电、生物质发电、电网维护、新能源等领域（运行维护）业务。同时，公司还具有承接市政、环保、港口服务等非电业务的资质与能力。
