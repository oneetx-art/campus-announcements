## 公司
性质:民企 · 行业:能源/化工/环保

佑赛科技成立于2011年，作为国家级专精特新重点“小巨人”企业，始终锚定国家“双碳”战略与能源安全新格局，以压缩空气储能和风光制复合成氨核心技术为根基，构建覆盖研发、装备、工程、运营的全产业链闭环，引领中国新型储能产业的高质量发展。公司核心成员来自清华大学，深度融合“产学研用”创新体系，在非补燃压缩空气储能、风光制氢合成氨等关键领域实现技术突破，参与建成全球首座商业化非补燃压缩空气储能电站、主导建成全球首座高寒宽滑压压缩电站及国内首个万吨级新能源制氢示范项目，以自主研制的百万千瓦级压缩电站设计建设能力，推动能源转型“卡脖子”技术国产化进程。
