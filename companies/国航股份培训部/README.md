## 公司
性质:央国企 · 行业:交通/物流/仓储

中国国际航空股份有限公司（以下简称“国航”）成立于1988年，是中国唯一载国旗飞行的航空公司、2008年北京奥运会和残奥会官方航空客运合作伙伴、2022年北京冬奥会和冬残奥会官方航空客运合作伙伴。目前国航（含控股公司）共拥有各型飞机934架和遍布全球的180个销售服务站点。国航总部位于北京，下辖西南、浙江、湖北、重庆、天津、上海、深圳、西藏、广东、贵州、内蒙古、山西、东北、大连、公务机、飞行技术等17家分公司；国航内蒙古有限公司、北京航空有限责任公司、中国国际货运航空有限公司、成都富凯飞机工程服务有限公司、国货航出港有限公司、北京航空食品有限公司等20家控股公司；以及32家境内外营业部。
