## 公司
性质:央国企 · 行业:金融业

南方电网资本控股有限公司（简称“南网资本控股公司”）是南方电网公司的全资子公司，成立于2017年4月，注册资本245亿元。作为南方电网产业金融板块重要组成部分，公司以服务主责主业为基石，为产业链上下游提供资金融通、保险保障、资产管理、投融资咨询等一站式金融服务，致力于成为支撑数字电网建设的“稳定器”、推动能源产业链整合的“加速器”、助力能源生态系统构建的“新引擎”，努力实现“源、网、荷、储”金融场景全覆盖，持续推动以融促产、产融结合。
