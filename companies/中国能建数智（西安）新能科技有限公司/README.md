## 公司
性质:央国企 · 行业:能源/化工/环保

中国能建数智（西安）新能科技有限公司（简称“数智新能”）是数科集团全资成立的新型储能数智科技投研运营企业，公司于2024年8月成立（注册资本金3亿元人民币），挂牌中能建数科西北区域总部、中能建数科智慧研究院。数智新能贯彻中国能建“创新、绿色、数智、融合”理念，作为数科集团核心新能源科技研发及投产平台，大力践行数科集团“发展新质生产力，锻造新质生产关系，培育新质资产”重要职责，开展西北区域全业务链市场营销，推进“新型储能+数智新能源”业务深耕落地。
