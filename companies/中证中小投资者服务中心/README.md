## 公司
性质:央国企 · 行业:金融业

中证中小投资者服务中心有限责任公司（CHINA SECURITIES INVESTOR SERVICES CENTER，缩写ISC，以下简称中证投服中心），是经中国证监会批准设立并直接管理的证券金融类公益机构，于2014年12月5日依法履行《证券登记结算法律法规定》的投资者保护职能，主要职责包括：面向投资者普及证券期货知识，引导理性投资；公益性持有上市公司股票，以投资者身份行使表决权、提案权、质询权等权利；对严重侵害中小投资者合法权益的行为提起代表人诉讼、支持诉讼、督促公司、行业等机构对证券、投诉服务；代投资者接受委托提供调解等纠纷解决服务；受托投资者委托，提供调解等纠纷解决服务；代表投资者向政府机构、监管部门反映诉求；运营管理中国投资者网站；开展资本市场法治与投资者保护研究；中国证监会委托的其他业务。
