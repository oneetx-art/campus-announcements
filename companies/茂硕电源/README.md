## 公司
性质:央国企 · 行业:通信/电子/半导体

茂硕电源科技股份有限公司于2012年3月16日在深圳证券交易所中小板块成功挂牌上市，成为“国内第一家以LED驱动电源为主业的上市企业”。2020年12月，济南国资入驻，茂硕电源转变为国资控股企业，在国资背景体制+民营激励机制的经营体制下，迎来新一轮的快速发展。经过十多年的发展与积累，茂硕电源连续多年在国内外市场占有率处于领先地位。与英国电信、法国萨基姆、印度Tata、欧司朗、飞利浦等多家世界500强或知名企业保持长期友好合作，客户分布在全球一百三十个国家或地区。
