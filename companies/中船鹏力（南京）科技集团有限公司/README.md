## 公司
性质:民企 · 行业:机械/制造业

中船鹏力（南京）科技集团有限公司是中国船舶集团有限公司旗下中船鹏力科技集团于1998年为能力建设、科技成果研发与公开发起设立的产业化平台。中船鹏力研究院，国家重点实验室，拥有两个研制（仿真和防务）、五个园区。产品和技术先后获得国家和省部级科研奖项，主要从事国防大型电子、机电装置的预研、研制和以军为本、民技术先进、产一体发展。产品范围包括雷达、电子对抗、信息对抗系统三大专业，重点发展智能机器人、电子与装备包装、新兴产业打造以信息技术和智能高端装备为核心的现代化战略新兴产业集团。
