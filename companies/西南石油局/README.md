## 公司
性质:央国企 · 行业:能源/化工/环保

中国石化西南石油局是中国石化集团西南石油局有限公司、中国石油化工股份有限公司西南油气分公司的统称，主要负责中国石化在四川盆地及周缘地区油气勘探开发与销售业务。公司机关设在四川省成都市，直属单位地跨四川、重庆、云南、贵州、广西等省（区、市）。现有油气勘查开采区块44个，总面积13.2万平方公里（含致密区块），资源量1万亿立方米，是四川盆地天然气勘探开发的主力军。
