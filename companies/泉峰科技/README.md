## 公司
性质:民企 · 行业:机械/制造业

南京泉峰科技（Chervon）有限公司（股票代码：2285.HK），是全球领先的专业从事电动工具和户外动力设备（OPE）及相关行业产品研发、生产、测试、销售和售后服务的整体解决方案提供商，产品销往超过100个国家。泉峰科技专注于“以用户为中心”的创新，拥有EGO、FLEX、SKIL、大有四个差异化的知名品牌，全面覆盖工业级/专业级和消费级电动工具以及高端和大众户外动力设备市场。公司总部位于江苏南京前三京，并在北美、欧洲、澳洲等海外重要市场设立分公司，目前全球雇员约10000人。
