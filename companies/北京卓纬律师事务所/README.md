## 公司
性质:民企 · 行业:咨询

北京卓纬律师事务所成立于2001年11月，是一家专注于提供商事、刑事及知识产权方面的法律解决方案的专业律师事务所。事务所总部位于北京，并在上海、深圳、海口设有办公室。目前、律师事务所拥有多名具有5年外企学习工作经历、国外名校硕士、博士等专业人员100多名，外聘专家数十位，可向客户提供全方位的高效、精准、细致的法律解决方案。
