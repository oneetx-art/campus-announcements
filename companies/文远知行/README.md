## 公司
性质:民企 · 行业:汽车制造/维修/零配件

文远知行WeRide（Nasdaq：WRD，HKEX：08000）成立于2017年，致力于以无人驾驶改变人类出行，是全球唯一旗下产品同时拥有8个国家自动驾驶牌照的科技公司，已在全球11个国家40个城市开展自动驾驶研发、测试及运营。2024年10月25日，文远知行正式在纳斯达克证券交易所挂牌上市，成为“全球通用自动驾驶第一股”，也是“全球RoboTaxi第一股”。2025年11月6日，文远知行正式在香港交易所挂牌上市，股票代码0800.HK。继在纳斯达克上市成为“全球RoboTaxi第一股”后，文远知行成为“港股RoboTaxi第一股”，也是全球首家在“美股+港股”双重主要上市的自动驾驶科技企业。
