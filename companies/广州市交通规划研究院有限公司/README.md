## 公司
性质:央国企 · 行业:房地产业/建筑业

广州市交通规划研究院有限公司（以下简称“广研”）成立于1985年，现属广州市规划和自然资源局管理，是全国第一个成立的专门从事交通规划研究的机构，也是全国城市交通研究综合实力最强的机构之一，现已成长为集交通、国土空间规划（城乡规划、土地规划）、自然资源、市政工程、测绘、水利、大数据等多专业融合的综合性设计研究机构，是广州城市发展决策的主要参谋。
