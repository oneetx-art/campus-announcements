## 公司
性质:央国企 · 行业:能源/化工/环保

中国同辐股份有限公司（以下简称中国同辐）成立于1983年，是中核集团直管的11家专业化公司之一，2011年在原中国同位素有限公司的基础上重组设立，2018年7月6日在香港联合交易所成功上市（股票代码：1763.HK）。中国同辐是国内集研发、生产、销售、服务于一体的核技术应用龙头企业，目前形成以核素、核药、辐照医疗装备、核医学整体解决方案、放射源及应用、辐照应用6大业务为核心，主业进出口贸易、其他战略性新兴产业为重点的“6+N”产业布局，和产品服务覆盖全国，并出口到世界50余个国家和地区。其中高新技术企业24家、“小巨人”企业2家、“专精特新”企业18家、24家“同辐拥有80余家成员单位，其中高新技术企业18个创新型企业。本都位于北京市海淀区，拥有员工3800余人。
