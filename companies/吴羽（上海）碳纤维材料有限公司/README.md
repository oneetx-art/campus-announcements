## 公司
性质:民企 · 行业:机械/制造业

吴羽（上海）碳纤维材料有限公司是由日本株式会社吴羽投资成立的日本股东100%独资企业，成立于2003年，注册资本1790万美元。我们是率先实现中国国内本地化生产碳纤维保温材料的公司之一。我们集团生产和销售的碳纤维产品，在全球有将近50年的销售实绩，应用领域为国家战略大硅片长晶、碳化硅、蓝宝石、光纤、热处理等高科技领域所必须的隔热材料。我们产品的原丝纯净、优越的稳定性和均一性、以及耐久性得到了客户的普遍认可，丰富的国外应用经验以及日益增长的高品质要求让我们的技术优势越发明显。
