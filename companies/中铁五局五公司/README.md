## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁五局集团第五工程有限公司是国资委管辖的中央企业—世界500强企业中国中铁股份有限公司旗下的中铁五局集团的子公司，其前身为铁道部第五工程局第五工程处，于1979年6月改制为工程局第七工程处，具有承担铁路、公路、隧道、市政、水利水电，以及路基、路面、桥梁、地铁、水工隧洞、房屋建筑工程的大型综合型建筑施工企业。
