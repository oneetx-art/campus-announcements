## 公司
性质:外企 · 行业:能源/化工/环保

梅塞尔创立于1898年，是全球最大的私营工业气体、医用气体和特种气体专家。公司以“气体创彩生活”为品牌，在亚洲、欧洲和美洲为客户提供全面的产品、技术与服务。11,800多名员工基于信任和互相尊重高效协作。2024年，梅塞尔的合并销售额达到约45亿欧元。梅塞尔1995年进入中国市场。目前，公司在中国的总投资额约17亿美元，设立了40多家企业，并在上海设立了梅塞尔亚太区总部。凭借强大的本地化网络，2,500名专业的员工以及深厚的行业专长，我们能够根据客户实际需求定制气体解决方案。在中国，梅塞尔已成为多个关键行业领先企业信赖的气体合作伙伴。
