## 公司
性质:民企 · 行业:机械/制造业

慕藤光(Mvotom Optics)成立于2011年，是一家专注于微精密场景下光学产品、光学高新技术及成像光学新产品研发生产的光学学子公司。是高新技术企业，专精特新企业。旗下产品覆盖光学镜头、工业光源、传感器、相机、图像软件、成像光学系统等精密量测、消费电子、汽车、医疗、覆盖半导体、新能源、绿能大板块，产品应用领域全方位、宽光谱等中高端设备场景，在下游、台均有可售高效、优质的光学产品。公司总部位于江苏昆山，在深圳、台北均有分支，产品服务中国、美国、德国、法国、英国、意大利、日本、韩国等多国市场，覆盖亚欧美澳。
