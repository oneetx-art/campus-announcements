## 公司
性质:民企 · 行业:医疗/医药/生物

青峰医药集团有限公司是一家集药品研发、生产与销售为一体的创新型医药企业集团，中国医药工业百强企业。公司以研发驱动为发展战略，已在上海、北京、杭州、赣州等地打造了协同高效的药物创新平台，建有高难度合成、热熔挤出、缓控释等高技术壁垒创新平台，形成了全球化、全链条的创新研发体系，在研品种近60个，多个创新药在美国开展临床研究。公司拥有完整的商业化生产体系，建有集原料药生产、中药提取、制剂生产为一体的现代生物医药产业化基地及国内独有的医药产业落地转化平台，并构建了从产品研发、生产、检验到售后的全生命周期的质量保障体系。公司产品覆盖31个省、市、自治区，抗感染、抗肿瘤、消化系统、中枢神经系统等药物在国内市场名列前茅。
