## 公司
性质:事业单位 · 行业:机械/制造业

中国科学院西安光学精密机械研究所（简称“西安光机所”）于1962年3月，为发展我国核武器，解决高速信息获取和耐辐射光学玻璃材料等问题而建，是国内外著名的高速摄影研究机构。现已发展成为以战略高技术创新与应用基础研究为主的综合性研究所。研究所是科技部认定的“国家创新人才培养示范基地”和“国家引才引智示范基地”，拥有国家重点实验室1个、中国科学院重点实验室3个，陕西省、西安市重点实验室及工程中心10个。现有博士后流动站2个、博士一级学科培养点5个、硕士点4个，现有博导83人，硕导186人，在学研究生600余人。现在职人员1200多人，中国科学院院士1人。
