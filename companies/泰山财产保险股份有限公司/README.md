## 公司
性质:央国企 · 行业:金融业

泰山财产保险股份有限公司是首家注册地在山东的全国性保险法人机构，注册资本27.03亿元，2011年1月18日挂牌开业。目前在山东、青岛、河北、江苏、内蒙古、浙江、宁波、北京、河南、陕西、山西、四川、天津、上海、深圳等省（含上海再保险运营中心），山东省内16市已实现市级机构全覆盖，下设山东泰山民间资本管理有限公司和全国性保险销售公司——泰安保险销售服务有限公司。
