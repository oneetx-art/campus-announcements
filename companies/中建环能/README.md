## 公司
性质:央国企 · 行业:机械/制造业

中建环能科技股份有限公司（300425.SZ），是隶属于中建集团的环保上市企业。公司自1999年成立以来，始终以提供优质的水环境服务、改善水环境质量为己任，致力于成为先进的环境技术与解决方案提供商。 公司秉承上善治水之理念，坚持研产销服一体化发展。在厂网河湖整体联网、城镇污水高效处理、污泥低碳稳定化发展、钢铁煤焦废水回用、离心机应用等领域，为客户提供核心工艺的技术产品和服务。公司立足以华南、华东、华北、华中、西南为核心的区域市场布局，快速响应客户需求，升华品牌的中心。 中建环能深悉生态文明的时代需求，构建开放共赢的聚作体系，在核心价值观“厚德笃行、品质保障”的指引下，聚焦绿色发展，用科技服务美好环境，追求人与自然和谐共生梦想！
