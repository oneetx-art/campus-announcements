## 公司
性质:央国企 · 行业:农林牧渔

中牧实业股份有限公司（简称“中牧股份”）成立于1998年12月25日，1999年1月7日在上海证券交易所上市，是我国最早的上市企业之一。公司业务涵盖兽用生物制品、兽用化药、饲料及饲料添加剂、畜产品贸易等领域，是我国动物保健品和动物营养品领域的重要企业。
