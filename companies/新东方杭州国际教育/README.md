## 公司
性质:民企 · 行业:教育/培训/科研

新东方国际教育培训事业部于2020年11月正式成立，是新东方教育科技集团旗下最核心的业务-新东方留学考试板块进行组织升级而来，脱胎于1993年创立的北京新东方国外考试部。为更好地适应时代的变化和教育发展趋势，更好地服务国际教育领域的学生和家长需求，新东方国际教育培训事业部的业务范畴覆盖从低龄人群、中学人群、大学人群到成人人群的全年龄段国际教育培训领域。课程产品覆盖如留学考试（雅思、托福、GRE、GMAT等）备考辅导、国际学科备考辅导、国际学科（AP、A-Level、IB等）、国际预科以及提升国际竞争力的各类英语能力提升及学科学术能力提升的课程和服务。截止2024年6月1日，我们已经在全国47个城市设立了学习中心，拥有超过4500名教师，其中在大学培训领域，每年培训覆盖人次达到10万次以上，已经帮助数以万计的学生成功实现了留学梦想。
