江苏永鼎股份有限公司（简称“永鼎股份”）成立于1978年，历经40多年稳健发展，拥有数十家控股、参股公司，现已成为核心的多产业综合性集团企业。旗下产业以通信科技、海外工程、汽车产业、超导业务所聚焦有上市公司（永鼎股份）。集团公司是中国光通信行业首家民营上市公司。
