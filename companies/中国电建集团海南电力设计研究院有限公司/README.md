## 公司
性质:央国企 · 行业:房地产业/建筑业

海南电力设计研究院（以下简称海南院）成立于1994年12月，原为海南省电力公司的直属企业。2004年，加入南方电网公司。2011年9月，电网企业进行主辅分离改革，海南院正式加入中国电力建设集团有限公司。海南院具有国家电力行业（送电工程、变电工程）专业甲级设计资质、工程咨询乙级资质、工程勘测乙级资质。现有员工160人，其中研究生以上学历36人，本科65人，大专及以下学历59人。具备高级技术资格的20人，中级技术资格的34人，初级技术资格的27人，各类注册师24人次。专业配套齐全，拥有先进勘测设计装备和印制出版装备，拥有先进的信息化技术装备和信息化管理体系。运用现代组织管理、企业标准化管理、流程管理等先进管理方法，规范管理，提升水平，技术实力雄厚。海南院主要业务范围为：发电厂设计及新能源开发、电力系统规划、咨询、设计；发、送、变电工程、电力调度通讯工程及上述配套工程的设计、咨询；工程的勘测及咨询业务；并从事资质范围内相应的建设工程总承包业务以及项目管理和相关的技术与管理业务。近几年海南院已在国内海南、广西、湖北、河北等多省开展电网业务，并在国外刚果金、刚果布、莫桑比克等多国承接电网设计任务…
