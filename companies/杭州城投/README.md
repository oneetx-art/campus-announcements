## 公司
性质:央国企 · 行业:金融业

杭州市城市建设投资集团有限公司（以下简称“杭州城投”）成立于2003年，是由杭州市政府出资，并授权经营国有资产的国有有限责任公司。经过二十余年的发展，杭州城投已发展成为一家业务范围涵盖水务、公交、能源、安居、产城、城建、置业、投资等领域的大型国有企业。
