## 公司
性质:民企 · 行业:快速消费品

东鹏饮料，上交所主板上市公司（605499），专注为消费者提供多品类饮料产品，致力于成为中国领先的饮料集团。2023年，东鹏饮料营收突破百亿，全面实施多品类发展战略，旗下拥有东鹏特饮、补水啦、东鹏大咖、果之茶、上茶系列、多喝多润、海臣娜等品牌。作为能量饮料的先行者之一，“东鹏特饮”连续四年位居中国能量饮料销量第一。目前，东鹏饮料在全国共布局13个生产基地，员工超10000名，经销商超3000家，活跃终端网点6420万家，经销网络覆盖了全国33个省级行政区、333个地级行政区。东鹏饮料始终追求商业价值与社会价值的共同繁荣，全方位落实可持续发展理念，践行低碳运营发展，同时积极履行社会责任，以“让爱更有能量”的公益理念在乡村医疗、体育教育、紧急救灾等领域以实际行动传递爱与温暖。
