## 公司
性质:央国企 · 行业:能源/化工/环保

黄委河南黄河网以40公里黄河中游干流—小浪底至小浪底工程施工区的一条流域为91.2公里，控制着黄河近92.3%的流域，黄河口至三门峡的近90%的流域。小浪底工程是黄河干流上一座集防洪、防凌、减淤、供水、灌溉、发电等为一体的大型综合性水利枢纽工程，是我国黄河上第一个由世界银行贷款、具有国际先进水平的特大型水利枢纽工程。工程于1991年开工，主体工程于1994年开工，2001年底全面竣工。主要功能是防洪、减淤、供水、灌溉、发电等，为保护黄河下游防洪安全发挥了巨大作用。小浪底工程的建成，极大地改善了黄河下游的生态环境，为黄河流域生态保护和高质量发展提供了有力支撑。
