## 公司
性质:民企 · 行业:智能硬件

村田集团于2005年6月在深圳市坪山区投资建立了深圳村田科技有限公司，目前从业人员约1600人。2010年开始，深圳村田科技有限公司连续9年列入深圳市工业百强企业。2020年，获得全国优秀外商投资企业奖项及深圳经济特区40年外资贡献奖，同时在深圳市坪山区出口创汇排名前列。
