## 公司
性质:央国企 · 行业:金融业

成方金融科技有限公司是中国人民银行立足信息科技“三集中”改革发展需要组建的软件集中开发机构，由人民银行所属单位出资，于2020年7月30日在北京注册成立，设有16个部门和成都、上海、天津3家分公司。成方金科以提升央行履职能力、引领金融科技发展、改进金融服务水平为目标，集金融科技创新、软件产品研发、系统集成服务等为一体，面向人民银行系统提供安全、可靠、高效的信息化建设服务。成方金科深度参与金融行业科技发展规划、金融科技标准制定，开展金融科技创新技术研发，全面提升人民银行科技履职能力，有效助力金融监管及金融服务水平提升。
