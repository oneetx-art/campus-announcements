## 公司
性质:央国企 · 行业:能源/化工/环保

中国有色集团（简称中国有色集团）成立于1983年，是国务院国资委直接监管的大型中央企业，拥有有色金属矿产资源勘探、采选、冶炼、加工、工程设计施工、贸易服务等完整产业链。中国有色集团作为率先“走出去”开发利用境外有色金属矿产资源的中央企业，在国内外有色金属资源开发领域作出了重要贡献，为国家有色金属安全和资产的保值增值作出了积极贡献。
