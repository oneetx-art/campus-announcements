## 公司
性质:央国企 · 行业:农林牧渔

浙江省农村发展集团有限公司（简称省农发集团）前身是1988年成立的浙江省农业投资开发公司，2005年改制为国有独资公司，成立三十多年以来，坚决贯彻落实中央及省委省政府决策部署，组建后整合省浙江粮食集团、并购黑龙江省良原集团、组建浙江省产业集团和乡投集团，自觉发挥好保障“米袋子”、丰富“菜篮子”、赋能“千万工程”与助力“共同富裕”等战略支撑作用，逐步形成种业收储保供、现代农产品流通、乡村产业运营、属性粮油业收储四大产业板块，是省属唯一一家以农粮为主业的功能性国有企业，是国家级农业龙头企业、中国服务业企业500强、浙江省服务业百强企业。
