## 公司
性质:央国企 · 行业:IT/互联网/游戏

赛尔网络有限公司成立于2000年12月，经教育部批准，负责中国教育和科研计算机网CERNET的运营。公司聚焦教育科研，服务国家战略，20多年来秉承“修己奉献，敬事创新”的核心价值观，艰苦创业，开拓创新，充分发挥CERNET网络技术优势，逐步形成了网络服务、安全服务、技术服务、产业服务和信息服务五大业务体系。公司全面参与技术教育数字化建设，积极推动网络安全服务创新，大力支持下一代互联网技术创新，在国家IPv6规模部署与产业孵化中起到了先锋示范作用，已经成为我国网信事业发展的重要力量。
