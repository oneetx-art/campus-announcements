## 公司
性质:央国企 · 行业:能源/化工/环保

中电投广西核电有限公司(以下简称“广西核电”)是国家电投集团所属二级单位，主要负责国家电投集团在桂核电项目的前期准备、建设、运营、管理工作。 白龙核电项目位于防城港市江山半岛的最南端，是国家电投集团在广西壮族自治区开发的首座核电站，是广西加快打造国家综合能源安全保障区的重大项目之一。项目规划建设2台CAP1000核电机组和4台“国和一号”机组，总装机862万千瓦，总投资约为1200亿元，一次规划、分期实施。2024年8月19日，一期工程获国家核准。
