## 公司
性质:央国企 · 行业:检测/认证

陕西卓信工程检测有限公司是中铁一局旗下从事质量检测和计量服务的专业化子公司，于2019年注册成立。前身为铁道部第一工程局中心试验室，始建于1983年。国家检验检测机构CMA资质认定、ILAC-MRA/CNAS检测和校准实验室认可资质、公路工程综合乙级质量检测机构资质、建设工程质量检测资质、水利工程检测乙级资质、专项计量授权资质和计量标准考核证书。2021-2022年，公司连续两年荣获中铁一局“优秀企业”。
