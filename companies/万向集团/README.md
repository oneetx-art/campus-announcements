## 公司
性质:民企 · 行业:汽车制造/维修/零配件

万向创立于1969年，由一家铁匠铺发展成为全球化运营的工业科技集团，入选国务院120家企业集团改革、国家创新示范基地，创中国世界名牌、获中国工业大奖，改革开放第一个产品出口、配套国际主机厂的中国汽车部件企业，新世纪以‘空气更清新’为使命，深耕清洁能源和汽车零部件制造、电池研发和应用制造，聚力攻坚锂电池、底盘、材料学、前沿研究、系统储能，科学至上建设万向创新聚能城，打造全球能源领域人才、科技的集聚地。
