## 公司
性质:事业单位 · 行业:教育/培训/科研

中国科学院空天信息创新研究院在中国科学院电子学研究所、遥感应用研究所、中国遥感卫星地面站、光电研究院的基础上整合组建，是中国科学院党组顺应党中央对科技机构改革的总要求，实施率先行动计划的重要举措。创建于1956年的电子学研究所，是我国第一个综合性电子信息科学研究所；1979年成立的遥感应用研究所，是我国遥感科技领域排头兵；1986年建成运行的中国遥感卫星地面站，填补了我国在卫星遥感技术领域的空白；成立于2003年的光电研究院，是光电工程、航天航空和应用科技等领域兼具总体管理与技术总体职能的空天单位。空天院战略定位为在空天信息领域，承担国家基础性战略性重大任务，提出并组织国家空天领域重大科技计划，建设和运行相关重大科技基础设施，解决国家在空天领域重大科技问题，获得国际领先研究成果。空天院拥有4个国家级重点实验室、1个国家工程研究中心、2个国家工程技术研究中心和1个国际研究中心，依托原有研究机构核心竞争力，聚焦国家战略需求，以重大科技成果产出为目标，已基本形成了空天信息领域高起点、大格局、全链条布局的研究方向
