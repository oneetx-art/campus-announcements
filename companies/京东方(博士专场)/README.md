## 公司
性质:央国企 · 行业:通信/电子/半导体

京东方科技集团股份有限公司（BOE）创立于1993年4月，是一家领先的物联网创新企业，为信息交互和人类健康提供智慧端口产品和专业服务，形成了以半导体显示为核心，物联网创新、传感器及解决方案、MLED、智慧医工融合发展的“1+4+N”生态链业务架构。作为全球显示领先企业，京东方始终秉持对技术的尊重和对创新的坚持，每年将营收的7%左右投入到研发中，始终保持高强度的研发投入。截至2024年，BOE累计自主专利申请超10万件。加入我们，您将与全球顶尖研发团队并肩作战，参与从基础技术研究到前沿技术应用的全方位创新，共同塑造显示与物联的未来图景。
