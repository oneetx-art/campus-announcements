## 公司
性质:民企 · 行业:金融业

泰康人寿保险有限责任公司广东分公司（简称泰康人寿广东分公司）于1998年成立于广州，属泰康人寿首批筹建分公司，也是最早进入广东市场的商业寿险公司之一。泰康人寿广东分公司下设19家中心支公司和1个电销中心，覆盖广东省所有地级市（不含深圳）。
