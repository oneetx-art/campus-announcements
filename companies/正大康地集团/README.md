## 公司
性质:外企 · 行业:农林牧渔

正大康地农牧集团有限公司创立于1979年，是泰国正大集团联合美国大陆谷物公司投资兴建的大型企业，批准证书编号为“深外资证字（1981）0001号”。正大康地以饲料、养殖、动物保健为核心业务，目前在广东、河南、重庆多地建立了十余家分子公司，饲料、动保与养殖业务全面发展。愿景和使命为中国养殖业优质高效发展提供立体解决方案的愿景...和共创共享经营者（客户、合作伙伴员工、股东、社区...）共创共享经济、社会价值，致力于推进行业可持续发展的使命，正大康地构建“营养+基因+技术支持”三位一体模式，为客户提供一体化解决方案，提高养殖效益；践行“营养免疫”理念，通过精准营养配方提升动物健康水平，从源头守护食品安全，构建绿色循环产业链，以技术创新赋能中国农牧行业。
