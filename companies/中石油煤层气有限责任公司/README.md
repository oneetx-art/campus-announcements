## 公司
性质:央国企 · 行业:能源/化工/环保

中石油煤层气有限责任公司是中国石油天然气股份有限公司独立设置的从事煤层气业务的专业化子公司，成立于2008年9月，总部位于北京市，在太原市、西安市分设2个集中办公地点，主要从事煤层气、致密气、页岩气等非常规资源的勘探、开发、生产、储运与销售，并覆盖相关工程技术服务。2022-2024三年产量规模持续换头，目前已具备煤层气年产400万吨的年生产能力，是国内最大的煤层气生产企业。
