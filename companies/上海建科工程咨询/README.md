## 公司
性质:央国企 · 行业:咨询

上海建科工程咨询有限公司是上海建科咨询集团股份有限公司（股票：603153）下属的国有企业，公司的经营业务范围涵盖全过程工程咨询、建设工程项目管理、代理建设管理、工程设计、工程监理、设备监理、招标代理、造价咨询、风险管理咨询和专项工程咨询十大类产品。公司立足上海、面向全国，探索国际，已在全国31个省市及以色列、柬埔寨等海外市场开展了咨询服务，树立了一流企业品牌。公司注重科技创新引领，承担了国家重点研发计划、上海市科委、住建委等省部级课题50多项，科技成果获得住建部华夏奖12项，上海市高新技术企业等22项，公司承接的多个项目获“上海市高新技术成果”。公司已承接10000多个工程项目，工程总投资额超过万亿元人民币，承担了许多上海市乃至国家重点工程、标志性建筑以及特大型建设工程，公司业务规模和产值连年在住建部的行业排名中名列前茅。
