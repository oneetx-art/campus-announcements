## 公司
性质:民企 · 行业:机械/制造业

山东明天机械集团股份有限公司成立于2007年，坐落于山东省济南市章丘区，是一家集科研、生产、销售为一体的专业化集团公司。公司年产值3亿元，核心国家专利30余项，员工300余人，其中教授级高工1人、博士4人、硕士10人，高级工程师11人，专业工程师60余人。集团下设山东明天机械有限公司、山东麦格莱威节能科技有限公司、山东特保罗环保节能科技有限公司和明天国际贸易（山东）有限公司。公司业务及产品涵盖罗茨鼓风机、磁悬浮鼓风机、磁悬浮压缩机，MVR蒸发器以及高难度有机废水“零排放”环保工程。荣誉称号：国家级高新技术企业及省级科技型中小企业；国家级专精特新“小巨人”企业；省、市级“专精特新”及瞪羚企业；“中国风机行业十大品牌”。
