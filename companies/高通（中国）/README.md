## 公司
性质:外企 · 行业:智能硬件

高通（中国）是美国高通公司在中国投资的载体，致力于推动中国移动通信业在技术研究、人才培养和科研成果产业化等方面的发展。在中国开展业务近30年，在北京、上海、深圳、西安、无锡和成都均设立了办公室，在北京和上海设立研发中心，并在深圳设立创新中心。
