## 公司
性质:民企 · 行业:通信/电子/半导体

昆山协鑫光电材料有限公司成立于2019年，主要从事大面积钙钛矿光伏组件的研发及量产。公司核心科研团队于2013年开始钙钛矿光伏商业化研究，在钙钛矿组件的设计、转化效率、稳定性以及量产进度等方面均领跑行业，成品率3倍于钙钛矿组件效率已突破29%，并成功通过了国际权威机构的钙钛矿老化测试，成为全球6家达成此光电转换效率的钙钛矿产业基地正式产运营。2025年8月协鑫光电GW级钙钛矿产业基地正式产运营，标志着钙钛矿光伏技术正式迈入全球商业化规模量产的新纪元。作为全球首个GW级钙钛矿光伏组件生产基地，该产线将面向全球市场推出全尺寸（1.15m×2.4m）、兼具高效率和稳定性的钙钛矿叠层组件，为实现“双碳”战略目标、构建新型能源体系贡献澎湃动能。
