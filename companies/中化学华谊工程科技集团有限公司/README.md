## 公司
性质:央国企 · 行业:能源/化工/环保

中化学华谊工程科技集团有限公司是由中国化学工程集团有限公司控股、上海华谊控股集团有限公司参股，于2023年1月成立的央企沪子公司。两大股东将自有研发工程咨询资源注入公司，致力于将公司打造成为集研发、咨询、设计、管理、建造、运维等全生命周斯一体化服务的国际一流化工行业生产性综合服务商。
