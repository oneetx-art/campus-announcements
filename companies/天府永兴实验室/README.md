## 公司
性质:事业单位 · 行业:教育/培训/科研

天府永兴实验室是四川省委、省政府布局建设的“碳中和”省级实验室，于2021年12月23日正式揭牌。现落户西部（成都）科学城。实验室瞄准国际前沿、国内领先、四川特色、低碳产业学术委员会主任，汇聚全国碳中和领域60余位院士专家学者，共同打造碳中和人才汇聚高地、科技创新先锋、产业发展引擎。
