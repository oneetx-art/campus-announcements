## 公司
性质:民企 · 行业:机械/制造业

四川普什宁江机床有限公司是五粮液集团下属子公司，始建于1965年，其前身为国营宁江机床厂，是国家级“专精特新小巨人”企业，公司长期坚持“精密、高效、成套、智能”技术产品研发定位。公司建有国家（专家）工作站、国家博士后工作站、四川省技术中心、国家一级计量单位，具有强大的开发和生产能力，是中国中小型精密机床研究设计、制造基地的骨干企业。
