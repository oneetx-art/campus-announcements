## 公司
性质:民企 · 行业:IT/互联网/游戏

小马智行（NASDAQ: PONY）成立于2016年，致力于提供安全、先进、可量产的自动驾驶技术和解决方案，实现未来交通方式的彻底变革。立足中国，着眼全球，小马智行在硅谷、北京、上海、广州、深圳、卢布尔雅那设立研发中心，并向欧洲、中东及亚洲等地拓展产品和业务布局，为全球用户和社会创造科技价值。基于世界模型™（PonyWorld）和虚拟司机™（Virtual Driver）的技术核心，小马智行打造自动驾驶出行服务（Robotaxi）、自动驾驶卡车物流（Robotruck）、技术授权与应用服务三大业务，是全球极少数实现全无人驾驶常态化运营的公司。2024年1月27日，小马智行在纳斯达克挂牌上市，创下2024年美股自动驾驶最大IPO，摘得“Robotaxi第一股”。
