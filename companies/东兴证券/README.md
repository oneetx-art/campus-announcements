## 公司
性质:央国企 · 行业:金融业

东兴证券是2008年由中国东方资产管理股份有限公司作为主要发起人发起设立的全国性综合类证券公司，于2015年在上交所上市，是境内首家资产管理系上市证券公司，总部设在北京。截至目前，在全国各地设有90余家分公司和证券营业部，拥有东兴基金、东兴投资、东兴资本、东兴证券（香港）、东兴基金5家一级全资子公司。
