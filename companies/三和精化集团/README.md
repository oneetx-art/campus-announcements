## 公司
性质:民企 · 行业:能源/化工/环保

三和精化集团是一家集科、工、贸一体化的科技集团，始创于1994年。集团以广东三和化工科技有限公司、广东三和控股有限公司、三和精化（广东）科技有限公司等多间制造型企业的产品进行灌制，并致力于气雾剂、有机硅、合成胶、润滑剂、润滑油、制动液、防水于水涂料、有機硅、合成胶、润滑剂、日化等其他产品的研发、制造和销售，旗下拥有七大专业生产基地（广东中山、广东顺德、河南濮阳）。
