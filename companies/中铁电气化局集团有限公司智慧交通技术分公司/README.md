## 公司
性质:央国企 · 行业:交通/物流/仓储

中铁电气化局集团有限公司智慧交通技术分公司（简称“智慧交通公司”）是中铁电气化局集团旗下的一家集检测检验、系统集成、产品研发、设备制造、运营维护、技术咨询为一体的高新技术企业。公司本部设在北京，现有员工400余人，下设2个分支机构，位于北京市（通信信息分公司、研究院），代管2个集面子公司，分别位于北京市（中铁电化集团北京电信研究试验中心有限公司）、陕西省西安市（中铁电化（西安）通号设备有限公司）。
