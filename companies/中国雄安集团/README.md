## 公司
性质:民企 · 行业:政府/机构/组织

中国雄安集团有限公司（以下简称“雄安集团”）成立于2017年7月18日，是经国务院批准同意，由河北省政府出资设立的省属重点骨干企业，是雄安新区开发建设的主力军和先锋队。雄安集团坚持“雄安主导、市场运作、企业管理”的原则，按照“投资、融资、开发、建设、经营”五位一体运行模式，以服务千年计、建设典范城市、创造美好生活为使命，成为具有世界眼光、国内一流的新型城市运营服务商，为现代服务业*开发建设、城市运营、战略产业投资、现代服务业* 主业，积极布局关键性资源和要素。
