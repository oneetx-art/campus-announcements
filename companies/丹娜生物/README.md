## 公司
性质:民企 · 行业:医疗/医药/生物

丹娜（天津）生物科技股份有限公司成立于2013年3月，注册资本5559万元，总部位于新生物生态城，专注于病原微生物体外诊断产品的研发、生产及销售，成为全球领先的聚焦企业。公司先后获得第一批国家支持的重点专科诊断“小巨人”企业、天津市科学技术进步奖一等奖、天津市级知识产权奖、天津市小巨人、获得国家制造业单项冠军等荣誉。
