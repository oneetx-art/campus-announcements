## 公司
性质:央国企 · 行业:机械/制造业

杭州前进齿轮箱集团股份有限公司成立于1960年，是我国专业设计、制造齿轮传动装置和粉末冶金制品的大型重点骨干企业和国家高新技术企业。2010年在上海证券交易所上市（股票代码601177），拥有全资子公司12家，控股子公司7家，参股公司4家，现有职工1500余人。产品行销全国31个省、市和自治区及55个国家、地区。公司建设有国家级企业技术中心、国家级博士后科研工作站、全省高端智能装备齿轮传动系统重点实验室、浙江省先进传动技术研究院。研发项目近年来先后荣获“国家科技进步二等奖”及“浙江省科技进步一等奖”。
