## 公司
性质:央国企 · 行业:金融业

上海外滩投资开发(集团)有限公司于2009年10月28日挂牌成立，是由黄浦区政府出资组建的国有独资企业。集团以“建设现代化国际化的外滩金融集聚带”为使命，以政府规划为指导，通过市场化手段和企业化运作，实现政府对外滩金融集聚带的战略目标和功能定位，推动外滩地区的城市更新。
