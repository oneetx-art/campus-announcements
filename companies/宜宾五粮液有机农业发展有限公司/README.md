## 公司
性质:央国企 · 行业:贸易/批发/零售

宜宾五粮液有机农业发展有限公司（以下简称“有机农业公司”）是五粮液股份公司全资子公司。有机农业公司立于2017年9月，主要负责酿酒专用粮基地设和粮食采购等业务。本基地建设任务包括核心区、示范区和辐射区粮食基地的建设、打造、维护、广告宣传、基酒产粮的收储和供给等相关业务，粮食采购业务包括酿酒专用粮的收购、存储、转运、供应、加工及销售等相关业务。2024年全面完成各项生产排推挑战，上下齐心勇争先、攻坚克难收入近50亿元，通过努力于2024年公司全年实现销售收入近50亿元。
