## 公司
性质:民企 · 行业:交通/物流/仓储

洲际船务集团控股有限公司成立于2012年，是一家综合航运服务提供商，致力于为客户提供海运运价指数保险上的一站式航运解决方案。2023年3月29日，公司成功在香港主板上市（2409.HK），成为港股全球第十大船舶管理公司，连续两年（2023和2024）首次进入全球十大管理公司排行榜，实现了历史性突破。目前，公司是中国最大、全球排名大的船舶管理公司。
