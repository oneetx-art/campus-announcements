## 公司
性质:民企 · 行业:智能硬件

朗道科技是国内领先的LPP-EUV光源制造商，专注于激光等离子体极紫外光源（LPP-EUV）的研发、生产与销售，致力于为中国半导体产业装上“中国芯”的关键引擎。团队由清华大学等高校学子实验室的研发成果为基础，聚焦半导体制造核心技术——EUV光刻光源，与工程界的高端人才团队优势快速迭代，以专业、高效、系统的研发资源，在自主研发的等离子体仿真软件助力下，以期最终实现完全可极化的新一代EUV光刻光源。
