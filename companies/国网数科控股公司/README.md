## 公司
性质:央国企 · 行业:IT/互联网/游戏

国网数字科技控股有限公司（国网雄安金融科技集团有限公司）成立于2016年，是国家电网公司的全资子公司，分别成立于2016年1月、2018年7月。作为国家电网公司战略性新兴产业单位，国网数科控股公司面向数字化、电子商务、金融科技、数字科技四大业务领域，积极推进新能源、光伏云网等平台应用，深化能源互联网数字科技创新，促进电子商务和金融科技业务的融合和全面提升，为政府、负荷侧、能源交易、上下游方面市场主体提供能源数字化、绿色数字供应链、金融科技及数字技术服务，赋能源荷电子化智能化建设。
