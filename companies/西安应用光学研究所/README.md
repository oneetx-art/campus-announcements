## 公司
性质:事业单位 · 行业:教育/培训/科研

西安应用光学研究所，创建于1962年，位于历史文化名都陕西省西安市，隶属于中国兵器工业集团有限公司，是我国唯一以光电技术和计量技术为双核的光机系统工程研究所，是集光、机、电、算、控等多学科交叉融合的应用技术研究所，光机系统集成应用技术实力雄厚，居于国际先进、国内计测领域一流，稳瞄稳像控制、目标智能识别、光学计量测试、形成了覆盖信息情报体系构建、光电系统工程设计等技术领域顶层研究的三大主业，能够面向全球客户提供光电系统解决方案。
