## 公司
性质:民企 · 行业:金融业

广东遂溪农村商业银行股份有限公司（简称“遂溪农商银行”）是一家具有独立法人资格的总行级地方性股份制商业银行，始建于1953年，前身是遂溪县农村信用合作社，2009年完成统一法人体制改革，2018年完成股份制改制。截至2025年11月末，遂溪农商银行总资产规模超180亿元，存款余额超160亿元，贷款余额超96亿元，存贷款总量位于县辖金融机构前列，现有营业网点37个，在职员工500余人，是县内网点最多、服务面最广的金融机构之一。
