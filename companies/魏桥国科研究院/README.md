## 公司
性质:社会组织 · 行业:机械/制造业

滨州魏桥国科高等技术研究院（简称“研强院”）是由世界500强企业山东魏桥创业集团与中科院大学战略合作，成立于2021年4月，位于山东的北大门、环渤海经济圈的重要城市-滨州，在新能源、生命健康、人工智能等四大科研方向布局科研力量，研究院是新型研发机构、山东省博士后创新实践基地、国家自然科学基金依托单位，作为承建单位获批滨州产才先进制造山东省实验室，成功入选山东省人才引育提升重点平台，荣获2024年度山东省人才工作表现突出单位。
