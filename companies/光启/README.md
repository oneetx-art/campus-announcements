## 公司
性质:民企 · 行业:能源/化工/环保

光启成立于2010年，致力于超材料技术的颠覆式创新，是我国新一代尖端装备的核心供应商和新一代智能装备供应商。旗下拥有上市公光启技术（002625.SZ）。自成立以来，公司持续深耕超材料技术研究，实现了从"实验室研究"推进至"产业化应用"，跨越了超材料技术由"前沿科学研究到工程化技术体系构建的鸿沟"，不仅成为我国唯一一家将超材料技术形成产品并大规模应用于尖端装备领域的科技创新企业，而且还打通了超材料从源头创新到产业应用的全链条。
