## 公司
性质:民企 · 行业:通信/电子/半导体

重庆吉芯科技有限公司是中国电子科技集团整合相关技术专业资源成立的国有控股高科技企业，是中电科芯片技术（集团）有限公司控股产业公司。公司成立于2019年6月21日，是国内领先的模数混合信号集成电路设计公司。
