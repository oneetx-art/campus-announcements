## 公司
性质:民企 · 行业:农林牧渔

桂林力源粮油食品集团有限公司始创于1953，2002年由国企改制为员工分散持股的大型民营企业，无股东持股超2%，无家族持股，员工责任共担，发展共享。目前已形成从农场到餐桌的产业链布局，业务涵盖饲料工业、畜禽育种养殖、粮油食品、生物科技四大领域。致力于成为一家“快乐的、受人尊敬的、可持续生存和发展的”企业。
