## 公司
性质:央国企 · 行业:能源/化工/环保

中国电力工程顾问集团东北电力设计院有限公司（中电工程东北院）为中国能源建设集团有限公司（以下简称“中国能建”）所属中国电力工程顾问集团有限公司（以下简称“中电工程”）的全资子企业。本院始建于1950年10月，是新中国成立后的第一个电力设计院。本院为国家大型甲级综合性工程勘察设计单位，拥有工程咨询、工程设计、工程勘察、工程总承包、项目管理（含全过程工程咨询）、新能源技术、市政与建筑工程、生态与环境工程等甲级资质，以及投资咨询、能源规划、建设工程监理、招标代理、工程造价咨询、电力行业规划、区域规划、产业规划、国际工程总承包、电力系统规划、新能源、大数据、生态与环境保护规划、信息化、直流输电、总承包管理、核电常规岛、建筑设计、岩土工程、测绘、市政（道路桥梁等）、城乡规划、北方地区供暖、东北亚跨境“南北互济”能源走廊、特高压交直流工程、电网工程、新能源工程、国际工程、市政工程、环境工程、数字化工程、绿色能源化工工程、能源规划研究中心（碳中和研究中心）、投资运营部、长春电缆管理有限公司（咨询公司）等业务板块。
