## 公司
性质:民企 · 行业:交通/物流/仓储

中谷海运集团是中国最早专业经营内贸集装箱航运的企业之一。历经多年发展，现已成为集物流、贸易、科技、金融、投资为一体的综合性现代化企业集团。集团旗下的上市公司中谷物流（603565.SH）年营业额超120亿，现已成为中国内贸集装箱行业龙头企业，运力规模排名全球第13位。公司目前业务辐射中国几十个省市百余座港口，下设200余家分公司及办事处遍及中国各地，运营船舶近100艘，业务量占中国市场份额超过四分之一，员工超过2000人。中谷获评中国物流企业50强、全国5A级物流企业、中国船东协会副会长单位等殊荣。在登陆A股主板市场之后，中谷立足构建更为完善的集装箱物流网络，通过搭建的“公、铁、水”多式联运平台，实现全程的运输门到门和运输物流方式的无缝衔接，从箱源到客户，中谷设立“提单库、一表到底、标准化运输”等创新形式。在外贸集装箱航运业务中，中谷陆续开拓了东南亚航线，真正提供更多高资质的运输选择，形成对国内集装箱物流业务的有力补充，从而为国内外客户提供更丰富的运输场景。
