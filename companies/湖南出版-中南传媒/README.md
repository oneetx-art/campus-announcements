## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

湖南出版传媒集团组建于2008年3月，2009年8月旗下中南出版传媒成为全国首批文化企业整体上市的出版龙头集团。近年来，集团按照湖南省委省政府部署，先后整合了湖南教育报刊集团等优质出版资源，努力打造主流舆论主阵地和主业突出、改革创新、集团主业为涵盖图书、报纸、期刊、音像、电子、网络、地图、IP、动漫等各媒体子户，积极拓展多元业务，努力构建全产业链、全介质、全平台的出版传媒格局。现拥有出版、印刷、发行、物资贸易、投资、地产等业务板块，图书出版在少儿、教辅等出版方面居集团第一，新书市场占有率位居全国第一。
