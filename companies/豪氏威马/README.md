## 公司
性质:外企 · 行业:机械/制造业

自1929年诞生以来，豪氏威马凭借专业技术与独特的解决方案，为船舶、海洋工程设备设计与制造领域提供了许多令全球客户满意的产品。公司总部位于荷兰，在中国、捷克、新加坡、巴西、美国、挪威均设有分支机构，豪氏威马（中国）有限公司成立于2004年，坐落于福建省福州市，是豪氏威马的重要组成部分。
