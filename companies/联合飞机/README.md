## 公司
性质:民企 · 行业:机械/制造业

联合飞机是专业从事无人机等高端装备研发、生产和服务的企业集团，工信部授予的国家级专精特新“小巨人”企业，拥有无人机全产业链研发服务能力，倾力为全球合作伙伴提供无人机装备与整体解决方案。联合飞机主持研制了中国第一架共轴无人直升机，制定了国内第一个无人直升机行业标准，研制了全球首款6吨级转旋翼无人机，获颁全国首张无人直升机型号合格证（TC），2024年入选《中国独角兽排行榜》中国航空航天领域TOP4，连续2年上榜胡润研究院《全球独角兽排行榜》。
