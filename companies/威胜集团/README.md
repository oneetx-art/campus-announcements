## 公司
性质:民企 · 行业:能源/化工/环保

威胜控股有限公司是中国领先的智能能源计量、能效管理及智慧公用事业领域的物联网解决方案提供商与运营服务商，产品涵盖电、水、气、热计量设备、电气设备及系统解决方案，集团于2005年在香港联交所主板上市，成为中国首家在该领域上市的能源计量与能效管理专业集团。业务覆盖全国所有省份，并在坦桑尼亚、巴西、墨西哥、匈牙利设有本地工厂，产品出口至全球70多个国家和地区。其核心子公司威胜集团有限公司位于长沙威胜科技园，引入了行业内首屈一指的自动化生产设备和工艺技术，采用先进的ERP、PLM、MES、WM5系统，是目前中国先进的能源计量与能效管理产品研发制造基地之一。以创新为发展引擎，威胜集团拥有实力强大的能源计量与能效管理技术研发团队，共有研发工程技术人员600余名，拥有国家认定企业技术中心、博士后科研工作站、国家示范院士专家工作站、湖南省电测仪表工程技术研究中心和企业科协等多个创新平台，是企业持续创新发展的重要动力。
