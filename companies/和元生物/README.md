## 公司
性质:民企 · 行业:医疗/医药/生物

和元生物（上海）股份有限公司（股票代码：688238）成立于2013年，是一家聚焦基因治疗领域的生物科技公司，专注于为基因治疗的基础研究提供基因治疗载体研制、基因功能研究等基因治疗药物开发，以及为基因治疗药物提供工艺开发及测试、IND-CMC药学研究、临床样品及商业化阶段GPM生产等CDMO服务。公司总部位于上海，在上海临港新片区建有精准医疗产业基地，拥有11,000平方米的综合研发及产业化基地，配备符合GMP标准的质粒、病毒载体研发及生产平台，致力于为细胞和基因治疗及相关健康产业的发展提供及时、优质、经济的CRO/CDMO服务。
