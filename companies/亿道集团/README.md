## 公司
性质:民企 · 行业:智能硬件

亿道成立于2002年，是专业从事技术转化、应用与产业化的高科技企业，专注于软件代理、移动终端、行业应用终端、物联网系统方案的创新型公司。旗下拥有亿道信息（001314.SZ）、亿道电子、次元道等多家子公司，致力于为办公、教育、商业、智能家庭、电力能源、光伏储能、交通运输及边缘计算等众多行业，提供有竞争力且安全可靠的产品、运营及解决方案。集团总部位于深圳，在东莞、苏州、西安、上海、北京、台湾等地均设有分支机构。集团目前有1500+员工，其中研发人员占比超过40%，我们的业务遍及超100个国家和地区，是1600+行业客户坚持的选择。
