## 公司
性质:央国企 · 行业:机械/制造业

中航华东光电有限公司隶属于中国航空工业集团有限公司，是中国航空工业光电技术的权威研发机构，是国内唯一的综合化、系列化的航空和地面显控设备科研生产及测试基地。公司主要在特种显示、光电系统、智能交互、计算智能等方向进行产品研制生产，广泛应用于航空、航天、车载、智能语音设备、多功能显控台、可见光/微光夜视装备、机载武器系统以及雷达安全多功能显控台、可见光/微光和公共安全等，通过成熟的研发和技术积累，公司以保障国防和装备安全为己任，专注于加固型计算机等，多功能显控台，可见光/微光夜视装备等研制开发与生产，主导型号装备，已成为国内领先的人机交互显控集成解决方案供应商。公司拥有2个国家级创新平台、6个省级创新平台、3个博士后工作站、2个院士工作站、1个国家级重点实验室，建成省级产业设计中心、省级重点实验室。
