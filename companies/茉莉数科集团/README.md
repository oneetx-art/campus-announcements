## 公司
性质:民企 · 行业:贸易/批发/零售

茉莉数科集团创办于2015年，总部位于广州，在上海、北京设有分公司，公司规模500余人，是业界领先的电商内容整合营销商业伙伴。茉莉数科秉持着以数据技术驱动理念，为品牌提供电商内容整合营销服务，包括全域社交媒体整合营销、品牌/效果营销、直播电商服务。迄今为止，已为包括阿里集团、宝洁集团、达能集团、欧莱雅集团在内的4000+品牌提供电商内容整合营销服务，成为超过60家头部集团入库供应商。茉莉数科多年来荣获多方荣誉超百项，是抖音、小红书、淘宝三大平台多牌照服务商，拥有10项国家专利认证、113项计算机软件著作权和3项版权登记，被评为「广东省高新技术企业」、「广东省专精特新企业」。2025年，“茉莉花生”大模型通过国家大模型和算法备案，并荣获「广州海珠AI五小虎」的美称。
