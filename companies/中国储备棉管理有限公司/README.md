中国储备棉管理有限公司（简称“中储棉公司”），是中国储备粮管理集团有限公司的二级子公司，具体负责国家储备棉的经营管理，实行自主经营、统一核算、自负盈亏。成立以来，中储棉公司认真执行国家棉花政策，不断提高企业经营管理水平和经营效益，认真落实国家对棉花市场的各项任务，确保国家储备棉存储安全，质量良好，调运通畅，促进国有资产的保值增值，完成国家宏观调控任务。已成为在国内、国际棉花领域具有较强影响力的企业之一。
