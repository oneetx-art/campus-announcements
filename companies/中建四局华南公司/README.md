## 公司
性质:央国企 · 行业:房地产业/建筑业

中建四局华南建设有限公司成立于1997年，是“中国建筑第四工程局有限公司”旗下的驻粤法人机构。2019年，在广州市黄埔区注册成为独立法人机构。深耕南粤区，开启新征程。公司现有员工1800余人，下设佛山、广州、总承包、基础设施、装饰园林、机电6家分公司、总承包5年在中建四局二级单位机电头羊评级，是国家高新技术企业，广东省建筑业龙头骨干企业，获国家优质工程奖、鲁班奖、詹天佑奖、国家及省部级文明工地奖、中央企业先进集体、全国工程职工小家、广东省五一劳动奖状等省部级以上荣誉70余项。为职工发展提供平台保障。
