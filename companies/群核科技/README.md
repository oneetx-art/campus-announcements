## 公司
性质:民企 · 行业:IT/互联网/游戏

群核科技于2011年成立，致力于成为全球领先的空间智能服务提供商，加速推动人工智能进入物理世界。公司构建了“空间编辑工具-空间数据-空间大模型”的业务飞轮，技术产品广泛应用于3D空间设计、电商3D AI设计、工业数字孪生、智能体训练等场景。公司产品覆盖全球200多个国家和地区，拥有全球最大的空间设计平台。依托于海量结构化空间数据，公司自主研发百亿级参数的多模态空间大模型，并向全球开源了空间语言模型SpatialLM和空间生成模型SpatialGen。
