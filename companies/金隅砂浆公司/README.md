## 公司
性质:央国企 · 行业:房地产业/建筑业

北京金隅砂浆有限公司隶属于北京金隅新型建材产业化集团有限公司，是金隅集团在新型建材产业链中的重要一环。金隅砂浆公司始于1982年，于2012年8月，由北京建筑材料科学研究总院分立而成，在预拌砂浆专业领域拥有40年技术积累，公司从事绿色新型建材—预拌砂浆的研发、生产、销售，是中国预拌砂浆行业技术依托单位。现已拥有北京房山、北京平谷，天津静海，河北唐山、河北承德、河北邯郸、陕西咸阳、山东淄博等8个生产经营基地。金隅砂浆公司生产8大系列、200余种产品，是涵盖瓷砖铺贴、内墙粉刷、地面找平、建筑保温、普通砂浆、市政地铁轨道、民用家装及EVA领域的绿色砂浆系统集成供应商，可为客户量身定制系统解决方案和专业化增值服务，产品品类、生产规模、产销量位居全国行业领先地位。
