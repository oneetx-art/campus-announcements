## 公司
性质:民企 · 行业:通信/电子/半导体

西安紫光国芯半导体股份有限公司（简称紫光国芯）成立于2006年，前身可追溯至2004年德国英飞凌西安研发中心，现为新紫光集团旗下核心企业。公司是一家以DRAM存储技术为核心的综合性集成电路设计企业，主营业务包括晶圆产品、存储芯片产品、模组及系统产品研发制造，以及集成电路设计服务。公司是国家高新技术企业、国家企业技术中心，产品广泛应用于服务器、计算机、消费电子等领域。公司于2024年6月在全国股转系统挂牌，并已启动北交所上市辅导。
