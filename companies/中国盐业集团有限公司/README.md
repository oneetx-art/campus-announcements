## 公司
性质:央国企 · 行业:能源/化工/环保

中国盐业集团有限公司创立于1950年，现为国务院国资委监管的国有大型企业，是我国盐业行业龙头企业、唯一中央企业和唯一全国性企业。中盐集团以“中盐”品牌为核心，以“创新、变革、竞争、共赢”为战略方针，以“世界一流盐化工企业集团有限公司”为战略目标，形成以盐、盐化工、农肥、盐穴综合利用为主，以及相关的生产性服务业务的“1+3+N”产业布局。盐的产销量世界第二，亚洲最大，其中食盐的产销量居世界第一。部分盐化工、农肥产品居行业前列，金属钠世界第一，纯碱全国第一、世界第二，保险粉全国第一、PVC糊树脂、烧碱、复合肥、有机氯等处于全国前十位。盐穴综合利用业务走在行业前沿，建成了国内最早的盐穴储气库群和世界首个非补燃压缩空气储能电站。
