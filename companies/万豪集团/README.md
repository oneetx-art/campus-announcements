## 公司
性质:民企 · 行业:农林牧渔

万豪集团是中国领先的农业科技创新企业，专注于植保产品与作物解决方案的研发、生产和全球运营。集团以原药、制剂、新型肥料为核心业务，致力于通过可持续农业科技保障全球粮食安全。集团战略布局四大现代化生产基地，分布于山东、江西等产业核心区，总设计面积1300余亩。百余条智能化生产流水线，具备万吨级高端原药产能100万吨，覆盖千余种植保产品，服务全球126个国家和地区，累计守护耕地超15亿亩。
