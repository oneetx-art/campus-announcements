## 公司
性质:事业单位 · 行业:法律

浙江震瓯律师事务所创建于1998年，2023年7月乔迁新址，总所位于温州市鹿城区益民路2号尚锦商厦（瓯越中央法务区）2幢6、5、4-1层，文成设有分所。秉承“专注、信赖、品质、高效”的服务理念，以法为本，以道为常，崇法尚德，敬业笃行。所内现有执业律师、实习律师、行政管理人员180余人，办公面积达4000余平方米。经过二十多年砥砺前行，震瓯所荣获全国公共法律服务工作先进集体、浙江省优秀律师事务所、浙江省著名律师事务所、全省律师行业党建工作模范所、全省律师行业抗疫先进集体、浙江省青年文明号、全省律师行业党建工作模范所等诸多荣誉，并连续十二年荣获“温州市十强律师事务所”称号、连续六年荣膺鹿城区“百强企业”称号、连续四年荣获鹿城区“服务业20强”称号。所内优秀律师云集，精英众多，不乏全国优秀律师，全国优秀仲裁员，多名律师被评为浙江省优秀律师，温州市优秀律师，温州市十佳律师，温州市青年律师之星等。
