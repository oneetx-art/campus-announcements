## 公司
性质:民企 · 行业:能源/化工/环保

四川中宏瑞石油机械工程有限公司位于四川省广汉市高新区，是一家服务于石油工程行业的集、产、研、销及现场工程服务于一体的“专精特新”型高新技术企业。公司研发生产的：石油钻井、高端磨套洗工具、打捞工具、钻井提速工具，内防喷工具以及套管清洁工具等，已经进入东南亚及中东地区，成为第一家为中东国家级油井提供设备、技术及一体式解决方案的中国民营企业。
