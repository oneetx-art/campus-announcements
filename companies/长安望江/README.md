## 公司
性质:央国企 · 行业:机械/制造业

重庆长安望江工业集团有限公司是大型军工企业，于2020年由重庆长安工业（集团）有限责任公司和重庆望江工业有限公司战略整合而成。公司最早可追溯至1862年，是我国最早的兵工企业。在军转民过程中，曾孕育出长安汽车、长安民生物流等知名上市企业。公司生产的特种产品参加了国庆50周年阅兵、60周年国庆、抗日战争暨世界反法西斯战争胜利70周年、80周年阅兵和人民的检阅。
