## 公司
性质:民企 · 行业:新能源

凯金新能源成立于2012年，作为全球负极材料头部企业，公司研发于生产和储备，主要产品包括高性能人造石墨负极、天然石墨负极、硅碳负极、复合负极等，产品广泛应用于动力、储能、3C数码等领域，是全球第一家在港股‘人造石墨负极材料行业第一’，亦是世界第一‘电池厂’有‘宁德时代’的负极材料头部供应商，并保持持续的快速发展。2022年，公司营收已超50亿元，带领行业共上高速路。在国内，公司有五大生产子，东莞松山湖总部，公司打造的‘凯金’品牌正极位于广东、山东及安徽的五大生产基地，在全国拥有500+、研发110+，先后被评为国家高新技术企业、国家专精特新‘小巨人’企业，并荣获中国专利优秀奖。
