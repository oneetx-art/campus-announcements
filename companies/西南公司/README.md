## 公司
性质:央国企 · 行业:房地产业/建筑业

中建新疆建工（集团）有限公司西南分公司成立于2011年，总部位于四川成都，是世界500强企业16位“中国建筑”的三级单位，是中建新疆建工集团优化区域布局，大力实施“东进西出”战略而设立的区域公司。公司现有职工800余人，下辖4家二级经营单位，经过10余年的发展，20多个城市覆盖，在西南、西北、华中、华东、华南、华北等业务拓展区域，在基建、新能源等领域构筑了核心优势。
