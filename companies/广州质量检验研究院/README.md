## 公司
性质:事业单位 · 行业:检测/认证

广州质量检验研究院是广州市市场监督管理局直属公益二类事业单位，始建于1951年10月，是国内最早成立的综合性政府检验检测机构。全院布局6座现代化实验基地，拥有各类高端检测设备，检测能力具备国内领先、国际一流水平，业务覆盖棉花纤维、医疗器械、化妆品、新能源、人工智能等多领域，承担各类产品质量安全检验检测、技术研发、风险评估等专业工作
