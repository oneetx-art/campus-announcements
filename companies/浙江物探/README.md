## 公司
性质:央国企 · 行业:房地产业/建筑业

浙江省工程物探勘察设计院有限公司（简称：浙江物探）位于杭州西子湖畔，成立于1994年，2022年地勘事业单位改革时承接了浙江省地球物理化学勘查院非事业职能、人员和资产等，成为浙江省自然资源集团有限公司一级子公司。公司秉承“自力更生、自主发展、自信果敢、自强不息”的企业精神，服务于城建、交通、水利、铁路、能源、生态环保、地理信息、防灾减灾等领域，完成国家、省级重点工程建设项目千余项，其他工程建设项目十余万项，获得“国家优质工程奖”等百余项荣誉。
