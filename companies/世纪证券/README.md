## 公司
性质:央国企 · 行业:金融业

世纪证券有限责任公司（以下简称“世纪证券”或“公司”）成立于1990年（原名江西证券公司），是新中国第一批成立的证券公司，全牌照证券公司，注册资本50亿元。公司总部设在深圳。证券主营业务涵盖财富管理、资产管理、投资银行、投资资易四大业务板块。公司以客户为中心，为企业集团、个人投资者、专业投资者、金融金融机构及政府部门提供资本市场为核心的全周期综合金融服务。
