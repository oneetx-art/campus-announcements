## 公司
性质:民企 · 行业:快速消费品

丹夫食品有限公司成立于2005年，是集高端烘焙美食研发、生产和销售为一体的专业化食品企业。设有福建漳州、山东济南两大生产基地，年产值数亿元，是国内华夫品类两大的创行者，引领华夫行业的发展。丹夫食品先后获得“国家金砖会议食材供应企业”、“福建省名牌产品”、“福建省著名商标”等荣誉。
