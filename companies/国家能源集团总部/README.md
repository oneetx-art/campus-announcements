## 公司
性质:央国企 · 行业:能源/化工/环保

国家能源集团于2017年11月28日正式挂牌，是经党中央、国务院批准，由中国国电集团公司与神华集团有限责任公司联合重组而成的中央骨干能源企业，世界一流能源企业建设、创建世界一流示范企业国有资本投资公司改革、国企100企业排名92位。集团拥有煤炭、电力、化工、运输等全产业链业务，在煤炭安全绿色智能、清洁能源高效稳定、现代化工高端多元低碳、运输物流协同一体、新能源多元创新规模化发展等领域取得全球领先业绩。拥有中国神华、龙源电力等2家A+H股上市公司，国电电力、长源电力、龙源技术、英力特等4家A股上市公司，产业分布在全国31个省市区以及10多个国家和地区。
