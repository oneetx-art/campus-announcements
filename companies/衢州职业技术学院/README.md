## 公司
性质:事业单位 · 行业:教育/培训/科研

衢州职业技术学院是由衢州市人民政府主办的公办高等职业院校，设有10个教学部门，28个高职专业，在校生近7000人，教职员工540余人，高级专业技术职称教师170余人。以“尚德弘毅、知行合一”为校训，坚持“俯身贴地，提升能力，服务地方经济社会发展”办学理念。
