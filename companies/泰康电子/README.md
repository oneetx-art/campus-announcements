## 公司
性质:民企 · 行业:汽车制造/维修/零配件

泰康电子有限公司成立于1986年，是一家集研发、生产、销售于一体的汽车零部件制造企业。主要产品有汽车开关、HOD集成模块、加热垫；拥有嘉兴、温州两个生产基地以及上海一个研发中心，员工1200余人。公司研发出的方向盘离手检测传感器及控制模块填补了国内空缺，方向盘电加热控制模块和离手检测控制模块集成到方向盘开关的技术，为此领域首创。
