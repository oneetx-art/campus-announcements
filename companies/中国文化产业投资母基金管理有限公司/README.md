## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

中国文化产业投资母基金由中宣部和财政部共同发起设立，是我国文化产业唯一的综合性国家级母基金。基金于2020年11月18日在北京成立，目标规模为人民币500亿元，首期已募集资金人民币317亿元。作为基金的普通合伙人和管理人，中国文化产业投资母基金管理有限公司负责母基金运营管理和投资决策。围绕落实国家文化战略和规划积极发挥作用，以政府引导资金撬动、吸引各方资本投入，通过市场化运作、专业化管理，支持企业改制重组和并购发展，促进文化资源投向新闻信息调整、推动文化产业高质量发展。基金主要整合和向产业结构服务、媒体融合发展、数字化文化新业态等文化产业核心领域，以及与文化产业高度相关的旅游、体育等相关行业，支持电影等重点行业发展；围绕粤港澳大湾区建设、长三角一体化发展等国家重大区域发展战略，增强文化产业实体化协同发展，做强做优做大文化企业，增强文化产业实力和核心竞争力，促进形成文化产业发展新格局。
