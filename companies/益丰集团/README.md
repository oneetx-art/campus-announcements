## 公司
性质:民企 · 行业:医疗/医药/生物

益丰集团是全国大型药品零售连锁企业，中国沪市主板上市企业，市值稳居国内上市连锁药店前列，被评为中国上市公司500强企业。作为中国大健康行业的领军者，益丰集团于2001年6月创立，先后布局医药零售、医药批发、医药饮片生产销售、慢病管理、互联网医院、医疗项目投资和医疗科技开发等大健康业态。2024年营收240.62亿元，同比增长6.53%；净利润15.29亿元，同比增长8.26%。公司布局湖南、湖北、上海、江苏、江西、浙江、广东、河北、北京、天津等十省市。
