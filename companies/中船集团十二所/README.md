## 公司
性质:事业单位 · 行业:机械/制造业

中国船舶集团有限公司第十二研究所，始建于1964年，位于陕西省兴平市， 中央企业下属事业单位，船舶行业唯一的热加工工艺技术研究所，水下装备及舰船装备先进材料及工艺技术的专业研制机构，船舶动力国家工程实验室制造技术主任单位，船舶行业铸锻指导组长单位和船舶行业协会铸锻分会主任委员单位，国家高新技术企业。建立了材料研制—工艺设计—工艺仿真与数字化验证—精密成型—可确性评估等测试分析—产品开发—失效分析与精密控性评估等全流程海洋环境先进材料及工艺技术研发体系，拥有陕西省纳米材料应用技术重点实验室、先进耐磨蚀工程中心、陕西省企业技术中心等创新平台，重点发展先进轻合金壳体材料及工艺、水下高性能复合材料及工艺、船用特种材料及精密成型、海洋环境表面工程、增减材制造及修复、先进工艺装备等专业方向，致力于为社会和客户提供一流的材料、产品及服务，为我国“海、陆、空、天、电、量子”等新型装备和多个大国重器研制提供了大量的材料工艺技术支撑。
