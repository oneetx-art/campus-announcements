## 公司
性质:民企 · 行业:快速消费品

国家先进印染技术创新中心是我国纺织印染领域唯一、山东省首家国家制造业创新中心。中心采用“公司+联盟”的运营模式，有山东中康国创先进印染技术研究院有限公司，现有印染产业链上的权威高校、龙头企业及投资公司16家股东单位，业务涉及印染行业全领域，产业链覆盖90%以上；组建中国先进印染技术创新联盟，现有包括14所行业高校在内的74家联盟成员单位，覆盖印染领域70%以上国家级创新资源。
