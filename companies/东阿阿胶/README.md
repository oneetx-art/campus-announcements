## 公司
性质:央国企 · 行业:医疗/医药/生物

东阿阿胶股份有限公司（简称“东阿阿胶”）是阿胶及系列阿胶产品的生产企业，是全国规模最大的阿胶块单一品种生产企业，拥有及继承多项国家级保密工艺，产品除国内销往东南亚、欧美10多个国家，1952年建厂，1993年由国有企业改组为山东东阿阿胶厂，1996年在深交所挂牌上市，2005年，有员工4000人左右，总资产130多亿元，品牌价值406.07亿元。
