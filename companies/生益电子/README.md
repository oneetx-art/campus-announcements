## 公司
性质:民企 · 行业:通信/电子/半导体

生益电子股份有限公司成立于1985年，注册资本8.3亿元，2021年在上交所科创板上市（股票代码688183）。公司总部位于广东省东莞市，现有东莞东城、江西吉安两大制造厂区，员工规模5000余人。自成立以来，公司始终专注于高精度、高密度、高品质印制电路板的研发、生产与销售，产品广泛应用于通信设备、网络设备、工控机/服务器、汽车电子、消费电子、工业控制、医疗与航空航天等领域。从产品到客户，生益电子与众多世界顶尖企业建立了长期稳定的战略合作关系。
