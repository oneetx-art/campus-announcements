## 公司
性质:央国企 · 行业:房地产业/建筑业

水发集团成立于2009年11月，是省政府批准组建的全省骨干水利工程投融资平台，2017年9月由省水利厅划归省国资委统一监管。业务涵盖水利水务、现代农业、清洁能源等产业，资产总额1630亿元，员工近20000名，旗下拥有4家上市公司。获得山东省首家“绿色企业”认证，国内信用评级双AAA，国际信用评级联合国际A级。
