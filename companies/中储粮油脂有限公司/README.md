## 公司
性质:央国企 · 行业:交通/物流/仓储

央企背书 民族品牌 中储粮油脂有限公司（简称油脂公司）是中储粮集团旗下二级子公司，总部位于北京，注册资本50.7亿元，总资产规模超过1000亿元。公司专注油脂油料经营管理，是承担国家重大专项任务的中央企业，是中国油脂市场的重要参与者，是中国最具活力和成长性的油脂企业之一。 肩负使命 布局全国 保障国家粮食安全，维护国家粮食市场稳定，“确保中央储备粮数量真实、质量良好，确保国家急需时调得动、用得上”是中储粮人的神圣使命！我们在全国油脂油料主要产销区布局大型储备库，执行国家对油脂油料市场的宏观调控任务，维护市场稳定，维护农民利益，依托中央储备油脂油料储备资源和专业化经营能力，服务国家粮食安全战略，服务地方经济发展。 以人为本 同心共赢 我们建立了完善的薪酬福利体系、人才培养体系，员工发展设有管理通道、专业通道双通道，培养并鼓励人才发展的专业化和全面化。
