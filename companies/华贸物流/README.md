## 公司
性质:央国企 · 行业:交通/物流/仓储

港中旅华贸国际物流股份有限公司（简称“华贸物流”），成立于1984年12月14日，于2012年5月29日在上海证券交易所挂牌上市，证券代码603128.SH，是中央企业中国物流集团有限公司控股的二级子公司。华贸物流在境内主要港口和物流枢纽城市设有90余个全资、控股子公司，拥有自营车辆近千台。华贸物流网络在香港及物流枢纽城市、欧洲、东南亚、非洲等地建立了超过40个自有境外服务网点。
