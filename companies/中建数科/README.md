## 公司
性质:央国企 · 行业:IT/互联网/游戏

中建数字科技有限公司是中国建筑集团有限公司（全球最大投资建设集团）的全资子公司，成立于2022年11月，注册于北京市，注册资本6.05亿元。公司秉承“使能中国建筑，使能中国建筑业”的企业使命，以打造建筑产业互联网作为数字化转型目标，以技术平台（PaaS）、大数据平台（DaaS）和云计算平台（IaaS）为基础，以数字指挥决策项目群、产业数字化项目群、海外信息化提升项目群、IT基础设施项目群、系统建设奠基项目群和工业基础协同项目群、产业互联网载体，快速积累在建筑领域信息化建设和数字化转型经验、提升服务能力，助力中建集团及建筑行业实现更高质量发展。
