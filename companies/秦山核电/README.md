## 公司
性质:央国企 · 行业:能源/化工/环保

秦山核电是中国核电起步的地方，是中国核电的“红色根脉”和“摇篮”，位于浙江省嘉兴市海盐县。处于华东电网负荷中心地区，1985年开工建设，是我国自行设计建造、逐步全面建成的第一座大型商用核电站，2015年首座国产化核电站投运，机组装机容量达530万千瓦。截至2025年11月，秦山核电已安全运行超174堆年，累计发电量超4900亿千瓦时，相当于减排二氧化碳8亿吨，植树造林约2560个西湖景区。拥有授权专利1020项，其中3项国际标准，12项国家标准。
