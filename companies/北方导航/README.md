## 公司
性质:央国企 · 行业:机械/制造业

北方导航控制技术股份有限公司属于中国兵器工业集团公司，创建于1960年，总部位于北京亦庄经济技术开发区。公司秉承“把军工电子产品做精做强，把军民两用产业做实做深”的发展理念，是国家重点保军企业。公司以导航控制和弹药信息化技术为核心，着力提升与控制相关的“军转民核心技术”在机器人、智慧弹药、物联网与控制、智能交通等领域的产业化应用，致力于导航与控制、制导与控制、稳定系统、综合管理等相关关键技术。
