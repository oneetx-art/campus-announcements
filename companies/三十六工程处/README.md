## 公司
性质:央国企 · 行业:能源/化工/环保

中煤第三建设(集团)有限责任公司三十六工程处（简称“中煤三建三十六处”）隶属于中煤矿建集团，是从事煤矿基本建设的专业化单位。现有在建项目26个，在册职工1200余人，各类职称人员326人，掘进队伍50余支（含全国优秀等级队40余支），施工设备近2000台（套），累计建成60多对大、中型矿井，开拓巷道70余万米，在立井、岩巷等工程施工中成果显著。施工“项目国家质量奖1项、省部级煤炭优秀施工阳杯”奖9项，先后获“全国级模范职工之家”“安徽省‘安康杯’竞赛优胜单位”等称号，综合实力稳居同行业前列。
