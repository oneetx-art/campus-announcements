## 公司
性质:民企 · 行业:医疗/医药/生物

浙江华海药业股份有限公司创立于1989年，总部位于中国浙江。2003年在上交所上市（股票代码600521.SH），是一家集化学药、生物药、医药包装及贸易流通为一体，国内多强、科工贸并举的国际化企业。并且在全球拥有40多家分子公司（包括美国、德国、西班牙、印度等）。公司产品覆盖心血管类、精神障碍类、神经系统类、抗感染类等领域。现有员工9000余人，其中技术研发人员2800余人，海外高层次人才100余人，招聘人才2000余人。作为中国医药国际化先导企业，坚持以提供“品质创新”的产品与服务，实现中国医药企业国际化华丽转身。在国际高端市场，公司树立了中国制药国际化形象的典范。
