## 公司
性质:民企 · 行业:教育/培训/科研

1996年，台胞魏珍女士怀着“报效桑梓”的崇高愿望，在素有“耕读传家”美誉的浙江诸暨创办了荣怀教育。荣怀教育由浙江诸暨荣怀教育园、湖北仙桃荣怀教育园、广西贺州荣怀教育园组成，共30多所学校、幼儿园。集团办学层次从幼儿园到高中的K15，是国内规模极大、质量较优、教育现代化和国际化较高的民办教育集团。荣怀秉持“把每一个学生当成自己的孩子来培养”的办学理念，坚持“诚实、勤奋、和谐、创新”的办学思想，荣获教育部“全国民办教育先进集体”的办学理念，坚持“诚实、勤奋、和谐、创新”的办学思想，荣获教育部“全国民办教育先进集体”，中国民办教育十大品牌，全国优秀民办中小学等荣誉称号。
