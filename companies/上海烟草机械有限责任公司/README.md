## 公司
性质:央国企 · 行业:机械/制造业

上海烟草机械有限责任公司创建于1952年，是中国首批烟机生产定点企业。公司建立了集产品研发、铸造加工、热处理、金属切削、钣金加工、装配调试、维修服务、零配件供应、智能服务与技能培训为一体的生产经营管理体系，拥有世界一流的数控加工设备、精密测量仪器和素质优良的人才队伍，具备国际先进的机械加工制造能力。产品主要为中速、高速及超高速全系列烟草包装成套设备，用户遍布全国所有卷烟工业企业，在国内市场居于主导地位，并出口至多个国家和地区。
