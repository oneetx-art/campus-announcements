## 公司
性质:央国企 · 行业:房地产业/建筑业

中航勘察设计研究院有限公司是中国航空工业集团公司成员单位，始建于1952年4月，地处北京市中关村科技园区，是国家建立的首批勘察设计单位之一。70余年来，我们积极参与了新中国航空工业、核工业、航天建设、国防建设、民用建筑、海外工程和高铁等国家和地区的工程建设，形成了集“生态和高碳工程、智能规划、绿色建造、大数据与人工智能”为核心的专业优势，始终保持着国内一流的技术水平和市场竞争力。
