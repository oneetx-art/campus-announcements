## 公司
性质:民企 · 行业:机械/制造业

中发天信（四川）航空科技股份有限公司成立于2016年，是在国家启动两机专项、军民融合大背景下诞生的由北京航空航天大学校友汇同北航国家重点实验室联合发起成立的国家高科技创新型企业。公司始终坚持以轻型涡喷涡扇航空发动机的研发生产为核心，深耕专精航空动力领域，通过不断创新商业模式和拓展业务规模，业务聚焦航空动力与能源、空天智能装备制造、大型无人机商业化三个方向，已发展成为一家集科研、生产、服务于一体的综合智能装备制造与技术服务企业，致力于成为国际一流轻型航空动力制造商。公司发动机产品已装配及拟计划装配共10余款机型，拥有近200项自主知识产权。近年来，公司立足国内市场需求，战略部署全国产能基地，同步开拓海外市场和探索国际合作新模式，目前在全国运营多家控股分子公司。
