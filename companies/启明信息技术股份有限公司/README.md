## 公司
性质:央国企 · 行业:IT/互联网/游戏

启明信息技术股份有限公司（简称“启明信息”）2000年成立，于2008年在深交所挂牌上市（股票代码002232）。公司作为中国第一汽车集团有限公司（以下简称“中国一汽”）下属核心软件企业，自成立以来深度参与中国一汽数字化建设，重点打造“一汽·七星云”全价值链平台级一体化数智化转型解决方案，形成覆盖“研、产、管、供、销、服、财”全业务领域的标杆案例。持续深耕制造业数智化转型，以客户为中心，为客户提供数智化转型咨询与服务、产品及实施，致力于成为国内数智化转型最佳实践与先进管理范式引领者，为行业发展贡献力量。公司是国家技术创新示范企业，2023年纳入国务院国资委科改企业，2024年获评“国家级工业互联网平台示范企业”
