## 公司
性质:民企 · 行业:通信/电子/半导体

深圳市江元科技（集团）有限公司是一家专注于在MID、智显、笔记本电脑的PCBA及整机，汽车电子设计研发的高科技集团公司，集研发、设计、生产和销售为一体。集团总部位于有“中国硅谷”美誉之称的深圳市南山区，是全球高科技产业的重要枢纽。江元集团目前旗下拥有MID事业部、智显事业部、笔电事业部、终端产品事业部、汽车电子等多个事业部，在深圳、赣州设有研发、生产和营销基地，自建2个高科技产业园：深圳江元智造工业园（建筑面积50000多平方米）、江西赣州工业园（占地160亩），业务遍及五大洲30多个国家和地区。
