## 公司
性质:民企 · 行业:能源/化工/环保

青山实业三十多年来专事不锈钢产业，已形成了从镍矿开采、镍铁冶炼到不锈钢冶炼、不锈钢连铸坯生产及不锈钢板材、棒线材加工的全产业链布局。永青集团有限公司于2017年设立，是青山实业董事局旗下的实体型企业管理集团之一，下辖产业子公司/机构逾百家，全面负责青山海外各项目的运营管理。积极响应国家“一带一路”倡议，在新加坡、印度尼西亚、澳大利亚、印度、美国、阿根廷、津巴布韦、莫桑比克等国家完成国际化产业布局。为进一步利用矿产资源，兴建工厂提取低品位镍矿中的钴、锰、钪及在盐湖钾锂中提取锂用于研发新能源电池及智慧储能系统并高效推动在新能源全产业链布局，为人类的绿色可持续发展贡献力量。
