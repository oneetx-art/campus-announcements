## 公司
性质:事业单位 · 行业:教育/培训/科研

天隼实验室由湖南省人民政府设立，坐星城长沙开福区，是集科研攻关、技术突破与人才培养于一体的国家直属事业单位与新型研发机构。我们紧密围绕国家重大战略部署和新型科技前沿，秉承“体现国家意志、支撑国家战略、践行国家使命、彰显国家实力”的崇高宗旨，聚焦战略性、前瞻性、基础性的重大科学难题与关键技术瓶颈，开展深入探索与集中攻关。实验室构建了高效协同的科研组织体系，下设十余专项研究部门，协同发力，共同推进多项国家级重大科研项目攻关。我们正持续建设一批极具科研项目自主权的科研团队，为前沿探索与技术突破提供坚实支撑。目前，实验室已形成以一流平台、稳定经费、开放生态为核心的科研环境，并配备具有竞争力的薪酬福利与多通道晋升机制，全力吸引、培育和成就高水平科研人才。
