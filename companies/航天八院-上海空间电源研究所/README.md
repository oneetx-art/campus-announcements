## 公司
性质:事业单位 · 行业:教育/培训/科研

上海空间电源研究所，地处上海市闵行区东川园区，是国内主要空间电源系统的抓总单位，主要承担星、箭、弹、船、探测、电器及其它特殊设备电源系统、控制设备、电源产品的研究、设计、制造和试验任务以及新能源产业化孵化工作，是中国航天科技集团有限公司唯一的电源专业所，拥有空间电源全国重点实验室等多个国家级科研平台，具备完善的人才培养体系，全所现有职工1400余人，核心技术人员1000余人，硕士研究生及以上学历人员近800人；六十余年来，已为上百余颗卫星、多型号运载火箭等提供优质电源系统或单机电源产品，为我国国防现代化建设和空间电源技术进步做出了重大贡献
