## 公司
性质:民企 · 行业:交通/物流/仓储

准时达(JUSDA)是制造业物流供应链科技管理服务平台，为富士康科技集团提供端到端全程物流供应链管理。借由过去20余年为富士康建立的精益供应链管理的丰富经验向社会，协助中国制造业品牌出海。同时准时达具备制造链及分销链的整合实践经验，通过与客户在供应链领域的深度融合，为企业提供从原材料采购端到工厂制造，再到终端消费环节(C2M2C)的供应链垂直整合解决方案。准时达已经在全球拥有155个服务据点，超过250万平方米的仓储分拨面积，48个大中华物流运筹服务中心，110个海外跨境转拨营运中心以及国际海空陆2,000多条服务路线。
