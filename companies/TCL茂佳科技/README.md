## 公司
性质:民企 · 行业:智能硬件

茂佳科技（MOKA），TCL科技集团成员企业，成立于2012年，聚焦于智能电视、显示器、商显等带屏智能终端产品，集研、供、产、销为一体，是全球第一的智能电视代工企业。总部位于惠州，设有深圳销售分部，在全球拥有6大制造基地，中国惠州、中国成都、波兰、墨西哥、印度、越南。惠州潼湖基地作为世界知名智能制造基地，具备先进生产技术及超前管理理念，拥有一流自动化生产设施和先进制造工艺，年产整机超1500万台。公司高速发展，实现连续正增长，现有员工逾10000人，客户群体覆盖除南极洲外的所有大洲，已建立超150个客户的合作伙伴关系。
