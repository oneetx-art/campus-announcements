## 公司
性质:民企 · 行业:能源/化工/环保

浙江工企环保集团有限公司是浙江申联投资管理有限公司（下称“申联投资”）旗下子公司。申联投资成立于2015年，注册资金5亿，聚焦环保产业，投资领域涵盖危险废物无害化处理、固废综合利用、生态修复、环境技术服务、智慧环保平台等环保产业。申联投资具备每年约400万吨危险废物的综合处理能力，危废资质涵盖35个危废类别，包括无机危险废物、有机危险废物、液态危险废物，拥有省级工程技术研发中心、院士工作站，拥有自主知识产权的核心授权发明专利34项，拥有具有140项授权专利，其中产业化技术20多项。浙江工企环保集团有限公司总部坐落于富春江畔，注册资金5亿，从事资源再生、危险废物资源化综合利用。集团在甘肃、新疆、广东、江苏等地建有危险废物处置利用基地。
