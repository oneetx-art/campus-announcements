## 公司
性质:央国企 · 行业:金融业

大连飞创信息技术有限公司（简称飞创公司）是大连商品交易所（简称大商所）全资子公司，2005年5月成立，现有员工400余人，主要承担大商所核心信息系统建设工作。大商所是国务院批准的四家期货交易所之一，也是中国东北地区唯一一家期货交易所，同时也是国家重要金融基础设施之一。飞创公司承担着金融行业大型IT系统的研发、运维等工作，自主研发实力雄厚，正以打造国际一流金融IT企业为目标，以前沿金融IT技术研发为核心，以富有竞争力的培训、薪酬福利、激励机制为保障，吸引汇聚众多国内外知名院校的博士、硕士以及行业顶尖金融IT人才，同时拥有北京及上海两家分公司，为市场提供专业、优质的金融IT服务。
