## 公司
性质:央国企 · 行业:房地产业/建筑业

天津市轻工业设计院有限公司，隶属于天津渤海轻工投资集团有限公司，创建于1958年，是一家集工程设计、工程规划、工程管理、工程咨询及工程总承包于一体的综合性工业设计院。公司专业配置齐全、技术力量雄厚，经过多年发展，公司立足京津冀、辐射全国，专注于食品发酵、粮油加工、日用化工、塑料制品、冷链物流、民用建筑、环保工程等领域，以务实严谨的作风、精益求精的设计和优质全面的服务，成为轻工行业的重要技术支撑单位。公司拥有轻工工程、建筑工程、商物粮等领域的多项甲、乙级设计资质，具备建筑工程施工总承包二级资质，可实现从设计到施工的完整EPC总承包服务链条，实现设计与施工深度融合。
