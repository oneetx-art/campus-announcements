## 公司
性质:事业单位 · 行业:政府/机构/组织

深圳国际量子研究院是合肥国家实验室（量子信息科学）深圳基地的建设和运营载体，于2021年9月正式成立。目前全院人员规模超500人，5人入选“MIT35岁以下科技创新35人”，1人获评欧洲物理学会菲涅尔奖，研究成果多次入选“中国科学十大进展”“美国物理学会国际物理学十大进展”“中国芯片科学十大进展”等。国量院具备优质的产、学、研资源，负责组织协调粤港澳大湾区相关研究队伍，承接国家量子信息重大科技任务，打造我国量子科技核心战略力量的南方支柱。
