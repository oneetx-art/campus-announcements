## 公司
性质:民企 · 行业:机械/制造业

扬州保来得科技实业有限公司成立于1992年，是保来得（香港）工业股份有限公司与扬州威利机械有限公司合资企业。专业生产经营粉末冶金含油轴承及机械结构零件。注册资本7721.052万美元。目前公司员工1600多人，生产品涉及微电机、家用电器、电动工具、减震器、汽车发动机零件及医疗器械零件等领域。在同行业中处于领先地位。扬州保来得获得“扬州市工业百强企业”、“高新技术企业”、“营业技术中心”、”环境友好型企业“、”最佳雇主企业“等荣誉称号。公司为员工提供良好的工作环境与福利待遇。
