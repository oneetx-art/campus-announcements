## 公司
性质:央国企 · 行业:交通/物流/仓储

广西现代物流集团是以广西物资集团为基础，组建成立的自治区直属大型国有企业，至今已走过75年历程。公司聚焦物流、环保、机电三大主业，以打造广西供应链产业链安全稳定的维护者、广西生态环境保护的先锋队、广西汽车生活服务潮流的领航员、广西再生资源循环利用的主力军、广西物流职业教育的排头兵为发展定位，实施“一核两极八体系”战略，致力于打造具有较强竞争力和影响力的全国一流的综合性物流企业，积极为构建广西现代流通体系、服务实体经济发展作贡献。
