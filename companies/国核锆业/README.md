## 公司
性质:央国企 · 行业:能源/化工/环保

国核宝钛锆业股份公司（简称“国核锆业”）2007年11月26日成立，注册资本26亿元，拥有3家全资子公司。是世界500强国家电力投资集团下属核心二级单位。国核锆业立足核级锆材国产化与自主研发，长期专注于我国多种核能技术堆用锆材料设计开发、生产制造和理化性能检验，解决影响核材料研制与应用过程中“卡脖子”难题，在我国明显课成为材料可制备领域和供应链领域优势作用发挥明星，国内唯一拥有材料供应链应链稳定的重要基址。是军工核-扬波包压接业海核岛、锆全金熔炼、错加工制造先完整核级锆材产业链的核级锆材专业科技型创业业企业。
