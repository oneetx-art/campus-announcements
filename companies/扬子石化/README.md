## 公司
性质:民企 · 行业:能源/化工/环保

扬子石化是中国石化的炼化企业之一，位于南京市江北新区。公司拥有1250万吨/年炼油、80万吨/年乙烯、140万吨/年芳烃等装置，是中国重要的成品油基地、炼化一体化基地、合成材料生产基地。公司规模产量为400亿元，累计向社会贡献2.05亿吨炼油，利税超2050亿元，为国家和地方经济社会发展做出重要贡献。
