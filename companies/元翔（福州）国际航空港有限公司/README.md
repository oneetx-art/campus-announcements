## 公司
性质:央国企 · 行业:交通/物流/仓储

元翔（福州）国际航空港有限公司作为福州长乐国际机场的管理机构与经营主体，隶属于翔业集团，是深耕民航领域的国有企业。公司始终以“打造独具闽港风格与现代海丝文明、精致运营典范的海上门户枢纽机场”为发展愿景，致力于推动福州机场向“通达世界的闽港门户”迈进。目前，福州机场二外扩工程正紧锣密鼓推进，工程建成后，机场将正式迈入“双跑道”时代，保障优秀学生加入，与企业共成长、同发展。
