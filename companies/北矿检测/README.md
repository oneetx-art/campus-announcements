## 公司
性质:央国企 · 行业:能源/化工/环保

北矿检测技术股份有限公司源于1956年成立的北京矿冶研究总院分析研究室，是中央企业矿冶科技集团有限公司的二级控股子公司。是国内权威、国际知名的矿冶检验检测技术研发与服务机构。2025年11月18日在北交所上市，证券代码：920160。主营业务：从事有色金属矿产资源检验检测技术研发、技术服务及仪器研发，业务涵盖矿石及矿产品、冶炼产品、环境样品、再生资源、先进材料、选冶药剂检验检测，检验检测技术研发及标准化、技术推广、高端分析仪器研发等领域。
