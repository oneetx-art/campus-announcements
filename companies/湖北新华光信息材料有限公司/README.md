## 公司
性质:央国企 · 行业:通信/电子/半导体

湖北新华光信息材料有限公司始建于1969年，是中国兵器工业集团所属子公司，地处湖北省襄阳市高新技术产业开发区，是我国最大的光学玻璃生产企业之一。公司专注于光学玻璃材料及元件的研发和制造，是国家专精特新重点“小巨人”企业、国家知识产权示范企业、国家绿色工厂、高新技术企业。产品包括成像玻璃材料（可见光和红外）、功能玻璃材料、二次压型毛胚、非球面精密压型、红外镜头等，广泛应用于智能驾驶、机器人、光通信、智能家居、智慧安防、投影、无人机、机器视觉、半导体及国防军工等领域。
