## 公司
性质:民企 · 行业:智能硬件

未岚大陆成立于2021年，是科创板上市公司九号公司（证券代码：689009）控股子公司。未岚大陆聚焦于智能割草机器人市场，旨在将机器人和人工智能技术应用于生活场景，并引领全球园林行业的智能化变革。2021年，推出智能割草机器人产品Segway Navimow H系列，将RTK和视觉技术引入草坪场景，成为全球首款大规模落地的家用无边界割草机器人。2024年和2025年分别发布系列和X系列产品，完成从500到10000平米多类型花园的全场景覆盖。目前Segway Navimow产品在包括美国、德国、法国、英国、北欧、加拿大、新西兰、澳大利亚等超过30个国家和地区售卖，被认证为2024年销量最多的无边界割草机器人品牌。
