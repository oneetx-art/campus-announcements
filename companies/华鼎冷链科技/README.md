## 公司
性质:民企 · 行业:交通/物流/仓储

河南华鼎冷链仓配科技有限公司（简称“华鼎冷链科技”）创立于2019年，定位为“中国的Sysco”，是钢圈实业（上海）有限公司的全资子公司。依托国内领先的大数据、物联网的网技术，为客户提供高效协同的数字化冷链供应链解决方案。截至目前华鼎冷链科技在全国已经25个省级区域中心仓，仓储总面积40万㎡，干支线路网5347条，辐射全国除港澳台以外的全部省区，290个地级市、超2000个县，通过华鼎自主研发的SAAS系统，已连接连锁餐饮、冻品工厂、商贸客户等2500余家，服务餐饮终端门店200000余家。自成立以来，华鼎冷链科技先后荣获国家级服务型制造示范平台、国家供应链试点企业、全国冷链百强企业、河南省大数据产业发展示范企业、河南省高新技术企业、河南省专精特新企业、城乡高效配送试点企业等多项荣誉。
