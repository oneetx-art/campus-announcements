## 公司
性质:央国企 · 行业:房地产业/建筑业

蜀道集团是四川省交通强省建设的主力军和排头兵，是一家以公路铁路投资建设运营为主业，投资经营与交通主业相关的现代服务、交通物流、交通沿线新型城镇化建设、矿产及新材料投资、清洁能源投资等产业的国有资本投资公司。集团资产总额超1.5万亿，投资建设运营高速公路里程近13000公里，投资建设铁路里程超6700公里，有5家上市公司。
