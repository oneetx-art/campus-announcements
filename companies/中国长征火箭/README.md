## 公司
性质:央国企 · 行业:机械/制造业

中国长征火箭有限公司成立于1998年3月27日，由航天一院控股，是航天一院为响应国家创新发展战略，顺应时代和行业发展潮流、满足日益增长的商业发射需求而改组设立的商业航天公司，是航天一院宇航市场化、产业化、商业化实施主体，致力于为客户提供发射服务一体化解决方案，构建商业航天技术研发、制造发射、应用服务全产业链，立志成为国内商业航天的领跑者和世界商业航天的主要竞争者。公司总部设立在北京火箭大街，同时拥有山东固体运载火箭产业基地和海南液体运载火箭产业基地，已形成北园南海的生产格局，以及固液并举、海陆齐射、回收复用的完整产品体系。
