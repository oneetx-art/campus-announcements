## 公司
性质:民企 · 行业:能源/化工/环保

烟台正海磁性材料股份有限公司（简称：正海磁材）成立于2000年，深圳创业板上市公司（股票代码300224）。公司致力于高端稀土永磁材料及器件的研发和制造，在国内设立5大生产基地，其中福建及五龙投产并建成韩国、泰国、美国3大仓库，在日本、德国、美国、马来西亚、中国香港设立营销中心，山东省级、国家级企业技术中心、国家级工程实验室等研发技术平台。
