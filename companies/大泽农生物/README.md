## 公司
性质:民企 · 行业:农林牧渔

广东大泽农生物科技股份有限公司（简称：大泽农），成立于2014年，深耕丁酸梭菌等益生菌领域，集研发、生产、销售、检测服务于一体。业务涵盖：饲料添加剂、水产动保、生物发酵原料等。大泽农以客户价值为导向，立足大湾区，服务全国市场，为客户提供高科技生物产品和专业高效的优质服务，创造客户价值，在益生菌领域保持行业领先。拥有广州、珠海、云南、湖南、贵州等地科研生产基地，联合高校院所，创新研发饲料添加剂，获42项专利。
