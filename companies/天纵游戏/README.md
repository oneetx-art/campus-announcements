## 公司
性质:民企 · 行业:IT/互联网/游戏

天纵游戏成立于2019年，是一家专注于精品游戏的研运一体化游戏公司。已荣获'国家高新技术企业'、'省级专精特新中小企业'及'2025年中国小游戏百强企业第15名'等多项权威资质与荣誉。公司核心团队拥有深厚的研发和发行经验，成功打造了多款市场标杆产品。其中首款自研产品《幻灵修仙传》自2020年上线至今长线运营超五年，深受市场和玩家认可，累计总流水数十亿；新作《三国大冒险》表现同样亮眼，稳居微信小游戏畅销榜TOP30s。我们坚持多品类、精品化的战略布局，在国风二次元卡牌、西游题材RPG、休闲放置等方向均有重磅新品储备。
