## 公司

江苏博研院为南京市政府批准设立的新型研发机构，由南京大学专家团队协同C9高校及牛津大学香港大学等海内外顶尖院士教授科学家共建，为江苏省高等教育学会教育人工智能研究会副理事长单位、国家教育部产学合作项目牵头单位、高校校友联合平台执行主席兼AI委员会主席单位、粤港澳大湾区教育发展协会常务会长单位，博研院设“一平台、七院所、一智库”的研究与运营模式，构建智能产业生态链。博研院与国内知名高校合作建立的联合实验室旨在依托高校富有前瞻性的科研力量，结合研究院真实、丰富的业务数据和应用场景，深入合作，联手培养创新型研究人才、进行前沿性的技术创新，并加速科研成果的落地应用。
