## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

上海美术电影制片厂成立于1957年4月，是中国历史悠久、片库丰富、知识产权众多的动画企业。拥有《大闹天宫》《小蝌蚪找妈妈》《黑猫警长》《葫芦兄弟》《大耳朵图图》等在内的近500部动画片，是文化部认定的重点动漫企业。60多年来，上美影制作的二维动画、水墨动画、木偶动画、剪纸动画获得了500多项国内外奖项，形成了中国动画的两次高潮，在国际上获得了“中国学派”的美誉。
