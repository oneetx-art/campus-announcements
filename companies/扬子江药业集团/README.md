## 公司
性质:民企 · 行业:医疗/医药/生物

扬子江药业集团创建于1971年，是一家集研产销于一体的大型医药企业集团，总部位于江苏省泰州市。现有员工20000余人，旗下子公司分布泰州、北京、上海、南京、广州、成都、苏州、常州等地。主要产品中西药并举，并涉及医疗器械、大健康等领域，部分产品出口至全球40多个国家和地区。集团曾获中国民营企业500强、全国纳税500强、中国医药工业百强企业等荣誉，拥有多个国家级创新研发平台及8家国家级绿色工厂，还两次获得中国质量奖提名奖，三次获得国家科技进步二等奖，五项中药材质量标准录入《欧洲药典》。
