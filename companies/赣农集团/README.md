## 公司
性质:央国企 · 行业:农林牧渔

江西省赣农投资发展集团有限公司系江西省农业发展集团有限公司下属二级国有企业，2020年1月经江西省人民政府批复成立，由省农业农村厅直属农业场所事企分开改革划转经营性资产整合组建。2022年获评农业产业化省级龙头企业，现有全资子公司7家、控股子公司2家，在职员工314人，资产总额24.67亿元，拥有多个省级以上农业农村示范基地。集团聚力构建以农业社会化服务、农文旅融合、园林绿化景观设计施工与养护为核心的现代产业体系，致力成为江西高标准现代农业社会化服务龙头企业、全省农文旅融合价值创造典范企业、全省生态园林服务链主企业，为全面推进乡村振兴、加快农业强省建设贡献力量
