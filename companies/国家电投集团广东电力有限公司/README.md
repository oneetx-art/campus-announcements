## 公司
性质:央国企 · 行业:能源/化工/环保

国家电力投资集团有限公司是中央直接管理的特大型国有重要骨干企业，肩负保障国家能源安全的重要使命。国家电投集团广东电力有限公司（简称“广东公司”）统筹负责国家电投集团在粤资产、海上战略发展和区域统筹协调，业务涵盖气电、海上风电、陆上风电、光伏、能源消纳侧产业（含集中供冷）及市场售电、码头运营等领域，在粤港澳大湾区（横琴、深圳、东莞、肇庆、江门、粤东（揭阳、粤西（湛江、阳江）、粤外（新疆、广西）已形成产业布局。截至2025年底，广东公司管理装机规模超560万千瓦，其中气电337万千瓦，海上风电181万千瓦，陆上风电20万千瓦，光伏发电24万千瓦。冷站生产能力14万冷吨，供热能力1998吨/小时，另有揭阳前詹通用码头，年设计吞吐量324.6万吨。
