## 公司
性质:民企 · 行业:IT/互联网/游戏

北京华顺信安科技有限公司是一家以网络空间测绘技术为基础，聚焦于安全大数据和网络空间资产安全的高科技企业。通过多年累积，网络空间资产库数据量已超过100亿条，形成了独有的网络空间资产安全生态。华顺信安旗下白帽汇安全研究院，在网络空间测绘技术方面居于全球领先水平，所运营的白帽子社区拥有数万名活跃的安全工程师。研究院正在通过自主运营的FOFA、NOSEC、Vulfocus、Goby平台，向各大行业用户输出漏洞风险预警能力，帮助用户及时发现网络资产存在的安全风险。公司曾在冬奥、建党100周年等多项国家级专项活动中提供重保支持，并参与多次公安部网络攻防实战演习支持工作并斩获一致好评。公司目前已经完成C轮融资，融资规模达数亿元。
