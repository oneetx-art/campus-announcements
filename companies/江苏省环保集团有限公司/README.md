## 公司
性质:央国企 · 行业:能源/化工/环保

江苏省环保集团有限公司（简称省环保集团）是经省委省政府批准，于2019年成立的省属大型战略性环保产业集团，注册资本金人民币59.80亿元。作为全省治理工作的重要抓手，引领省市国有资本集成发展环保产业，集团着力在大气和水环境治理、土壤污染治理与修复、固废危废安全处置、生态保护修复、农村环境综合整治、工业园区环境整治、生态环境监测、环境监理运维等方面发挥作用。集团以打造国内领先国际一流的高科技环保集团为发展目标，牵头推进全省重大环境基础设施建设，积极构建企业为目标资本协同推进、各类资本积极参与的科技环保矩阵省市国目标，牵头推进全省重大环境基础设施建设，积极构建企事业产科技资本增效战，努力打造一支高素质专业化的人才队伍，加快推动集团高质量发展。
