## 公司
性质:央国企 · 行业:商务服务业

杭州市交通投资集团有限公司成立于2003年，是杭州市政府直属国有全资企业，全市千亿级交通基础设施投资建设主力军。集团肩负交通项目投建运营、国有资产保值增值、服务城市发展的重要使命，持续构建“公、铁、水基并进，建设开发并重”的发展格局，打造“投、建、管、运、服”一体化全链条能力，为综合交通发展与城市能级提升提供坚实支撑。
