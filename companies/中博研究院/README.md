## 公司
性质:民企 · 行业:IT/互联网/游戏

中博信息技术研究院有限公司成立于2001年，是中国通信服务有限公司专业子公司，注册资本10008万元，专业从事管理咨询、软件开发、运营维护、云服务、信息系统集成及培训赋能服务。公司是“江苏省高新技术企业”、“江苏省软件企业”、“江苏省软件企业技术中心”、“江苏省规划布局内重点软件企业”、“南京市工程技术中心”、“江苏省产业人才培训基地”，拥有建筑智能化专项设计甲级、安防设计施工维护能力一级等多项资质，并通过CMMI5级、ITSS一级及相关服务与质量体系认证。公司以“做服务数字化转型的软件领军企业”为愿景，致力于为客户提供“一站式”数字化解决方案，相关应用覆盖了各级政府行政管理部门、教育、金融、电力、水利、交通等多个领域，赢得了良好的行业地位和企业声誉。经过在通信信息化领域十年的历练和积累，中博研究院拥有自主知识产权的研发平台、成熟高效的研发体系以及近千人的专业人才队伍。公司聚焦“架构师+产品经理+行业经理+项目经理”为核心的数字化专业技术人才梯队建设，持续打造完善的高素质专家人才培养体系，拥有多名中国通服高级专家及专家人才。
