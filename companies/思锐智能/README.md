## 公司
性质:民企 · 行业:通信/电子/半导体

青岛思锐智能科技股份有限公司是由中国中车发起设立、股权多元、聚焦半导体核心设备的国际化高科技公司。公司总部位于青岛，并在芬兰、北京、上海设有研发中心，产品包括原子层沉积（ALD）设备及离子注入（IMP）设备，广泛应用于集成电路、第三代半导体、新能源、光学等诸多领域。2018年，公司完成了对ALD技术发源地芬兰福科公司的100%股权收购，逐步建立了完善的ALD产品体系。2023年，思锐智能首台高能离子注入机顺利交付。2024年，完成了离子注入机全系列主流机型的研发，形成了双主业发展的战略布局。目前公司业务范围覆盖全球40个国家及地区，累计超过500个全球客户，已成为拥有全球客户拓展能力的中高端半导体装备生产制造商。
