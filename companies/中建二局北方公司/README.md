## 公司
性质:央国企 · 行业:房地产业/建筑业

中建二局北方公司成立于2003年，总部设在沈阳，是中建二局6大区域公司之一，目前在辽宁、吉林、河北、山东、江苏等地设立分公司。公司年合同额超200亿元，年营业收入近100亿元，是中建集团在东北区域的骨干三级子企业，公司曾获中国建设工程鲁班奖、连续5年荣获国家优质工程奖，获评全国文明单位、全国五四红旗团委、全国抗击新冠肺炎疫情青年志愿服务先进集体，被授予全国五一劳动奖状，先后涌现全国劳动模范、全国巾帼建功标兵和全国工程建设优秀项目经理等诸多先进典型。
