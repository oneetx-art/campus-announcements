## 公司
性质:央国企 · 行业:机械/制造业

上海振华重工启东海洋工程股份有限公司（简称“振华海工”）隶属于世界500强之一中交集团旗下的上海振华重工（集团）股份有限公司。公司位于江苏省南通市启东船舶工业园区，地处长江入海口（黄海东海交界）3公里北岸，与上海崇明岛隔江相望，公司现拥有50万平方米的海工装备、船舶制造厂区，其中30万平方米重型车间；30万吨级干船坞；5万吨级舾装及500米长的专业船舶装发码头。公司坚持面向世界、聚焦制造、突出主业、专注专业，建设具有全球竞争力的世界一流装备制造企业发展目标，是国内最具规模的三大海工主业之一的海工业务，承接各型海上疏浚船舶、起重船舶、铺管铺缆船舶及特种海工船舶的设计和建造，打造了“天鲲号”“海洋石油201”“JSD6000”“航津轮”“二航长鹰”为代表的大国重器。
