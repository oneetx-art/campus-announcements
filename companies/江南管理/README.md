## 公司
性质:民企 · 行业:房地产业/建筑业

浙江江南工程管理股份有限公司成立于1985年，原为国家电子工业部直属骨干企业。肩负工程建设管理体制改革使命，是新中国工程咨询行业的先行者、探索者、领航者，连续十多年被评为国家级优秀工程咨询企业，企业综合实力位居行业前三，被住建部评为“全国工程质量安全管理优秀企业”，科技部授为“国家高新技术企业”，被国家工商行政管理总局列为“全国守合同重信用单位”，2024年荣获杭州市人民政府质量奖，为浙江省咨询行业首家获奖企业。经过40年的创新发展，江南管理已成为国内著名、领先、覆盖全产业链和多领域的工程咨询标杆企业，业务涵盖房建、市政、水利、轨道交通、能源化工、环保通信等领域，能够为客户提供全过程工程咨询、工程设计及咨询、前期策划及咨询、BIM建模及咨询、项目工程管理及代建、招标代理、造价咨询、工程监理、第三方工程评估等服务，是覆盖全产业链和多领域的工程咨询行业标杆企业。
