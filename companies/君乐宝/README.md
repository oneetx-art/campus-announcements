## 公司
性质:民企 · 行业:快速消费品

君乐宝乳业集团创立于1995年，是中国奶业领先企业之一。业务范围包括婴幼儿奶粉、酸奶、低温鲜奶、常温液态奶、奶牛育种、牧业、草业，建立起涵盖奶业全产业链的产业布局，为消费者提供营养、健康、安全的乳制品。业务布局现有生产基地：东北生产基地、华东生产基地、华北生产基地。未来生产基地：西北生产基地、云南生产基地、两湖生产基地、华南生产基地。企业愿景是成为中国营养健康食品企业领先者。
