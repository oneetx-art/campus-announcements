## 公司
性质:民企 · 行业:机械/制造业

宸微设备科技（苏州）有限公司于2022年10月成立，是一家集集成电路、电气控制、软件开发、精密制造于一体的装备类企业，公司着眼于半导体领域核心设备的国产替代，专注于先进封装工艺的装备研发与制造。南航科技（广东横琴）有限公司成立于2024年8月，是南航集团的下属企业。主营业务是研制可满足中国民航飞行员技能全生命周期管理体系要求的飞行训练设备，以及飞行安全与数据分析产品研发应用，实现模拟仿真技术在其他领域的推广应用。
