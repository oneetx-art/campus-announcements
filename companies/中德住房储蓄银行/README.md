## 公司
性质:央国企 · 行业:金融业

中德住房储蓄银行有限责任公司（以下简称“中德住房储蓄银行”）是中国建设银行的控股子公司，由中国建设银行和德国施威比豪尔住房储蓄银行共同投资组建，成立于2004年2月，注册资本20亿元。中德住房储蓄银行是一家主营住房储蓄业务的商业银行，总部设于天津，目前在天津设有和平、滨海两家支行，在重庆、大连、济南设有分行。为满足业务快速发展对高素质人员的需求，中德住房储蓄银行现面向各高等院校招聘应届毕业生。
