中车广东轨道交通车辆有限公司（以下简称“中车广东公司”）是中国中车与广东省、港铁公司的战略合作伙伴,注册资本为人民币14.1亿元.其中,中车青岛四方机车车辆股份有限公司占股45.9%,广东省铁路建设投资集团有限公司占股31.1%,中车南京浦镇车辆有限公司占股12.6%,港铁公司占股10%.中车广东公司于2010年6月挂牌成立,主要从事城际、市域等新型、低地板动车组产品研发、轨道交通车辆进出口业务.
