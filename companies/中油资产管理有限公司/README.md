## 公司
性质:央国企 · 行业:金融业

中油资产管理有限公司（以下简称“中油资产”）是中国石油天然气集团有限公司（以下简称“中国石油集团”）所属中国石油集团资本有限责任公司全资子公司，成立于2000年4月，注册资本137.25亿元。作为中国石油集团资产集中处置内部专业服务机构，中油资产始终践行资产处置阳光高效的初心使命，着力构建集实物资产、债权、股权、房地产等一体化、全方位的专业服务平台，推动业务向标准化、数字化、智能化方向发展，提升资产处置专业化服务和精益化管理水平，助力主业单位实现资产轻量化、资产结构优化的目标，确保国有资产保值增值。
