## 公司
性质:央国企 · 行业:IT/互联网/游戏

云筑是中建集团旗下，国内居于领先地位的建筑产业互联网公司，是一家从事数字化服务的国有企业，于2015年在四川成都成立。云筑以“助推建筑行业数字化”为己任，依托中建集团产业基础，为建筑行业提供“数字供应链”与“智慧用工”两大整体解决方案，助力行业降本增效和管理提升的建筑互联网平台提供商。公司成立以来，云筑获评国家级高新技术企业、中央企业互联网服务和双创平台知名品牌、国家工信部大数据产业示范项目、国家电子商务示范企业等认证及称号，拥有124项软件著作权和104项专利，并通过全球软件领域最高级别CMMI5 3.0级认证。
