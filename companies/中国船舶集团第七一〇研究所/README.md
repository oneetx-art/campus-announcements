## 公司
性质:央国企 · 行业:机械/制造业

中国船舶集团有限公司第七一〇研究所（以下简称七一〇所）1958年始建于上海，1970年迁至湖北宜昌，现位于武汉，是专业从事舰船作战系统总体、基础共性技术、保障“五位一体”国家战略需求的央企。七一〇所建有1600余人建制单位，其中博士硕士及以上800余人，拥有国家特种工程技术院士、国防科技优秀青年、湖北省“百人计划”等，致力于学科交叉融合与产学研用。七一〇所产业涵盖：装备设计、生产、管理、运维；建成三大国家级平台、重点实验室、博士后科研工作站；军工智能航行技术达国际领先；国产化技术在航母等航行器装备应用；科技成果转化超600项；获国家科技进步奖、国家技术发明奖等40项；获国家级、省部级以上奖励150余项。
