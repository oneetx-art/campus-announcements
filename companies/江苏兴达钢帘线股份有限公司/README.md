## 公司
性质:民企 · 行业:机械/制造业

江苏兴达钢帘线股份有限公司是研制、生产和销售高性能子午线轮胎增强用骨架材料钢帘线的专业化企业。经过30多年的发展，我司已成为世界轮胎骨架材料领域的行业主导成员, 拥有江苏泰州、山东东营、山东济宁与泰国春武里府四大生产基地，产品涉及子午线轮胎用钢帘线、胎圈钢丝、胶管钢丝等。目前，公司员工有8000余名，国内市场占有率35%，国际市场占有率达24%。 公司坚持科学发展，重视技术创新和管理创新工作。以国家企业技术中心、博士后科研工作站、省级重点实验室和省级工程技术研究中心等研发平台为依托，成功开发出新结构钢帘线四大类100余种，产品各项性能指标达到国际先进水平。公司是子午线轮胎用钢帘线国家标准的主持起草单位，自主研发的“子午线轮胎专用高性能新结构钢帘线生产技术”开发成果获得了国家科技进步二等奖，公司先后获得“国家高新技术企业”、“全国文明单位”、“行业首批国家级绿色工厂”、“省工业互联网标杆企业”等多项荣誉称号。 “兴达国际”2006年成功在香港上市，现公司钢帘线产量已居全球第一。现因公司业务发展需要，诚挚邀请有智之士加盟兴达公司和兴达公司共创美好明天！
