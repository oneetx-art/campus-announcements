## 公司
性质:央国企 · 行业:汽车制造/维修/零配件

福建汽车工业集团有限公司（简称“福汽集团”）是福建省属汽车工业大型国有企业，成立于1992年，是福建省汽车产业的核心国有企业（即“整车集团”），也是国内的汽车企业集团之一。旗下拥有金龙汽车、东南汽车、福建奔驰等控股参股整车企业，以及福汽启腾、云度新能源、金旅客车、金冠智能科技、蓝海物流、金新新能源、星联汽配、云内福汽等产业链上下游企业。
