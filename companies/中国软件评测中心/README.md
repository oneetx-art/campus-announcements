## 公司
性质:央国企 · 行业:IT/互联网/游戏

中国软件评测中心（工业和信息化部软件与集成电路促进中心）是中国电子信息产业发展研究院代管的事业单位，成立于1990年，是中国最早从事IT和军工领域信息化建设的第三方权威机构，承担国家软件与集成电路公共服务平台、国家机器人质量检验检测中心、智能网联驾驶测试与评价和工业信息化部重点实验室等建设，提供国家重大科技专项支撑保障，在新型工业化领域开展技术研究、检验检测、认证评估等工作。首家通过中国合格评定国家认可委员会（CNAS）认可并取得中国计量认证（CMA）的计算机硬件产品质量检测机构。
