中国软件评测中心（工业和信息化部软件与集成电路促进中心）是中国电子信息产业发展研究院院部管理的事业单位，成立于1990年。是中国最早从事IT和军工国家质量与集成电路公共服务平台的事业单位，是中国国家软件测试的第三方权威机构，承担国家质量与集成电路公共服务平台、国家机器人质量检验检测中心、智能网联车辆测试与评价工业和信息化部重点实验室等建设，提供国家重大科技专项支撑保障，在新型工业化领域开展技术研究、检验检测、认证评估等工作。
