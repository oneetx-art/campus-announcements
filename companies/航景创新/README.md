## 公司
性质:民企 · 行业:机械/制造业

北京航景创新科技有限公司是专注于大型无人直升机及eVTOL产品研发、生产制造和技术服务的国家专精特新“小巨人”企业。公司自主掌握新一代无轴承旋翼系统、多冗余飞行控制技术、先进复合材料主旋翼、航空涡轮发动机等核心技术，形成了起飞重量200-2500公斤级的产品序列，其中PWH-1500、PWH-2000-3000型大直升机处于国际先进水平。公司具备无人机整机研发生产及交付能力，在航空应急救援、运输投送、“蓝军”训练等领域成为行业风向标产品，出口东南亚、中东、非洲等国家，获得海内外客户高度认可。
