## 公司
性质:民企 · 行业:机械/制造业

万控始创于1991年，总部位于浙江省温州市乐清市，旗下拥有“万控”“默飓”等品牌，分别在浙江丽水、天津北辰、四川成都、温州滨海等地建立了现代化制造基地，员工超3000人。2022年3月登陆上交所主板上市，股票代码603070。万控主要生产高低压电气机柜，充气柜，环网柜，真空断路器等电气设备，配套应用于电厂，石化，电力控制，电网建设，轨道交通，冶金钢铁，能源工业等各领域，是电气机柜行业的技术标杆，拥有强大的科技研发能力，设有省级企业技术中心、研发中心、博士后工作站、万控-攀钢电气用钢联合实验室等科研组织，是全国电工电子设备结构综合标准化技术委员会主任委员单位。万控及旗下企业作为主要起草者和参与者单位共承担了32项国家标准的制订，拥有各类专利技术400余项，全面推动电气机柜行业产品升级换代，持续引领行业技术发展。
