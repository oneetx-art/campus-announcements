## 公司
性质:民企 · 行业:智能硬件

西安羚控电子科技有限公司（简称：羚控科技），创立于2014年，源自国内唯一的无人机领域国家级重点实验室——西北工业大学无人机特种技术国家重点实验室。是国家级高新技术企业，产品布局以西安为总部，下设公司苏州羚控及杭州羚控科技有限公司和山东羚控智能装备有限公司。羚控科技以飞机设计为核心，专注于为客户提供场景最丰富的研发设计能力和工程实现经验，专注于为客户提供高质量的无人机解决方案，广泛应用于应急救援、人常作物、物流运输等领域，致力于成为世界著名的无人化智能特种飞行装备供应商。
