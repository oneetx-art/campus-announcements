## 公司
性质:央国企 · 行业:能源/化工/环保

中安联合煤化有限责任公司是中国石化与安徽省皖北煤电集团合资组建的大型煤化工企业，成立于2010年，项目总投资267亿元，建设安徽省与中国石化战略合作的重点工程——淮南市“一号工程”，下设煤化工和煤矿两个分公司。一期建成250万吨/年煤炭洗选、170万吨/年甲醇制烯烃及35万吨/年聚乙烯、40万吨/年聚丙烯、35万吨/年聚丙烯产品。
