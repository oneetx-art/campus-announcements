## 公司
性质:民企 · 行业:机械/制造业

广东金鼎光学技术股份有限公司成立于2011年8月10日，是一家深耕高端光学制造领域的国家高新技术企业、国家超级专精特新“小巨人”企业。公司注册资本5243.8920万元，是一家以开发、制造、销售全自动非球面精磨机（系列）、超精密非球面纳米研磨机、光学冷加工自动化设备及其光学镜片、光学镜头等产品的光学公司；产品销往日本、美国、德国等国家和中国香港、中国台湾等地。
