中冶赛迪集团有限公司是中国五矿、中国中冶骨干子企业，其前身重庆钢铁设计研究总院系国家钢铁工业设计研究骨干单位，现已发展成有自主核心产品的科技型技术服务企业，入选国务院国资委创建世界一流专业领军示范企业。主要业务为以高端咨询为引领的钢铁工程技术、智能化信息化、城市建设、绿色环保四大板块。拥有工程设计综合甲级资质和冶金工程施工总承包特级资质。总部位于重庆，在海内外设立了20余家子公司，业绩遍布全球六大洲30余个国家。
