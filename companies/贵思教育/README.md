## 公司
性质:民企 · 行业:教育/培训/科研

贵思教育品牌始于2008年，为陕西省职业教育与成人教育行业知名品牌，前身为西安交通大学继续教育学院直属培训中心。旗下拥有陕西贵思教育科技集团工会、归群利民之家。是颇具规模的贵思教育科技集团。旗下拥有陕西贵思教育科技集团工会、归群利民之家。是颇具规模的正规教育成人教育培训、职业运营培训办学范围的正规教育培训机构。陕西省西安市小寨商圈+龙延堡大区专属18届3000平米“书春式”标准化教学基地。专注服务18周岁以上在校学生，励志发展成为以升学培训为愿景，基于战略、体系、品牌、资质、资金、团队、薪酬、场地与生源及技术多源生长的“1+3+N”新职业教育与成人教育生态品牌。总计培训院校员工职业近270人，各类在籍学生人数2.6万余人，累计培训毕业学生6万余人。
