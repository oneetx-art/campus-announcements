## 公司
性质:民企 · 行业:交通/物流/仓储

中铁联合国际集装箱有限公司（简称“中铁联集”）成立于2007年3月，是经原铁道部、商务部批准设立的中国铁路首家中外合资企业，主要负责建设、运营国家中长期铁路网规划中的18个铁路集装箱中心站。铁路集装箱中心站是全国铁路货运场站网络的重要组成部分，是铁路发展多式联运和现代物流服务的重要基地。
