## 公司
性质:央国企 · 行业:房地产业/建筑业

中建交通铁路公司是中国建筑旗下三级单位，隶属于中建交通建设集团，是中国建筑系统内铁路站房领域的先行者，先后承建了乌鲁木齐新客站、济南东站、张家口南站等50余座高铁站房及城市交通枢纽，获得过“国家优质工程奖”“全国铁路建设最高奖-优质工程一等奖”“中国铁路系统火车头奖”等多项荣誉。近年来铁路公司不但深耕优势业务，承建商高高铁站前十标四标项目、西藏文化广电艺术中心项目，同时不断拓展业务领域，先后中标临哈铁路临河至额济纳段扩能改造工程、际华三五三一搬迁改造项目等项目。
