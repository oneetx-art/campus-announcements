## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

人民教育出版社（简称“人教社”），是教育部所属大型专业出版社，成立于1950年12月1日，毛泽东主席亲笔题写社名。首任社长兼总编辑是著名文学家、教育家、出版家、社会活动家叶圣陶先生。1983年挂牌成立课程教材研究所，邓小平同志亲笔题写所名。2020年11月，在人教社成立70周年前夕，习近平总书记给人教社老同志回信，充分肯定了人教社在基础教育教材和教育图书编研出版中为我国教育事业发展作出的积极贡献。
