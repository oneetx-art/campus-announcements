## 公司

哈尔滨电气国际工程有限责任公司（以下简称哈电国际）是哈电集团的电力总承包公司，成立于1993年，哈电集团主营电站设备研发和制造，拥有“一总部、三基地”的全球产业布局，电力装备业务遍布全球60多个国家和地区。哈尔滨电气国际工程有限责任公司是中国最大的具有完整自主知识产权的“走出去”的工和企业之一，也是中国ENR排名前150位，中国产品出口的电力总承包类龙头企业之一，多次荣获ENR全球最大50家国际承包商荣誉称号，持为全球电事业提供中国解决方案。
