## 公司
性质:央国企 · 行业:机械/制造业

中船第九设计研究院工程有限公司，始建于1953年5月23日，隶属于中国船舶集团有限公司，由原中船第九设计研究院改制而来，始终以“国之重器”的担当锚定发展方向，取得了国家有关部委批准的船舶、军工、机械水运、建筑、市政、环保等领域的工程设计综合资质甲级，工程勘察综合资质甲级，以及工程咨询、工程监理、城乡规划编制、房屋建筑工程施工总承包一级等资质，具备了对外工程总承包、境外设计顾问及施工图审查的资质。
