## 公司
性质:央国企 · 行业:金融业

中国银河资产管理有限责任公司是经国务院同意、国家金融监督管理总局（原银保监会）批准成立的第五家全国性金融资产管理公司（AMC）。股东单位包括中央汇金投资有限责任公司、中国银行金融资产负债管理运营集团有限公司和中信证券股份有限公司。中国银河资产于2020年12月获批金融许可证正式开业。公司秉承“守正创新、和合共赢”核心价值观，以“努力打造受人尊敬、拥有特色核心竞争力的现代金融资产管理公司”为发展愿景，笃定“重塑资产价值，共创美好生活”的价值理念，坚持市场化、专业化、生态化、集约化、数智化原则，努力打造“重塑商业模式、金融资产治理、数字化重要作用，努力担当好金融风险化解者、社会资源配置者和实体集团服务者。
