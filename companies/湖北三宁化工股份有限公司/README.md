## 公司
性质:民企 · 行业:能源/化工/环保

三宁化工位于湖北省宜昌市枝江市姚家港千亿化工园区，现有员工7000余人，固定资产226亿元，拥有20余家分厂、子公司，是一家集现代煤化工、精细磷化工、化工新材料、工业服务业为一体的大型化工企业。公司是高新技术企业、中国化工百强、化肥10强、湖北省100强企业。2024年公司实现销售收入164.2亿元，利润总额19.07亿元，缴纳税金6.72亿元。近年来，公司陆续投资600多亿元新建己内酰胺、聚合、尼龙新材料、磷化工等八大项目，每年研发费用投入均在4亿元以上。公司位于武汉的三宁研究院是博士后科研工作站、省新型肥料校企联合中心、碳磷基新材料湖北省工程研究中心、磷酸及磷酸盐湖北省工程技术研究中心。研究院拥有一支由多领域、多学科的博士、硕士及专业技术人员组成的研发团队，总面积12万平米，包含现代化标准实验室2万平米，设有多个工艺技术研究室和产品分析测试研究室，以及多台先进的工艺反应设备和分析测试设备，以打造成高标准现代化研发中心。
