## 公司
性质:央国企 · 行业:能源/化工/环保

浙江省水利水电勘测设计院创立于1956年，2021年完成公司注册登记，正式更名为浙江省水利水电勘测设计院有限责任公司（以下简称“浙水设计”），是一家具有的工程咨询、勘测设计、工程勘察等10项甲级资质的国有大型勘测设计单位，位列全国工程咨询行业综合实力百强，是全国优秀勘察设计院、国家高新技术企业，连续六届蝉联“全国文明单位”。目前现有员工1300余人，平均年龄38岁，高级职称443人，拥有享受国务院政府特殊津贴、全国水利系统劳动模范、水利部“青年拔尖人才”、浙江省勘察设计大师等行业领军人才50余人次。
