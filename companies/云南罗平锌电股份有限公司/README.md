## 公司
性质:央国企 · 行业:能源/化工/环保

罗平锌电于2000年12月21日成立，2007年2月15日在深圳证券交易所挂牌上市，是国内首家集水力发电、铅锌矿开采选矿、锌冶炼及深加工的矿-电-冶一体化上市公司，主要业务由水力发电、矿山开采和锌冶炼、食用菜籽油四大部分组成，下辖6个生产单位，4个全资子公司，3个控股公司，3个参股投资公司，目前公司的市值：32.946亿元。
