## 公司
性质:民企 · 行业:快速消费品

河南尚品食品有限公司成立于2011年，专注于牛肉、鸭肉、猪肉、涮锅火锅肉等腌腊肉品的研发、生产、销售一体化经营。尚品食品为出口食品备案企业、海关AEO高级认证企业、国家级绿色工厂企业，并先后获得“农业产业化省重点龙头企业”、“河南省专精特新企业”、“国家级高新技术企业”等荣誉称号。目前已成为迪士尼、开市客、山姆、元初、海底捞、锅圈、罗森等国内外连锁企业的核心供应商，并与温氏、圣农、盈和、奥尔滨、东方希望、益客集团、龙大、乐世邦、家佳、7-11等品牌连锁指定合作伙伴。
