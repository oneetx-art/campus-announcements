## 公司
性质:央国企 · 行业:能源/化工/环保

华电金沙江上游水电开发有限公司（以下简称“华电金上公司”）成立于2006年4月，是国务院国资委监管的特大型中央企业、世界500强中国华电集团有限公司直属单位，下辖叶巴滩分公司、巴塘分公司、拉哇分公司、苏洼龙分公司、昌波分公司、波罗分公司、昌都分公司7家分公司，甘孜新能源公司、昌都新能源公司、金藏物资公司3家子公司和岗托筹备处，主要负责金沙江上游川藏段风光水一体化基地开发建设和管理。基地位于四川省甘孜州与西藏自治区昌都市交界处，是国家“十四五”重点建设的九大清洁能源基地之一，也是发展新质生产力、推动建设西电东送接续基地的先导工程和构建新型电力系统的重要生力军，正着力打造全国主要流域风光水一体化先行基地。
