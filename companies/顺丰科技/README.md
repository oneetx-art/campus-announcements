## 公司
性质:民企 · 行业:交通/物流/仓储

顺丰科技有限公司成立于2009年，是顺丰旗下专注智慧物流解决方案的科技服务商。顺丰科技基于对物流场景的深度理解和行业头部公司的数智化实战经验，结合多元业务中沉淀的数据与前沿的技术探索成果，为用户提供更懂数智物流的科技服务。基于人工智能、大数据、运筹、数字孪生等技术，对顺丰各业务进行全面的数智化，让包裹准时、安全地送达；让小哥们的工作合理、公平；让技术的研发灵活、快速；让集团的经营高效、健康。依托顺丰的物流履约的基础以及大数据、人工智能、区块链等前沿技术，提供适应行业特色的智慧供应链产品、综合方案，对供应链全链条进行数智化改造，让各行业客户拥有更科学、卓越的智慧供应链。
