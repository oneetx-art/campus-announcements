## 公司
性质:民企 · 行业:机械/制造业

四川大禹机械密封件制造有限公司是中国最早的流体密封生产企业之一，其前身可追溯到1976年的国营机械厂，同时也是全球流体密封先驱企业。49年的发展历程使公司成长为一家优秀的流体密封服务商，为全球客户提供整套流体密封解决方案、产品、售后、技术培训等服务。公司现为“国家高新技术企业”、“中国机械密封协会理事单位”、“四川省专精特新中小企业”、“四川省2025年先进智能工厂”、自贡市机械密封协会会长企业。
