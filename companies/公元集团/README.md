## 公司
性质:民企 · 行业:机械/制造业

公元塑业集团成立于1983年，是一家以塑料管道为主业，同时涵盖光伏新能源、开关插座等八大产业的大型企业集团。其核心子公司公元股份（股票代码：002641）成立于1993年，作为管道行业龙头企业，连续多年蝉联中国民营企业500强。产销量连续多年位列国内塑料管道A股上市企业第一，出口量连续多年居全国行业第一。
