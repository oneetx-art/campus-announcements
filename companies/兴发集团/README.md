## 公司
性质:央国企 · 行业:能源/化工/环保

兴发集团源于湖北省兴山县，是一家全球领先的精细磷化工企业，总资产547.68亿元，员工6000余人，控股上市公司兴发集团（600141）。2021年实现销售收入255.7亿元，创利税40亿元。2021年12月24日，习近平总书记视察兴发集团，对兴发集团转型发展给予了充分肯定。2022年9月30日，绿色发展理念与实践国际论坛在兴发集团成功举办，展示了兴发集团在绿色发展、生态环保、科技创新、走生态优先、绿色发展之路，推动长江经济带高质量发展。
