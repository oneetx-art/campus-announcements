## 公司
性质:央国企 · 行业:金融业

爱建证券有限责任公司是国内历史悠久、拥有全牌照的综合类证券公司，秉承“爱国建设”的改革和奋斗精神，于2002年经中国证监会批准，在上海组建成立。公司主要股东为上海陆家嘴金融发展有限公司和上海爱建集团股份有限公司，目前公司注册资本22亿元人民币。
