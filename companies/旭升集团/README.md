## 公司
性质:民企 · 行业:汽车制造/维修/零配件

宁波旭升集团股份有限公司（股票代码：603305）成立于2003年，是一家在上海证券交易所上市的平台型轻量化企业。集团总部位于中国宁波，旗下拥有压铸、锻造、挤压、集成四大事业部，并在中国、美国、墨西哥、泰国等地设立了研发中心与制造基地。公司产品主要涵盖新能源汽车的电驱动系统、电控系统、电池系统、底盘及悬挂系统、高性能车身系统，以及储能系统和机器人系统。
