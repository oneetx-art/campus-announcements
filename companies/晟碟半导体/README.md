## 公司
性质:外企 · 行业:通信/电子/半导体

晟碟半导体（上海）有限公司专注于提供内存存储产品工艺的研发、封装、测试、自动化解决方案，产品范围应用于高性能，车规级，智能终端等多个存储器应用产品。是全球规模较大的闪存存储产品封装测试工厂之一。2022年公司获得了世界经济论坛“端对端灯塔工厂”和“可持续发展灯塔工厂”双认证，是全球首家同时获此殊荣的企业。此外，公司荣获了“2025年度卓越级智能工厂”称号、责任商业联盟RBA铂金级和首选工厂奖。同时，公司也注重于可持续发展和节能减排，取得了“固体废物零填埋”、“上海市节水企业”、“国家级绿色工厂”等证书。
