德州联合石油科技股份有限公司始建于1961年，注册资本1.5亿元，总资产15亿元。2022年1月，德石股份首次公开发行A股并在深交所上市，股票代码“301158”，股票简称“德石股份”。公司下设新疆德石机械有限公司、俄罗斯联合石油技术服务有限公司、青岛德石能源技术有限公司、IAE International,Inc.等分支机构。公司作为国内领先、国际知名的集研发、生产、经营、服务于一体的综合性石油装备制造企业，深耕高端制造60余年，为中国石油、中国石化、中国海油、延长石油等国内大型能源集团，以及BAKERHUGHES、WEATHERFORD、NOV等国际油气行业知名公司提供专业产品与服务，是国际油气开发行业信赖的合作伙伴，致力于为客户创造更高价值！
