## 公司
性质:央国企 · 行业:能源/化工/环保

南钢成立于1958年，国家“第二个五年计划”布局的重点企业，国内先进制造业集群——新特钢材材料产业集群重点企业，南京市支柱产业龙头企业。2000年南钢股份在上海上市，现为复星国际成员企业。南钢始终坚持创新驱动，产业向新材料、新装备转型突破，钢铁产业向精品、特钢延伸，形成了“一体三元五链”的发展格局。南钢坚持“创建国际一流受尊重的企业智慧生命体”的企业愿景，秉承“创建绿色智慧钢厂、打造百年老店、助力员工成长、造福社会大众”的企业使命，积极打造以钢铁新材料为核心，新材料、新能源、新产业深度融合的相互赋能、复合成长的“产业智慧生命体”。
