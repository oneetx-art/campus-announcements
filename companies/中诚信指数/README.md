## 公司
性质:民企 · 行业:金融业

中诚信指数公司是中诚信集团旗下提供指数投资全链条服务的研究驱动型公司。作为中国金融市场中专业的指数投资全流程解决方案服务商，我们始创于1992年10月，是经中国人民银行批准成立的中国第一家从事信用评级、证券市场咨询和信息服务的全国性非银行金融服务机构。自成立以来，承做了中国资本市场几乎所有债券及融资工具评级的第一单，业务辐射全国并覆盖亚洲、欧洲、美洲。中诚信指数的综合市场份额始终稳居第一，市场占有份额约40%，是国内第一、世界第四的成员评级机构。中诚信指数结合有一支高质量投研团队，成员毕业于国内知名院校，包括国际顶尖数据和来自公募基金、证券公司等资管机构的研究人员，产出涵盖量化研究、风险管理、信用研究等多个专业领域的研究力量，垂幕集团作为中诚信最具产品机构多的专业指数、多因子指数、另类资产机构，为机构投资者提供被动投资策略的研究成果，编制资产指数，为机构投资者提供指数投资的全流程服务。目前，公司已与多家知名头部机构（包括银行、保险资管、商业银行、公募基金、证券公司、信托公司、期货公司以及企业客户等）建立密切合作关系，中诚信指数服务的资金规模已超2600亿元。
