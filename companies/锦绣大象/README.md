## 公司
性质:民企 · 行业:农林牧渔

山西锦绣大象农牧集团股份有限公司（下称“集团”）起步于1989年，经过三十余年的创新发展，已成为集饲料生产、白羽肉鸡和生猪遗传育种、养殖与屠宰、食品加工于一体的现代化农牧集团。集团经营基于禽产业、饲料产业和猪产业三大板块。集团业务覆盖山西、陕西、河北、辽宁、内蒙古、湖北等地区，旗下拥有224个分（子）公司，经营375个生产厂（场），员工14000余人。
