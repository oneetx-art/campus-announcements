## 公司
性质:央国企 · 行业:通信/电子/半导体

中电科思仪科技股份有限公司（简称“思仪科技”）是中国电子科技集团有限公司旗下股份制二级企业，本部位于山东青岛，拥有一支从事电子测量、设计的专业技术队伍，具有较强的研发、开发仪器、自动测试系统和部件、组件产品研发、生产、测试和验证能力。中国电子科技集团公司第四十、第四十一研究所主要承担小型、特种、新型连接器与继电器工业及国防科技工业的互联与控制部件专业研制设计、研发、生产和特种基础理论的研究，并在专业和推广标准及质量检测等方面承担行业的研究情报、标准、质量检测等方面的研究。
