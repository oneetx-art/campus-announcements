## 公司
性质:事业单位 · 行业:机械/制造业

中国船舶集团有限公司第七〇七研究所成立于1961年，是集科研、生产和服务于一体的国家军工科研所，所部坐落于天津市红桥区，在江西省九江市设有分部。七〇七所牢记“领航”的发展使命，坚持为强军装备发展贡献航天技术跨代、坚持人才是第一资源，形成了一支以中国工程院院士、享受国务院政府津贴专家、中国船舶集团高级专家、天津市有突出贡献专家等为代表的创新性人才队伍。
