## 公司
性质:央国企 · 行业:机械/制造业

中车株洲电力机车有限公司始创于1936年，是中国中车旗下核心子公司，具有中国业内型谱最全、品种最多的产品体系，创造了中国轨道交通装备领域的诸多纪录。公司在国内外设有35家分子公司，其中包含9家海外子公司，在全球范围内拥有3千余名员工。
