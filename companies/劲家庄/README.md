## 公司
性质:民企 · 行业:快速消费品

劲家庄（惠州）健康食品有限公司由知名影星何家劲先生与好友于2011年创办，是广东省级高新技术企业。劲家庄秉持用纯天然、无添加、药食同源的中式滋补健康养生理念同现代生产工艺相结合，依托“全谷物+道地原料溯源”双轮驱动，成为新中式滋补创新领导品牌。产品数量多达百余种，拥有多款爆火明星产品，其中核桃桑葚黑芝麻丸长期稳居线上品类榜首，能量燕麦棒入选北京冬奥会/杭州亚运会官方供应，成为广东省唯一一家为冬奥会、亚运会供应食品的生产企业。
