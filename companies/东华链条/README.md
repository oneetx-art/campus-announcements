## 公司
性质:民企 · 行业:机械/制造业

东华链条集团创建于1991年，总部位于杭州，是一家全球研发、制造、营销型市服务型一体的国际化链传动企业，是中国首批制造业单项冠军示范企业、国家认定企业技术中心、国家知识产权示范企业、国家级绿色工厂、国家级博士后科研工作站。在全球拥有中国杭州、中国兴化、中国常州、日本石川、德国伍珀塔尔、波兰宁罗等六大研发制造基地。
