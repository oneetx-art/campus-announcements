## 公司
性质:民企 · 行业:机械/制造业

广州毅昌科技股份有限公司成立于1997年，2010年以中国工业设计第一股在深交所主板上市。国家认定企业技术中心，拥有国家级工业设计中心，主营集产品技术研发、生产基地为广州、合肥、芜湖、安庆及青岛等六个生产基地，是汽车、白色家电、医疗健康、消费电子等行业提供结构部件的一站式服务，主营产品为汽车内饰件、结构件、电子电器结构件、医疗设备及耗材、模压组件、注塑、钣金冲压、表面处理（喷涂/粉饰）、开发、销售等，重点客户包括海信、迈瑞医疗、万孚生物、零跑汽车、东方雨虹、海信博盈等。
