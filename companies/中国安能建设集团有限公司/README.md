## 公司
性质:央国企 · 行业:房地产业/建筑业

中国安能建设集团有限公司，是经党中央、国务院批准，根据跨军地改革战略部署，于2018年9月由武警水电部队整体转隶组建的一家中央企业，主要担负国家重大自然灾害工程救援和重点工程建设任务。集团公司是国家防总成员单位，是应急管理部自然灾害工程应急救援中心，是唯一以应急管部应急救援和工程建设为主责主业的中央企业，是自然灾害工程应急救援领域的国家队力量。
