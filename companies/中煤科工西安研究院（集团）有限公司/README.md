## 公司
性质:央国企 · 行业:能源/化工/环保

中煤科工西安研究院（集团）有限公司，成立于1956年5月，1999年9月随煤炭部从北京到西安，隶属于中国煤炭科工集团有限公司，系国务院国资委管理的大型国有骨干科技型企业，经过近70年发展，已成为我国煤炭系统专业从事煤田地质与勘探、煤矿安全高效开采地质保障技术、装备与工程领域最具有突出优势的国家重点高新技术企业，先后荣获“全国五一劳动奖状”“中央企业先进集体”“陕西省先进集体”“中国企业先进党组织”“西安市思想政治工作先进单位”“全国守合同重信用单位”等称号。
