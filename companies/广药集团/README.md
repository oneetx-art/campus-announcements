## 公司
性质:央国企 · 行业:医疗/医药/生物

广州医药集团有限公司（以下简称“广药集团”）是世界500强、生物医药、医疗服务商等与大健康产业相关的多产业群开发、生产销售以及医疗健康养生服务的全链条企业集团。旗下拥有“广州白云山医药集团股份有限公司”（香港H股、上海A股上市）等2家上市公司，连续多年位列《财富》世界500强，目前名列第459位，先后荣获“全国五一劳动奖状”“全国爱国拥军模范单位”“全国脱贫攻坚先进集体”等荣誉，入选国企改革“双百企业”等名单。
