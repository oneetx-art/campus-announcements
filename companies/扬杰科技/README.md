## 公司
性质:民企 · 行业:通信/电子/半导体

扬州扬杰电子科技股份有限公司是国内少数集半导体分立器件芯片设计制造、器件封装测试、终端销售与服务等产业链垂直一体化（IDM）的杰出厂商。产品线含盖硅基芯片、MOSFET、IGBT及功率模块、SiC、整流器件、保护器件、小信号等。公司产品广泛应用于汽车电子、人工智能、清洁能源、5G通讯、智能安防、工业、消费类电子等诸多领域。目前，公司在全球设立了多个研发、制造及销售网点，并连续数年被评为中国半导体功率器件前三强企业。公司于2014年03月23日在深交所上市，证券代码300373。
