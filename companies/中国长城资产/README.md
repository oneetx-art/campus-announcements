## 公司
性质:央国企 · 行业:金融业

中国长城资产是国务院批准成立的国有金融资产管理公司之一。自1999年成立以来，始终坚守“化解金融风险、提升资产价值、服务经济发展”的初心使命。2016年底，公司完成股份制改革，正式更名为中国长城资产管理股份有限公司，标志着公司迈进现代企业制度建设的新阶段。中国长城资产以不良资产经营管理为主，多种业务资质为支撑，拥有32家分公司和7家控股子公司，机构网络覆盖全国30个省、自治区、直辖市及香港特别行政区。近年来，公司聚焦金融机构改革化险、实体经济纾困重组、房地产市场和资本市场风险化解等重点领域，充分发挥金融救助和逆周期调节功能作用，形成“金融化险体系、实体企业纾困、重组重整顾问咨询”等综合业务产品体系，在化解重点领域风险，支持实体经济发展，服务国家战略实现中持续发挥积极作用。
