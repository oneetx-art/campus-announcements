## 公司
性质:央国企 · 行业:农林牧渔

中国储备粮管理集团有限公司是经国务院批准组建的涉及国家粮食安全和国民经济命脉的公益类国有大型骨干企业，实行集团-分（子）公司-直属库“三级架构”。目前下设24家分公司、1家二级专业子公司和1家控股公司，人员、机构和业务覆盖全国31个省、自治区、直辖市。中国储备粮管理集团有限公司河南分公司是中储粮集团公司在河南省的区域性管理机构，2000年9月成立，负责管理河南地区中央储备粮油和直属企业。目前，在全省共管辖27家直属企业。
