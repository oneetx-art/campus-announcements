## 公司
性质:社会组织 · 行业:文化/传媒/广告/体育

法律出版社有限公司由中华人民共和国司法部主管主办，成立于1954年，是法律出版领域的标杆企业。作为国内法律图书市场占有率与品种规模“双领先”的权威机构，我们始终秉持“为人民传播法律”的宗旨，形成了涵盖图书出版、期刊出版、音像出版、数字出版、法文化创意设计等多元化业务格局。出版物覆盖全面依法治国、法律文本、法学教育、法律考试、法学学术、司法实务、法律应用、法律普及以及法律文化等多个领域。
