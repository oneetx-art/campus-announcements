## 公司
性质:事业单位 · 行业:教育/培训/科研

乾元国家实验室是中央管理的新型科研事业单位，是电磁（信息与能量）科学技术领域突破型、引领型、基础型一体化的国家战略科技力量。实验室位于浙江省宁波市。实验室由国家顶级战略科学家领衔，承担了一批中国科学院、中国工程院院士，聚焦国家战略科学需求，汇聚了国家重大科技项目，探索新型举国体制下有组织科研与自由探索深度融合的研究范式，具有开放自由的科研氛围、完善一流的科研平台、稳定饱满的科研任务和全面优厚的福利待遇。
