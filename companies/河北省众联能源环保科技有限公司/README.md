## 公司
性质:民企 · 行业:能源/化工/环保

河北省众联能源环保科技有限公司成立于2005年，注册资金5400万元，总部位于河北省石家庄市桥西区裕华路66号海悦天地F座，公司在新疆、广东、山东及河北唐山、承德、沧州、衡水、邢台、邯郸等地设有分公司或驻外机构，独资或控股多家环境工程和环境检测技术服务公司，现有职工总人数近700余人。其中高级职称技术人员57名、中级职称技术人员270名、硕士学位技术人员326人、环境影响评价工程师66人、安全评价师49人、注册安全工程师25人，咨询工程师4人、二级建造师5人。我公司专注节能降碳、环境保护、安全咨询等技术开发和技术服务，从项目前期筹划、工程建设到建成验收、运营管控以及后续提升改造为企业提供全流程、全方位的安全、环保、节能降碳整体技术方案，技术水平和服务质量稳居同行业前列，被河北省工业和信息化厅、河北省科学技术厅等部门认定为专精特新中小企业、高新技术企业，也是中国环保产业协会认定的AAA级信用等级企业，多年被河北省环境保护产业协会评为环保骨干企业。
