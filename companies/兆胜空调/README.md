## 公司
性质:民企 · 行业:机械/制造业

江苏兆胜空调有限公司创建于1985年，坐落于扬子江泰兴经济开发区，是集研发、制造、营销、运维于一体，在船舶、海工、风电、储能、数据中心、化工、粮仓、医药等特殊空间领域深耕拓展，同时聚焦海上新能源领域，积极布局CO₂捕集与燃料供给系统/烟气系统冷却、低电力船舶储能智能管理产品的研发、制造和运维，为客户提供低碳、安全的个性化定制环控系统解决方案及全生命周期服务。
