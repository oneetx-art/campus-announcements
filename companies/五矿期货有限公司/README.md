## 公司
性质:央国企 · 行业:金融业

五矿期货有限公司是中央直管的国有重要骨干企业中国五矿集团的三级公司，总部在深圳市南山区五矿金融大厦，成立于1993年，是中国成立最早的一批期货公司之一，现拥有5家分公司和17家期货营业部，另下设五矿产融、五矿金融等3个子公司。
