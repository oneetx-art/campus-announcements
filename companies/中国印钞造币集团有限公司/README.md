中国印钞造币集团有限公司（简称“印钞造币公司”）于1980年经国务院批准成立，是中国人民银行所属企业。印钞造币公司始终肩负“为国造币、为民服务”的崇高使命，专业从事负责币的设计、研发、印制并服务于现金全生命周期管理。
