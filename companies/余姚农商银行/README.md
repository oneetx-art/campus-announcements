## 公司
性质:其他 · 行业:金融业

余姚农商银行成立于1952年，是浙江省第一家信用社——南山信用社，历经73年风雨，已成为县域金融“小冠军”。存贷规模1660亿，资产规模1190亿，营业网点82个，员工890余名。获得中国银行业最具社会责任金融机构奖、连续四年蝉联浙江民企最满意银行、浙江农商银行系统综合实力十强银行、宁波市生产性服务业20佳企业、乡村振兴主办银行等荣誉。
