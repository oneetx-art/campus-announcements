## 公司
性质:民企 · 行业:耐用消费品

河南新飞智家科技有限公司，简称“新飞公司”，是以冰箱、冷柜、空调、洗衣机为主导产品的现代化白色家电制造企业。新飞冰箱、冷柜产销量连续多年名列行业前茅，“新飞”品牌被公认为中国著名的绿色家电品牌。新飞冰箱拥有国家专利AES五重除菌技术，并连续多年获得行业大奖。2024年，新飞智家科技产业园已全面公司，新飞冰箱、冷柜年产将达到400万台以上，成为行业内具有影响力的白色家电制造企业，并推动上下游产业链全面发展。未来，新飞将持续为全球用户提供多元化卓越的健康产品。
