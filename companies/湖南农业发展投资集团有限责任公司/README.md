## 公司
性质:央国企 · 行业:农林牧渔

湖南农业发展投资集团有限责任公司成立于2022年7月，是由湖南省现代农业产业控股集团有限公司与湖南粮食集团有限责任公司合并组建的省属大型国有农业企业。集团注册资本100亿元，资产总额654亿元，控股新五丰、金健米业两家上市公司。主营业务涵盖粮油肉储进出口、种猪生猪养殖、食品研发加工、粮油进出口、乡村振兴等领域，产品包括米、油、面、生猪、鲜肉、米粉、速冻食品、乳制品及休闲食品等，旗下拥有“金健”“裕湘”“U鲜”等多个知名品牌。集团现有农业产业化国家甲级和省级重点龙头企业16家、高新技术企业11家、国家级和省级创新平台有农业产业化国家和省级重点龙头企业16家、高新技术企业11家、国家级和省级创新平台19个、省级专精特新中小企业5家、院士专家工作站1个、博士后科研工作站2个、专利223项，获省级以上科技奖励25项。2024年位列中国农业企业500强第40位、畜牧业第4位，获评“中国十佳粮油集团”。
