## 公司
性质:民企 · 行业:能源/化工/环保

北京高能时代环境技术股份有限公司成立于1992年，2014年登陆上海主板上市，是国内最早专业从事固废污染防治技术研究、成果转化和提供系统解决方案的国家级高新技术企业之一。公司以技术创新推动产业转型升级，形成以资源循环利用、环保运营服务和环保工程服务为核心业务板块的综合型环保服务平台。此外，公司积极推进国际化战略，在东南亚、中亚、拉美、非洲等地拓展市场，同时布局城市矿产资源领域，致力于搭建全球化资源供应与环保服务网络。
