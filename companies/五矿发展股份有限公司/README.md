## 公司
性质:央国企 · 行业:贸易/批发/零售

五矿发展股份有限公司成立于1997年5月21日，是中国五矿集团旗下的上市公司，主要从事钢铁、矿产品贸易、供应链服务等业务。公司业务涵盖国内和国外市场，提供综合贸易服务，是全国性贸易、物流、金融服务平台。公司在2021年荣获“中国500强企业”排名第195位，2022年荣获“中国上市公司500强”排名第178位，2023年荣获“中国上市公司100强”荣誉称号。
