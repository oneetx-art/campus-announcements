## 公司
性质:央国企 · 行业:机械/制造业

国机金刚石（河南）有限公司（国机金刚石）成立于2023年12月27日，隶属于中国机械工业集团有限公司（国机集团），控股股东为新材科投资集团有限公司（国机精工）。国机金刚石由国机精工与河南省联合投资集团（河南省财政厅出资、省国资委监管）合资成立。肩负引领超硬材料行业高质量发展的使命，以巩固提升超硬材料及制品产业链国际竞争优势为主线，以培育钻石、关键装备、结构陶瓷服务、功能化应用、超硬材料新消费和标准检测服务为主攻方向。业务涵盖金刚石行业上中下游各关键环节，努力建成科技驱动的世界一流金刚石产业集团。国机金刚石注册资本25亿元，现有员工2000余人，总部设在郑州市，在上海、深圳、成都、哈密等地设立分子公司。
