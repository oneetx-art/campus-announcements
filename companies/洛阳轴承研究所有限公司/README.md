## 公司
性质:央国企 · 行业:机械/制造业

洛阳轴承研究所有限公司是“点、精、尖、特”专业轴承主机及高端技术研制、其前身洛阳轴承研究所成立于1958年，是我国轴承行业的综合性研究机构。1999年进入中国机械工业集团有限公司，转制为科技型企业。
