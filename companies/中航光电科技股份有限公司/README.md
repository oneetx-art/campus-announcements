## 公司
性质:央国企 · 行业:机械/制造业

中航光电科技股份有限公司是专业为航空及防务和高端制造提供互连解决方案的高科技企业。公司多元从事中高端光、电流体连接技术与产品的研究与开发，自主研发各类连接产品500多个系列，35万多个品种，拥有国家认定企业技术中心、博士后科研工作站以及国家和国防认可实验室。截至2024年底，公司累计计获得授权专利5900余项，主持参与制订行业标准220余项，公司产品广泛应用于防务、商业航空航天、轨道交通、新能源、石油装备、电力装备、工业装备、医疗设备、智能互联与消费电子、高端制造领域。
