## 公司
性质:事业单位 · 行业:医疗/医药/生物

首都医科大学附属北京友谊医院始建于1952年，是新中国成立后，由党和政府建立的第一所大型综合性医院。经过70余年的发展，首都医科大学附属北京友谊医院已发展为集医疗、教学、科研、预防为一体的国家三级甲等综合医院，形成了西城院区、通州院区、顺义院区和城市副中心行政办公区门诊部“一院四部”新发展格局。
