## 公司
性质:民企 · 行业:金融业

阳春农商银行是具有独立法人资格的股份制商业银行，始建于1952年，2012年完成股份制改革。秉承“手握手的承诺 心贴心的服务”理念，扎根阳春70余年，始终深耕“三农”，支持小微企业发展，践行“勤劳金融”，主动融入乡村振兴，是阳春市网点覆盖广、资金实力雄厚、存贷款规模一直雄踞当地银行业前列的金融机构，连续多年获得阳春市“纳税信用A级纳税人”、省级、市级“青年文明号”、“广东省先进职工之家”、“广东省模范职工小家”、“全国工会职工书屋示范点”等荣誉称号。
