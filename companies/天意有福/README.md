## 公司
性质:民企 · 行业:机械/制造业

天意有福科技股份有限公司是一家基于'互联网+数字印刷'开展个性化定制印刷产品的大规模智能化生产的高新技术企业。公司始于1992年，于2015年8月新三板成功挂牌。在国内从事商务细分市场画册、出版物、包装印刷品、个性化影像印刷品、工业配套说明书、标签及其他印刷品的印刷。
