## 公司
性质:外企 · 行业:财务/审计/税务

HRnetGroup集团成立于1992年，于2017年在新交所上市（SGX：CHZ），是亚太领先的人力资源集团。集团内共有19个品牌，分布于亚洲18个发达城市，包括：新加坡（总部）、上海、北京、广州、深圳、苏州、成都、香港、台北、高雄、吉隆坡、曼谷、首尔、东京、雅加达、新竹及西安。目前，HRnetGroup在中国的品牌包括：HRnetOne，PeopleSearch，RecruitFirst，REForce（2018年收购品牌），AllwaysHRnet（2024年收购品牌）为客户提供中高端人才寻猎、灵活用工、RPO招聘流程外包等整体人力资源解决方案。HRnetGroup集团目前有超过900名咨询顾问和近50,000名合同工可随时服务于我们的客户。我们服务的领域覆盖了消费品与零售、医疗、信息技术与电信、金融、制造业等近30多个行业，并在人力资源、财务与会计、法律与合规等领域发挥职能。
