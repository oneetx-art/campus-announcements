## 公司
性质:民企 · 行业:房地产业/建筑业

安徽万乘电能有限公司前身为安徽万乘电力建设有限公司，成立于2018年1月10日，2022年12月7日更名为安徽万乘电能有限公司。公司坐落于安徽省合肥市经济技术开发区启迪科技城机器人产业基地；注册资本伍仟万元。是一家专业从事电力工程施工、安装、试验、调试及后期维护，光伏新能源安装的综合性电力服务企业。公司拥有电力工程施工总承包贰级、城市及道路照明工程专业承包贰级、建筑机电安装工程专业承包贰级、承装类三级、承修类三级、承试类三级，安全生产许可证资质、环境管理体系认证证书、环境管理体系认证证书、职业健康安全管理体系认证证书等资质证书。
