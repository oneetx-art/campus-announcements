## 公司
性质:央国企 · 行业:农林牧渔

中国储备粮管理集团有限公司是经国务院批准组建的涉及国家粮食安全和国民经济命脉的公益类国有大型骨干企业，实行集团—分（子）公司—直属库“三级架构”。目前下设24家分公司、11家二级专业子公司和1家控股公司，人员、机构和业务覆盖全国31个省、自治区、直辖市。中国储备粮管理集团有限公司湖南分公司（简称“中储粮集团湖南分公司”）是中储粮集团公司的派出机构，于2000年10月成立。中储粮集团湖南分公司根据中储粮集团公司授权委托，主要负责湖南辖区的中央储备粮油经营管理、国家粮食收储政策和宏观调控任务执行，积极助力和服务好地方“三农”事业发展。中储粮湖南分公司下辖17家中心库、27家分库，分布在全省14个市州。
