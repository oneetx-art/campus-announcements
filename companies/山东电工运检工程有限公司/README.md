## 公司
性质:央国企 · 行业:能源/化工/环保

山东电工运检工程有限公司成立于1988年，是中国电气装备集团所属山东电工电气集团有限公司的全资子公司，位于山东省济南市。公司业务涵盖运维、检修、电力保障、设计咨询、工程总包及设备成套系统服务等领域，专注于风、光、储、线路、配电设备运维，聚变变压器、开关柜、配电网等核心电力设备检修及调试，重点开展会议保电、临时供电、设备租赁及应急业务，致力于为客户提供覆盖电力从设备全生命周期的一站式、高价值服务，逐步实现从单一检修服务商向电力系统全链条价值服务商的转型，赋能电力系统安全、高效、绿色运行。
