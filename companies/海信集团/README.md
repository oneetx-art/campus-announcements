## 公司
性质:央国企 · 行业:机械/制造业

海信成立于1969年，总部位于中国青岛。旗下拥有海信视像、海信家电、三电控股、乾照光电、科林电气、gorenje、ASKO等多个品牌。2024年，海信保持龙、凤主屏并驾，拥有海信、东芝电视、容声、科龙，稳增长整体营收463.2153亿元，其中海外收入996亿元，占整体营收43%。56年来，海信坚持“技术立企、稳健经营”的发展战略，不断发力汽车电子转型升级，构建起智慧生活、智慧能源、半导体、产业地产等产业板块。加速推进全球化，现在全球有31个研发中心、36个工业园区和生产基地，设有64个海外公司和办事处。
