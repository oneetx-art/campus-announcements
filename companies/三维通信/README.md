## 公司
性质:民企 · 行业:通信/电子/半导体

三维通信作为国际领先的移动通信解决方案供应商，是行业公认的无线信号覆盖、无线专网通信、无线信号安全、卫星通信服务领域的专家。集团旗下子公司业务还涵盖互联网数字营销、通信设施租赁及运营等。自1993年成立以来，三维通信作为中国首批通信上市公司，积累了行业前沿的研发及创新能力，荣获“国家重点高新技术企业”、“国家规划布局内重点软件企业”、“国家创新型试点企业”、“国家知识产权示范企业”等专项荣誉。
