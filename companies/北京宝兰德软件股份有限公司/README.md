## 公司

北京宝兰德软件股份有限公司（股票代码688058，简称“宝兰德”）成立于2008年，于2019年登陆科创板，是国家高新技术软件企业，荣获国家级专精特新“小巨人”企业称号。宝兰德聚焦基础软件中间件、智能运维及大数据+人工智能三大领域，致力于为千行百业专业的提供数字化解决方案。总部位于北京，设立了北京、西安、长沙、南京、成都5个研发中心及20余家分支机构，形成覆盖全国30个省市的技术服务网络。
