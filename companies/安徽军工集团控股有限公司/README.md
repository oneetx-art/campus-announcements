## 公司
性质:央国企 · 行业:机械/制造业

安徽军工集团控股有限公司（以下简称“安徽军工”）是重点保军骨干企业，2000年3月正式挂牌成立。主营业务包括军品和民品两大类，现已形成了以导弹、迫击炮弹、单兵火箭、特种子弹药、光电对抗装备、喷火装备、引信、点火器等系列武器弹药为核心的军品业务，民品产业中预应力锚具产品、新能源储能安全系统、公共安全监测告警系统、消防器材及工程等已成为重要支撑产业板块，完成由低端配套向高端集成化、绿色化核心跨越，正在积极布局纳米新材料、防爆技术、电气电装等战略性新兴产业。安徽军工现有二级子公司7家、三级子公司10家，核心子公司安徽长城军工股份有限公司于2018年8月在上交所成功上市，是全国首家以军品弹药武器装备为主营业务的上市公司。
