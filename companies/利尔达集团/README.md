## 公司
性质:民企 · 行业:通信/电子/半导体

利尔达科技集团是物联网产品研发、技术应用、服务落地的一站式合作伙伴，以“万物互联，利尔智达天下”为指引，二十余年来服务数万家客户，助力诸多领域智能化升级。公司总部位于杭州，注册资金42163万元，2023年2月17日已在北交所成功上市（股票代码：920249）。公司主营业务为IC增值分销业务和物联网模块及物联网系统解决方案的研发、生产和销售。作为国家重点领域高新技术企业和国家电子信息产业基地实训中心，参与了多项国家及行业标准的起草，是国家物联网基础标准工作组重要成员之一。获得“浙江省隐形冠军”、“浙江省科技小巨人”、“浙江省专精特新”等称号。
