## 公司
性质:事业单位 · 行业:机械/制造业

中国航空综合技术研究所（简称“综合所”）隶属于中国航空工业集团有限公司，成立于1970年，是从事国防军工领域标准化与质量等通用基础技术研究与应用的中央全额拨款国家队科研事业单位。综合所现有员工1300余人，主业科研人员900余人，硕士及以上学历占比63%，副高以上职称占比34%。拥有国家“百千万”人才、中国国防科技“511人才”等50余人，获评“院士、国家及省部级专家、政府特贴专家”等20余人。
