## 公司
性质:央国企 · 行业:能源/化工/环保

中国能源建设集团安徽电力建设第二工程有限公司是中国能源建设股份有限公司的骨干子公司。公司成立于1952年，是一家拥有电力施工总承包特级资质、市政施工总承包一级资质、建筑行业兴安安全设备安装许可证等20多项主资质的具有行业大型央企。公司聚焦能源与城市建设，以工程建设为核心，打造一流投资、建设、运营一体化综合服务商。70多年来荣获国家科学技术进步奖一等奖、国家重大技术装备成果特等奖、中国建筑工程鲁班奖等300余项国家及省部级荣誉，被誉为“与中国电力同行，与时代同行”的铁军。
