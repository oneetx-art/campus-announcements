## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁六局集团石家庄铁路建设有限公司是国有大型综合建筑施工企业，隶属于世界500强企业——中国中铁股份有限公司的全资子公司中国中铁六局集团有限公司。公司总部位于河北省会石家庄市，前身是1953年成立的北京铁路局北京工程处石家庄工程段。2004年4月6日公司重组成立，目前设有23个工程项目部，在岗职工1300余人。公司多次被评为“优秀施工企业”和中国铁路总公司、北京市、河北省“先进施工单位”及河北省“重合同守信誉单位”等称号。公司主要承建大型铁路综合工程、市政工程、公路工程、房屋建筑工程、桥梁工程、水利水电与新能源工程等，目前在建工程分布在全国各地，以河北地区为主，山东、河南、安徽、四川等省份均有在建项目。
