## 公司
性质:央国企 · 行业:能源/化工/环保

中国平煤神马控股集团有限公司（简称中国平煤神马集团）由原平煤集团和神马集团两家“中国500强企业”重组成立，是新中国成立以来第二家煤炭资源重组的特大型煤炭企业，拥有“中原大化”的称号。平煤神马集团是改革开放之初国家第一批引进的15个重点建设项目之一，是中国尼龙化工和浸胶帘子布的现代化企业，生产了我国高品质轮胎骨架引进日本先进设备技术、尼龙66工业丝。近年来，集团完整、准确、全面贯彻“创新、协调、绿色、开放、共享”新发展理念，坚持“六个坚定”发展战略，逐步形成，以煤炭为源头的多条特色产业链，开放、共享、形成发展，成为跨区域、跨行业、跨所有制经营的国有特大型集团。
