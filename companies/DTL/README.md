## 公司
性质:民企 · 行业:金融业

DTL成立于2010年，总部设于新加坡，是专注于全球金融市场的量化投资公司。作为新加坡金管局（MAS）持牌机构，构建了覆盖股票、债券、衍生品等全资产类别的投资体系，凭借卓越的夏普比和持续稳定的绝对收益，长期领跑量化领域。中国布局：2018年推进本土化战略，先后在上海、北京设立分支机构；2022年完成外商独资私募证券投资基金管理人（WOFE PFM）登记，开启中国发展新阶段。
