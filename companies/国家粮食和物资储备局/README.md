## 公司
性质:事业单位 · 行业:农林牧渔

国家粮食和物资储备局是国家发展和改革委员会管理的国家局，为副部级。主要职责是根据国家储备总体发展规划和品种目录，组织实施国家战略和应急储备物资的收储、轮换、管理，统一负责储备基础设施的建设与管理，对管理的政府储备、企业储备以及储备政策落实情况进行监督检查，负责粮食流通行业管理和中央储备粮棉行政管理等。
