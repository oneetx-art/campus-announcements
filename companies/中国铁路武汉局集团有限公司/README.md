## 公司
性质:央国企 · 行业:交通/物流/仓储

中国铁路武汉局集团有限公司（简称“武局”），是中国国家铁路集团有限公司管理的18个铁路局集团之一，成立于2005年5月18日，2017年11月完成公司制改革并更名，注册地位于湖北省武汉市武昌区，是国有大型铁路运输企业。 公司地处全国铁路网中部核心枢纽，管辖湖北省全境、河南省南部及安徽省部分地区的铁路线路，营业里程约7500公里，其中高铁里程约2700公里，路网覆盖“米”字形高铁枢纽，是长江经济带、中部地区崛起等国家战略的重要交通支撑。 核心业务涵盖铁路客货运输、线路设备养护维修、工程建设、多元经营（物流、文旅、装备制造等），同时承担着服务区域经济社会发展、保障国计民生物资运输、满足旅客出行需求的重要职责，是中部地区综合交通体系的关键组成部分。
