一汽铸造有限公司是中国一汽全资公司,专注于铸锻产品研发与制造,始建于1953年,与中国第一汽车制造厂同步诞生。公司持续聚焦“世界一流,永续发展”企业愿景,为汽车工业提供核心铸锻产品,是中国汽车工业铸造与锻造领域的重要基地。
