## 公司
性质:合资 · 行业:通信/电子/半导体

意瑞半导体创立于2014年，专注于传感与控制IC的研发与生产，荣获国家批准的高新技术企业，研发核心团队来自意法半导体（ST），曾是ST内部全权负责汽车车身控制IC开发的研发团队，有着十年的汽车电子IC开发经验。自成立以来，公司一直致力于汽车、工业、家电、医疗和通信等市场，在霍尔传感器IC领域，意瑞拥有较为齐全的产品序列，包括霍尔开关、单芯片霍尔电流传感器IC、线性霍尔和轮速传感器IC等，是国内少有品类齐全的传感器IC供应商。作为半导体技术的创新者和创造者，意瑞半导体致力于成为世界级领先的感知与控制芯片供应商。
