## 公司
性质:央国企 · 行业:能源/化工/环保

北京北燃实业集团有限公司（简称北燃实业集团）为北京控股集团全资公司，起源于1958年，是一家多元化产业布局的集团化企业。北燃实业集团主要业务涵盖城市供热及新能源、城市能源服务、园区运营服务和液化气储存与供应，业务足迹遍布30多个省份，100多个城市。具备“科研+设计咨询+工程施工+运营服务”的全过程咨询和解决方案的能力，能够为供热、燃气等能源项目提供一站式服务方案，提高项目的整体效率和质量。近年来，北燃实业集团为国家重大项目提供了强力支持。
