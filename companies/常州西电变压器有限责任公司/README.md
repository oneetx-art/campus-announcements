## 公司
性质:央国企 · 行业:机械/制造业

常州西电变压器有限责任公司（简称西电常变）始建于1958年，位于长三角中心城市江苏常州，隶属于中央企业中国电气装备集团旗下的中国西电电气股份有限公司，是国家指定生产变压器类产品的制造商、高新技术企业。作为中国特高压技术研究中心及创新制造商，江苏省超特高压变压器工程技术研究中心的创新示范型企业，西电常变拥有华东地区唯一的1000kV交流变压器与±1000kV换流变压器研发制造能力，其技术水平和新品业绩在行业中稳居前列。
