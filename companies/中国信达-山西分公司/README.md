## 公司
性质:央国企 · 行业:金融业

中国信达资产管理股份有限公司成立于2010年6月，其前身为1999年批准成立的中国信达资产管理公司，是国务院批准成立的中国第一家金融资产管理公司。2013年12月，中国信达在香港联合交易所主板挂牌上市，成为首家登陆国际资本市场的中国金融资产管理公司。目前中国信达设有33家分公司，旗下拥有9家直接管理的从事不良资产经营和金融服务业务的平台子公司，包括南商香港、信达证券、金谷信托、信达金科、信达香港、信达投资、信达地产、信达资本、中润发展，集团员工约1.4万人。
