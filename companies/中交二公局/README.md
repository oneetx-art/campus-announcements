## 公司
性质:央国企 · 行业:房地产业/建筑业

中交二公局工程有限公司（简称中交二公局），于1956年成立于古城西安，是世界500强——中国交通建设股份有限公司的控股子公司。中交二公局致力于基础设施建设，在公路、桥梁、隧道、铁路、城市轨道交通、场站枢纽、城市综合开发、市政、房建、水利、运营等全产业链为客户提供“投资、建设、设计、生态环保”一体化服务。业务遍及全球31个省区市及海外40多个国家，在建项目600多个。
