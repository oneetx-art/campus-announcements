## 公司
性质:民企 · 行业:机械/制造业

中国龙工控股有限公司，系中国工程机械行业领军企业之一，2005年在香港联交所主板上市，位列全球工程机械50强、全国百家明星侨资企业、中国机械工业核心竞争力100强。公司在福建、上海、江西三大基地拥有19家全资子公司，产品覆盖装载机、挖掘机、叉车、压路机和滑移装载机等品类，型号超过1000多种。其中装载机产销量持续行业领先，叉车产销量占据行业前三，品牌营销服务网络“遍布全国、辐射全球”。
