## 公司
性质:民企 · 行业:医疗/医药/生物

上海锐康生物技术研发有限公司是科伦药业集团（002422.SZ）下伊川宁生物科技股份有限公司（301301.SZ）的全资子公司，为川宁生物合成生物制造高端研发创新中心。锐康生物采用前沿的合成生物学，辅以自动化、智能化精准生物造物设备，来进行高附加值产品的研发，产品主要聚焦在高附加值天然来源保健品和化妆品活性成分等领域。
