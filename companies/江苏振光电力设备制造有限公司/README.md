## 公司
性质:央国企 · 行业:机械/制造业

江苏振光电力设备制造有限公司始建于1965年，现隶属于世界500强企业中国电气装备集团有限公司，位于江苏省镇江市。公司占地面积约15.6万平方米，年产能超1000kV及以下输变电线路铁塔、钢塔等，拥有多个生产车间及下属公司，是国家电网、南方电网、中国能建等特大型电力企业的重要供应商。公司注重人才培养，拥有成熟的加工工艺和稳定的质量、生产管理体系，秉持创新、打造电工产品的原则，致力于成为国际一流的电力装备制造商和系统服务商。
