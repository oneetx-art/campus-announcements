## 公司
性质:外企 · 行业:机械/制造业

1962年，祖籍潮州的吴清亮先生在新加坡创立了立时集团，目前已成为全球第四的涂料制造与服务商，旗下拥有约30个品牌，业务遍布全球。立邦中国区总部设立于上海，在中国投资建设近70家生产基地，员工近1.5万人。以“刷新美好生活空间”为企业使命，立邦一直致力于提供高质量的创新产品和服务来满足中国工业和城市的快速发展，以及人们对美好生活的需求。如今，立邦的业务范围涵盖建筑领域和工业领域，包括装饰涂料、建筑工程漆、汽车涂料、船舶涂料、工业漆、更多建筑材料（含美缝及胶粘剂、防水及瓷砖铺贴、辅材工具等），以及立邦刷新服务。
