## 公司
性质:民企 · 行业:机械/制造业

南京电气科技集团有限公司源于南京电气（集团）有限责任公司（原南京电瓷厂），前身为中央电瓷制造厂，始建于1936年，为白云电气集团在华东地区的总部，位于南京栖霞区经济技术开发区。建厂89年来，南京电气以产业报国、振兴民族工业为己任，为国家电力建设特别是重点工程建设做出了重要贡献，产品已用于多项特高压工程。公司拥有机械工业玻璃绝缘子工程技术研究中心、江苏省高压绝缘子工程技术研究中心、国家级实验室三大中心，2个国家级、3个省级专精特新小巨人企业。近年来，公司荣获全国机械工业先进集体、机械工业现代化管理企业、南京市博士后工作站等称号，连续多年入选中国机械500强企业和中国工业行业排头兵企业。
