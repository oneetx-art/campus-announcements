## 公司
性质:民企 · 行业:通信/电子/半导体

上海瞻芯电子科技股份有限公司（简称“瞻芯电子”）是中国领先的碳化硅（SiC）功率器件和芯片方案提供商，于2017年在上海临港成立。在浙江义乌设有晶圆厂，在深圳设有销售中心。公司已建成国内第一条自主可控、车规级碳化硅（SiC）功率器件和芯片量产线，为客户提供一站式芯片解决方案。广泛应用于新能源汽车、光伏与储能、充电柜和工业电源等领域。浙江瞻芯电子科技有限公司（简称“浙江瞻芯”）为瞻芯电子的全资子公司，于浙江义乌占地50亩，在2023年建成投产了一座车规级SiC晶圆厂，具备碳化硅（SiC）晶圆设计、制造和测试等产业链，通过了汽车行业质量管理体系认证。北京的瞻芯电子科技有限公司（简称“北京瞻芯”）为瞻芯电子的全资子公司，是瞻芯电子的北京区域中心，这将进一步完善全国商业布局，竭力拓展北方市场，同时辐射中国大陆其他的碳化硅产业重镇。
