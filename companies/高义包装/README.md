## 公司
性质:民企 · 行业:机械/制造业

广东高义包装科技股份有限公司成立于2014年，总部位于广东省东莞市，是一家提供一站式印刷包装解决方案的领先国际化企业。在中国、越南、马来、印尼、菲律宾、泰国设有生产基地。为微软、苹果、戴森、小米等知名企业提供彩盒、礼盒、纸托、说明书等纸质包装产品。公司2024年营业收入1亿多元，员工人数超4000人，近5年营业收入复合增长率超20%。公司是国家高新技术企业，被东莞市政府列入“倍增计划企业”名单，2025年通过广东省绿色包装及智能印刷关键技术工程技术研究中心认证。
