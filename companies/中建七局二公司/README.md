## 公司
性质:央国企 · 行业:房地产业/建筑业

中建七局第二建筑有限公司成立于1952年，注册资本金51亿元，是世界500强中国建筑旗下三级独立法人单位，是中国建筑第七工程局有限公司全资子公司。公司总部位于江苏南京，主要经营区域涵盖江苏、山东、山西、安徽、江西、河南、浙江、上海、福建等地，业务不断向实力强、影响力大、资源集中的核心城市、核心区域聚焦，先后荣获“全国工程建设质量管理优秀单位”“全国安康杯竞赛优胜单位”“全国守合同重信用企业”“全国建设行业安全生产先进单位”“全国AAA级信用之星”“全国工人先锋号”等荣誉称号。
