## 公司
性质:央国企 · 行业:金融业

中国农业科学院上海兽医研究所始建于1964年，是全国综合性兽医科学研究机构。研究所聚焦国家农业生物安全“主责主业”，围绕“国之大者”抓主抓重，以重大动物疫情、人畜共患病、重大外来病等为对象，开展生物安全公共政策、基础理论、监测预警、技术攻关、产品研发、集成应用等全链条研究，为保障国家农业生物安全、科技自立自强提供战略支撑。
