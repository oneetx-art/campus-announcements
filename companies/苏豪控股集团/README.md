## 公司
性质:央国企 · 行业:金融业

江苏省苏豪控股集团是江苏省级大型国有独资企业，集团坚持“贸易强基、金融赋能、实业支撑、创新驱动”的发展战略，聚焦贸易和金融两大主业，在大宗贸易和物资储备、国际化经营、纺织服装品牌建设、现代物流保障、智能制造创新、房地产投资六大板块持续发力，具有金牌铸造特色，功能更突出，竞争优势明显，是江苏省打造“服务贸易强省”的主力军，是全国供应链创新与应用100家示范企业之一，是全球供应链联盟（GSCC）成员单位，是中国上市公司协会（CSC）理事单位，是中国企业联合会、中国企业家协会常务理事单位，连续多年入选“中国服务业企业500强”和“中国对外贸易500强企业”。
