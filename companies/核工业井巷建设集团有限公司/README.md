## 公司
性质:央国企 · 行业:房地产业/建筑业

核工业井巷建设集团有限公司成立于1992年，隶属于浙江省自然资源集团有限公司，是一家省属国企，经过三十多年的发展，已成为一家集工程施工、咨询投资、规划设计、勘察测绘、生态环境治理、物资商贸、人力资源开发管理、物业运维等业务为一体的综合性企业，集团拥有2家“专精特新”中小企业、1家浙江省科技型中小企业，建有省级院士专家工作站、省级博士后工作站、省级企业技术中心等科研机构，累计取得国家发明专利、实用新型专利、著作权、工法、科技创利成果等数百项；与国内多所重点院校以及科研院所建立了“产学研”合作基地。
