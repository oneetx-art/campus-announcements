## 公司
性质:民企 · 行业:机械/制造业

南京恒电电子有限公司成立于1998年10月，是广东盛路通信科技股份有限公司（股票代码：002446）全资子公司。公司是国家级高新技术企业、国家专精特新小巨人企业、江苏省服务型制造示范企业、江苏省企业技术中心、江苏省工程研究中心等。建有国家级博士后工作站、江苏省微波集成电路应用工程中心、南京恒电先进微波技术研究院。公司专业从事微波混合集成电路及其相关组件的设计、开发、生产与服务。产品包括各类微波器件、多功能微波组件、小型机等。公司位列全国微波射频民营企业第一梯队，是雷达部件的核心供应商。
