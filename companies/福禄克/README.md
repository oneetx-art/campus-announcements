## 公司
性质:外企 · 行业:机械/制造业

福禄克（Fluke）研发、制造专业电子测试工具及软件，是美国FORTIVE集团下属全资子公司。创立于1948年，福禄克业务遍及全球100多个国家和地区。福禄克自1978年进入中国市场，与中国的制造业和工业共同成长。福禄克中国集研发、工程、制造、供应链和销售为一体，目前共有18个分公司或联络处，作为区域创新中心，传承经典，持续创新，助力智能制造新未来。
