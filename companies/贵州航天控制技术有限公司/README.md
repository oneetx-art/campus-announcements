## 公司
性质:央国企 · 行业:机械/制造业

贵州航天控制技术有限公司（航天科工十院0612研究所），隶属于中国航天科工集团第十研究院，公司成立于1965年，经过多年发展，形成了以遥测遥控、惯性导航、惯性器件、石油钻控装备、信息技术为典型代表的产业发展格局，初步形成了注（贵州技术中心）+辅（北京研发中心、成都研发中心、西安研发中心）的发展布局，现有员工2000+人，硕博近300+人，是一家航天央企全资企业。
