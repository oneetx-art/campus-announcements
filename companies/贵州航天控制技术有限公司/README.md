## 公司
性质:央国企 · 行业:机械/制造业

贵州航天控制技术有限公司（航天科工十院0612研究所），隶属于中国航天科工第十研究院，公司成立于1965年，经过多年发展，形成了以伺服机构、惯性导航、惯性器件、石油测控装备、信息技术为典型代表的产业发展格局，初步形成了1主（贵阳技术中心）+3辅（北京研发中心、成都研发中心、西安研发中心）的研发格局，现有员工1000余人，硕博300余人，是一家航天高科技企业。
