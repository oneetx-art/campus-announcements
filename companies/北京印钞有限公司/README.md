## 公司
性质:央国企 · 行业:机械/制造业

北京印钞有限公司始建于1908年，是中国近代以来由政府兴建的第一家国家印钞厂，是中国第一家采用雕刻凹印工艺印制钞票和邮票的企业，也是北京市最早的近代工业企业之一。北钞公司隶属于中国人民银行中国印钞造币集团有限公司，是一家以人民币印制为主、集现金综合服务、高端防伪产品设计开发、货币文化服务为一体的现代化大型国有企业，同时还承担了印钞专用机等研制供应以及印钞工程化实验中心、现金机具与鉴别能力检测等职能。
