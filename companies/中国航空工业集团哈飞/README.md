## 公司
性质:央国企 · 行业:机械/制造业

中国航空工业集团有限公司（简称“中国航空工业集团”）是由中央管理的国有特大型企业，经营范围涵盖航空装备、航空研究、运输试验、航空供应链与军贸、通航运营、航空产业金融、航空投资、航空教育、爱飞客、工业制造等产业，下辖100余家成员单位、26家上市公司，员工逾40万人。哈尔滨飞机工业集团有限责任公司（简称“中国航空工业哈飞”）创建于1948年，是我国“一五”时期的156个重点建设项目之一，曾承担和研制生产了我国第一架直升机、第一架轻型喷气轰炸机、第一架大型水上反潜轰炸机等50种机型。改革开放后，相继自主研制生产了直9系列直升机、运12系列飞机，并推出“松花江”、“赛马”等系列汽车产品，建成了年产30万辆的汽车生产线。近年来，公司以聚焦航空主业，加快推进航空产品升级换代，形成了以“AC312、AC352、AC332”民用直升机和“运12E、运12F”固定翼民用飞机为主导的产品谱系，同时，以“一机多型、系列发展”的产品格局，全力满足用户需求。中国航空工业哈飞制造团队，国际权威适航当局认可的具备全机适航取证能力，国内最大的航空复合材料制造基地，国内领先的制造体系，国内最大的航空复合材料零部件生产…
