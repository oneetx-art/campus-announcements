## 公司
性质:民企 · 行业:汽车制造/维修/零配件

三花控股集团创立于1984年，全球雇员人数超36000人，是全球制冷家电、新能源汽车热管理领域的行业领军企业。浙江三花汽车零部件有限公司（简称“三花汽零”）成立于2004年，是上市公司-浙江三花智能控制股份有限公司（股票代码：002050）位列浙江省省属控制股企业。三花汽零专注于汽车领域冷热电转换、温度控制的相关产品和技术的研发，为新能源汽车提供包括场景所需的热管理、变频控制为核心，为新能源汽车提供全场景覆盖的热管理技术解决方案。
