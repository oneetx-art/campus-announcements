## 公司
性质:民企 · 行业:生活服务业

东莞国药成立于1955年，位于粤港澳大湾区几何中心，深耕在“双万”之城东莞，历经70载的辛勤耕耘，现已发展为市内一家实力雄厚的医药销售龙头企业。目前，东莞国药集团旗下拥有全资子公司、控股子公司、参股公司等共100多家，是全国唯一一家地市级网点超过千家的医药零售企业，销售规模稳居全国零售行业前列，成为东莞医药零售行业的翘楚。2024年底，东莞国药获评广东省第一批“广东老字号”。
