## 公司
性质:央国企 · 行业:机械/制造业

航天科工火箭技术有限公司是中国航天科工集团运载火箭总体单位，主要从事固体运载火箭、可重复使用液体运载火箭、轨道航天器、液氧甲烷发动机研发和生产，研制了我国首型车载机动固体运载火箭，实现了我国航天发射十战十捷从液体到固体的拓展，目前多项第一。公司现估值已超百亿元。公司注册地湖北武汉市，设有武汉研发中心（东西湖区）、北京研发中心（北京经开区）、武汉火箭产业园（新洲区）、液体运载机试验中心（宜昌市），锚定建设一流运载火箭总体部和一流航天发射服务公司目标，坚定履行强军首责，践行“固液并举”发展战略，具备完善的固体、液体运载火箭和液体发动机试验能力，拥有国家创新平台，企业获得国家技术“小巨人”等创新高，先后荣获国家科技奖二等奖、军队科技进步奖、湖北省科技进步奖等多项荣誉，现有员工400余人，构建了以院士候选人（公示）、全国劳动模范、国务院特殊津贴、专家等为中坚力量的领军人才为核心，中青年科研骨干为国家高层次水平人才梯队，持续培育航天人才成长沃土。
