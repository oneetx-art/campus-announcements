## 公司
性质:央国企 · 行业:农林牧渔

江西省农发城乡发展集团有限公司是江西省农业发展集团有限公司旗下二级国有企业，前身为1992年经原省体改委批准成立的省级地产公司，2016年战略升级为江西省地产开发集团有限责任公司，2024年正式更名，是省级重点乡村建设服务平台。集团深入贯彻乡村振兴与生态文明建设部署，聚焦山水林田湖草自然资源系统治理核心任务，构建了以全域土地综合整治、农业产业种植、国土空间技术服务为核心的业务体系，致力于打造新时代投建服一体化乡村建设综合服务商
