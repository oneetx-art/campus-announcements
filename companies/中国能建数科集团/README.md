中能建数字科技集团有限公司（简称“数科集团”）是中国能建的全资子公司，是中国能建“数字化转型和科技强企”的主要载体，入选国资委创建世界一流项目示范企业。目前拥有八家直属企业、十余家二级管理企业、二十余家所属综合企业，业务范围覆盖新智能、数字化、新能源、储能、生态环保等领域，现有员工2200余人，工程项目遍布全球80余个国家和地区。
