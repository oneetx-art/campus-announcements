## 公司
性质:民企 · 行业:金融业

中再资产管理股份有限公司（以下简称“公司”）是由中国再保险（集团）股份有限公司于2015年2月发起成立的国内首批保险资产管理公司和唯一具有再保险背景的资产管理公司。注册资本金人民币15亿元。经营范围包括管理运用自有资金及保险资金、受托资金管理及相关咨询等业务。公司秉承稳健审慎的投资理念，推动科学化的配置管理模式，深耕市场，严防风险，构建起了境内外双资产管 理平台，具备多货币、多账户、多市场、多品种投资和服务能力，在固收、权益、另类等投资领域具有丰富经验， 形成了独特的竞争优势， 获投行业连续多年超行业平均水平， 曾获方鼎奖、金牛奖、 金理财奖、 金龙奖、 金融界奖等多项殊荣。
