## 公司
性质:外企 · 行业:智能硬件

宝时得，1994年创立，是一家以全球化视野布局的高端品牌高科技企业，始终致力于工具电动化与智能化的创新探索。集团在全球拥有十五家海外分公司，设立意大利、澳大利亚、苏州与上海四大研发中心，以及苏州、张家港、昆山和越南四大制造基地，综合实力稳居全球电动工具行业前列。
