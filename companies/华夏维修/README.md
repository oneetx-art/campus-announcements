## 公司
性质:民企 · 行业:机械/制造业

华夏飞机维修工程有限公司（简称“华夏维修”）是华夏航空股份有限公司（股票代码：002928）的全资子公司，成立于2019年9月，总部位于重庆，是一家集航空器维修、机队技术管理、改装设计、航空维修培训、航空器喷涂、航材租赁销售等为一体，具有综合性航空维修服务功能的维修公司。公司拥有中国民用航空局（CAAC）、美国联邦航空管理局（FAA）等机构颁发的维修许可证，在重庆主维修基地现有维修机库2个、部附件厂房1个，同时设有西安、呼和浩特、包头、库尔勒、贵阳、天津、衢州等多个维修基地。
