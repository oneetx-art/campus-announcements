## 公司
性质:民企 · 行业:机械/制造业

壹墨环境科技（江苏）有限公司是北京壹墨在长三角区域化布局的重要战略基地。公司拥有50余项核心技术专利，并拥有引以为傲的自主研发装备制造能力。公司深度聚焦以下核心方向，致力于实现水环境治理从“工程化”到“生态化”的跨越：水环境综合治理生态化解决方案研究；城市污水溢流污染控制智能高效技术研发；雨水径流污染控制技术体系研究；污水处理生态工艺设备研发。
