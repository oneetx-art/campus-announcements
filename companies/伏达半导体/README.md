## 公司
性质:民企 · 行业:通信/电子/半导体

伏达半导体（NuVolta Technologies）成立于2017年，专注于电源管理芯片及解决方案研发，尤其在无线充电领域取得了显著成就。产品覆盖无线充电接收和发射芯片、有线快充芯片、通用模拟电源以及汽车电源管理芯片，广泛应用于消费电子、汽车电子和工业医疗等多个领域。核心团队汇聚了行业顶尖人才，分布在合肥、上海、深圳、北京、杭州、韩国、美国等地。
