## 公司
性质:民企 · 行业:机械/制造业

武汉光至科技股份有限公司2018年5月成立于武汉光谷，董事长黄志华博士毕业于清华大学，创始团队拥有深厚的理论设计、技术开发和产品工程化经验。公司主要专业从事脉冲激光器的研发、生产和销售，并提供激光工艺开发和激光器定制服务。公司产品主要应用于新能源、硬脆材料加工、表面标刻与清洗等领域。公司以光纤激光技术和固体激光技术为基础，综合高速电控软件和热控结构技术，陆续推出了光纤MOPA、QCW、光纤红外皮秒和绿光以及固体纳秒紫外等系列工业激光器产品，并具备其它特殊波长科研定制类激光器OEM/ODM开发能力。
