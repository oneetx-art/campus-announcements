## 公司
性质:民企 · 行业:通信/电子/半导体

佳腾电业创立于2006年，是中国首家专注于扁平电磁线研发、生产与销售的国家级专精特新小巨人企业。作为全球唯一具备全尺寸扁线量产能力的供应商，佳腾在全球微小型及中型扁线市场占有率稳居第一，部分细分领域市场份额超60%，业务覆盖全球2000余家客户，其中包括阿斯麦尔ASML、华为、苹果等50多家世界500强企业。顺应新能源汽车产业链蓬勃发展浪潮，佳腾率先突破高压电驱技术瓶颈，成为全球首批、国内首家可提供800V架构电机线材解决方案的企业，目前佳腾已成为路特斯、宝马、奥迪、奔驰、大众、蔚来、斯特兰蒂斯等汽车品牌的项目定点供应商。佳腾致力于通过不断创新为全球供应链提供更多高端材料解决方案，未来将在碳纤维复合材料领域发力，力争成为国际高端材料产业的领航者。
