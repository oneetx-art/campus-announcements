## 公司
性质:民企 · 行业:文化/传媒/广告/体育

深圳华夏艺术中心有限公司成立于1991年9月，属华侨城集团文化板块专业化子公司。2024年7月，华夏艺术中心经营范围进一步扩大，授权运营深圳华侨城当代艺术中心Q.POWER文化艺术中心，运营面积增加到26000平米，场馆数量增加到7个；业务范围增加了艺术展览、新型时尚艺术空间运营，已形成了拥有剧院演出、展览策划、公教活动组织、文综空间运营为一体的多业态文化场馆运营公司。
