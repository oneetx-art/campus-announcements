## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

省广集团成立于1979年，是中国最早成立的广告公司，2010年在A股上市（股票代码：002400），被业内誉为“中国广告营销第一股”。2025年，广东省委省政府明确省广集团为广东省属数字营销工程技术中心。省广集团是中国最具规模的营销集团之一，年度营收超200亿，全球奖项5000+，服务全球知名企业300+家，致力于成为卓越的全球化智能营销集团。
