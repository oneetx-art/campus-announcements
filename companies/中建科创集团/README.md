## 公司
性质:央国企 · 行业:房地产业/建筑业

中国中建科创集团有限公司是中国建筑股份有限公司集团的全资子公司。注册资本1.50亿元，2022年12月在上海成立。公司聚焦建筑行业“碳”和数字化经济领域，坚持市场化、产业化方向，以培育“专精特新”、“高精尖特”企业为重要路径，以实现核心技术自主可控、创建知名品牌为基本要求，打造原创技术策源地，推动技术创新和产业发展。
