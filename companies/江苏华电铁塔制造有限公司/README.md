## 公司
性质:民企 · 行业:机械/制造业

江苏华电铁塔制造有限公司始建于1984年，位于国家级经济开发区-徐州经济开发区，紧邻京福高速公路和京沪高铁，交通位置优越。现隶属于宏盛华源铁塔集团股份有限公司。公司注册资本4135.64万元，拥有现代化厂区200000平方米，是一家集生产1100千伏及以下不同电压等级的输电铁塔（角钢塔、钢管塔、钢管杆）、构支架、微波通讯塔等钢结构产品的专业公司，具备年产角钢塔20万吨，年产复合钢管塔、钢管杆、变电构架4万吨以及镀锌12万吨的生产能力，是承接我国第一条特高压交流试验示范工程的18家厂家之一。公司检测中心是中国电气装备铁塔板块首家获得CNAS认可的无人实验室，标志着其符合ISO/IEC17025国际标准要求，具备国际接轨互认能力。
