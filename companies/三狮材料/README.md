## 公司
性质:民企 · 行业:房地产业/建筑业

浙江三狮南方新材料有限公司（简称“三狮材料”），总部位于杭州市余杭区，是中国建材集团在浙江省设立的区域性专业化商混运营公司，商品混凝土综合产能位居浙江省内第一，是浙江省大型重点工程项目和城市建设的材料主供商。目前，三狮材料旗下成员企业46家，员工总数2100余人，商混产能近4000万方/年，业务主要分布于杭州、宁波、嘉兴、湖州、绍兴、金华、衢州及上海片区，涉及商品混凝土的生产与销售、信息科技等。三狮材料秉持“材料创造美好世界”的使命，持续向高端化、绿色化、智能化转型升级，致力于成为世界一流的商混企业。
