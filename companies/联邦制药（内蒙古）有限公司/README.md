## 公司
性质:民企 · 行业:医疗/医药/生物

联邦制药（内蒙古）有限公司是联邦制药国际控股有限公司（股票代码：HK3933）在国内建设的第五个集医药中间体、人用（兽用）原料药于一体的现代化综合性制药企业，具备完善的质量、环保、安全保障体系。公司位于内蒙古巴彦淖尔经济技术开发区，现有员工6500余人，总投资超过100亿元。内蒙古光大联丰生物科技有限公司是联邦制药（内蒙古）有限公司全资子公司。公司主要产品包括：原料药（阿莫西林、氨苄西林、克拉维酸钾及混粉、他唑巴坦酸等）、化工中间体（6-APA、克拉维酸叔辛胺、青霉素工业盐等），产品远销欧洲、南美等，市场份额50%以上，2023至2024连续两年成为巴彦淖尔市投资第一、产值第一、销售额第一、纳税额第一、就业人数第一的龙头企业，为地区经济繁荣做出了重要贡献。公司配备员工食堂、集体宿舍、单身公寓、家属楼、幼儿园及体育馆等完善的生活设施；自2023年起陆续建成研发中心、技能培训中心、员工活动中心、多功能会议厅（在建）、合成中试大楼（在建）等，大大提升公司员工生活、研发、生产、质量、人才培养各方面核心竞争力，为公司长久发展保驾护航。
