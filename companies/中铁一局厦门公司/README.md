## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁一局厦门公司是世界500强中国中铁成员企业中铁一局的全资子公司，2006年6月诞生于美丽的鹭岛——厦门。公司成立以来，中铁一局厦门公司大力提升市场份额和企业影响力，六次获得中铁一局“优秀企业”，入选2017年中国中铁“三级综合工程公司20强”，成为厦门市建筑施工领域首批“国家高新技术企业”，获批福建省“省级企业技术中心”，成功入选厦门市建筑业领军企业和福建省建筑业龙头企业，荣膺2023年厦门市、2023年度建筑业突出贡献企业，荣登2023年1-12月度建筑业企业10强第三名；现有市政公用工程施工总承包一级资质、建筑工程施工总承包一级资质、水利水电工程施工总承包二级资质、桥梁工程专业承包一级资质、隧道工程专业承包一级资质、机场场道工程专业承包二级、城市及道路照明工程专业承包一级资质、环保工程专业承包一级资质、地基基础工程专业承包一级资质、建筑装修装饰工程专业承包一级资质等，建筑机电安装工程专业承包一级资质、测绘乙级资质等，通过国家质量、环境、职业健康安全管理体系认证。公司业务范围覆盖福建、江西、河南、陕西、浙江、江苏、广东及澳门等地区。
