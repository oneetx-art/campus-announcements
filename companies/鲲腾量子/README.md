## 公司
性质:民企 · 行业:通信/电子/半导体

鲲腾量子起源于中科院量子信息重点实验室，以光量子、窄线宽可调谐半导体激光、非线性频率变换、光学放大等相关核心技术为基础，研制面向光子、原子、离子量子计算和精密测量用高性能可调谐单频激光系统，包括可调谐窄线宽半导体种子激光、半导体锥形放大器、无展宽低噪声光纤放大器、单通和外腔增强频率转换模块；开发各类高质量量子纠缠源及光子干涉模块产品，为开展光量子信息和量子光学的相关科学研究和实验教学提供必需设备；以专业化高水平实现国外同类高端仪器设备的替代，并围绕光量子技术特点，不断拓展量子技术和激光技术应用场景。
