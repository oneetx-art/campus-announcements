## 公司
性质:央国企 · 行业:金融业

浙江省富浙融资租赁有限公司成立于2012年5月，前身浙江省铁投融资租赁有限公司，是全国第九批内资融资租赁试点企业，是浙江省租赁业协会理事单位、中国融资租赁（西湖）论坛常务理事单位、浙商总会金融服务委员会委员单位、浙江省金控企业联合会成员单位。目前公司注册资本金为10亿元，由浙江省国有资本运营有限公司持股66.63%，浙江富浙资产管理有限公司持股15%，浙江省广电集团持股18.37%。
