## 公司
性质:民企 · 行业:机械/制造业

阿维塔（AVATR）是阿维塔科技旗下的高端智能电动汽车品牌，专注于未来出行领域的研发与创新。阿维塔借力于前瞻设计和硬核科技，创造引领未来的情感智能新汽车，打造全球高端智能电动汽车领导品牌。公司总部位于中国重庆，并在上海及德国慕尼黑设有分部。阿维塔立足于长安汽车的智能制造底蕴、宁德时代的电池技术突破，融合了华为在智慧出行领域的前沿技术，构建了“新架构、强计算、高压充电”的全新一代智能电动汽车技术平台。
