## 公司
性质:民企 · 行业:能源/化工/环保

先利达化工建于2003年，是一家经国家农业部和发改委批准的农药原药及制剂定点生产企业，长期致力于作物增产解决方案的研发、推广与新化合物创制。公司以“质量第一，服务为农”为宗旨，产品覆盖杀虫剂、杀菌剂、除草剂、植物生长调节剂及肥料，坚持高效、安全、绿色、环保的品质理念。2023年3月，集团完成股权重组，成立母公司——河南红霸科技有限公司，注册资本人民币7000万元。下设研发中心与销售中心，并全资控股5家子公司，业务涵盖境内外销售、互联网电商以及农药研发生产等领域。目前，集团旗下拥有2家销售公司及3家定点农药生产企业，在郑州白沙工业园区和驻马店高新技术产业开发区建有两大生产基地，总占地约150亩，形成了研、产、销一体化的完整产业链。红霸科技正以清晰的架构和充足的资源，推动集团在农业科技领域的持续发展。
