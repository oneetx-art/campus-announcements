## 公司
性质:民企 · 行业:机械/制造业

北京精雕集团创立于1994年，是一家专注于精密数控机床及精密零部件研发、生产、销售和数控工程服务的高新技术企业，主营产品为精雕精密数控加工中心。为构建和推动集团持续发展的基础资源和运营平台，建立了位于北京的集团总部和核心研发中心，位于廊坊的整机核心制造基地，位于天津的关键功能部件研发和生产基地，以及位于西安的产品研发中心。
