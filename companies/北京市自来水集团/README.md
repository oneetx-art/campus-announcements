## 公司
性质:央国企 · 行业:能源/化工/环保

北京市自来水集团是北京市政府所属的国有独资公司。集团负责北京市中心城区、通州（密云、延庆副中心）、怀柔、门头沟、房山、昌平、大兴、门头沟等郊区新城的供水供应，涵盖供水工程设计、施工、安装，管网抢修等业务。在供水能力、自来水水质、资产规模、技术装备等方面，均居国内同行业领先水平，是目前我国最具影响力的城市供水企业之一。
