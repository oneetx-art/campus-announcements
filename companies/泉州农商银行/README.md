## 公司
性质:民企 · 行业:金融业

泉州农商银行成立于2011年3月，由原泉州市区农村信用合作联社与泉港区农村信用合作联社合并改制而成，网点覆盖全市各县（市、区），是省内第一家由泉州市、辖区设立11家村镇银行，也是一家由泉州市、漳州市、三明市、泉州下辖县（市、区）国有企参股的农商银行。目前下辖53个营业网点（含营业部），先后获评“全国模范职工之家”、“全国巾帼文明岗”、“全国敬老文明号”、“全国金融系统五一劳动奖状”、“全国厂务公开民主管理示范单位”、“全国工人先锋号”、“福建省‘经营管理十强’”、“福建省‘业务发展十强’”等荣誉称号。
