## 公司
性质:民企 · 行业:贸易/批发/零售

广东时光生活科技有限公司（原广州拓客），公司成立于2012年，总部位于广东广州，是一家集产品设计、研发、生产、仓储供应链及线上运营销售于一体的生活科技型电商公司。主营类目：小夜灯类、灯具类、礼品类、3C数码等十多个品类。拥有ONEFIRE（万火）、KUFIRE（酷火）等多个年销售额过亿的自主品牌。ONEFIRE（万火）连续6年，天猫小夜灯类目品牌TOP1。旗下天猫/淘宝/京东/亚马逊/抖音等平台店铺50+家，业务遍及中国、美国、英国、德国、法国、西班牙、意大利、日本等国家。自有10000+平米标准化工厂，单日产能20000件。自建30000+平米生产物流中心，仓储高峰期日处理单量超50W单。专业视觉团队支持，配备3000平米摄影基地+专属签约模特。
