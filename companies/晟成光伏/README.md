## 公司
性质:民企 · 行业:能源/化工/环保

苏州晟成光伏设备有限公司成立于2010年，是京山轻机（000821）的全资子公司，坐落于苏州高新区。晟成光伏主要从事光伏行业智能化装备的研发、制造、销售及服务，不仅为客户提供光伏组件制造整线解决方案，兼容常规、双玻、半片、MBB、OBB、XBC、叠瓦等不同需求，同时也为TOPCON、HJT、钙钛矿等高效电池和硅片制造领域提供相关智能装备以及MES系统。公司业务已经覆盖国内外所有主流光伏企业，产品远销全球30多个国家和地区，累计装机量超800GW，光伏组件自动化产线细分领域市场份额排名第一。自成立以来，晟成光伏已获得“国家级制造业单项冠军示范企业”“国家智能光伏试点示范企业”“国家高新技术企业”“国家级博士后科研工作站”等多项国家重要荣誉，拥有892项知识产权。
