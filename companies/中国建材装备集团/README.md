## 公司
性质:央国企 · 行业:机械/制造业

中国建材装备集团有限公司是中国建材集团有限公司的全资子公司。由中国建材行业拥有70余年悠久历史和设备研制两大甲级设计院——天津水泥工业设计研究院有限公司与合肥水泥研究设计院有限公司战略整合而成，是国务院国资委批准的“国有公司治理型”下属专业化投资集团。拥有从山砂骨料到水泥生产全套专业产线平台，拥有矿山破碎到水泥产出完整流程、全规模的辊压机、立轴辊、辊筛解决方案，以输送机、提升机、装车台及成品库设备、预热器、冷却器、篦冷机、收尘器、堆取料机、包装机、计量设备、粉体工程、电气、智能化、工程等全产业链的专业技术与服务能力。
