## 公司
性质:央国企 · 行业:机械/制造业

哈尔滨锅炉厂有限责任公司创建于1954年，隶属于中国电建集团，是党中央管理的国家关系安全和国民经济命脉的国有重要骨干企业之一。作为中国最早最大的电站锅炉研发与制造基地，哈锅拥有先进的大型装备研制核心技术，创造了100余项行业之最。经过70余年的发展，目前已成为电站锅炉、石化容器、船舰动力等领域优秀的电站解决方案服务商。“十四五”以来，公司形成了“双系统、双支柱”多元支撑、协同发展的现代产业体系，通过实际行动践行“3060”双碳目标。
