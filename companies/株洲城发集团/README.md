## 公司
性质:央国企 · 行业:房地产业/建筑业

株洲市城市发展集团有限公司简称株洲城发集团，是株洲市委、市政府为优化整合城市资源，按照现代化市场化多元化发展格局组建的国有企业，公司总资产规模近1500亿元，国内主体信用评级AAA，主要从事城市建设、城市运营和城市开发三大主业，涵盖产业园区运营、房地产、工程建设、商贸物流、新能源、低空、公用事业、文化旅游、资产运营等业务，2022年首次跻身中国服务业企业500强，连续五年获湖南企业100强，连续四年获评湖南服务业企业50强。未来集团将锚定三四高新美好蓝图，以建设幸福株洲服务美好生活为宗旨，聚焦六大集团整合发展，坚持以经济效益为导向，实施五大发展战略，不断增强企业核心能力，致力于打造国内一流城市综合运营商
