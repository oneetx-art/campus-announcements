福建省海峡信息技术有限公司（简称“海峡信息”）成立于1999年，是福建广电网络集团股份有限公司直属单位。作为国控的企业使命，始终秉承“网络安全领域技术研发和产品销售及安全服务，是国内网络安全行业的先行者、开拓者。公司目前已拥有众多业内一流的信息安全专家以及具有核心自主知识产权的网络安全产品线，建立了新一代云端“云智密”主动防御体系，全面涵盖网络安全、云安全、商用密码、数据安全等安全产品与服务解决方案，为全国数万家单位客户提供网络安全防护。
