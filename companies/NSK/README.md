## 公司
性质:外企 · 行业:机械/制造业

日本精工株式会社（NSK LTD.）成立于1916年，充分利用生产轴承锤炼出的精密加工技术，进军汽车零部件、精密机械产品、电子应用产品等领域。产品广泛应用于传统机械、风电、轨交、家电、医疗以及机器人、高端装备、人工智能、低空经济、新能源汽车、自动驾驶等新兴领域。NSK中国投资有限公司是NSK在中国的总部，全权负责NSK在中国大陆以及香港的生产、技术、销售及运营。
