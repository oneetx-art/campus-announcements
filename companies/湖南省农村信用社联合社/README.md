## 公司
性质:其他 · 行业:金融业

湖南省农村信用社联合社（简称“湖南省农信联社”）成立于2005年，是按照国务院省政府授权，对全省102家农商银行进行管理、指导、协调、服务的省级金融机构。总部在长沙，下辖营业网点3890个，从业人员8.3万人。截至以来，在湖南省委省政府的坚强领导和社会各界的关心支持下，湖南省农信联社坚持深化改革、完善系统管理、优化服务、稳健经营、转型发展，全系统改革发展取得显著成绩。截至目前，全系统各项存款余额1.67万亿元，市场占比18.9%，各项贷款余额1.13万亿元，市场占比14.5%，存、贷款规模及市场份额均居全省银行业金融机构第一位，是湖南农村金融的主力军、地方金融的排头兵、普惠金融的领跑者。
