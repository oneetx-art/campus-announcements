## 公司
性质:央国企 · 行业:IT/互联网/游戏

中兵勘察设计研究院有限公司（简称兵勘院），创建于1952年，是隶属于中国兵器工业集团公司的国家大型综合性甲级勘察设计研究单位，2011年与五洲工程设计研究院重组为中国五洲工程设计集团有限公司。兵勘院通过了ISO质量、环境、职业健康安全管理体系认证和CMA计量体系认证，是国家工商行政管理总局授予的“守合同重信用企业”、中国勘察设计协会授予的“诚信单位”，是国家高新技术企业，企业信用等级为“AAA”级。
