## 公司

北京中冶设备研究设计总院有限公司（简称中冶设备院）始建于1978年，是由原冶金工业部所属国家科研事业单位转制的科技型企业，专业从事钢铁及游乐设施等领域的技术研发、咨询设计、设备供货及工程承包。1999年进入中国冶金建设集团公司，是中国冶金科工股份有限公司的全资子公司，是中国五矿集团有限公司的骨干子企业。
