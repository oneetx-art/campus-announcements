## 公司
性质:央国企 · 行业:金融业

上海黄浦投资控股（集团）有限公司是黄浦区国资委全资的专业化国有资本投资运营平台，成立于2017年3月，是黄浦区政府投资基金的管理平台、新兴产业重要项目的股权投平台、国资国企改革的资本运作平台，拥有近9年的政府投资基金管理经验，与央地国企、国际知名机构、社会资本均形成长期合作，在推动上海国际金融中心建设、外滩金融集聚带建设等方面做出积极贡献。
