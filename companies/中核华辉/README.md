北京中核华辉科技发展有限公司（简称“中核华辉”）成立于2001年6月，是中国核工业集团有限公司旗下企业，由中国核工业建设股份有限公司（股票代码：601611）控股。公司专注于为中核集团及中国核建提供信息化、数字化和网络安全服务，是核工程与民用建造领域信息化解决方案的重要供应商，同时也是国家高新技术企业。
