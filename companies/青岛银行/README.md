## 公司
性质:其他 · 行业:金融业

青岛银行成立于1996年11月，2015年12月3日在香港联交所上市，2019年1月16日在深圳证券交易所上市，是山东省首家主板银行、全国第二家A+H上市银行。2017年起，青岛银行开启综合化、多元化发展之路，先后发起设立青银金融租赁公司，成立青银理财有限责任公司。目前，青岛银行拥有员工人数近5500人，在山东省内设有17家分行205家网点，实现山东省地级市全覆盖。
