## 公司
性质:央国企 · 行业:IT/互联网/游戏

贵州大数据产业集团有限公司（简称“贵州大数据集团”）是贵州省数字经济领域大型国企，共挂“贵州大数据集团”“贵州省数据资产运营有限公司”两块牌子。集团重点围绕“数字基础设施、共性支撑平台、公共服务、公共数据运营主体、数字政府系统建设及运营主体、公共数据和公共资源的国有企业”功能定位，持续强化实体化、市场化、产业化运营，推动数据要素市场化配置改革，构建“数据流通、数据安全、数据应用及数据治理体系”，全力建设全国首个自主可控的省级政务云平台，是贵州省唯一一块具有“数据流通全产业链”的企业。集团在贵州本地运营华为云Stack和苹果iCloud服务，在中国大数据第一城贵阳，与华为、苹果等企业深度合作。
