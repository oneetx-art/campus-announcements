## 公司
性质:央国企 · 行业:能源/化工/环保

云硫矿业是我国最大的露天硫铁矿企业，素有“东方硫都”之美誉，近年获得“国家级绿色矿山”“全国五一劳动奖状”等称号。2015年，云硫矿业成功借壳贵糖股份（000833）上市。云硫主要产品产能：硫精矿120万吨、硫酸52万吨、磷肥20万吨、铁矿粉24万吨、氨基磺酸2万吨。“云硫”牌商标为广东省十佳自主创新品牌、广东省著名商标，硫铁矿、硫酸、磷肥产品为广东省名牌产品。10万吨/年湿法磷酸项目于今年初投产试运行。
