性质:央国企 · 行业:机械/制造业

中国机械科学研究总院集团有限公司是国务院国资委直接监管的中央大型公益类科技企业集团，始建于1956年，提升中国装备制造水平是中国机械总院的神圣使命。拥有18家全资及控股子企业（公司），共有8000余名员工。建有国家重点实验室、国家工程研究中心、国家制造业创新中心、国防科研创新中心等10个国家级、73个省部级创新平台。拥有4个国际合作基地、71个国际/国家的重要学会协会，是国家科技创新体系的重要组成部分。
