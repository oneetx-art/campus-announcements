## 公司
性质:民企 · 行业:机械/制造业

众远新材料成立于2018年，专注于高端金属材料领域，特别是增材制造（3D打印）金属粉末方面。公司构建了涵盖高温合金、模具钢、钛合金、铝合金、医疗健康、能源动力等产品制造应用。公司通过严格的质量管理体系，确保材料“精质量”稳定可靠，致力于成为客户供应链中值得信赖的合作伙伴。公司掌握的VIGA等气雾化制粉核心技术，实现宏观材料、自主可控，并以定制化服务快速响应客户需求，是客户实现稳定生产的技术伙伴。目前，众远拥有230余人的专业团队，建成三座现代化多研发制造基地，年产能规划10000吨。公司与多所高校深度合作，推动产学研融合，已申请专利18项，持续致力于“制造及可持续未来”，以创新为引领，寻找与定制“创造可行技术来项”。
