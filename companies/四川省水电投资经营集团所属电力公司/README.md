## 公司
性质:央国企 · 行业:能源/化工/环保

四川省水电投资经营集团有限公司成立于2004年12月，是四川省委、省政府批准成立的国有大型一类企业，负责投资、经营、管理省级地方电力国有资产，是四川省地方电力系统农网、城网、缺电县、无电地区电力建设项目的总业主，四川省第二大电网公司，四川能源发展集团所属子集团。截至2025年6月底，公司资产总额近900亿元，员工1万余人；拥有全资公司7家、控股公司19家、参股公司16家，其中持股上市公司3家，是四川能投发展（01713·HK）的控股股东，是西昌电力（600505·SH）、广安爱众（600979·SH）的第二大股东。
