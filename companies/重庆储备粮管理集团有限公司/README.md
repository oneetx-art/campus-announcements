## 公司
性质:央国企 · 行业:农林牧渔

重庆市属重点国有企业，成立于2010年2月，负责市级储备粮油的经营管理，承担储备粮油收购、储存、调运、轮换、销售等相关业务。作为重庆市政府调控粮食市场和承担粮食应急保供的主要载体，认真落实国家和重庆市粮食储备政策，紧扣粮食储备主责主业，以“确保储备粮油数量真实、质量良好、储存安全、管理规范，确保储备粮油收得进、管得好、调得动、用得上”为使命，推动绿色储粮、智能化管粮，发挥重庆市粮食安全“蓄水池”和重庆粮油市场“调节器”作用，牢牢扛稳保障地方粮食储备安全政治责任。
