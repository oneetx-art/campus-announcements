## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁隧道局集团建设有限公司是中铁隧道局集团有限公司集中优势资源打造的子公司，隶属于世界500强企业“中国中铁股份有限公司”。公司是经国务院国资委核准的建筑施工类子公司，拥有全国统一装备、技术最先进的隧道及地下工程专业施工设备，具备铁路、公路、市政、水利水电、房屋建筑、机电安装等多领域施工资质，可承担隧道、地铁、机电等工程总承包，同时包括投资、设计、施工、运营等业务，拥有国家高新技术企业、国家铁路工程施工总承包特级资质、市政公用工程施工总承包特级资质等，连续多年获得省部级以上荣誉225项，其中国家科技进步奖2项、省部级以上科技进步奖115项、工法126项、国家级以上工法59项。
