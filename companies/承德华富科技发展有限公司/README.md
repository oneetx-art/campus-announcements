## 公司
性质:民企 · 行业:机械/制造业

承德华富科技发展有限公司成立于1998年，总资产1.2亿元，现有员工230人，公司在国内居于领先地位。应用范围与出口数量方面，玻璃电熔炉的建档、特、新企业；是中国日用玻璃协会理事会单位。公司玻璃电熔炉行业标准的制定者；是国家级专、精、特、新企业；是中国日用玻璃协会理事会单位。公司自动化控制领域的研发人员和技术工人、公司拥有一支专业的设计、安装及售后服务团队，为客户提供全天候的优质技术服务，在山西、四川、广东设立了办事处。公司设计建造的玻璃电熔炉广泛应用于手工器皿、灯饰、乳白餐具、药用玻璃、香水瓶、耐火餐具、太阳能集热管、琉璃瓦、玻璃绝缘子、陶瓷辅料、微晶玻璃等行业。迄今为止，公司累计新建、大修项目超过900台，目前运行中的设备有340台，业务合作单位除西藏外在国内各个地区。
