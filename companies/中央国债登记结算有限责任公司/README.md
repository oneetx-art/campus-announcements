## 公司
性质:央国企 · 行业:金融业

中央国债登记结算有限责任公司（简称“中央结算公司”）是由国务院出资设立的中央金融企业，注册资本125亿元，主要承担债券市场登记托管系统、证券结算系统和信息服务库职能。自1996年12月成立以来，公司忠实履行国家金融基础设施职责，全面深度参与中国债券市场的培育和建设。
