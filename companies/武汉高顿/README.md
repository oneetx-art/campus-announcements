## 公司
性质:民企 · 行业:教育/培训/科研

高顿教育武汉分公司成立于2014年，是高顿集团上海总部外派规模最大的分支机构之一，现坐落于光谷万科中心33-34层（地铁11号线直达，毗邻武汉多所高校，交通便捷）；团队规模超500人，专注ACCA、CFA、CPA等高端财经证书培训及学员实训项目运营。作为华中地区财经教育标杆，我们已与中南财经政法大学、中国地质大学（武汉）、华中农业大学、武汉理工大学、武汉大学、湖北大学、武汉纺织大学、江汉大学等数十所武汉重点高校建立深度战略合作，每年为会计师事务所、头部券商、国有银行等名企输送超千名财经人才；同时依托集团“终身财经教育生态”，为众多武汉财经金融企业提供财务体系培训、人才定制服务，是光谷商圈极具影响力的教育品牌之一。
