## 公司
性质:央国企 · 行业:金融业

恒丰银行是12家全国性股份制商业银行之一，前身为1987年成立的烟台住房储蓄银行。目前，恒丰银行注册资本1112亿元，位居全国银行业第五位。截至2024年末，全行总资产15353.33亿元，各项业务发展势头良好，经营效益稳步提升。在全国设有330余家分支机构，主要分布在北上广深、长三角及沿长江、黄河经济带、环渤海经济带等经济发达地区，其中一级分行及总行直属分行20家。在上海设有资金运营中心、私人银行部专营机构，在青岛设有全资子公司——恒丰理财有限责任公司。恒丰银行武汉分行成立于2017年6月，是恒丰银行在湖北省设立的一级分行。自成立以来，分行立足湖北省区域经济发展，围绕中部崛起、长江经济带建设、“一芯驱动、两带支撑、三区协同”等重大战略，加大企业产业结构升级、普惠金融发展、居民金融服务等方面支持力度，持续提升服务地方经济发展质效。八年来，武汉分行已累计向湖北省重点区域、重大项目、民生工程及相关产业实现投放600亿元。
