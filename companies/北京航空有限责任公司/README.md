## 公司
性质:央国企 · 行业:交通/物流/仓储

北京航空有限责任公司是中国国际航空股份有限公司（以下简称“国航”）的合格控股子公司，根据于国航集团与北京市政府战略合作框架协议精神，于2011年2月组建成立。北京航空有限责任公司经营公共航空运输、公务航空运输业务，以北京大兴国际机场为基地，开展国内、国际客货发运。
