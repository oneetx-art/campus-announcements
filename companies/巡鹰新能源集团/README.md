## 公司
性质:民企 · 行业:能源/化工/环保

安徽巡鹰新能源集团有限公司总部坐落于安徽省合肥市，是集新能源研发、制造、运营、服务和资本整合为一体的集团化公司。集团深耕“能源+经济系统”双碳战略，历经多年发展，业务多个核心板块，成功构建出“从材料-电芯-客户终端-回收池”的完整产业链闭环，是全球少数掌握全产业链制造能力的电池企业之一。集团先后获评国家高新技术企业、国家级专精特新“小巨人”企业、工信部《新能源汽车废旧动力蓄电池综合利用行业规范条件》白名单企业、安徽省首台技术中心、安徽省绿色工厂等多项资质与荣誉。目前拥有超千亩现代化生产基地，在职员工超千人，累计申请1000余项涵盖新能源后市场全产业链的全球专利技术。
