## 公司
性质:民企 · 行业:新能源

特锐德川开电气有限公司（以下简称：“特锐德川开电气”），位于天府之国成都。公司建基于1980年，2015年11月与青岛特锐德电气股份有限公司重组，成为特锐德（股票代码：300001）旗下控股子公司，占地301亩，现有员工1900余人。注册资本金3.471亿元人民币。特锐德川开电气是中国最大的箱式电力设备研发生产基地，是西南最大的智能电气设备研发制造基地，也是国家级高新技术企业、国家知识产权优势企业、四川省首批“贡嘎”百亿企业。公司拥有15万平方米生产厂房、18条精益化生产线，连续五年荣登四川制造业企业100强，整体规模和实力名列西南第一、全国开关行业前五。
