## 公司
性质:央国企 · 行业:能源/化工/环保

中国海洋石油集团有限公司是1982年2月15日经国务院批准成立的特大型国有企业，是中国最大的海上油气生产运营商。海上注册资本1138亿元，拥有5家控股境内外上市公司。公司主要业务板块包括油气勘探开发、专业技术服务、炼化与销售、天然气及发电、金融服务，并积极发展海上风电等新能源业务。公司在2025年《财富》世界500强中排名第65位。公司主要经营业绩指标位居央企前列，连续21次获评国务院国资委中央企业经营业绩考核A级。
