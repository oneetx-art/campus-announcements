## 公司
性质:央国企 · 行业:金融业

遂宁银行成立于1986年，是一家由国家批准设立的国有控股城市商业银行。39年来，遂宁银行始终秉承“奉献金融 富国惠民”的企业使命，以“智造便捷好银行”为发展愿景，以“时刻相伴 遂您心愿”为服务理念，坚持“党建引领、经营稳健、发展务实、结构日趋合理”的价值追求，不断开放、创新、发展，业务经营日臻完善，资本实力稳步提升。目前，遂宁银行已完成在遂宁本土、成都、德阳、绵阳、广安、资阳的战略布局，营业网点及自助银行近80家，成功连接成渝地区双城经济圈核心区域。在近千名经济金融精英的不懈努力下，在为超百万客户提供优质金融产品与服务的进程中，遂宁银行践使命、显担当，相继荣获“中国红十字博爱奖章”“中国银行业竞争力研究报告2024百强”“中国金融行业消费者信赖品牌”“四川慈善奖·最具爱心捐赠企业”“遂宁市招商引资先进集体”等多项荣誉。
