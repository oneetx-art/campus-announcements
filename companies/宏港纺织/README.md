## 公司
性质:民企 · 行业:机械/制造业

福建省宏港纺织科技有限公司成立于2010年11月2日，坐落于国家级开发区——福州新区福清功能区，是一家面向全球市场的省级重点企业。公司总注册资金2.4亿元人民币，总投资约12亿元人民币，占地334亩，是集研发、织造、染整加工及贸易为一体的综合型、大规模、高科技含量的化纤领域高端纺织企业，与众多国际一线品牌如ZARA、H&M、VS、M&S等建立长期合作关系。公司与同一集团旗下的航港针织、鑫港纺机、新宏港纺织、利港新材料、宝港进出口贸易、福华（印尼）纺织构成集经编机械自主研发制造，到高端经编面料、纬编面料、蕾丝面料、运动鞋材面料开发设计、织造，到特殊功能整理加工服务及贸易为一体的一站式经编产业链。
