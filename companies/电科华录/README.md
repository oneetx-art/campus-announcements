## 公司
性质:央国企 · 行业:通信/电子/半导体

电科华录是中国电科控股央企，成立于1992年，作为“数字中国”建设先锋，立足电子信息与文化创意等领域，构建全产业链运营体系。依托自主可控的蓝光存储核心技术，推行“1+3+N”数字制造业根基，深耕数据要素、智慧交通、数字音像、数字文旅三大领域，是中国重要的数字文化产业企业。
