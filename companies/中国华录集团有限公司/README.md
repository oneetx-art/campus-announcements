## 公司
性质:央国企 · 行业:通信/电子/半导体

中国华录集团有限公司是中国电科控股央企，始于1992年，作为“数字中国”建设先锋，立足电子信息制造业根基，深耕数据要素、智慧交通、数字音视频与文化创意等核心领域，构建全产业链运营体系。依托自主可控的蓝光存储核心技术，推行“1+3+N”数字经济战略，业务覆盖全国重点城市并延伸至亚、非、欧三大洲，是中宣部、科技部认定的“国家文化和科技融合示范基地”，曾多次荣获中国电子信息百强企业、国家技术创新示范企业、改革开放40年中国电子行业突出贡献品牌、全国文化企业三十强、国企文化产业领导品牌等荣誉称号，同时拥有极具民族底蕴的文化品牌——“中国唱片（CRC）”，在中国文化传播中发挥了重要作用。
