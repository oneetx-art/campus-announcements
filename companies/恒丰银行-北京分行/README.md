## 公司
性质:央国企 · 行业:金融业

恒丰银行股份有限公司（简称“恒丰银行”）是12家全国性股份制商业银行之一，前身为1987年成立的烟台住房储蓄银行。2003年，经中国人民银行批准，改制为恒丰银行股份有限公司。2019年完成市场化改革股改建账。恒丰银行北京分行作为恒丰银行服务首都经济发展的旗舰分行，于2014年11月19日成立，目前设有2家二级分行，11家同城支行，1家筹备支行。十年来，北京分行积极围绕习近平总书记关于北京“四个中心”城市定位开展工作，适时推出创新产品，引领一流客户体验，逐渐摸索出了一条兼顾效益与风控、速度和质量的特色发展道路。
