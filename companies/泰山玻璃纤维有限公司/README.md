## 公司
性质:央国企 · 行业:机械/制造业

泰山玻璃纤维有限公司是中国建材集团所辖中材科技的全资子公司，是国家高新技术企业、国家技术创新示范企业、国家制造业单项冠军企业、国家智能制造试点示范企业。目前公司拥有泰安总部、邹城公司、淄博公司、太原公司四大生产基地，玻纤及制品产量超150万吨/年，企业在职员工9000余人，总资产250亿元，位居全球第二，是全球高端玻纤产品的主要供应商和服务商。
