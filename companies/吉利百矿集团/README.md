## 公司
性质:民企 · 行业:能源/化工/环保

吉利百矿集团有限公司是一家大型创新型铝业集团，是吉利科技集团新材料（资源）板块的核心企业之一，业务涵盖煤炭、电力、电解铝、碳素、铝精深加工、生态锰等多个领域，并构建了煤电铝一体化、生态锰产业一体化的循环经济产业链。2019年完成混合所有制改革后，吉利百矿集团投资运营企业30余家，员工近9000人。目前，集团已形成电解铝产能130万吨、铝轮毂520万只、发电装机200万千瓦、煤炭产能315万吨、碳素产能100万吨、碳酸锰矿产能33万吨、电解金属锰产能6万吨的产业格局。
