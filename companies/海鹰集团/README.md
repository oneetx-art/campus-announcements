## 公司
性质:央国企 · 行业:机械/制造业

海鹰集团创建于1958年，隶属于中国船舶集团有限公司，是我国第一家水声装备科研和生产骨干企业，在水声装备领域形成了多个“第一”的技术突破。六十多年来，海鹰集团始终践行“水声报国、强军富民”的核心价值观，秉承“传承为本、创新为魂、励精图治、奋发图强”的企业精神，打造了具有鲜明特色的军民融合发展道路。
