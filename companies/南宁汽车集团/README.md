## 公司
性质:央国企 · 行业:汽车制造/维修/零配件

南宁汽车集团创立于2019年，是南宁产投集团全资子集团公司，主为汽车及零部件制造、新能源生态服务、投资与资产管理。截至2025年12月，南宁汽车集团注册资本30亿元，资产总额41亿元，全资、投资企业13家，拥有1个整车生产基地及2个汽车零部件制造基地，业务范围涵盖美国、越南、菲律宾、缅甸、柬埔寨、印度尼西亚、埃及、泰国、阿尔及利亚、韩国等十多个国家和地区。2023-2024年，连续两年荣获“纳税信用A级企业”荣誉称号。
