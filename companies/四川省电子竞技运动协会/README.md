## 公司
性质:社会组织 · 行业:政府/机构/组织

四川省电子竞技运动协会成立于2016年12月12日，是经四川省体育局指导、四川省民政厅批准成立的省级社团法人组织；协会下设四川省电子竞技运动协会高校分会和四川省电子竞技运动协会元宇宙分会。协会以整合全省电子竞技资源为目的，积极配合政府深入挖掘电竞市场价值、聚集电竞产业要素资源，完善电竞产业生态布局、构建“电竞+”产业创新发展格局。通过聚拢四川省电竞各业资源，搭建企业与政府、企业与企业之间的有效沟通桥梁，共同努力使四川成为电竞内容生产者的创想之地、电竞职业俱乐部和运动员的征战之地、电竞爱好者的交流之地。
