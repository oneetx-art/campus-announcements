## 公司
性质:央国企 · 行业:金融业

海南省财金集团有限公司是由海南省政府出资100亿元设立的国有金融资本投资管理公司，于2022年2月18日开业，总部设在海南海口。海南财金集团秉持“市场化、专业化、国际化、规范化、功能化”发展理念，致力于打造“专业化政府基金管理平台、多牌照金融综合服务平台、多功能金融开放创新平台”三大平台，力争成为一家资产规模过千亿、金融牌照多元化、治理体系日趋完善的省级金融控股集团。
