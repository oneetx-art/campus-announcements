## 公司
性质:央国企 · 行业:通信/电子/半导体

江苏曙光光电有限公司隶属于中国兵器工业集团有限公司，坐落于人文荟萃、风景秀丽的历史文化名城扬州，始建于1952年，是集科研论证、设计研发、工艺研究、集成测试、科技总装于一体的国有独资国家重点军工单位、国防科技工业重点企业、国家高新技术企业。公司以图像装备为基础，以光学、信息的发展方向，构建起以激光信息基础、智能化工程、信息处理、图像融合体系，深耕于打造曙光光电信息系统为重点的先进光电信息体，自主研制、智能驾驭显控系统、车辆/舰艇光电信息系统、单兵班组光电信息系统、激光制导系统、微光光电对抗、激光通信、小型化无人平台等七大系统，实现了国内多型激光和光电装备关键核心技术的突破，引领陆军、发展部队等军兵种升级，为陆军、海军、附空、火箭技术武器和现代产品升级提供能用、管用、实用、好用的装备。
