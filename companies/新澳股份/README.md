## 公司

浙江新澳纺织股份有限公司（简称新澳股份），成立于1991年，是一家集羊毛洗毛、制条、染色、纺纱、针织、机织、后整理及成品服饰于一体的毛精纺全产业链企业。公司拥有先进的生产设备和技术，产品涵盖羊毛衫、衬衫、西装、大衣等多个品类，远销欧美、日韩、东南亚等多个国家和地区。
