## 公司
性质:央国企 · 行业:能源/化工/环保

江西钨业控股集团有限公司前身始于1907年，是具有百年历史的江西省属国有重点大型工业企业，集团专注“钨、钽铌锂、稀土”三大核心主产业，高端装备制造、前沿新材料、新能源三大战略性新兴产业。集团现拥有1家上市公司，4家国家级专精特新“小巨人”企业、8家省级“专精特新”中小企业、14家高新技术企业，拥有国家认定企业技术中心等国家级科研创新平台7个，省级科研创新平台25个，设立博士后工作站1个。集团构建了钨矿山、钨冶炼、高端硬质合金及精深加工于一体的完整钨产业链；形成了稀土冶炼分离、稀土功能材料和科研应用一体的产业格局；掌握了智能预脱贫、重介质选矿、高端磁选装备、超细钨粉及碳化钨粉粉生产等采选冶新工艺及成套装备生产技术。从资源勘查开发的前端布局，到精细化冶炼加工的中端提质，再到高附加值产品的后端延伸，百年江钨秉持“让有色更‘绿色’，让有色更‘出色’”的可持续发展理念，始终以赤子之心，熔铸“钨业报国”的信仰，锻造“产业强国”的担当，在有色金属领域不断创新突破，努力打造成为受人尊敬、在行业内有竞争力、员工有幸福感的现代产业集团。
