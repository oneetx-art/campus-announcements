## 公司
性质:民企 · 行业:通信/电子/半导体

安意法半导体有限公司成立于2023年8月，位于重庆高新区西永微电园滨河路168号，注册资金6.12亿美元，由三安光电股份有限公司(占比51%)与意法半导体(中国)投资有限公司(占比49%)共同出资设立，项目占地面积约461.8亩，建设一条8英寸的碳化硅晶圆生产线，主要生产新能源汽车电控芯片、碳化硅晶圆生产于2023年9月开工建设，2024年9月进设备，2024年11月具备点亮条件，2025年2月27日通线试生产。公司将充分利用三安光电在国内碳化硅衬底生长方面的技术沉淀、生产管理经验，与意法半导体在国际MOSFET功率芯片领域的技术领先性和市场品牌优势，强强联合，共同致力于为中国新能源汽车、充电桩、光伏发电、高压直流等领域的芯片应用，提供充裕的保障支持。项目建成后，将形成具有自主知识产权、掌握核心技术、掌握行业话语权，具有重要国际影响力的第三代化合物半导体材料产业生产基地，并引领重庆市快速形成化合物半导体产业集群效应。
