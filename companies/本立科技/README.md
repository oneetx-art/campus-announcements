## 公司
性质:民企 · 行业:能源/化工/环保

浙江本立科技股份有限公司（创业板：301065）是国内领先的专注于清洁生产的化工中间体制造企业，主要从事中间体的研发、生产和销售。公司总部位于浙江省台州湾经济技术开发区，占地面积364亩；在杭州未来科技城设有研发中心，配备超1200平方米的专业实验室。公司拥有国家发明专利25项，实用新型专利6项和软件著作权9项，已建成省级高新技术企业研发中心、省级技术中心和博士后创新实践基地等创新平台。
