## 公司
性质:社会组织 · 行业:政府/机构/组织

重庆一中七十一中学校，位于重庆市沙坪坝小龙坎马道子95号，始建于1964年，是沙坪坝区教委重点打造的一所底蕴深厚、质量优异、特色鲜明的大型单办初中。学校现有教职工132人，市区级骨干教师及学科带头人13人，中高级教师87人，现有30多个教学班，学生近1700人。学校功能教室齐备、硬件设施完善，开设有川剧、蜀绣、古筝、武术、茶艺、花艺、咖啡制作等30余门“和美六艺”特色课程，让学生学有所获，学有所长。2025年，学校正式成为重庆一中教共体的核心成员校，依托重庆一中优质资源，积极探索教育管理、队伍建设、教学教研、人才培养、考核评价“五位一体化”运行机制，在教共体建设上不断踔厉前行，努力促进学校高质量发展。学校办学规模持续扩大，社会美誉度不断提高，成为了沙坪坝区一所新优质初中。
