## 公司
性质:央国企 · 行业:房地产业/建筑业

上海同济城市规划设计研究院有限公司孕于同济百年规划教育，依托同济大学国家一流学科城乡规划学，正式成立于1994年，是全国首批获得“城乡规划编制甲级资质”的规划设计科研机构。30年来始终秉承“求精、做实、解难、创新”的企业精神，探索城市发展规律，为中国高质量城乡发展不懈努力；始终坚持以技术创新为企业特点，在顶尖专家教授引领下持续深耕，为建设学科融合型、青年发展型、创新引领型企业步履不停。目前被评为上海市产教融合建设培育试点企业、上海市高新技术企业、杨浦区百强企业。
