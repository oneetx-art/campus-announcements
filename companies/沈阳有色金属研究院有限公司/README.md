## 公司
性质:央国企 · 行业:能源/化工/环保

沈阳有色金属研究院有限公司成立于1958年，是中国有色集团沈阳矿业投资有限公司出资的从事有色金属资源开发和综合利用研究及相关产品生产的科研机构，隶属于中国有色矿业集团有限公司。拥有博士后科研工作站、辽宁省镍资源开发利用专业技术创新中心、辽宁省矿物材料专业技术创新中心；获得国家及省部级科技奖励60余项；在选矿、药剂、岩矿、湿法冶金、红土镍矿冶炼、分析检测等领域树立了专业特色和技术品牌。
