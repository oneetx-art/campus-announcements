## 公司
性质:央国企 · 行业:通信/电子/半导体

中船（重庆）装备技术有限公司（简称重庆装备）是中国船舶集团有限公司直接管理的二级单位，现与中国船舶集团重庆船舶工业有限公司一体化管理。公司始建于二十世纪六十年代中期，前身是四川省第六机械工业局，经过历次改革调整，现已发展成为拥有13家骨干企业的实体化经营企业集团，是船舶动力配套关键件及机电装备基础零部件重要的“创新中心”和“制造基地”，正着力打造成为动力机电领域创新型领军企业。重庆装备目前资产总额超230亿元，旗下共有13家企业，包含1家科研创新研究院，9家制造类型企业，2个战略新兴产业公司。拥有7家国家专精特新“小巨人”企业、3个国家企业技术中心、3个国家级博士后科研工作站、2个国家工程实验室、5个国家高新技术企业、1个国家级高技能人才培训中心、1个国家级技能大师工作室。现有在岗职工9000余人，专业技术人员2600余人，直接从事研发技术人员1200余人。拥有享受国务院特殊津贴人员19人、全国技术能手3人，集团级及以上各类专家38人。
