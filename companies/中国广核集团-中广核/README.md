## 公司
性质:央国企 · 行业:能源/化工/环保

中广核核电运营有限公司（简称“运营公司”，英文简称“CNOC”;）是国内大型的专业化核电运维服务商，于2012年8月成立，注册资本1亿元人民币，员工总人数2700多人。 经过10年的快速发展，运营公司已逐步建立了九大专业化产品和能力，分别是：维修服务、备件管理服务、“8+1”重大设备管理、生产准备技术服务、培训服务、环保服务、核应急服务核电独立安全监督评估、招标（管理）中心。近年来，公司在“向技术进步要效益，向管理提升要效益”理念指引下，持续打造以核电特殊高端维修能力为龙头的核心能力。在检修领域，现已开发出核燃料组件修复、主泵维修、电仪设施可靠性与老化检测、核级焊接维修等特色产品，并在战略备件统一管理、生产运营管理体系ERP解决方案、核燃料装卸料培训等领域输出成熟产品，具备了在确保安全的基础上，面向全国、跨地区、多基地同时提供多个检修、备件管理、生产准备、培训等服务的能力。
