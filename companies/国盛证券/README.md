## 公司
性质:央国企 · 行业:金融业

国盛证券成立于2002年12月，2016年4月成为国盛金融控股集团股份有限公司全资子公司，注册资本46.95亿元。公司注册于江西南昌，在上海、深圳、北京设立业务总部。2022年10月，在江西省委、省政府的高位推动下，江西国资收购国盛金控，完成了国盛金控股东变更，实现了国盛证券回归江西省属国有企业。
