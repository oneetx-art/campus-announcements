## 公司
性质:央国企 · 行业:金融业

福建海西金融租赁有限责任公司经原中国银保监会批准，由厦门银行发起和控股，于2016年9月正式成立，注册资本金12亿元，主体信用评级AAA级，是持有福建省首张金融租赁牌照的全国性金融机构。海西金租自成立伊始，便坚持深耕福建，发挥金融租赁融资融物的优势，服务实体经济，回归金融租赁本源，目前已建立完善的金融租赁产品和服务体系。公司业务主要聚焦福建、江苏和川渝区域，产业选择上聚焦以“新能源”为代表的大直租方向，以及以“工程机械”“机加工”为代表的中小直租方向；同时，积极挖掘地方国有企业直租业务，助力区域经济发展。海西金租坚持市场化的经营理念，建立科学高效激励机制，并致力成为一家“深耕福建、面向沿海，服务实体、特色两岸，打造价值领先”的金融租赁公司。
