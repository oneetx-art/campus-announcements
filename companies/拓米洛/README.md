## 公司
性质:民企 · 行业:机械/制造业

TOMILO成立于2014年，专注于高端环境试验设备的研发、生产及销售，为客户提供产品老化试验设备与环境可靠性测试设备及解决方案。公司厂房面积25,000㎡，具有完备的组织架构，售前支持、销售、研发、制造、售后服务、财务人事等部门，共计职工600余人；拥有一支强大的技术研发队伍，拥有专业研发技术人员150多人，其中博士及研究生学历30人以上，同时与浙江大学、西安交通大学、上海理工大学开展深度产学研合作。公司先后获得国家级高新技术企业、江苏省专精特新小巨人企业、江苏省工程技术研究中心、江苏省首台（套）重大装备、通过知识产权管理体系认证、ISO9001、ISO14001、江苏省瞪羚企业、苏州市独角兽培育企业、苏州市首批标准化实践基地等资质荣誉。公司主要产品涵盖恒温恒湿试验箱、快速温变试验箱、冷热冲击试验箱、步入式温湿度试验箱、整车环境舱、冷水机及直冷机等。这些设备广泛应用于新能源汽车、消费类电子、光伏储能和半导体等领域。
