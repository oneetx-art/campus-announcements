## 公司
性质:央国企 · 行业:IT/互联网/游戏

深圳数据交易所（以下简称“深数所”）的设立，是深圳市委、市政府坚定落实《深圳建设中国特色社会主义先行示范区综合改革试点实施方案（2020-2025年）》等文件精神、深化数据要素市场配置改革任务的关键举措。在深圳市委、市政府指导下，推动数所于2022年11月5日正式挂牌并持牌运营，深数所主要为企业化发展，交易平台为注册、融合创新、促进新型生产力发展，为高质量发展，营造数据安全合规的服务环境，加快打造成为数据要素探索应用场景大规模赋能流通的可行路径，打造适应数字经济发展的数据要素市场化交易平台，积极探索适应数字经济发展的全国数据要素配置示范路径。
