## 公司
性质:民企 · 行业:医疗/医药/生物

浙江京新药业股份有限公司（证券代码：002020）成立于1990年，是一家集研发、生产、销售于一体的医药上市公司，主营业务包括化学制剂、原料药、中药及医疗器械。公司以“精心守护健康”为使命，遵循“做强精神药品，发展医疗器械”的经营方针，致力于成为中国精神神经、心脑血管领域的领先者。公司分设新昌、杭州2个总部，3个研发基地（上海、杭州、新昌），7个生产基地。公司是国家重点高新技术企业，拥有国家级企业技术中心、博士后科研工作站、省级重点企业研究院、省级高新技术企业研究中心，截至目前，公司注册资本8.6亿元，总资产79亿元。
