## 公司
性质:央国企 · 行业:机械/制造业

成立于1954年，隶属于中国航空工业集团，拥有4家控股子公司，1400余人在职员工，拥有国家高新技术企业资质、国家认定企业技术中心、博士后工作站、国家级实验室以及电力电子系统、照明系统等专业级实验室，是国内领先的航空照明与控制、电力电子、综合告警、模拟仿真等系统解决方案提供商，航空装备现代产业链照明系统优势单位。
