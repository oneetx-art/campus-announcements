## 公司
性质:民企 · 行业:金融业

广东惠东农村商业银行股份有限公司（以下简称“惠东农商银行”）于2013年10月正式成立，前身是始创于1953年、有着七十年历史的惠东县农村信用合作联社。惠东农商银行总行设在惠东县，地处广东省东南部沿海，毗邻香港、深圳，是粤港深澳“一小时经济圈”门户；交通便捷，深度融入粤港澳大湾区生活圈；环境优美，有双月湾、海龟湾、巽寮湾等著名旅游景点；新材料、新能源、大数据等战略性新兴产业发展势头强劲，是一个宜居宜业的城市。惠东农商银行在岗从业人员600余人，营业网点40个，是惠东县营业网点分布最广，从业人员最多的本土法人银行之一。一直以来，惠东农商银行在广东省联社、地方各级政府和有关监管部门的支持指导下，始终坚守“支农支小、服务三农”的初心，深入推进农村金融（普惠）户户通工程，抢抓机遇，开拓创新，各项业务实现了快速发展，总资产达280亿元，存贷款规模、金融服务覆盖面、支农支小满足率、地方税收贡献度等方面稳居全县金融机构前列。
