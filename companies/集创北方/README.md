## 公司
性质:民企 · 行业:通信/电子/半导体

北京集创北方科技股份有限公司成立于2008年，是一家国际领先的显示芯片设计企业，致力于成为全显示控制解决方案领跑者。公司现已拥有全品类显示驱动芯片、电源管理芯片、SoC芯片、车载芯片等产品系列，可广泛应用于移动终端、可穿戴设备、户内外超高清显示屏、AR/VR、工业、车载、医疗等领域场景。集创北方相关产品已应用于抗战胜利70周年阅兵、新中国成立70周年阅兵、建党百年庆典晚会、巴黎奥运会、北京冬奥会、央视春晚、卡塔尔世界杯等重大事务中，在显示芯片领域建立了较高的品牌知名度及市场地位。公司还多次独立承担或参与国家重大科研项目，包括国家科技部863项目、国家科技重大专项项目、国家重点研发计划项目等，为解决我国半导体显示产业“缺芯少屏”局面下的“缺芯”问题做出了重要的贡献。集创北方LED显示驱动芯片市占率连续五年排名全球第一，智能手机LCD TDDI，大尺寸DDIC、面板电源管理芯片市占率均位列大陆厂商第一名。截至到2025年6月底，公司在申请专利共2573件，曾多次荣获“国家知识产权优势企业”、“北京高精尖产业设计中心”等荣誉。
