## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁十九局集团有限公司是世界500强中国铁建所属中央企业，前身是中国人民解放军铁道兵第九师，组建于1949年8月，1984年1月集体转业并入铁道部，2001年12月企业改制现名称。中铁十九局总部位于北京经济技术开发区，拥有“六特六甲”资质，业务涵盖工程承包、规划设计咨询、投资运营、房地产开发、物资物流及其他新兴产业等领域，分布在全国除港澳台以外的所有省、直辖市、自治区以及海外29个国家和地区。现有员工1.5万余名，享受国务院政府特殊津贴专家5名，拥有各类注册执业资格人员3500余名，年产值600亿元以上。
