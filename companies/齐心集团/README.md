## 公司
性质:民企 · 行业:通信/电子/半导体

齐心集团（股票代码：002301）始创于1991年，专注政企采购服务30余年，齐心集团于2009年在深圳A股成功上市，是中国B2B办公物资服务和SaaS云视频的龙头企业。 齐心集团以企业运维物资集采为核心，以高附加值商品供应链和全链路数字化为底座，打造场景化、全产链、数智化的企业服务平台，通过持续叠加商品品类与服务，齐心集团不断满足企业级客户的一站式采购需求。
