## 公司
性质:民企 · 行业:快速消费品

青海互助天佑德青稞酒股份有限公司成立于1992年，地处“世界青稞酒特色产区·中国青稞酒之源”，从事青稞酒的研发、生产、销售，主营“互助、天佑德、八大作坊、永庆和、世义德”等品牌，主导产品含“天佑德中国青稞酒之源”系列、“星级系列”、“高原系列”、“出口型系列”、“冰系列”、“生态系列”等。目前在册员工2000多人，是青海省“绿色食品工厂”、全国就业与社会保障先进民营企业，也是全国青稞酒行业的龙头企业。2011年12月22日，公司在深圳证券交易所上市，证券简称是天佑德酒，证券代码是002646。
