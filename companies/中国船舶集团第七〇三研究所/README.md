## 公司
性质:事业单位 · 行业:教育/培训/科研

中国船舶集团有限公司第七〇三研究所成立于1961年6月，是我国唯一从事大中型船舶主动力研制的科研事业单位，是集研发、生产、系统集成、试验验证、装备供货及全寿命一体化保障于一体的综合性研究所。三所现有员工2000余人，其中副高职及以上人员900余人，硕士研究生及以上学历800余人，拥有工程院院士1人，经过多年的培养，全所已形成一支老、中、青相结合的强有力的科技人才队伍。七〇三所本部设在哈尔滨，在无锡设有分部。近年来，七〇三所以本部为核心，形成了广纳贤才、近悦而善的发展格局，目前正奋力建设世界一流船舶动力及能源装备创新型研究所。
