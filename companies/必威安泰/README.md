## 公司
性质:民企 · 行业:医疗/医药/生物

内蒙古必威安泰生物科技有限公司成立于2008年8月，位于呼和浩特市和林格尔乳业开发区，占地120亩，注册资本1.25亿元。公司专注于生物制品研发生产，建有符合GMP标准的新型疫苗车间，配备国际先进仪器设备及实验动物中心，拥有7500平米进口SPF级养猪生产线，年产20亿毫升，覆盖多种动物领域。公司被认定为自治区“企业研发中心”“重点龙头企业单位”“企业技术中心”和国家“高新技术企业”，“口蹄疫疫苗标记疫苗”获全国商业科技进步一等奖。2024年，瑞普生物控股后，公司构建全生命周期质量管理体系，获多项国际权威认证，包括ISO9001、ISO14001、ISO45001、ISO22001及兽药GMP、CNAS、GCP、GSP等。
