## 公司
性质:央国企 · 行业:房地产业/建筑业

企业成立于1958年，现已发展成为具有电力工程总承包能力的综合性大型企业，是世界五百强中国电力建设集团有限公司在闽骨干企业，海西能源建设的龙头企业。公司具有电力工程施工总承包壹级资质，可广泛开展对外承包工程经营、工程施工总承包、专业承包、工程监理、检测调试及建设管理、咨询服务等业务。已承建各类发电机组近200台，装机容量突破3000万千瓦；完成各等级输变电工程300余项，输电线路20000多公里；工程分布全国22个省（市、自治区），海外工程遍布亚洲、南美、非洲、欧洲近20个国家，在菲律宾、孟加拉、印尼、巴西、肯尼亚等地建立了海外分支机构。
