## 公司
性质:央国企 · 行业:房地产业/建筑业

株洲市城市发展集团有限公司（简称“株洲城发集团”）是株洲市委、市政府为加快城市建设，优化整合城市资源，按照现代化、市场化、多元化发展格局组建的国有企业，公司总资产规模近1500亿元，国内主体信用评级AAA，主要从事城市建设、城市运营和城市发展三大主业，涵盖产业园区运营、房地产、工程建设、商贸物流、新能源、低空、公用事业、文化旅游、资产运营等业务。2022年首次跻身“中国服务业500强”，连续五年获评“湖南企业100强”，连续四年获评“湖南服务业企业50强”。 未来，株洲城发集团将锚定“三高四新”美好蓝图，以“建设幸福株洲，服务美好生活”为宗旨，聚焦“清水塘、物流、公用事业、建投、运营、文旅”六大子集团的整合发展，坚持以经济效益为导向，重点实施效益优先、风险防控、改革转型、项目为王和党建引领“五大战略”，防风险、抓改革、强管理、增效益，加快培育企业发展新质生产力，不断增强企业核心功能和核心竞争力，致力于打造国内一流城市综合运营服务商。
