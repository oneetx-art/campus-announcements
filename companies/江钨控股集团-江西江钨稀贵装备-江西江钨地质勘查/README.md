## 公司
性质:央国企 · 行业:机械/制造业

江西钨业控股集团有限公司前身始于1907年，是江西省属国有重点大型工业企业，以钨、钽铌锂、稀土为三大核心主产业，融合高端装备制造、前沿科研创新、贸易服务、资源循环再生等产业。集团拥有1家上市公司，4家国家级专精特新小巨人企业、8家省级专精特新中小企业、14家高新技术企业，拥有7个国家级科研创新平台、25个省级科研创新平台，设立博士后工作站1个。旗下江西江钨稀贵装备股份有限公司是集团唯一上市公司，办公位于江西省南昌市高新区，从事磁选装备研发生产销售，产品国内强磁选机市场占有率超70%，出口海外获欧盟CE认证。江西江钨地质勘查有限公司是集团全资子公司，办公位于江西省南昌市高新区，是集团唯一专业地质勘查综合技术服务单位，承担有色金属找矿、资源评价等工作，对外承接地勘技术项目
