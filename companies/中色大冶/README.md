## 公司
性质:央国企 · 行业:能源/化工/环保

大冶有色金属集团控股有限公司（简称“中色大冶”），系中央企业中国有色集团内最大的出资企业，公司始创于1953年，文化传承的“五朵”黄矿，有3000多青年，属于国家“一五”期间156个重点项目之一，是一家集地勘、采矿、选矿、冶炼、加工等为一体的国有特大型铜业联合企业。公司现有8家直属单位、8家全资子公司、14家控股子公司、15家参股子公司和海外非洲等多个基地。
