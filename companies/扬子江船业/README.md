## 公司
性质:民企 · 行业:机械/制造业

扬子江船业是一家以船舶制造为主业，航运、新能源综合的大型企业集团。公司最早起步于1956年的江阴船舶合作社，是国内规模最大的民营造船企业之一，也是第一家在新加坡主板上市的中国民营造船企业。
