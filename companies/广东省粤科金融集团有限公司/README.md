## 公司
性质:央国企 · 行业:金融业

广东省粤科金融集团有限公司是广东省人民政府授权经营的国有企业，是国内最早成立的创投机构之一，也是国内首家省级科技金融集团，着力打造服务广东科技创新的重要平台。截至2024年12月底，集团注册资本116亿元，总资产504.97亿元。粤科系基金规模1398.19亿元，累计为3000多家科技企业提供投融资服务，投资186家企业成功IPO上市。
