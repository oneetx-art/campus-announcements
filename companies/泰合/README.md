## 公司
性质:民企 · 行业:机械/制造业

东莞泰合复合材料有限公司（简称TTC），创建于2003年，为全球顶级自行车品牌提供高品质的车架、前叉及配件等产品，致力于创造更美好的骑行体验。公司总部位于东莞黄江，坐拥黄牛埔和大屏嶂两大森林公园，现有员工4000余人，拥有3个制造中心（东莞、柬埔寨、越南），1个研发中心，1个金融中心。TTC创造了全球之最—599g最轻量碳纤维自行车车架，与SCOTT、Merida、Ridley、Cannondale等知名品牌合作多年，产品遍布亚洲、欧洲、北美和南美等区域。TTC不仅是碳纤维自行车行业引领者，更是骑行文化与创新科技的领跑者！
