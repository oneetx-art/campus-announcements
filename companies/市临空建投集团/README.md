## 公司
性质:央国企 · 行业:房地产业/建筑业

杭州市临空建设投资集团有限公司（以下简称市临空建投集团）成立于2022年12月5日，是杭州市政府直属国有企业，注册资本金100亿元，是杭州市政府按照“一个主体、加一个平台、一套班子”的总体架构，发挥“工作主体+生活配套+产业引导”的复合功能，组建作为“临空经济示范区14.72平方公里范围投资建设和开发经营平台”，主要承担临空经济示范区投资、建设和运营管理。成立以来，集团实行市场化、规范化的投融资和运营，建立产业基金与政府以投促产的投资机制；确立“开发建设、城市会展中心及配套、产业招商、临空科技金融、全域数字商贸物流港等一批标志性、引领性重大项目建设运营，全力推动临空经济示范区建设成为‘港产城’深度融合的现代航空都市区。
