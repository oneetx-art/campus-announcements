## 公司
性质:民企 · 行业:能源/化工/环保

赣州腾远钴业新材料股份有限公司（以下简称腾远钴业），成立于2004年，是一家集科研、生产、贸易于一体的现代化企业，是新能源汽车锂电池及3C消费电子产品（手机、平板、笔记本电脑）电池的核心材料供应商，是全球新能源产业链上的重要成员。作为一家全球新能源产业链上的跨国企业，腾远钴业布局赣州、上海、香港、刚果金（非洲）等地区，国内外总计3200余人。公司于2022年3月成功在创业板上市，股票代码：301219。
