## 公司
性质:央国企 · 行业:机械/制造业

中国航天科工二院二〇八所成立于1983年8月30日，是航天工业系统第一家科技情报专业研究所。主要从事航天防务情报战略研究、信息资源建设与服务、知识管理研究、科技文化传播、数字化研究与咨询设计、管理信息化系统开发与实施、网络安全与系统运维、系统集成与产品研发、人力资源咨询与服务等。
