## 公司
性质:央国企 · 行业:机械/制造业

南通中远海运船务工程有限公司隶属中国远洋海运集团旗下的中远海运重工有限公司，专业从事船舶和海工修理改装业务40余年，拥有配套完善的水上、陆上设施施、船舶配套服务经验丰富、业务精湛的工程技术设计、项目管理和生产技能工人团队，致力于为全球客户提供优质的船舶和海工修理改装服务。启东中远海运海洋工程有限公司隶属中国远洋海运集团旗下中远海运重工有限公司，是中远海运集团系统内唯一一家专门从事海洋工程装备和模块制造的现代化大型国有企业。作为中国海洋工程装备制造业的开拓者，为海上清洁能源装备全产业链资源整合者提供一体化解决方案的服务商。
