## 公司
性质:民企 · 行业:机械/制造业

河南空天新材料研究院有限公司成立于2021年9月，总投资5亿元，总建筑面积95450.8㎡，是郑州轻研合金科技有限公司为建设河南省高性能轻合金创新中心及配套轻合金加工材中试线项目而成立的全资子公司，拥有河南省高性能轻合金创新中心和河南省航空航天轻合金工程技术研究中心两大创新研发技术中心。采用“大学基础研究+研究所试制+公司产业化”的产学研科创经营模式，结合新材料1-9级成熟度的开发历程，采取“一流科研平台+先进技术+优秀人才+高端产品”四轮驱动企业发展模式，致力于高性能有色金属材料的研究开发、生产销售、技术服务。
