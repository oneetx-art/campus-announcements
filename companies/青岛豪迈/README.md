## 公司
性质:央国企 · 行业:机械/制造业

公司成立于2007年，占地366亩，注册资金4.35亿元，是上海华银控股集团有限公司全资子公司，属央企上市公司，拥有国际先进自动化生产线设备500余条，主要产品为±1100kV及以下电压等级的输电线路角钢塔、钢管杆、钢管塔等，变电构支架、广播通信塔和港口机械、钢结构等产品，是国内最早参与特高压建设的13家单位之一。经过多年来经营发展，目前，公司已形成了以输电线路铁塔为主体，融资租赁项目、港口机械、钢结构业务多元化发展体系。同时凭借可靠的产品质量和优质的售后服务，公司产品覆盖全国各地，并远销至埃塞俄比亚、阿富汗等多个海外国家和地区。公司先后获评“青岛市级企业技术中心、青岛市“重合同，守信用”企业、“AAA”信用等级企业、百强企业等荣誉称号。多项产品（技术）获得行业和地方专项奖励。
