## 公司
性质:其他 · 行业:医疗/医药/生物

宁夏伊品生物科技股份有限公司成立于1999年，是一家国有控股混合所有制企业，经过20多年的努力，已发展成为具有行业竞争优势的生物制造领军企业。伊品生物2025年营业收入160.01亿元，公司拥有八家子公司，分布在宁夏、内蒙古、黑龙江、新加坡、荷兰等地，公司拥有四大核心产品板块：动物营养（赖氨酸、苏氨酸、蛋氨酸、色氨酸、磷酸二氢钙、复合调味料等）、肥料类（有机肥、菌肥、土壤调理剂等）、新材料类（生物基PDA、尼龙盐溶液及切片等），销售覆盖全国30余省市自治区，远销海外100+国家。
