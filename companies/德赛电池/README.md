## 公司
性质:民企 · 行业:机械/制造业

惠州市德赛电池有限公司，成立于2003年10月23日，为深圳市德赛电池科技股份有限公司的全资子公司，母公司在深交所主板上市（股票代码：000049）。公司致力于锂电池相关产品的研发、制造与销售，不断追求电池核心技术的创新和突破，同时，积极开展高端电子产品的智能装配业务，是电池行业领先的锂电芯开发设计与高端封装技术、高端智能硬件装配工艺技术，建有现代化的自动化生产工厂和高端的电池性能测试实验室。公司产品广泛应用于智能手机、笔记本电脑、医疗仪器、电动自行车、平衡车、汽车启停、无人机、储能、智能家居等终端产品和设备。致力于成为全球一流的新能源解决方案提供商及相关电子产品专业制造商。
