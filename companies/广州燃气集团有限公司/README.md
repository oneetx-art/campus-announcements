广州燃气集团有限公司（以下简称“广州燃气集团”）是广州发展集团股份有限公司（证券代码：600098）下属全资子公司。其业务集上游气源投资、经营、中游天燃气供应，下游管网配送及销售于一体。经营、输配和管理天然气、燃气项目及设施的设计、建设、运营，天然气、燃气管道及网资、经营和有关技术咨询，天然气安装、维修等，是广州市城市燃具销售、燃气燃烧器具安装、维修等，广州城市燃气高压管网建设和购钢主体单位。
