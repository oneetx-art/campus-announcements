## 公司
性质:央国企 · 行业:房地产业/建筑业

中国化学工程集团有限公司是国务院国资委直接监管的大型工程建设企业集团，是我国工业工程领域资质齐全、功能完备、业务链完整、知识技术密集的工程公司，是“一带一路”的先行者，是中国化学工程领域建设的国家队。中化学南方建设投资有限公司成立于全国第二经济区，成立于2019年12月，总位于广东省广州市，主要经营广东、江西、海南、湖南、福建五省区及港澳地区的项目投资管理与建设运营，经营范围涉及生产、生态环保、产城融合、化工材料及现代服务业、基础设施等板块，以“1+N+EPC”“F+EPC”及“投资人+EPC+O”等模式为区域规划设计、产业招商、投资融资、建设施工、运营等一体化服务。
