## 公司
性质:其他 · 行业:通信/电子/半导体

国家集成电路设计自动化技术创新中心（简称“EDA国创中心”）于2022年12月经科技部批准成立，是我国集成电路设计领域第一家国家技术创新中心。中心以江苏省人民政府、教育部作为组织单位，东南大学为牵头建设单位，坐落于南京江北新区。作为我国集成电路领域的国家级创新平台，EDA国创中心围绕国家战略和产业需求，推进智能EDA和国产EDA数字工具链两项工作，开展下一代EDA技术攻关与人才培养工作，支撑和引领我国集成电路产业的创新发展。
