## 公司
性质:民企 · 行业:通信/电子/半导体

中国电子产业工程有限公司（以下简称中电易联）成立于1989年，是中国电子信息产业集团有限公司的全资子公司。公司总部位于中国北京，是国家国防电子行业“走出去”的引领者和网信产业的重要对外合作平台。公司战略重点聚焦防务电子、信息工程等主业，在国家政策支持引导下，为全球客户在电子信息领域提供咨询、建设和服务，业务内容涵盖信息感知、信息传递、信息处理和辅助决策等多个方面。目前，公司业务遍及全球160多个国家和地区，在23个国家和地区设有分支机构。公司秉承一贯的诚信理念，服务国家战略、立足行业发展，坚持互惠互信、坚持合作共赢，着力与合作伙伴一同构建平等开放的产业生态体系。
