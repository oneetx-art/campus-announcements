## 公司
性质:事业单位 · 行业:教育/培训/科研

中国科学院上海技术物理研究所创建于1958年10月，是我国最早从事红外科学与技术研究的单位之一，主要研究领域包括红外物理与材料、红外探测与感知技术、遥感与空间光电技术、微光机电技术、辐射度量计量技术等，是集基础研究、应用基础研究、工程技术研发和系统集成于一体的综合型研究机构。
