中铁隧道局集团有限公司工程测量试验分公司（试验检测有限公司）成立于1980年，前身为铁道部隧道工程局试验室、工程试验分公司。2017年随集团总部搬迁至广州南沙，2020年4月资源，正式更名为工程测试试验分公司，整合了测量业务资源，集团测量总队划归测试分公司，全面涵盖铁路、公路、建筑工程等领域。
