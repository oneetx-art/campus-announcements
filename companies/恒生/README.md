## 公司
性质:民企 · 行业:IT/互联网/游戏

恒生电子是一家以“让金融变简单”为使命的金融科技公司，总部位于中国杭州。1995年成立，2003年在上交所主板上市，在北京、上海、深圳、武汉、南京以及香港、新加坡等地设有研发中心和子公司。恒生聚焦金融行业，致力于为证券、期货、基金、信托、保险、银行、交易所、私募等提供整体解决方案和服务。恒生已连续17年入选FINTECH100全球金融科技百强榜单，2024年排名第22位，位列亚洲企业第一。
