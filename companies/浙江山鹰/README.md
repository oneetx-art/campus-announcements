## 公司
性质:民企 · 行业:机械/制造业

浙江山鹰纸业有限公司成立于2002年5月，是连续十年蝉联中国500强及中国轻工业造纸十强的山鹰国际控股股份公司全资子公司，其注册资本29.86亿元。公司发展至今共有六条造纸生产线，年产瓦楞纸260万吨，产值近百亿。主要产品包括箱板纸、瓦楞纸、白面牛卡纸及涂布白面牛卡纸。同时配套总装机容量为67MW自备热电厂、日处理量8.5万吨污水处理厂。作为龙头企业，亦是海盐县唯一一家省级大学生就业实习基地。
