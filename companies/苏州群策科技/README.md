## 公司
性质:民企 · 行业:通信/电子/半导体

苏州群策科技有限公司是欣兴集团在苏州设立，以设计、研发、生产、销售各类载板及高密度互连基层板的公司。公司成立于2005年，位于苏州工业园区凤里街160号，注册资本13.9亿人民币，员工3500余人。公司主要产品为晶圆级“IC封装载板”，广泛应用于各类电子通讯产品、物联网、高速运算芯片、5G基站等，客户分布在中国大陆、香港、日本、美国、欧洲等世界各地。公司相继通过ISO9001、ISO14001、IATF16949、ISO45001、QC080000等国际认证资格。公司荣获“亚洲最佳企业雇主奖、品质合作优秀供应商、省级高新技术企业、省级企业技术中心、省级智能车间、市劳动和谐企业、5A级劳动保障信誉单位”等多项荣誉称号。
