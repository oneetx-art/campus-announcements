## 公司
性质:央国企 · 行业:金融业

浦发银行（全称上海浦东发展银行股份有限公司）是1993年1月9日成立的全国性股份制商业银行，总部位于上海，在境内外设立42家一级分行、1700家营业机构，覆盖境内所有省级行政区域并开设香港、新加坡、伦敦三家境外分行，形成以银行集团为主体，涵盖信托、基金、理财、金融租赁、境外投行、科技银行、货币经纪、科技公司等多个行业的经营格局。
