## 公司
性质:央国企 · 行业:房地产业/建筑业

中核华辰建筑工程有限公司（以下简称“公司”）是中央直管的国有重要骨干企业-中国核工业集团有限公司（以下简称“中核集团”）的一类企业。注册资本金4.46亿元，主要从事勘察、设计、工程咨询、建筑施工、机电安装、装饰装修、钢结构工程、市政公用工程、机电工程安装、地基与基础工程、建筑幕墙工程、建筑智能化工程、石油化工工程、核工程、钢结构等多个施工总承包一级和专业承包一级资质；具有园林设计行业（设计甲级）、人防工程（设计甲级）资质、林业工程、环境工程（机电工程及核技术工程）等领域专业资质，拥有国家高新技术企业、国家知识产权优势企业、陕西省建筑业工程技术研究中心、省级企业技术中心等研发平台，荣获中国建筑工程鲁班奖、国家优质工程奖、中国安装之星、全国优秀焊接工程奖等“省部级以上奖200余项”，先后被评为“高新技术企业”、“陕西省优秀施工企业”“中国建筑AAA级信用企业”。
