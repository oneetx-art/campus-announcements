## 公司
性质:央国企 · 行业:金融业

中国保险投资基金是国务院常务会议批准设立的中长期资金战略性、主动性、综合性投资平台，旨在集中保险行业的长期稳定资金，对接国家重大战略中市场化需求，带动社会有效投资，支持实体经济发展。中保投资有限责任公司作为基金类管理人，是上海市国资委监管的金融及类金融管理公司，坚持市场化专业化运作，聚焦另类投资领域，逐步形成了'资产管理+投资'的'基金+资管'产品矩阵。公司业务包含丰富的'业务定位和REITs战略配售、私募可转债、未上市股权投资、组合工具箱，涵盖了新债首发战略配售、资多层次资金等多种产品，满足实体经营多资、S基金需求。
