## 公司
性质:民企 · 行业:能源/化工/环保

南京寒锐钴业股份有限公司（A股代码300618）创立于1997年，总部位于南京江宁开发区，是一家业务涵盖钴、铜、镍矿山勘探运作、矿石开采、选冶、钴新材料、铜精细钴镍系列产品生产和销售为一体的跨国企业集团。产品销售至韩国、日本、德国、瑞士、以色列、印度、美国等多个国家和地区，其中钴、钴盐产品已经成为中国和世界的龙头供应企业之一。
