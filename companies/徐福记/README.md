## 公司
性质:民企 · 行业:快速消费品

徐福记由来自中国台湾的徐氏四兄弟于1992年于广东东莞创立。2025年，雀巢全资收购徐福记。目前主要的生产基地坐落于东莞，总占地面积超过50万平方米，拥有39个大型现代化车间，129条高品质自动化生产线。主要生产糖果、糕点、沙琪玛、巧克力及果冻等休闲糖果食品，散、包装类近800个款式，生产吨数可达208,000吨。
