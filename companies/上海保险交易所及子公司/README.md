## 公司
性质:央国企 · 行业:金融业

上海保险交易所（以下简称上海保交所）于2015年11月获国务院批准设立，2016年6月12日正式开业，为全国金融监管管理总局管理单位。上海保交所是按照公司法组建的股份有限公司，由91家股东发起设立，注册资本22.35亿元，注册地位于上海自贸试验区。上海保交所旗下保交所、中保科联等各类保险活动供应商，英文简称“SHIE”。上海保交所积极发挥“服务联通、产品合规增信标准、生态基础共建共享，打造领先的保险交易市场。中保保险资产登记交易系统有限公司是上海保交所的核心子公司。中保科联技术有限责任公司于2019年3月经原中国银保监会管理委员会批准设立，是上海保交所的全资子公司。上海国际再保险登记交易中心有限公司于2024年10月获国家金融监督管理总局批准设立，是上海保交所的全资子公司。
