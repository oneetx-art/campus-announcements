## 公司
性质:央国企 · 行业:金融业

中国银联是经国务院同意、中国人民银行批准的银行卡清算机构，成立于2002年3月，总部设于上海。自成立以来，在中国人民银行的领导下，中国银联成功创建了“银联”自主品牌，以银联成立为标志，我国银行卡产业进入高速发展的快车道。近年来，中国银联深入贯彻新发展理念，加快创新发展，建立了包括银行卡、云闪付、手机闪付及各类创新支付工具在内的多层次、多元化产品体系。通过与全球2600多家机构合作，目前银联卡全球受理网络已延伸到183个国家和地区，覆盖中国境内外超7500万家商户，全球84个国家和地区发行了银联卡，打造了具有全球影响力的银行卡品牌。
