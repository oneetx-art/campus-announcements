## 公司
性质:民企 · 行业:机械/制造业

软控股份有限公司是从橡胶机械的引领者到多元高端科工业态的打造者，成立于2000年，山东青岛橡胶与轮胎工程技术研究中心，2009年承建国家橡胶与轮胎工程技术研究中心，2011年承建轮胎先进装备与关键材料国家工程研究中心，2013年承建数字化橡胶轮胎装备国际联合研究中心，2016年、2021年荣膺“轮胎行业收入最佳供应商”，连续3年蝉联橡榜行业销售收入全球NO.1，2024年度EcoVadis评级中荣获金牌认证
