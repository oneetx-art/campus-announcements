## 公司
性质:民企 · 行业:金融业

超量子基金是一家聚焦AI研究的人才孵化基金管理公司，总部位于深圳福田区。量化研究中心和算法研发中心，专注于投资策略的研发与部署量化策略与产品。公司已通过基金业协会管理人备案（GP17344），具备基金发行与管理资格。超量子基金目前在招涉及技术创新部、团队成员均毕业于世界一流学府，掌握前沿技术与算法。凭借数学与编程功底，为算法优化和策略迭代提供支持；运用过深度学习、强化学习等技术体系，辅以强大的计算算力基础设施支持，打造自动化与实时交易系统，成功将研发的人工智能算法学习技术与投资策略进行有效结合。超量子基金目前已经拥有大量具有潜力和社会影响力的项目，培养具备大量的学习与思考能力、数理逻辑能力、计算机编程能力以及团队协作能力的高端复合型人才为发展策略，在金融市场中不断提升，追求卓越。
