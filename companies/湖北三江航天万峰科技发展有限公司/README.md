## 公司
性质:央国企 · 行业:机械/制造业

湖北三江航天万峰科技发展有限公司始建于1970年，隶属于中国航天三江集团有限公司，是集研发、生产于一体的国防科技工业企业。公司在光电探测、测控、系列电源、舱体制造、能工机器人及人工智能等技术方面具有雄厚研发实力。公司是第一批被认定的国家高新技术企业、国家火炬计划重点高新技术企业，拥有1个国家级工业设计中心、2个国家级智能制造优秀场景、1个国家级技能大师工作室、1个湖北省企业技术中心，入选国家技术创新示范企业、国家“绿色工厂”。
