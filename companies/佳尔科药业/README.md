## 公司
性质:民企 · 行业:医疗/医药/生物

佳尔科药业成立于1993年，是从事甾体类原料药、中间体，以及玻尿酸等软胶囊保健食品研发、生产和销售的高新技术企业。公司先后被评定为高新技术企业、江苏省信用单位、江苏省优秀企业等。通过了中国NMPA、美国FDA、日本PDA认证及原料药官方药品GMP认证。公司建有江苏省雌甾药物工程及中间体技术研究中心。公司立足于人才发展，注重人才培养，建立为导向、营造充满活力的人才发展氛围，以福利为纽带，营造充满活力的人才发展氛围，期待有梦想、敢想、敢拼、敢干的有你加入。
