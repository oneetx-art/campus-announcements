## 公司
性质:民企 · 行业:机械/制造业

广东利元亨智能装备股份有限公司（以下简称‘利元亨’）成立于2014年11月19日，于2021年7月1日在上海证券交易所科创板挂牌上市，股票代码：688499，是全球第一家研制出整线装备、头段全机、贴胶化工序装备的新能源（主要从事锂电池的研发、生产与销售，为新能源、汽车、3C、核电、固态电池、储能、钙钛矿电池、氢能等领域提供ICT、AI算力、软件产品、行业的工业软件。利元亨专注新能源、比亚迪、广汽等世界500强企业，成功打通全固态电池全产业链工艺，具备湿化膜/固化膜产品与服务，此外在固态电池装备方面，已向头部车企交付固态电池整线制备设备，机器人/自动化/仓储/物流全体系赛道适配机器人技术方面，能提供移动操作一体化机器人与调试生产线。
