## 公司
性质:民企 · 行业:机械/制造业

德晟智能于2011年成立，是一家从事智能硬件的科技企业，公司主要研发、生产、销售及应用服务于无人机、机器人、智能家居、智能硬件、3D/AM等智能装备及自动化设备，拥有知识产权100余项。公司成立以来，依托掌握的“硬件+核心算法”，深耕智能制造领域，为客户提供“硬件+软件+算法”的整体解决方案。2021年被认定为优秀供应链企业；2022年被认定为国家高新技术企业；2022年被认定为广东省智能装备生态合作联盟单位；2023年被认定为“专精特新”智能硬件企业；2023年被认定为国家知识产权优势企业；2024年被认定为韶关市工程中心企业。
