## 公司
性质:央国企 · 行业:通信/电子/半导体

中国铁塔股份有限公司成立于2014年是在落实“网络强国”战略、深化国企改革、促进电信基础设施资源共享的背景下，经国务院同意、国资委批准的大型国有企业，是全球规模最大的通信铁塔基础设施服务提供商。中国铁塔股份有限公司南昌市分公司是中国铁塔下属分公司，于2014年10月28日揭牌成立，主要从事通信铁塔等基站配套设施和高铁地铁公网覆盖、大型室内分布系统的建设、维护和运营，并面向社会各行业提供站址应用、综合信息业务以及能源保障服务。始终坚持融入和服务地方经济社会发展大局，认真贯彻新发展理念，深化共建共享，积极助力网络强国、数字中国及双碳战略落地，以实际行动助力南昌数字经济做优做强“一号发展工程”。
