## 公司
性质:央国企 · 行业:金融业

广西农村投资集团有限公司于2015年12月在原广西水利电业集团有限公司基础上成立，是广西壮族自治区属国有资本投资集团，注册资本71亿元，是广西脱贫攻坚投资平台和广西乡村振兴战略实施的资本投资运营平台。目前拥有1家上市企业广农糖业，9家糖业企业产糖量超120万吨，排名广西第一，年均产值近70亿元；全资企业共160余户，分布在广西50多个县市区及贵州、新疆等地，员工人数约1万人，主营业务涵盖农机服务、水务、种业、农业供应链、基金投资、糖业、新能源共七大领域
