## 公司
性质:民企 · 行业:IT/互联网/游戏

北京航天拓扑高科技有限责任公司隶属于中国运载火箭技术研究院北京航天万源科技有限公司，是一家致力于智能制造和智慧产业的高新技术企业。公司成立于2001年，总部科研场所占地15000平方米，公司现有员工350余人。为有力支撑中国梦、航天梦、强军梦的总体战略目标，依托航天核心技术、高端人才、雄厚资金，公司现已拥有智慧工厂、智慧能源、军工软件三大事业部及北京、沈阳两大研发中心，培养了一支高素质、实战型服务团队，荣获多个国家、省部级技术奖项。多年来，拓扑人凭借强大的自主研发实力和丰富的系统集成实施经验，先后为探月工程、北京奥运、北京冬奥、雄安智慧城市建设等国家重点项目保驾护航。
