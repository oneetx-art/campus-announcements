湖南出版集团组建于2000年6月，2004年9月整体转制为湖南出版投资控股集团，2010年10月成立中南出版传媒集团股份有限公司，2011年10月登陆A股主板市场，成为全国首批文化产业整体上市的出版龙头。近年来，集团坚持改革攻坚、改革重塑理念，在融合发展、精品生产和产业升级中不断焕发出新的活力。集团主营涵盖图书、报纸、期刊、音像、电子、网络、地铁媒体、移动媒体、户外媒体等多种媒介，集编、印、发、供、研各环节于一体，形成了出版主业综合实力位居全国第一方阵的产业发展格局，多元业务，出版湘军亮相欧洲书市，年均出书1万余种，图书市场占有率居地方出版集团第一，新书市场占有率位居全国第一。
