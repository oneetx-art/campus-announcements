## 公司
性质:民企 · 行业:机械/制造业

光韵达成立于1998年，是一家集研发、设计、制造、销售、服务为一体的国家高新技术企业，也是一家激光产业链覆盖的智能应用解决方案与服务提供商，业务涵盖激光制造服务、智能装备、航空零部件和激光应用解决方案等四大板块。深耕激光领域27年，从应用、到装备、到激光光源的研究开发，利用“激光技术+人工智能”为电子信息和航空、新能源领域提供创新的激光制造服务和智能制造解决方案。2011年8月代码：300227，成为国内首家激光应用领域上市公司。目前，公司在汽车电子和通信设备等领域先后布局了激光全加工，并已建造五个产业基地，形成了光华南、华东、华北、西南四大服务区域。
