## 公司
性质:央国企 · 行业:金融业

上海金融期货信息技术有限公司（简称：中金所技术公司）是由中国金融期货交易所全额出资成立的下属子公司，是集信息技术规划、开发和运维于一体，以保障系统安全高效运行为核心使命的现代化IT企业。公司于2012年3月成立，自成立以来，始终秉承“与交易所共发展、与行业共繁荣、与员工共成长”的经营理念，致力于为中国金融期货市场打造一流的技术高地、人才高地和管理高地。
