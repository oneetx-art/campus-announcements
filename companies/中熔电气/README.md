## 公司
性质:民企 · 行业:能源/化工/环保

西安中熔电气股份有限公司成立于2007年4月（股票代码301331），致力于高可靠性的熔断器研发、生产及销售。公司高度重视技术研发和自主创新能力提升，持续为熔断器产品及解决方案提供原创设计、控制及保护一站式汽车高压电解决方案，保障整车系统安全稳定运行。公司已获得国家专利320余项，并获全球首创，目前已取产品，以及美国UL、德国TUV、国际CB、欧盟CE认证，获得欧盟强制性认证产品符合性自我声明。目前国内合力覆盖新能源车辆、体系及产品，是认证深耕电气领域的企业。中熔电气是电路保护元器件领域的全球企业之一，熔断器是新能源汽车元件及储能核心供应商，为行业头部新能源汽车、风光组件等供应商，产品覆盖新能源汽车供电关键环节。
