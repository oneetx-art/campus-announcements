## 公司
性质:央国企 · 行业:能源/化工/环保

浙江浙能电力股份有限公司（以下简称“浙能电力”）成立于1985年6月，本部位于浙江杭州，先后经历全民所有制企业（浙江省电力开发公司）、有限责任公司（浙江省电力开发有限公司）、股份有限公司（浙江电力）等证券交易上市（股票代码：600023）。浙能电力控股股东为浙江省能源集团有限公司（以下简称“浙能集团”），持股比例69.45%。实际控制人为浙江省人民政府国有资产监督管理委员会。浙能电力是省属国企电力板块的上市平台，也是浙江省规模最大的发电企业。
