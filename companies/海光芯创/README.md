## 公司
性质:民企 · 行业:通信/电子/半导体

苏州海光芯创光电科技股份有限公司创立于2011年，是国家高新技术企业，专注于硅光芯片设计、芯片封测、高速光电子器件、高速光模块等产品的研发、生产制造及技术服务，业务覆盖AI算力中心、云数据中心等应用市场。公司坚持自主研发，率先实现硅光芯片及硅光模块的全链条国产化突破，搭建起一支硕博占比近30%的研发团队，承担多个国家级、省市级重大科技项目，参与多项行业标准制定，知识产权50余项，成功进入全球AI算力产业链市场，成为北美和国内主流互联网大厂重要合作伙伴和主流供应商。近年来，公司在北京、南京、南通、新加坡设立全资子公司，联动五地资源，逐步打造具有全球竞争力的光电子产品生产基地，进一步开拓发展空间。未来，海光芯创将继续从技术、产品、客户服务着手，致力于成为全球光电子通信行业的领先企业。
