## 公司
性质:民企 · 行业:金融业

广西扶绥农村商业银行股份有限公司（简称“扶绥农商行”）是由扶绥县农村信用合作联社改制设立，于2015年10月9日正式挂牌开业。截至2025年末，全行各项存款余额达121.15亿元，较年初增长5.95亿元，增长率5.16%；各项贷款余额突破90亿元大关，达90.65亿元。全行共有从业人员234人，辖1家营业部、11家支行、9个分理处，营业网点共计21个，服务区域涵盖县辖11个乡镇，是扶绥县辖内网点最多、从业人员最多、服务范围最广、服务人口最多的法人银行业金融机构，近年来相继荣获县委、县政府授予“特别贡献企业”“勇争第一 强县有我”先进集体、“纳税大户”等多项荣誉，深得广大客户的支持和认可，是名副其实的“扶绥人自己的银行”。
