## 公司
性质:事业单位 · 行业:文化/传媒/广告/体育

成都市广播电视台为成都市人民政府直属正局级“公益二类”事业单位，由中共成都市委宣传部代管，是中国西部地区主流广电媒体之一。建台75年来，成都市广播电视台紧紧围绕主流舆论宣传引导，先后培育打造了《成都新闻》《今晚800》《新闻背景》《深夜快递》《成都全接触》《热线188》《谭谈交通》《红绿灯》《陈岳叔叔讲故事》等知名栏（节）目和“看度新闻”新媒体矩阵，以及《你好，成都！》《12345追踪》《燃体验》《人生·观》《理赔家》《天府工匠》《ChengduPlus》等系列融媒体品牌产品；荣获“中国新闻奖”“中国广播电视大奖”“五个一工程奖”“飞天奖”“星光奖”“金鹰奖”“四川新闻奖”等各级各类奖项共计2600余次；5次被知名智库和权威机构评选为全国“十大最具影响力城市台”。
