## 公司

美建建筑系统（中国）有限公司（简称ABC），于1994年由全球预制金属建筑系统的领导者——美国建筑公司（American Buildings Company）与美国工业投资集团CII共同投资创建。ABC继承和发展了美国建筑公司的全套金属建筑技术体系，致力于为中国和全球市场提供各类钢结构建筑及产品的方案、设计、制作、安装以及售后维护等一系列富有竞争力的服务。
