## 公司
性质:央国企 · 行业:能源/化工/环保

公司位于浙江遂昌县境内，创建于1976年。是一家集采、选、冶炼为一体的省属国有黄金矿山企业，隶属于杭州钢铁集团有限公司。旗下拥有7家全资子公司、1家控股公司和2家参股公司。公司业务范围涉及矿业开发、贵金属冶炼、金银深加工、铸造、旅游、复合材料等行业，主要产品有金、银、金银制品、萤石粒子矿、萤石精矿粉、精密铸件、氰化亚金钾、铅锌精矿、硫精矿、旅游商品、高性能连续纤维增强热塑性复合材料等。拥有检测、地质勘探、测量等资质，可提供地质勘探、储量评估、矿物元素分析、选矿试验、爆破作业等技术服务、旅游服务和连续纤维增强热塑性复合材料系列产品的专业研发、生产。
