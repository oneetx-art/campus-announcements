## 公司
性质:央国企 · 行业:通信/电子/半导体

天津光电通信技术有限公司（国营第七五四厂）诞生于“两航起义”，至今已有70多年历史。公司研发基地位于天津市河西区泰山路6号，是集专业从事无线电通信、光网络通信、通信系统、信息安全、技术服务等领域产品研发、制造和销售的高新技术企业，长期服务于军队、国防及政府部门。公司是国家重点“专精特新”小巨人企业、高新技术企业。拥有400人研发团队，其中国务院津贴、专家等高端人才荣誉获得者60人次，天津市“131”创新型人才等市级人才荣誉获得者60人次。2016年，李克强总理亲临指导，并留下“老企业、新气象、大未来”寄语。公司坚持年度研发投入占比13%以上，用科技创新驱动企业快速发展。
