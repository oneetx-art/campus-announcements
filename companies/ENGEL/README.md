## 公司
性质:外企 · 行业:机械/制造业

ENGEL集团是奥地利家族企业，全球注塑机制造商之一，创立于1945年，全球有10家生产工厂，员工总数7000人，全球年营收达15亿欧元，85+个国家拥有子公司和代表处，每年研发投资超1.25亿欧元，投资总额超过5亿欧元(2018-2025)。作为单一来源供应商，ENGEL集团为塑料加工提供集成解决方案，涵盖热塑性塑料和弹性体注塑机及自动化，单个组件也在市场上获得了成功。
