## 公司
性质:民企 · 行业:金融业

广东揭西农村商业银行股份有限公司（简称“揭西农商银行”）是一家具有独立法人资格的地方性股份制商业银行，服务范围覆盖县内各列乡，存贷款规模及市场份额稳居揭西县同县前列。揭西农商银行作为揭西县金融主力军，始终坚持“支农支小、助力乡村振兴”的定位，为支持地方经济建设和助力乡村振兴作出了积极贡献，未来也将以金融活水，赋能地方高质量发展。
