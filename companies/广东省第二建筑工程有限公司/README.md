## 公司
性质:央国企 · 行业:房地产业/建筑业

广东省第二建筑工程有限公司是中国500强企业广东省属国企——广东省建筑工程集团控股有限公司控股的上市公司的下属企业。公司总部位于汕头，是广东省建筑业龙头骨干企业、AAAA级广东省守合同重信用企业、全国建筑业AAA级信用企业、全国优秀施工企业、全国质量管理先进单位、全国安全管理先进单位。公司深耕建筑行业70余载，具备建筑工程施工总承包、市政公用工程施工总承包、机电工程施工总承包、建筑装修装饰工程专业承包等一级资质；水利水电工程施工总承包、地基基础工程专业承包、公路路基工程专业承包等二级资质。近年来，公司紧紧围绕集团的工作部署和高质量发展的主业，优化经营模式，努力推动公司高质量发展。公司在上海、广州、深圳、海南、四川、浙江等地设立分公司，先后承建了一批具有影响力的标志性工程，为国家和地方经济发展做出了卓越的贡献。如今公司已发展为具有综合实力强、行业形象好、人才队伍强、科技成果丰、品牌品质优、企业文化浓等特色优势的综合性建筑施工企业。
