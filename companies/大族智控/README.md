## 公司
性质:民企 · 行业:机械/制造业

深圳市大族智能控制科技有限公司（简称“大族智控”）是大族激光科技产业集团股份有限公司的全资子公司，公司长期专注于为装备制造业提供数控系统，立志为中国智能制造，成为国际知名的数控系统及核心功能部件的研发与解决方案提供商。主要产品包括数控系统、总线式IO模块、示教器、伺服驱动器等，其产品已广泛应用于激光加工、锂电装备等工业领域。
