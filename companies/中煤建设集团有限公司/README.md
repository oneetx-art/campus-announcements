## 公司
性质:央国企 · 行业:房地产业/建筑业

中煤建设集团有限公司（简称“中煤建设集团”）是中国中煤能源集团有限公司的全资子公司，是集矿山工程施工、建筑安装工程施工、煤炭生产、矿山运营、洗选加工、监理咨询、物流仓储等业务于一体的大型工程建设集团，是我国煤炭建筑行业骨干企业。拥有3个矿山工程施工总承包特级资质、18个施工总承包壹级资质、22个施工总承包贰级资质、3个专业承包施工壹级资质、2个煤炭行业甲级资质。先后有200余项工程荣获“国家‘太阳杯’”“国家优质工程”等省部级以上奖项，超深立井、超大直径冻结、提井、模筑等多项施工技术在国际上处于领先地位。
