## 公司
性质:央国企 · 行业:房地产业/建筑业

中建海峡建设发展有限公司（中建海峡）是中国建筑股份有限公司旗下全资成员企业，公司1952年始创于上海，1966年整编为基建工程兵二十一支队二〇三团，1983年“兵改工”入驻福建，2012年由中建集团整合系统内部优势资源，正式更名组建为中建海峡建设发展有限公司。公司注册资本15亿元，现有员工5200余人，年经营规模超800亿元、年营业收入超300亿元。
