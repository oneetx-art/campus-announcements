## 公司
性质:央国企 · 行业:新能源

中交海峰风电发展股份有限公司成立于2022年5月26日，注册资本25亿元，是世界500强——中国交通建设集团有限公司的控股子公司。中交海峰风电作为中交集团在新能源领域的探索与实践，由中交集团联合三峡集团、大唐集团、国家能源集团、远景能源等业内多家头部大型央企和知名民企组建而成，旨在进一步做强、做优、做大海上风电产业，为国家实现“双碳”目标贡献更多力量。公司业务涵盖海上风电装备研发投资、运营维护、海外风电、设计咨询、“海上风电+”等领域，逐步发展成为集海内外业务为一体的多元化企业，致力于打造具有全球竞争力的“科技型、管理型、质量型”世界一流海上风电综合服务商。
