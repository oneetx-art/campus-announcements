## 公司
性质:民企 · 行业:通信/电子/半导体

瑶芯微电子成立于2019年8月，总部位于上海张江，在西安、成都设有研发中心，在深圳设有销售办公室。公司布局功率半导体以及音频芯片两大产品线。功率产品方面，覆盖高中低压不同功率等级、碳化硅、氮化镓及硅基全产品类别，为客户提供功率芯片整体解决方案，产品广泛应用于新能源汽车、AI数据中心、光伏储能、工业等领域；音频产品方面，公司专注音频前端信号链，覆盖传感器以及信号处理芯片，产品广泛应用于手机、耳机、智能座舱、机器人等领域。
