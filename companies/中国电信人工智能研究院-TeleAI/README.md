中国电信人工智能研究院（TeleAI）是中国电信集团二级单位，在国务院国资委、上海市政府和中国电信集团共同支持下组建，2024年5月在上海成立，同年7月在世界人工智能大会上正式揭牌。聚焦人工智能领域核心技术研发，汇聚算力、数据、网络及通信等多方面优势，布局智传网、具身智能、世界模型、人工智能基础设施、AI安全与治理等前沿领域，打造全栈技术创新体系，推动产学研用一体化发展的创新高地。
