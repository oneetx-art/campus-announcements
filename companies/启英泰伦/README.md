## 公司
性质:民企 · 行业:通信/电子/半导体

成都启英泰伦科技有限公司于2015年在成都高新区注册成立，是一家专注于人工智能语音芯片及解决方案的国家专精特新“小巨人”企业。其芯片产品以高语音识别率、强抗噪能力及端侧语音大模型为特色，提供集语音识别、语音唤醒、语义理解、深度降噪、声纹识别、声音检测等于一体的端侧智能语音解决方案支持多语种、多方言识别，可满足多场景的实时语音处理和交互需求，广泛应用于智能家居、消费电子物联网设备等领域。公司通过“芯片+算法+大模型+开发平台”完整生态链，助力客户快速实现产品智能化升级，推动AI语音技术在终端设备的规模化落地。现服务客户超1万家，在离线智能语音芯片市场覆盖率第一。
