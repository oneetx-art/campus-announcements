## 公司
性质:央国企 · 行业:房地产业/建筑业

中国建筑第二工程局有限公司华北公司成立于2005年3月1日，系中国建筑第二工程局有限公司所属的非法人分支机构，六家区域公司之一，总部设在北京。近年来，公司紧盯轨道交通、医疗院校和高端制造业厂房等业务，攻坚城市更新、能源水利等重点领域，打造了一系列优质工程。公司累计荣获鲁班奖10项、詹天佑奖8项、国家优质工程奖15项、中国钢结构金奖5项、全国国建证工程安全生产标准化工地37个、省级优质工程奖百项，被评“中央企业先进基层党组织”“全国五一劳动奖状”、“全国工人先锋号”等国家级称号30余项、省部级称号百余项。逐渐形成了以“京津冀”为核心区域，辐射带动山西、河南、陕西等地的经营布局，致力打造国内一流的建筑施工强企。
