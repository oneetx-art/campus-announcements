## 公司
性质:民企 · 行业:医疗/医药/生物

建发致新是世界500强建发集团成员企业，于2010年总部位于上海，是建发集团成员企业。作为全国性医疗器械供应链平台，建发致新主要从事医疗器械直销及分销业务，并为医院提供医用物资的集约化运营（SPD运营管理及GPO集中供应）等服务，与1000余家国内外知名医疗器械生产厂家建立并保持长期稳定的合作关系。目前，建发致新在全国31个省、直辖市、自治区的3300余家医疗机构提供上万种产品的直销服务，并通过建发全国的分销网络，以医疗耗材IVD诊断产品为切入点，经营实力强、创奇、泰尔茂、迈克、贝瑞摩尔特等众多国内外知名企业产品，覆盖血管介入、外科、眼科、齿科、骨科、IVD产品等领域。
