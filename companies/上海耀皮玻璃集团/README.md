## 公司
性质:民企 · 行业:能源/化工/环保

上海耀皮玻璃集团股份有限公司成立于1983年，1993年改制上市（600819.SH），是中国玻璃制造行业最早的上市公司之一。2024年底，集团资产总额约80亿元，销售收入约56亿元。业务覆盖浮法玻璃、建筑加工玻璃和汽车玻璃。下辖13家子公司，生产基地分布于上海、江苏、天津、重庆、武汉、广东、广西、大连。
