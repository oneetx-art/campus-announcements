## 公司
性质:民企 · 行业:能源/化工/环保

金冠电气股份有限公司成立于2005年，2021年在上海证券交易所科创板上市（股票代码：688517），是全国惟一一家以避雷器为主业的上市公司，金属氧化物避雷器产品被国家工信部连续六年认定为制造业单项冠军产品。主要产品包括避雷器、电阻片、开关柜、环网柜、柱上断路器、充电桩、工商业储能等。
