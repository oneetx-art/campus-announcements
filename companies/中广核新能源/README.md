## 公司
性质:央国企 · 行业:能源/化工/环保

中国广核新能源控股有限公司（以下简称“中核新能源”）是中国广核集团（以下简称“中广核”）重要二级成员公司，于2014年10月在香港上市，定位为中广核开发、运营非核清洁及可再生能源电力的重要平台，全国负责中广核新能源产业的改革创新和运营发展。中广核新能源于2007年正式开拓新能源业务，历经十年发展，目前已形成“光伏+”“陆风+”“渔光一体、海上风电、气电、核电联产等业务类型。截至2025年6月，中广核新能源在运装机总量超584万千瓦，其中风电项目1726万千瓦，太阳能光伏项目240万千瓦，排名行业前列。规划2025年，装机规模突破7000万千瓦。
