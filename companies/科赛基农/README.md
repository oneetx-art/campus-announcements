## 公司
性质:民企 · 行业:能源/化工/环保

山东科赛基农控股有限公司创立于2001年，总部位于山东省济南市。公司是一家集研发、生产、销售于一体的国家农药定点生产企业，拥有原药合成、制剂加工及植保服务完整产业链。公司生产基地位于山东省济宁市汶上县，占地400余亩，拥有现代化的研发中心、生产车间及仓储物流设施。科赛基农致力于成为世界领先的作物保护方案提供商，为全球农业发展提供优质的产品和服务。
