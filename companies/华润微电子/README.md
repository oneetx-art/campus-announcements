## 公司
性质:央国企 · 行业:通信/电子/半导体

华润集团是国资委直属的国有重点骨干企业，2025年位列《财富》世界500强第67位。华润微电子有限公司是华润集团旗下负责微电子业务投资、发展和经营管理的高科技企业，拥有芯片设计、掩模制造、晶圆制造、封装测试等全产业链一体化经营能力。华润微电子坚持以“长三角+成渝双城+大湾区”的两江三地布局，业务范围遍布无锡、上海、重庆、深圳、香港和东莞等地，拥有3家产品公司、1条掩模生产线、2条12吋晶圆生产线、2条8吋晶圆生产线、3条6吋晶圆生产线、4条封装测试生产线。自2004年起，华润微电子连续被工信部评为中国电子信息百强企业。2020年2月27日，华润微电子成功登陆科创板（股票简称“华润微”，股票代码“688396”）。
