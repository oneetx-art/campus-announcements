## 公司
性质:合资 · 行业:金融业

厦门国际银行股份有限公司（XIB）成立于1985年，总部位于厦门，是中国第一家中外合资银行。作为首家在港澳均拥有全功能附属商业银行的城市商业银行，本行协同港澳附属机构形成了“以内地为主体、以港澳为两翼”的战略布局，在北京、上海、广州、深圳、珠海、杭州、厦门与福建其他8个设区市，以及香港、澳门特别行政区等地共设有150余家营业性机构网点。
