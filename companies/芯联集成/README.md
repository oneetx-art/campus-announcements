## 公司
性质:民企 · 行业:通信/电子/半导体

芯联集成是一家专注于功率、传感和传输应用领域，提供从芯片及模组到封装的一站式解决方案的制造商。公司主要从事MEMS、IGBT、MOSFET、模拟IC、MCU等的研发、生产、销售。为汽车、新能源、工控、家电等领域提供完整的一站式芯片系统代工方案。芯联集成是国内领先的具备车规级能力的代工企业，拥有种类完整、技术先进的车规级IGBT/SiC芯片及模组产品芯片库，也承担着重要的车规级高端工业控制芯片及模组制造基地。同时，芯联集成还是国内规模、技术领先的MEMS晶圆代工企业。
