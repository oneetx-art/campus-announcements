## 公司
性质:央国企 · 行业:交通/物流/仓储

现代投资股份有限公司成立于1993年，主营高速公路建设、经营和管理，1999年在深圳证券交易所挂牌上市（股票代码：000900，简称“现代投资”）。公司注册资本15.18亿元，实际控制人为湖南省国资委。公司以“创享美好之路，践行绿色发展”为使命，重点打造以高速公路运营管理为主体，以金融服务和产业经营为“两翼”的“一体两翼”发展格局，经营范围涉及高速公路、银行、期货、环保、新能源、资产管理、路衍等领域。
