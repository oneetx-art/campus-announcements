## 公司
性质:民企 · 行业:通信/电子/半导体

芯合电子（上海）有限公司（Unisemi Power Inc.）成立于2018年，致力于中高端芯片的设计开发制造与营销。设计团队聚集国际知名半导体设计与制造公司高端人才，在上海、北京、苏州设有研发中心，深圳、东莞具备销售和技术支持。目前聚焦在高性能、高质量数模混合芯片产品，探索世界顶尖芯片领域。产品在移动应用市场涵盖全套功率管理解决方案，并积极布局汽车电子中电源管理和智能功率芯片，产品应用多家国际知名品牌客户，满足主流手机产品功能与可靠性要求。
