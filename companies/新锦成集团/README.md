## 公司
性质:民企 · 行业:机械/制造业

广东新锦成集团有限公司成立于2007年，总部位于广东佛山，经历十八年的沉淀与蜕变，已发展成为一家集研发、制造、营销、服务于一体，在国内外颇具影响力的大型现代化建陶企业集团。旗下包含新岩素岩板、兴辉瓷砖、欧福莱瓷砖、圣堡龙瓷砖、巴宝莉瓷砖等多个品牌，致力于满足消费者全场景的装修需求。
