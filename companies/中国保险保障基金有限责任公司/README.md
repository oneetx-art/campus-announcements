## 公司
性质:央国企 · 行业:金融业

中国保险保障基金有限责任公司是国务院批准设立的国有独资企业。根据《保险保障基金管理办法》，公司依法负责保险保障基金的筹集、管理和使用。一是筹集、管理、运作保险保障基金；二是监测保险业风险，发现保险公司经营管理中出现可能危及保单持有人和保险行业的重大风险时，向国务院保险监督管理机构提出监管处置建议；三是对与保险保障基金管理有关的公司和个人机构提供救助或者保单持有人的保单受让工作等；四是在保险公司被依法撤销或者依法实施破产等情形下，参与保险公司的清算工作；五是管理和处分受偿资产；六是国务院批准的其他业务。
