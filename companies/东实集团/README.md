## 公司
性质:央国企 · 行业:房地产业/建筑业

东实集团是东莞市属国企，成立于2011年10月，注册资本68.8亿元，截至2025年9月，集团总资产1542亿元，净资产140亿元，主体信用评级AAA。作为东莞市属国企，东实集团以“城市东莞 品质东实”为使命，成立“城市开发建设综合服务、园区运营、产业投资”四大板块，构建的全城市建设开发产业链闭环，旗下包括理文造纸企业、粤海装备技术产业园、东实新能源、东实旗云城市服务、粤海电力控股建设、产业投资、环保商业设施、人才安居保障性住房、产业园区、环保、商超、酒店、文体场馆运营、物业管理、设备运维等；同时承担“工改工”、城市更新、“莞深产业合作园”等项目。集团先后获得国务院国资委、国家知识产权局、全国质量标杆等荣誉。
