## 公司
性质:合资 · 行业:交通/物流/仓储

北京飞机维修工程有限公司（Ameco）由中国唯一载旗航空—中国国际航空股份有限公司和国德汉莎航空公合经营，是中国民航合资最早（1989年）、规模位于行业前列的民用飞机维修企业。2015年6月9日，经股东双方对Ameco国航的二次重组，建立新的北京飞机维修工程有限公司，其中国航持股75%，德国汉莎持股25%。Ameco拥有12000名员工，拥有一支作风严谨、技术过硬的工程技术人员队伍，其中工程师团队规模达2100余人，全面确保公司专业化、产业化发展。
