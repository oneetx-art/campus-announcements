## 公司
性质:央国企 · 行业:机械/制造业

贵阳航空电机有限公司成立于1958年，是贵州省第一家航空企业，隶属于中国航空工业集团机载系统，主要从事电力变换类、配电类、电驱动类产品等研发、生产、销售工作。是航空工业电力变换子系统领域的核心供应商，也是贵州省唯一的C919机载成品供应商
