## 公司
性质:民企 · 行业:房地产业/建筑业

北京中林国际林业工程咨询有限责任公司成立于2013年9月，是专业服务于林业生态领域、从事林业调查规划设计、工程咨询的综合性技术服务企业。公司持有林业调查规划设计甲级资质、工程咨询甲级资质，业务范围涵盖森林、野生动植物、湿地、荒漠、草原调查监测和评价；森林分类区划界定；征占林地可行性报告编制；森林资源规划设计调查、作业设计调查等多项服务以及建设项目的可研、建设方案、规划等的咨询。公司业务遍布全国，并在云南、四川、青海、宁夏、陕西、甘肃、内蒙等多个省市设立了分支机构，为实现科研技术与市场优势互补，公司与北京林业大学在北林科技产业园区合作共建研发中心，共同开展生态建设领域的合作与研发。秉承“科学严谨、优质服务、笃守诚信、追求卓越”的企业宗旨，公司坚持以市场为导向、以客户为中心，以品质求生存、以信誉求发展、以创新求突破，依托完善的技术保证体系，为客户提供优质、高效的服务，完成的项目多次荣获国家、行业主管部门的表彰。
