## 公司
性质:民企 · 行业:能源/化工/环保

湛清环保成立于2014年，是一家专注于为新能源、新材料行业提供废水处理与资源循环利用解决方案的国家高新技术企业，总部位于江苏昆山高新区，在江苏淮安、四川宜宾设有分支机构。公司业务涵盖废水研发与系统、环保药剂、运营服务及资源回收四大板块，研发技术团队占比超过70%。其核心工艺与装备入选国家多部委联合发布的《国家鼓励发展的重大环保技术装备目录》等多项目录。目前，湛清环保已为全球超1000家企业提供服务，客户涵盖新能源锂电、光伏材料等高增长领域。公司获评国家专精特新“小巨人”企业、瞪羚企业等荣誉，并作为环保标杆企业参与《绿色中国100》项目拍摄，承担基地工业绿色转型。
