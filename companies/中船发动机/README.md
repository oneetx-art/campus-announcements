## 公司
性质:央国企 · 行业:机械/制造业

中船发动机有限公司（简称“中船发动机”，英文缩写：CSE）是中国船舶集团旗下核心大型专业化船用低速柴油机制造企业，本部设在中国青岛，下辖宜昌两个全资子公司。公司始于1958年，成立于2017年，注册资本55亿元，占地面积约3000亩，员工总数2300余人。中船发动机主营业务为船用发动机生产制造及售后服务、陆用电站主机生产制造及售后服务、能源装备生产、生产环节涵盖铸造、焊接、热处理、机械加工、总装、调试等。公司通过了质量管理体系、环境管理体系、职业健康安全管理体系、能源管理体系、安全生产标准化等各项资质体系的认证并保持有效运行。取得CCS、DNV-GL、BV、ABS、LR、NK、RINA及KR等世界九大船级社的认证。产品覆盖MAN、WinGD、J-ENG三大品牌300-980mm缸径范围全系列发动机的生产制造、调试和服务，广泛运用于散货船、油船、集装箱船、LNG运输船、PCTC汽车运输船等各类商用船舶，国际市场占有率保持领先。
