## 公司
性质:民企 · 行业:能源/化工/环保

深圳市量能科技有限公司创始于2003年，是一家专业从事研发、生产和销售绿色环保免充电池的国家高新技术企业。坚持“心有能量，海阔天空”的核心理念，为低碳提供安全高效的绿色能源系统解决方案。公司拥有深圳、梅州、盐城及越南四大生产基地，现有厂房共超过70000平方米，镍氢电池日产80万只，锂电池日产超60万只，是镍氢电池国家标准主导修订单位，并参与多项锂电池行业国家标准的制定。经过20多年努力，公司已拥有较强的技术研发水平及研发能力，先后4次获得中国专利优秀奖。荣获“龙华新区民营50强”、“广东省名牌产品”、“深圳知名品牌”、首届“龙华新区质量进步奖”、“龙华区中小微创新百强企业”、“广东省专精特新中小企业”、“广东省工程技术研究中心”、“国家高新技术企业”和国家级专精特新“小巨人”等企业荣誉。
