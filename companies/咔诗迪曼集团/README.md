## 公司
性质:民企 · 行业:贸易/批发/零售

咔诗迪曼集团成立于2015年，是一家集研发、生产、线上、线下销售一体的直播新零售公司。在快手平台获得了多项荣誉，如黑马主播和美妆杰出贡献等，成为了CCTV签约的品牌强国上榜品牌，构建了“达人孵化+直播电商+线下私域”三大业务板块咔诗迪曼带货GMV5亿+，年消耗2.8亿+，单场直播GMV1000万+目前集团员工已超500人，成为功效护肤品单爆品行业头部品牌。旗下有咔迪朗快手直播公司、莉曼直播公司、莉婕私域运营公司，以及建筑面积25000㎡的咔诗迪曼化妆品生产基地、3000㎡云仓等，目前分公司分布在广州佛山、黑龙江等。
