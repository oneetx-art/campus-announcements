## 公司
性质:民企 · 行业:交通/物流/仓储

上海嘉星物流有限公司成立于2003年9月，是一家专业的供应链第三方解决方案服务商，凭借多年积累的行业内优质供应链客户资源、渠道资源以及方案资源，为客户提供独特而广泛的端到端供应链解决方案。在核心城市均设有分支机构，构建了覆盖全国的星干线运力网络，为各行客户提供安全高效的空运、陆运、铁运、海运及多式联运服务。
