## 公司
性质:民企 · 行业:能源/化工/环保

新疆格瑞迪斯石油技术股份有限公司（简称：格瑞迪斯）成立于2011年10月21日，注册资本5095万元，注册于新疆巴州库尔勒经济技术开发区，2014年改制为股份有限公司，2022年9月在全国股转系统挂牌（股票代码：873735）。公司旗下有北京格瑞迪斯石油技术有限公司、加拿大有限公司、四川格瑞迪斯石油技术有限公司。公司是国家级高新技术企业，国家重点支持的“专精特新”小巨人企业，国家知识产权示范企业，新疆自治区认定的企业技术中心、工程技术研究中心，设有国家级博士后科研工作站，曾获自治区行业技术发明奖一等奖和科技进步奖一等奖、自治区科技进步奖二等奖、创新业、开发建设新疆奖等多个奖项。公司现有专利56项，其中发明专利22项、实用新型专利34项，软件著作权登记17项。
