## 公司
性质:民企 · 行业:通信/电子/半导体

天津普林电路股份有限公司成立于1988年，于2007年5月在深圳证券交易所上市。2020年TCL全资收购中环集团，TCL科技控股天津普林。2023年天津普林收购泰和电路，2024珠海新厂房投产。公司主营“多品种、小批量、高品质、高可靠性”PCB的研发、生产和销售，拥有PCB全制程生产能力，产品广泛应用于工控、医疗、汽车电子、通信电子、航空、消费电子等领域。
