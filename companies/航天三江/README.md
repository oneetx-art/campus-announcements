## 公司
性质:央国企 · 行业:机械/制造业

中国航天三江集团有限公司（中国航天科工集团第四研究院，以下简称“航天三江”），隶属于中国航天科工集团有限公司，是我国固体运载火箭研制生产的主体与技术抓总单位、特种越野车及底盘研发生产主要单位、国内重要的武器装备系统总体研制单位，是国家重点高新技术企业和“863计划”成果产业化基地。航天三江拥有6个国家级研发中心，6个院士工作站，1个国防重点学科实验室，1个博士后科研工作站，2个湖北省重点实验室，1个湖北省工程研究中心，1个湖北省产业技术创新联合体，4个湖北省工程技术研究中心。航天三江现有在岗职工1.6万余人，拥有中国工程院院士2人，国家级、省部级专家180余人，高级以上职称人员3000余人，博士、硕士5400余人，享受国务院政府特殊津贴人员近200人。
