## 公司
性质:央国企 · 行业:机械/制造业

北京电子量检测装备有限责任公司（简称：北电检测）是北京电子控股有限责任公司旗下二级企业，前身为北京维拓智联科技有限公司，成立于2001年，传承自1957年成立的“一五”计划重点工程国营738厂。公司作为北京电控半导体量检测设备及关键零部件平台，专注于半导体显示和集成电路量检测设备及关键部件的研发、制造与技术服务。
