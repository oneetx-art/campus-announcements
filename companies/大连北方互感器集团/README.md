## 公司
性质:民企 · 行业:机械/制造业

大连北方互感器集团创建于1997年，位于大连市普兰店区，下辖大连北方互感器集团有限公司、大连北方真空开关有限公司、大连北方避雷器有限公司和湖南大北互互感器有限公司。主导产品有500kV级及以下各种互感器、避雷器，126kV级及以下各种绝缘件、断器等。隔离关领全国内同行业，综合实力居国内数字化等方面均领先企业在研发、生产、实质质量管理领先水平。
