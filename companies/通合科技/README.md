## 公司
性质:民企 · 行业:能源/化工/环保

通合科技，是一家以高频开关电源及相关电子产品研发、生产、销售、运营和服务于一体，为客户提供系统能源解决方案的高新技术企业。公司成立于1998年，2015年12月31日成功在深交所创业板挂牌上市，股票代码300491。作为一家极具潜力的知识密集型高新技术企业，公司持续稳定发展。现有员工1800余人，研发人员占比超过30%。公司坚持“技术立企”，是国内率先实现功率变换全程软开关的电力电子企业，累计获得专利240余项、软件著作权60余项。多年的实践探索使公司聚焦于新能源、智能电网及航空航天三大业务领域。随着公司战略布局的不断拓展，形成了石家庄、西安双总部协同发展的产业格局，销售网络已覆盖全国30多个省市自治区，产品远销海外。
