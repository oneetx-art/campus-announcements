## 公司
性质:央国企 · 行业:金融业

中国石化财务有限责任公司成立于1988年7月8日，是经中国人民银行批准成立的非银行金融机构，隶属于中国石化集团公司。公司是集团建设金融板块重要棋子，始终坚持“立足石化、服务主业”经营宗旨，积极发挥集团“资金归集平台、资金结算平台、资金监控平台和金融服务平台”功能作用，充分利用专业、资金管控平台及金融服务，持续打造资金一流金融服务、一流运营效率、一流风控体系，持续提高资金使用效率、降低融资成本、防范金融管控风险，主要人才规模位于一流企业集团财务公司前列，兵头具备一流服务队伍的水平位居财务公司行业前列，在服务集团高质量发展中彰显金融担当。
