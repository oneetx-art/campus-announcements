## 公司
性质:央国企 · 行业:机械/制造业

中国航天科技集团有限公司第五研究院总体设计部（北京空间飞行器总体设计部）成立于1968年8月，是我国组建成立最早、总体领域最多、专业技术最齐备的空间飞行器研制核心抓总单位，是五星宇宙重磅工程任务抓总单位，载人航天、空间科学与深空探测等宇航总体业务的经营管理主体和责任主体，宇航总体专业技术发展的责任主体。
