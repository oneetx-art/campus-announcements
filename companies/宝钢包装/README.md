## 公司
性质:央国企 · 行业:机械/制造业

上海宝钢包装股份有限公司（简称宝钢包装）是中国宝武钢铁集团有限公司二级单位，国内快速消费品金属包装的龙头企业、国内金属包装领域领导者和行业标准制定者之一，于2015年在上海证券交易所挂牌上市（证券代码：601968）。宝钢包装致力于为食品、饮料等快速消费品提供金属包装整体解决方案，主要业务包括：金属易拉罐及配套易拉盖、包装彩印产品的生产制造；主要服务于全球碳酸饮料和啤酒品牌客户和知名长饮料及食品企业，与国内外知名快消品牌客户建立了长期、共赢的战略合作关系。
