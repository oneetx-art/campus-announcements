## 公司
性质:央国企 · 行业:机械/制造业

中车唐山机车车辆有限公司是中国中车部属龙头企业和中国中车机车研发、制造、中国铁路总公司三个机车车辆定点企业之一。拥有国家级的三个机车车辆研发中心，创造了“第一辆铁路机车‘中国火箭号’、第一辆客车用车厢‘紫光号’和中国第一列时速350公里高速动车组均在此生产制造。
