## 公司
性质:民企 · 行业:机械/制造业

联眺科技成立于2024年，注册资本1亿元，在上海、武汉和北京分设研发中心、生产基地和服务中心。核心团队来自清华、华科、浙大等高校，平均拥有15年以上经验。公司专注于集成电路制造工艺电源，对产品覆盖刻蚀、沉积、离子注入等关键工艺，对标国际先进水平，致力于成为全球领先的集成电路工艺电源整体解决方案提供商。
