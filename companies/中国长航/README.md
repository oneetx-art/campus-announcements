## 公司
性质:央国企 · 行业:交通/物流/仓储

中国长江航运集团有限公司（中国长航）是我国的内河航运企业，隶属于招商局集团，是国家最大的内河、远洋航运企业，拥有百年历史。公司以江海联运、提供航运（沿海-长江）全程物流服务与科技为支撑，提供远洋、沿海、长江等航运服务。公司与多家合资企业合作，是国家落实长江经济带战略的专业化区域性公司。
