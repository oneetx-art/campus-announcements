## 公司
性质:央国企 · 行业:能源/化工/环保

中化泉州石化是国务院国资委监管的国有重要骨干企业中国中化（2024年《财富》杂志世界500强化学品行业榜单第1位）在石油化工领域的旗舰企业，是坐落于福建省湄洲湾石化基地的泉惠石化工业园区，是一家集炼化生产、仓储运输于一体的现代化石油化工企业，总投资655亿元，拥有1500万吨/年原油加工能力、100万吨/年乙烯及80万吨/年芳烃生产能力，含生产装置41套，炼化一体化产能居国内前列，主要产品包括成品油、基础石化原料、有机化工中间体以及聚烯烃等。
