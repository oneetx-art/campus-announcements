## 公司
性质:民企 · 行业:交通/物流/仓储

浙江邦泰物流有限公司成立于2011年，是一家专注于国际工程物流与大宗货物运输的综合型现代物流企业。公司业务涵盖海运、陆运、空运及多式联运，为客户提供从项目策划、运输执行到现场交付的一站式物流解决方案。邦泰物流在国内（宁波、上海、连云港）、印度尼西亚、塞尔维亚、智利、澳大利亚、刚果（金）、坦桑尼亚、赞比亚、莫桑比克、津巴布韦、南非等地设有分公司。
