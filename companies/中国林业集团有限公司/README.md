## 公司
性质:央国企 · 行业:农林牧渔

中国林业集团有限公司（简称中国林业集团）是我国林草行业唯一一家中央企业。中国林业集团忠实践行习近平生态文明思想，主动融入和服务国家重大战略，以“打造具有全球竞争力的世界一流林草生态集团”为目标愿景，聚焦“以国家储备林为主体的森林资源经营管理、生态保护与修复、林产工业、碳汇及相关配套服务”等四大核心主业。锚定林草产业发展主战场，着力打造国家重点生态工程建设示范样板，为推进强国建设、民族复兴伟业贡献中林智慧和中林力量。
