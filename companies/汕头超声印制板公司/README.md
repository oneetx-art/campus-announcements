## 公司
性质:民企 · 行业:通信/电子/半导体

汕头超声印制板公司（简称CCTC），成立于1986年，专业生产PCB，系超声电子股份公司具有国际先进的中外合资企业。中国CPCA副理事长单位。公司管理和软件作业系统均通过ISO9001、ISO14001、IATF16949、ISO45001等国际认证。目前产品包括HDI板、软板、软硬结合板、刚挠结合板等，产品广泛应用于通讯、汽车、医疗、数码、消费电子等领域和产品。
