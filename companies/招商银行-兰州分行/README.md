## 公司
性质:央国企 · 行业:金融业

招商银行兰州分行成立于1996年6月6日，是招商银行在西北地区设立的第一家分行、系统内成立的第七家分行，也是甘肃省第一家入驻的全国性股份制银行。近年来，兰州分行践行价值银行战略，努力为社会各界提供最新最优质的金融服务。截至目前，分行拥有员工千余名，已设立24家同城支行，盈利能力、资产质量等核心指标均达国内先进银行水准。
