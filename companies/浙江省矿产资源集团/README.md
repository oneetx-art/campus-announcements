性质:央国企 · 行业:能源/化工/环保

浙江省矿产资源集团有限公司成立于2023年6月，是浙江省自然资源集团实施矿产资源板块重组和专业化整合出资设立的一级子公司。公司总部位于浙江省杭州市，注册资本金3亿元人民币，下辖4家全资子公司，1家控股子公司，2家参股公司和1家分公司。公司经营范围主要为矿产资源勘查、非煤矿山矿产资源开采、矿产品销售、选矿、矿物洗选加工等。
