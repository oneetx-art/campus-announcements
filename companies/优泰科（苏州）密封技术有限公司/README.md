## 公司
性质:民企 · 行业:机械/制造业

优泰科（苏州）密封技术有限公司创立于2008年，位于苏州工业园区高端制造与国际贸易区，注册资本5390万元，是中密控股集团的全资子公司。作为国内无模具密封产品和服务的先行者，拥有多项自主知识产权和核心技术，填补了国内多项相关技术的空白，是中国橡塑密封行业最具竞争力的企业之一。优泰科专注于橡塑密封材料、橡塑密封制品及加工系统的研发、生产和销售。是国际领先的高品质液压、气动密封的制造商与服务商，可提供多种高性能密封材料及密封整体解决方案。产品广泛应用于采矿装备、能源装备、工程机械、盾构机械和通用机械等领域，并远销全球50多个国家和地区，荣获国家高新技术企业、江苏省研发高端装备用密封件工程技术研究中心、苏州工业园区瞪羚培育企业等荣誉称号，国家专精特新企业，是中国橡塑密封行业的领军企业。
