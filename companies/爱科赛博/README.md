## 公司
性质:民企 · 行业:能源/化工/环保

西安爱科赛博电气股份有限公司创立于1996年，专注于先进电力电子装备业务，现有员工1100余人，研发技术人员500人，是精密测试电源、特种电源、电能质量控制领域领军企业，2023年在上海科创板成功上市。公司在西安设有高新三期总部园区和信息大道园区，在苏州太湖科学城设有苏州基地园区，在成都设有模块电源产品研发生产基地，在北京、深圳、香港设有分子公司，支撑国内和海外业务开展。公司产品广泛应用于光伏储能、新能源汽车、高端科研、航空航天、智能配电网等多个领域，服务过多个国家重大科技基础设施和特种装备重点型号，是多家行业头部企业的优选供应商。公司坚持持续研发创新，与知名高校长期产学研合作，有三个省级创新平台，拥有核心自主知识产权，专利200余项，其中发明专利60多项，参与制定16项国家和行业标准，曾获国家科技进步二等奖等多项荣誉。
