## 公司
性质:民企 · 行业:机械/制造业

秦皇岛兴龙科技集团有限公司（简称中秦兴龙工业集团），隶属于秦皇岛中秦兴龙投资控股有限公司，从2003年开始从事汽车铝合金车轮行业，目前已经发展成为以铝合金车轮研发制造为主，集材料研发、装备、模具研发制造、产品检测于一体的汽车零配件及配套装备生产企业。集团创始于1994年，旗下包含秦皇岛戴卡兴龙轮毂有限公司、秦皇岛兴龙轮毂有限公司、秦皇岛中秦渤海轮毂有限公司、秦皇岛兴龙模具科技开发有限公司、秦皇岛中秦智能装备有限公司、中秦渤海科技有限公司6家子公司。员工4200余人，年产值近80亿元，年纳税1.77亿元，铝合金车轮年产能1650万只，汽车底盘转向节年产能4万吨。
