## 公司
性质:央国企 · 行业:能源/化工/环保

冶金研究设计所是矿冶科技集团有限公司下属的综合性研究机构，作为国家和行业矿冶领域共性关键技术研究的重要力量，肩负着服务国家战略、打造原创技术“策源地”、引领行业科技进步的使命。致力于有色金属冶炼及综合利用关键技术、装备研发与工程实践，解决复杂多金属矿提取与分离、资源综合高效利用等共性技术难题，促进有色金属冶金过程的清洁生产、高效利用与节能减排。研究领域广泛覆盖重金属、稀有稀散金属及贵金属冶金，二次资源循环与综合利用，海底资源开发，冶金药剂、冶金装备与新材料开发等多个前沿方向。历经60余年的耕耘发展，开发了富氧侧吹全热态炼铜、密闭电解、强化悬浮焙烧等一系列工程化技术及装备，获授权发明专利300余项，国家及省部级科技奖200余项。冶金研究设计所现有员工70人，其中享受国务院政府津贴5名，全国有色行业设计大师1名，正高级工程师20人，高级工程师17人，博士24人，硕士38人，拥有一支专业配套完整的高素质人才队伍。
