## 公司
性质:外企 · 行业:文化/传媒/广告/体育

普林斯顿大学出版社成立于1905年，是国际上享有盛誉的非营利学术出版机构，致力于通过全球范围内跨同行评议的书籍联结不同领域的作者和读者，以促进出版范围严谨文化的对话与交流。2017年PUP正式在北京成立办公室，成为第一家、也是目前唯一一家正式在中国注册开设办公室的北美大学出版社。
