## 公司
性质:民企 · 行业:耐用消费品

格力电器（成都）有限公司成立于2018年6月，是珠海格力电器股份有限公司全资子公司，是格力电器全球首个洗衣机产品生产基地。公司坐落于交通便利、风景秀丽的天府之国——成都市新津区新科大道88号，一期总投资约20亿元，占地581亩，总建筑面积达35.48万平方米。园区内包含10栋生产车间、1栋研发中心大楼、1栋职工食堂、4栋职工宿舍楼，拥有3条总装精益生产线，具备高端热泵洗护机、中端滚筒洗衣机、波轮洗衣机全系列产品的生产能力，规划年产量约150万台洗衣机。
