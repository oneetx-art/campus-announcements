## 公司
性质:央国企 · 行业:房地产业/建筑业

华润建材科技是央企华润集团旗下的港股上市公司，是一家业务涵盖水泥、骨料、混凝土、新型建材、供应链的综合性建材企业。拥有国家级绿色矿山9座、省级（自治区）级绿色矿山23座，22家生产基地被列入国家级、省（自治区）级“绿色工厂”名单。位列“中国500强企业”第212位、“中国500强企业”第8位，荣获“2024年可持续发展报告”联央企企业典范评价社会责任报告专家委员会“五星”联央企企业典范评价。
