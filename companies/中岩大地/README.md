## 公司
性质:民企 · 行业:房地产业/建筑业

北京中岩大地科技股份有限公司创立于2008年12月19日，是以岩土技术为核心竞争力的科技型上市企业。中岩大地以“智慧岩土专家”为战略定位，秉承“悦人达己、创新卓越”的企业理念， 致力于以科技为依托，为客户提供更优质解决方案的服务。业务涵盖岩土工程、特种材料、环境保护等岩土板块的服务建设。始终按照“与大地和谐共生”的发展愿景，促进人文环境建设与自然环境保护的协调发展，创建员工与企业共享发展平台，在传承中求发展，推动企业走向卓越。
