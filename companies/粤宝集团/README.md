## 公司
性质:民企 · 行业:商务服务业

粤宝集团是宝马南区最具影响力的经销商集团，在2024年中国汽车经销商集团百强排行榜中位列第84名。作为国内BMW首批授权经销商，不仅是传统豪华车市场的佼佼者，更是新能源领域的时尚引领者。主要代理BMW、Lincoln、Infiniti等豪华品牌，同时还囊括了AITO问界、特斯拉、理想等新能源翘楚，现今已拥有40多家汽车品牌4S店，经营范围覆盖广东、广西、海南、浙江、江苏等地。
