## 公司
性质:民企 · 行业:机械/制造业

镭目科技，创立于1993年，是集科研、研发、生产、销售、服务于一体的创新型技术企业。公司业务涵盖钢铁、核电、化工、材料等多个领域，其中，冶金领域技术产品在国内市场占有率高达85%，产品远销欧洲、北美洲、南美洲、中东、亚洲等地区，共计30多个国家。镭目科技由衡阳镭目公司、长沙镭目公司及北京研究所组成，技术力量雄厚，成就卓然。是国家专精特新“小巨人”企业、国家重点高新技术企业、镭目科技始终致力于科技研发与创新，为钢铁工业提供智能化、信息化、无人化解决方案，打造“一键式”数字化梦工厂。
