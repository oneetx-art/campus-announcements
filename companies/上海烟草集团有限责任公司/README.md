## 公司
性质:央国企 · 行业:快速消费品

上海烟草集团有限责任公司是工商一体，以京津沪三地卷烟工业生产和上海市卷烟商业销售为主的，多元化、集约化、现代化的大型国有企业。公司下辖上海、北京、天津卷烟厂和涉及仓储物流、包装印刷、烟用材料等领域的多家产业链企业，在上海市辖有各区及海烟物流等18家商业企业并涉足酒店、食品等行业，控股参股企业40余家。公司先后获得“全国文明单位”“中国的脊梁”优秀国有企业等多项殊荣。
