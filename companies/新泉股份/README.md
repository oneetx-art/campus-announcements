## 公司
性质:民企 · 行业:汽车制造/维修/零配件

新泉股份（股票代码：603179），是一家上海主板上市公司，专业从事汽车内外饰件系统零部件及模具的设计、制造及销售。公司成立于2001年4月28日，目前国内拥有27家分子公司，海外8家分子公司，1个省级技术中心，1个通过国家CNAS认证的实验中心，全国百家优秀汽车零部件供应商之一，国内领先的汽车饰件整体解决方案提供商。公司通过“造型设计、同步开发、模具管控、产品总成制造、准时交付”等研发及服务的专业能力，为汽车品牌商提供汽车饰件总成内护产品，主要包括仪表板总成、顶饰件框架总成、门内护板总成、立柱护板总成、流水槽盖板总成和保险杠总成等。
