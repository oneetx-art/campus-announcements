## 公司
性质:央国企 · 行业:机械/制造业

航天长峰朝阳电源有限公司，隶属中国航天科工集团第二研究院，是北京航天长峰股份有限公司的全资子公司，注册资本18607.15万元。公司位于辽宁省朝阳市双塔区龙泉大街北段333A号，厂区占地面积16万平方米，建筑面积5.4万平方米。航天朝阳电源专注电源技术研发与电源产品研制生产，是辽宁省“先进集体”，国家级专精特新“小巨人”企业，荣获国防科技进步特等奖等多项荣誉。公司主要研制生产模块电源、单体电源、总线电源、电源系统四大谱系产品，广泛应用于电子信息、新能源、轨道交通、人工智能、智慧医疗、智能制造等领域。
