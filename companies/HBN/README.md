## 公司
性质:民企 · 行业:快速消费品

2019年，功效护肤品牌HBN正式诞生，以“拥有看得见效果”的创新理念，致力于让用户把每一分钱都花在有效成分上。作为国内首个以真功效为理念的护肤品牌，以及国内较早宣布只做能被权威验证的“真实有效”的护肤品的先驱品牌之一，HBN通过权威第三方人体功效检测，推动护肤品均“持证上岗”，让“真功效”名副其实。HBN创始人原为国内知名大学的一名老师，拥有行业少见的科技与美学交叉专业背景。品牌自成立起便坚持自主创新研发，自建了CNAS权威认证实验室，拥有高规格超5000㎡产研一体化研发中心，并搭建起超百人的高素质交叉学科研发团队，其中硕士、博士等高学历人才占比高达85%。HBN也是国内产业极少持续重投基础研发的品牌，通过自研和内外共同结合，以第一作者或第一完成单位发表近40篇SCI国际期刊论文；同时完成四款中国自研功效新原料备案，数量位列国货护肤品牌前列。发展八年，HBN目前已身中国美妆行业头部阵营，是当下最年轻的行业头部阵营品牌；5年累计销售额超过70亿，成为了国内人气、销量、口碑领先的中国功效护肤标杆品牌。
