## 公司
性质:民企 · 行业:医疗/医药/生物

浙江永太科技股份有限公司成立于1999年10月，是一家以高端氟精细化学品研发、生产和销售为核心业务的国家高新技术企业，于2010年在深圳证券交易所上市（股票代码002326）。公司主要从事氟苯精细化学品的研发、生产和销售，产品涵盖医药、农药和电子化学品等领域。永太科技在浙江、上海、广东、福建、内蒙古等地设有子公司，并在美国、德国设立了销售、研发中心。公司拥有员工3500余人，其中研发人员600+名，与美国默沙东、德国默克、巴斯夫、拜耳、宁德时代、比亚迪等全球知名企业建立了长期合作关系。
