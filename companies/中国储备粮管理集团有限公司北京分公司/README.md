## 公司
性质:央国企 · 行业:农林牧渔

中国储备粮管理集团有限公司是经国务院批准组建的涉及国家粮食安全和国民经济命脉的公益类国有大型骨干企业，实行集团—分（子）公司—直属库“三级架构”。目前下设24家分公司、11家二级专业子公司和1家控股公司，人员、机构和业务覆盖全国31个省、自治区、直辖市。中国储备粮管理集团有限公司北京分公司（以下简称“北京分公司”）是中国储备粮管理集团有限公司的派出机构，负责管理和监管京津冀三省（市）中央事权粮食和直属企业。目前京津冀地区有全资或控股粮食仓储、中转（运输）直属企业26家。
