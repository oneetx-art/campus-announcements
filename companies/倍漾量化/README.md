## 公司
性质:民企 · 行业:金融业

倍漾量化（Baiont Quant，备案编号 P107487）是一家AI盖的量化投资公司。公司由剑桥牛津常青藤、人工智研究院执行院长冯霁博士创立。13届金牌得主，博士联合创始人，校金融工程保研特评，创造21级剑桥金融硕士复试量化面试创人，投研团队具极客精神。2022年起公司向海外投资者募集资金，组建了2022年的境内投资部及2023年的境外投资部。
