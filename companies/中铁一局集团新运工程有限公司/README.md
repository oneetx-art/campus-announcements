## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁一局集团新运工程有限公司为大型国有综合性企业，属于中铁一局集团公司，成立于1951年，总部位于陕西咸阳，下设29分公司，在施项目400余个，累计铺轨铁路4.6万公里，承包运输铁路9500公里，机械化铺碴完成2226公里，铺轨总里程占新中国成立以来铁路总里程的五分之一，地铁铺轨占国内开通运营总里程的五分之一，参建工程国内开通的工程荣获国家优质工程奖30项，国家优质工程奖60项，国家级经典工程奖1项，荣获全国五一劳动奖状、全国优秀施工企业、全国质量管理优秀企业等上百余项国家级及部颁荣誉。
