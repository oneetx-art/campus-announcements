## 公司
性质:央国企 · 行业:机械/制造业

青岛中科国晟动力科技有限公司（简称“中科国晟”）成立于2017年10月，由中国科学院工程热物理研究所与青岛城投投资集团有限公司、青岛军民融合发展集团有限公司共同发起成立，位于青岛市西海岸新区横口国家级军民融合创新示范区。中科国晟专注于20-50MW轻型燃气轮机研发与产业化，tG30系列燃机轮机实现100%自主化生产，广泛用于电力、机械驱动、船舶动力等核心装备，产品应用于电力与能源动力系统等领域。业务范围涵盖燃气轮机整机、油气、冶金、化工、大中修服务与备件供应、技术咨询与培训，及元化解决方案设计管理、EPC总承包、合同能源管理等多元化解决方案。
