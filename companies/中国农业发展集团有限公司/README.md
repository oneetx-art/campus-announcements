## 公司
性质:央国企 · 行业:农林牧渔

中国农业发展集团有限公司（简称中国农发集团）成立于2004年，是国务院国资委直接管理的大型综合性中央农业企业，由原农业部所属中国水产（集团）总公司、中国牧工商（集团）总公司等企业多次合并重组而来。经过多年改革发展，已成为横跨农牧渔、纵贯一二三产业、服务功能完整的农业生产与服务型企业，主营业务范围涵盖种业、渔业、畜牧业及农业服务业等领域。在世界30多个国家（地区）建有项目基地和分支机构，与100多个国家（地区）保持经贸往来。
