## 公司
性质:央国企 · 行业:政府/机构/组织

深圳市城市公共安全技术研究院有限公司是市委、市政府2016年创新设立的唯一聚焦城市公共安全领域的市属国有企业，是国家高新技术企业、国务院国资委科改企业、深圳市专精特新企业。城安院首创国内城市公共安全宽口径、多领域研究模式和企业化市场化运作机制，围绕自然灾害、事故灾难、公共卫生、社会安全全场景，结合城市安全发展需求，聚焦政策研究、风险评估、监测预警应急处置、调查评估和安全文化全过程，全周期开展安全咨询与支撑安全科技与创新、安全投资与推广三大版块业务，形成了城市全域风险识别辨识与评估、城市高风险单元综合监测预警、城市安全综合应急处置、城市安全技术创新与智囊支持、安全应急产业引领带动等五大核心能力，构建大安全大应急框架下的“全灾种统筹应对、全过程统一管理、全天候积极防范、全力量有效协调”服务支撑保障体系。
