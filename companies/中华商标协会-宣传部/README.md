## 公司
性质:社会组织 · 行业:政府/机构/组织

中华商标协会（英文名称：CHINA TRADEMARK ASSOCIATION，缩写：CTA）成立于1994年，是国家民政部批准成立的商标领域全国性专业社团、商标代理行业组织，由国内知名企业发起、受原国家工商行政管理总局直接领导，承担着宣传商标政策法律、提升社会商标品牌意识、加强商标代理行业自律、服务商标品牌建设、促进商标品牌国际交流等职能。
