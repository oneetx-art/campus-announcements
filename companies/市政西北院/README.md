## 公司
性质:央国企 · 行业:房地产业/建筑业

中国市政工程西北设计研究院有限公司成立于1959年，原属国家建工部，2000年加入中国建筑集团，2007年全面改制为中建股份有限公司控股。AECOM技术集团参股的中外合资企业。作为具备工程设计综合甲级资质的设计企业，中建市政西北院秉承“全链条咨询+全产业链服务”理念，以基础设施建设全生命周期服务为核心，依托专业技术和数字化能力，提供涵盖工程咨询、勘察设计、工程总承包、项目管理及投资运营等一体化服务。公司总部设立在兰州，有17个生产部门，在全国22个省的主要城市设立了29家实体分支机构及3家子公司。
