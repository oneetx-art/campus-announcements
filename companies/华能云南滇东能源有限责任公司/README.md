## 公司
性质:央国企 · 行业:能源/化工/环保

华能云南滇东能源有限责任公司成立于2003年8月18日，公司下辖滇东厂区和雨汪厂区，是国家实施“西部大开发”能源战略开发建设的重点能源项目。滇东厂区现运行装机容量2400MW(4×600MW)，雨汪厂区现运行装机容量1200MW(2×600MW)，雨汪二期扩建2×1000MW超超临界火电机组于2025年6月开始桩基建设。公司是云南电网及南方电网的骨干企业，对优化云南电网电源结构、提高电网运行可靠性和经济性起到积极作用，是集经济效益、社会效益、生态效益于一体的高效、环保工程。
