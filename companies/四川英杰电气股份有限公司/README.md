## 公司
性质:民企 · 行业:机械/制造业

四川英杰电气股份有限公司成立于1996年，是专业的工业电源设备研发及制造企业，于2020年在深交所创业板上市，拥有8家分子公司，在多地设有研发中心，是多项荣誉企业，产品应用广泛，总部位于四川德阳
