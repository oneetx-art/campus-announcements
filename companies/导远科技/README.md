## 公司
性质:民企 · 行业:通信/电子/半导体

导远科技（Asensing）成立于2014年，专注于时空感知领域的技术研发和产品开发，是全球领先的定位传感器及解决方案供应商。基于自研芯片和算法，导远科技打造了多种形态的高精度定位、姿态传感器产品和集软硬一体的解决方案，用精准、实时、可靠的定位和姿态信息赋能多种载体实现准确、安全的自动驾驶，助力汽车、机器人、智慧农业、清洁能源、低空经济、工程机械、智慧交通和医疗器械等行业的智能化升级。导远已为全球30多家车企和数百家机器人、能源工业、智慧农业、三维扫描等多个行业的企业提供高精度定位产品及解决方案，其中汽车领域装配车型超100款，国内车型覆盖率超70%，并获得多家国际车企的技术认可及定点，截至2025年9月底，公司已量产交付超500万套产品。
