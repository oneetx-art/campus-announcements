## 公司
性质:民企 · 行业:通信/电子/半导体

新忆科技成立于2018年，孵化自清华大学新型存储器团队，致力于RRAM新型存储技术和存算一体技术的研发，是一家拥有核心技术和自主研发能力的创新型高科技企业。公司主营业务为新型阻变存储器（RRAM）及其周边产品，包括嵌入式RRAM IP、独立式存储器和面向端侧的算力核心器件。应用领域涵盖手机、安全芯片、物联网、消费电子、医疗电子、网络通信设备和工业控制设备等。其中独立式存储器产品2021年已量产，累计出货超千万颗。
