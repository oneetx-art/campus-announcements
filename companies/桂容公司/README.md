## 公司
性质:民企 · 行业:机械/制造业

桂林电力电容器有限责任公司的前身是桂林电力电容器总厂，创建于1967年，是原国家机械部直属企业、国家二级企业、全国500家大型机械及设备制造业之一。2017年投资成立全资子公司——桂林智源电力电子有限公司。公司是国家技术创新示范企业、国家高新技术企业、国家专精特新重点“小巨人”企业、国家级绿色工厂、博士后科研工作站，是电力电容器及其成套设备的专业制造企业和科研基地。
