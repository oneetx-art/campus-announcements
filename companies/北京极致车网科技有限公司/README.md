## 公司
性质:民企 · 行业:贸易/批发/零售

北京极致车网科技有限公司成立于2014年11月，由中石油，北京市海淀区政府和美元基金经纬中国共同出资设立。以大数据和技术创新为核心驱动力，致力于为客户提供安全、专业、高效的汽车金融服务，是中国知名的汽车消费金融系统和综合服务供应商，属于高科技、高增长（两高）性企业。九年间先后完成由联想集团、中国石油、经纬中国、华映资本，戈壁创投，春晓资本等四轮共计3亿元融资。创始团队由资深专家和互联网企业精英组成。截至2025年，业务覆盖全国10余个省份60多个城市，累计服务客户近百万人，放款金额超500亿元，系统备案经销商2万余家，22年全年交易额超70亿。现有员工500余人，90%的员工都是90后，平均年龄27岁。
