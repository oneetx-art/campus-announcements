## 公司
性质:央国企 · 行业:汽车制造/维修/零配件

上汽红岩汽车有限公司拥有60年民族重卡制造经验,以'上汽红岩·中国力量'为品牌核心,以信得过的技术、安全可靠的产品、有温度的企业为品牌价值内涵,持续推动中国重卡产业发展。公司位于重庆两江新区,注册资金46亿元人民币,现有员工2000余人,具备年产7.5万辆整车的生产能力。上汽红岩拥有数百条经经销商、近千家服务商,实现零部件全球化采购,产品出口欧洲、非洲、东南亚、中东、南美洲等40多个国家和地区。在上汽集团的技术赋能下,上汽红岩不断推动重卡产品向新能源化、智能化、网联化、定制化方向升级迭代,开启全球首例'5G+L4'智能驾驶重卡商业化运营,实现互联网梦想卡车3.0全系配置,新业态合作平台持续拓展;产品覆盖纯电动、燃料电池、混合动力三大技术领域,掌握电驱、电控、电池系统核心技术。面向未来,公司将秉持'红岩精神',锚定'智电'赛道,坚持'科技+生态'双轮驱动,聚焦全价值链创新,成为全球绿色、高效、智慧物流解决方案的领先者,持续为成渝地区双城经济圈建设和西部大开发战略贡献力量,持续彰显重庆制造的实力与担当。
