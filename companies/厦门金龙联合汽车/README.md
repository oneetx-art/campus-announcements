## 公司
性质:央国企 · 行业:汽车制造/维修/零配件

厦门金龙联合汽车工业有限公司（简称“金龙客车”）成立于1988年12月，隶属于厦门金龙汽车集团股份有限公司（股票代码：600686）。2025年，金龙品牌价值高达1096.18亿元，位列中国汽车行业品牌前列。金龙秉承“建设美好出行社区”，致力于“成为智慧交通领域的解决方案提供商”。业务领域涵盖：物质流（新能源重卡、房车和自动驾驶等商用车的研发设计、制造与销售）；能量流（新能源技术研发及产业化）；信息流（智慧交通系统解决方案）。企业实力方面，拥有CNAS国家试验室、工业设计中心、博士后工作站及福建省重点实验室等7个国家级部级科技创新平台，累计获得35项国家省部级科技成果奖，是国家企业技术示范企业、“两化融合”示范企业、国务院国资委科改标杆企业。国际化战略上，金龙坚持国际化经营之路，深耕海外市场二十余年，深入践行“一带一路”倡议，累计向全球近150个国家和地区，出口14万辆大中型客车，连年位居行业第一。
