## 公司
性质:民企 · 行业:金融业

泰康保险集团股份有限公司成立于1996年，已发展成为一家涵盖保险、资管、医养三大核心业务的大型金融保险服务集团。泰康基金是泰康资产在公募基金行业的重要布局。泰康基金管理有限公司前身为泰康资产公募事业部，2015年4月泰康资产作为首家获得公募基金管理业务资格的保险系资管公司，以公募事业部的方式进军公募基金领域。2022年11月，泰康资产和泰康基金安全、平稳、高效地完成了公募基金业务的平移交接。
