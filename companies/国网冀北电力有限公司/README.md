## 公司
性质:央国企 · 行业:能源/化工/环保

国网冀北电力有限公司是国家电网有限公司的省级子公司，本部设在北京，供电区域覆盖唐山、张家口、秦皇岛、承德和廊坊，负责运维首都500千伏大环网、华北地区万余公里“西电东送”、“北电南供”大通道和特高压线路，肩负保障首都供电安全、服务冀北地区经济社会发展和国家新能源发展的重要职责使命。冀北公司地处京畿、环绕首都，公司以构建坚强智能电网为己任，努力为冀北五地市的经济发展和社会民生提供可靠电力保障和优质供电服务。作为国家“十四五”规划九大清洁能源基地之一的冀北清洁能源基地，风能、太阳能资源丰富、开发迅猛，拥有世界装机容量最大的抽水蓄能电站、世界首个柔性直流环网工程、国家首个风光储输示范工程，成为探索和实践新型电力系统的典型区域。公司围绕中国式现代化建设河北篇章和国家电网高质量发展布局，以争创“两个标杆”（新型电力系统示范标杆、高质量发展标杆）为引领，全力推进新型电力系统建设。欢迎各位高校毕业生前来应聘！
