## 公司
性质:央国企 · 行业:通信/电子/半导体

中国铁塔股份有限公司云南省分公司（简称“云南铁塔”）是中国铁塔在云南省的分支机构。云南铁塔于2014年10月31日注册成立，作为十八大后成立的“新国企”，公司成立后始终践行以共享为核心的新发展理念，着力推动“网络强国”“5G新基建”“数字云南”等国家战略的落地见效，不断夯实数字通信网络底座。
