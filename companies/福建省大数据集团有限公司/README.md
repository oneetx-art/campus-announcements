## 公司
性质:央国企 · 行业:IT/互联网/游戏

福建省大数据集团有限公司是全国率先成立的省级国有独资大数据企业，于2021年8月26日注册成立，注册资本金100亿元，拥有一级管理企业9家，其中包括控股上市公司1家。集团的成立，是福建省委、省政府坚持一张蓝图绘到底，深化“把数字福建建设作为基础性先导性工程”重大决策部署，加快培育数据要素市场，进一步推进新时代数字福建建设的重要举措。集团定位为省级电子政务公共平台和省级部门政务信息系统主业主单位，负责省级电子政务网络、云、平台等系统的建设和运维；全省公共数据资源一级开发主体；全省数字经济发展的市场、专业主主体及主要投资平台。
