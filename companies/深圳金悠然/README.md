## 公司
性质:民企 · 行业:生活服务业

深圳市金悠然科技有限公司（Royal Dental Laboratory）成立于1994年，是佳兆业健康集团成员（股票代码：00876.HK），国家高新技术企业，销售网络覆盖全国各大中城市。公司创立了国际知名品牌——美加，销售网络的义齿领军企业。公司自成立以来，一直致力于为人类牙齿的健康和靓丽提供高效的一站式牙齿修复解决方案，为广大的牙科医生和消费者提供安全、优质、快捷的产品服务。公司拥有一支专业、高效且具有凝聚力的国际化技术团队和管理团队；并有独特的创新管理模式，通过对国际前沿技术的掌握和研究、高科技精密设备的引进，不断对新型材料的应用，始终保持与世界先进牙科技术同步发展，并对世界牙科创新进行持续而有效的探索。
