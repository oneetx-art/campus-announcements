## 公司
性质:民企 · 行业:能源/化工/环保

华油惠博普集团（以下简称HBP）成立于1998年，于2011年2月25日在深圳证券交易所主板上市（股票代码：002554），是我国第一家登陆A股市场的石油石化领域的技术及设备系统解决方案提供商。作为一家国有控股的上市集团，HBP拥有30多家全资、控股及参股公司，在中东、中亚、非洲等地设有分、子公司及办事处，目前主营业务涵盖油气工程及运营服务、环境工程及服务、碳中和工程及服务、油气资源开发及利用一体化服务等领域。
