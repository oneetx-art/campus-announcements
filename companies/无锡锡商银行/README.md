## 公司
性质:其他 · 行业:金融业

无锡锡商银行诞生在享有“百年工商名城”美誉的无锡，是全国第十九家民营银行，注册资本20亿元，于2020年4月开业。本行秉持服务中小企业、服务科技创新、服务城乡居民的初心，坚持差异化定位、市场化机制、数字化赋能，致力持续提升数字信用能力，解决市场未被有效满足的金融需求，让产品易知、服务易得、实惠易享。开业至今，本行稳健经营存贷款主业，整体规模稳步增长，风险内控相对稳健，探索出供应链金融与个人金融“双轮驱动”的特色化经营模式，在运用金融科技、践行普惠金融、服务实体经济等方面取得了一定的实效，成为无锡本地助民扶微的金融生力军。
