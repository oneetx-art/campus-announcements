## 公司
性质:民企 · 行业:医疗/医药/生物

北京泰德制药股份有限公司成立于1995年，坐落于北京经济技术开发区，是专注于国际领先高端制剂技术和创新生物医药领域的高科技制药企业，是中国先进的靶向药物、现代外用透皮膏贴剂药物研发和产业化基地。公司已连续13年入选国家工信部中国医药工业百强榜，连续7年入选中国医药研发产品线最佳工业企业。
