## 公司
性质:央国企 · 行业:通信/电子/半导体

南京熊猫汉达科技有限公司（国营第七一四厂）的前身——中央无线电器材厂在炮火声中创建，被誉 为中国电子工业的摇篮。公司隶属于中国电子信息产业集团，是国内领先的信息与通信解决方案供应商，在短波、超短波、卫星、SJL等通信领域始终处于行业龙头地位。公司产品广泛应用于机载、舰载、背负、手持移动等通信端，拥有多项知识产权，填补了我国电子通信领域多项空白，致力于奉献国家通信工程、通信保障等重大重点通信建设，被誉为我国电子通信“国家队”称号。
