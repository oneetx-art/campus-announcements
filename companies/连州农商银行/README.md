## 公司
性质:民企 · 行业:金融业

连州农商银行前身为连州市农村信用合作联社，经原中国银行保险监督管理委员会批准于2019年1月开业，至今已有70余年的发展历程。作为深耕连州的地方金融长子，连州农商银行始终坚持党建引领发展，坚守支农支小、服务实体经济的初心使命，践行普惠金融、助力乡村振兴，将金融长子的责任与担当牢牢扛在肩上，为推动连州经济社会高质量发展注入源源不断的金融活水。截至2025年11月末，连州农商银行现有网点21个，从业人员280多人。资产总额达132.30亿元，各项存款余额117.24亿元，各项贷款余额76.48亿元，存贷规模及市场占有率连续多年名列连州市银行业金融机构前茅，是与“三农”“小微”联系紧密的本土法人银行，是支持县域经济高质量发展的重要金融支柱。
