## 公司
性质:央国企 · 行业:通信/电子/半导体

中国航天科技集团有限公司深入贯彻落实党中央关于卫星互联网系统建设的重大战略部署，主动作为，创新担当，整合航天五院、八院星任务的优势力量，于2024年9月在雄安新区设立中国航天科技集团商业卫星有限公司（简称“中国商业卫星”）。中国商业卫星公司肩负了集团公司赋予的三重使命：以服务星网高质量建设为工作主线，全力支撑星网系统任务高质量完成；不断深化体制机制改革，打造航天科技集团公司全面深化改革样板；构建具有竞争力的核心产品和能力体系，助推集团公司产业升级，打造适应量产价低可靠的全面开放的供应链生态，矢志建成“中国第一、世界领先”商业卫星公司。
