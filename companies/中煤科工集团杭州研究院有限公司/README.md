## 公司
性质:央国企 · 行业:能源/化工/环保

中煤科工集团杭州研究院有限公司成立于1958年，现为国务院国资委管理的中国煤炭科工集团管理的二级企业，首批国家高新技术企业，国家级专精特新“小巨人”企业，是我国煤炭行业和工业环保领域科技创新的国家队和排头兵，主要从事环保技术的研究开发、技术咨询、工程设计、工程承包、工程运维和产品生产等业务，是中国煤炭学会环境保护专业委员会依托单位，负责编辑出版国内外公开发行的《能源环境保护》杂志。
