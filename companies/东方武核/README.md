## 公司
性质:央国企 · 行业:机械/制造业

东方电气（武汉）核设备有限公司（简称东方武核），位于湖北省武汉市，是中国东方电气集团有限公司的核心子企业。公司主要从事核电站反应堆堆内构件的产品研制和服务，成立以来已成功研制了我国自主知识产权的三代核电“华龙一号”百万千瓦级核电堆内构件、全球首台模块化小堆“玲珑一号”堆内构件等多种堆型的核电产品，为擦亮国家核电名片贡献了东方力量。公司在核设备研制期间曾荣获国家科学大会奖、国家科技进步特等奖、国家发明三等奖的荣誉，是国家级专精特新重点“小巨人”企业、国家级“绿色工厂”、国家“高新技术企业”。公司秉承“求实 创新 人和 图强”的企业精神，坚持“专、精、特、新”的发展路线，始终以服务国家战略为已任，着力打造世界一流的核动力装备研制和服务企业。
