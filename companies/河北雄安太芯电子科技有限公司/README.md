## 公司
性质:央国企 · 行业:通信/电子/半导体

河北雄安太芯电子科技有限公司是中国电科十三所在雄安新区重点布局的高端芯片设计公司，是雄安新区二类疏解企业和重点支持的集成电路设计企业，主要面向5G毫米波和6G通信、卫星通信、毫米波与太赫兹安检交通雷达以及高端微波测试测量等新兴产业，设计开发高端射频芯片，提供前端硬件解决方案，综合技术水平行业领先。已获‘国家高新技术企业’‘国家科技型中小企业’‘专精特新中小企业’‘雄安新区企业技术中心’等资质，荣获第九届中国创新创业大赛（河北赛区）冠军、河北省优秀集成电路企业。
