## 公司
性质:央国企 · 行业:能源/化工/环保

重庆三峡学院是由重庆市人民政府主办的全日制普通本科院校，学校始建于1956年，坐落于重庆市万州区。现有万州、沙龙两校区，占地面积近1800亩，校舍建筑面积约为50.39万平方米。2013年增列为硕士学位授予单位，2017年被列为重庆市博士学位授予单位立项建设（培育）单位，2021年获批重庆市市级博士后科研工作站，重庆市委宣传部批复学校为重庆市首批“市级重点马克思主义学院”。
