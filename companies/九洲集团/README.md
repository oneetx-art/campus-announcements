## 公司
性质:央国企 · 行业:通信/电子/半导体

四川九洲投资控股集团有限公司（以下简称“九洲集团”）位于中国科技城四川省绵阳市，前身为国营涪江机器厂，始建于1958年，为国家“一五”期间156项重点工程之一的大型高科技企业集团。专注于电子信息产业，经过60余年的发展，已成为军工企业、空管系统科研生产基地、国家有线电视宽带网络系统和数字电视设备龙头企业。
