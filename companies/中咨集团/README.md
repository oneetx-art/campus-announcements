## 公司

中国公路工程咨询集团有限公司（简称“中咨集团”）于1992年在京成立，是世界500强企业——中国交通建设集团有限公司的全资子公司。中咨集团拥有公路交通全产业链，具备“工可—设计—投资—建设—监理—运营—养护”全过程、一体化解决能力，是行业运营的全过程咨询服务商。下设30余家子、分公司，经营范围遍布全国各省、市、自治区，并拓展到亚洲、非洲、欧洲40余个国家和地区。
