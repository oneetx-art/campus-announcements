## 公司
性质:事业单位 · 行业:政府/机构/组织

中国科学院长春光学精密机械与物理研究所成立于1952年，是新中国第一个以光学为主要研究领域的国立科研机构，被称作新中国“光学的摇篮”。现有职工2600余人，在多个科研领域成果显著，业务涵盖光电传感等，形成光电子产业集群，近五年产业系统累计销售收入超160亿元。
