## 公司
性质:民企 · 行业:机械/制造业

东莞盛雄激光成立于2008年，注册资本5100万，是国家高新技术企业、国家级专精特新小巨人企业、东莞市上市后备企业。成立至今共申请专利133项，其中发明专利44项。拥有多学科交叉设备，尤其在高功率皮秒/飞秒激光器、超激光微加工工艺、激光加工算法和机器视觉方面有丰富经验的产线技术支撑。17年加工时间，东莞盛雄激光从一家普通的激光打标机制造商发展成为中国超快激光微纳加工系统细分领域前三强，设备单价以100-500万元为主，并且拥有自研核心功率超快激光光源，目前公司主营业务聚焦于新能源动力电池和太阳能光伏，全球首创300W大功率皮秒激光器叠片电池正极极片制片装备。
