## 公司
性质:央国企 · 行业:能源/化工/环保

东江环保股份有限公司（以下简称“东江环保”），成立于1999年，是广东省属国有控股深港两地上市公司，隶属广晟控股集团。东江环保总部及56家分子公司，具备44类危险废物经营资质，年危废处置能力超280万吨。经过25年发展，东江环保已成长为以工业和市政废物的资源化利用与无害化处理、稀贵金属回收为主，水治理、环境工程、环境检测协同发展的大型集团公司。
