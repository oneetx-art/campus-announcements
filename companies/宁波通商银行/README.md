## 公司
性质:其他 · 行业:金融业

宁波通商银行于2012年4月16日成立，注册资本52.2亿元，是国内首家由外资银行成功重组而来的城商行。成立以来，始终坚持稳中求进的总基调，坚定走差异化特色化发展道路，致力建设高美誉度的专业“心”银行，目前已成长为一家规模适度、特色鲜明、质效良好、品牌形象不断提升的专业特色银行。连续多年荣获“宁波市服务业纳税20强”，主体评级连续为AA+。2024年在中国银行业协会综合评价城商行序列排名第23位；在英国《银行家》千家银行排名第620位。总部位于宁波，在上海、杭州、绍兴等地设有分行，并在上海成立资金营运中心，形成了“立足宁波、辐射长三角”的经营发展格局。
