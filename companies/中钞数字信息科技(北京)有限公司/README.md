## 公司
性质:央国企 · 行业:IT/互联网/游戏

中钞数字信息科技(北京)有限公司是中国印钞造币集团有限公司所属唯一以数字信息技术为主营主业的专业化公司，依托于印钞造币行业的数字化发展，肩负“信息技术研究、金融科技创新、财务共享服务”三大主责，承担中国印钞造币集团有限公司信息化建设与运行维护任务，以数字人民币为核心的金融科技理论化体系与前瞻性技术研究，以及财务共享服务的建设与运营。公司将以金融科技为核心，推动金融科技与印钞造币产业深度融合，助力中国印钞造币集团有限公司和印钞造币行业实现转型升级创新发展。
