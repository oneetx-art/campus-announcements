## 公司
性质:央国企 · 行业:能源/化工/环保

东北电力设计院创建于1950年，是新中国诞生后成立的第一个电力勘察设计单位，国家高新技术企业。具有开展工程项目管理（含全过程工程咨询）、勘察设计、总承包与项目管理（含监理工程师）、咨询、核电及新能源等能源业务的完整产业链，形成了以电网工程、电源工程、新能源、环境工程、产业规划及国际工程服务，能源电力规划研究、工程总承包及项目管理、工程咨询及工程监理（含新能源、核电等）、生态环保及能效改造等业务，直流输电、综合能源、储能、煤储、碳捕、氢能、柔性、智慧化、建筑、运营一体化解决方案等，为客户提供投资、设计、建设、运营、调试等咨询服务。
