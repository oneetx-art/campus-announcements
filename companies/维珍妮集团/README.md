## 公司
性质:合资 · 行业:快速消费品

维珍妮国际(控股)有限公司(下称“维珍妮”)创建于1998年，总部位于香港，2015年在香港联交所主板上市。作为行业全球领先的创新设计制造商，维珍妮通过IDM(创新设计制造商)的业务模式，为全球领先的品牌创新、设计与制造一系列的高端科技内衣、功能性运动产品，以及消费电子类产品配件。
