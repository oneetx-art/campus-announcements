## 公司
性质:民企 · 行业:机械/制造业

北京微纳星空科技股份有限公司成立于2017年8月，主要从事卫星整星、地面站产品的研发与制造业务，围绕卫星解决方案为客户提供包括论证、设计、制造、测试、发射、测运控在内的“一站式”“星地一体化交付服务。作为国家专精特新“小巨人”企业、国家级高新技术企业、商业航天领域独角兽企业，微纳星空拥有自主知识产权的卫星平台和核心部件，掌握卫星制造近40项关键技术，拥有注册专利超300件。目前，微纳星空已在北京、长春、无锡、成都等地广泛布局，构建起一条涵盖整星、载荷和部组件的“研、产、试”造星全闭环，构建起年产大于60颗卫星的研制能力。
