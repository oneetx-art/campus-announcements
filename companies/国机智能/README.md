## 公司
性质:央国企 · 行业:机械/制造业

国机智能科技有限公司（简称“国机智能”）是中国机械工业集团有限公司直属企业，其前身为始建于1958年的第一机械工业部广州热带机床研究所，与下属始建于1958年的原机械工业部广州机床研究所，是国内机床行业归口“液压、润滑、密封”类技术研究与应用以及橡胶机械与电加工技术研究开发、润滑、液压、密封等技术及相关产品研制单位。
