## 公司
性质:其他 · 行业:金融业

晋商银行股份有限公司（简称“晋商银行”，英文JIN-SHANG BANK CO.,LTD,2558.HK），总行在山西太原，2008年12月30日经中国银监会批准于太原市商业银行更名，在2009年2月28日正式挂牌成立，并于2019年7月18日在香港交易所上市。在山西省委、省政府的正确领导下，在监管部门的指导帮助下，晋商银行先后实施引进战略投资者、H股上市等战略性突破，逐步走上了稳健发展、业绩良好、风险可控的现代商业银行发展道路。成立以来，晋商银行秉承“以客户为中心”的服务理念，实现了对全省11个地级市的网点全覆盖，目前下辖154家营业网点。
