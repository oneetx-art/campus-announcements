## 公司
性质:民企 · 行业:能源/化工/环保

广特集团（注册商标“广特电气”）成立于2000年，毗邻广州南站，公交站直达，是一家集能源投资、建设运维、电力设备制造、电力工程设计、电力工程安装的集团化企业。集团由广东广特电气、广东东维能电气、江苏广特电气、瀚阜能源、广特新能源、诚汉设计、华电建设、进源类电器等多家公司组成，致力于全球客户提供能源类投资及用电方案的咨询、设计、建设、运维、技术支持等全方位系统集成的优质服务。集团下辖有三山、狮山、江苏三大生产基地，公司专业生产智能型高低压成套设备，智能型断路器，电力变压器（叠铁芯和节能型三维立体卷铁芯）等输配电设备。公司各类产品均严格按国家标准、ISO9001质量管理体系、3C质量认证体系生产，注册商标“广特电气”被评为广东省著名商标，在市场上享有较高美誉度和知名度。
