## 公司

上海电气富士电机电气技术有限公司成立于2014年2月，由上海电气集团和富士电机株式会社共同投资组建，专注于变压器类产品的研发、制造、销售与服务，为全球客户提供卓越品质的电气传动产品和一体化系统工程解决方案。公司拥有全球化的研发、销售、制造和服务体系，产品远销40多个国家和地区，广泛应用于电力、化工、冶金、水利等领域，取得了迪拜光伏、印度水利工程等一批世界级标杆项目。
