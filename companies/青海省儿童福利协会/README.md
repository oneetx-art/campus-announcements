## 公司
性质:社会组织 · 行业:政府/机构/组织

青海省儿童福利协会于2015年7月在省民政厅注册成立。协会主要围绕儿童保护、儿童发展和儿童机构赋能，重点开展政府购买、困境儿童救助帮扶防灾减灾以及流动儿童关爱等服务。是壹基金、上海联劝公益基金会和海南成美慈善基金会青海地区枢纽机构。
