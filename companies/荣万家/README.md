## 公司
性质:民企 · 行业:房地产业/建筑业

荣万家生活服务股份有限公司（简称荣万家）成立于2000年11月，是中国物管协会会员单位，2021年1月15日在港交所上市（股票代码H02146）。荣万家成立以来不断发展壮大，截至2025年6月30日，公司管理485个物业项目，在管建筑面积约9060万平方米，覆盖中国19个省、直辖市及自治区的69个城市，订约管理523个物业管理项目，总合约面积约71个城市。管理项目涵盖住宅物业及非住宅等业态，包括商业物业，如物业、体育场馆、政府办公楼、学校、医院、公共交通等。荣万家有城市环卫、城市环卫、垃圾分类处理、园林绿化、水处理是一家大型的综合性专业物业服务企业。
