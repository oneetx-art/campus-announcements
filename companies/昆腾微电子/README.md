## 公司
性质:民企 · 行业:通信/电子/半导体

昆腾微电子是一家集成电路设计高新技术企业，公司于2006年9月在北京成立。目前，注册资本8,600万元，总部位于北京市海淀区，在西安、深圳设有分支机构。公司专注于模拟集成电路的研发、设计和销售，主要产品包括音频SoC芯片和信号链芯片。音频SoC芯片包括无线音频传输芯片、FM/AM收发芯片、USB音频芯片等，主要应用于消费电子领域。信号链芯片主要为数据转换器产品，包括模数转换器（ADC）、数模转换器（DAC）以及集成型数据转换器，主要应用领域为通信、工业控制等。
