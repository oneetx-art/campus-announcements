## 公司
性质:央国企 · 行业:政府/机构/组织

湖南湘江新区发展集团有限公司（简称湘江集团）是由长沙市政府直属管理、湖南湘江新区管理委员会履行出资人职责的国有大型企业，集团成立于2016年4月，注册资本550亿元，资产规模超2400亿元，信用评级为AAA级。集团聚焦城市开发、产业投资、金融服务三大主业板块，致力于打造国内一流的城市综合运营服务商。
