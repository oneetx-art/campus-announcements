## 公司
性质:央国企 · 行业:通信/电子/半导体

深圳市鹏新旭技术有限公司（简称鹏新旭、PST），总部位于深圳市坪山区，是深圳市重大产业项目旗下的一家高端技术型企业，于2022年3月注册成立，公司聚焦集成电路泛工程建设和卓越制造，致力于芯片灌流需求，为客户提供高制程应用的泛工程产品，满足多厂区设计。目前公司已开发支持产品功能的领军人。
