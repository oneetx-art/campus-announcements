## 公司
性质:央国企 · 行业:耐用消费品

长虹创始于1958年，历经多次转型，已发展成为集智慧家居、数字产业、特种装备、绿色能源、医疗健康等产业为主的千亿级跨国企业集团。旗下拥有7家上市公司，3家新三板公众公司，产品和服务覆盖160多个国家和地区、超5亿用户。长虹智慧显示（中国）公司是长虹控股集团核心子公司之一，主要从事智能产品、信息家电、液晶电视等相关产品的技术研发、生产制造、品质控制、市场营销等业务。公司拥有员工5000余人，其中包含500多名中高级技术人才，具有整机、机芯、光学、音质、画质、屏驱动、无线、外设、PCB设计、光学、结构、软件等专业化的开发团队。在人工智能、物联网、超超大模型等技术方面领先行业。目前，公司正聚焦电视智慧显示主业创新，强化技术研发和市场拓展，提升核心竞争力，为用户带来更多更好更有独特价值的产品和服务。同时，持续加强人才培育，优化管理，提升运营效率，推动公司高质量发展。
