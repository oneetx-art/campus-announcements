## 公司
性质:民企 · 行业:金融业

洪泰基金由新东方创始人俞敏洪与华泰联合证券首任董事长盛希泰于2014年共同创立，是专注硬科技与产业创新的投资平台。洪泰以深度产业理解为底色，聚焦人工智能+（硬件/软件）、芯片与机器人、航天卫星与低空经济、先进装备制造、前沿科技、生命健康等高壁垒赛道，持续发掘并陪伴具备核心技术与长期价值的领军企业。目前，洪泰基金管理规模超300亿元，已投资企业200余家，构建起高科技、高效能、高质量的产业生态，在投资界与实业界拥有广泛影响力。
