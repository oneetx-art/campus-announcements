## 公司
性质:央国企 · 行业:金融业

山西信托股份有限公司成立于1985年，属国有控股性质，是山西省唯一一家从事营业性信托活动的非银行金融机构，也是省内唯一能够横跨货币市场、资本市场、实业产业，综合运用投融资功能的持牌金融机构。公司经营范围主要为资金信托、动产信托、不动产信托、有价证券信托、其他财产或财产权信托等。
