## 公司
性质:央国企 · 行业:机械/制造业

上海振华重工（集团）股份有限公司（ZPMC）是著名的重型装备制造企业，在上海证券交易所A股和B股上市的国有控股企业，控股方为世界500强企业——中国交通建设集团有限公司（CCCC）。公司总部设在上海，在上海、南通等地拥有8个生产基地，总面积1667万平方米、海岸线10公里。ZPMC已出口到全球110个国家和地区，主要是大型港口集装箱机械、产品和国家主要工程。产品类型有港口机械、矿山机械、煤炭散货物料装卸机械、重型海工产品、大型重型等特种钢结构、系统集成及工程总承包、投资融资等。
