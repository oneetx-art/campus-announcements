## 公司
性质:民企 · 行业:通信/电子/半导体

河南仕佳光子科技股份有限公司（以下简称仕佳光子，股票代码：688313）成立于2010年，公司聚焦光通信行业，主营业务覆盖有源光芯片及器件、无源光芯片及器件、光缆及连接器、线缆材料四大板块。公司拥有无源和有源IDM双芯片平台优势和强大的器件模组研发创新能力，经过10多年发展，已经成为全球光通信行业研发有无源芯片、器件的核心供应商，产品被广泛应用于数据中心、骨干网、城域网、接入网、激光雷达、光纤传感等领域。
