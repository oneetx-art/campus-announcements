## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

浙江出版联合集团为省政府直属的国有独资出版企业集团，覆盖出版、印刷、发行、纸张供应全产业链，以图书、电子音像制品和期刊等出版物的出版发行、文化投资、物业经营三大板块为主业，融合数字出版、数字媒体、数字营销、信息技术服务等新兴业态。集团全资和控股法人单位共计130余家，员工近7000人。集团先后入选全国文化体制改革先进单位、全国新闻出版“走出去”先进单位、全国首批数字出版转型示范单位，连续17次入选“全国文化企业30强”，总体经济规模位列地方出版集团第一梯队。
