## 公司
性质:央国企 · 行业:交通/物流/仓储

上海海烟物流发展有限公司，成立于2002年，为上海烟草集团有限责任公司直属单位，以集团公司“和搏一流”的企业精神，做精做强的战略思想，从事物流配送为主、及卷烟营销、非烟经营在内的三项业务，覆盖现代物流、商品流通、品牌营销、信息服务为一体的供应链服务商，对上海烟草零售终端包括卷烟、酒类、食品等数千种规格商品，实行统一管理、统一经营、统一配送。
