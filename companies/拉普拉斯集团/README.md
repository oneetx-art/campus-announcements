## 公司
性质:民企 · 行业:机械/制造业

拉普拉斯新能源科技股份有限公司（简称“公司”）于2016年5月正式成立，是由一群在海内外光伏及半导体设备行业具有深厚背景的专家携手创立的高端装备与解决方案提供商。公司于2024年成功登陆科创板，股票代码：688726.SH。凭借强大的技术实力和创新能力，公司荣获了国家级制造业单项冠军企业、国家级专精特新“小巨人”、中国装备优秀企业等多项荣誉，还被认定为广东省返巨人高端装备专业工程研究中心。公司还拥有一支高素质的研发团队，2024年获批设立深圳市博士后创新实践基地。拉普拉斯集团现有员工人数超2000名，其中研发、技术支持人员占比高达50%以上，为集团持续的技术创新和产品研发提供了坚实的保障。
