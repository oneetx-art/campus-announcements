## 公司
性质:合资 · 行业:智能硬件

卡斯柯成立于1986年，由中国铁路通信信号股份有限公司（国资委监管大型央企）与阿尔斯通（全球轨道交通领先企业）共同出资成立，公司总部位于上海，在全国设有7家子公司、10家分公司，拥有员工2000余人。作为一家全方位的轨道交通控制系统集成商，卡斯柯拥有完整的列车运行控制系统产品线，参与建设城轨线路110余条，国内市场占有率第一，开通里程世界领先；参与建设高铁与客运专线180多条，调度指挥产品市场占有率全路第一。公司业务遍布全国各地，产品和服务远销20多个国家和地区。
