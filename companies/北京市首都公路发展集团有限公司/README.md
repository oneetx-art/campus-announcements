## 公司
性质:央国企 · 行业:交通/物流/仓储

北京市首都公路发展集团有限公司（简称“首发集团”）为北京市国有独资公司，1999年成立，负责北京市高速公路、城市道路及配套设施投资、建设及运营管理。首发集团在市委、市政府领导下，全面融入国家发展战略和首都发展大局，牢固树立聚焦主责主业、高质量发展的理念，实现了道路交通、交通科技、静态交通、设施经营和交通枢纽业务的协同发展。
