## 公司
性质:民企 · 行业:房地产业/建筑业

中蓝连海设计研究院有限公司（以下简称“中蓝连海”）是中化环境科学板块旗下科技型骨干企业，1962年1月成立于江苏省连云港市，前身为化学工业部化学矿山设计研究院。公司业务范围涉及化学矿山工程、环境影响评价、安全评价、工程市政研发和营销等，主要从事科研开发、设计咨询、勘察测绘、技术服务、项目管理、工程总承包等。在化学矿绿色采选、磷石膏工艺与药剂开发、磷尾矿处理、磷石膏综合利用、环保工艺技术与微生物菌剂开发等领域具有雄厚实力。环保工艺技术与微生物菌剂开发等应用技术处于国内领先水平；中蓝连海磷矿选矿工艺与药剂开发、钾盐及钾肥胶磷矿开发享誉国际市场，并拥有一系列专利和专有技术。
