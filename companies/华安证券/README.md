## 公司
性质:民企 · 行业:金融业

华安证券股份有限公司前身是1991年成立的安徽省证券公司，是安徽省第一家专营证券机构。2001年整合原安徽省证券公司、安徽证券交易中心的证券类资产，成立华安证券有限责任公司，2012年整体变更为股份有限公司，2016年公司首次公开发行股票在上海证券交易所挂牌上市，股票代码600909。公司设有证券分支机构150家，期货分支机构14家，通过子公司开展期货、公募基金、私募基金、另类投资等多元业务，形成立足安徽、面向全国、放眼亚太的区域布局，近年来经营业绩稳健，主要业务指标进入行业前三分之一位次。公司践行ESG理念，坚持服务实体经济定位，秉持综合化经营特色化突破发展战略，致力于打造服务新兴产业的创新型投资和服务大众的专业财富管理机构两大品牌
