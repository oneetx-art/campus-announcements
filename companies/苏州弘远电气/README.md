## 公司
性质:民企 · 行业:机械/制造业

苏州弘远电气是一家专注于高端电机驱动器（变频器和伺服驱动器）研发、生产和销售的专精特新企业及国家认证高新技术企业。主要服务于制造装备、节能环保、新能源三大领域，产品可广泛应用于起重、精密机床、金属制品、电线电缆、石油石化、印刷包装、钢铁建材、矿山冶金、新能源汽车、隧道盾构机和印刷设备等。公司拥有多项自主知识产权的交流传动控制技术，是目前为止全球第二家完全自主掌握直接转矩控制算法的厂家，也是目前为止全球第一家同时全部掌握驱动器三种（直接转矩控制、磁通矢量和V/F）控制算法的公司，公司在运动控制领域技术及方案处于全球领先水平。公司致力于将企业打造成一个让员工充分的展示自己能力和魅力的优秀平台，共同推动企业成为享誉全球的工业自动化和新能源系统方案优选供应商。
