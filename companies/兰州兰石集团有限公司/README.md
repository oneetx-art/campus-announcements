## 公司
性质:央国企 · 行业:机械/制造业

兰州兰石集团有限公司（简称“兰石集团”）始建于1953年，由新中国“一五”期间156个国家重点项目中的兰州石油机械厂和兰州炼油化工设备厂合并而成。兰州兰石超合金新材料有限公司（简称“兰石超合金”）隶属于兰石集团，是我国西北最大的高端金属材料研发生产基地，拥有国际一流的装备生产能力，产线覆盖冶炼、锻造、热处理和机加工全流程，产品涉及军工核电、新能源、航空航天、石油钻采、炼油化工、能源装备、有色金属等行业领域，打造了钛合金、高温合金、铜合金和高端铸钢为代表的系列核心产品。与中科院金属研究所、钢铁研究总院、西安交通大学、东北大学、太原科技大学、兰州理工大学等高校科研院所建立长期战略合作关系。兰州兰石恒昌金属材料有限责任公司（简称“兰石恒昌”）是兰石超合金公司为提升铸锻板块厂房设备利用率，优化调整产品业务结构，加快推动自身业务转型升级，引入浙江国工新材料技术开发有限公司、东莞市钢纳金属材料有限公司、东莞市斯瑞纳模具技术有限公司等战略投资者基于优势互补、资源共享、合作共赢的理念，共同出资，对铸锻板块实施混改的一家混合所有制公司。
