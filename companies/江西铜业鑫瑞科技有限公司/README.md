## 公司
性质:央国企 · 行业:能源/化工/环保

江西铜业集团有限公司（简称江铜集团）成立于1979年，省属国有企业，是我国有色金属行业大型集团公司，公司主营业务包括铜、金、银、铅、锌等金属矿产开发、技术及产业链拓展。鑫瑞科技是江铜集团资本运营平台，致力于推动创新链与产业链融合发展，先后与国内知名科研院校建立战略合作关系，不断提升自主创新和市场运营能力。碳纳米公司是江铜集团科技创新平台全资子公司，成立于2020年元月，注册资本1000万元，主要从事新材料技术推广服务，石墨及碳素制品销售，石墨及碳素制品制造，涂料制造（不含危险化学品），涂料销售（不含危险化学品），家用电器销售，家用纺织制成品制造等业务。智信公司成立于2022年12月13日，由江西铜业瑞博士有限公司、江西铜组技术研究所有限公司、公司注册资本16555万元，主要从事技术服务、技术推广，矿山机械设备及销售，专用化学产品制造等。
