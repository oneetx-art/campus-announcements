## 公司
性质:央国企 · 行业:能源/化工/环保

中国石油国际事业有限公司是中国石油天然气股份有限公司的全资子公司，于2002年1月18日注册成立，注册资金180.96亿元人民币，业务覆盖原油、成品油、天然气、化工品、国际转口贸易、境内沿海沿边口岸设施、境外贸易运作平台的投资和管理，并从事境内外期货、电碳交易等业务。
