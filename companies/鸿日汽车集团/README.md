## 公司
性质:民企 · 行业:汽车制造/维修/零配件

鸿日汽车集团1995年创建于山东滨州，是集棉纺、房地产、金融、出行科技、零部件及整车研发、制造、销售于一体的综合性商业集团。研发总部位于山东青岛，建成了青岛、上海研发中心，拥有山东滨州、日照、安徽金寨三大生产基地，总产能规划100万台年营收50亿元。远销20余国，未来将铺设50个国家以上的全球网络，打造全球化汽车集团。
