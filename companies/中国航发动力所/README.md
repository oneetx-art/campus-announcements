## 公司
性质:事业单位 · 行业:机械/制造业

中国航发沈阳发动机研究所（简称：中国航发动力所），隶属于中国航空发动机集团有限公司，始建于1961年8月6日，是新中国第一个航空发动机设计研究所，是我国大、中型航空涡喷、涡扇发动机的“摇篮”。主要从事军、民用航空发动机及燃气轮机的设计研究与产品开发，满足了我国国防武器装备现代化建设和国民经济发展的需要，忠实履行党和国家赋予的神圣使命。
