## 公司
性质:政府机关 · 行业:政府/机构/组织

上海浦东软件园股份有限公司成立于1992年，由原机械电子工业部和上海市人民政府共同组建而成，负责开发运营全国成立最早的软件园区——上海浦东软件园。先后以滚动开发模式建设了祖冲之园、三林园、昆山园、南京园、软件园等多个专业园区，是“国家软件出口基地”“国家新型工业化产业示范基地”“国家数字服务出口基地”等称号。同时园区致力于推动中国软件和信息服务行业创新发展，构建了以数字算力、数字算法、数字应用、数字服务为主的数字经济产业生态体系，集聚了一批高质量、创新型的数字产业代表企业。自开园以来，园区共计培育、引进超4000家企业，截至2024年底共有企业和配套服务机构1900余家，其中高新技术企业169家，园区企业产值总额达1130亿元。
