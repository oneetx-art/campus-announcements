## 公司
性质:央国企 · 行业:医疗/医药/生物

创美药业（股份代号：2289.HK）主营医药分销业务，向下游分销和零售终端分销西药、中成药、保健用品等，并提供第三方物流服务及医药产品咨询服务。公司于2000年在汕头创立，于2015年在香港上市。目前在汕头、广州、珠海、深圳分别设立物流基地，并在广州、佛山、珠海、惠州、深圳分别设立子公司。公司拥有以SAP为核心的现代化信息系统，涵盖整个医药分销供应链，同时运营自建B2B电商服务平台“创美e药”。
