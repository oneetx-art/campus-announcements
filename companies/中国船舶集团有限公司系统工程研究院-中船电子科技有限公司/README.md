## 公司
性质:央国企 · 行业:机械/制造业

中国船舶集团有限公司系统工程研究院（船舶系统工程部）成立于1970年，是我国最早以“系统工程”命名，并将系统工程理论和方法应用于海军装备建设的军工科研单位。始终站在海军舰船装备发展前沿，历经“一次转型两次跨越和一次探索”，发展成为覆盖海军整体体系，以系统集成专业为主业，涵盖“体系顶层研究、系统综合集成、核心设备研制”三个层次的骨干军工科研单位。
