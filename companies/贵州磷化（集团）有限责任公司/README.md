## 公司
性质:民企 · 行业:能源/化工/环保

贵州磷化集团是19年省整合重组企业，由瓮福集团和开磷集团组建，主营集磷矿采选、磷复肥、精细磷化工、新能源电池材料、化工品及绿色环保产品等，在省内的福泉基地、息烽、开阳、瓮安，以及省外的贵金、四川达州、福建上杭、江苏连云港有布局。磷化工、工业及饲料加工基地，连续五年进入“中国企业500强”名单，连续五年在“中国化肥企业100强”名单中排名第一，磷矿石、磷酸产品位居全国第一、世界前三。
