## 公司
性质:事业单位 · 行业:教育/培训/科研

北京大学中国社会科学调查中心成立于2006年9月，是直接隶属于北京大学的教学科研实体。中心专业从事追踪型社会调查及相关研究，其核心创新项目包括“中国家庭追踪调查”（CFPS）、“中国企业创新创业调查”（ESIEC）和“中国健康与养老追踪调查”（CHARLS）。此外，中心还承担学术和政府机构的委托调研，以调查、收集、整理、集成管理和社会科学研究数据为目的，为教学、科研、政策分析和决策提供数据平台。
