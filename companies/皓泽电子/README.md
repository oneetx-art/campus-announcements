## 公司
性质:民企 · 行业:通信/电子/半导体

河南皓泽电子股份有限公司成立于2012年，总部位于河南孟州。在上海、昆山、厦门、郑州等地均设有研发中心。主要业务为微型摄像头自动对焦驱动马达的研发、设计、生产及销售。产品广泛应用于智能手机、平板电脑、计算机及周边、智能穿戴等众多领域。目前主导产品涵盖500万像素的中低端马达到2亿像素的高端自动对焦、光学防抖自动对焦马达。系河南省制造业单项冠军企业、国家专精特新重点“小巨人”企业、国家知识产权优势企业；具有独立自主的产品设计和自动化软硬件开发能力，拥有河南省工程技术研究中心和企业技术中心。
