## 公司
性质:事业单位 · 行业:教育/培训/科研

南昌师范学院前身是1952年成立的江西省中等师资进修学校，1956年更名为南昌师范专科学校，1958年升格为江西教育学院，新中国江西省人民政府首任省长邵式平同志亲笔题写校名。1969年与江西师范学院、江西大学文科合并，成立井冈山大学，1979年恢复江西教育学院独立办学，1981年教育部在我校召开全国教育学院院长会议，会后颁布加强教育学院建设若干问题的暂行规定。2013年4月，经教育部批准，改制更名为南昌师范学院，2019年顺利通过教育部本科教学工作合格评估，2022年1月被列为江西省十四五新增硕士学位授予单位立项重点建设单位
