## 公司
性质:民企 · 行业:贸易/批发/零售

上海德威文化科技有限公司成立于2009年，始终负责把画框艺术简单的使命，专注于手绘类美术器材领域，围绕主体建立，以生产为总部，以昌邑品牌为中国核心，业务至上，打造一个全方位、多层次的艺术生态体系，通过打通供应链、品牌体验共享生态空间，联合提供我们建构了一个从美学课程与艺术考级认证，传统画材建材，整个用户买到实践，再到技能决定的垂直专业美术画材品牌TOUCHMARK解决方。2014年起创业，遵循以色彩为中心的产品设计理念，致力于为用户打造更适合年轻的美术笔，继续国内马克笔行业连续五年将马克笔，从少儿到专业的美术的课程进阶，每个阶段学习成长，再到商业应用的积累，到基础美术的教学我们都能为用户提供相应的产品和服务，满足用户全生命周期的绘画需求。
