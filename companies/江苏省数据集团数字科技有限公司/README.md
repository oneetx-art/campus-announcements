## 公司
性质:央国企 · 行业:IT/互联网/游戏

江苏省数据集团数字科技有限公司成立于2017年12月，注册资本1.2亿元，系江苏省数据集团全资子公司。作为集团政务数字化服务的主要实施平台，江苏数科秉持“一体两翼”发展战略，即数字基础设施建设与运营为主体，以密码应用业务和网络数据安全服务为两翼，主营业务涵盖企业数字化服务、电子认证运营服务、网络安全系统开发、信息技术集成服务以及第一类增值电信业务等领域。公司下设安全技术子公司，并在南京、苏州、无锡、南通、苏中及苏北设有六个分支机构，在全省范围内部署51个服务网点。
