北京亦庄投资控股有限公司（简称亦庄控股）是1991年经北京市、市政府批准，与国有企业。同步成立的北京市属一级国有全资企业。亦庄控股以建设经开区、服务经开区为初心，以服务北京国际科技创新中心建设为引领，以国际一流产业新城运营商为发展定位，以绿色、智慧、国际化为发展方向，形成“科技园区开发运营、科技产业投资促进、智慧城市建设服务”三大业务板块，不断培育产业新城全链条服务和科技产业全周期发展两大核心竞争力，助力首都经济社会实现高质量发展。
