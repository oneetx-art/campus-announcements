## 公司
性质:央国企 · 行业:交通/物流/仓储

广州广汽商贸物流有限公司，是世界500强广汽集团下属全资子公司广汽商贸有限公司100%投资设立的专业物流公司，企业性质为国企。是股东倾力打造的首家承接多个汽车主机厂全方位物流业务的综合性汽车物流企业。公司成立于2010年1月18日，注册资金5.5亿元。公司拥有物流中心占地面积34.39万平方米，已建成仓库面积26.29万平方米。公司目前主要业务为向广汽传祺、广汽埃及及其配套零部件厂家提供采购、生产、销售、售后等环节全方位的物流服务。公司本着“服务客户 奋力拼搏 专注专业 持续改善”的宗旨，以世界一流为目标，全力以赴，为中国汽车产业发展提供最佳的物流服务。持续加强“标准化、自动化、数字化、智能化”的建设，提升现代化物流服务水平，打造成为一家客户信赖、市场认可的智慧物流企业。
