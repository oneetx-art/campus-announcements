## 公司
性质:社会组织 · 行业:政府/机构/组织

北海市长青社会工作服务中心成立于2019年11月，是在北海市民政局登记注册，以社会工作者为主体，坚持“助人自助”宗旨，遵循社会工作专业伦理规范，综合运用社会工作专业知识、方法和技能，开展困难救助、关爱妇女儿童、禁毒防艾、社区运营、青少年发展等服务工作的民办非企业单位。接受业务主管单位共青团北海市委员会及登记管理机关北海市民政局的业务指导和监督管理。
