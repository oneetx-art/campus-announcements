## 公司
性质:外企 · 行业:能源/化工/环保

MODEC成立于1968年，是全球领先的海上油气浮式解决方案提供商，专注于浮式生产储油卸油装置（FPSO）等设施的设计、建造与运营。我们为FPSO及其他浮式油气生产设施提供覆盖全生命周期的工程、采购、建造与安装（EPCI）服务。同时，MODEC自有并运营船队，能够为全球油公司提供端到端、有竞争力的生产解决方案，助力客户安全、高效、可持续地开发海上油气资源。
