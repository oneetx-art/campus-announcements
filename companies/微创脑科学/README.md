## 公司
性质:民企 · 行业:医疗/医药/生物

微创脑科学（02172.HK）起源于2012年成立的微创神通医疗科技（上海）有限公司（以下简称“神通医疗”），参与和见证了国内神经介入行业的发展。神通医疗作为国内最早进入这个领域的医疗器械公司，现已成为最具知名度的行业品牌。微创脑科学有限公司自成立之日起始终致力于神经介入治疗领域高端医疗器械的研究与开发，经过多年发展，公司已建立全面的脑卒中介入治疗产品线，提供脑血管疾病治疗全解决方案，已成为领域内规模体量最大的中国公司。截至2025年8月，神通医疗已有26款产品在中国获批上市，其中4款创新产品进入国家药监局创新医疗器械特别审批通道。公司的产品已累计覆盖全国3500余家医院，为超过57万名患者提供安全有效的脑血管疾病解决方案。同时，公司具有领先的国际化视野和全球布局，截至2025年8月，共有9款产品在30+个海外国家或地区实现商业化。
