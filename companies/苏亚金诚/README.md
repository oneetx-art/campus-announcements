## 公司
性质:民企 · 行业:财务/审计/税务

苏亚金诚会计师事务所（特殊普通合伙），前身为江苏苏亚审计事务所，成立于1996年5月（原隶属于江苏省审计厅），具有证券、期货相关业务审计备案资格和司法鉴定资格，是中国银行间市场交易商协会会员、中国科技咨询协会会员、江苏省金融业联合会会员、江苏省投资基金业协会会员、江苏省破产管理人协会副会长单位。事务所内设四个审计业务部、质量控制部、技术支持部、业务培训部、业务发展部和办公室，下设北京、连云港、扬州、常州、镇江、苏州、无锡、安徽、盐城、海南、四川等11个分支机构。自2003年以来，连续名列中国注册会计师协会公布的全国百家会计师事务所综合评价排名前30位，2012年以来，连年被江苏省注册会计师协会评为AAAAA级会计师事务所。
