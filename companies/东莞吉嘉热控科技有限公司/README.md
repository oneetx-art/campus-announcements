## 公司
性质:民企 · 行业:机械/制造业

热控科技专注于电子散热液冷板解决方案，提供从研发设计、加工制造、端到端交付全流程服务。产品包括液冷板、快接头、管路组件及冷却系统等。公司拥有业内顶尖的研发设计团队，可针对不同的应用场景，提供业界领先的，具有高前瞻性、高标准、高质量且高度定制化的热控制整体解决方案。热控科技致力于持续技术创新，为客户创造价值。客户遍及ICT、半导体工业、分析仪器和医疗设备、轨道交通、新能源、工业自动化等行业；在产品的设计仿真、生产制造，质量控制，交付及现场管理等方面，热控科技有着丰富的经验。
