## 公司
性质:央国企 · 行业:检测/认证

国合通用（重庆）测试评价认证有限公司（简称国合重庆）是中央企业中国通用科技集团有限公司（简称中国有研）所属国合通用测试评价认证股份公司（简称国合通测）的全资子公司，于2022年11月在重庆市两江新区注册成立，是国合通测在西南地区布局的综合性材料测试评价认证机构，承担国合通测西南实验室、先进射线技术与应用研究中心及电子材料和试剂分析技术研发中心的建设任务，项目总投资2.6亿元。于2024年在重庆两江新区建成总面积逾10000平米，包含材料成分分析、机械和物理性能测试、微观组织分析、无损检测等4个主要研究方向的综合性实验室。预计达产年销售收入1亿元以上，将成为西南地区检验检测行业的龙头企业，引领行业发展，推动当地新材料产业集聚。
