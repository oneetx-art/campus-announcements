## 公司
性质:民企 · 行业:智能硬件

北京灵思创奇科技有限公司成立于2013年，基于正向设计方法论MBSE，提供智能装备仿真测试一体化平台LinkSxIL及轻量级数字孪生体解决方案，落地于无人系统、机器人、电机伺服控制等垂直产业场景，服务于国防军工、商业航天、汽车、能源电力及工厂自动化等行业。灵思创奇已在多个工业领域实现进口产品替代，累计服务200+工业及科研用户，300+高等院校，并于2024年获深创投A轮战略投资。
