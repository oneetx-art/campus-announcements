## 公司
性质:事业单位 · 行业:教育/培训/科研

首都师范大学附属育新学校成立于1997年，是一所集中小学为一体的十二年制公办学校，位于海淀区西三旗育新花园小学部，为海淀区首批素质教育优质校和新建园小区中学部，高中为海淀区示范高中、海淀区新品牌学校。学校接受北京市教委、首都师范大学党委和海淀区教委的领导和管理。
