## 公司
性质:央国企 · 行业:机械/制造业

重庆铁马工业集团有限公司是中国兵器工业集团有限公司所属国有独资企业，主要研制生产特种车辆、专用汽车、汽车上装等系列车型及特种车辆传动部件的骨干企业，重庆市和谐劳动关系AAA级企业。公司地处重庆市九龙坡区杨家坪，地理位置优越，交通方便，占地面积100万平方米。公司始建于1941年，公司主产品已达国内领先水平，研制和生产的产品参加了建国10、35、50、60周年、建军90周年等七次“大阅兵”，接受党和国家领导人的检阅，受到国务院、中央军委、国防科工局及中国兵器工业集团的嘉奖，公司先后通过了“国家级两化融合”“国家高新技术企业”“国家知识产权优势”企业认定，获得“全国五一劳动奖状”等荣誉称号。
