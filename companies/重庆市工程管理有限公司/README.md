## 公司
性质:央国企 · 行业:房地产业/建筑业

重庆市工程管理有限公司成立于1979年，是重庆国际投资咨询集团有限公司全资子公司，属重庆市属重点国有企业重要子企业，注册资本金7000万元，是全国高新技术企业、重庆市全过程工程咨询第一批试点企业，拥有首批国家甲级监理资质。公司业务涵盖城乡规划、工程勘察、建筑设计、投融资咨询、招标代理、造价咨询、项目管理、工程监理等全过程工程咨询服务，涉及房屋建筑、市政、交通、水利水电、生态环境等多个领域，累计完成各类项目超8000个，多次获得鲁班奖、国家优质工程奖等国家级、省部级奖项，是基础设施建设领域投融资变革和技术创新的引领者和践行者
