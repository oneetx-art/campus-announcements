## 公司
性质:民企 · 行业:通信/电子/半导体

青芯半导体科技（上海）有限公司成立于2019年，总部位于上海浦东张江，在无锡、武汉、成都和深圳均设有研发中心。作为国内前沿的ASIC设计企业，公司提供端到端的定制芯片业务，涵盖SOC设计、可测试性设计、物理设计、存储IP定制及先进封装与测试解决方案。公司致力于通过定制化集成电路开发，在网络交换、汽车电子、智能硬件及物联网领域提供芯片设计全流程解决方案。公司还围绕服务器加速领域(计算加速,互联加速,存储加速和安全加速)展开自有芯片产品开发。公司核心团队成员曾就任于世界500强公司IBM、GlobalFoundries、Marvell，拥有近20年芯片设计和研发经验。2021年11月起公司获得国家高新技术企业认定，目前公司员工约200人左右。
