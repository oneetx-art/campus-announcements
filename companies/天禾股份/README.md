## 公司

广东天禾农资股份有限公司（下称“天禾股份”）于2009年3月通过股份改制成立，是广东省供销合作联社的直属企业之一。公司以现代化肥、农药等农资产品的销售并提供专业的农技支撑，主要从事化肥、农药等农资产品的销售并提供专业的农技服务。2024年全国农资流通企业综合竞争力排名第4（AAAAA级），是中国具有较大品牌影响力的农资流通企业。公司于2020年9月在深圳证券交易所挂牌上市。
