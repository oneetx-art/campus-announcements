## 公司
性质:民企 · 行业:能源/化工/环保

圣泉集团始创于1979年，总部坐落于“一代儒商”孟洛川的故里章丘，总占地1545亩。产业覆盖生物质精炼、新能源、电子化学品、酚醛树脂及复合材料、铸造材料、健康医药等领域，为全球上万家客户持续提供更具竞争力的生物制造和化学新材料产品及解决方案。2021年8月10日，公司在沪市主板上市（股票代码：605589）。
