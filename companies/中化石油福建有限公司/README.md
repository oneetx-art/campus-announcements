## 公司
性质:央国企 · 行业:能源/化工/环保

中化石油福建有限公司成立于2007年，隶属于中国中化能源业务板块，是中国中化在福建省设立的全资子公司。公司致力于在福建省内拓展和经营中化品牌加油站零售、直分销业务以及轻资产网络，积极开拓新能源业务，并与福建省内多家国有企业开展合资合作，在营加油站超过270座。公司持续强化人才队伍建设，以卓越运营引领高质量发展，稳步确立在福建省成品油市场主营地位。
