## 公司
性质:民企 · 行业:能源/化工/环保

时代长安动力电池有限公司（简称“时代长安”）由宁德时代、长安汽车、深蓝汽车共同出资，是一家集动力电池、新兴能源技术、新材料技术的研发、制造、销售为一体的科技型生产制造企业。公司成立于2023年6月，注册资本为150000万元人民币，坐落于四川宜宾翠屏区，占地1000亩，是一家以高起点规划、高标准建设、高效率推进的现代化、智能化、数字化、绿色低碳化的动力电池超级工厂。
