## 公司
性质:民企 · 行业:农林牧渔

六夫丁是一家专注于杀虫剂、研发、生产及提供植保技术服务于一体的国家级高新技术企业。现有员工500余人，生产基地近5亿，在中国农科院等科研机构和生产科研单位，先后与新烟碱类杀虫剂、河南农业大学、河南科技学院等高校、公司与河南省博士后创新工作站、河南省黄、河南省、河南省农科院建立战略及合作关系，河南省新烟碱类杀虫剂技术研究中心、河南省新农药创制与应用重点实验室，在产品研发、生物解决方案等方面，六夫丁不断创新，为国家农药减量增效，用户品质升级、作物解决等中国农、河南省新农药创制与应用要求战略增效。
