## 公司
性质:其他 · 行业:金融业

广东省农村信用社联合社（简称广东省农信联社）成立于2005年，是由广东省内农商行自愿入股组成，根据省政府授权，履行对全省农商银行的管理、指导、协调和服务职能。广东省农信联社拥有稳健金融科技平台，承担广东农信全省产品创新、资金清算、同业业务管理、风险管控、产品研发创新、清算项目、国际业务、管理机构、科技金融业务管理提供科技服务，管理核心系统客户、3416个营业网点及服务终端，为82家法人机构客户数9000万以上。广东省农信联社先后取得ISO20000、ISO27001、CMMI5、TMMi4、CDMM四级、DCMM四级等国际认证以及企业标准“领跑者”等国内权威认证，与多家头部金融科技、互联网公司建立战略合作伙伴关系，在大数据、云计算、人工智能、5G、信息安全和互联网应用等方面有着深度合作，整体信息科技水平处于全国农信前列。
