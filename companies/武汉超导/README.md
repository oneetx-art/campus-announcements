## 公司
性质:民企 · 行业:机械/制造业

武汉超导智能装备科技有限公司（简称“武汉超导”）是一家从事研发、生产、制造、销售超导智能装备的硬科技企业，由经开产投集团创公司与强超导领域国家级人才团队合作共建。公司核心团队由院士领衔，成员来自中国科学院、中国计量科学研究院、华中科技大学等超导领域国家级人才。
