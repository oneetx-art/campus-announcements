## 公司
性质:央国企 · 行业:贸易/批发/零售

苏美达股份有限公司（苏美达）成立于1978年，系国机集团的重要成员企业。经过40多年的蓬勃发展和几代苏美达人的接续奋斗，业已发展成为一家在产业链供应链与国际、运营领域都具有规模与品牌影响力的国际化、多元化企业集团。2016年，苏美达（600710）正式登陆资本市场，实现整体上市。截至2024年底，苏美达拥有：13家二级子公司、28家海内外全资/海外成员企业、37家及控股实业工厂、16000余人在职员工；市场覆盖160多个国家和地区，2024年收入实现1171.7亿元，进出口总额129亿美元，位列2023《财富》中国上市公司500强97位。
