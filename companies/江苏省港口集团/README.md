## 公司
性质:央国企 · 行业:交通/物流/仓储

江苏省港口集团成立于2017年5月，是江苏省属大型国有企业。集团是实施整合沿江沿海港口、岸线及相关资源一体化运营的企业和临港产业等领域的国有资本投资运营主体。拥有全省航运服务中心、大宗物资储运交易中心和现代物流中心，航线通达全球各地，港口岸线资源优越，腹地经济发达、产业集群丰富。
