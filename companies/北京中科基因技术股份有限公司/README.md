## 公司
性质:民企 · 行业:医疗/医药/生物

北京中科基因技术股份有限公司成立于2016年，作为国家级高新技术企业及专精特新企业，已稳居国内兽医第三方检测行业领先头部位置。公司在国内拥有29家全资及控股子公司，业务网络覆盖全国主要省市，并构建了包含24家连锁实验室的庞大服务网络，其中21家已通过CNAS认可。依托分子生物学、病理学等七大核心技术平台，公司成功建立起宏大的动物健康监测大数据，在深耕兽医诊断标准化、信息化、数字化与智慧化的同时，其自主研发的多款新型生物材料产品成功打破国际垄断，实现了关键核心技术的国产替代，正全力铸就国际一流的智慧兽医体系。
