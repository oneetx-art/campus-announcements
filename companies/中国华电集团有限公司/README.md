## 公司
性质:央国企 · 行业:能源/化工/环保

中国华电集团有限公司成立于2002年，是中央直管的国有重要骨干企业，是以电力为核心的特大型能源企业集团，连续13年获国务院国资委年度经营业绩考核A级，连续14年上榜《财富》世界500强。业务涵盖电力、热力、煤炭、科技工程、产业金融等多个板块，产业分布于全国32个省（区、市）及多个一带一路沿线国家，天然气发电装机规模全国第一、水电装机规模全国第二，是我国在东盟地区最大的发电运营商
