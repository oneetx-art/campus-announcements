## 公司
性质:央国企 · 行业:金融业

中国金币集团有限公司（以下简称“中国金币”）是经国务院批准、我国唯一经营贵金属纪念币的行业性公司，成立于1987年8月，2021年11月由全民所有制企业改制为有限责任公司，是我国贵金属纪念币总经销，负责贵金属纪念币的设计、生产、经销和服务等工作。自成立以来，中国金币坚持“以人民为中心”的发展理念，攻坚克难，改革鼎新，经过近40年的发展，在促进中国贵金属纪念币发展、见证中国发展重大事件、传播中华优秀文化、丰富人民群众投资收藏需求、推动世界文明交流共建等方面做出了积极贡献。
