## 公司
性质:民企 · 行业:能源/化工/环保

广东日丰电缆股份有限公司，成立于2009年，总部位于广东省中山市，是一家专业从事‘装备电缆’研发、设计、生产和销售的企业，公司于2019年上市，现有员工3000多人。目前拥有天津、江门、中山等6大生产基地，占地面积超40万平方。荣获‘中国电缆行业100强企业’等称号，是国内橡套电缆领域的领跑者。产品广泛应用于新能源（风电/光伏等）、锂电池/充电桩（液冷/化成容等）/车内高压线束、储能（电池储能连接）、建筑机械、塔机/升降机配套（塔机/风机电梯/化成容等）、高端装备配套（盾构机/掘进机等）、电焊机设备、通信设备（5G基站等）、家电（空调等）、电源及电动工具等行业，与众多世界强企如：华为、中兴、明阳等建立了战略合作伙伴关系。
