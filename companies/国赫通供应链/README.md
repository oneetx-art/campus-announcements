## 公司
性质:民企 · 行业:交通/物流/仓储

国赫通供应链有限公司（Sinotraffic Co.,Ltd.）是首批全国供应链创新与应用示范企业和2024年青岛市供应链领军标杆企业，致力于打造全球领先的车辆与装备物资供应链品牌。公司成立于2010年，总部位于青岛，在上海、广州、烟台、连云港、天津、霍尔果斯、喀什设有分子公司和自营场站，在一带一路沿线国家创新国际物流网络，在俄罗斯、墨西哥、伊朗、哈萨克有海外仓。
