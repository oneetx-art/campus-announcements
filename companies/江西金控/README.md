## 公司
性质:央国企 · 行业:金融业

江西省金融控股集团有限公司（以下简称“集团”）于2015年9月正式组建成立，注册资本金80亿元，是江西省首家国有全资金融控股集团。组建以来，集团秉持省政府“贯彻落实省委、省政府加快金融业改革发展重大方针政策的重要载体；做大做强江西地方金融板块的主力军团和龙头企业；省属地方金融机构的投资主体和金融资产的管理平台”的定位，围绕服务全省经济社会发展和加快自身能力建设两大目标，全力做好金融“五篇大文章”，努力打造成为区域有特色、全国有影响力的现代企业。目前，集团已控股保险、期货、担保、基金、资产管理、融资担保等11家金融类及类金融机构和1家科研机构，参股银行、信托等6家金融及类金融机构。其中，三家主体的信用等级被评为AAA，三家主体的信用等级被评为AAA，形成了“3+3”的信用主体集群，是江西省首家拥有3个AAA信用等级被评主体的企业，也是江西地方金融业态形式最全、业务领域较广的综合性金融控股集团。
