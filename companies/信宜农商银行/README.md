## 公司
性质:民企 · 行业:金融业

广东信宜农村商业银行股份有限公司（以下简称信宜农商银行）根植信宜经济金融沃土，成立于1952年，70余年来与信宜共同成长，支持城乡经济建设，是信宜市纳税大户、服务“三农”和小微企业的金融主力军，承担着举足轻重的金融责任。信宜农商银行现有营业网点45个，从业人员760余人，总资产超过286亿元，存、贷款市场份额均居信宜市银行业金融机构前列，是信宜市县域金融的中坚力量。
