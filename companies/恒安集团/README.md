## 公司
性质:民企 · 行业:快速消费品

恒安集团创立于1985年，是目前国内知名的生活用纸和妇幼卫生用品制造商，拥有心相印、七度空间、安儿乐等知名品牌。恒安国际于1998年12月8日在香港联交所上市，2011年编入香港恒生指数成分股。企业成立40年，持续健康发展，生活用纸、妇女卫生巾、婴儿纸尿裤三大主导产品在国内市场的占有率均名列前茅。
