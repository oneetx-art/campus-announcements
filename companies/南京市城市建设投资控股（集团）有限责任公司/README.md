## 公司
性质:央国企 · 行业:房地产业/建筑业

南京市城市建设投资控股（集团）有限责任公司组建于2002年11月28日，是由南京市人民政府国有资产监督管理委员会出资设立的市属大型国有独资企业，主要职能是接受市政府委托，承担城市基础设施及市政公用事业项目的投资、融资、建设、运营、管理任务。集团注册资本200亿元，拥有员工近3万人，截至2025年底，总资产达1129亿元。目前，集团下辖各级子企业近140家，全资控股二级企业（单位）17家，其中上市公司1家；科技型企业12家。
