## 公司
性质:民企 · 行业:机械/制造业

吉天星舟由吉林大学林君院士、张刘教授联合创办，成立于2021年6月，是国内首家以批量化提供光学主载荷为主营业务之一的商业化航天公司。公司具备完整的空间光学遥感相机的设计、生产、试验验证体系，基于自主知识产权研发“高时效、高几何、高光谱”成像技术，构建满足全域应用需求的光学载荷技术、产品体系，同时开展星座运营及数据应用服务，致力于成为全球领先的光学遥感载荷产品及服务的提供商。
