## 公司
性质:民企 · 行业:汽车制造/维修/零配件

山东美晨科技股份有限公司成立于2004年，2011年在深交所上市，股票代码：300237。公司秉持“科技+环保”经营方针与策略，经过多年潜心发展和经营，现已形成以智能制造、高端品质人居环境和景观建设营造，以及生态农业、高端品牌的集团公司。全资子公司山东美晨工业集团有限公司是一家全球化发展的国家级高新技术企业，是国内汽车关键零部件行业领先企业。公司主要研发和生产流体管路、橡胶减震和悬架系统、新能源热管理系统、智能装备产品，广泛应用于乘用车（含新能源汽车）、商用车和工程机械市场领域，市场占有率全国前三，是山东省制造业单项冠军企业，连续17年获“全国百佳汽车零部件供应商”称号。
