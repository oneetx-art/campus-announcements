## 公司
性质:央国企 · 行业:教育/培训/科研

中国航空工业集团有限公司（简称“中国航空工业集团”）是由中央管理的国有特大型企业，是国家授权的投资机构，由原中国航空工业第一、第二集团公司重组整合而成立。集团各成员单位设有国家级重点实验室、国家级研究制造中心、国家级科技工程研究中心等科研机构，拥有中国科学院、中国工程院院士78位、国家级突出贡献专家200多位、国家级特级专家100多位、高级技术人才50000多人。沈阳兴华航空电器有限责任公司(以下简称中国航空工业集团兴华)，1955年在沈阳正式成立，是国家第一家航空电连接器生产单位，属军工央企，隶属于中国航空工业集团有限公司。拥有国家级工业设计中心、国家高新技术企业以及国家CNAS认证实验室。
