## 公司
性质:民企 · 行业:能源/化工/环保

浙江绿色石化技术创新中心于2023年1月由浙江省人民政府批复建立，是省级新型研发机构。总部位于宁波市高新区，由荣盛控股集团、浙江大学、天津大学浙江研究院等七家股东单位共同出资成立。中心以开展科研、设计、运行为主，围绕绿色炼化及化工新材料领域科技成果转化应用提供一体化协同创新，致力于打造国际领先的绿色石化高能级技术创新平台。
