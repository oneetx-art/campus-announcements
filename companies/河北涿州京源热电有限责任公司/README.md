## 公司
性质:央国企 · 行业:能源/化工/环保

河北涿州京源热电有限责任公司（简称“涿州热电”）作为京能集团落实京津冀协同发展战略、京能电力展现城市热电联产建设成就的窗口，一期项目投资35亿元建设2×350MW国产超临界、间接空冷燃煤热电联产机组，已分别于2017年11月和2018年6月投产运营，年发电量约30亿千瓦时，供热能力780兆瓦，年供热量约550万吉焦，为涿州和北京房山地区供热面积达2000万平方米。两台机组综合供电煤耗等指标在国内同类型机组中名列前茅，烟气污染物实现超低排放，是我国北方地区第一个基于纳滤分制盐技术实现脱硫废水零排放的电厂，替代关停两地高污染、高能耗燃煤小锅炉近500台。2019年顺利通过河北省高新技术企业认证。二期扩建项目建设2×1000 MW间接空冷超超临界燃煤热电联产机组，投产后可实现北京及涿州地区4600万平方米集中供热需求，每年可向京津冀地区输送约90亿度电量，是京能集团首个百万千瓦级煤电机组，预计2028年投产运营。届时累计装机容量将达2700MW，累计供热面积6600万平方米。
