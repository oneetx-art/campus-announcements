## 公司
性质:央国企 · 行业:IT/互联网/游戏

隶属于中国建筑科学研究院有限公司（简称“中国建研院”），前身为中国建研院建筑工程软件研究所，于2017年成立北京构力科技有限公司，承担中国建研院六大业务领域之一：软件与信息化。1988年创立PKPM软件品牌，2021年创立BIMBase品牌。软件产品覆盖全国建筑设计市场95%以上，聚焦五化：“信息化”、“数字化”、“工业化”、“绿色化”、“智能化”，致力于成为建设行业软件与信息化发展的引领者，现有员工千余人，其中46%以上员工拥有硕士及以上学历。
