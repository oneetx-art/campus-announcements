## 公司
性质:央国企 · 行业:商务服务业

福建省投资开发集团有限责任公司（简称“福建投资集团”）于2009年4月由7家省属国有企业重组设立，注册资本103亿元，是福建省属唯一的国有资本投资公司。截至2024年末，集团下属权属企业117家，参投项目41个，连续14年在全国省级同类企业中排名前3。集团聚焦福建省经济社会发展中发挥着支撑、引领、示范作用。
