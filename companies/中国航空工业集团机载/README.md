## 公司
性质:央国企 · 行业:机械/制造业

中国航空工业集团有限公司是由中央管理的国有特大型企业。经营范围涵盖航空武器装备、军用运输类飞机、直升机、机载系统、通用航空等产业。中航机载系统有限公司（简称“中国航空工业集团机载”）是中国航空工业集团的主要供应商和国家队。为构建民机机载产业发展新格局，2023年3月在上海成立中航机载系统工程中心有限公司（简称“民机机载系统工程中心”），与中国航空工业集团机载实施一体化管理，是我国民机机载系统研发的牵头和总体单位。
