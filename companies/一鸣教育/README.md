## 公司
性质:民企 · 行业:教育/培训/科研

湖南一鸣教育创始于2009年，是一家专注于中小学教育和咨询服务的综合型教育公司，旗下拥有两大子品牌：一鸣教育（K12综合体）、鸣德高级中学。公司总部位于湖南长沙，目前在长沙、怀化、永州、邵阳等地开设了30多家直营校区，公司秉承“尊重个性，因材施教”的教育理念，其先进的教学理念，精细的管理教学，过硬的教学质量，得到了社会各界的高度认可和广大家长和学员的一致好评。
