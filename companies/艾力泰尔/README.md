## 公司
性质:民企 · 行业:IT/互联网/游戏

北京艾力泰尔信息技术股份有限公司（简称“艾力泰尔”），成立于2004年6月，于2016年在新三板挂牌，是一家以“物联网+AI”技术为核心，面向涉水行业提供大数据解决方案、人工智能产品于物联网，服务的国家高新技术企业。公司总部位于北京，在黑龙江、吉林、山东、江西、广西、贵州、新疆、河北、云南、四川、陕西、辽宁等省份建立了分（子）公司及办事处。艾力泰尔以水业务为核心，以“1+4+N+1”模式构建透彻感知、全面互联、智能分析、智慧应用、泛在服务的现代化水文体系，致力于打造中国水文第一品牌。公司始终秉承“创新赢未来”的发展战略，目前已在智慧水文、智慧水利、智慧灌区、智慧水务、智慧水库及现代农业六大业务中形成了核心竞争力。
