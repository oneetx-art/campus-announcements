## 公司
性质:民企 · 行业:快速消费品

上海臻臣集团是一家集研发、生产与销售于一体的全球领先化妆品制造企业。集团于2015年在上海奉贤成立，目前拥有员工近2000名，其中研发团队近200人，建有4大现代化生产基地，年产能达3.5亿件，具备完善的供应链体系与坚实的品质保障能力。近年来，集团持续深化全球化战略布局，自2024年起全面加速海外市场拓展，积极构建国际化运营新格局，致力于为员工提供宽广的发展平台与多元成长空间。
