## 公司
性质:央国企 · 行业:金融业

东莞信托有限公司成立于1987年，位于东莞松山湖，注册资本金人民币22.20亿元，是东莞市属国有全资企业，广东省“立足东莞，深耕湾区”的发展战略，围绕自身能力禀赋选择培养产业金融、标品信托、服务信托和家族信托及财富管理等业务，打造具备专业能力和地区特色的综合型信托公司。截至2025年6月末，东莞信托管理信托资产规模总额1187.45亿元，今年来为投资者分配收益5.99亿元。
