## 公司
性质:央国企 · 行业:金融业

一家拥有全业务牌照的综合证券服务商。1988年成立，2007年8月27日，在深圳证券交易所上市，成为深交所首家上市证券公司。2025年上半年，公司营业收入20.46亿元，总资产996.47亿元，净资产193.24亿元。公司已在全国28个省、自治区、直辖市的66个大中城市设立了47家经纪业务区域分公司、82家证券营业部和3家分公司。设立东证融通、东证融达、东证融汇3家全资子公司，控股渤海期货、东方基金，参股银华基金。
