## 公司
性质:央国企 · 行业:农林牧渔

中国储备粮管理集团有限公司（以下简称“中储粮集团公司”）是经国务院批准组建的涉及国家粮食安全和国民经济命脉的公益类国有大型骨干企业，实行集团—分（子）公司—直属库“三级架构”，目前下设24家分公司、11家二级专业子公司和1家控股公司，人员、机构和业务覆盖全国31个省、自治区、直辖市。中国储备粮管理集团有限公司江西分公司（以下简称“中储粮集团江西分公司”）是中储粮集团公司派驻江西省的区域性机构，主要负责江西辖区中央事权粮油的经营管理工作。目前，中储粮集团江西分公司下辖22家直属库、34个分库，覆盖全省11个市，分布在50余个县（市、区）。
