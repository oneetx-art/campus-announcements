## 公司
性质:民企 · 行业:医疗/医药/生物

上海元莘生物医药科技有限公司，成立于2016年7月，总部位于上海市闵行区浦江镇。元莘生物科学研究和前沿分子生物学技术应用性能，在算生命数据开发、人基因组库、临床医学基因检测、生物信息学服务等在内的一站式、全方化服务企业，系统解决方案，为上海海紫竹科技园、金科路孵化企业和元莘生物致力于为上提供计算平台和分析中心，目前数据中心存储能力，有效保存生命科学研究和医疗健康两大领域对数据分析和存储的需求。元莘生物专注于高通量测序大数据挖掘应用，自公司成立以来已服务客户3000+，累计客户SCI论文1000余篇，累计影响因子>3000，助力中国高校生命科学技术服务产业的发展。公司先后荣获国家高新技术企业、国家，2019年度中国博士后创新例业大赛创业组项目奖、2020年度上海市闵行区创业大赛企业组、2020年度华东师范大学及创创业大赛二等奖等荣誉。
