## 公司
性质:央国企 · 行业:房地产业/建筑业

中国能源建设集团黑龙江省电力设计院有限公司（以下简称“黑龙江院”）始建于1955年，是一家实力雄厚的央企电力工程公司，具有勘察综合类甲级，电力工程施工总承包、火力发电工程、送变电工程、新能源工程、城市热力管网、乙级资质等多门类资质及资信，主要承担电力系统规划投资开发建设等业务，工程业绩遍及20多个省、市、自治区及海外多个国家和地区。黑龙江院积极拓展面向国内外，拓展新能源、新基建、新产业等领域，提供工程一体化解决方案的全生命周期管理服务商和新型电力系统投资商。
