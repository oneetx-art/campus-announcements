## 公司
性质:事业单位 · 行业:政府/机构/组织

水利部长江水利委员会（以下简称长江委）是水利部派出的流域管理机构，按照法律法规和水利部授权，在长江流域和澜沧江以西（含澜沧江）区域内行使水行政管理职责，设计了长江三峡、南水北调中线、形成了“团结、奉献、科学、创新”的长江委精神。通过七十多年的努力，逐步构建起水资源防洪减灾体系、水资源综合利用体系、长江源流生态环境保护与保护。与世界上60多个国家、地区和国际组织开展了广泛科技交流与合作，先后荣获国家科学技术进步奖特等奖“全国文明单位”“全国五一劳动奖状”等荣誉称号。
