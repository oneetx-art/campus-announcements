## 公司
性质:民企 · 行业:医疗/医药/生物

远大医药集团有限公司（股票代码：00512.HK）（简称“远大医药”），英文名称为Grand Pharma-ceuticals Group Limited，是一家集精准药物诊疗及心血管精准介入医疗科技、制药科技、生物科技于一体的科技创新型国际化医药企业。目前，企业全球员工超1万，境内外所属公司超30家，拥有15个技术平台和9个研发中心，超200个重磅自产品，业务涵盖呼吸及重症抗感染板块、肿瘤板块、心血管急救板块、眼科板块、心脑血管精准介入诊疗板块、核药抗肿瘤诊疗板块、高品质医美板块。
