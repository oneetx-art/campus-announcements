## 公司
性质:央国企 · 行业:咨询

中讯邮电咨询设计院有限公司是一家面向电信运营商和政企客户提供信息通信网络咨询设计、网络和安全产品、数智应用和服务的数智型科技企业。1952年创建于北京，是原邮电部组建最早、规模最大的综合性甲级咨询勘察设计单位，2006年成为中国联通的子公司，是国家“高新技术企业”、国务院国资委“科改企业”、“世界一流专业领军培育企业”，获评国资委科改企业“标杆”最高评级。在北京、上海、广州、成都、郑州、苏州等地设置分（子）公司，机构遍布全国31个省市自治区。拥有几十项“中国第一”的通信高新技术工程设计；1800余项省部级以上奖项，其中国家科技进步奖3项，国家级设计咨询奖200余项；专利授权和软件著作权1200余项；发布国家标准50余项，行业标准300余项。先后涌现出7位国家级设计大师，69位国务院政府特殊津贴专家。
