## 公司
性质:央国企 · 行业:IT/互联网/游戏

国家电力投资集团有限公司（简称“国家电投”）是中央直接管理的特大型国有重要骨干企业，肩负保障国家能源安全的重要使命，由中国电力投资集团公司与国家核电技术有限公司于2015年5月重组成立。国家电投集团数字科技有限公司（简称“电投数科”）是国家电力投资集团有限公司的全资二级企业，公司于2013年8月成立，位于北京市昌平区未来科学城。公司是国家最高新科技企业，致力于数字化转型支撑服务平台化建设，着力打造运营台、电投集团智力服务型国家电投集团数字、数据资产治理运营平台、数字人才培养保障平台、数字化基础设施投资运营平台、数字化安全保障输出平台，支撑国家电投集团及其所属企业的“智改数转”。
