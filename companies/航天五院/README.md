## 公司
性质:央国企 · 行业:机械/制造业

中国空间技术研究院成立于1968年2月20日，首任院长是著名科学家钱学森，五院主要从事空间技术开发、航天器研制、空间领域对外技术交流与合作、航天技术应用等业务，经过发展已成为中国主要的空间技术及其产品研制基地，是中国空间事业最具实力的骨干力量。自1970年4月24日成功发射我国第一颗人造地球卫星以来，五院抓总研制和发射了640余颗航天器，目前400余颗航天器在轨运行，研制的航天器覆盖载人航天、深空探测、导航、通信、遥感、空间科学与技术试验、空间安全等业务领域，实现了航天器系列化、平台化发展，圆满完成载人航天工程、探月工程、北斗工程、高分工程为代表的重大航天任务，为实现我国航天三大里程碑跨越发展做出了突出贡献。
