中国电科芯片技术研究院是中国电子科技集团有限公司直接管理的研究院。为解决芯片“卡脖子”问题、有效保障产业链供应链安全，整合中国电子科技集团公司在重庆、全国四个国家/集团研究所研发资源，总部设在重庆，多地均有研发中心。电科芯片立足五十多年来的技术、资源积累，成体系布局四大专业方向：集成电路、微声电子、半导体微电子、智能传感
