## 公司
性质:央国企 · 行业:能源/化工/环保

中国电力工程顾问集团西北电力设计院有限公司（以下简称“西北院”）成立于1956年10月，位于陕西西安高新技术产业开发区，是大型勘测设计企业，同时具有2项甲级工程咨询资质、1项勘察工程设计、1项工程勘察资质，致力于能源规划、勘测设计、工程总承包、EPC总承包、电网、风电、光伏、光热、地热、抽水蓄能、储能、超高压直流、综合管廊等业务，是发电、电网、新能源、基础设施等客户提供全生命周期一体化服务的建筑实力，已与全球五十多个国家和地区建立了业务往来关系。
