## 公司
性质:民企 · 行业:教育/培训/科研

希望学是一家面向全国中小学生，提供小学、中学全学科直播课程的在线培训学校。希望学的主讲老师、教研人员、班主任团队皆毕业于清华大学等高校，拥有丰富的教学培训经验及完善的教学体系开发能力。目前在北京、长春、沈阳、天津、石家庄、济南、西安、成都均开辟基地。我们的团队由一群才华横溢、热情洋溢的小伙伴组成，在6000多位高校中，有百位伙伴毕业于清华、北大等的知名高校。每天，我们都在为“成为受尊敬的教育机构”不懈努力。如果您也有明确目标、敢追梦的心，那就是对我们的最佳选择！
