## 公司
性质:央国企 · 行业:房地产业/建筑业

中国中元国际工程有限公司（简称中国中元）成立于1953年，现隶属于中国机械工业集团有限公司，是全国勘察设计综合实力百强企业，并入选工程项目管理60强企业榜单。中国中元业务涵盖医疗康养、新兴工业、能源工程、社会物流、机场工程、大科学装置、科研实验设施、数据中心、生态环保、文体教育、酒店办公、城市治理与更新等领域，可提供建筑工程建设全产业链、全生命周期的专业化服务。历经70余年发展，中国中元已成为集科技研发、工程咨询、工程设计、工程总承包、项目管理和设备成套为一体的国有大型科技型专业化工程公司。
