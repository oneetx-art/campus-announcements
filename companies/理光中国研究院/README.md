## 公司
性质:外企 · 行业:IT/互联网/游戏

理光集团全球总部设立在日本东京，在全球范围约200个国家和地区提供数字办公解决方案、印刷业务和成像解决方案。理光中国研究院成立于2004年1月，作为理光集团全球人工智能研发中心，一直致力于尖端技术和解决方案的研发工作，共同促进环境创新。理光中国研究院是国家高新技术企业、国家技术先进型服务企业、北京市首批认定的外资研发中心，同时也是北京市“专精特新”企业、中关村高新技术企业。在人工智能、深度学习、计算机视觉、机器人、人在中关村国家自主创新示范区孵化、器网络挖掘等前沿领域都取得了系统性、无同突破，多项技术位居世界水平前列，在国内外获近千项技术专利。
