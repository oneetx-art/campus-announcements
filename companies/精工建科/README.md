## 公司
性质:民企 · 行业:房地产业/建筑业

长江精工（上海）建筑科技有限公司，是精工钢构在历经20多年钢结构工程业务发展，为整体协同发展集团的工业建筑板块，在“精工”品牌基础上成立的一家大型专业化集团公司。拥有精工成套技术体系和管理体系，为中国集成、设计、制作、安装以及售后维护等一体化建筑及产品的方案。全球市场客户提供各类建筑钢结构深化服务，是中国预制金属箱式幕墙领域的领跑者。公司在上海已设立正在建立20家省级（分）公司和数家区域公司，从全国为总部，以区域系统解决方案供应商和工业建筑领域的佼佼者的形象构建的建筑系统集成（EPC）商业模式已全球领先。
