## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

中青旅是中国旅游行业改革开放的见证者。1980年，经党中央批准，中青旅成为我国改革开放后创立的首家旅行社类企业；1997年，中青旅成为行业首家完成国企改革的A股上市公司；2017年底，按照党中央国务院部署，中青旅从共青团中央整体划转至中国光大集团，列入光大集团一级直属企业序列，成为唯一一家拥有中央大型金融控股集团发展背景的旅游类上市公司。
