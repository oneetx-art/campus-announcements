## 公司
性质:事业单位 · 行业:通信/电子/半导体

中国电科五十五所位于江苏南京，是以固态器件与微系统、光电显示与探测器件为主业的军工骨干研究所。建所60多年来，以“实现半导体核心器件自主可控”为主责，在第一、二、三代半导体及新一代半导体领域建立自主发展体系，形成了从设计、工艺到封装、测试，从材料、芯片、模块到微系统的完整技术体系和产品体系，产品广泛应用于国家海陆空天网各型重点装备工程，以及5G移动通讯、新能源、微显示等国民经济建设领域，先后取得3000多项科研成果，其中国家级、省部级科技进步奖600多项。荣获“全国文明单位”“全国五一劳动奖状”“全国模范职工之家”“全国工人先锋号”“全国青年文明号”等一系列光荣称号。
