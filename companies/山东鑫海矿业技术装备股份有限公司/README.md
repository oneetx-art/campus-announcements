## 公司
性质:民企 · 行业:机械/制造业

山东鑫海矿业技术装备股份有限公司(股票代码:836797) 是集矿山设计研究、矿山工程及设备制造与采购、矿山运营管理为一体的国际化矿业全产业链服务商。作为“矿山全产业链服务（EPC+M+O）”的推出者，鑫海矿装通过以矿业全产业链服务模式，为客户提供涵盖“研究咨询、设计和工程、设备制造与采购、调试和交付、矿山管理和运营”的一站式系统解决方案，帮助客户实现降本增效与提升运营效益的目标。
