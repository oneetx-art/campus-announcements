五〇二所（中国航天科技集团有限公司第五研究院第五〇二研究所）始建于1965年10月11日，根据我国《1956-1967年科学技术发展远景规划纲要》提出的“四项紧急措施”而组建，原为中国科学院自动化研究所，是我国最早从事卫星研制的单位之一，我国第一颗人造卫星“东方红一号”控制分系统即由五〇二所抓总研制。现隶属于中国航天科技集团有限公司第五研究院。
