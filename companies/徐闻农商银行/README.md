## 公司
性质:民企 · 行业:金融业

徐闻农商银行始建于1952年，始终以“服务三农、服务地方经济、服务小微企业”为宗旨，是湛江市最南端徐闻县历史最悠久的金融机构之一。2019年正式由徐闻县农村信用合作联社改制组建而成，是徐闻县唯一的地方性独立法人金融机构，下辖33个“实、镇、村”三级全覆盖，存款规模稳居当地金融机构前列，为徐闻地区营业网点最多、服务面最广、贡献度较大的地方金融机构，是徐闻人自己的银行。
