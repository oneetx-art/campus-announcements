## 公司
性质:民企 · 行业:机械/制造业

深圳汉莎技术有限公司（简称深圳汉莎）成立于2000年，是德国汉莎技术公司（80%）和北京凯兰航空技术有限公司（20%）共同出资建立的航空维修企业。公司坐落于大湾区内的深圳宝安国际机场，与香港、澳门以及广州相邻，这个优越的地理位置同时还便于连接亚洲和世界各地。深圳汉莎是一家综合性的航空维修供应商，提供机身结构部件修理、部附件修理和发动机返厂快修服务。我们主要的客户是中国及亚太区航空公司和航空维修企业。
