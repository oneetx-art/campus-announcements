## 公司
性质:民企 · 行业:医疗/医药/生物

北京福元医药股份有限公司（股票代码601089）以“专注医药领域，共创健康人生”为使命，致力于成为“国内领先、国际知名的福元医药健康企业”。总部位于北京，下辖安徽福元、浙江爱生、万生人和、福元沧州等多家分子公司。福元医药精心打造研发、生产、销售三位一体的核心竞争优势，建有国家级博士后科研工作站，拥有专业的现代化生产基地，产品覆盖领域广泛，研发涉及化学仿制药、创新药、原料药、中药、保健品、医疗器械等领域；生产心血管、代谢、精神、抗感染、呼吸、营养、妇科、外用药等产品。公司入选北京医药产业跨越式发展工程G20企业，荣列中国药品研发综合实力百强、北京民营企业科技创新百强，中国化药研发实力五十强，获得行业内外的广泛认可。
