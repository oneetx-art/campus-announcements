## 公司
性质:民企 · 行业:新能源

诺瓦聚变能源科技（上海）有限公司成立于2025年4月，总部位于中国上海临港，是中国首家专注于小型模块化聚变反应堆（Small Modular Reactor，SMR）商业化的高科技创新企业。公司汇聚国际顶尖科学家、工程师及能源专家，秉承“Fusion for AI”使命，以场反位形（Field-Reversed Configuration，FRC）技术为核心，创造性地融合磁约束与惯性约束两大传统路径的优势。诺瓦聚变致力于以最低成本、最短时间推动聚变能源产业化落地，从根本上为人工智能与未来产业提供清洁、永恒、可靠的能源保障，引领全球能源转型与可持续发展新纪元。
