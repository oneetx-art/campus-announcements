## 公司
性质:民企 · 行业:汽车制造/维修/零配件

宇通是以客车、卡车为主业的大型商用车集团，总部位于河南省郑州市，产品覆盖客车、卡车、专用车辆、环卫设备及工程机械，旗下拥有2家上市公司，历经30余年发展，累计销售新能源商用车超23万辆，新能源稳居行业第一梯队，致力于实现电动化、智能网联化与商用车的融合发展
