## 公司
性质:民企 · 行业:通信/电子/半导体

龙腾半导体股份有限公司成立于2009年，是集芯片设计、晶圆制造、模块研发、封装测试于一体的全产业链IDM企业。公司将技术创新作为企业发展第一驱动力，累计参与制定国家标准10项（主导制定国家标准《IGBT芯片》等），起草行业标准《MOSFET 电力场效应晶体管（GPP）》、《中低压SGT MOSFET》、《中低压沟槽FS IGBT》、《碳化硅 MOSFET》 等行业标准及功率模块产品标准，为新能源汽车、轨道交通、消费、特种器件、工业控制等领域客户提供重点支持与精准定制解决方案。
