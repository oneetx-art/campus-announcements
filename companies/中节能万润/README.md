## 公司
性质:央国企 · 行业:能源/化工/环保

中节能万润股份有限公司，隶属于中国节能环保集团（国资委直属央企），主要从事环保材料、电子信息材料、生命科学与医药和新能源材料四个领域产品的研发、生产和销售。万润于2011年12月在深圳证券交易所挂牌上市，现有员工4700余人，是以研发创新驱动的平台型企业。在30年的发展历程中，通过持续开发更加先进的新材料工艺，不断生产更加优质的新材料产品，逐渐积累了深厚的化学合成优势和快速的产业化优势。创新平台工艺涵盖了有机合成、纯化、有机合成、高分子聚合等多个大类，并拥有多家在业内具备一定规模与影响力的专业化子公司。
