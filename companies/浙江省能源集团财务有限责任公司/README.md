## 公司
性质:央国企 · 行业:金融业

浙江省能源集团财务有限责任公司于2006年8月25日在杭州正式成立，是经国家金融监管部门批准设立的非银行金融机构。公司注册资本为人民币35亿元，由浙江省能源集团有限公司绝对控股。公司以“立足集团、服务集团”为根本宗旨，以建设一流司库为目标，专注于为集团成员单位提供一流的金融和财务服务，在资金统一归集管理，提升资金使用效率和收益水平等方面发挥了重要作用。截至2024年末，公司资产总额近400亿元，营业收入超7亿元。
