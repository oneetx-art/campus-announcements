中国航空研究院始建于1960年，是中国航空工业集团有限公司直属单位，是在政府间科技合作框架下从事航空技术国际合作的科研事业机构，现有7家所属单位。航空工业智航院成立于2021年，是航空工业人工智能科技发展的技术总体单位，与中国航空研究院实行一体化运营管理。
