## 公司
性质:民企 · 行业:通信/电子/半导体

广东晶科电子股份有限公司（简称：晶科电子，APT集团，股票代码：2551.HK）于2006年由香港科技大学孵化创立，总部位于广州南沙，是中国领先的融合（LED+）技术的智能视觉显示及系统解决方案提供商。公司围绕GaN研发技术实现产业链垂直整合，成为LED芯片、封装器件及应用方案供应商，产品广泛应用于LED显示、照明与新型显示等领域，构建了集研发、制造与销售于一体的集团化运营体系。
