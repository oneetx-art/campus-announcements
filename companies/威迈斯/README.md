## 公司
性质:民企 · 行业:机械/制造业

威迈斯（集团）总部位于深圳市南山区，国家级高新技术企业，于2023年在上海证券交易所上市。公司创新研发、生产、销售和技术服务为一体的综合性企业，主要产品包括车载电源的车载充电机、车载DC/DC变换器、电驱总成，电动汽车电控系统的电机控制器、电源集成产品。作为中国新能源汽车零部件细分领域头部企业，威迈斯致力成为全球汽车制造商最具价值合作伙伴，客户覆盖国内多家头部车企以及众多海外知名豪华厂商。自2020年以来，公司营业收入从6.57亿元增长至63.72亿元，复合增长率57.51%，在中国乘用车车载充电机第三方供货市场出货量持续排名第一，公司电驱多合一总成产品业务规模取得持续快速增长。
