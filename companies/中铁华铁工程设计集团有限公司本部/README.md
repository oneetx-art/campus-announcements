## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁华铁工程设计集团有限公司（简称：中铁华铁）是世界500强中国中铁股份有限公司的全资子公司，总部位于北京市丰台区，源于1953年在北京成立的原铁道部设计总局工厂设计事务所。作为国家高新技术企业、北京市设计创新中心、高速铁路建造技术国家工程研究心理事单位，中铁华铁业务涵盖建筑、铁路、机械、城市轨道交通、市政、公路等多个工程领域，是一家集勘察设计、监理咨询、EPC总承包、设备集成、岩土工程等于一体的综合型勘察设计咨询企业。
