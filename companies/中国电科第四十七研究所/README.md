## 公司
性质:事业单位 · 行业:教育/培训/科研

中国电子科技集团公司第四十七研究所，始建于1958年，是国家军工一类研究所。以支撑网络信息体系的微电子元器件自主可控、保障军工微集成电路国产化需求为使命，主要从事数字单片集成电路及模拟与数模混合信号集成电路产品研发生产，产品广泛应用于航天、航空、船舶、兵器、电子和核工业等重要军事装备。拥有国内先进水平的集成电路设计开发平台和测试系统，拥有高可靠封装科研生产线、可靠性试验和检验设备，取得科研成果近2000项、获省部级以上奖项170余项。
