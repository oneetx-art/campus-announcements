## 公司
性质:民企 · 行业:医疗/医药/生物

南通联亚药业股份有限公司（Novast）于2005年在江苏南通成立，为国际药企的研发、生产和供应其成长为一家立足国内、历经20年的发展，联亚药业已逐步成长为集研发、生产和销售于一体的具有较高知名度和影响力的跨国制药公司。公司有1个药品成功登陆美国市场，实现了中国制药企业拥有自主知识产权制剂在美国处方药销售市场零的突破，截止目前，公司共有45个高端制剂获得FDA批准，已有近40个产品进入美国处方药市场，其中有多个药品在美国市场占有率排名第一，为迄今国内同类产品中获得美国FDA批准最多的制药企业之一。
