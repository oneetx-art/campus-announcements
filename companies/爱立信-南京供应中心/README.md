## 公司
性质:外企 · 行业:通信/电子/半导体

爱立信南京供应中心设立于1992年，目前主要生产4G和5G通信设备，是业界领先的移动通信基站制造和供应中枢。2016年，南京供应中心制定了智能制造战略转型目标，全面推动自身数字化、智能化转型。2018年，爱立信追加投资5亿瑞典克朗（折合人民币约4亿元）对其进行智能改造。2019年9月，南京供应中心5G智能工厂转型升级正式完成。作为全球最先进的新产品工业化中心之一，南京供应中心广泛使用机器学习、人工智能、蜂窝物联网等技术，在生产流程的每一个环节均实现了现代化，显示出数字化运营的强劲实力，并入选“中国标杆智能工厂百强榜”。
