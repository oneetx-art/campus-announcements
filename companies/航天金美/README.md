## 公司
性质:央国企 · 行业:通信/电子/半导体

航天金美（重庆）通信有限公司（以下简称公司）是中国航天科工集团有限公司所属航天工业发展股份有限公司旗下的特种通信装备骨干企业，主要从事通信系统、通信装备和5G终端的研发、生产、营销和运维服务。公司获评国家级和重庆市“企业技术中心”，设有人社部批准的国家级博士后科研工作站，是中国航天科工集团有限公司通信网络技术中心，拥有重庆市复杂环境通信重点实验室、重庆市国防科技重点实验室，科研开发、技术研究和系统集成能力居同行前列。公司先后荣获国家“科学技术进步奖”一等奖、“国家级新产品奖”等荣誉，被授予“国家信息产业基地龙头企业”、“创新型十高高新技术企业”和“文明单位”等称号。
