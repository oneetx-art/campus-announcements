## 公司
性质:民企 · 行业:汽车制造/维修/零配件

卡尔动力（KargoBot）是全球领先的L4级自动驾驶卡车公司。成立于2021年，卡尔动力由滴滴及鄂尔多斯集团投资赋能。以全球首创的“领航车有人、跟随车无人”的“混合智能编队模式”，在干线、专线物流运输场景中，率先实现了在中国西北、华北多地的自动驾驶常态化测试和运营。卡尔动力以全球最大规模自动驾驶运输车队（超300台）、最大规模货运量（2亿吨公里），多维度领航全球自动驾驶货运实践。团队汇聚了行业优秀研发人才，来自卡内基梅隆大学、清华大学等顶尖高校和安波福等业内领先公司，拥有良好的教育背景和行业从业经历。
