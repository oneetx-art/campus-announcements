## 公司
性质:民企 · 行业:通信/电子/半导体

通达集团成立于1988年，总部设于香港，主要研发和生产基地分布在厦门、石狮、深圳、常熟。集团以“做一家备受社会尊敬的企业”为使命，专注全球智慧移动通讯及消费类电子产品领域，涵盖手机、家电、汽车、智能家居、体育用品、网通设备及5G相关行业。通达集团于2000年在香港联交所主板上市，2023年通达集团控股公司通达创智（厦门）股份有限公司在深交所主板上市。集团拥有几十项发明类专利，荣获“中国电子元件百强企业”、“高新技术企业”、“纳税特大户”、“厦门市民营企业百强”、“泉州市民营企业百强”等称号。
