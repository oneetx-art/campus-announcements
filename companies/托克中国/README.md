## 公司
性质:外企 · 行业:贸易/批发/零售

托克集团是全球领先的大宗商品贸易商之一，自1993年成立之初，托克便积极投入中国市场，并创立了托克中国。经过30多年的发展，托克中国已成为托克集团在亚洲运营的重要区域枢纽。在中国，托克从事有色金属矿产、精炼金属、原油和石油产品、以及黑色矿物（包括铁矿石和煤炭）等领域的贸易，同时积极参与碳交易，也是中国最大的铜、铅、锌精矿进口供应商。
