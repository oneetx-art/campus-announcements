## 公司
性质:民企 · 行业:通信/电子/半导体

莫仕（Molex）是全球公认的电子解决方案供应商，总部位于芝加哥郊外，于2013年12月正式成为KOCH旗下企业。莫仕光学解决方案事业部（Molex OSU）以杰出的产品设计和完美的品质，为全球通讯领域一流的设备制造商和互联网巨头提供创新型光集成解决方案。作为全球重要的光连接器、激光光源、有源连接组件及子系统供应商之一，其在数据通讯、电信、城市市场份额稳居前三。随着全球云计算数据中心市场规模持续扩大和5G电信网络建设全面展开，事业部迎来了前所未有的发展契机。
