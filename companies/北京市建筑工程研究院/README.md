## 公司
性质:央国企 · 行业:房地产业/建筑业

北京市建筑工程研究院（以下简称"建研院"）成立于1956年，是建筑工程领域多学科、综合性、技术研发型国家级高新技术企业。多年来，紧紧围绕建筑领域的重点、难点问题，不断开拓创新，在大跨度空间结构建造技术、超高层建筑施工液压爬模综合技术、结构健康智慧监测、装配式建筑智能化安装技术、智能建造关键技术、建设工程质量检测及司法服务、功能性高分子建筑材料、城市更新及抗震加固技术等方面获得了大量科技成果，培育了专业的技术团队。目前设有博士后工作站、2个市级技术中心、5个市级职工创新工作室等创新工作平台。
