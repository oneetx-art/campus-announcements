## 公司
性质:央国企 · 行业:政府/机构/组织

河南投资集团成立于1992年，注册资本120亿元，由河南省政府授权省财政厅履行出资人职责，按照金融类省管重要骨干企业管理。成立以来，始终坚守“政治使命、企业属性”的理念，秉承“融资汇智、服务河南”的宗旨，践行“投资促进科技进步、创新推动产业发展、科创造就美好生活”的使命。按照2017年省政府批复的国有资本运营公司定位，发挥“投资管理+授权管理+资产产管理+金融服务”功能，以“股权投资运营”为主业，以“基金+直投”为工具，以金融服务和资本运营为支撑，形成了金融与实业双轮驱动、基础产业与新兴产业相互促进、强周期产业与弱周期产业优势互补的发展格局。
