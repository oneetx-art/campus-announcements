## 公司
性质:央国企 · 行业:能源/化工/环保

福建省三钢（集团）有限责任公司（以下简称三钢集团）前身为福建省三明钢铁厂，建于1958年，经过60多年的发展，已形成以钢铁制造为主，集化工新材料新能源、数智供应链、文旅康养、环保资源、金属深加工为一体的行业、长流程、跨所有制的大型企业集团。目前，三钢集团有职工1.53万人，总资产667.3亿元，拥有全资及控股子公司18家（福建三钢闽光股份有限公司为上市公司），紧密型企业1家，其中钢铁主业有三明闽光、泉州闽光、罗源闽光三个长流程钢铁生产基地，具备年产钢能力1250万吨。近年来，三钢集团坚持以习近平新时代中国特色社会主义思想为指导，坚持创新驱动，强化结构调整，全面推进高端化、智能化、绿色化转型，持续提升企业核心竞争力。2024年，实现营业收入474.49亿元，工业总产值449.29亿元，主要经济指标保持行业先进水平。
