## 公司
性质:民企 · 行业:生活服务业

手擀现烤中国汉堡开创者塔斯汀诞生于2012年。十三年来，塔斯汀从一间西式快餐店出发，始终致力于西式快餐的国味改良，走出了一条中国汉堡的创新之路。作为手擀现烤中国汉堡技艺，研发更多以汉堡为载体，融合中国传统面点烹饪，迸发更多元的饮食风味，以东方味蕾探索西式快餐的更多可能性，用中国味道传递中国文化。历经十三年发展，塔斯汀已成长为手擀现烤中国汉堡品类门店数第一品牌。截至2025年10月，塔斯汀全国门店数超10000家，覆盖300余座城市。未来，塔斯汀将秉持产品创新驱动品牌发展的理念，继续深耕中国汉堡这一品类，在中华美食的魅力谱系中韵味创新。
