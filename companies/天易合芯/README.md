## 公司
性质:民企 · 行业:通信/电子/半导体

天易合芯是由海内外团队联合多家上下游产业资本与一线创投集团，于2014年成立的集成电路设计企业，致力于模拟（信号链和电源）、射频集成电路及SOC的设计、研发、产品销售和技术服务等。本公司的团队成员均具有世界级领先水平的高性能模拟集成电路设计经验，并掌握了一系列的核心技术，在所在领域形成了强大的竞争壁垒和产品性能的领先地位，在多个细分领域占国内市场占有半大部分。产品主要应用于智能穿等消费电子、手机通信、PAD笔电、工业医疗领域，已与三星、华为、小米、联想、诺基亚、大疆、联影、华勤、闻泰、龙旗等几大ODM等等众多公司合作。并正在加大在信息通信、工业医疗、汽车电子领域的投入，目前公司处在高速成长期。
