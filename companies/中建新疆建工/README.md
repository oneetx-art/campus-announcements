## 公司
性质:央国企 · 行业:房地产业/建筑业

中建新疆建工（集团）有限公司是世界500强第16位企业——中国建筑股份有限公司的控股子公司。中建新疆建工现有22家全资子公司、2家分公司，1家控股上市公司、2家参股公司，总部设21个职能部门。已形成新疆建工（集团）、中建市政、中建投资公司、中建西部建设、中建安装五大全产业链子公司为核心，辐射为中心：以山东为核心，辐射华东地区；以深圳为中心，辐射华南地区；以雄安为核心，辐射京津冀地区；以乌鲁木齐为核心，辐射新疆本地及中亚、西亚市场。先后在塔吉克斯坦、坦桑尼亚、吉尔吉斯斯坦、巴基斯坦、蒙古国、苏丹、塔吉克斯坦、吉尔吉斯斯坦、哈萨克斯坦等国家承建工程。
