## 公司
性质:民企 · 行业:IT/互联网/游戏

北京天地和兴科技有限公司（简称天地和兴）是我国最早专注于工业网络安全的专精特新企业，自2007年创立以来，凭借着深厚的技术底蕴和卓越的创新能力，迅速崛起成为国家级专精特新“小巨人”企业以及国家级高新技术企业。天地和兴以北京为总部，业务广泛辐射全国31个省、自治区、直辖市，深度服务于电力网、石油石化、轨道交通、智能制造、冶金矿山、市政水务、应急环保和运营商等关键信息基础设施行业。
