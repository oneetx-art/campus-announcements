## 公司
性质:央国企 · 行业:金融业

恒银期货有限公司成立于1999年9月，是河北建设投资集团有限责任公司金融业务板块的核心企业。作为河北省唯一一家法人期货公司。下设厦门、山东、武汉三家省外分支机构及唐山、邯郸、沧州三家省内营业部，主要从事商品期货经纪、金融期货经纪及期货投资咨询业务。
