## 公司
性质:央国企 · 行业:机械/制造业

中国航天科工集团第二研究院二〇六所创建于1970年7月15日，是我国航天事业和国防科技工业的中坚力量，航天强国建设和国防武器装备建设的主力军。二〇六所形成了以发射及发射控制技术、智能控制技术、先进机电平台技术、精密机电地面、先进源空技术等为核心的专业技术体系，承担地面、舰面、空中等多领域发射平台及地面装备、精密机电产品、空间机电产品等研制生产任务，研制生产的多型装备先后参加了庆祝建国35周年、50周年、60周年、70周年，纪念中国抗日战争暨世界反法西斯战争胜利70周年，庆祝建军90周年共6次阅兵仪式。二〇六所共获得国家科学技术进步特等奖3项，多次荣获国家科学技术进步一等奖、二等奖，荣获第十六届全国质量奖、全国五一劳动奖状、全国文明单位、全国模范职工之家、全国工人先锋号、中央企业先进基层党组织、中央企业思想政治工作先进单位、中央企业五四红旗团委等荣誉。二〇六所始终坚持党的全面领导，秉承“国家利益高于一切”的核心价值观，践行“科技强军、航天报国”的光荣使命，始终站在我国地面装备技术发展的最前沿，荣定世界一流航天防务智能机电研究所的奋斗目标阔步前行！
