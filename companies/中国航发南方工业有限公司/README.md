## 公司
性质:央国企 · 行业:机械/制造业

中国航发南方工业有限公司，始建于1951年10月，隶属于中国航空发动机集团有限公司，国央企，是我国中小航空发动机研制生产基地。公司是国家“一五”期间156个重点建设项目之一，国家首批试点的57家企业集团之一，国家首批创新型企业，是我国中、小型航空发动机主要研制生产企业。
