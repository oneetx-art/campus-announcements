## 公司
性质:民企 · 行业:机械/制造业

始建于1954年的洛轴，是国家“一五”期间156个重点建设项目之一，经过70多年的建设与发展，已成为我国轴承行业规模最大，配套能力最强的综合性轴承企业之一。主要从事轴承及轴承零部件的研发、生产和销售，是国内轴承行业排头兵企业，拥有国家认定企业技术中心、行业唯一的国家重点实验室、国家认可实验室（CNAS）等国家创新平台。公司产销规模、配套服务能力位于中国轴承行业前列，至今仍保持着产品尺寸最大、结构最复杂、精密度高等多项行业纪录。
