## 公司
性质:央国企 · 行业:能源/化工/环保

国网新疆电力有限公司（以下简称公司）是国家电网有限公司在新疆注册的全资子公司，以建设运营电网为核心业务，承担着贯彻落实新时代党的治疆方略，保障自治区安全、经济、清洁、可持续电力供应的基本使命。公司成立于1990年5月，经营区域覆盖疆内14个地（州、市），供电营业区域面积约160万平方公里，营业户数超1300万户。公司下属15家地（州、市）供电公司、12家业务单位和81家县公司，公司共有员工3万余人。2024年，公司业绩考核排名跃升至国网省公司第11名、A级序列，各项工作取得新成绩、迈上新台阶，得到各级领导充分肯定和社会各界广泛赞誉。公司广阔的发展前景，必将为广大英才提供施展才华的舞台，真诚欢迎您的加入，携手国网新疆电力，把握机遇、放飞梦想，共同开创新疆电力事业的美好明天！
