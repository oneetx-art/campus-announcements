## 公司
性质:民企 · 行业:机械/制造业

陕西汉德车桥有限公司成立于2003，由潍柴动力与陕汽集团合资组建，是集研发、制造、销售、服务于一体的大型高新技术企业，在西安、宝鸡、株洲、铜川布局四大生产基地，具备年产各类桥总成150万根的生产能力，销售收入最高超130亿元。下辖汉德车桥(株洲)齿轮有限公司、陕西金鼎铸造有限公司2家全资子公司，共有员工5400余名。产品主驱涵盖全系列桥产品、客车桥、非公路车桥、产品四驱四大系列，销量连续九年位居车桥第一，全球级第三。
