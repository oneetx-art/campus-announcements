## 公司
性质:民企 · 行业:教育/培训/科研

菁思教育成立于2019年，总部位于温州，是一家致力于构建青少年全知识、全思维、文学素养、英语语言能力素养为一体的多元化素质教育公司。作为温州市素质教育领域的领军企业，公司业务涵盖“精品课堂”、“个性化1对1辅导”、“竞赛培优课堂”、“专业升学咨询”等多维度教育服务。经过持续稳健的发展，已在温州多个核心区域设立分校，形成完善的教育服务网络。
