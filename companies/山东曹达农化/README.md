## 公司
性质:民企 · 行业:能源/化工/环保

山东曹达农化有限公司是一家集专业药剂、农药复配制剂、科研、生产于一体的现代化化工有限公司。公司成立于1995年，旗下拥有曹达、天诚、泰鲁等多个品牌公司，拥有近120吨专利、1100余项农药登记证。公司及其产品先后获得全国企业征信系统AAA级信用单位、山东省著名商标、全国用户信得过十大行业名牌、中国十大著名品牌、守合同、重信用企业、曾被共青团中央授予青年就业创业见习基地等荣誉和奖项。
