## 公司
性质:民企 · 行业:能源/化工/环保

白云电气集团作为广东改革开放的排头兵，从1979年打铁起步，历经四代人、六个阶段、四十多年的转型升级，探索出了一条传统电力装备制造企业充分利用“云、探、物、智、移、秘”技术，转型为绿色智慧能源的践行和引领者的民营企业绿色发展之路，能为客户提供源、网、荷、储一体化绿色智慧能源和节能降碳解决方案。集团是中国机械工业百强、中国工业行业排头兵、国家创新型企业，核心企业已在上交所主板上市。
