## 公司
性质:央国企 · 行业:金融业

招商银行武汉分行成立于1992年，是招商银行首家省级分行，也是第一家进入湖北地区的全国性股份制商业银行。多年来，武汉分行紧跟湖北“城市圈扩容为城市群，不断加速发展网点落子布局，目前已成为区域股份制商业银行发展中的排头兵。以武汉为中心，辐射黄石、宜昌、孝感、襄阳、黄冈、十堰、荆州等七大城市，建设上百家服务网点，让“金葵花”盛开在荆楚大地。
