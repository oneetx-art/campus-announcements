## 公司
性质:民企 · 行业:快速消费品

璞真成立于2000年，是一家专注于复合调味料的研发、生产和销售的专业服务商，成立至今已有25周年。璞真食品始终聚焦餐饮产业链核心需求，专注为连锁餐饮企业提供风味标准化整体解决方案。自2003年进入西式复合调味料行业，至2012年率先提出中餐味道标准化并进入中餐复合调味料行业，璞真已成为中、西复合调味品的标准化全案解决制造公司，累计服务超1000家连锁餐饮品牌。
