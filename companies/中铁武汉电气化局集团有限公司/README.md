## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁武汉电气化局集团有限公司是世界500强-中国中铁股份有限公司旗下的全资子公司。公司先后参建中国第一条电气化铁路宝成线及工厂、京沈、沪昆、海南环岛、京十、潍莱、广州等30余条国家重点铁路，参建北京、武汉、兰州等30余座城市，开展高速建筑、以400km/h及以上高速项目机电通道原管理、国家重点工程及高铁、关键技术研究。公司全面搭建时速达350公里的“高铁智能高铁、新制式轨道交通等前沿技术“十四五”系统中国（国家）研发-铁路电化建设，试运行1035正线公里（国）研发-铁路电化建设，试运行1035正线公里（国）研发“一带一路”的标志性工程。习近平总书记“高质量共建一带一路”的标志性工程。
