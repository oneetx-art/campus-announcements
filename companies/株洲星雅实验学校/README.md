## 公司
性质:民企 · 行业:教育/培训/科研

2018年4月，长沙雅礼教育集团携手湖南星雅教育发展有限公司创办株洲南雅实验学校，现更名为株洲星雅实验学校。学校是一所民办完全中学，占地面积110亩，现有教职工227人，学生2800多人，58个教学班。学校先后荣获多项荣誉，如2021-2025年连续五年获评“株洲市普通高中教育质量综合评价优秀学校”等。
