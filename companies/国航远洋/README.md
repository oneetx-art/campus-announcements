## 公司
性质:民企 · 行业:交通/物流/仓储

福建国航远洋运输（集团）股份有限公司（简称“国航远洋”）成立于2001年4月，主要从事国际远洋、国内沿海和长江中下游航线的干散货运输业务，是我国大型干散货航运企业之一。经过二十余年的发展，于2022年12月15日在北京证券交易所成功上市，成为北交所“航运第一股”，也是福建省首家在北交所上市的企业，证券代码：833171。公司形成了以航运业务为主，以船舶管理、商品贸易等相关业务为辅的业务布局。根据交通运输部公布的《中国航运发展报告》，自2019年至2023年，公司经营船队规模连续5年国内排名行业第四。
