## 公司
性质:民企 · 行业:快速消费品

C咖,于2021年正式运营,是专注科研创新的油皮精准护肤品牌;成立首年,7个月内斩获3轮融资,股东为本溪(小米集团创始人雷军创办)和元璟资本(阿里巴巴集团联合创始人吴泳铭创办)等海内外顶级资本投资;经过4年沉淀,C咖已成为2000W+用户选择的品牌,获中国加油护肤第一品牌市场认证;此外,集团还孵化了面部身体护理品牌-HUKO乎刻;未来将持续推出更多品牌和创新产品,与消费者见面(新品牌正在筹备中)。
