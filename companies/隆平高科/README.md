## 公司
性质:民企 · 行业:农林牧渔

隆平高科1999年成立，2000年在深交所上市，是由袁隆平院士作为主要创始人设立的现代种业企业，也是中信集团作为第一大股东实施管理，湖南杂交水稻研究中心、北大荒集团作为重要国有股东单位，以及公司管理层、育种家和骨干员工共同持股的混合所有制企业。公司主营业务包括杂交水稻、玉米和小麦三大主粮种业，黄瓜、辣椒、谷子、食葵等专精特新种业，以及种粮一体、农民培训、农业援外等农业服务，不断为民族种业的崛起和先进农业技术的全球传播贡献力量。目前杂交水稻种子业务全球领先，杂交玉米种子业务中国领先、巴西前三，辣椒、黄瓜、谷子、食葵业务构建领先。
