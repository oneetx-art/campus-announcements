## 公司

中材锂膜有限公司（以下简称“中材锂膜”）隶属于国务院国资委直接管理的大型央企——中国建材集团旗下A股上市公司中材科技股份有限公司，是专业从事锂离子电池四大核心材料锂电池隔膜的研发、生产、销售及技术服务的高新技术企业。中材锂膜（萍乡）有限公司于2022年6月在萍乡市芦溪县工业园区注册成立，主要从事湿法隔膜及涂覆隔膜的研发、生产和销售。
