## 公司
性质:央国企 · 行业:金融业

江苏农商联合银行及所辖60家农村商业银行，是具有独立企业法人资格的地方性金融机构，是江苏省内存贷款规模最大、网点覆盖率最广、服务客群最多的金融机构，是支持地方经济发展的农村金融主力军。截至2025年12月末，全系统资产总额5.17万亿元，各项存款余额4.16万亿元，各项贷款余额3.32万亿元，存贷款余额均居省内银行业首位。目前辖内已有6家农商银行在国内主板上市，江苏是A股上市农商银行最多的省份。
