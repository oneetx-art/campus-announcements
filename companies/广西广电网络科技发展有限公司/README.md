## 公司
性质:央国企 · 行业:通信/电子/半导体

广西广电网络科技发展有限公司（以下简称“广西电科公司”）前身为广西广播电视信息网络股份有限公司（以下简称“广西广电网络公司”），是经上级批准设立的国有文化企业，全面承接传播播出安全保障和广电网络资产运营管理的职能定位。公司下设89个市、县分公司，5家全资子公司，1家共司制公司，5家参股公司，员工总数约4100人。主要从事有线广播电视传输、5G移动数字电视业务、宽带互联网业务、广播电视网络建设运营和数据专网业务、客服系统集成、通信工程、文化数字化等综合信息服务。
