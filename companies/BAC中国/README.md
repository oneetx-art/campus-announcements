## 公司
性质:外企 · 行业:机械/制造业

BAC是全球卓越的冷却技术及解决方案供应商，总部位于美国。自1938年以来，BAC始终致力于为舒适性空调、工业及冷冻领域提供绿色、混合的方案。多元化的产品技术涵盖蒸发冷却、混合冷却、绝热冷却、干式冷却及浸没式液冷。BAC秉承创新，引领行业迈向可持续发展的未来。BAC中国总部位于大连，在北京、上海、苏州分别设有公司，是亚太区暖通空调、工业冷冻及过程冷却节能的卓越供应商，为客户提供业界领先、细节卓越的卓越供应及可持续解决方案。
