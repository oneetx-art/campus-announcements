## 公司
性质:央国企 · 行业:能源/化工/环保

中国电能成套设备有限公司（以下简称“中国电能”）是国家电力投资集团有限公司全资子公司，成立于1972年，前身为水利电力部成套设备公司，1987年更名为水利电力部成套设备局，1999年改制为中国电能成套设备有限公司。中国电能是我国电力招标采购、设备成套、工程咨询、设备监理服务的发起者和引领者，拥有国内电力发展历程中设备招标、设备成套、设备监理的领先纪录二十余项。
