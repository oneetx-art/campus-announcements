## 公司
性质:央国企 · 行业:机械/制造业

中国航天科工六院红岗公司（内蒙古航天红岗机械有限公司）是中国航天科工集团第六研究院所属子公司，始建于1965年，主要从事航天装备研制与生产工作，在金属材料、复合材料成型的研发制造领域具有一定竞争优势，拥有以先进材料、先进制造、基础前沿为核心的完整专业技术体系。
