## 公司
性质:央国企 · 行业:金融业

中国出口信用保险公司（以下简称“中国信保”）是支持中国对外经济贸易发展与合作、具有独立法人地位的中央金融企业，是我国唯一的政策性保险公司、四家政策性金融机构之一。公司总部设在北京，在全国设有26家分公司，1家全资子公司，并设立7家境外机构。中国信保以“履行政策性职能，服务高水平开放”为己任，有效服务国家战略，精准支持企业发展，确保财务可持续，积极扩大出口信用保险覆盖面，在服务共建“一带一路”、全力促进外贸稳中提质、培育国际经济合作和竞争新优势、推动经济结构优化等方面发挥了不可替代的作用。2015年以来，中国信保业务总规模连续在全球官方出口信用保险机构中排名第一。中国出口信用保险公司福建分公司（以下简称“中国信保福建分公司”）于2002年7月正式揭牌运营，下设宁德营业部、漳州营业部、泉州营业部，负责为我省行政区域（除厦门）的企业提供出口信用保险相关服务。
