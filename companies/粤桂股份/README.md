## 公司
性质:央国企 · 行业:政府/机构/组织

广西粤桂广业控股股份有限公司（简称“粤桂股份”），是国内制糖业第一家上市公司，是环保集团控股企业。粤桂股份以糖纸制造、硫铁矿开采及硫化工为起点，重点布局绿色化工新材料和光伏产业，构建循环产业体系，在“化工+新能源材料”赛道上不断走深走实，现已逐渐形成糖浆纸、硫化工和新能源材料三大板块协同发展的业务格局，发展壮大成为一家国有控股综合上市公司。
