## 公司
性质:民企 · 行业:教育/培训/科研

新东方教育科技集团从教育领域出发，集团业务目前涵盖教育服务、生活服务、文旅服务三大领域，公司定位于以学生全面成长为核心，以科技为驱动力的综合性教育集团。深圳新东方学校是新东方教育科技集团于2003年在深圳注册成立的分校，总部位于南山区TCL大厦。凭借经济特区的环境优势，深圳学校发展迅猛，业务范围覆盖少儿、初高中素养教育等领域。
