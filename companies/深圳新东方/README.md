## 公司
性质:民企 · 行业:教育/培训/科研

新东方教育科技集团从1993年北京新东方学校起步，历经近33年创新深耕已成长为覆盖教育服务、生活服务、文旅服务三大领域的综合教育集团——2006年登陆美国纽交所，2020年港股二次上市。深圳新东方学校是集团2003年在深圳经济特区设立的直属分校，总部坐落于南山区TCL大厦。依托深圳的创新土壤与资源优势，我们已快速拓展为业务覆盖少儿、初高中素养教育等领域的本地核心教育机构。
