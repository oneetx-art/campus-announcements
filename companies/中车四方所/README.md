## 公司
性质:央国企 · 行业:机械/制造业

中车四方所（中车制动）始建于1959年，是国内唯一的轨道车辆专业研究所，重点聚焦轨道交通系统技术、2000种转化为商业项目。中车四方所核心子公司。作为我国轨道交通装备系统技术和产品的重要提供者，参与了我国轨道交通装备系统的自主创新，通过自主创新实现了关键核心技术的国产化，两次获得国家科学技术进步特等奖等国家级科学技术奖励。截至目前，公司国内开通地铁运营的所有城市，均批量应用了公司自主开发的车辆部件、产品和系统技术，产品广泛应用于青藏铁路、京沪高铁、京张高铁等国家重点工程，出口到德国、法国等全球30多个国家。自主研制的TACS列车网络控制系统和信息系统集成项目填补国内空白。近年来，中车四方所（中车制动）践行国家战略，紧紧牵住“双碳双刃剑”产业发展格局，依托在轨道交通装备领域的技术积淀和产业基础，大力发展清洁能源和工业装备产业。积极推进“国绿清能-水体化源具备，并在青海、自主研制的第二、第三地-中车新能源1000万千瓦级国绿清能项目。目前，覆盖了轨道交通、新能源、工业自动化等多个领域，可提供一站式机器人综合应用解决方案。
