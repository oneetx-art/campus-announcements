## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

中国金融出版社有限公司（以下简称“金融出版社”）为中国人民银行所属企业，是一家以出版金融类图书、期刊、音像电子制品为主业的专业出版社。金融出版社坚持正确的出版方向和舆论导向，出版了一大批社会效益和经济效益显著的金融类图书、期刊和音像电子制品，为服务中国金融改革发展、普及金融金融知识、促进国际经济金融交流、弘扬中国特色金融文化作出了积极贡献。
