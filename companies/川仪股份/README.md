## 公司
性质:央国企 · 行业:机械/制造业

重庆川仪自动化股份有限公司是世界500强中国机械工业集团有限公司（简称“国机集团”）旗下仪器仪表研发制造骨干企业、国机集团所属二级企业A 股上市公司（股票代码603100）。公司前身为1965年成立的四川仪表总厂，是我国“三线建设”时期重点布局，公司已发展成为国家自动化系统、装置高新技术的企业，连续多年获评工业自动控制系统装置制造业行业协会理事长单位。公司总部坐落于重庆市两江新区，构建了完善的研发、生产、销售、服务体系。主力产品覆盖工业自动化控制、智能仪表、传感器等多个领域，国内市场占有率持续位居前列，多项核心技术成功实现国产化替代，为我国制造业和新型工业化建设作出重要贡献。
