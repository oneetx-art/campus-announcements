## 公司
性质:央国企 · 行业:金融业

成都银行股份有限公司（以下简称“成都银行”）成立于1996年12月，是一家国有控股的地方性股份制商业银行，引入马来西亚丰隆银行作为境外战略投资合作伙伴。2018年1月18日，成都银行在上海证券交易所主板上市。截至2025年6月末，成都银行总资产13722.25亿元，各项存款9834.81亿元，各项贷款8346.28亿元。2025年，成都银行位列英国《银行家》“全球1000强”第324位、一级资本排名第305位；位列《财富》“中国500强”第170位。
