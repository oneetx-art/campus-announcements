## 公司
性质:央国企 · 行业:机械/制造业

重庆嘉陵特种装备有限公司隶属中国兵器工业集团有限公司，现有员工2100余人，资产35亿元。拥有重庆沙坪坝、璧山、北碚以及成都郫都等多个生产基地。经营产品涵盖特种产品、特种车辆、光电产品、汽车零部件、摩托车等研发制造，产品出口亚非欧、南北美等多个国家和地区。公司特种产品谱系齐全，涵盖国内装备、公安边防和反恐处突等多个领域，是我国某特种产品的行业标准制定者、检验用品的唯一供应商，为国防事业做出重要贡献。公司为拥有4个省部级技术中心、1个专家级和1个国家级新技术企业、省部级专精特新超级技能大师工作室和4个劳模创新工作室。
