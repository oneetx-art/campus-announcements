## 公司
性质:民企 · 行业:机械/制造业

明石创新技术集团股份有限公司创立于1995年，是以先进制造为 主业、以技术创新驱动产业发展为核 心模式的创新型工业企业集团。秉承“深耕 产业，守正创新”的经营理念，经过多年发展，明石集 团构建了“实业+研究院+创投”的产业体系，涵盖微纳 制造、医疗健康设备、环保专用设备、陶瓷新材料等四大 战略新兴产业领域，注册资本37.89亿元，总资产 120亿元、净资产100亿元，构建了以明石创新产业技术 研究院为引领的集团研究院体系，认定了17个省级以上 创新平台，牵头建设了国家级制造创新中心。
