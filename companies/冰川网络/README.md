## 公司
性质:民企 · 行业:IT/互联网/游戏

冰川网络成立于2008年，2016年在国内创业板上市。公司践行“一切为了用户体验”的企业文化，研运一体化发展，在MMOARPG、放置卡牌领域积累深厚。成立以来面向全球市场陆续推出了多款明星产品：《远征OL》、《龙武》、《远征手游》、《龙武手游》、《X-HERO》、《超能世界》，赢得了广泛的用户口碑，成长为国内知名网络游戏企业。
