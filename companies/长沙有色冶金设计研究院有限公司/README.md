## 公司
性质:央国企 · 行业:能源/化工/环保

长沙有色冶金设计研究院有限公司（简称“长沙有色”）成立于1953年，国家高新技术企业，注册资金7亿元，现隶属于中国铝业集团有限公司，为中铝国际的工程板块核心子公司。经过近七十年的发展，长沙有色院已成为有色金属行业全产业链和项目全生命周期的设计和服务提供商，主要为国内外有色金属采矿、选矿、冶炼、新能源材料等客户提供咨询、工程总承包、科学研究和技术开发、冶炼、化工等近40个技术专业，下属选矿子公司、工程施工子公司、投资公司、全资子公司等，长沙院取得了甲级资质15项、乙级资质17项，完成了工程咨询设计项目1.3万余项，承担了政府和省部级重大技术研发项目2300余项，获得了13项国家重大奖项726项（其中国家科技进步奖1项、标准、规范76部，主编了国家核心期刊1部，行业标准、国家权专利796件，主、参编了国家、行业有色矿冶领航者、绿色环保先锋队、新兴产业孵化者。
