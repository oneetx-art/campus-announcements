## 公司
性质:其他 · 行业:医疗/医药/生物

康华生物（300841.SZ）是中国领先的创新型疫苗企业，业务覆盖创新生物制品研发、生产与商业化全流程。公司在成都龙泉驿区、温江区布局现代化产业基地，并设立上海研发中心，兼顾前沿技术突破与成熟管线转化。未来，康华生物将持续通过川沪联动、产融结合的策略，在预防性与治疗性疫苗领域打造具有全球竞争力的产品组合，为公众健康提供坚实保障。
