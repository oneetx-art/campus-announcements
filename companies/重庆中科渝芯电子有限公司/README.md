## 公司
性质:民企 · 行业:通信/电子/半导体

重庆中科渝芯电子有限公司（Analog Foundries）成立于2010年3月，是专业从事模拟集成电路芯片制造与服务的国家级专精特新“小巨人”高科技企业。公司坐落于重庆市西永微电子产业园，拥有一座月产2万片的6英寸模拟晶圆厂。公司长期专注于模拟晶圆工艺技术与生产，建立了覆盖模拟集成电路产品门类齐全的系列化工艺制造平台，包括各种工作电压和速度，多种器件结构的Bipolar、CMOS、BCD、BICMOS和功率器件工艺制程，以及SiGe、SOI、JFET、高精度无源器件等特种技术，向国内外客户提供特色差异化的工艺制造、产品和服务。可支持AD/DA转换器、放大器、驱动器、电源管理、通讯/接口等集成电路及DMOS、SBD/SBR、TVS、滤波器、光电器件产品的研制生产。
