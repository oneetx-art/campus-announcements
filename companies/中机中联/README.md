## 公司
性质:央国企 · 行业:机械/制造业

中机中联工程有限公司（简称“中机中联”）前身为机械工业部第三设计研究院，1964年成立于天津，1965年内迁至重庆，2013年更名为中机中联工程有限公司，具有科技综合甲级资质，是国家级高新技术企业、国有科技型工程公司，隶属于中央大型企业集团——中国机械工业集团有限公司。中机中联秉承“精益求精、至善至美”的管理方针，聚焦工程项目全过程设计、工程总包、设备成套、工程运维的项目全生命周期，为工程项目提供全生命周期、全产业链一站式服务。
