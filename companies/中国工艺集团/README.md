## 公司
性质:央国企 · 行业:耐用消费品

中国工艺集团有限公司（保利工艺）是中国领先的综合性工艺美术产业集团。2007年，经国务院批准，由中国工艺品进出口总公司和中国工艺（集团）公司这两家中央企业联合重组设立。两集团企业在支援国家经济建设、推动工艺美术产业和黄金市场改革发展方面做出突出贡献。2017年，经国务院批准，整体并入中国保利集团有限公司。
