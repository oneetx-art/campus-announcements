## 公司
性质:央国企 · 行业:能源/化工/环保

黄河万家寨水利枢纽有限公司是随着国家“九五”重点工程——万家寨水利枢纽的建设而组建的，其前身是1993年成立的“水利部万家寨工程建设管理局”，1997年按现代企业制度改制为“黄河万家寨水利枢纽有限公司”。公司由水利部、山西省、内蒙古自治区联合组建，主要经营范围为供水、发电、水利水电工程开发与运营管理、代建管理技术服务、建设咨询等。万家寨公司管理万家寨和龙口两座大型水利枢纽工程。万家寨枢纽是黄河中游梯级开发的第一座大型水利枢纽，是黄河中游治理开发的关键性工程，设计年供水量14亿m³，总装机容量1080MW，设计多年平均发电量27.5亿kW·h。龙口水利枢纽是万家寨水利枢纽工程的反调节配套工程，总装机容量420MW，设计多年平均发电量13.02亿kW·h。公司先后荣获“国家一级水利工程管理单位”“全国水利系统卓越绩效模式先进单位”“全国水利建设与管理先进集体”“山西电力行业优秀企业”等荣誉称号。
