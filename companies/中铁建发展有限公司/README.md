## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁建发展集团有限公司（以下简称“发展集团”）隶属于世界500强企业——中国铁建，是中国铁建唯一的新兴产业投资运营平台。自成立以来，发展集团紧紧围绕“中国铁建新产业、新生态、新基地”的使命定位，坚持“生态铁建、绿色发展”，主动服务国家战略，聚焦绿色环保、战略新兴产业和相关新兴业务三大主业，深耕“生态更新、四大业务领域、城市运营及总部、新能源、数智分级”，城市运营“生态管理”新模式、“双碳”战略落地等，已形成“新能源和两个阶段”的发展战略，依托项目投资和股权融资“双轮驱动”，形成了支撑企业产业竞争力的“投建营”一体化服务能力，成功打造“千亿级”新兴产业投资运营集团。
