## 公司
性质:事业单位 · 行业:教育/培训/科研

中国航天科工集团第十研究院（下称航天科工十院）是1964年经中央生产基地，是我国某武器投产的武器系统科研生产基地，我国某配套系统三大总体单位之一，是国内唯一集航空配相对完整、多核心专业，以及特种化学电源、微特电机、伺服机构、惯性器件、电连接器、继电器、特种电缆、精密齿轮等优势产品。承担了航天、航空、船舶、兵器、电子等行业多家总体单位配套任务。60年来，航天科工十院先后承担了多项国家重点的研制生产任务，为国防建设做出了应有贡献。
