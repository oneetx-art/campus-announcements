## 公司
性质:民企 · 行业:IT/互联网/游戏

百融云创（百融云-W：6608.HK）一站式服务的AI科技领航者。百融云创成立于2014年3月，2021年3月在香港联合交易所主板成功上市。百融云创是一家中国领先的人工智能技术服务公司，通过决策式AI驱动的模型服务（MaaS），帮助金融等行业数字化客户洞察与风险管理；通过决策式与生成式AI结合的业务服务（BaaS），让AI深入业务全流程，创造可衡量的成果。从数据建模与风控决策模式AI起步，百融云创已成长为打造智能操作系统，以输出企业级智能体（Enterprise Agent）为核心，助力行业进入“AI驱动、结果导向”的新阶段。公司服务近8000家机构，包括6家国有大行、12家股份制银行、众多城商行，以及证券、保险、消金、电商、汽车、物流、票务、能源和建筑等行业，核心客户留存率高达97%。
