## 公司
性质:民企 · 行业:快速消费品

深圳市金蝶轩食品有限公司（品牌名称“KNAC御蝶坊”）成立于2000年3月，总部位于广东深圳。御蝶坊是一家集研发、生产、配送、销售一体化的西式糕点食品大型企业。主营面包西饼、生日蛋糕、水吧饮品、中秋月饼、喜嫁礼饼等产品。御蝶坊在深圳有直营连锁专卖店近80家，超100万高频消费会员，自建2万平方全程无菌封闭化工厂，业已成为深圳具有代表性的烘焙连锁品牌。
