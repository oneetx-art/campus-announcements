## 公司
性质:央国企 · 行业:金融业

中国能建投资集团（以下简称投资集团）成立于2014年，注册资本60亿元，为中国能源建设股份有限公司（以下简称中国能建）的全资子集团，是中国能建投资业务旗舰和核心平台，承担着中国能建产业牵引、拉动、转型、升级、发展的历史使命。投资集团大力弘扬“守正、创新、价值创造、绿色共生、和谐共赢”的企业精神。坚守新发展理念，投资集团在能源电力领域实现了规模化、跨越式发展，覆盖了各级子企业，管理现有优势，业务开发已基本覆盖全国省级行政区域，与各级政府建立了全方位的战略合作关系。投资的电（场）站类型已涵盖火电、水电、风电、光伏、光热、生物质发电、储能等多种能源类型。投资集团始终恪守“两个初衷”、心系“国之大者”，全面将高质量发展核心要求嵌入各源泉，集中布局与发展主业，坚守价值投资、价值创造本深，品牌与市场实现一体产业，坚持畅通循、以投、控、管、资、营、退“七优”的良性资产循环，以高质量投资引领高价值增长，奋力打造行业一流、国际知名的创造投资集团，持续为股东、合作伙伴、员工和社会创造更大价值。
