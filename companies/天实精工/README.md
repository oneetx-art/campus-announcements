## 公司
性质:民企 · 行业:机械/制造业

重庆市天实精工科技有限公司成立于2015年12月，公司坐落于重庆市两江新区龙井大道。公司主要从事高端摄像头模组研发、生产及销售，拥有AF、OIS、TOF等多摄、PDAF、虹膜识别、高感度4.0um潜望长焦、T-LENS、3D、ISP大模块等功能摄像头产品研发制造能力。产品已应用于包括传音、OPPO、联想、TCL、中兴、海信、魅族等为代表的手机客户，以亚马逊为代表的物联网客户。公司先后被国家及地方政府认定为“国家级高新技术企业”、“国家级专精特新‘小巨人’”、“国家级绿色工厂”、“国家级智能制造优秀场景”“重庆市智能工厂”、“重庆市智能制造标杆企业”等荣誉称号。
