## 公司
性质:外企 · 行业:能源/化工/环保

林德（Linde）是全球领先的工业气体和工程公司之一，林德所触及的终端市场涵盖众多行业，包括航空航天、化工、食品与饮料、电子、能源、医疗健康、制造业以及初级金属等。林德工程总部位于德国慕尼黑，其亚太区总部位于中国。1913年向中国提供首套空分装置以来，林德工程已向多个行业的客户提供了200多套空分、制氢和天然气液化等工业气体装置。
