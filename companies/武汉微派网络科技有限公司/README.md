## 公司
性质:民企 · 行业:IT/互联网/游戏

武汉微派网络科技有限公司（简称“微派网络”）创立于2013年8月，公司以“创造简单的快乐”为使命，致力于移动互联网文化创意产品的研发和运营。微派网络聚焦移动互联网休闲游戏和社交产品领域，自主研发了《贪吃蛇大作战》《会玩》《坦克无敌》《青藤之恋》《微派桌游助手》等系列精品，总用户量突破8亿。近年来，微派网络积极开拓国际市场，以精品内容助推文化出海，于2019-2020年度、2021-2022年度、2023-2024年度，连续3次入选国家文化出口重点企业。未来，微派网络将持续在文化创意领域深耕，创造亿万人互连的文创乐园！
