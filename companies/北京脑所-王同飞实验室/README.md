## 公司
性质:央国企 · 行业:教育/培训/科研

北京脑科学与类脑研究所CIBR是北京市政府与中国科学院、北京大学、清华大学等多所单位共建的新型研发机构，瞄准世界脑科学前沿，整合脑科学领域资源，搭建研究平台，产出重大原始创新成果，重点聚焦脑认知原理解析、脑重大疾病、神经科学新技术、神经工程四大研究方向，2024年6月12日正式挂牌。王同飞实验室致力于探索能量代谢的神经调节机制，聚焦小鼠下丘脑神经网络的结构与功能，重点关注体温调节与其他代谢相关生理活动的互作，长远目标是深入理解哺乳动物冬眠现象及其潜在临床应用，研究手段丰富多样，开展多学科交叉研究。
