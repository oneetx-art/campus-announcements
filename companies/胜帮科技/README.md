## 公司
性质:央国企 · 行业:房地产业/建筑业

胜帮科技股份有限公司隶属于世界500强陕西煤业化工集团（位列《财富》世界500强榜单第178位），总部位于上海浦东张江高科技园区，下设陕西公司及5家子公司，是一家集技术研发、工程咨询、工程设计、采购施工、项目管理、开车指导、运行维护、投资、贸易、信息科技等多功能于一体的现代科技型企业。截止2025年9月30日，胜帮科技在煤化工、石油化工、精细化工、炼油、节能环保等领域已取得多项工业化技术开发成果，自主开发并拥有92项专利，其中发明专利35项，在粉煤热解、煤焦油加氢、荒煤气制LNG联产合成氨工艺、胜帮油页岩干馏技术、悬浮床加氢技术、催化裂化、煤炭分质利用制芳烃等众多细分领域处于国内领先水平；建成运行装置100余套，其中凭借自主创新的全球首套榆林化学120万吨粉煤热解装置，荣获中国煤炭工业协会“科学技术奖特等奖”，全球首套荒煤气制LNG联产合成氨装置试车一次成功。
