## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

人民交通出版社成立于1952年，是交通运输部所属出版单位，是新中国成立后最早创办的中央级出版社之一，是国家一级出版社、全国百佳图书出版单位、交通运输科普教育基地、出版融合发展示范单位。
