## 公司
性质:社会组织 · 行业:政府/机构/组织

广东省学生体育艺术联合会（简称“省学体艺联”）是经广东省民政厅批准成立的省级社会团体，自2003年成立以来，在广东省教育厅指导下，开展全省性大中小学校体育类和艺术类各项活动，助力广东省学校体育和美育事业发展。
