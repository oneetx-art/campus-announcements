## 公司
性质:央国企 · 行业:能源/化工/环保

四川省自然资源投资集团是经四川省人民政府批准设立的省属功能型I型国有企业，注册资本金150亿元，员工1.1万人，资产总额402亿元。自然资源厅将省级政府授权履行出资人职责。集团以服务自然资源、建设资源强省为重大使命，肩负全省科技战略性矿产资源开发管理及自然资源领域国有资本投资主体职责，以矿产资源勘查开发为核心主业，以土地整治、生态修复与防灾防治、自然资源行业支柱，协同推动工程勘察设计等“一业多元”发展，打造全省战略性矿产资源勘查开发“第一军团”、自然资源领域投资“第一尖兵”。
