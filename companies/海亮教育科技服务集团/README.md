## 公司
性质:民企 · 行业:教育/培训/科研

海亮集团于1989年在绍兴诸暨市成立，总部位于杭州滨江区。现有员工2.6万余名，产业布局13个国家和地区，营销网络辐射全球。管理总部1个、海亮集团是世界500强企业，连续21年上榜中国企业500强、中国民营企业500强第25位，浙江民营企业第6位。海亮教育科技服务集团隶属于世界500强企业海亮集团，创立于1995年，是学校教育与科技服务双轮驱动的领军企业。旗下拥有“海亮教育”“海亮科服”双核心品牌，聚焦“将乡村教育振兴作为永久的战略大科、构建教育生态圈、建设卓越教育高地”三大战略，以等科技和服务推动大规模高质量的因材施教，让每个生命出彩。
