## 公司
性质:央国企 · 行业:机械/制造业

中国船舶集团有限公司（以下简称中船集团）是中央直接管理的特大型国有重要骨干企业，是我国船舶工业发展的国家队、主力军。中船集团有着深厚的历史底蕴，旗下拥有在不同的历史时期，中船集团始终坚决贯彻党中央、国务院决策部署，自力更生、艰苦奋斗，推动我国船舶工业实现了跨越式发展。中船集团科研规模超亿位元，员工总数近20万人，拥有科研院所、上市公司和上市子公司等二级管理单位共84家。中船集团是我国海军武器装备科研、设计、生产、试验、保障的主体力量，拥有我国最强大的船舶设计建造能力，能够设计建造符合世界上任何一家船级社规范、满足国际通用技术标准和安全公约的要求、适航于全球任意航线的船舶。中船集团还不断发展贸易、投资与金融、服务等船海服务业，加速建设产业结构合理、质量效益领先、军工核心突出、国际竞争力强的世界一流船舶集团。
