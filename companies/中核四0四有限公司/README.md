## 公司
性质:央国企 · 行业:能源/化工/环保

中核四0四有限公司是中国核工业集团有限公司的直属单位，是我国核工业的摇篮，是我国核技术发展的开拓者和奠基者。公司拥有完善的配套生活基地，位于甘肃省嘉峪关市，交通便利，环境优美，医疗教育资源丰富，是一座宜居宜业的城市。公司拥有3个国家级研发平台，10个省部级研发平台，6个集团级研发平台，3个国家级大师工作室，11个校级创新工作室，2个校企联合研发平台，具有雄厚的科技研发实力。
