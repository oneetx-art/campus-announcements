## 公司
性质:央国企 · 行业:机械/制造业

公司前身东风电机厂，是国家于1965年建设的三线绝密级军工企业，为我国国防工业发展做出了重大贡献。上世纪八十年代实施“军转民”，2001年改制为有限公司，系我国中小发电设备及电机制造行业国有大型骨干企业。2025年，企业整合为乐山高新投资发展（集团）有限公司控股、东方富兴资产管理有限公司和中国东方电气集团有限公司参股的全资国有企业。公司产品覆盖水力发电、火力发电、风力发电、高效电机、驱动电机、军工产品等六大产业板块，拥有机电产品自营进出口权，产品先后出口日本、欧美、非洲、东南亚等30多个国家和地区。公司位于历史文化名城乐山市，毗邻举世闻名的世界自然与文化遗产乐山大佛、峨眉山。
