## 公司
性质:央国企 · 行业:能源/化工/环保

中国盐湖工业集团有限公司（以下简称“中国盐湖”）成立于2024年10月，是中国五矿集团有限公司为深入贯彻习近平总书记关于“加快建设世界级盐湖产业基地”重要指示精神，胸怀大局、勇担使命，秉持央地协同、合作共赢原则，联合青海省委省政府共同发起设立。新组建的中国盐湖以国家粮食安全压舱石、新能源产业稳定器和高端轻金属材料生力军为定位，是由青海盐湖工业股份有限公司（股票代码：000792）、青海汇信资产管理有限责任公司和五矿盐湖有限公司三家企业整合组建的大型国有企业，现有钾肥产能530万吨/年，占国内市场约35%，产能规模位列全球第四，是国家粮食安全的重要保障；碳酸锂产能5.8万吨/年，占国内总供给约8%，卤水资源提锂产能居全国第一；纯碱、烧碱、PVC等百万吨级产能，单项产品规模均居世界前列，并布局基础材料、稀缺元素提取等高端领域。
