## 公司
性质:央国企 · 行业:房地产业/建筑业

北京保障房中心有限公司于2011年6月成立，主要负责北京市保障性住房投资建设与运营管理，涵盖投资融资、建设创新、租赁型住房运营、产权型住房交易、商业资产经营、住房金融服务等六大业务板块。作为北京市属住房保障平台企业，是全市规模最大的租赁住房专业机构，在保障群众住房需求、助力首都高质量发展中发挥着重要作用，在全国同行业中处于领先地位。
