## 公司
性质:央国企 · 行业:交通/物流/仓储

辽宁省机场管理集团有限公司（以下简称“机场集团”）是省重点功能保障类企业，负责机场组的国有资产、运营和管理，为客、货航空运输提供服务保障，下辖沈阳、“丹东五”为，机场集团坚持以做强做优，下锚沈阳、丹东、锦州、朝阳、鞍山等“一干+四支”5大国有资本和国有企业，加快集团机场建设为目标，公司有“十四五”以来，机场集团坚持以做强做优，持续推进“四型机场”建设，全面助力辽宁振兴发展。截至2025年10月，机场集团完成运输吞吐量17.9万吨、旅客吞吐量2175.8万人次、货邮吞吐量14.3万吨，其中，沈阳机场完成运输起降13.9万架次、旅客吞吐量2126.1万人次、货邮吞吐量17.9万吨，三项运输指标排名均为东北第一。
