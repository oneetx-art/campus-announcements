## 公司
性质:事业单位 · 行业:政府/机构/组织

内蒙古能源研究院成立于2024年6月，是内蒙古自治区人民政府直属事业单位，肩负着推动能源领域科技创新的重要使命，是立足内蒙古、面向全国的新型科研机构。研究院聚焦新型电力系统构建，汇聚内蒙古得天独厚的资源禀赋和多元的创新生态，开展战略性、前瞻性和集成性、构建开放协同的创新生态，开展战略性、前瞻性和集成性、科技攻关与实证验证，加速关键技术突破和重大科研成果转化应用。核心任务体系包括：承接国家级重大能源项目的关键技术研发、核心装备的实验验证与示范应用；促进具有重大产业影响力的国家级科技成果在内蒙古率先落地、转化、规模化推广；系统构建以国家战略需求为导向、以基地为核心载体、紧密对接地方产业实际需求的能源科技创新体系。
