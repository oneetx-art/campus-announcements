## 公司
性质:民企 · 行业:能源/化工/环保

天元航材始于1971，现布局多区域核心基地：总部运营中心与产品测评中心位于武汉东西湖区理想科学城，总部创新中心位于深圳，研究院设立于杭州（中试基地）及生产工厂，在营口建有省级成果转化中心（中试基地）及生产工厂，在宜昌亦设有生产基地。作为国家级专精特新“小巨人”企业，公司专注于精细化工、液体橡胶、氮化硼等高端新材料的研发、成果转化（中试）、生产及应用服务。公司产品广泛应用于航天、航空、高铁、船舶、汽车、新能源、电子、陶瓷及精加工等领域。2027年，公司最后一轮融资估值超40亿元，计划于2027年完成深交所上市申报。因业务高速发展需要，现广纳英才，诚邀您加入天元航材，与我们携手共进，共创世界一流新材料企业的未来！
