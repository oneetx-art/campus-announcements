## 公司
性质:其他 · 行业:金融业

潮州农商银行于2019年6月29日挂牌开业，前身是始建于1952年的原潮州三家农信社。按照广东省委省政府部署，实施省联社对广州农商银行作为战略投资者实施“主发起行”制农村商业银行改革，成为潮州最大的地方性法人银行。截至2024年末，全行员工1400多名，下辖39个营业网点，实现全市51镇（街道）金融服务全覆盖。全行资产总额511亿元，存款余额422亿元，贷款余额201亿元，存贷款规模、网点数量均稳居全市金融机构前列。
