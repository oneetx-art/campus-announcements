## 公司
性质:民企 · 行业:机械/制造业

北京启望精密光学科技有限公司为面向我国高端制造业战略发展需求设立的市场化高端精密光学企业。公司秉承“助力开拓，仪器装备”的企业文化精神，致力于解决我国在高端光学系统、仪器装备等领域面临的卡脖子问题，助力实现我国半导体产业高端制造业的自主可控升级。公司坚定践行超精密光学技术产业化的历史使命，积极创建面向产业时代发展需求的超精密光学产业化研发与生产管理体系。公司拥有集建模仿真、协同设计、精密制造、精密检测、集成装配、系统测试等于一体的全研发、生产链条，可为各类客户提供具有高市场价值的定制产品与技术服务。公司目前主营业务包括以下两大板块：(1)以半导体晶圆/场晶圆缺陷检测装备镜头、大口径超高精度干涉检测标准镜头为代表的高端镜头业务；(2)以高精度光学元件干涉检测工作站、高精度集成装配心装备为代表的高端光学元件装备业务。启望精密目前拥有员工150余名，其中研发人员占员工总数的70%，多为来自于985院校的优秀硕士/博士毕业生。公司的注册地为北京市经济技术开发区，公司注册资本金为2.6亿元。
