中国科学院赣江创新研究院由中国科学院与江西省人民政府共同出资创建，2020年7月经中央编办批准成立，是江西省第一个中国科学院直属科研机构。面向关键金属资源领域国家和产业发展重大需求，开展定向性基础研究、应用基础研究与关键技术攻关，构建全链条创新体系，已成立多个研究单元，正筹建全国重点实验室，汇聚科技人才300余人，在读研究生600余名，发挥国立科研机构的骨干与引领作用。
