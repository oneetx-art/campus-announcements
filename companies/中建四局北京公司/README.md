## 公司
性质:央国企 · 行业:房地产业/建筑业

中建四局北京公司（北方分局）于2020年7月28日正式揭牌，是具备电力施工总承包壹级等六项资质，代表世界500强企业中国建筑股份有限公司主力进军北京建筑市场的重要战略支撑。总部位于北京市丰台区，直属4家生产型分公司和2家多元化单位（产业融合事业部和山东经理部）。在北京市海淀区和雄安新区均设有法人公司，逐步形成了以雄安为核心，以山东、天津、河北、山西、东北三省为重点的区域布局，经营范围涵盖传统房建、基础设施、仓储物流、城市综合体、水利水电、固废处理、水污染治理、乡村振兴和新能源业务等多个领域。
