## 公司
性质:央国企 · 行业:教育/培训/科研

中国船舶集团第七〇八研究所始建于1950年11月，是军工央企中国船舶集团有限公司下属骨干研究所，集总含波稳性、单体船体验、节/自航模、船舶阻力、耐波性、操纵性等研究，是我国舰船研究设计的“摇篮”。
