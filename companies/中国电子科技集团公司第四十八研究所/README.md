## 公司
性质:央国企 · 行业:通信/电子/半导体

中国电子科技集团公司第四十八研究所（以下简称48所），又名“长沙半导体工艺设备研究所”，始建于1964年，是国家南方半导体工艺设备研发中心、科研机构，隶属于中国电子科技集团有限公司，中央编制员额事业单位（独立公司），拥有多项国家级、省部级科研创新平台，设有博士后科研工作站、硕士培养点、卓越工程师培训点。
