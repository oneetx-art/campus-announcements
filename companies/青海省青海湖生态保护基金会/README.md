## 公司
性质:社会组织 · 行业:政府/机构/组织

青海省青海湖生态保护基金会成立于2023年12月，是在青海省民政厅登记注册的一家省级慈善组织，业务主管单位是青海省青海湖景区保护利用管理局，基金会以“建设个生态友好的和美社会”为愿景，以“协同创新推动生态理，探索可持续发展的绿色未来”为使命。基金会以“开展态保护、推动公益创新、实践社会责任、助力行业发展”为核心业务，基金会坚持“严谨高效、责任担当、持续创新、透明公开、迈向卓越”价值理念，助力打造生态文明高地，促进人与自然和谐共生。
