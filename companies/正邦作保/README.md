## 公司
性质:民企 · 行业:农林牧渔

江西正邦作物保护股份有限公司成立于1997年，在发展中始终秉承“以人为本，以正兴邦”的理念，经过二十余载奋进，成长为集科研创新、原药制剂生产和业务国际化于一体，年产值20亿元的国家农药定点生产企业。截止2025年，正邦作保农药制剂产品和农业服务方案广泛应用于全国水稻、柑橘、北方果树、瓜菜等多种作物。并在缅甸、孟加拉、巴基斯坦、老挝等国家分别设立全资子公司及现代化生产基地。正邦作保拥有5家国家农药定点生产企业；拥有农药登记证873个。公司生产线自动化设备不断升级改造，建立二维码可追溯体系，致力于提升产品质量和生产效率。正邦作保研究所先后成为江西省“农药工程技术研究中心”，“省级企业技术中心”，拥有68项发明专利。依托强大的研发力量，正邦作物保护股份有限公司多次被认定为“高新技术企业”，被评为“中国农民最喜爱的农药品牌”和“十佳农药品牌”，并荣获“2024全国农药行业制剂销售TOP100”排行第四的佳绩。
