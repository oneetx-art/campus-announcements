## 公司
性质:央国企 · 行业:商务服务业

广州市文化金融服务中心有限公司成立于2017年11月，由广东广州日报传媒股份有限公司、广东省绿色投资运营有限公司等国企共同发起设立，是广州市人民政府批准设立的全市唯一一家综合性专业文化金融服务机构，是由文化和旅游部、商务部共同命名的国家对外文化贸易基地（广州）的运营主体，也是广州市文化产业重点实施项目及市文化产业重点投融资平台。
