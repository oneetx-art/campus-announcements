## 公司
性质:央国企 · 行业:机械/制造业

山东电工电气集团科学技术研究有限公司（以下简称“研究院”）是山东电工电气集团有限公司全资子公司，是集团电工装备高端研发、科研成果转化与工程应用的研发创新核心平台，为集团公司科技创新提供工作支撑。2022年2月注册成立运行。研究院总部设在济南，陕西西安设有博士后工作站和研发基地，聚焦输配电与储能系统、智能电网、电缆装备等主研方向，研究输变电高端装备与重大科学问题，围绕产品共性关键技术、前沿技术、基础支撑技术、新型关键技术等，开展“卡脖子”技术攻关、新产品与产业化应用、技术与产品标准制定等。
