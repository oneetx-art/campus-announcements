## 公司
性质:民企 · 行业:IT/互联网/游戏

北京红松在线科技有限公司成立于2020年，专注于服务退休人群，致力于创造美好退休生活。目前，红松业务已覆盖红松APP、银发兴趣学习、银发文旅、银发消费品等领域。丰富的科技互动、多样化适老化的产品与服务，旨在解决退休人群的孤独和价值感缺失等问题，让退休生活更丰富、更美好。红松始终坚持“永远只做正确的事”的价值观，以成为全球领先的银发文娱科技平台为愿景，持续拓展服务内容，提升产品体验，不断探索面向未来的银发生活新模式。红松总部及研发中心设于北京，并于重庆、成都、武汉、杭州、深圳设立分公司；目前用户超千万，遍布全球30多个国家和地区。
