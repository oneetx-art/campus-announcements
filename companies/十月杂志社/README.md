## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

《十月》创刊于1978年，是我国改革开放以来创办的首大型文学期刊，以刊登中篇小说为主，兼顾其他文学体裁作品。2004年起从双月刊改为月刊，每年增加6期《十月·长篇小说》，专门刊发国内优秀原创长篇小说。《十月》发行量和影响力一直位居国内文学期刊前列，曾连续获得第一、二、三届国家期刊奖和首届中国出版政府奖，并入选“新中国60年有影响力的期刊”等。
