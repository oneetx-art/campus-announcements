## 公司
性质:央国企 · 行业:能源/化工/环保

江西省天然气集团有限公司是江西省投资集团有限公司全资子公司，2011年10月注册成立，资产总额超135亿元，是江西省省级天然气管网建设、运营、输气和储备保障的唯一主体，业务覆盖江西省，涵盖省级管网运营、城镇燃气、天然气勘探开发、省级LNG储备调峰、工业园区供气、LNG车船利用、油气技术服务等领域，目前承担着全省天然气保供任务，是江西省天然气能源供应保障的骨干企业，公司坚持上中下游产业一体化发展战略，聚焦科技创新、综合能源、数字化等领域，积极引领绿色低碳能源发展和清洁能源供应，致力建设成为智慧能源综合服务商
