## 公司
性质:民企 · 行业:能源/化工/环保

恒逸集团始创于1974年，总部位于杭州，历经50年发展，现已成为以石油化工、纺织原材料生产为核心，覆盖金融、贸易、物流等领域的国际化的世界500强企业。企业形成了富有竞争力的涤纶“锦纶+”驱动模式和“油丝纺”产业结构，产业遍及“三国九省”。恒逸—文莱大摩拉岛（PMB）石油化工项目是国家“一带一路”重点项目。
