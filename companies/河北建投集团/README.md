## 公司
性质:央国企 · 行业:能源/化工/环保

河北建投投资集团有限责任公司，前身为河北省建设投资公司，成立于1988年8月。2009年，是河北省政府批准，改制为国有独资有限责任公司，是河北省国资委履行监管职责的国有资本运营机构和投资主体。控股河北建投能源（000600.SZ）和新天绿色能源（600956.SH，00956.HK）两家上市公司，参股华能国际、大唐发电、唐山港、秦港股份等多家上市公司。
