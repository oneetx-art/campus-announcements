## 公司
性质:央国企 · 行业:能源/化工/环保

山高新能源集团有限公司(01250.HK)是山东省国资委所属山东高速集团和北京市国资委所属北控水务集团共同打造的国有控股、香港联合交易所主板上市企业。公司主营业务聚焦“双碳”赛道新能源发电和清洁供暖等业务，风力、光伏电站装机总量近5GW，年发电量超65亿度，年减碳排放量近512万吨。截至2025年6月，公司总资产规模超495亿人民币。
