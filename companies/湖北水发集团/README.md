## 公司
性质:央国企 · 行业:房地产业/建筑业

湖北水利发展集团有限公司（简称湖北水发集团）于2023年9月由省委、省政府正式批复组建，注册资本200亿元。湖北水发集团作为服务支撑湖北流域安全、供水安全、江河安澜的主平台，聚焦水资源能源保障、重大水利基础设施建设运营、水利技术研发应用、创新发展基础设施建设运营、水利基础设施应用设施建设、运营、管理主体职责，推进全省重大水利项目建设，保障防洪、抗旱、灌溉、水土保持、水安全等功能发挥作用。经营水资源市场，加大水网以品开发和产业链延伸，致力于打造全国一流的水资源开发运营商，水环境治理集成商，水利技术服务商。现有15家子公司。
