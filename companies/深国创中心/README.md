深圳国家高技术产业创新中心（深圳发展改革研究院）（以下简称中心）成立于1992年，前身为深圳市政府技术机构。2009年，在工信中心基础上组建国家高技术产业创新中心，为非营利性公共技术服务机构，企业化管理的事业单位，实行扁平化、矩阵式组织架构，共有12个业务研究所、2个中台能力支撑部、6个职能服务部，人员规模约300人，硕士及以上学历员工占比超80%。
