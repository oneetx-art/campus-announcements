## 公司
性质:民企 · 行业:房地产业/建筑业

新城市投资控股集团成立于1994年，是以股权投资和房地产开发为核心，拥有多家全资公司的集团企业。新城市集团三十多年来积极投身于城市的建设与发展，将“城市共生长”的企业理念与国家战略高度契合，是国务院“万里碧道”示范项目《万绿湖碧道》的独家建设单位。是广州市“三旧”改造标杆企业，是“城中村全面规划改造”的倡导者。
