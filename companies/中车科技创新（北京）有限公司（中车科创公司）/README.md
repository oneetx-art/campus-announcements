## 公司
性质:央国企 · 行业:通信/电子/半导体

中车科技创新（北京）有限公司是中国中车深入实施创新驱动发展人才强国战略，贯彻落实国家关于加快建设世界重要人才中心和创新高地战略部署，充分发挥中车技术优势、人才优势和品牌影响力，在北京海淀中关村科学城注册成立的一家科技创新型企业，主要从事技术研究、产品开发、试验检测、技术咨询及推广服务等。作为中国中车科技创新和品牌孵化平台，中车科创公司紧密围绕中国中车“双赛道双集群”产业发展新格局，聚焦轨道交通装备关键新兴产业前沿技术、关键核心技术研发，突出人才引领驱动，持续提升自主创新能力和核心竞争力，致力打造先进轨道交通装备原创技术策源地及现代产业链链长，助推中国中车高质量发展。
