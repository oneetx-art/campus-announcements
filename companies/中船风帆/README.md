## 公司
性质:央国企 · 行业:机械/制造业

风帆有限责任公司直属中国船舶集团有限公司，前身保定蓄电池厂始建于1958年，是国家“一五”期间156个重点建设项目之一。风帆整合推进“风帆”“火炬”双品牌战略，生产基地分布于保定、唐山、淄博和扬州，主营产品为起动用、牵引用、工业用铅酸蓄电池、特种材料制品以及消费型、动力型锂离子电池。风帆2GWh锂电池2500万只铅蓄电池PACK年生产能力，是国内各大汽车主机厂的常年合作伙伴，奔弛、宝马、奥迪国内主要供应商，汽车起动电池配套市场占有率25%以上，牵引用蓄电池市场占有率30%左右，产品出口30多个国家和地区。
