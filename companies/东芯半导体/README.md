## 公司
性质:民企 · 行业:通信/电子/半导体

东芯半导体股份有限公司成立于2014年，总部位于上海，是一家设计、销售、韩国拥有独立的知识产权，聚焦于中小容量NAND、NOR、DRAM芯片的研发、设计和销售，是目前国内少数可以同时提供NAND、NOR、DRAM设计工艺和产品方案的存储芯片研发设计公司。
