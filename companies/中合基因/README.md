## 公司
性质:民企 · 行业:医疗/医药/生物

中合基因科技有限公司于2022年成立于中国天津，是一家以酶促DNA生物合成技术为核心，主要从事DNA生产与销售的高新技术企业，核 心产品广泛应用于合成生物学领域。公司设立天津研发基地、常州生产基地，团队硕博占比超40%；已成功研发并上市TIESyno™-96 DNA生物合成仪、基因拼接仪、Auto Sp-1500基因拼接仪等产品，拥有超30项核心知识产权；与多家高校和科研院所以及企业建立战略合作；成功获评国家高新技术企业，天津市专精特新小企 业、雏鹰企业、瞪羚企业、天津市科技型、创新型中小企业；积极参与领域内创新创业赛事，先后荣获合成生物学竞赛“SYNBIO FUTURE”金奖、“第十一届中国创业赛优秀企业奖”，金桥奖项目二等奖，中国发明博览会金奖等众多荣誉；已完成天使轮及Pre-A轮融资，累计获得近亿元投资。
