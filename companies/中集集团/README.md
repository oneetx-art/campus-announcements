## 公司
性质:央国企 · 行业:交通/物流/仓储

中集集团于1982年9月22日正式投产，是世界领先的物流装备和能源装备供应商。1994年公司在深圳证券交易所上市，2012年12月在香港联交所上市，目前是A+、H股双公上市企业。中集在亚洲、北美、欧洲、澳洲等地区拥有300+成员企业及4个国家和地区客户箱销售网络分布在全球100多个国家和地区，研发中心及制造基地分布在全球近20个国家和地区。海外实体企业超过30家，2024年，中集集团的集装箱业务创造了约1776亿元的销售收入，员工数量约2万+，优秀的中集员工
