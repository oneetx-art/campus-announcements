## 公司
性质:央国企 · 行业:能源/化工/环保

华电广西能源有限公司成立于2008年1月，原为中国华电集团广西分公司，2014年4月改制为子公司，2024年9月，中国华电集团有限公司在广西揭牌成立中国华电总部，与中国华电广西有限公司合署办公，成为总部。公司主要是广西区域中国华电集团的开发、投资、建设和运营，“四个平台”定位，充分发挥资金、技术、人才、管理等方面优势，深化东盟国家在能源领域合作，带动华北北海水产和东盟国家能源电力装备、技术、人才“走出去”，为推进高质量共建“一带一路”，构建更为紧密的中国-东盟命运共同体贡献华电力量。
