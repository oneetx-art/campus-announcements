## 公司
性质:央国企 · 行业:通信/电子/半导体

中电科东方通信集团有限公司（简称“电科东信”），成立于1958年，为中国电子科技集团有限公司旗下的二级成员单位，旗下共24家控股子公司，控股2家上市公司（东方通信、东信和平）。电科东信是工信部首批认定的智能制造试点示范企业之一，产业分布于长三角、京津冀、粤港澳大湾区，并在“一带一路”沿线国家和地区建立了产业基地；拥有国家级企业技术中心、国家地方联合工程研究中心、企业博士后科研工作站等科技创新平台，与国际接轨的现代化科技产业基地6个。公司以信息通信、智能科技、数字安全为核心，以智能制造和资产经营为支撑，为政府及公共安全、垂直行业、金融、交通、能源、军队等关键部门和垂直行业提供安全的数字化、网络化、智能化产品、解决方案及服务。
