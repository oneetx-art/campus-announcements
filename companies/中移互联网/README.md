## 公司
性质:央国企 · 行业:IT/互联网/游戏

中移互联网有限公司是中国移动面向互联网领域设立的子公司，前身是2012年移动互联网基地，2015年10月30日在广州注册成立，是中国移动“三转”（网随人动-“网改数”-科改）企业。公司聚焦“信息+互联网”，胸怀国之大者，勇当信息服务科技创新公司排头兵，成为移动互联网产品创新主力军，利用中国移动的规模、能力、体系优势，与中国移动的智能“9+9”数据融合界面、面向算网、大数据、人工智能等新型信息基础设施，布局5G消息、超级SIM、移动认证、移动云、物联网、科创基金、超算、大AI应用基座、下沉场景、生态拓展，拓展信息服务新空间，激发CHN价值增长新动能，为两个“做强做优做大”贡献更大力量。
