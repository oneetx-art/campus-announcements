## 公司
性质:民企 · 行业:医疗/医药/生物

大连医诺生物股份有限公司（INNOBIO）成立于2003年，自创立以来始终秉承“集天然精华·造绿色健康”的使命，专注于类胡萝卜素、氨基酸、营养酶解、维生素等功能性营养素的研发与生产。公司依托微囊技术和生物合成技术，为全球60多个国家和地区的客户提供包括眼健康、运动营养、基础营养、婴幼儿配方及动物营养等领域的综合解决方案。公司总部设于大连，并在美国、荷兰、上海、黑龙江等地设有子公司。此外，公司在大连和佳木斯建有现代化生产基地，构建起“研发-生产-服务”一体化的全球供应链体系，为持续服务全球客户奠定坚实基础。
