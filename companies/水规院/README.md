## 公司
性质:央国企 · 行业:房地产业/建筑业

中交水运规划设计院有限公司（原交通部水运规划设计院，简称“水规院”）成立于1951年，是新中国设立的第一家水运勘察、规划与设计机构。现隶属于世界500强企业中国交通建设股份有限公司。水规院现有工程行业甲级资信、工程设计综合甲级、工程勘察综合甲级、工程咨询综合甲级资信和城乡规划甲级等“综甲一甲”资质以及港口航道工程施工总承包壹级等40多项资质，设计了新中国第一座海港、第一座内河港、第一座船厂、第一座大型海船闸，以及多个中国与江河的一万吨级海港枢纽及80多个国家主港，为国内外客户提供了万余项交通及城市建设工程的规划、设计、管理和总承包成果。
