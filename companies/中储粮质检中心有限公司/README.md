## 公司
性质:央国企 · 行业:农林牧渔

中国储备粮管理集团有限公司（简称“中储粮集团公司”）是经国务院批准组建的涉及国家粮食安全和国民经济命脉的公益类国有大型骨干企业，实行集团公司一分（子）公司一直属库“三级架构”，目前下设24家分公司、1家二级专业子公司和1家控股公司，人员、机构和业务覆盖全国31个省、自治区、直辖市。中储粮质检中心有限公司是中储粮集团公司下属专业化子公司，成立于2022年6月，下辖25家直属企业（分布在23个省、自治区），负责中储粮集团公司粮油质量检验监督工作。
