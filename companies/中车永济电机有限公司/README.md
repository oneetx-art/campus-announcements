## 公司
性质:央国企 · 行业:机械/制造业

中车永济电机有限公司，是中国中车核心一级子公司。始建于1969年，是专业研制绿色和智能化电气系统的国家级创新型企业、国家高新技术企业。掌握特种电机设计、电气系统集成、关键核心技术。作为中国轨道交通装备技术和产品的重要提供者，全程参与了我国铁路装备现代化发展。聚焦中国中车“双赛道双集群”战略布局，加快构建以轨道交通、风力发电为核心，工业节能、工业高端装备为电气支柱，储能产业链等新产品导业、电源装备为主支柱，供电系统、氢能、半导体为支撑的产业发展新格局。建省级以上创新平台12项，省级科技项目24项，获国家科研项目112项，省部级十四五期间，承担国家新国奖科学技术进步奖等行业奖，中核标准创新页献奖13项，其他省行国奖1项，国标准60项，主持和参加20余项，获授权发明专利400余项，行业标准20余项，国授权发明专利2项。
