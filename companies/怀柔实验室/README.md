## 公司
性质:事业单位 · 行业:政府/机构/组织

怀柔实验室是国家级新型科研事业单位，面向清洁低碳高效新型能源体系构建和'碳达峰、碳中和'战略目标，开展战略性、前瞻性、基础性科学技术研究，创新目标导向、开放协同的新型科研机制，汇聚海内外优秀人才，加速关键技术创新突破和重大科研成果转化应用。实验室在北京设置智慧能源中心、新型电力系统中心、可再生能源中心、清洁能源中心、基础前沿研究、战略研究中心，同时，在山西、新疆设有研究基地，组建了能源领域国家实验室体系创新联盟，与40余家能源领军企业、高水平研究型大学建立了战略合作，汇聚了1700余人的科研人才队伍。
