## 公司
性质:央国企 · 行业:医疗/医药/生物

北大医疗管理有限责任公司（以下简称北大医疗），成立于2005年，是中国平安医疗生态的重要成员公司。依托北京大学医学部完善的医教研体系、专家资源和学科优势，以及平安集团综合金融及医疗科技，北大医疗已经建成以北大国际医院为旗舰，覆盖“医疗+科技+健康”全生命周期的健康医疗服务网络。北大医疗致力于打造有平安特色的、中国领先的核心业务格，作为平安“综合金融+医疗养老”战略中医疗板块管理集团。
