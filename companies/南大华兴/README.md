## 公司
性质:民企 · 行业:能源/化工/环保

江苏南大华兴环保科技股份公司是一家专业从事工业污染控制新技术研发与应用的高新技术企业。公司成立于2016年，国家工程中心主任、俄罗斯工程院院士、南京大学环境学院李爱民教授为公司首席科学家。公司具有较为完善的科技创新与产业发展生态，拥有南京大学盐城环保产业创新基地和研究生协同培养基地、江苏省产业技术研究院水环境工程技术研究所（加盟所）、中国石化联合会精细化工废水处理工程技术中心、张全兴院士工作站等平台，获批国家专精特新“小巨人”、国家知识产权优势企业、省瞪羚企业、省五一劳动奖状等称号，获得国家授权专利130余项（其中发明专利80余项）。公司全职环保技术人才260余人，可为社会企业、工业园区、地方政府提供研发、咨询（规划、环评、验收）、司法鉴定（检测与评估）、设计（EPC+）、托管（运营）一站式全链条的生态环境综合服务。
