## 公司
性质:央国企 · 行业:房地产业/建筑业

中国葛洲坝集团第二工程有限公司（简称葛洲坝二公司）创建于1970年，隶属国务院国资委监督管理的大型央企、世界500强——中国能建集团的骨干子企业，其隶属的中国葛洲坝集团股份有限公司核心骨干企业，是国家高新技术企业、全国守合同重信用企业。多年来，公司在水电水利、综合交通、建筑工程、环境治理、新能源等领域积累了丰富的业绩，近年来还投资建设了贵州的黔精高速、六盘水机场高速公路、海南洋浦国际航运大厦等一批项目。
