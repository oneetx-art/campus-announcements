## 公司
性质:事业单位 · 行业:教育/培训/科研

北京航天试验技术研究所隶属于中国航天科技集团第六研究院，始建于1958年4月10日，是我国功能齐全、技术先进的多型号动力系统综合试验基地，同时也是我国唯一的液体推进剂研究中心，承担研制和生产了国内大部分运载火箭、卫星飞船等航天器上使用的常规及低温液体推进剂产品。依托试验与测试、推进剂研发的核心技术，研究所形成了以氢能领域、功能材料、特种装备与系统工程三个业务板块为代表的航天技术应用产业，主要涉及氨液化、加氢站、车载供气系统、氢能装备检测与安全、改性材料、安防环保设备、烟草机械等。许多产品在业内拥有着良好的口碑和市场，一些产品走出国门，远销海外。氢能综合利用居国内领先水平，成功研制我国首套氢液化系统设备，致力于创建全球知名能源装备供应与服务商。
