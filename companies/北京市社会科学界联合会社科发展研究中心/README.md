## 公司
性质:事业单位 · 行业:政府/机构/组织

北京市社会科学界联合会社科发展研究中心（以下简称社科发展研究中心）是北京市社会科学界联合会（以下简称市社科联）所属公益一类事业单位，主要职责是承办北京社科论坛研究、信息收集整理、相关刊物的组稿及发行等工作。其编辑出版的《中国特色社会主义研究》是马克思主义理论学科的期刊（双月刊，CN11-3527/D），入选全国中文核心期刊、中国人文社会科学核心期刊、中文社会科学引文索引（CSSCI）来源期刊、国家社科基金资助期刊。
