## 公司
性质:央国企 · 行业:机械/制造业

北方华安工业集团有限公司隶属于中国兵器工业集团有限公司，总部位于“世界大湿地、中国鹤家乡”一黑龙江省齐齐哈尔市，拥有南京、西安两个科技研发中心，是我国中大口径弹药科研与生产骨干企业、国家重点保军企业、高新技术企业。华安集团占地面积300余平方公里，建筑面积近60万平方米，具备科技研发、机械加工、表面处理、总装集成、试验测试等综合科研生产能力。华安集团坚持智能化弹药的发展方向，以满足我军远程压制、精确打击、高效毁伤对智能化与多功能弹药的需求为出发点，将企业打造成为以大口径炮弹与特种弹药为特色的重要的弹药研发生产基地。
