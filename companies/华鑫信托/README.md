## 公司
性质:央国企 · 行业:金融业

华鑫国际信托有限公司是由中国金融监督管理总局批准设立的金融机构，注册地为北京市西城区，注册资本金73.95亿元，隶属于国务院国资委监管的特大型中央企业-中国华电集团有限公司。2024年，华鑫信托各项经营指标均创历史新高，实现营业收入29亿元，创行业新标高，并且已连续五年实现增长，稳居行业第一梯队。成立十五年来，历经卓绝奋斗，始终保持稳健、高质量发展态势，资产管理信托、标品投资、普惠金融、资本市场、绿色金融、家族信托等众多业务长足发展，同时先后获批了特定目的受托受托机构、固有股权投后业务、受托境外理财业务（QDII）等资格，连续多年获得信托行业最高评级-A级信托公司。
