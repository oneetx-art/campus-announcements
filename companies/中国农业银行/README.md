## 公司
性质:央国企 · 行业:金融业

中国农业银行是服务乡村振兴的领军银行、服务实体经济的主力银行，坚守三农主责主业，全力服务国家战略。截至2025年6月底，有2.29万个营业机构，网点覆盖全国所有县域，有44.5万名员工，8.88亿个人客户，1299万对公客户。2014年起连续十一年入选全球系统重要性银行，连续四年在服务乡村振兴监管考评中荣获最高等级“优秀”，2022年荣膺全球“零售银行品牌价值排行榜”四连冠，被中央广播电视总台、中国企业改革与发展研究会授予“ESG榜样示范基地”称号。
