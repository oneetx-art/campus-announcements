## 公司
性质:民企 · 行业:政府/机构/组织

华威企业创办于1985年，1993年组建华威集团，现已发展成为一家以专业市场运营、学校教育、精密制造、汽车服务等产业为主的综合型产业投资集团，也是福州市政府认定的“综合型总部企业”。集团及下属企业陆续被授予“中国驰名商标”“全国五一劳动奖状”“国家高新技术企业”“国家专精特新‘小巨人’企业”“中国杰出创新企业”“中国道路运输领袖品牌”“全国诚信示范市场”等多项国家和省、市级荣誉。2025年1月24日，旗下华威农商集团作为原始权益人的“易方达华威市场REIT（证券代码：180605）”在深圳证券交易所成功上市，成为全国首单农贸市场公募REITs、福建省首单民营企业REITs。
