## 公司
性质:民企 · 行业:通信/电子/半导体

天孚通信（简称TFC）2005年成立，是业界领先的光器件整体解决方案提供商和光电先进封装制造服务商。2015年在中国创业板成功上市。公司的产品广泛应用于光纤通信、数据中心、光学传感等领域。公司在苏州和新加坡分别设立国内外总部，并在江西高安、泰国春武里府（曼谷附近）布局了量产基地，同时在苏州、日本、深圳等地设立研发中心。
