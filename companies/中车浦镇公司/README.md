## 公司
性质:央国企 · 行业:机械/制造业

中车南京浦镇车辆有限公司始建于1908年，坐落于国家级南京江北新区，为中国中车旗下一级企业，是轨道交通、铁路客车和城市轨道交通装备专业化研制企业，系统集成供应商及城市轨道交通整体解决方案提供者。现有厂区位于南京、杭州、芜湖、无锡、成都、唐山、马来西亚、土耳其等地，拥有子公司12个，市场遍布于香港、亚洲、美洲等21个国家和地区。
