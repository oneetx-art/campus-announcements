## 公司
性质:民企 · 行业:医疗/医药/生物

广州市华南农大生物药品有限公司成立于2004年，是一家从事预防、诊断、治疗用兽用生物制品的研发、生产、销售和技术服务的国家高新技术企业。2015年与中国A股市场一家专注于兽药领域的上市公司——瑞普生物股份有限公司（股票代码：300119）强强联手，成为其一家控股子公司。公司现拥有通过国家农业部GMP验收的胚毒灭活疫苗、禽流感受灭活疫苗及细胞毒灭活疫苗3条生产线，其中禽流感受灭活车间及细胞悬浮灭活车间均通过生物安全三级防护资质认证。公司坚持科技创新的发展宗旨，依托华南农业大学兽医学院，协同瑞普生物研究院，立足于高新生物技术，以发展国家兽用生物制品产业，维护国家防疫体系为己任，建立现代化企业制度，提升企业核心竞争力，努力成为我国兽用生物制品行业的先驱。
