## 公司
性质:央国企 · 行业:机械/制造业

厦门虹鹭钨钼工业有限公司是中国企业500强、上市国控高新技术企业集团厦门钨业的核心成员之一，是一家成立于1992年的国有控股企业。公司主要从事钨钼难熔金属的棒材、杆材、丝材、深加工制品的研发与生产，是国家高新技术企业，获福建省级龙头企业、厦门市首批“高技术、高成长、高附加值”企业称号；拥有国内钨钼加工行业首家博士后工作站，与中科院金属研究所联合成立了稀有金属加工实验室；多项产品荣获福建省制造业单项冠军产品荣誉称号，数十项技术获得福建省、厦门市科技进步奖。
