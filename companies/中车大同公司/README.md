## 公司
性质:民企 · 行业:机械/制造业

中车大同电力机车有限公司是新中国建设的第一座大型铁路机车企业，始创于1954年，70余年来，已累计造12000余台各型电力机车，产品遍布全球五大洲30多个国家和地区。公司是中国中车“一核三极多点”战略布局的重要一极，以“打造世界一流轨道交通装备产业集群”为目标，构建了“机车+城轨+工程”的产业发展格局，形成了“研发+制造+服务”的全产业链发展模式。
