## 公司
性质:民企 · 行业:新能源

深圳市崧盛电子股份有限公司，成立于2011年，是一家集中、大功率LED驱动电源的研发、生产、销售与服务为一体的国家高新技术企业。公司总部位于深圳，智能制造基地位于中山市（7万余平方米），在香港、欧洲、北美、东南亚设有子公司。公司持续研发高效能、稳定可靠的LED驱动电源产品及技术解决方案，同时大力拓展新能源行业，深研锂创兴科技有限公司专注储能逆变器的研发和制造，主要生产住宅和商业及工业应用级储能逆变器，以科技力量推动行业变革。
