## 公司
性质:央国企 · 行业:政府/机构/组织

天津宏达投资控股有限公司成立于2024年8月，注册资本金1亿元，是天津市国资委直接监管的一级国有企业。公司聚焦三大核心业务领域精准发力：赋能科技创新高地建设，深度参与和开展高校科创园的建设与发展，为天津市建设具有全国影响力的科技创新策源地提供坚实支撑；激活存量资产价值潜能，系统推进土地、房产等存量资源的优化配置与价值提升，通过专业化、市场化运作，将资源优势高效转化为企业发展动能与核心竞争力；持续提升资本运营能力与效能，紧密围绕公司战略规划与主责主业，积极探索以基金投资为引擎、优质项目为牵引、精细化区域管理为基石的国有资本运营新模式，有效服务区域经济高质量发展。
