## 公司
性质:民企 · 行业:机械/制造业

天海融合防务装备技术股份有限公司于2001年在深圳证券交易所创业板上市，是国内首家船舶科技类上市企业，上海市民营百强企业。天海防务现有主营业务涉及船舶与海洋工程、军民融合产业、清洁能源利用三大业务领域，着力打造“一总部三平台”的业务架构，充分发挥平台的协同作用，公司秉持“技术引领，军民融合，水陆并举，节能环保”的发展战略，坚持“以企立企、科技报国、以人为本、臻于至善”的愿景，致力创新发展，以诚信与实力，构建企业的发展之道。
