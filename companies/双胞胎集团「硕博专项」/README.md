## 公司
性质:民企 · 行业:农林牧渔

双胞胎集团成立于1998年，是一家专业从事生猪养殖、养猪服务、饲料制造、良种繁育、养猪培训、粮食收储与贸易为一体的全国性大型企业集团，集团下设分公司900余家，员工人数3万人。2024年集团饲料销量达1550万吨，猪饲料外销全球销量第一；生猪上市1778万头，营业收入1038.68亿元，是中国企业500强，农业产业化国家重点龙头企业。
