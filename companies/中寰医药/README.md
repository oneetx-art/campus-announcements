## 公司
性质:民企 · 行业:医疗/医药/生物

中寰医药是行业领先的全球一站式药品开发、分销管理服务企业，致力于“引进全球好药，服务健康中国”，为广大病患提供高品质的进口与自研药品。公司以商业模式与研发创新为驱动，总部位于福建省福州市，并依托南京药物研究院、北京、杭州、上海、苏州等合作机构打造了高效协同的药物开发与引进平台，公司目前产品涵盖肿瘤、中枢神经、消化、代谢、心脑血管、抗感染、免疫等领域，品种/品规合计60余个，大部分产品获得FDA、EMA与NMPA等多国批准，产品质量与品质受到国际与市场高度认可。公司拥有完整的药品全生命周期管理体系与服务，已建成符合GSP标准的药品仓储、运输供应链平台、面向临床机构、KA连锁与基层医疗机构的CSO营销服务平台等，公司产品及营销网络覆盖全国31个省、市、自治区。
