## 公司
性质:外企 · 行业:快速消费品

杭州久积控股有限公司是一家坐落于杭州高新区（滨江）内的日资企业，主营家居装饰用品与轻纺制品。久积已成功创立至今二十载有余，杭州久积1998年从传统的设计、生产与全球贸易为一体的策划、生产型企业转型升级为产品集品质快速消费品制造企业。公司目前拥有五大生产基地、多条流水线及专业设计团队。同时开设三大展厅以便更全面、更直观并细致地向海内外客户进行产品展示、宣传企业文化。
