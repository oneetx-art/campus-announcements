## 公司
性质:民企 · 行业:通信/电子/半导体

深圳市天龙世纪科技发展有限公司成立于2011年，是一家专业研发、生产三防手机、PDA扫描手持终端、宽窄带融合对讲、执法记录仪等智能通讯终端的国家高新技术企业、国家级科技型中小企业、专精特新企业。公司产品涵盖消费类和行业手持终端两大类，海外消费类三防手机覆盖欧洲、南北美洲的80多个国家和地区，行业通讯终端包括防爆智能终端、对讲机系列产品、执法记录仪系列产品、工业平板系列产品、PDA扫描与手持数据采集终端、北斗高精度定位导航终端、车机/农业通信控制终端。公司集主板研发、ID/MD设计、生产加工于一体，研发及生产场地6000平米，配置了先进的多功能实验室，承接各行业通信终端OEM/ODM定制。
