## 公司
性质:民企 · 行业:机械/制造业

TCL瑞智（惠州）制冷设备有限公司（以下简称“TCL瑞智”），成立于2001年1月17日。位于全国文明城市——广东省惠州市，地处国家级高新技术开发区——惠州仲恺高新技术产业开发区，由TCL集团和台湾瑞智精密股份有限公司共同投资成立，是“国家级高新技术企业”。公司总投资壹亿贰仟万美元，占地面积16万平方米，使用面积13万平方米，拥有厂房面积8万平方米。公司技术源承台湾瑞智总厂，生产设备主要引进德、日等地先进设备。公司拥有专业的研发工程中心和研发技术团队，并长期致力于新产品的研究与开发。
