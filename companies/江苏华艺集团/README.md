## 公司
性质:民企 · 行业:耐用消费品

江苏华艺集团始创于改革开放的1979年，是我国从事现代扎染文化创意、艺术染整集成创新与时尚纺织设计智造的集团公司，也是国家文化产业示范基地、纺织行业艺术染整与现代扎染协同创新中心、中国博士后科研工作站、江苏省首批省级非遗研工坊、江苏省“最美公共文化空间”和“南通扎染”非遗工坊、遗产传承基地。
