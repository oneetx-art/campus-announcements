## 公司
性质:央国企 · 行业:通信/电子/半导体

东方通信股份有限公司（简称“东方通信”）创立于1958年，是一家集硬件设备、软件、服务为一体的整体解决方案提供商。公司于1996年成功改制上市，成为上海证交所同时发行A股和B股的国有控股上市公司。
