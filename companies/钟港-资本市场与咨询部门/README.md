## 公司
性质:民企 · 行业:金融业

钟港资本有限公司（“钟港”）是一家根植香港、着眼于提供债券相关综合性服务的证监会持牌金融机构。三大主营业务包括：资本市场与咨询、全球市场、资产管理。钟港成立于2017年，由中国著名消费电子及半导体显示生产商TCL科技集团（000100.SH）建立，并联合一批来自国际资本市场投融资领域的资深专业人士共同创办。钟港是TCL科技集团中国A股上市公司的控股及并表企业。管理团队成员具有国际化多元化背景，过往曾经长期共同协作。
