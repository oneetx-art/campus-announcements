## 公司
性质:央国企 · 行业:机械/制造业

中国航空工业集团是由中央管理的国有特大型企业，经营范围涵盖航空武器装备、通用航空、机载系统、航空科研等产业，下辖100余家成员单位、25家上市公司，员工逾40万人。陕西宏远航空锻造有限责任公司成立于1965年，隶属于中国航空工业集团有限公司，是一家以航空锻造为核心业务的大型专业化企业。公司现有员工2000余人，其中专业技术人员400余人。历经六十年发展，宏远公司已成为我国航空、航天、兵器、机械、电力等重点行业的重要锻件供应商，为国家重大装备和国防建设做出了突出贡献。
