## 公司
性质:央国企 · 行业:能源/化工/环保

中铝宁夏能源集团有限公司成立于2003年6月，是中铝集团的能源企业，主营煤炭、火电、风电、光伏、新能源科技，是肩负着保障国家能源安全和协助中铝集团‘双碳’战略的重要骨干企业。注册全称中铝宁夏能源集团有限公司，简称中铝宁夏能源集团、中铝宁能。 公司拥有王洼煤矿600万吨/年、王洼二矿360万吨/年、银洞沟煤矿300万吨/年、银星煤矿400万吨/年，已建成矿井煤炭生产能力1660万吨/年，配套王家洼煤业1200万吨/年、银星煤业400万吨/年洗煤厂。建有王洼煤业公司至固原北站自备铁路，运力900万吨/年。目前正在积极获取新的煤炭资源。
