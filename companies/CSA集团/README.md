## 公司
性质:外企 · 行业:财务/审计/税务

CSA集团（Canadian Standard Association 加拿大标准协会）是一家致力于安全、社会公益和可持续发展的全球性组织。我们是全球标准制定、测试、检验和认证的领导者之一，业务范围包括加拿大、美国、欧洲和亚洲。我们的使命是以更高的标准把握未来。CSA集团在全球提供本地化的测试和认证服务，核心业务领域覆盖多种产品，包括危险场所和工业控制、建筑及卫浴、医疗安全和技术、家电及燃气用具、照明灯具、新能源及可持续发展，并提供消费品评估服务。目前，已有数以亿计的产品贴有CSA认证标志。
