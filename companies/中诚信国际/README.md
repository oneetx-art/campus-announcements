## 公司
性质:央国企 · 行业:金融业

中诚信国际始创于1992年10月，是经中国人民银行批准成立的中国第一家从事信用评级、金融证券咨询和信息服务的全国性非银行金融服务机构，是国内最具市场、技术领先优势的综合性信用评级机构，从事银行间债券市场、交易所市场、境外市场债券评级项目，以及可转换债、投资咨询、认证等服务业务。
