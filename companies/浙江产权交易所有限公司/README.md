## 公司
性质:央国企 · 行业:商务服务业

浙江产权交易所有限公司（以下简称“浙交所”）为浙江省国资委直属企业，成立于2003年12月。浙交所是国务院国资委选定的从事央企实物资产转让服务机构、财政部指定的中央、地方管理金融企业国有产权交易机构、浙江省国资委选定从事省属监管企业国有资产交易的服务机构、宁夏、青海等省级国资部门有确定的国有资产交易指定服务机构。浙交所坚持监管与创新并重，资产交易服务规范运作，是全国产权交易行业的骨干机构之一。
