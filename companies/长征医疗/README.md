## 公司
性质:央国企 · 行业:医疗/医药/生物

航天新长征医疗器械（北京）有限公司（简称“长征医疗”），是中国航天科技集团有限公司第一研究院第十八研究所全资子公司，由航天科技集团秉承“军民融合，央地协同，医工结合，校企合作”的方针而设立。为守护人民生命健康，走好国产自主可控的航天新长征路，公司以航天伺服技术为基础，坚持医工结合，聚焦高端医疗装备领域，致力于为医院重症监护、医院外急救等场景提供高端体外生命支持，顺利入选国务院国资委首批启航企业。目前，公司产品已在各医院多次开展院内转移、院间转运、跨省、跨国航空转运，顺利完成生命支持，设备的高可靠性、便携性和易用性的特点得到了临床医生的一致好评。未来，长征医疗将继续履行“航天科技服务健康中国”的使命，持续推进长征火箭相关先进技术向民用高端医疗领域转化，致力于成为国际一流的生命支持类高端医疗装备“产学研医”一体化高新技术企业，奋勇承担守护国家和人民生命安全的伟大重任，让敢于突破、敢于创新的航天基因在高端医疗领域持续涌动。
