## 公司
性质:民企 · 行业:通信/电子/半导体

杭州禾迈电力电子股份有限公司成立于2012年，是一家以技术创新为驱动力，专注于光伏和储能领域的高新技术企业。公司于2021年在上海证券交易所科创板上市（证券简称：禾迈股份，证券代码：688032）。作为全球领先的光储解决方案提供商，禾迈已构建覆盖DIY、户用、工商业及大型电站等多场景的全系列光储产品及智慧能源解决方案。
