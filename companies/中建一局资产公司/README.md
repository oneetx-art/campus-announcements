## 公司
性质:央国企 · 行业:商务服务业

中建一局集团资产运营管理有限公司(简称中建一局资产公司),成立于1953年,总部北京,致力于打造'中国建筑旗下最具价值创造力的资产运营品牌,公司注册资本1.88亿元。资产公司现有员工100余人,是中建系统更具增值服务力、更具专业化优势、更具行业认可度的资产运营专业公司,具有资产管理、影视制作、设计、会议服务、铁路物流、仓储材料设备进出口贸易、物业管理等运营资质,具备中建一局非生产类资产的成功管理经验和成熟运营团队。公司以资产运营管理、CI传媒、城市更新为主营业务,为一局建筑主业赋能。公司具有竞争力的薪酬体系、特色福利制度、丰富员工活动、多元人才培养计划、多体系培养机制。
