## 公司
性质:央国企 · 行业:能源/化工/环保

北矿新材科技有限公司成立于2011年，是中央企业矿冶科技集团有限公司所属全资二级子公司。北矿新材自成立以来，坚持走创新驱动发展之路，高度重视科技创新能力建设，先后被认定为国家高新技术企业、国家技术创新示范企业、国家专精特新“小巨人”企业等，拥有“修复工程技术研究中心”“北京市涂层材料表面强化与重制企业技术研究中心”“特种涂层材料与技术北京市重点实验室”等多个创新平台，是国内航空发动机涂层材料、高纯难熔金属材料的主要供应商和技术创新基地。
