## 公司
性质:民企 · 行业:智能硬件

深圳汉阳科技有限公司（YARBO）成立于2015年，总部位于深圳，并在纽约、香港、新加坡设有办公室，广东惠州设有生产基地。作为一家国家高新技术企业、“专精特新”及中外合资企业，公司专注于消费级智能庭院维护机器人的研发、生产与销售，拥有强大的自主研发实力。凭借创新技术，YARBO率先推出全球首款全自动扫雪机器人，填补了扫雪机器人的行业空白。我们致力于为北美、欧洲等高端家庭用户提供智能化、全季节的庭院维护解决方案，涵盖扫雪、割草、吹落叶等核心功能。未来，YARBO将持续探索智能庭院的多场景应用，让全球用户享受更轻松、更愉悦的高品质户外庭院生活。
