## 公司
性质:民企 · 行业:能源/化工/环保

索通始创于1998年，从贸易业务起步，持续发展现已形成主业，并以“C+CARBON 战略”为指引，持续向碳材料产业集群拓展，现已发展成一家拥有多元化股东、具备现代化治理机构的上市公司。业务遍布全球110多个国家和地区。作为世界领先的预焙阳极生产商，拥有以山东临邑为基地的年产能已达全国前列，公司凭借其在质量、成本、服务、创新等方面的优势，与国内外大型电解铝企业建立了良好的长期合作关系。历经二十余年的奋斗，索通已构建起以“矿、炭、素、铝”一体化绿色能源供应链为基础，以“绿色低碳、智能制造”为战略路径的低碳绿色循环经济产业体系。
