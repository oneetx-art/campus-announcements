大商所飞泰测试技术有限公司（简称飞泰公司）是大连商品交易所的全资子公司，成立于2020年，是证券期货行业中首家挂牌的行业测试公司。公司承担大连商品交易所的信息实验室资质和管理体系，是行业首批测试系统建设和测试产品解决方案提供商，已累计为期货系统报备企业，界面与行业，IT专业服务等领域客户提供近百项测试技术，以及超过200家证券、期货和基金公司。
