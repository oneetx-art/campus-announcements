## 公司
性质:央国企 · 行业:金融业

广西融资担保集团有限公司是广西自治区级直属金融企业，由自治区人民政府授权自治区财政厅履行出资人职责，是集政府性、商业性于一体的融资担保机构。集团于2020年6月3日经工商注册成立，目前注册资本金（实缴）58.48亿元，获4家权威评级机构AAA信用评级。集团下设广西融资再担保有限公司、广西桂惠融资担保有限公司和广西科技融资担保有限公司3家子公司。
