## 公司
性质:央国企 · 行业:能源/化工/环保

新疆众和股份有限公司（以下简称“公司”）是铝基新材料产业的技术引领者和全球供应商，于1958年建厂，1996年在上海证券交易所上市（股票代码：600888）。历经60余年的发展，已成为中国战略性新材料产业的核心骨干企业，中国电子元件百强企业、铝加工十强企业，积极构建以“能源-电解铝-高纯铝-电子铝箔-电极箔”铝基新材料循环经济产业链为主体，集冶金技术服务、智慧物流、镁基资源开发协同发展的产业格局。公司建有“国家认定企业技术中心”“博士后科研工作站”等多个国家级科研平台，是首批国家“创新型企业”，与国内多所知名高校院所开展深度合作，为国家发展提供了“绿色”原材料保障及解决方案。
