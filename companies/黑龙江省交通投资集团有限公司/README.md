## 公司
性质:央国企 · 行业:交通/物流/仓储

黑龙江省交通投资集团有限公司于2019年1月18日注册成立，是黑龙江省政府出资成立的国有资本投资公司，是黑龙江省交通基础设施建设投融资平台、交通资本经营和债务管理平台、东北亚跨境物流贸易平台、矿产土地资源经营管理平台。注册资本417亿元，资产总额2981亿元，下辖二级企业20户，控股上市公司1户，合并范围内企业共203户，员工总计1.58万人。曾获得“全国抗击新冠肺炎疫情先进集体”“全国五一劳动奖状”“第十八届全国职工职业道德建设标兵单位”等多项荣誉。
