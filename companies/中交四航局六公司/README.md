## 公司
性质:央国企 · 行业:房地产业/建筑业

中交四航局第六工程有限公司（以下简称六公司），总部坐落于美丽浪漫的绿色海滨城市——珠海，为中国交通建设集团有限公司旗下中交第四航务工程局有限公司重要全资子公司，入选中交集团“2023-2024年度重点三级公司”。六公司目前拥有“建筑施工总承包一级资质”“市政公用工程施工总承包二级资质”“公路工程施工总承包三级资质”“建筑装修装饰工程专业承包一级”以及“建筑机电安装工程专业承包一级”等资质。经过多年的发展，六公司已经成长为以房建为主营业务，公路、市政、水利、冷链业务多元化发展的工程施工企业，业务范围涵盖粤港澳大湾区、成渝经济圈、海南自贸岛、华中、华东等地区。
