## 公司
性质:民企 · 行业:交通/物流/仓储

寰宇义嘉国际物流集团作为一家国际化综合物流企业，依托多年项目管理经验积淀、标准化作业体系与至诚服务理念，为客户构建全链条、专业化、定制化的物流解决方案。集团总部为寰宇义嘉国际物流（北京）有限公司，在天津及于上海等核心港口城市设有分支机构；在阿联酋，有全资子公司寰宇义嘉国际物流（天津）有限公司，并于海外多个核心港口城市设有分支机构；区域覆盖中东、南亚、东南亚、非洲及欧美等主要区域市场。公司业务所在行业包括石油化工、电力、新能源、基础建设、冶金矿业、会展物流等，主要业务范围为大型海外工程项目的国际多式联运及物流相关方案设计和咨询服务等。
