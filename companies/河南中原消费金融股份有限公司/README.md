## 公司
性质:民企 · 行业:金融业

河南中原消费金融股份有限公司（简称“中原消费金融公司”）于2016年底成立，是经中国银保监会批准成立的全国性非银行金融机构，由中原银行与上海伊千网络信息技术有限公司共同出资引入华平投资作为新股东，经河南银保监局批准，公司发起设立，2019年9月20日，公司已发展来新契机，注册资本为人民币20亿元，为国内已设立31家持牌消费金融公司，中原消费金融公司是第18家成立的，拥有河南郑州（总部）、上海两大职场。
