## 公司
性质:民企 · 行业:医疗/医药/生物

甘李药业股份有限公司（股票简称：甘李药业，股票代码：603087.SH）成立于1998年，是一家集科研、开发、生产、销售于一体的高科技生物制药企业，全球范围内拥有员工6000余名。总部位于北京通州经济开发区南区，隶属于中关村国家自主创新示范区。甘李药业山东有限公司是甘李药业基于国际化、化学化发展战略，在全球投资规模最大的生产基地。项目于2019年9月正式签约临沂，并于2020年6月19日开工建设，2021年7月整体土建完成。一期已投资约3.2亿元，用地约480亩，建筑总面积约27万平方米，公司定位于全链条降糖产品生产基地，专注于生物制品、快速器械、化学药品的生产，药品将广泛供应全球市场。
