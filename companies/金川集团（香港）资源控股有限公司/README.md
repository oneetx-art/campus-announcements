## 公司
性质:央国企 · 行业:能源/化工/环保

金川集团（香港）资源控股有限公司（以下简称金川香港）于2009年底在香港注册成立，2010年初正式组建运营，是金川的全资子公司。公司（以下简称建香港）是金川集团子公司。金川香港核心控股与业务布局涵盖全球多个国家和地区，投资参与上市公司金川集团国际资源有限公司、持有赞比亚柯蒂斯矿业公司、印尼金川PT.WP公司、赞比亚拉比公司、印尼华恩房地产公司、赞比亚海益公司，核心资产主要分布于南非、刚果（金）、赞比亚、印度尼西亚、墨西哥等国家，本次招聘岗位工作地点为刚果（金）和印度尼西亚。
