## 公司
性质:民企 · 行业:机械/制造业

爱士惟是一家专业从事光伏并网逆变器、储能逆变器、储能电池、智能充电桩及智慧能源管理系统等产品研发、制造的新能源高新技术企业。公司成立于2009年，曾经隶属于全球知名太阳能逆变器研发和制造企业德国SMA集团。总部位于中国上海，并在苏州、上海、西安、科隆设有研发中心，在扬中设有生产制造中心，业务分支机构遍布亚洲、欧洲、南美洲、非洲、大洋洲，产品行销全球多个国家和地区。
