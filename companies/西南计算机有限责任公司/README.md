## 公司
性质:央国企 · 行业:通信/电子/半导体

重庆机电控股（集团）公司所属西南计算机有限责任公司（国营第七八九厂），成立日期：2001-05-24，位于重庆市南岸区南坪光电电路1号，是以研发和生产指挥控制系统产品、电子信息类设备为主的国有军工电子企业。公司经过60年的建设和发展，已成为国家军工电子领域具有行业影响力的骨干企业，也是我军多个军兵种指挥自动化系统的科研、生产、维修应用基地，在指挥系统总体设计以及国产化计算机的集成运维等方面，拥有过硬的研发、制造、检测和技术保障能力。公司现有在册职工700余人，拥有工程技术人员300余人，其中高级工程师95人，正高级工程师50人，享受国务院政府特殊津贴专家1人。公司拥有国家认定的企业技术中心、重庆市工业和信息化重点实验室等平台，多项科技成果获国家和省部级奖励
