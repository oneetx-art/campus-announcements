## 公司
性质:央国企 · 行业:房地产业/建筑业

广东省建筑科学研究院集团股份有限公司（简称“广东建科”）前身成立于1958年，2014年完成股份制改造,2016年整体改制成功上市（A股代码:301632）。广东建科以'创新发展、服务社会'为使命，积极践行'绿色低碳，城乡建设'的发展理念，主要从事建设工程质量安全、绿色低碳、防灾减灾、生态环境、城市更新、智慧城市、智能建造、全过程工程咨询等技术服务工作，业务横跨房建、市政、交通、水利工程建设全产业链，多领域、多业态、多专业的水利、环保、安防等业务领域，拥有以院士为代表的高水平技术团队，业务遍布全国，具备向世界经济贸易服务、全国员工高层次素质和能力、国内工程检测服务、城市更新、城市规划、智慧城市等行业领域。公司是工程建设、战略新兴、建筑的重要业务板块，是政府在工程建设领域培育的重要技术支撑单位，是国家科技示范企业、高新技术企业，是粤港澳大湾区建筑科技联盟理事长单位、'全国五一劳动奖状''全国工程勘察设计行业优秀勘察设计企业' '全国用户满意企业' '全国五四红旗团委'等称号。
