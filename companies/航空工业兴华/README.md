## 公司
性质:央国企 · 行业:交通/物流/仓储

沈阳兴华航空电器有限责任公司（以下简称航空工业兴华）于1957年9月4日经原第二机械工业部批准成立，是我国最早从事航空电器研制的专业企业之一。公司隶属于中国航空工业集团有限公司，是国家高新技术企业、国家CNAS认可实验室、国家级博士后科研工作站以及辽宁省企业技术中心、辽宁省标杆创新中心，是一家集研发、生产、创新、制造为一体的互连系统解决方案提供商。
