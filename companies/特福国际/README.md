## 公司
性质:民企 · 行业:耐用消费品

广东特福国际控股有限公司（下称“特福国际”）由科达制造股份有限公司（上海证券交易所上市股票代码：600499与瑞士证券交易所上市股票代码：KEDA）与森大集团合资经营，其全资控股的海外建材业务自2016年启动，于2023年正式变更为“特福国际”，是中国最早进入非洲、南美洲等海外市场的工贸一体传化企业之一。公司积极响应国家“一带一路”倡议及“走出去”战略，深耕海外市场，致力于高端瓷砖、建筑玻璃、浴室洁具等产品的研发生产与营销贸易，业务覆盖非洲、南美洲10余个国家与地区，拥有14个海外生产基地与国内外员工14000余人。未来，特福国际将稳步推进全球化布局进程，开启全球化产能新篇章！
