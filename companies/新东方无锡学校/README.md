## 公司
性质:民企 · 行业:教育/培训/科研

新东方教育科技集团由1993年成立的北京新东方学校发展壮大而来。从教育领域出发，经过32年创新发展，集团业务目前已涵盖教育服务、生活服务、文旅服务三大领域。新东方无锡学校是新东方教育科技集团直属分校，在2006年经无锡市教育局审批成立，目前涵盖了素质素养教育、高中、国际游学&营地教育、文旅等众多项目，迄今教学点已覆盖锡城各区域。
