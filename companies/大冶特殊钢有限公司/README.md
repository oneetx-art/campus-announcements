## 公司
性质:央国企 · 行业:机械/制造业

大冶特殊钢有限公司（简称：大冶特钢），始建于1913年，具有百年历史，是中国近代“钢铁摇篮”，地处都市圈副中心城市黄石市，是中国品种规格最齐全的高品质棒材、高端厚壁无缝钢管、高合金锻材三大特钢生产基地，隶属于世界500强大型央企中信集团先进材料板块中信泰富特钢集团。
