## 公司
性质:民企 · 行业:金融业

上海启林投资管理有限公司成立于2015年5月28日，注册资本金217万元，是一家专注于量化投资的私募基金公司，公司于2017年8月获取证券类私募管理人牌照（登记编号P1064620）。截止至2023年8月，累计资产管理规模已达250亿人民币。公司采用多策略多因子的量化投资策略，坚持以投研为核心的投研理念，使用前沿的投资方法，通过量化分析、资产配置，凭借业内领先的量化策略平台和独特的策略开发模式，为不同需求的投资者提供定制化资产管理专业服务。启林投资展开全球市场的量化投资策略研究，覆盖国内外金融行业的业务线。公司致力于打造结构扁平、工作高效的团队，向更多优秀的人才开放。
