## 公司
性质:民企 · 行业:医疗/医药/生物

稳健医疗（武汉）有限公司是稳健医疗用品股份有限公司（股票代码：300888）于2017年1月注资成立的全资子公司，也是国家高新技术企业。公司坐落于武汉市长江新区智能制造产业园，一期面积260余亩，主要业务包含水刺无纺布业务、棉柔巾业务、印花业务、灭菌业务及物流仓储服务等。2020年投资30亿建设武汉稳健二期项目，占地430余亩，以建立稳健集团第二总部为核心，规划成立四个板块十大中心。
