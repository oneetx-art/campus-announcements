## 公司
性质:央国企 · 行业:金融业

建信期货有限责任公司是中国建设银行股份有限公司附属公司，总部位于上海陆家嘴，成立于1993年，于2014年4月重组更名，注册资本金93605.98万元。公司有多年期货经纪服务经验，能够为客户提供全期货品种的投资和风险管理服务，资产品管理业务可根据客户委托，提供多层次、多品种财富管理工具，下设全资风险管理子公司可从事仓单服务、基差贸易、场外衍生品等风险管理试点业务以及大宗商品押风险管理、一般贸易等业务。
