## 公司
性质:央国企 · 行业:金融业

苏州农发创新资本管理有限公司成立于2011-03-04，注册资本1.5亿元，为苏州市农业发展集团全资子公司，是国有控股的专业性金融投资及资产管理公司。公司深耕股权投资与基金管理赛道，核心聚焦政府引导基金、VC/PE成长型股权投资基金、专项产业投资基金的设立募集、项目投资、投后赋能与全周期资产管理，立足苏州、辐射长三角，深度联动地方产业、科创企业、各级国资平台，以资本力量赋能实体经济、现代农业、高新技术与战略性新兴产业，在服务区域产业升级、培育优质本土企业过程中发挥关键国资资本引导作用。公司合规经营资质完备，2014年完成中国基金业协会登记，是多个行业协会会员单位，深度参与区域股权投资行业交流与产业资源对接。
