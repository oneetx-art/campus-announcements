## 公司
性质:民企 · 行业:机械/制造业

征图新视（江苏）科技有限公司成立于2009年，是为制造业提供工业图像的完整解决方案提供商，专业制造视觉及自动化检测及配套自动化设备。征图的明星产品有：印刷及包装图像检测及相关自动化设备、电子半导体检测、表面检测、薄膜检测、汽车精密零部件、电子产品外观检测及装配自动化设备等。公司拥有国内最早的机器视觉检测及软件开发经验的研发团队，在光学、图像检测软件、机械、电气、气等方面拥有核心技术，及配套自动化的研发方向，都拥有十余年的核心技术积累及数十项技术创新，在行业内处于领先地位。
