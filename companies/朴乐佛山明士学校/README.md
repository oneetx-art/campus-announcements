## 公司
性质:民企 · 行业:教育/培训/科研

朴乐教育集团（原朴新教育）是以学生全面成长为核心，以教育与科学为驱动力的综合性教育集团，总部位于中国北京海淀区中关村。其前身为朴新教育科技集团（NYSE：NEW），于2014年9月在北京成立，由多位教育培训行业资深人士组成，2018年在纽交所上市，成为在纽交所上市的中国第三大综合课外辅导集团。后于2021年12月遵循国家相关政策，从上市主体剥离，合规经营。明士教育创办于2004年，是佛山规模最大的教育机构之一，于2019年加入朴乐教育集团，专注于中、小学学生全面成长培养，业务范围包括中小学素质教育培训、能力成长中心、营地拓展训练。
