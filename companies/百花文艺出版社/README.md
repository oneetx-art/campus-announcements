## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

百花文艺出版社是中国最早成立的专门从事文艺出版的单位之一，于1958年8月正式挂牌运营。百花文艺出版社自成立起运营以高品质、多种类的书刊出版深度参与了当代中国人文艺术生活的建构，在读者、作家及文艺批评界具有广泛的影响力，是当代宜传册影的全国优秀出版社。
