## 公司
性质:民企 · 行业:机械/制造业

昆山长鹰硬质材料科技股份有限公司（简称长鹰硬科）成立于2003年，注册资本7714.28万，是一家专业的硬质合金、金属陶瓷材料制造商和供应商。公司拥有3万平方米的生产车间、先进的实验室和完备的研发设施设备，超过900名熟练的员工，包括优秀的材质和模具的工艺设计工程师团队。2009年公司被评为“江苏省高性能硬质合金工程技术研究中心”，2012年公司被认定为“江苏省高新技术企业”，2020年被评为“苏州园区城‘最具关爱员工雇主’、昆山市‘最佳职业发展雇主’、昆山市‘劳动关系和谐企业’”，公司先后成立研究生工作站、博士后科研工作分站，2023年认定为国家级“专精特新”小巨人企业。
