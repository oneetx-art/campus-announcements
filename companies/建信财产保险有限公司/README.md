## 公司
性质:央国企 · 行业:金融业

建信财产保险有限公司（简称“建信财险”）于2016年10月成立，是经监管机构批准设立的全国性财产保险公司，隶属于中国建设银行集团，经营总部设立在北京。公司经营发展在总体上服务国家发展战略，在功能上有效补充、在战略上有力策应建行集团，肩负着“服务建行集团战略、服务建行集团主业、服务建行集团客户”的担当使命，在业务模式、产品创新、渠道布局、客户服务和风险管理方面突出银行系保险公司特色，实现公司高质量发展。
