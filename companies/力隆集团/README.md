力隆集团（1983年成立）坐落于中国东海之滨——浙江宁波，是一家专注电梯与扶梯部件研发制造四十余年的中国独资企业。集团以小港装备园区300亩旅游工厂为基地，拥有员工1200人，年销售额达16亿元，是国际知名电梯品牌的主力供应商，提供OEM/ODM定制与电梯系统解决方案。
