## 公司
性质:民企 · 行业:机械/制造业

合肥致真精密设备有限公司（Truth Equipment Co.,LTD）成立于2021年5月，是一家专注于高精度物理气相沉积设备及其关键组件研发和制造的国家高新技术企业。公司研制了多款具有自主知识产权的国产高端科研级和产业链级磁控溅射设备，同时为合作伙伴和客户提供薄膜加工制造、工艺调试、设备软件开发等服务。
