## 公司
性质:民企 · 行业:咨询

上会会计师事务所（特殊普通合伙）原名上海会计师事务所（以下简称上会），创办于1981年，是由财政部在上海试点成立的全国第一家会计师事务所，并成为全国第一批具有上市公司、证券、期货、金融资质的会计师事务所之一。发展至今具备上市公司、金融证券机构、大型企业年报、外汇专项、司法鉴定审计和高新技术企业专项审计等多项业务资质和相应的业务来源。
