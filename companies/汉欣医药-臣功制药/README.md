## 公司
性质:民企 · 行业:医疗/医药/生物

南京汉欣医药科技有限公司由美国Amphastar公司中国研发中心，于2021年7月6日重组设立，注册资本1.83亿人民币。汉欣医药依托优势技术平台，凭借雄厚研发实力，迅速发展为集多肽、蛋白、多糖的原料及成品的研发、生产及销售于一体的大型医药集团。南京臣功制药股份有限公司成立于1992年，是南京汉欣医药科技有限公司全资子公司，主要从事各种中西药制剂的生产、销售与服务，旗下拥有制剂、原料药生产和药品批发流通等多家全资子公司。通过三十余年的拼搏奋进，臣功制药已蝶变为产品系列化、营销多元化、品牌高端化、资源规模化、管理国际化的大型综合医药集团。
