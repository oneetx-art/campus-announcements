## 公司
性质:央国企 · 行业:能源/化工/环保

中国电建集团山东电力建设有限公司（简称山东电建，英文简称SEPCO）成立于1952年，下属全资子公司有中电建宁夏工程有限公司和电建港航有限公司（央企三级公司），隶属于世界500强中国电力建设股份有限公司（四大央企）。山东电建具有电力能源、油气化工、节能环保、基础设施等领域的投资、勘测设计、设备总成套、建筑施工和调试运行的全产业链服务能力，拥有电力施工总承包特级资质，电力工程、建筑工程、机电工程、石油化工工程施工总承包一级等30余项资质，是沙特国家电力公司及阿美石油公司认证的EPC等总承包商。
