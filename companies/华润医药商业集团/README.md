## 公司
性质:央国企 · 行业:医疗/医药/生物

华润医药商业集团有限公司是国有大型综合性医药物流企业，华润集团大健康板块业务单元之一，作为医药流通行业领先企业，始终践行“润泽健康，共创美好”的企业使命，为大众美好生活提供健康服务保障，引领大健康产业创新发展，为健康中国战略目标实现做出卓越贡献。华润医药商业服务大国民生，主要从事医药品营销、物流配送以及提供医药供应链解决方案服务，是首批通过国家GSP认证的药品经营企业，具有药品和医疗器械的进出口资质、医药三方物流经营资质。公司与国内外近万家医药生产企业保持着长期稳定的合作关系，建有以北京为中心覆盖全国31个省市的营销网络，主要服务于全国各级医疗机构、医药商业批发企业和零售药店。2024年，华润医药商业主营业务收入达2,132亿元，商务部医药流通企业排名前3强，下属470余家分子公司，分布于全国28个省市。
