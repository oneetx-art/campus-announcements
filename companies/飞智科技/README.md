## 公司
性质:民企 · 行业:智能硬件

浙江飞航智能科技有限公司成立于2021年，是由浙江大学创新创业研究院控股的科技创新企业。依托浙江大学的技术与人才资源，公司专注于智能无人装备领域，构建了“智能感知+协同控制+场景智能”三位一体的技术体系，致力于以AI与具身智能等前沿技术推动创新研发与产业化落地。公司以人工智能驱动的感知、决策系统为核心，自主研发包括无人装备控制模组、底层结算终端、智能无人机等硬件产品，形成从底层算法、硬件平台到上层应用的全栈能力。目前已为能源电力、应急安全、军用防务、机器人行业提供高度智能化的解决方案。公司先后获评“国家高新技术企业”“浙江省专精特新企业”“浙江省高新技术企业研究开发中心”等荣誉认定。以成为“无人装备智能化领航者”为使命，公司正通过持续的技术创新，为行业客户提供坚实的技术支持与优质的产品服务。
