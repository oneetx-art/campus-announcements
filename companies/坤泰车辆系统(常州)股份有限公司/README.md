性质:民企 · 行业:汽车制造/维修/零配件

坤泰车辆系统(常州)股份有限公司成立于2017年12月，作为新能源混动汽车动力传动系统的独立第三方企业，公司专注混合动力DHT、扁线电机等核心部件的研发、生产与销售，并拥有面向大市场的整车及零部件测试验证能力。通过开发常州、淮南、淮北和多系统协同解决方案，公司能够为客户提供模块化全域混动的混合动力系统技术方案，致力于成为具有国际竞争力的汽车核心零部件创新企业。
