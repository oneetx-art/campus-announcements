## 公司
性质:民企 · 行业:房地产业/建筑业

亚厦是以建筑装饰、幕墙、安装及智能化为核心，以EPC及装配式为特色的建筑装饰全领域一体化领航企业。自2010年3月23日在深交所正式挂牌上市，连续22年稳居全国行业龙头地位。亚厦是行业唯一的国际峰会（如APEC、G20、金砖五国、上合峰会等）元首核心区承建商及企业参建了全国80%的国际机场、1/3的高星级酒店以及众多城市地标和大型场馆。亚厦坚持走低碳绿色的新型建筑工业化道路，整合国家科研基地9000余项，其中发明专利2500余项，亚厦装修+国星涂料深耕，以匠心和创新创造美好人居，与国同行，同至未来。亚厦三十多年来持续深耕大匠运匠技艺，为城市高质量发展勾勒精美画卷。
