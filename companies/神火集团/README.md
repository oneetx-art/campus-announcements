## 公司
性质:央国企 · 行业:能源/化工/环保

河南神火集团有限公司是商丘市国有企业，成立于1994年，主要从事煤炭开采与洗选加工，电力生产与配送，氧化铝生产及电解铝冶炼，铝板带箔生产以及新型合金材料、高端储能材料研发与加工等。系国务院国企改革“双百企业”、河南省百户重点企业、河南省重点扶持的骨干煤炭企业及铝加工企业、河南省第一批循环经济试点企业，现有员工2.6万人。
