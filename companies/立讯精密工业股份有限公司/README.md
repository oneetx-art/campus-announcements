## 公司
性质:民企 · 行业:通信/电子/半导体

立讯精密工业股份有限公司成立于2004年5月24日，于2010年9月15日在深圳证券交易所成功挂牌上市（股票代码：002475）。自2024年以来，公司营业收入复合增长率连续多年达50%。2024年公司实现营业收入2687.95亿元，较上年同期增长15.91%。公司致力于为消费电子产品（智能手机、智能可穿戴设备、混合虚拟现实设备、声学模组、无线充电、汽车LCPE天线、震动马达、VCM等）、汽车领域产品（汽车线束、汽车连接器、光传感器、智能驾驶域控制器等）以及企业通讯产品（高速互联、光模块、核心器件、模组等）及企业通讯基站滤波器等提供从核心部件、模组到系统组装的一体化智能制造解决方案。公司近3年累计研发投入达251.92亿元，截至2024年末，拥有发明专利、实用新型专利及外观设计专利超7000项
