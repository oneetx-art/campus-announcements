## 公司
性质:民企 · 行业:机械/制造业

上海谱星航天科技有限公司是国内领先的光谱定量遥感解决方案提供商与微纳卫星制造商，短时间内完成三轮头部机构融资，累计融资近3亿元，全力推进千星遥感星座项目。公司采用上海、长春双基地运营模式，长春谱星空间技术有限公司定位为卫星研发中心，具备50套光学载荷与30颗20-50kg微纳卫星批量生产能力。上海谱星智能科技有限公司定位为星座运营及遥感应用研发中心，开展遥感AI模型研发。公司搭建光学载荷、微纳卫星、遥感数据服务三位一体产品体系，自主研发的光谱定量遥感载荷及光谱定量遥感卫星，实现从硬件研制到星座数据服务的全链条闭环。公司立足打破传统定性遥感局限，输出高精度可量化遥感数据，依托AI加航天融合优势，布局1024颗光谱定量遥感星座，致力于打造全球领先的天基定量数据基础设施。当前公司已拿到数亿元正式订单，自试验星计划2027年发射。团队由资深卫星总师带队，核心人员来自航天院所与头部商业航天企业，具备载荷研制、整星生产、在轨运维与数据服务全链条能力
