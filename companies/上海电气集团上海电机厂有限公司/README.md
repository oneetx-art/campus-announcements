## 公司
性质:央国企 · 行业:机械/制造业

上海电气集团上海电机厂有限公司是一家具有现代化生产规模的综合性电机制造及电机成套装备制造商。公司成立于1949年12月1日，中小型电机中大型直流电动机、风力发电机、中小型电动机，以及横铸多领域的电机产品与火电厂的驱动、控制成套设备。产品广泛用于火电、核电、风电、冶金、水利、石化、矿山、建材、船舶等各行各业。无论是生产经营规模、市场占有率及综合经济效益等均名列全国同行业前茅，是电机行业排头兵，在国内外享有良好的声誉。
