## 公司
性质:央国企 · 行业:汽车制造/维修/零配件

东风柳州汽车有限公司（简称东风柳汽）创立于1954年，是由东风汽车集团控股的国有全资控股公司，至今已拥有70多年发展历史，是东风公司在南方的商用车生产基地。公司旗下拥有乘龙、东风风行商乘两大品牌，商用车涵盖牵引车、载货车、自卸车、专用车、纯电动物流车、纯电、环卫车等系列产品，乘用车涵盖MPV、SUV、轿车等系列产品，当前，商用车全系列、产品已全部实现新能源转型。东风柳汽在国内拥有营销服务网点2500个，覆盖全国30+省、市、自治区；在海外拥有营销网点近300个，产品远销海外70+国家及地区，连续多年保持销量领先！
