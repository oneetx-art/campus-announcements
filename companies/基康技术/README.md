## 公司
性质:民企 · 行业:机械/制造业

基康技术股份有限公司创立于1998年，是一家专业从事智能监测终端的研发、生产与销售，同时提供安全监测物联网解决方案及服务的高新技术企业，产品主要用于工程安全监测及自然环境监测领域，2022年12月20日登陆北京证券交易所。公司自主知识产权产品广泛应用于水电站、核电站、风电场、油气储运、水利工程等多个领域，曾参与三峡、白鹤滩、南水北调、港珠澳大桥等多个国家级重点项目。
