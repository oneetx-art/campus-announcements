## 公司
性质:民企 · 行业:IT/互联网/游戏

北京清维科技有限公司（简称“清维如风”）成立于2022年9月，主要定位于智能航空装备及机场数字化平台提供商。清维如风为机场物流行业提供数字化机场及智能航空装备。公司产品涵盖自动驾驶软/硬件技术、机场特种车辆整车产品等。公司致力于用科技赋能机场智慧物流，构建数字机场生态系统，推动机场特种装备向智能、高效转变，实现机场物流领域真正的数字化变革。
