## 公司
性质:民企 · 行业:机械/制造业

怡和机器有限公司（怡和机器）是怡和集团旗下成员，于1923年在上海成立，总部现设于香港，业务遍及亚洲。怡和机器为楼宇、能源及运输行业、环境基建设施提供产品及采购、合约工程及技术服务，专门提供电气、机械及建筑技术，并具备合约工程专业知识，提供大型安装、操作与保养等服务，协助客户把设施运作臻达世界级水平。
