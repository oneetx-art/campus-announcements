## 公司
性质:央国企 · 行业:能源/化工/环保

河南能源义马煤业集团股份有限公司（简称义煤公司）有规模建制开采历史始于1905年，1958年3月成立义马矿务局，1997年12月改制为义马煤业（集团）有限责任公司，2008年12月改制为统一部署，与河南煤化集团联合重组，在河南省委省政府的义马煤业集团股份有限公司。2013年9月公司进行战略重组，成为河南能源集团旗下一员。2011年2月，公司下属河南大有能源股份有限公司在上海证券所上市（股票代码：600403），是河南能源下属的唯一一家煤炭上市公司。公司生产主要涉及能源、现代物流等，主要分布在河南、青海两省12对，青海、新疆及澳大利亚。现有正常生产矿井14对（常煤矿），截止2024年12月底，义煤公司煤炭资源共对（非煤矿山）12对。截止2024年12月底，义煤公司煤炭资源共吨/年（不含澳大利亚MDS矿1500万吨/年），拥有动力煤、焦煤、13.03亿吨，可采储量6.81亿吨，核定生产能力1790万工业、高炉喷吹煤、炼焦用精煤等多品种，可满足电力、化工、钢铁等多行业的需求。
