## 公司
性质:央国企 · 行业:机械/制造业

时代新材是中国中车一级子公司、A股上市公司，也是中国中车旗下新材料产业平台，始建于1984年，其前身为原铁道部株洲电力机车研究所橡胶试验室，2002年在上海证券交易所上市，2014年收购德国BOGE；综合国际化指数近40%，是一家销售规模持续过百亿的高科技指数化制造企业。
