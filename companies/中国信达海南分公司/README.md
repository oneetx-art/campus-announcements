## 公司
性质:央国企 · 行业:金融业

中国信达资产管理股份有限公司（以下简称“中国信达”）的前身为中国信达资产管理公司，成立于1999年4月，是经国务院批准，为有效化解金融风险、维护金融体系稳定、推动国有银行和企业改革发展而成立的首家金融资产管理公司。中国信达海南分公司是中国信达在海南省设立的分支机构。
