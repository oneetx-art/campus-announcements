## 公司
性质:民企 · 行业:金融业

北京金融街资产管理有限公司，是国有控股上市公司金融街控股股份有限公司（深交所主板A股上市公司，股票代码：000402）旗下唯一的商务地产运营平台，具备20年区域高端商务地产运营经验，致力于发展成为国内领先的大型综合性商务地产运营商。金融街控股连续22年荣获“沪深上市房地产公司综合实力TOP10”。自2008年成立以来，金融街资产公司深耕北京、上海、天津、重庆等一线城市，管理规模已超过150万平米。核心资产位于北京金融街，包括5A级写字楼金融街中心、高端商场金融街购物中心，餐饮街区金树街等。作为国家级金融管理中心，北京金融街不但聚集了“一行两会”等中国最高金融决策和监管机构，还入驻有金融机构1800余家，是国内世界500强企业聚集度最高的区域。金融街资产在上海、天津和重庆也有诸多代表项目：上海海伦中心写字楼、上海悦融中心写字楼、上海金融街购物中心、天津津塔写字楼、天津南开写字楼、重庆融器口后街商业项目等。金融街资产公司具备写字楼、商业、公寓、体育中心各业态的专业运营管理团队，拥有丰富的综合体项目定位、产品研发、运营管理、资产价值提升等商务地产全链条资产管理经验，以及完备的特色业务能力体系…
