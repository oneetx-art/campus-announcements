## 公司
性质:央国企 · 行业:金融业

申万菱信基金成立于2004年1月，申万宏源证券持有公司67%的股份，日本三菱UFJ信托银行持有公司33%的股份，股东实力雄厚。（截至2025年8月30日）资产管理规模1022.83亿元。公司产品布局相对完备，形成“投资美好生活、创新理财服务”的产品规划。打造“主动权益、量化指数、固定收益和多资产”等产品大类。公司拥有公募、特定客户资产管理人、合格境内机构投资者（QDII）管理人、保险资金投资管理人、基金投资顾问、合格境内有限合伙人（QDLP）等业务资格。多次荣获中国基金业金牛奖、中国明星基金奖、中国金基金奖等多项业内重要奖项以及东方财富“最佳指数投资团队”等荣誉。
