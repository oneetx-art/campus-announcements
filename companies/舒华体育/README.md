## 公司
性质:民企 · 行业:耐用消费品

舒华体育，国内领先的科学运动服务商，创立于1996年，2020年在上海证券交易所主板上市（股票代码：605299.SH）。2017年，舒华被国家体育总局评为“国家体育产业示范单位”。2013至2016年、2021至2024年，舒华与中国奥委会达成八年合作；2017年，舒华健身器械成为金砖国家领导人厦门会晤指定产品；2020至2022年，成为“国家体育总局冬季运动管理中心指定健身器材赞助商”、“北京2022年冬奥会和冬残奥会官方健身器材供应商”；2023年，为杭州亚运会运动员村及亚残运会运动员村健身中心提供健身器材、教练指导等服务。创办至今舒华慈善基金规模超6000万元。未来，舒华力争2030年成为百亿企业。
