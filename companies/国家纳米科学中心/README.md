## 公司
性质:事业单位 · 行业:政府/机构/组织

国家纳米科学中心是由中国科学院和教育部共同建设，2003年12月直属中国科学院委员会办公室批复成立的中国科学院直属事业单位。国家纳米中心定位于纳米科学的原创性基础研究和变革性产业技术，目标是建设世界级纳米科技创新高地、人才汇聚高地、技术转移转化高地。
