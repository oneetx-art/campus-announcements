## 公司
性质:央国企 · 行业:交通/物流/仓储

深圳市大洋物流股份有限公司（简称“大洋物流”）成立于2005年，总部位于深圳，是国家“AAAA级”物流企业和“一带一路”倡议的践行者。已通过质量、环境、健康安全管理三体系认证。公司深耕欧亚市场二十多年，打造1+2+N端到端物流产品服务为主产品，并拥有空运、工程陆航、仓储、报关、供应链管理等进出口物流服务。服务网络覆盖深圳、广州、上海、天津、西安、成都、塔什干、阿拉木图、新加坡、莫斯科、杜伊斯堡等国内外多个城市。
