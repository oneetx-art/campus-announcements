## 公司
性质:民企 · 行业:贸易/批发/零售

阳采集团始创于2014年，是一家专注于通过数字化平台为全国大型企业提供集中采购服务的企业，总部位于北京和太原两大城市，注册资本3.3亿元，在职员工800余人，销售网络覆盖全国。公司以“开放、连接、赋能”为核心理念，秉承“一城一供应商、两采技一周高效、三商四一”的战略布局，为企业客户提供“阳光、高效、低成本”的一站式数字化采购服务，服务领域涵盖建筑机电、石油化工、钢铁冶金、航天军工、轨道交通、建筑工程、能源流通、通讯电子、光伏电力等众多行业。
