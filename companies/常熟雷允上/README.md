## 公司
性质:民企 · 行业:金融业

常熟雷允上制药有限公司坐落于江南福地常熟，是一家现代化中药制药生产企业。公司始创于1969年，1998年加入中国远大集团，成为其旗下全资子公司。公司具有50多年研发和生产中药注射剂的丰富经验，致力于专攻肝病专科用药，同时向心脑血管、肿瘤用药方面拓展，以中药注射液、中药口服液为特色产品，主要产品有苦黄注射液、生脉注射液、丹参注射液、天佛参口服液等。
