## 公司
性质:民企 · 行业:机械/制造业

深圳市磨维科技有限公司为什方科技的全资子公司，专研于3D视觉智能引导技术。核心产品为工业机器人3D视觉引导系统，依托自研的3D点云重建、特征识别与轨迹规划等核心算法，为工业机器人赋予“工业自动驾驶系统”“眼睛与大脑”，打造“工业自动驾驶系统”。公司一体化解决方案（3D相机+算法）已广泛应用于铸件去毛刺、自动化打磨、焊接、点胶及高精度装配等领域。尤其在压铸行业，是目前唯一实现全方位智能动态补偿的解决方案，屡获行业奖项。公司拥有多项专利与软著，技术骨干多毕业于清华、北大等C9院校，涵盖数学、光学、人工智能等各学科高学历人才。
