## 公司
性质:民企 · 行业:智能硬件

深圳市康冠科技股份有限公司（股票代码：001308）成立于1995年，是一家全球平板显示解决方案提供商，专注于为客户提供屏显研发制造、差异化的平板显示产品，并向全球市场输出中国智造解决方案。公司在智能交互平板、创新型显示产品、专业类显示产品、智能电视四大领域，实现了“AI+办公”、“AI+教育”、“AI+医疗”、“AI+视讯”等多场景领域的全球化多点产业布局。
