## 公司
性质:民企 · 行业:机械/制造业

大连泰星能源有限公司，简称PPEDL（原名为大连松下汽车能源有限公司），成立于2014年12月。是由日本“泰星能源解决方案有限公司（日本丰田集团与松下集团合资成立的公司）”与“大连辽无二电器有限公司”合资成立的一家中日合资企业。坐落于第十个国家级新区大连金普新区。公司是专业从事环保型汽车用锂离子电池及电池组的设计、制造、销售、售后及进出口业务的大型动力电池企业。公司于2017年年底正式量产，目前在职人数3500余人。
