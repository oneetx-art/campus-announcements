## 公司
性质:民企 · 行业:医疗/医药/生物

上海观合医药科技股份有限公司成立于2016年，是行业领先的一站式CRO实验室服务平台，为全球制药企业提供药物临床试验相关的创新诊断解决方案。公司由迪安诊断（300244.sz）与泰格医药（300347.sz / 3347.hk）合资设立，并遵循GCP、GLP、CAP等行业规范搭建了严格的质量管理体系。
