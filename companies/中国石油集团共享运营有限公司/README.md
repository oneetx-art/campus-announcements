## 公司
性质:央国企 · 行业:能源/化工/环保

中国石油集团共享运营有限公司（以下简称“公司”）由中国石油天然气集团有限公司和中国石油天然气股份有限公司（以下分别简称集团公司、股份公司）共同出资，于2019年10月注册成立，是集团公司参与国内外市场竞争的专业运营服务提供方，是集团公司财务、人力资源、信息技术、客户服务、法律事务及其他职能管理的有机组成部分，旨在促进中国石油管理转型发展，提升管理水平和运行效率。公司提供财务、人力资源、信息技术、客户服务、法律事务等共享服务。公司本部位于北京市，分别在北京、西安、大庆、成都、吉林、天津、乌鲁木齐等地设有11个二级单位
