## 公司
性质:央国企 · 行业:机械/制造业

通号（广州）工程技术有限公司成立于2024年9月，系中国通号一级子公司。由中国铁路广州局集团有限公司与中国铁路通信信号股份有限公司、中国铁通粤港澳大湾区核心引擎——广州科学城组建，坐落于粤港澳大湾区核心引擎——广州科学城。公司传承行业标杆“中国通号”和“百年广铁”优秀品质，致力于打造一流轨道交通全产业链，为客户创造更高价值。以‘数字轨道交通产业’定位，构建集设计研发、深度融入粤港澳大湾区建设服务于一体的产业体系，智能制造、数字工程、智慧运维等国家工程，持续探索轨道交通领域的创新突破与价值赋能。
