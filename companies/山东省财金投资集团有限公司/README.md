## 公司
性质:央国企 · 行业:金融业

山东省财金投资集团有限公司（以下简称“山东财金集团”）前身是成立于1992年的省经济开发投资公司。2015年9月，省政府批复省经济开发投资公司转企改制方案，组建山东财金集团。2020年2月，省委、省政府明确山东财金集团是由省财政厅根据省政府授权，直接履行国有金融资本出资人职责的省属骨干金融企业、功能型国有资本投资运营公司，打造成财政金融政策联动的投资运营公司。目前，山东财金集团注册资本300亿元，拥有德邦证券、泰合资产等18家全资及控股公司，参股企业69家，是中国企业联合会、中国企业家协会副会长单位，山东省企业联合会、山东省企业家协会等副会长单位。境内主体评级为AAA级，国际评级为惠誉A和穆迪A2，均为山东省企业最高信用等级。
