## 公司
性质:央国企 · 行业:机械/制造业

中国航发哈尔滨轴承有限公司成立于2010年5月，位于哈尔滨市呼兰区南京路888号（新区托管区），是中国航发旗下唯一从事轴承研制的专业化企业，主要从事轴承及轴承技术衍生产品的研发、制造、销售、服务等业务。公司主要承担航空发动机主轴轴承、直升机传动系统轴承、飞机机体轴承、附件轴承全部四大类航空轴承的配套任务，建有国家级科技创新平台及中心2个、省部级4个、集团级2个，设有国家级博士后科研工作站。
