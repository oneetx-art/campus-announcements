## 公司
性质:央国企 · 行业:能源/化工/环保

西南化工研究设计院有限公司（简称“西南院”）始建于1958年，是世界500强“中国中化控股有限责任公司”旗下“昊华化工科技集团股份有限公司（股票代码600378）”的全资子公司。致力于碳一化工、变压吸附气体净化与分离、精细化工等领域的技术研究开发和成果推广，是集技术许可、工程设计、工程咨询、工程总承包与管理、产品生产与销售等业务的整体解决方案服务商。
