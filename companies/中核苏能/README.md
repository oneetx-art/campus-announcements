## 公司
性质:央国企 · 行业:能源/化工/环保

中核苏能核电有限公司成立于2017年12月25日，主要负责田湾核电站7、8号机组与连云港徐圩供热供电项目的建设、运营与管理。公司由中核集团、江苏省国信集团、连云港市金控集团共同出资成立，计划分两期建设，项目于2023年11月开工，计划2028年建成投运。
