## 公司
性质:央国企 · 行业:机械/制造业

郑纺机成立于1949年11月13日，前身为国营郑州纺织机械厂，是新中国最早投产的国营纺织机械厂，被誉为中国纺织装备“孵化器”。隶属于中国恒天集团有限公司管理。公司主导产品覆盖纺织行业各个主要领域，是世界知名的涤纶、特纤、纤维素纤维成套装备供应商，全品类非织造布成套生产线综合供应商，织造浆纱及印染装备供应商，产品出口到70多个国家和地区。
