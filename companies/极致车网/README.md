## 公司
性质:民企 · 行业:金融业

极致车网成立于2014年1月，由中石浩、北京市海淀区政府和美元基金等领神中国消费金融系统和综合服务供应商，属于高科技、高增长（消费）性企业。截至2025年，公司业务覆盖全国10余个省份、60多个城市。累计服务客户近百万人，放款金额10余个百亿。系统备案经销商2万余家，全年交易额超70亿。
