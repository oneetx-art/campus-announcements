## 公司
性质:央国企 · 行业:通信/电子/半导体

吉林华微电子股份有限公司是集功率半导体芯片设计研发、芯片加工、器件封装测试及产品营销为一体的IDM（垂直整合）型功率半导体企业，是国家企业技术中心、国家博士后科研工作站、国家知识产权示范企业、国家级绿色工厂，拥有CNAS认可实验室，是行业内具有竞争力的领军企业。公司于2001年3月在上海证券交易所上市，股票代码600360，为国内功率半导体器件领域首家上市公司。
