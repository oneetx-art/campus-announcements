## 公司
性质:央国企 · 行业:机械/制造业

中国航天科工集团有限公司（以下简称航天科工）是我国国防科技工业的中坚力量，航天事业的建设者和国防装备建设的主力军。航天科工始终坚持国家利益高于一切的核心价值观，牢记“科技强军、航天报国”企业使命，坚定履行强军首责，实现高水平科技自立自强，坚持高质量发展。经过60余年的开拓创新、锐意进取、拼搏奉献，航天科工已成为一家战略性、高科技、创新型领军企业，航天科工总部位于北京，现辖属24家二级单位，近150家三级单位，600余家企事业单位，在职职工13万余人；拥有包括9名两院院士、70余名国际宇航科学院院士、300余名国家级科技英才在内的一大批知名专家、专业技术研究人员等。
