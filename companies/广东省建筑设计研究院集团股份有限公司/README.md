## 公司
性质:央国企 · 行业:房地产业/建筑业

广东省建筑设计研究院集团股份有限公司（GDAD）始建于1952年11月，是全国优秀勘察设计企业、科技先进院、高新科技企业、当代中国建筑设计百家名院、国务院国资委“双改”示范企业、广东省勘察设计行业领军企业、广州市总部企业、中国工程设计企业60强企业。现有博士后科研工作站、博士工作站、三家省级工程技术研究中心。
