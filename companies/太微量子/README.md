## 公司
性质:民企 · 行业:通信/电子/半导体

安徽省太微量子科技有限公司发源于中国科学技术大学，拥有涉及量子领域和精密仪器领域的核心技术和尖端人才。团队深耕于量子实验教学和高端精密仪器领域，量子实验教学包括量子阱、共聚焦单光子探测、冷原子磁光阱、飞秒激光等产品。高端精密仪器包括量子气体显微镜、高精度电流源、激光点扫描共聚焦显微镜等产品。目前产品已交付了国内外几十所高校、研究所等多家客户。应用的领域包括：量子数学科普、量子精密测量、生物医学检测以及计量检测等。
