## 公司
性质:央国企 · 行业:能源/化工/环保

青岛云路先进材料技术股份有限公司成立于2015年，2021年成功在科创板首发上市（股票代码：688190）。公司专注于非晶、纳米晶、磁性粉末等先进磁性金属材料的研发与制造，凭借产品在节能降碳方面的显著优势，广泛服务于全球电力装备、电机、光伏、家电、新能源汽车、人工智能AI、无线充电、电力电子用EMI滤波器、大科学工程等多个下游行业领域，并持续加大技术与人才投入，加速实现技术突破。作为全球非晶合金材料市场占有率第一的龙头企业，公司拥有从材料设计、工艺实现到应用拓展的全产业链能力，多项核心技术达到国际领先水平。云路股份致力于成为全球功率变换和电磁兼容领域材料解决方案的引领者，并为青年人才提供广阔的发展平台与成长空间。
