性质:央国企 · 行业:机械/制造业

中国航空工业集团有限公司（简称“中国航空工业集团”）是由中央管理的国有特大型企业，经营范围涵盖航空武器装备、军用运输类飞机、直升机、机载系统、通用航空、航空服务、航空文化等产业，下辖100余家成员单位、26家上市公司，员工逾40万人。陕西飞机工业（集团）有限公司创建于1969年，隶属于中国航空工业集团，被誉为“中国预警飞机摇篮”，中航工业重点保军企业，被列入《中国军民两用技术与产品大全》。公司是我国唯一研制生产大、中型军民用运输机、特种机的大型飞机制造企业。
