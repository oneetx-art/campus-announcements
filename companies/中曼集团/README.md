## 公司
性质:民企 · 行业:能源/化工/环保

中曼石油天然气集团股份有限公司（简称中曼石油，英文缩写ZPEC）成立于2003年，总部位于中国（上海）自由贸易试验区临港新片区，注册资本雄厚，是国内一流、国际知名的钻并工程承包商、石油装备制造商和高科技综合性能源公司。2017年11月17日，中曼石油在上海证券交易所挂牌上市，成功登陆A股资本市场（股票代码：603619）。中曼石油是国内首家通过挂牌方式获得石油天然气探矿权的民营企业，首家获得油气采矿许可证的民营企业，被自然资源部誉为企业参与国家油气体制改革的先行者和典范。2018年以来，公司深耕油气勘探开发领域，通过竞标和跨国并购方式，已拥有新疆温宿、哈萨克斯坦坚戈/岸边和伊拉克EBN/MA、阿尔及利亚Zerzait等6个油气区块的权益和勘探开发评估权。截至目前，获得各国政府批复超过15亿吨，其中在实施项目石油探明储量约2亿吨以上。
