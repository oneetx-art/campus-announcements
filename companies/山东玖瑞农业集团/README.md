## 公司
性质:民企 · 行业:农林牧渔

山东玖瑞农业集团成立于2013年，总部位于青岛，是国家高新技术企业、山东省农业产业化龙头企业、省级领军饲料企业。集团自成立以来，植根山东大地，逐步拓展湖北、四川、河南、东北、北京等地区，围绕种猪、种鸡、饲料、食品、终端消费，涉及生物技术及新型饲料添加剂、智能化养殖设备、智慧农业、供应链金融、互联网营销等多领域，秉承“玖耀农业，恒久为民”的企业理念，致力于打造从田间到餐桌、绿色健康、可持续发展的现代化产业|农牧食品生态体系。
