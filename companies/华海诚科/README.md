## 公司
性质:民企 · 行业:通信/电子/半导体

江苏华海诚科新材料股份有限公司成立于2010年，是一家专注于环氧塑封料、电子胶粘剂等电子封装材料的研发、生产与销售的高科技企业。公司先后荣获国家级专精特新“小巨人”企业、国家高新技术企业、首批国家专利产业化样板企业培育单位等多项荣誉。2023年4月4日，公司成功于科创板首发上市（股票代码：688535），成为国内环氧塑封料行业首家科创板上市企业。2025年9月1日，公司关于收购所华微电子有限公司事项获得上交所并购重组审核委员会审核通过。本次收购完成后，公司将进一步聚焦主业，优化产品结构与客户结构，提升国际竞争力与全球影响力。
