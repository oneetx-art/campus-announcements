## 公司
性质:央国企 · 行业:房地产业/建筑业

南京市市政设计研究院有限责任公司（简称南京市市政院），前身是上世纪六十年代可追溯，1985年正式成立，2003年完成事业单位转企，2014年被北控水集团收购，现已发展为江苏省市政设计行业龙头企业、国家高新技术企业。公司资质齐全，拥有城乡规划编制、工程设计行业市政多项甲级资质及多项乙级资质，业务覆盖城乡规划、交通工程、水环境、建筑工程等城乡建设全领域。公司高层次人才占比60%，教授级高工、高工50%，拥有多名行业资深人才及各类优秀人才。建院以来，公司累计获得国家、省市各级各类奖项700余项，综合实力位列全国市政设计行业前15位，拥有30余个创新平台，公布百余项知识产权，主编参编多项国家、省级标准，还斩获多项省市级荣誉，行业影响力突出。
