## 公司
性质:央国企 · 行业:机械/制造业

中国地质装备集团有限公司成立于1987年，是中央直接管理的国有重要骨干企业——中国机械工业集团有限公司的全资二级企业，是我国地质装备行业的发源地、国家队和主力军。中地装集团主要基于“国家资源能源安全重要保障力量，高精尖地质勘查装备行业引领者”核心功能定位，坚持以国家战略和行业发展为引领，面向资源、能源、环境三大服务领域，大力发展装备制造业务，形成钻采装备、物探仪器、分析仪器三大主导产品板块，覆盖地球物理勘探测量、地质钻探取心验证和地球化学分析测试等地质勘探主要流程。
