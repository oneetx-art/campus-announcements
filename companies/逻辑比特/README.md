## 公司
性质:民企 · 行业:通信/电子/半导体

杭州逻辑比特科技有限公司成立于2022年6月，专注于超导量子芯片的设计、制备与操控。依托在超导量子计算领域的深厚技术积累，公司已自主研发出高相干超导量子芯片、千比特级量子测控系统等核心产品。公司源自浙江大学超导量子计算实验室，先后发布“天目”“莫干”等世界领先的超导量子芯片，并三次刷新固态量子系统全局纠缠比特数的世界纪录。正如“逻辑比特”这一名称所寓意的，我们的目标是实现从物理比特到逻辑比特的跨越，推动超导量子计算走向实用化，打造世界一流的量子计算企业。
