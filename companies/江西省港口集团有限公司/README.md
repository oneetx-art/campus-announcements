## 公司
性质:央国企 · 行业:交通/物流/仓储

江西省港口集团有限公司主要经营范围为港口基础设施投资建设、港口码头、航电枢纽运营管理、港口和航运配套服务区、货物运输及物流贸易、港口及临港产业投资、港区土地开发利用以及经批准的其他业务。注册资本50亿元。截至2025年10月底，集团资产总额约346.46亿元，净资产139.61亿元，权属企业70余家，共有干部职工1300余名，企业信用评级为AAA。目前，集团聚焦主责主业，布局有港航物流、航电能源、工程建设和多元经营四大业务板块。
