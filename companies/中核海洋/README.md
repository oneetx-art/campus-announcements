## 公司
性质:央国企 · 行业:能源/化工/环保

中核海洋核动力发展有限公司由中国核能电力股份有限公司（含上海国营（集团）有限公司、江南造船（集团）有限责任公司、上海电气集团股份有限公司、浙江浙能电力股份有限公司五家股东共同出资于2017年在上海设立。中核海洋是中核集团海洋核动力产业平台公司，承担着我国海洋核动力产业发展的重要目标及中国核电核能多用途利用产业布局，助推我国海洋动力产业和核能新生海洋产业的高质量发展。公司的主要经营范围包括海洋核动力装备设计、开发、市场拓展、组织建造、热管理、海水养殖、动力装置及其生产的电力、热力、淡化水等相关产品，海洋核动力装备系统适用核技术专业领域内的技术咨询、技术服务、技术培训等。
