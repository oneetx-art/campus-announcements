## 公司
性质:央国企 · 行业:机械/制造业

中国重型机械研究院股份公司（原西安重型机械研究所），创建于1956年，是面向我国冶金、重型机械等行业的重大技术装备研发、设计与工程总承包的高新技术企业，现隶属于中央直接管理的国有重要骨干企业——中国机械工业集团有限公司，致力于服务国家重大战略，满足国家重大需求，攻克“卡脖子技术”与“短板装备”，实现国产化装备的智能化、高端化、绿色化。主要从事矿山重型、精炼、连铸、轧制、挤压锻造、环保装备技术研发和工程总包，提供工程咨询、机械工程监理、设计咨询、设备检测等专业技术服务。
