## 公司
性质:央国企 · 行业:机械/制造业

北京华能新锐控制技术有限公司（西安热工院北京自控部）是清洁能源控制与信息领域的一流科技研发企业，是国家级高新技术企业，也是全国电站过程监控及信息标准委员会（SAC/TC376）和电力行业热工自动化与信息标准参与多项本领域国家标准和行业标准制订。公司汇聚200余名高精尖人才，正式在册员工博士研究生占比86.2%，高级高精尖占比45%，拥有8名科技高端人才与3名高精尖技术专家。累计获得172项知识产权（含2项国际专利）；承担国家发改委、能源局、国资委等部委共计11项重大攻关项目；荣获中国电力科学技术进步一等奖、河北省科技进步一等奖等10余项省部级及全国电力行业科技进步奖；主要产品入选国家能源局“首台（套）重大技术装备”名单和国资委《中央企业科技创新成果推荐目录》。
