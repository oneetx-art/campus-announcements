## 公司
性质:央国企 · 行业:交通/物流/仓储

中国港湾工程有限责任公司（CHEC）是最早由中国政府批准设立的对外承包工程企业之一，公司正式成立于1980年，2005年重组成为中国交通建设集团的全资子公司，并代表中国交建全面开展海外业务。作为全球领先的工程承包商，投资运营商和城市发展商，中国港湾聚焦港口、道路桥梁、轨道交通、城市综合开发及生态治理等领域，典型管控建造一体化综合服务能力。
