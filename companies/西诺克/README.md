## 公司
性质:民企 · 行业:贸易/批发/零售

温州西诺克进出口有限公司成立于2010年10月10日，是一家专注隐藏式插座研发、生产与销售的工贸一体型企业。公司核心产品涵盖桌面插座、地面插座、轨道插座三大系列，凭借隐形设计与智能集成技术，获80多项专利。公司产品通过CB、TUV、UKCA、CE、UL、ETL、EMC、FCC、RoHS、Reach、GCC、SAA等100多项国际认证，业务覆盖100多个国家和地区，2017年，公司跻身乐清地区综合企业出口50强、商贸企业出口20强。
