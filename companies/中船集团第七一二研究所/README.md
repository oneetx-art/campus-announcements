## 公司
性质:事业单位 · 行业:机械/制造业

中国船舶集团第七一二研究所始建于1963年4月，主要承担船电电力推进系统及化学电源的研究、设计、制造、试验及总装总调任务。现有从业人员1800余人，其中国家级人才13人、省部级人才24人、集团公司级人才43人。拥有“电气工程”国家一级学科及四个专业博士学位授权点、“船舶化学电源技术”“船舶综合电力技术”两个专业博士学位授权点和“博士后科研工作站”。获得国家和省部级科技成果380余项，其中国家科技进步特等奖1项、一等奖3项，国防科技进步特等奖3项、一等奖8项，授权专利1200余项，其中发明专利900余项。
