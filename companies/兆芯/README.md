## 公司
性质:央国企 · 行业:通信/电子/半导体

兆芯是成立于2013年的国资控股公司，总部位于上海，在北京、西安等地设有子公司，拥有一大批具备硕士、博士学历的专职研发人员。兆芯掌握自主通用处理器及其系统平台芯片研发设计的核心技术，全面覆盖其架构与实现的专项研发人员。兆芯掌握自主通用处理器体系，截至目前已申请1600余件专利，授权近1400件。兆芯坚持“自主创新、生态完善、好用不贵”的发展理念，致力于为用户提供高效、兼容、安全的自主通用处理器及相关芯片等产品，构建从云计算到端自主生态体系，切实服务信息技术应用创新发展，同时坚持应用牵引，面向国内外公开市场的需求，着力为产业链持续创新注入转化外开放升级基础、需求，助力产业的构建“双循环”新发展格局，推动国民经济高质量发展。
