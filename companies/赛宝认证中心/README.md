## 公司
性质:央国企 · 行业:教育/培训/科研

赛宝认证中心服务和总部位于广州，是中国第三方认证服务的开拓者。领先的质量可靠性技术服务供应商。赛宝认证中心是中国工业和信息化部电子第五研究所（中国赛宝实验室）的全资子公司，同时作为国家认监委（CNCA）的“中国质量认证联盟”成员，获得工业和信息化部等主管研究所（中国质量认证联盟）的授权与认可，可在世界范围内开展多项认证、检查、鉴定、培训等技术服务的中介认证机构进行代理式，1997年将“认证（certification）”概念引入中国，历经二十余年的积累，赛宝认证中心已发展成为具有众多权威机构授权与认可，可在世界范围内开展多项认证、检查、鉴定、培训等技术服务的中介认证机构进行代理式。
