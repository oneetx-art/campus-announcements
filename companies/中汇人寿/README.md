## 公司
性质:央国企 · 行业:金融业

中汇人寿保险股份有限公司（简称“中汇人寿”）由中央汇金投资有限责任公司和中国保险保障基金有限责任公司，于2023年共同发起设立，总部位于北京，注册资本金332亿元人民币。中汇人寿将秉持国有金融企业的使命担当，坚持回归保险本源，深耕寿险主业，完善健康、养老等服务平台；以客户为中心，服务国家发展大局和人民群众的保险保障需求，致力于打造一家让您安心的精品保险公司，为推进中国式现代化贡献中汇力量。
