## 公司
性质:民企 · 行业:能源/化工/环保

福建古雷石化有限公司地处中国东南沿海的古雷半岛，成立于2016年11月3日，由福建炼油化工有限公司（50%）和旭腾投资有限公司（50%）按50:50的股比合资设立。公司主要负责古雷炼化一体化项目一期（500万吨/年重油催化热裂解）及公用工程的建设和运营工作，该项目是迄今为止一体化体量最大的石化产业综合体项目。
