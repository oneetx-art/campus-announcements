## 公司
性质:民企 · 行业:教育/培训/科研

昂立教育，1984年创办于上海交通大学，1993年6月在上海交易所挂牌上市（股票代码600661），成为中国A股市场第一家以教育培训为主营业务的上市公司，被誉为“国内教育产业A股上市第一股”。历经41年依旧朝气蓬勃的昂立形成了以素质教育、职业教育、成人教育和国际与基础教育四大板块并行的业务格局。目前在上海有100多个直营校区，全国1000余所合作学校和3700多名员工。展望未来，我们将坚守教育初心，遵循教育的本质，以为新时代赋能己任，以为国家培养人才为职责，努力为国家和社会交出一份满意答卷。
