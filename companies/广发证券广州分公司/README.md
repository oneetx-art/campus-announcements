## 公司
性质:民企 · 行业:金融业

广发证券是国内首批综合类证券公司，已实现A+H股上市（A股代码：000776，H股代码：01776-HK）。凭借深厚的专业底蕴与创新能力，在资本市场树立了'博士军团'的专业形象。成立以来，公司始终以客户需求为核心，深耕投资银行、财富管理、交易及机构客户服务、投资管理等核心业务领域，多次荣获行业权威奖项，是金融行业稳健发展与创新突破的代表企业。广州分公司是广州地区证券市场份额的领跑者，营业网点如同璀璨星辰，广泛覆盖全市各区，为本地企业与居民提供便捷、专业的金融服务。依托全企业牌照优势，分公司将数字化工具、数据分析等先进手段深度融入业务流程，无论是为大型企业设计定制化融资方案，还是为高净值客户打造专属资产配置计划，都能以高效、智能的服务满足客户多元化需求，在区域金融生态建设中发挥着重要作用。
