## 公司
性质:央国企 · 行业:机械/制造业

中国船舶集团有限公司第八研究院是由中国船舶第七二三研究所（扬州）和中国船舶第七二四研究所（南京）重组合并而来。在军品领域，首创性地将电子探测的“矛”与电子对抗的“盾”同时并举，打造电子战一体化系统，围绕电子探测、电子信息与对抗领三大研究，建设国兴电子对抗、预研电大专业院；新中智能高端装备、新材料产业板块，打造以战略新兴产业集群，旗下拥有的国家级战略新兴产业集团作为核心国家冠军企业1家，国家级“专精特新”小巨人企业1家，国家级“专精特新”企业3家，江苏省“省专精特新”企业3家，江苏省“超低保温技术与应用”重点实验室。产业集团被评为江苏省瞪羚企业。
