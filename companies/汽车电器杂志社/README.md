《汽车电器》创刊于1960年，由中国汽车工业工程有限公司主管，是国内创办最早、最具专业影响力的汽车电器与电子技术领域科技期刊之一。刊物面向汽车整车及零部件制造商、维修检测人员、科研院所及高校师生，致力于推动汽车电器技术进步与产业升级，目前已被中国知网、万方数据、维普数据库等主流学术数据库全文收录。
