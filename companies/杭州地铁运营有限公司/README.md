## 公司
性质:央国企 · 行业:交通/物流/仓储

杭州市地铁集团有限责任公司成立于2002年6月，是杭州市政府直属企业，从事杭州市轨道交通工程的建设、运营、开发、投资等业务，致力于“打造国内一流城市轨道交通综合运营商”。杭州地铁运营有限公司是杭州地铁集团下属的全资子公司，主要负责杭州地铁的运营维护、安全管理及新线运营筹备等业务。公司秉承以人为本的理念，视人才为推动企业成长与发展的核心竞争力，为员工提供广阔的职业发展平台，助力每一位员工成就理想、实现人生价值。
