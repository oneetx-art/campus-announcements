## 公司
性质:民企 · 行业:生活服务业

山东橙子便利生活有限公司于2017年9月在泉城济南注册成立。公司以“橙子便利”为核心品牌，持续聚焦山东市场，坚持做“小而美”的企业。自成立八年来，橙子便利立足济南，辐射山东，相继进驻济南、泰安、济宁、淄博、德州、聊城、滨州、东营、潍坊、烟台十地市，门店数量近500家。橙子便利是一家以便利店为载体，以供应链为支撑，数字化建设、品牌输出为一体的综合性零售企业，并连续多年入围全国便利店行业100强。
