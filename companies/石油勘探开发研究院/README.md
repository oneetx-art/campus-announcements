## 公司
性质:央国企 · 行业:能源/化工/环保

石油勘探开发研究院（“石勘院”）隶属于中国石化，是中国石化直属上游综合性研究机构。2000年7月，中国石化重组为上市油气勘探开发理论和技术的创新力、形成上中下游完整的科技工作体系，正式组建成立石勘院。目前，石勘院本部设在北京，并在无锡、合肥等地分别设立了研究所（中心）。本部办公地为昌平区百沙路197号院中国石化科学技术研究中心。
