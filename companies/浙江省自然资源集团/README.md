## 公司
性质:央国企 · 行业:政府/机构/组织

浙江省自然资源集团有限公司是经浙江省人民政府批准，在浙江省地勘事业单位分离改革中组建成立的省属国企，于2022年5月24日挂牌。集团有员工5700余人，下设浙江有色等14家二级子公司，全资和控股企业70余家，拥有建筑工程、市政公用工程、水利水电工程、矿山工程、公路工程施工总承包壹级资质十余项，地基基础工程、隧道工程、建筑装修装饰工程、钢结构工程施工专业承包壹级资质十余项，施工监理、工程勘察、人防工程设计、测绘、地质灾害防治等甲级资质近二十项，工程质量检测、检验检测机构认证、爆破作业单位许可证等专业资质近十项，服务涵盖资源勘查、实业安防、生态修复、工程建设等多个领域，拥有一批具有市场声誉的自有企业品牌。
