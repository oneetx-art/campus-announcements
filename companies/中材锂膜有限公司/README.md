## 公司
性质:央国企 · 行业:机械/制造业

中材锂膜有限公司是隶属于国资委直属央企、世界500强企业中国建材集团有限公司旗下中材科技股份有限公司，2016年3月在山东省滕州市注册成立。专业从事锂离子电池隔膜及技术研发、工程电池隔膜产品的研发、生产、销售及技术服务，公司主营产品为3-12μm湿法隔膜及陶瓷涂覆隔膜，应用于新能源汽车动力电池、3C消费电池、储能电池等领域。
