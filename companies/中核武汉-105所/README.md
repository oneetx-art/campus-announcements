## 公司
性质:央国企 · 行业:能源/化工/环保

核动力运行研究所（简称“105所”）成立于1982年，位于湖北武汉东湖新技术开发区。2007年，为把握核电快速发展机遇，105所作为主发起人成立了中核武汉核电运行技术股份有限公司（简称“中核武汉”），逐步构建“一所两制”模式，发展成为国内规模大、技术力量强的核电运行技术研究与技术服务专业化，是国际原子能机构、核安全局、能源局的主要技术支持单位，40多年来，为保障我国核安全、可靠、经济运行作出了突出贡献。
