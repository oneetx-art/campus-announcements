## 公司
性质:民企 · 行业:机械/制造业

城林科技（集团）公司，是一家从事事高端装备和声环境治理设备的研发、制造、安装及运维服务的国家级高新技术企业集团，在哈尔滨、上海、沈阳设有科研生产基地，在广州设有分公司办事处。集团总部坐落于哈尔滨经济技术开发区，占地面积2.98万㎡，注册资本金1亿元，以燃气轮机辅机系统、航空发动机试车台为核心动力系统，移动/备用电源、复杂声环境分析与控制等四大战略领域，业务覆盖能源动力、环保、航空航天等国家战略领域。
