## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

外语教学与研究出版社（外研社）由北京外国语大学于1979年创建并主办，是以外语教育出版为特色，国内领先、国际知名的综合性文化教育出版机构。以“记载人类文明，沟通世界文化”为使命，依托北外学术优势，探索教育服务转型与数字化融合创新，推动国际化布局与中外文化交流。
