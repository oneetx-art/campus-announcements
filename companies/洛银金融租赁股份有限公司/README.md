## 公司
性质:民企 · 行业:金融业

洛银金融租赁股份有限公司（以下简称“洛银金租”）作为中原银行子公司，成立于2014年12月，是全国第3家由城商行发起设立的金融租赁公司，也是河南省首家金融租赁公司。注册资本20亿元，总部位于河南省洛阳市，在郑州、上海、深圳、成都、长沙、西安设有6个业务部，业务范围覆盖中原和西南等具有发展潜力的地区以及华东、华中、华南等经济发达地区。
