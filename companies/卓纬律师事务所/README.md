## 公司
性质:民企 · 行业:咨询

卓纬律师事务所成立于2013年，致力于深度整合中国实践经验与国际专业视野，为复杂商事领域客户提供专业的法律服务。卓纬核心业务覆盖资本市场、金融市场、公司业务、国际商务、争议解决、反垄断与竞争法、知识产权、税务、私人财富、合规等多个领域，在银行与金融、证券、保险、人工智能与大数据、新能源、生物医药与大健康、航空经济与高端航运等领域有深入布局。卓纬坚持专业化、国际化、一体化服务理念，目前在北京、上海、深圳设立办公室，服务覆盖全国主要经济中心，持续布局全球商业生态，作为中国银行业协会首席合规顾问，能够为客户提供高质量专业服务，致力于成为兼具国际声誉与客户信赖的顶尖律所。
