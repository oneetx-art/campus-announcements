## 公司
性质:事业单位 · 行业:教育/培训/科研

中国科学院计算技术研究所（简称计算所）创建于1956年，是中国第一个专门从事计算机科学技术综合性研究的学术机构，培养了几百名硕士、博士等计算机专业人员，在这工作学习了几十名院士和千余名计算机专业人才，设有计算机体系结构国家重点实验室、智能处理器研究中心、泛在计算系统研究中心等多个国家级研究中心，形成了一支实力雄厚、梯队合理的战略科技骨干人才队伍。
