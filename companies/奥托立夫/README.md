## 公司
性质:外企 · 行业:汽车制造/维修/零配件

奥托立夫(Autoliv)于1953年成立于瑞典，是全球领先的汽车安全系统供应商，在全球25个国家建有生产和运营机构，拥有约6万5千名员工，为全球超过100个汽车品牌提供安全方案。奥托立夫致力于研发、生产和销售汽车安全系统，如安全带、方向盘、气囊、行人保护系统、集成式儿童座椅及断电安全保护开关等。
