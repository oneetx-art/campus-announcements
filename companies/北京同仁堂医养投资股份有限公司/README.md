## 公司
性质:央国企 · 行业:医疗/医药/生物

北京同仁堂医养投资股份有限公司(以下简称“同仁堂医养公司”)为同仁堂集团旗下二级集团，成立于2015年，前身是北京同仁堂投资发展有限责任公司、北京同仁堂医养产业投资集团有限公司，2024年6月顺利完成股份制改制，正式更名为北京同仁堂医养投资股份有限公司。 成立近十年来，同仁堂医养公司始终坚持以客户为中心，深耕医养大健康领域，以历史悠久的“同仁堂”品牌为依托，以坚实的产业基础为支撑，通过投资并购、合作共建、管理服务等方式，形成在北京、上海、山西、浙江、辽宁、贵州等地，有北京同仁堂中医院、同仁堂二中医院、上海承志堂、义乌三溪堂、酒仙桥社区卫生中心等20余家线下医疗机构布局，建成覆盖“连锁医院、基层连锁医疗机构、互联网医院”的分级诊疗服务网络，为客户提供现代化、定制化、一站式中医医疗服务。 未来，同仁堂医养公司将进一步发挥中医药在疾病治疗和预防养生过程中的独特优势，构建“中医+”特色服务体系，呵护生命健康，致力于成为国内领先的医养健康产业集团。
