## 公司
性质:央国企 · 行业:机械/制造业

宝鸡石油机械有限责任公司（以下简称宝石机械）是中国石油天然气集团有限公司的全资子公司，现已成为集研发、制造、服务于一体，销售与服务网络覆盖全球的综合性石油装备企业。宝石机械拥有7000米钻机、12000米电动钻机等核心技术装备，是国内唯一一家承担石油钻采装备标准化技术研究中心依托单位，是行业内唯一博士后科研工作站。
