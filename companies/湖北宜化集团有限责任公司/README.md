## 公司
性质:央国企 · 行业:能源/化工/环保

湖北宜化集团有限责任公司发源于1977年创建的宜昌地区化工厂，是宜昌市属重点国有企业，现有从业人员2万多人。在湖北、新疆、内蒙古、青海等地有30多家生产型子公司，控股上市公司湖北宜化(000422.sz)。拥有煤矿、磷矿、盐矿等矿产资源储量27亿吨，年开采能力达4000万吨。现有主导产品27种，化肥产品总产能500万吨，为中国绿色增值肥料引领者，化工产品总产能300万吨，其中PVC产能排名全国第五，季戊四醇产能排名全球第二、亚洲第一，为全球超过32个国家和地区提供优质产品和服务解决方案，多项产品跻身国内外第一品牌，成为全球信赖的中国制造。
