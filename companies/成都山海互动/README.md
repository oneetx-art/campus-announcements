## 公司
性质:民企 · 行业:IT/互联网/游戏

成都山海互动成立于2016年，位于高新区吉泰五路凯旋广场2栋603-604，现在规模80人左右，专注于3D模型制作，主营游戏、影视、数字人、元宇宙等数字娱乐平台的资产和产品制作。公司主要服务于腾讯、沐瞳科技、字节跳动、哔哩哔哩、游族、网易等一线游戏及动画厂商。参与制作过《王者荣耀》、《权利的游戏》、《阴阳师》、《晶核》等游戏项目。公司开发的《GIEF》元宇宙、成都交子商圈《OPENCITY》元宇宙，分别荣获2022、2023年成都元宇宙典型案例。同时也制作了《2023世界杯幻大会》、《3D北京琉璃厂》等元宇宙空间，开发了杜甫、杨雄等一些列中国名人数字人，应用于杜甫草堂及成都科幻馆。
