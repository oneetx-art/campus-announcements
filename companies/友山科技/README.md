## 公司
性质:民企 · 行业:能源/化工/环保

浙江友山新材料科技有限公司成立于2018年，是华友控股集团的全资子公司，注册资金5亿元。友山科技专注于磷酸铁锂的研发、生产与销售，主营产品涵盖磷酸盐系动力电池正极材料、储能电池正极材料等系列产品，在国内内蒙古、广西、贵州、云南及海外印尼等地建有八大生产基地，现有产能规模位居磷酸铁锂行业前三。
