## 公司
性质:央国企 · 行业:金融业

中信银行信用卡中心隶属于世界200强企业中信集团下属的中信银行，于2002年在深圳成立，是中信银行信用卡业务进行统一管理、集中操作、独立经营的专营机构。下辖77家分中心，业务覆盖23个省、5个自治区和4个直辖市；中心行已成立23年，发展至今，综合实力跻身国内信用卡中心行列。截至2025年8月末，中信银行信用卡累计发卡量突破126亿张，贷款余额4593亿元，位列股份制银行第二。
