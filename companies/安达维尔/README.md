## 公司
性质:民企 · 行业:机械/制造业

北京安达维尔科技股份有限公司（Andawell）是机载设备研制、航空维修、测控及智能设备研制、工业软件研发等为一体的航空航天领域解决方案综合提供商。公司成立于2001年，是在中关村国家自主创新示范区内注册的高新技术企业，于2017年在深交所创业板上市。
