## 公司
性质:外企 · 行业:通信/电子/半导体

美国泛达公司成立于1955年，总部设在芝加哥。公司经过多年的稳步发展，现已成为业界领先的网络及电气解决方案供应商。全球年销售额达8亿美金，拥有3000多位员工，业务遍及全球28个国家和地区。泛达通讯零部件（无锡）有限公司成立于1997年7月，主要产品为模块化电子插座、金属配线架、面板适配器、铜缆线、不锈钢扎带、布线机柜等。公司占地面积9000多平方米，现有员工300名。由于杰出的业绩，公司先后获得无锡新区“先进外商投资企业”、“优秀投资企业”，2002年至今年被评为“无锡市工业百强企业”。
