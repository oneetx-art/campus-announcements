## 公司
性质:央国企 · 行业:交通/物流/仓储

浙江省嘉兴机场管理有限公司，为浙江省机场集团有限公司的全资子公司，管理运营嘉兴南湖机场。嘉兴南湖机场（英文：Jiaxing Nanhu Airport，IATA代码：JNH，ICAO代码：ZSJX）位于浙江省嘉兴市，地处长三角城市群几何中心，是长三角世界级机场群的重要节点。机场定位为军民合用机场、客运支线机场、专业性航空货运枢纽，是长三角地区首个、全国第二个专业性航空货运枢纽，于2025年12月26日正式通航。
