中冶建筑研究总院有限公司（原冶金工业部建筑研究总院，简称中冶建研院），成立于1955年，是我国从事检验检测认证、建筑和环保技术研究、推广及应用的核心骨干企业。是中国中冶旗下11个骨干法人单位、15个金属子公司、4个控股公司、5个参股企业，在上海、深圳、厦门、新加坡等地均设有分支机构，全院员工5000余人。
