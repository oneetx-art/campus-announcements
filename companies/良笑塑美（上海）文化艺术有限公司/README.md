## 公司
性质:民企 · 行业:文化/传媒/广告/体育

良笑塑美（GSAS）是由日本手办御三家之一的GOOD SMILE COMPANY（GSC）于2018年在中国成立的全资子公司。GSAS在产品的设计制作、生产制造方面，采用与GSC相同的工艺流程与质量标准，依托GOOD SMILE品牌长久以来积累的模型制作和新品研发经验，致力于向海内外市场输送高品质的手办产品。GSAS集授权交涉、产品企划、原型制作、量产和终端销售于一体，积极与国内外动画、漫画、游戏、小说、影视等IP方展开合作。成立至今，已于众多国内外头部版权方达成合作，推出了近百款热门IP的手办产品。
