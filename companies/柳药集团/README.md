## 公司
性质:民企 · 行业:贸易/批发/零售

广西柳药集团股份有限公司是一家综合性医药上市企业，公司前身是1953年成立的柳州医药批发站，2012年改制为民营企业，2014年12月4日在上海证券交易所上市（股票代码603368）。公司经过七十多年在医药大健康领域的深耕细作，现已拥有以医药工业、形成以医药研发、医药零售、医药商业为主业，供应链增值服务协同发展的综合性医药大健康业务服务版图。医药互联网医疗、终端健康管理等创新医疗业务是集团的核心业务。
