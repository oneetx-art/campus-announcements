## 公司
性质:央国企 · 行业:能源/化工/环保

国核电力投资集团有限公司（简称“国家电投”）是中央直接管理的特大型国有重要骨干企业，拥有火电、风电、水电、核电、燃气、生物质、新能源等电力可再生能源装备、清洁能源整机设备供应商之一。光热发电设备等全部电源品种，是清洁低碳能源供应商与全球最大的光伏发电企业。国核湛江核电有限公司（简称“公司”）于2015年12月17日在广东省湛江市注册成立，由国家电力投资集团全资公司控股，负责国家电投在湛江开展的开发、投资建设、运营管理和建设，以及国家科技重大专项CAP1400先进核电技术的推广应用。目前，公司正积极推动湛江核电项目，项目规划建设两台百万千瓦级核电机组，总投资约1300亿元。一期工程规划两台单机容量为125万千瓦的核电机组，已于2023年9月27日正式开工建设，计划于2028年建成投运。
