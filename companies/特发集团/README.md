## 公司
性质:央国企 · 行业:政府/机构/组织

深圳市特发集团有限公司（简称特发集团），是我国改革开放、设立经济特区的历史产物。1981年8月2日，特发集团的前身深圳经济特区发展公司经广东省委和办公厅会议决议成立，是深圳最早的国有大型综合性企业集团和部分经济管理先驱。作为深圳国有企业改革的一面旗帜，特发集团先后推动了盐田港创立、南油集团、南山集团等一批特区早期大型集团公司的创立，孕育培植了深深房、万科、海王、华源、深国商、特发信息、特力、特发服务等七家上市公司。
