## 公司
性质:央国企 · 行业:房地产业/建筑业

中国化学工程第十六建设有限公司是国务院国资委管理的中国化学工程集团有限公司的全资子公司，是一家大型综合性建筑企业。石油化工工程施工总承包特级企业。公司始建于1965年，总部位于世界水电之都湖北宜昌，是集工程设计、高端咨询、技术研发、工程建造、建设管理、实业投资及生产试车、设备制造、物资材料供应、检维修、运营管理、产运服一体化的中央企业，注册资本20亿元。公司坚持走专业化、多元化、国际化发展道路，强力推进创新发展、转型发展、安全发展战略，始终秉承创新科技和管理、为客户提供期望的工程和服务、为利益相关方创造价值的宗旨，明势而为、合作共赢，建设成为行业内可持续高质量发展示范企业。
