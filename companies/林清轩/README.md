## 公司
性质:民企 · 行业:快速消费品

林清轩（02657.HK）创立于2003年，是高端国货护肤品牌。“以油养肤”理念开创者、“中国国货品部精华油首创者”。首创红山茶花系列护肤品，国内外“细胞级抗皱”产品的专业优秀代表。品牌以现代科技与植物特色相结合，构建从种植、研发、生产、销售的全价值产业链，并与上海交通大学共建细胞级抗皱研究平台。
