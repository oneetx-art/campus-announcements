## 公司
性质:央国企 · 行业:能源/化工/环保

国网吉林省电力有限公司是国家电网有限公司的全资子公司，以经营、管理、建设电网为主营业务。公司下辖9家地市供电企业、49家县供电企业、15家省业务单位、3家合资公司。吉林电网位于东北电网的中部，北连黑龙江电网，南接辽宁电网，西临内蒙古东部电网，是东北电网北电南送的重要通道，截至2024年连续实现第19个安全年。
