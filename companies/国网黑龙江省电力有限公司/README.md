## 公司
性质:央国企 · 行业:能源/化工/环保

国网黑龙江省电力有限公司是国家电网有限公司全资子公司、特大型国有骨干企业，承担着建设、运行维护黑龙江电网和全供电区安全可靠供电的任务。公司供电面积47万平方公里，占东北供电区域总面积的58.3%，服务各类客户1997万户，供电人口3062万。直接管理单位34个，其中地（市）级供电企业18个、业务单位16个，另有省合资公司3个。全网共有500千伏变电站19座、220千伏变电站158座。500千伏线路54回、总长7412千米，220千伏线路581回、总长17806千米。全省发电装机总容量5036万千瓦，系统最大负荷1848万千瓦。
