## 公司
性质:民企 · 行业:快速消费品

利郎集团成立于1987年，专注服装发展领域，是一家集设计、研发、生产、营销于一体的中国知名男装品牌。目前在全国拥有近2800家门店，2025年持续变革增长，上半年核心销售与效益双增长，总收入同比增长7.9%。集团发展至今，旗下拥有主品牌LILANZ、青年商务装品牌LESS IS MORE及传奇高尔夫运动品牌万星威（MUNSINGWEAR）的中国业务。2025年开启国际化进程，并于东南亚开设海外首店。利郎以“多品牌、国际化”布局协同发展，持续升级品牌力、产品力与创新力，为简约男装的无限遐想释放更多创新灵感。
