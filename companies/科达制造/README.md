## 公司
性质:民企 · 行业:机械/制造业

科达制造股份有限公司创建于1992年，于2002年在上海所上市（股票代码：600499），2022年7月，科达制造成为中国首批赴瑞士上市的四家企业之一。公司主要业务为建材机械、海外建材、新材料及新能源装备等。2024年公司实现营业收入126亿元，同比增长29%。其中海外收入超80亿元，归母净利润10.06亿元。公司员工超1.8万人，其中外籍员工超1.3万人。2025年第一季度，科达制造营业收入37.67亿元，同比增长47.05%。公司历史国家技术创新示范企业、国家知识产权示范企业、国家制造业单项冠军等殊荣，旗下多家子公司获国家专精特新“小巨人”称号，引领行业的技术进步。
