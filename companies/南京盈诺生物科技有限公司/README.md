## 公司
性质:民企 · 行业:医疗/医药/生物

北京星昊医药股份有限公司创建于2000年，是一家从事高端药物制剂研发产业化服务的创新型企业，并承担多个国家级科技和产业化项目，包括“十三五”科技重大专项、工业转型升级项目等，2023年在北交所上市，总资产约18亿元，员工700余人。南京盈诺生物科技有限公司为北京星昊医药股份有限公司全资子公司，作为长三角战略新布局，位于江宁高新区，规划总投资10亿元，建设国际化生物医药创新生态圈，打造15万平方米智慧园区，构建千余人才矩阵，建设先进实验室、智能化生产线及开放共享平台，公司被评为2024年度南京市重大产业项目。
