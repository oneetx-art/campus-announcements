## 公司
性质:民企 · 行业:机械/制造业

中航光电精密电子（广东）有限公司（简称“中航密”）成立于2015年，位于广州番禺，是中航光电科技股份有限公司（股票代码：002179）的全资控股公司，国有。企业，公司所在园区占地200亩，在职员工近1000人。公司立足于消费电子领域，拥有世界一流的精密模具设计制造能力及精密注塑、冲压零部件加工能力，是集研发、生产、销售和技术服务于一体的国家高新技术企业。公司主要生产新能源、通讯、消费电子、军用等领域连接器，公司产品广泛应用于液晶面板、通信、电力、轨道交通、新能源汽车等高端制造领域。公司秉承“忠诚奉献、自力更生、艰苦奋斗、勇攀高峰”新时代航空报国精神，践行“诚信、厚德”为核心的特色企业文化，致力于成为世界一流的精密模具解决方案及精密零组件提供商，并成为细分领域精密连接器主流供应商。
