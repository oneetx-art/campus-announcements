## 公司
性质:央国企 · 行业:能源/化工/环保

宏盛华源铁塔集团股份有限公司（简称“宏盛华源”），是中国电气装备集团有限公司所属的装备制造类子公司，是国内特高压输电线路铁塔制造骨干企业，也是国内铁塔行业第一家主板上市公司。公司主要从事输电线路铁塔的研发、生产和销售，产品覆盖全国32个省、自治区、直辖市以及全球90多个国家和地区，是国家电网、南方电网两大电网公司的主要供应商之一。
