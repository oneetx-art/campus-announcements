## 公司
性质:央国企 · 行业:能源/化工/环保

中国电力国际发展有限公司（简称“中国电力”）于2004年3月在香港注册成立，同年10月在香港联交所主板上市（股票代码：HK.2380），是中国境内首家香港红筹上市的电力央企，国家电力投资集团的核心子公司（简称“国家电投”）常规能源业务的旗舰企业和上市平台。中国电力秉承“低碳赋能美好生活”的宗旨，坚持“绿色赋能、智慧创新、共同成就”的理念，积极致力于建设世界一流的绿色能源供应商。
