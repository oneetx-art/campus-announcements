## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

海南省演艺集团是海南省委、省政府根据海南自由贸易港建设国家战略，整合全省优质演艺资源于2023年4月正式组建的省属国有文化企业集团，注册资本10亿元，旗下拥有多家文艺院团，运营多个文化演艺场馆，主营剧目创排、国内外剧目演出、剧场运营、旅游演艺、演艺设备、艺术培训、国际文化交流、大型活动策划执行等业务，先后承办多项省级重大文化活动，是海南文艺创作实力最强、演艺资源最集中、运营剧场规模最大的文化企业集团
