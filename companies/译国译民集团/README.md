## 公司
性质:民企 · 行业:商务服务业

译国译民集团成立于2003年2月27日，深耕翻译服务领域二十余年，业务网络覆盖全国，已在各地设立20余家分支机构。译国译民集团是全球语言服务行业前50强，入选中国翻译协会首批“译训工程”联合培养基地，是中国翻译协会理事单位（TAC）、美国翻译协会会员单位（ATA），是首批全国翻译专业学位研究生教育实习基地，已通过ISO9001质量管理体系、ISO17100口译服务体系、ISO14001环境管理体系及ISO45001职业健康安全管理体系等多项国际权威认证，亦荣获国家高新技术企业认证。目前，集团拥有专职员工300余人，签约国内专家译员逾10,000名，签约外籍译员超过5,000名。公司已形成“语言服务+学术出版”双轮驱动的发展模式，在北京、上海、深圳、香港设有营销中心，在福州、武汉、西安、济南、杭州、南京、沈阳等地设有翻译、培训和出版服务中心。服务范围遍及中国大陆、港澳台及东亚、东南亚、欧洲、北美等地区。作为中国翻译行业的标杆企业，译国译民集团始终致力于推动国际传播与文化出海，积极促进中外文化交流，助力企业客户拓展全球版图、实现国际化发展。
