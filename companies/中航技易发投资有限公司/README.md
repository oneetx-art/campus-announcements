## 公司
性质:央国企 · 行业:金融业

中航技易发投资有限公司（简称“中航技易发公司”），成立于2011年6月，注册资本金65000万元，是中国航空工业集团公司成员单位，隶属于中航技进出口有限责任公司，办公地址位于北京市经济技术开发区。公司核心业务涵盖写字楼运营、商业租赁、园区综合管理等领域，历经十余年发展，形成以商业写字楼租赁管理为主业、以品质提升为抓手的三位一体发展格局。
