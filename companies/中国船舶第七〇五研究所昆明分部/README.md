## 公司
性质:央国企 · 行业:机械/制造业

中国船舶第七〇五研究所始建于1958年，是我国唯一从事鱼雷及其发射装置总体研究所。昆明分部位于四季如春的昆明市五华区，地铁4号线大河埂站旁，是省级文明单位和花园式单位。占地300余亩，拥有较为完善的科研试验、生产设备设施和良好的办公条件。现有职工1000余人，承担多项国家重点型号研制和国防预研，专业从事水下攻防体系研究以及水下精确制导武器、水下无人航行器、水下智能装备、水下特种装备、水面水下发射系统等领域的技术创新、产品研发及生产。
