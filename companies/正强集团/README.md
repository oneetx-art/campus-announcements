## 公司
性质:民企 · 行业:机械/制造业

正强科技集团成立于2008年，是一家集研发、设计、制造、销售和服务为一体的综合科技型企业，深耕于电机和五金行业17余年，现有员工700余名。集团下属事业部7个（中山五龙、中山电机、东莞正哲、成都正强、惠州正强、东莞龙熙、海外营销），分布于中山、东莞、惠州、成都。集团目前的业务全面覆盖了“电机、电容、陶瓷制品、精密冲压与模具制造、精密电子、精密表面处理”等多个领域，已发展成为一家集“配件加工、电子元器件、精密部品、智能装备”为一体、深度为多个行业客户提供一站式产品和服务解决方案的多元化企业。
