北京首都科技发展集团有限公司（简称首发展或集团）是市科委、中关村管委会履行国有资产出资人职责的特殊功能类国有独资企业。集团成立于2014年，注册资本5亿元，由市科委按照市委市政府部署组建，成立以来，集团围绕服务北京国际科技创新中心建设的战略定位，坚持政府引导+市场化运营的方式推动重大原始创新成果在京转化落地，截至目前下属共有二级控股公司6家，在直投项目16项，管理基金投资项目80余项，子基金再投资项目3700余项
