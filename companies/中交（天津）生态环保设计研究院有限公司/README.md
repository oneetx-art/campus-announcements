## 公司
性质:央国企 · 行业:能源/化工/环保

中交（天津）生态环保设计研究院有限公司（称中交生态环保院）隶属于世界500强企业中国交通建设股份有限公司（简称中国交建），是具有120余年企业历史的中交天津航道局有限公司（简称天航局）的全资子公司。中交生态环保院是中国交建首家以生态环保为核心业务的设计企业，公司成立于1980年，前身为交通部天津航道局设计研究所。公司主要从事流域及水环境治理领域的项目包装入库、规划咨询、工程设计、岩土工程、测绘工程、水运工程海水淡化、环保技术研发应用、BIM技术的研究与应用等多项核心业务板块。拥有测绘、工程勘察、水运行业设计、工程咨询、环境工程设计五类甲级资质，具有对外承包工程资格，是集科研、设计、工程管理于一体的国家级高新技术企业。
