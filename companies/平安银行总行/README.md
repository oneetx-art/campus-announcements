## 公司
性质:央国企 · 行业:金融业

平安银行是一家总部设在深圳的全国性股份制商业银行（SZ000001），其前身为深圳发展银行，是中国内地首家公开上市的全国性股份制银行。平安银行坚守金融为本的初心，经过多年发展，已成长为一家经营管理成熟稳健、机构网点覆盖广泛、金融服务品类齐全、品牌影响市场领先的商业银行，在科技赋能、零售业务、综合金融等领域形成独特竞争力和鲜明经营特色。截至2025年6月末，在职员工40,761人（含派遣人员），通过全国10家分行，合计1134家营业机构为客户提供多种金融服务，以金融高质量发展助力经济高质量发展。
