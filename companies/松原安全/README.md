## 公司
性质:民企 · 行业:汽车制造/维修/零配件

浙江松原汽车安全系统股份有限公司是中国汽车被动安全领域领军企业。公司成立于2001年，2020年成功于深交所创业板上市。松原安全实施全球化布局，在中国长三角、东南亚及欧洲设有研发中心与智能生产基地，形成亚欧协同发展格局。公司专注汽车主被动安全融合，产品涵盖安全带、方向盘、安全气囊、安全电子以及全链路零部件产品，为全球主流整车厂提供全生命周期汽车安全解决方案。
