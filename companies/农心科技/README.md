## 公司
性质:民企 · 行业:农林牧渔

农心作物科技股份有限公司，成立于2006年，是一家集研发、生产和销售为一体的绿色农药A股上市企业（股票代码：001231），总部位于陕西省西安市高新区。公司秉承“健康作物，品味生活”的使命，坚守“守正出奇，共同成长”的价值理念，致力于作物的健康成长，为农户提供优秀的作物解决方案。公司拥有两大生产基地：农药制剂生产基地——陕西上格之路生物科学有限公司，原药生产基地——陕西一简一至生物工程有限公司。
