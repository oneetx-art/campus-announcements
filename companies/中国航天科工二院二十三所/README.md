## 公司
性质:事业单位 · 行业:机械/制造业

中国航天科工二院二十三所组建于1958年11月24日，是我国地空导弹制导雷达的摇篮，我国最高水平的制导雷达研究所。二十三所以雷达系统工程及电子信息技术为专长，主要从事雷达空间目标监视、预警雷达、气象雷达、空天基雷达、测量雷达、雷达电子对抗装备和相关电子产品、元器件的研发生产，先后承担我国重要武器装备研制生产任务，始终站在我国雷达技术发展的最前沿。经过不断创新发展，二十三所已成为专业配套齐全、探索一代、预研一代、研制一代、生产一代，保障“一代”目标的完善的中国雷达行业领军企业，形成了以北京本部为核心，产品实现系列化、专业化。打造的良性质发展格局，京津冀地区、湖北地区、环太湖地区三大产业集群，成都、西安、武汉等多地研发机构协同发展的企业架构，先后培养中国工程院院士3人，高级职称人员近千人，多人享受政府特殊津贴，累计荣获国家发明奖、国家科技进步奖、省部级奖项500余项，多项成果填补国内空白、居于国际领先地位。
