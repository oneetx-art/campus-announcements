## 公司
性质:事业单位 · 行业:教育/培训/科研

中国人民大学中国调查与数据中心（NSRC）是中国人民大学的校级直属科研机构。从2008年成立以来，以数据采集、数据存储、数据开发为主要方向，致力于建设大规模、成体系、全方位、多层次、连续性的社会科学基础数据平台。中心常年执行中国综合社会调查（CGSS）等大型连续性调查项目；运行与维护着中国国家调查数据库（中社科ADa）的年度发布和中国发展指数（RCDI）。
