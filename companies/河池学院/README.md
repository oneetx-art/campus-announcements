## 公司
性质:事业单位 · 行业:教育/培训/科研

河池学院前身是创建于1951年的广西省宜山师范学校，2003年4月建立，实行自治区与河池市共建、以自治区为主的管理体制。现有全日制在校学生近17000人，教职员工1000多人，设有13个二级学院，51个本科专业，涵盖9大学科门类，被誉为“桂西北中小学教师的摇篮”等，聚焦转型发展、产教融合、校企合作，力争到2035年建设成为国内知名区域高水平地方应用型大学
