## 公司
性质:央国企 · 行业:金融业

新产投集团成立于2019年1月，由原辰能集团、中盟集团、科力公司重组设立，是黑龙江省首批国有资本投资公司改革试点企业，为省级战略性新兴产业和未来产业投资及资本运营平台，承担战略性新兴产业和全省加快发展新生产力重大战略功能，现已形成创业投资、基金投资、清洁能源、创新战略、特种制造、化工新材料、资产管理、生物质发电、地产开发、研究院十个专业化平台的发展格局。截至2025年末，集团注册资本69.04亿元，资产总额353.43亿元，各级企业89户，控股两家上市公司，管理及参股基金34支，总规模近200亿元，占全省四分之三，员工9161人，连续五年获得省委考核优秀等次和省国资委经营业绩考核A级评价。集团围绕12348发展战略，打造国内一流竞争力的国有资本投资运营公司，为黑龙江全面振兴全方位振兴贡献新产投力量
