武昌船舶重工集团有限公司（简称武昌造船），地处大汉长江之滨，是中国船舶集团有限公司旗下大型现代化造船企业，是我国船舶及国防工业的重要骨干厂。始建于1934年，底蕴深厚，前身为武昌机厂，武昌造船历史是国家‘一五’计划时期156个重点建设项目之一。
