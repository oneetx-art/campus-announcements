## 公司
性质:央国企 · 行业:房地产业/建筑业

中国水利水电第九工程局有限公司（以下简称“水电九局”），成立于1958年，总部坐落在贵州省贵阳市，隶属中国电力建设集团有限公司。水电九局集施工、设计、科研、投资于一体，拥有资质的数量和类别在国内建筑类企业中处于领先地位：具备“双特三壹”“五甲”资质，即水利水电工程、建筑工程施工总承包特级资质，矿山工程、市政公用工程及水利工程（河道整治、水库枢纽、灌溉排涝）专业甲级五项工程设计甲级资质。
