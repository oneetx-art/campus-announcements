## 公司
性质:央国企 · 行业:金融业

四川银行股份有限公司（以下简称四川银行）是四川省首家省级法人城市商业银行，注册资本金300亿元，位居全国城市商业银行前列。四川银行坚持“服务地方经济、服务中小企业、服务城乡居民”的市场定位，遵循“客户导向、合规为上、智慧引领、支撑成渝双城经济圈建设和战略性新兴产业，培育具有成渝双城经济圈发展特色的新兴金融服务品牌，成为四川高质量发展的金融主力军。四川银行在川营业网点151家，已在成都、眉山、乐山、攀枝花、自贡、泸州、内江、达州、南充、凉山、广安、宜宾、广元、巴中、雅安设立分行，并将逐步增设分行。
