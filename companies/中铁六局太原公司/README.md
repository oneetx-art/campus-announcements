## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁六局集团太原铁路建设有限公司是世界500强企业中国中铁旗下的三级子公司，隶属于中国中铁六局集团有限公司。公司前身为原杏花岭区，注册资本金5.5亿元。其前身为太原铁路局太原基本建设施工处，始建于1953年，是一家拥有七十多年历史的国有大型建筑施工企业。
