## 公司
性质:央国企 · 行业:金融业

紫金财产保险股份有限公司（简称“紫金保险”）成立于2009年5月，总部位于南京市，是江苏省首家全国性财产保险公司，注册资本60亿元人民币。紫金保险作为江苏省财政厅主管的国有大型金融企业，覆盖全国21个省份，拥有25家省级分公司，铺建构逾500家，员工队伍7000余人。公司总资产超235亿元，保费规模站稳百亿平台，连续三年被惠誉国际授予A-（强劲）财务实力评级，连续五年获得保险公司经营评价A，监管综合风险评级保持AA以上。公司致力“服务地方高质量发展和人民高品质生活”，牵头承保江苏惠医保和多个重大产业保险项目，首创道路交通事故救助基金管理“紫金模式”，先后获得“中国价值成长性十佳保险公司”“卓越竞争力财险公司”等荣誉，形成了江苏有优势、华东有影响、全国有特色的紫金保险品牌，综合实力位列地方国资金企三甲。2025年正值“十四五”收官、“十五五”谋划的关键节点，公司锚定“高标质量增长，以“三力五心”打造质下紫金，保持高速目标，多项经营指标创历史新高，展现强劲发展势头，为综合竞争力在“十四五”末期跻身前全国十实现良好开局。
