## 公司
性质:社会组织 · 行业:政府/机构/组织

四川长江经济研究院（简称“长研院”）是由四川泸州（长江）经济开发区和市属重点国有企业泸州临港投资集团有限公司于2014年10月筹建成的省级社科研究机构，是川南地区唯一的AAA级经济研究智库机构，是泸州市唯一以经济研究为主研方向的重点哲学社科研究基地——“川南区域经济研究中心”。长研院聚焦“咨询服务”和“培训服务”两大核心业务，主要承接政企事业单位的中长期发展规划、园区规划、重大招商引资项目/投资项目可研、项目融资可研、项目投后评价、产业/产业链规划、社会治理研究、人力资源规划/组织效能评价、专家讲座/主题论坛、企业定制培训、公开课、定制研学等。
