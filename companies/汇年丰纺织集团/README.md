## 公司
性质:民企 · 行业:快速消费品

汇年丰纺织集团专注于生产各类针织面料，从时尚前沿到流行趋势，集研发、织造、染整、销售于一体。旗下睿邦科技产业园整合了自营织造中心以及现代化染整中心，且有新定义面料可供应，研发战略新，快速响应不同市场需求。集团现有三大品牌：“HNF汇年丰”、“REBORN睿邦”、“华丰”，形成以“中高档” 女装、男装、休闲、运动、针织面料为骨架的系列产品。其中国各地叠加面料销售，市场占有率领先。汇年丰不仅在中国针织面料华南、华北、华中地区设有分公司，且业务已拓展至海外市场如欧盟、中亚、东南亚、东欧等15个国家。全球年销量约20亿，年现产值约50万吨以上。
