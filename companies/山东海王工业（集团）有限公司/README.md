## 公司
性质:民企 · 行业:机械/制造业

海王公司成立于1989年，集团旗下拥有海王旋流器、海王科技、九州天承、国德新材料、麦安矿机等多家高新技术企业。36年来，海王公司致力于为矿山、煤炭、砂石建材、电力、环保等资源、能源行业提供旋流器、智能化分选机、智能干选机、智能传感器/智能执行器/智能化系统、耐磨管道/膏灌/清浆/阀门/非标设备/耐磨件等系列产品，成套装备和一站式技术解决方案，服务于全球5大洲70多个国家和地区10000家用户。
