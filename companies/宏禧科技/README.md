## 公司
性质:民企 · 行业:通信/电子/半导体

浙江宏禧科技有限公司是一家从事硅基OLED微型显示器研发与制造的高科技企业，总部位于浙江省义乌市，目前拥有上海浦东、安徽滁州等生产（研发）基地。公司产品主要应用于拓展显示（XR）、电子取景器（EVF）等前沿科技领域。宏禧科技是高新技术企业、浙江省科技型中小企业、浙江省创新型中小企业、浙江省示范性重大产业培育发展项目、义乌市上市挂牌后备企业。目前已建成国际领先的12英寸硅基OLED生产线，拥有从驱动芯片设计到微型显示器蒸镀封装工艺的全环节技术和管理团队，技术团队研发与量产经验丰富。
