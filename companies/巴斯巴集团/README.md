## 公司
性质:民企 · 行业:能源/化工/环保

巴斯巴科技集团成立于2010年，以Ebusbar科技成就美好未来为企业愿景，是一家集新能源汽车充电设备研发、生产、销售和服务为一体的国家高新技术企业。公司集研发、生产、销售为一体，位居行业前列，在江西吉安、贵州、深圳等地设有基地。巴斯巴科技集团拥有12大产品线，包含电子、充电桩、高压配电盒、大电流产品、充电枪、充电线等，是新能源汽车充电系统的全球领先者。
