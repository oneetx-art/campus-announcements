## 公司
性质:央国企 · 行业:机械/制造业

中国船舶集团有限公司第七〇九研究所（以下简称七〇九所）1956年组建创建，成立初期隶属于中国科学院，是中国科学院中创建数字计算机技术及自动化学科最早的单位之一，是中国最早从事计算机研究的单位。自动控制和数学理论研究与开发。从自主研制作战片为使命，以自主、系统软件为统一体化整体解决方案的国家重点综合性研究所。
