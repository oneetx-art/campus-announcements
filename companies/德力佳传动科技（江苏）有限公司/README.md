## 公司
性质:民企 · 行业:机械/制造业

德力佳传动科技（江苏）有限公司于2018年落户无锡山经济开发区，注册资本1.25亿元，主要从事风电关键核心设备-风电增速机和齿轮箱的研发与生产。公司积极响应新时代风电行业发展需求，紧盯风电绿色清洁能源装备领域，努力将绿色清洁能源装备产业优势转化为高质量发展优势。先后荣获“无锡市企业技术中心”、“无锡市瞪羚企业”、“高新技术企业”、“无锡市先进制造业和现代服务业深度融合试点”等称号。
