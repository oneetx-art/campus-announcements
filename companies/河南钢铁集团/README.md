## 公司
性质:央国企 · 行业:能源/化工/环保

河南钢铁集团有限公司（以下简称河南钢铁集团）成立于2023年3月1日，是河南省省委省政府为推动全省钢铁产业整合重组和钢铝钢铁产业融合发展，以安阳钢铁集团为主体，组建成立的特大型冶金产业集团。河南钢铁集团的核心企业——安阳钢铁集团有限责任公司，始建于1958年，是新中国第一批重点建设的钢铁企业，经过60多年的砥砺前行，现已发展成为安阳、周口两大钢铁基地比翼齐飞，矿产资源、绿色铸造、节能环保、数字信息、物流贸易等多元产业协同发展的千万吨级特大型钢铁集团，主要产品涵盖中厚板、型棒材、热轧卷板、冷轧卷板、高速线材等多个品种，广泛应用于国防、交通、装备制造、船舶平台、石油管线等领域，是中原地区最大的精品板材和优特钢生产基地。2024年，洛阳铜加工集团有限责任公司正式纳入河南钢铁集团。
