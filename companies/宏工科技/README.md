## 公司
性质:民企 · 行业:机械/制造业

宏工科技股份有限公司（证券代码：301662）成立于2008年，是一家集研发、设计、生产、销售与软件开发为一体的物料处理自动化综合服务商。公司创立以来一直秉承着“让物料处理更简单”的初心，聚焦物料处理和工业自动化，致力于为食品、医药、橡塑、精细化工、电池匀浆、锂电新材料等行业提供一站式的物料综合处理解决方案。截至目前，公司已在德国、美国、匈牙利等多个国家开设分公司，致力于构建全球市场的经营格局。
