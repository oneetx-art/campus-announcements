## 公司
性质:事业单位 · 行业:教育/培训/科研

中航工业第一飞机设计研究院，是中国航空工业集团有限公司直属的集歼击轰炸机、轰炸机、民用飞机、运输机和特种飞机设计研究于一体的国家大中型飞机设计研究院，是中国航空工业集团有限公司内陕西首家获得综合认证的“国家高新技术企业”和“国家级国际科技合作基地”。拥有国家认定企业技术中心、国家工业设计中心、国家级引智示范基地等13个国家级创新平台。先后成功研制试和装备我国多型飞机，是我国唯一一型具有里程碑意义的中型预警机——空警一号、第一架歼击轰炸机——“中国飞豹”、第一架支线客机——新舟60飞机、第一架中远程运输机——运8系列飞机、第一架大型运输机——运20飞机的安全责任单位。
