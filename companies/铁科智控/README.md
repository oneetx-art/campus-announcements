## 公司
性质:央国企 · 行业:IT/互联网/游戏

广州铁科智控有限公司成立于2017年12月7日，作为轨道交通信号领域全产业链覆盖的技术产品与服务供应商，公司以自主知识产权的MTC-Ⅰ/CBTC信号系统为核心，打造覆盖城轨、市域铁路、中低速磁浮及有轨电车等多种制式的全场景解决方案，已成功实现广州、重庆、大连、长沙、清远、丽江等城市轨道交通项目的全功能交付与安全运营。
