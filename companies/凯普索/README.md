## 公司
性质:民企 · 行业:能源/化工/环保

凯普索绿色能源科技（南京）有限公司是一家专注于绿色化工与可持续发展解决方案的高新技术企业，总部位于南京市。公司自2017年起致力于研发小型化、数智化的集装箱式绿氨装置，已获多项国际专利认可，项目管理体系通过ISO9001质量管理等多项国际认证。2020年，凯普索成功交付全球首座绿氨工厂。在其他Power-to-X领域，凯普索参与了全球首个商业级绿色甲醇项目。目前，公司业务已覆盖全球百余家国家和地区，如美国、加拿大、巴西、哥伦比亚、丹麦、挪威、澳大利亚、意大利、纳米比亚等。公司秉持“以德驭才、创新求变、合作共赢”的企业文化，期待优秀的你加入，与我们一同为“创造绿色无碳美好生活”贡献一份力量！
