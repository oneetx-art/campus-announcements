## 公司
性质:民企 · 行业:能源/化工/环保

双杰集团（股票代码：300444）成立于2002年，立足配电领域，深耕电力行业。数字平台等新能源板块均有布局，下设60余家分子公司，在北京、安徽合肥、江苏无锡、湖北黄冈、内蒙古呼和浩特、内蒙古赤峰和新疆昌吉均设有先进生产基地及研发中心。在各基地的协同分工下，双杰等20余个覆盖全国各省及大部分市县，产品远销欧、美、非等20余个国家和地区，年销售额近百亿。
