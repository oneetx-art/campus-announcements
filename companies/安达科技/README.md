## 公司
性质:民企 · 行业:能源/化工/环保

贵州安达科技能源股份有限公司主要从事磷酸铁、磷酸铁锂的研发、生产、销售，主要应用于锂离子电池正极材料；2015年被列为贵州省第二批“100户成长型企业”；2018年通过国家高新技术企业认证；2021年成为中国无机盐工业协会磷酸铁锂专业委员会主任单位，并获评“动力电池正极材料行业单项冠军产品”；2023年被评为“国家级专精特新小巨人企业”。
