## 公司
性质:央国企 · 行业:通信/电子/半导体

成都中电锦江信息产业有限公司（以下简称“公司”）始建于1954年，是中国电子信息产业集团有限公司的全资子公司。公司是西部地区唯一的专业从事军用电子管雷达行等高科技企业，是国内地面雷达行业综合实力名列前茅的军工电子骨干企业，是中国天气雷达发源地，也是我国军民两用新一代天气雷达的主要供应商。
