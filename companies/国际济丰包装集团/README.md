## 公司
性质:民企 · 行业:机械/制造业

国际济丰包装集团，深耕东北（沈阳、大连）、华北（天津、青岛莱西）、华东（苏州含太仓、常熟、吴江、相城，嘉兴桐乡、湖州、南京、滁州）、华中（孝感）、华南（惠州、佛山）及西南（重庆）六大区域，稳健运营16家现代化工厂。同时，我们正积极筹备在成都、郑州、长沙、西安、南昌、太原增设新基地，以进一步扩大全国布局。我们专注于高端瓦楞纸箱、展示架等包装解决方案，各工厂均配备先进生产线，确保产品质量卓越，满足市场多样化需求。我们不仅是经济效益的追求者，于2018年在香港主板成功上市（股票代码：01820.HK），更是环保先锋，自2009年起，我们率先实现碳中和，累计减排超53.50万吨，通过“济丰杯”设计大赛激发环保创意，引领绿色包装潮流。人才是发展基石，自2005年起，我们持续开展校园招聘，已吸引并培养了超过300名优秀大学生，为他们提供实践舞台、系统培训及广阔职业路径，实现个人与企业共同成长。
