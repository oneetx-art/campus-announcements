## 公司
性质:央国企 · 行业:房地产业/建筑业

中国电子工程设计院股份有限公司(CEEDI)创建于1953年，先后隶属于电子工业部、信息产业部，2003年由国务院国资委管理，2009年并入国家开发投资集团有限公司，是一家拥有工程设计综合甲级资质等三十余项国家顶级资质的综合大型设计院。建院70余年，在服务国家电子信息产业及其重大战略中发挥重要支撑作用。CEEDI以设计为龙头，拥有电子工程行业领先的核心技术优势，聚焦电子信息产业和智慧城市建设等领域，提供全生命周期的一体化服务。服务范围涵盖：投资咨询、规划咨询、工程设计、工程采购、工程施工、专项承包、检验检测、运营维护。
