## 公司
性质:民企 · 行业:通信/电子/半导体

杭州长川科技股份有限公司成立于2008年4月，是一家致力于提升集成电路专用装备技术水平、积极推动集成电路装备业升级的高新技术企业。公司于2017年4月17日在深交所创业板挂牌上市，员工超4000人，研发人员占比50%以上，拥有海内外授权专利超1100项，在国内外多地设有分支机构，形成全球化布局，先后被认定为多项企业荣誉。
