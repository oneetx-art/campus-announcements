## 公司
性质:央国企 · 行业:能源/化工/环保

中石化宁波工程有限公司隶属中国石化，位于浙江宁波。作为集团公司，主营业务涵盖长流程完整的综合性工程服务商，主营业务包括长周期工艺研发、工程咨询、工程设计、EPC总承包、施工总承包和装备制造等，服务领域覆盖石油化工、煤化工、天然气及精细化工、战略新兴产业、绿色环保和数智化等。坚持实施“科技先行+市场先行”科技创新发展战略，公司具有教育部留学服务中心派遣资格的国企，为全球客户提供全生命周期的一站式整体解决方案。
