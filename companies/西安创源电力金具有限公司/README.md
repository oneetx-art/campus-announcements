## 公司
性质:央国企 · 行业:机械/制造业

西安创源电力金具有限公司生产经营场所位于陕西省西安市鄠邑区，于2000年8月经陕西省电力公司批准成立，现为中国能源建设集团(股份)有限公司的全资子公司，陕西省高新技术企业。公司主要从事1000kV特高压交流、±1100kV特高压直流及以下（电压等级）输变电金具的研发、生产与销售，具有多条国家特高压重点工程的履约供货业绩，是国内特高压电网电力金具行业主流生产厂家之一。
