## 公司
性质:央国企 · 行业:通信/电子/半导体

哈尔滨电机厂有限责任公司始建于1951年，是哈尔滨电气集团有限公司的核心子企业。公司已成为国内领先、世界一流，为中国乃至全球能源电力行业提供系统性、一体化、全生命周期产品方案和服务的设备制造商、运维服务商、系统集成商，形成了“水、火、核、气、风”协同发展的产业格局。公司在水电、数字孪生及智能运维技术等方面均有专业影响力。公司下设哈尔滨大电机研究所有限公司、哈尔滨电机厂(镇江)有限责任公司、哈尔滨电气集团海洋智能装备有限公司等子公司。
