## 公司
性质:央国企 · 行业:房地产业/建筑业

江西水投集团是经江西省人民政府批准，于2008年3月成立的依法履行出资人职责、根据省政府授权的大型国有独资企业。江西省国资委代表省政府履行出资人监管职责。经过17年的发展，集团已由省委、省政府的水利投融资平台发展成为涵盖五大板块的省属重点企业。
