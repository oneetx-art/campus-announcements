## 公司
性质:民企 · 行业:咨询

正略集团是以战略咨询业务为核心的管理咨询服务机构，在咨询行业内广受赞誉，被誉为中国咨询业的“黄埔军校”。自1992年11月11日创办至今，秉承“学无罔，思无殆，言有物，行有恒”的核心价值观，践行“竹文化”，咨询中国，智惠四海。经过三十余年的不断探索与实践，正略集团已为500强企业、国企央企、规划公司到独角兽公司、上市公司等客户，提供从规划方案到落地实施的全过程专业服务。正略集团总部位于北京，在全国多地设有全资子公司。
