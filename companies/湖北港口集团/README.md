## 公司
性质:央国企 · 行业:交通/物流/仓储

湖北港口集团有限公司是湖北省属国有企业。作为湖北省港口航运投资、建设、运营主体，集团以建设长江中游航运中心和多式联运国家物流枢纽为使命，致力于加快建成国内一流航运枢纽、一流港口企业、一流开放通道。在省委省政府坚强领导下，集团构建了“以一港一园”为龙头，鄂东南、宜昌荆州战略，构建“以武汉为龙头，鄂东南、宜昌荆州为两翼，汉港为延伸”的一体化发展格局，辐射全国、衔接日韩、联通欧洲、连接东盟的联运网络，形成了港口服务、综合物流、临港园区建设开发运营三大业务板块。
