## 公司
性质:民企 · 行业:医疗/医药/生物

福建广生堂药业股份有限公司创建于2001年，是专注于肝病治疗药物领域的国家级重点高新技术企业，也是目前国内唯一拥有五大抗乙肝病毒临床优选用药的企业。公司下设多个子业务单元，涵盖肝病、男科、呼吸、心血管、中成药等领域。广生堂药业于2015年成功上市（股票代码：300436），是福建省第一家在A股上市的民营医药制造企业。
