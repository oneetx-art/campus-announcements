## 公司
性质:民企 · 行业:机械/制造业

创建于1954年，原为机械工业部直属的综合性科研机构，1999年转制为中央二级科技型企业；服务国家重大战略，承担了多项国家攻关任务；总部设在北京，建有怀柔中试验证基地，常州、湖州市生产基地；拥有八个研究开发事业部、五个控股公司、七个创新平台、两个检测实验室；依托有国际仿生学标委会（ISO/TC266）、全国机器人标委会（SAC/TC591）等16个国际、全国性行业组织；拥有博士后科研工作站和两个专业的硕士学位授予点，编辑发行两本学术期刊。
