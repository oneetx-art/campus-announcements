## 公司
性质:民企 · 行业:IT/互联网/游戏

新大陆软件公司成立于2002年，总部位于福建自贸区，是新大陆科技集团成员企业，连续21年被评为中国软件百强企业，公司信用等级连续9年被评定为AAA级，是国家创新型企业、国家规划布局内重点软件企业、福建省高新技术企业，拥有涉及国家秘密的计算机信息系统集成甲级资质与通过CNAS国家实验室认证的软件评测中心。公司通过了CMMI5级认证、数据治理服务商能力成熟度四级评估及数据管理能力成熟度（DCMM）四级乙方认证，信息系统建设和服务能力达CS4（优秀级），并作为主要参与者之一，推动了国家DataOps成熟度评估标准制定。公司在职员工逾2500人，研发交付人员占比超90%，公司在大数据、云计算、人工智能应用开发等领域拥有先进、自主可控的核心技术，致力于为客户提供全方位、电信级、端到端的数智化解决方案。
