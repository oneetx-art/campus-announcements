## 公司
性质:央国企 · 行业:房地产业/建筑业

湖南路桥建设集团有限责任公司始建于1954年，作为国家基础设施建设领域的骨干力量，系湖南省属国有重要骨干企业，现隶属于湖南建设投资集团。该公司业务覆盖高速公路、市政工程、轨道交通等基础设施建设领域，是集投资、建设、运营于一体的综合性交通基础设施服务商。
