## 公司
性质:事业单位 · 行业:教育/培训/科研

北京空天技术研究所隶属于中国航天科工集团第三研究院，是国家为满足航空、航天技术领域发展需求而组建的开放性单位，围绕强化国家战略科技力量，聚焦航空航天总体研发平台，是国内临近空间与空天飞行器研究的总体单位，空间飞行器、新概念飞行器三大研发方向，汇集总体设计、结构与强度等六大核心动力系统与能源、制导控制、气动热与热管理等六大核心专业，带动起降总体、轨道运行等10个新兴、专业武器发展。建立空天飞行器全国重点实验室，牵引全国80余家优势单位开展空天技术全面重点实验室，牵引全国80余家优势单位开展空天技术原创领域高水平科技自立自强。推动加快实现临近空间与空天飞行器等关键科技自主。
