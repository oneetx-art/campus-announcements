## 公司
性质:央国企 · 行业:农林牧渔

中国内蒙古森林工业集团有限责任公司（简称内蒙古森工集团），是内蒙古自治区直属特定功能类国有企业。受国家林业和草原局委托，经营保护着我国面积最大、集中连片的重点国有林区，生态功能区总面积10.67万平方公里，横跨呼伦贝尔市、兴安盟的9个旗市，森林面积8.37万平方公里，森林蓄积9.41亿立方米，森林覆盖率78.39%，生态系统服务功能价值7858亿元/年。内蒙古森工集团由总部、42个直属单位及其下属单位三个层级组成，肩负着筑牢我国北方重要生态安全屏障的光荣使命，集生态保护、林木育种和育苗、森林防火和航空护林、林业调查规划设计、林业有害生物防治、野生动植物保护等主业于一体。 近年来，内蒙古森工集团深入践行“绿水青山”“金山银山”价值双向转化路径，加快构建现代化林业产业体系，重点打造生态旅游、林下经济、林业碳汇、生态矿产、传统产业升级五大产业板块，推动“绿色颜值”向“经济价值”高效转化，绘就了守护绿水青山、发展现代林业的壮美画卷。
