## 公司
性质:合资 · 行业:商务服务业

中以合资民航MRO标杆企业，2016年2月成立，总部位于宜昌三峡机场，占地500亩。获取中国民用航空管理局（CAAC）及美国联邦航空管理局（FAA）颁发的各类维修许可。具备B737NG系列8C、A320CEO系列8C、B737CL系列6C、A320NEO系列4C、MA60系列4C定检，B737NG、A320、A330拆解和整机喷漆等业务能力。服务东航、海航、吉祥等24余家航司及租赁公司；拥有3座专业机库（含4机位定检/客改货生产线、宽体机喷漆线），截至目前已完成580余架次维修任务，AOG应急支援覆盖全国。继续提升管理水平，加强维修新能力的建设，一如既往的在民航维修领域精耕细作、确保安全、不断创新，立志打造国际接轨的MRO企业。
