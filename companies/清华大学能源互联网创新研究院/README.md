## 公司
性质:事业单位 · 行业:政府/机构/组织

清华大学能源互联网创新研究院成立于2015年4月，是国内首家能源互联网专业研究机构。聚焦能源互联网政策战略、创新规划、关键技术、产业生态和人才培养，致力于打造具有国际影响力的新一代能源网络战略决策智库。2020年4月，成为国家高端智库“清华大学国家治理与全球治理研究院”的首批校级研究机构。
