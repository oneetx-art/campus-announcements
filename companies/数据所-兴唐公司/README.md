## 公司
性质:央国企 · 行业:通信/电子/半导体

数据通信科学技术研究所，简称数据所，成立于1972年，隶属于国内信息通信设备制造领域最大央企——中国通信科技集团。数据所是我国专业从事数据通信、保密通信与网络安全技术研究和装备研制的单位，是国家数据通信工程技术研究中心依托单位，以安全核心和自主产品为基础，是中国信科集团网络信息安全板块的核心企业。主要业务涵盖网络信息安全理论、算法、芯片、整机、系统、服务全产业链条，所研产品广泛应用于国家重要信息系统、基础设施以及国民经济各行各业，在通信安全领域具有核心技术优势和领先行业地位。兴唐通信科技有限公司是数据所全资子公司。
