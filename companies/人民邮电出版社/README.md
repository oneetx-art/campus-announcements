## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

人民邮电出版社成立于1953年10月，隶属于中国工信出版传媒集团，是工业和信息化部主管的大型专业出版社。人民邮电出版社围绕“立足信息产业，面向现代社会，传播科学知识，引领美好生活”的出版宗旨，已发展成为集图书、期刊、音像电子及数字出版于一体的综合性出版大社。是全国百佳出版社、全国百佳图书出版单位、中国出版政府奖先进出版单位，拥有“全国文明单位”、“中央国家机关‘五一劳动奖状’、中央国家机关‘文明单位标兵’”和“首都文明单位标兵”等重要荣誉，坚持把社会效益放在首位、实现社会效益与经济效益相统一，综合实力位居行业前列。
