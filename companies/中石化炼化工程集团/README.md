## 公司
性质:央国企 · 行业:房地产业/建筑业

中石化炼化工程（集团）股份有限公司是由中国石化集团公司控股的、面向境内外炼油化工工程市场的大型综合工程建设服务商之一。公司重组成立于2012年8月，并于2013年5月在港交所主板挂牌上市。公司业务覆盖石油炼制、石油化工、芳烃、新型煤化工、无机化工、医药化工、清洁能源、储运设施及环保节能等多个领域，能够为全球客户提供涵盖工程研究、技术咨询、技术许可、工程咨询、工程设计、项目管理、EPC总承包、采购、设备制造、开车施工、环境治理、大型设备吊装和运输、预试车和工程服务等。公司已在全球30多个国家和地区为客户成功交付了数百个投资庞大、工艺复杂、技术先进、质量优良的现代化工厂，拥有广泛而稳定的客户资源，享有良好的行业影响力和社会声誉。
