## 公司
性质:合资 · 行业:机械/制造业

北京飞机维修工程有限公司（Ameco）由中国唯一载旗航空公司——中国国际航空股份有限公司和德国汉莎航空公司合资经营，是中国综合航企。2015年6月1日，现股东双方对 Ameco 的股权结构重组，新建立的北京飞机维修工程有限公司，其中国航持股75%，德国汉莎持股25%。北京飞机维修工程有限公司（Ameco）作为国航旗下的主要的航空维修企业，助国航承担专机保障、奥运火炬传递、海外撤侨等国家使命。公司总部设在北京，拥有10家航线分公司以及200多个国内国际维修站点，形成了覆盖全国的维修服务网络，为国内和国际三方客户提供基地维修和重维修，享有过 Ameco 的近12000名员工，拥有一支作风严谨、技术过硬的工程技术人员队伍，其中工程师团队规模达2100余人，全面确保公司专业化、产业化发展。
