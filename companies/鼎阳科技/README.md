## 公司
性质:民企 · 行业:机械/制造业

深圳市鼎阳科技股份有限公司是国家专精特新重点“小巨人”企业，是国内极少数具有数字示波器、信号发生器、频谱分析仪和矢量网络分析仪四大通用电子测试测量仪器主力产品研发、生产和全球化品牌销售能力的通用电子测试测量仪器厂家，同时也是国内极少数同时拥有这四大主力产品并且四大主力产品全线进入高端领域的企业。公司总部位于深圳，在美国克利夫兰、德国奥格斯堡、日本东京、马来西亚槟城州成立了子公司，在成都成立了分公司，在北京、上海、西安、武汉、南京设立了办事处，产品及服务远销全球80多个国家及地区。公司是研发驱动型高新技术企业，研发人员占比45%，包括深圳市、宝安区高层次人才共23名，每年将营业收入的20%投入研发，累计专利数量已有354项（其中发明专利231项），建立了中国合格评定国家认可委员会（CNAS）认定的测量实验室，是广东省科技厅认定的“广东省高端通信测量仪器工程技术研究中心”，广东省工业和信息化厅认定的“广东省鼎阳科技工业设计中心”，已被评定为“国家知识产权优势企业”。
