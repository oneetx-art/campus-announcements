浙江省嘉兴机场管理有限公司是浙江省机场集团有限公司的全资子公司，负责管理运营嘉兴南湖机场。嘉兴南湖机场位于浙江省嘉兴市，地处长三角城市群几何中心，是长三角世界级机场群的重要节点，定位为军民合用机场、客运支线机场、专业性航空货运枢纽，是长三角地区首个、全国第二个专业性航空货运枢纽，于2025年12月26日正式通航，2026年2月10日获批临时对外开放，2026年5月28日开通首条国际货运航线
