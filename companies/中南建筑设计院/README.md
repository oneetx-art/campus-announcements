## 公司
性质:央国企 · 行业:房地产业/建筑业

中南建筑设计院股份有限公司（以下简称“中南建筑院”）建于1952年，是新中国最早成立的六大城市综合建筑设计院之一。具有工程咨询、工程设计、工程总承包、项目管理等甲级资质，拥有国务院国资委管理的30余家中央企业集团成员，有中央一类企业、地方国企（含省级、市级）、建设工程以实施单位为甲方，实施设计、咨询、项目管理等，国家高新技术企业（含综合类、市政类、超高层）资质和检测（含建筑结构、给排水、消防、节能）等资质及工程监理、项目管理、建筑工程咨询、工程设计与质量检测、环境影响评价和水土保持评估等机构
