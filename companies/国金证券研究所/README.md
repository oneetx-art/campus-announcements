## 公司
性质:民企 · 行业:金融业

国金证券成立于1990年12月，注册地成都，注册资本30.24亿元人民币。2008年在A股上市（SH600109），属于全国综合类证券经营机构。国金研究所创建于2005年，是业内老牌卖方研究所之一，拥有180余人分析师团队，聚焦海内外千余家重点上市公司，服务3000+公募、保险、私募、银行和QFII等机构客户，构建起一套从宏观经济到细分领域全产业链覆盖的综合研究体系。宏观、固收、策略、非银、计算机、建材、公用事业与环保、电新、电子、机械、汽车、轻工等团队屡获市场重要奖项。国金研究所强调研究员回归研究本源，围绕定价能力，通过构建数字化体系，赋能立体式研究，致力于打造高水平、具有广泛影响力的综合研究所。
