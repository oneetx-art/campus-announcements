## 公司
性质:央国企 · 行业:机械/制造业

西南技术物理研究所创立于1958年，由中国科学院四川分院物理研究所演变而来，现隶属于中国兵器工业集团有限公司，是我国率先从事军用激光技术研究的专业机构。经过60余年的发展，已从激光基础研究和器件研制，发展成为以光电技术和制导技术为两大专业方向，在半导体器件、激光武器系统、激光应用、光电制导、光电对抗、光电信息等领域具有较强优势的科研生产机构，在国家和军队层面占据重要地位。
