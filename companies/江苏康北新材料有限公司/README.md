## 公司
性质:民企 · 行业:能源/化工/环保

江苏康北新材料有限公司成立于2018年，位于常州市钟楼区经济开发区，地理位置优越，交通便利。公司聚焦有机硅方向的新材料研发和应用，公司主要研发方向是电子元器件用阻尼、导热电力系统的绝缘、屏蔽;轨道交通减震阻燃;新能源领域隔热、密封;医疗行业材料的安全应用。应用领域包括:航空航天、轨道交通、汽车工业、新能源电池、电气柜、半导体等领域。公司已通过ISO9001、ISO14001、ISO45001、IATF16949质量管理体系认证，EN45545-2、UL94-VO、UL157-2007Gaskets and Seals等CE安全认证、NSF61等产品性能认证以及RoHS、PAHS、REACH绿色环保认证。获得授权国家发明专利近27项。
