## 公司
性质:央国企 · 行业:房地产业/建筑业

上海陆家嘴物业管理有限公司于1992年5月18日成立，是国家建设部首批物业管理一级资质企业，系上海陆家嘴金融城发展有限公司的全资子公司。公司是中国物业管理协会副会长单位、上海市物业管理行业协会副会长单位、浦东新区物业管理行业协会会长单位、上海市合同信用促进会常务理事单位。
