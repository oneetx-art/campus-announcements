## 公司
性质:其他 · 行业:金融业

齐鲁银行股份有限公司（股票代码：601665）成立于1996年6月，是全国首批、山东省首家成立并引进境外战略投资的城商行。2021年4月成功挂牌上海证券交易所主板上市，是山东省内首家城商行上市主体，山东省唯一省级法人银行，连续多年入选全球银行品牌价值500强。近年来，齐鲁银行坚持以习近平新时代中国特色社会主义思想为指导，持续稳健发展的经营特色，坚守“服务地方、服务中小企业、服务城乡居民”的市场定位，大力发展“服务+专业、创新+效率、敬业+特色”的核心优势，致力于打造高效的品牌银行、创新银行、特色银行、数字银行、合规银行、幸福银行。
