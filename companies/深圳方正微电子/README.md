## 公司
性质:央国企 · 行业:通信/电子/半导体

深圳方正微电子有限公司成立于2003年12月，是中国第三代半导体领先的IDM企业，主要从事SiC晶圆、器件、模组的研发、生产制造与销售服务，为新能源汽车、光储充、UPS、工业电源、AI计算、消费电子、低空飞行器eVTOL、机器人等领域提供SiC芯片产品解决方案。2021年8月，深圳市重大产业投资集团有限公司入主方正微电子，方正微电子成为深圳市国资委直管的国有独资企业，致力于将其打造为国家第三代半导体制造高地。公司秉承让数字世界更绿色的追求，具备SiC IDM端到端完整能力，可为客户提供SiC全场景解决方案及服务，拥有自外延→芯片设计→晶圆制造→模块设计→器件及模块封装→市场及销售服务的完整业务体系。
