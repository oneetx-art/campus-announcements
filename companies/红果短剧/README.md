## 公司
性质:民企 · 行业:IT/互联网/游戏

红果短剧是字节跳动旗下微短剧平台，由北京笔墨留香科技有限公司开发运营，2023年5月推出“红果免费短剧”APP，同年8月上线独立应用。平台以免费观看为核心模式，涵盖都市、玄幻、言情等类型短剧，同步设置电影、听书、小说等栏目，用户可通过观看短剧赚取“钻石”兑换现金收益，主要依靠广告实现商业化。截至2024年3月，平台月活跃用户达5400万并以人均单日1.38小时使用时长超越爱奇艺等长视频平台，同年9月突破1.2亿。
