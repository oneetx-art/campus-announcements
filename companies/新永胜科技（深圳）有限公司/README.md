## 公司
性质:民企 · 行业:耐用消费品

我们是新永胜，于1977年诞生于中国香港。一直专注于内衣、泳衣及运动服产品的设计、研发、生产，长期与国际品牌合作，客户遍布亚、欧、美、澳等世界各地，在同行业和客户中赢得了极好的声誉。2004年在江西吉安建立生产基地，分别于2016年，2018年在江西永丰县、遂川县设计分厂。企业文化包括使命与愿景：活力革新工业，成就百年永胜！价值观：信任、创新、分享。职业发展有管理、技术/专业双通道发展， “线上培训学院”、 “导师制”等培训制度。公司福利有周末双休，国家法定节假日，年休假；依法缴纳社保，提供食宿，设有运动场所及服务设施，还有节日福利、生日礼物、年度旅游等文娱活动。
