## 公司
性质:央国企 · 行业:机械/制造业

新乡航空工业（集团）有限公司（以下简称新航）是隶属于中国航空工业集团有限公司的国有大型独资企业，位于中原经济区核心发展城市——河南省新乡市。新航起源于1939年建厂的八路军金军火工厂，1953年纳入航空工业体系，从事航空飞机附件的研制与生产，在飞机环境控制技术、流体污染测控技术、流体压力与流量控制技术、流体热交换技术等居行业和国内领先水平。
