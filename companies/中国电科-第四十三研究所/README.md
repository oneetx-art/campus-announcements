## 公司
性质:事业单位 · 行业:教育/培训/科研

中国电子科技集团公司第四十三研究所，始建于1968年，位于安徽省合肥市，隶属于中国电子科技集团有限公司，是我国混合集成电路与微系统技术领域的国家级研究机构和行业领军者。产品涵盖DC/DC电源模块、功率驱动电路、信号处理电路、微波器件、金属封装外壳、先进SiP封装等多个领域，累计荣获国家级、省部级科技成果奖100余项，连续四年获得中国电科集团经营业绩考核A级
