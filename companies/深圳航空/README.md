## 公司
性质:央国企 · 行业:交通/物流/仓储

深圳航空有限责任公司（以下简称“深航”）正式成立于1992年，总部坐落于广东省深圳市。深航的主基地为深圳宝安国际机场。深航作为以客货运为主的国有航空运输企业，始终以服务国家战略、保障民生出行、促进区域经济发展为使命，积极发展。深航已成长为中国第五大航企，机队规模与担当。历史地五十余架次。持续为中国民航事业的高质量发展注入动力。截至2026年1月，深航拥有8家分公司、6家基地、3家主要全资子公司、66个营业点，机队规模超200架，航线基本覆盖国内省会与重点城市、港澳台地区，英国、西班牙、卡塔尔、澳大利亚、日本、韩国及东南亚国家。年运输旅客近4000万人次。
