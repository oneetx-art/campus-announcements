北京仲裁委员会（北京国际仲裁中心）是依据《中华人民共和国仲裁法》规定组建的，是独立于行政机关和其他社团法人、自然人的民商事仲裁机构。北仲自成立至今，坚持“独立、公正、专业、高效、卓越”的价值理念，竭诚为不同法域、多种文化背景的境内外当事人提供优质商事争议解决服务。
