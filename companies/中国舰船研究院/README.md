中国舰船研究院（中国船舶集团有限公司第七研究院，简称七院）成立于1961年，地处北京朝阳区奥林匹克中心区。七院始终以首任院长刘华清提出的“攀科技高峰，固海上长城”为己任，六十余年来见证了共和国舰船科技事业从无到有、规模从小到大、能力由弱到强的光辉历程，为舰船科技水平提高做出了重大贡献。
