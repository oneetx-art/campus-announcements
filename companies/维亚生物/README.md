## 公司
性质:民企 · 行业:医疗/医药/生物

维亚生物(01873.HK)成立于2008年，向全球创新研发企业提供从早期基于结构的药物研发到商业化药物交付的一站式综合服务。维亚总部位于上海，并在嘉兴、苏州、成都等地设有实验室及办公地点。目前集团拥有超过2000名员工，其中约97%的研发人员具有本科及以上学历。
