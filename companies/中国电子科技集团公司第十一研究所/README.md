## 公司
性质:央国企 · 行业:机械/制造业

中国电科11所是世界500强企业中国电子科技集团有限公司的二级单位，总部位于北京。11所成立于1956年，是新中国成立的第一家电子元器件所，是国内唯一有激光、红外两大专业，集科研、生产、整机、保障于一体，产品涉及材料、器件、整机、系统全产业链配套的综合性军工研究所，是国家一类骨干科研事业单位。
