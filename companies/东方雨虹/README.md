## 公司
性质:民企 · 行业:机械/制造业

东方雨虹成立于1995年，是优质建筑建材系统服务商。发展至今近30年，员工规模1万+人，全国布局64+家生产研发物流基地，优质产品远销100+个国家和地区，经典工程覆盖全球。东方雨虹获批建设特种功能防水材料国家重点实验室，拥有国家认定企业技术中心、博士后科研工作站等。美国费城建立“东方雨虹防水涂料全球卓越研究中心”。东方雨虹2023年营业收入328.23亿元。自2008年上市以来，公司业绩增长约46倍。连续多年荣获《财富》中国500强、胡润中国500强等奖项。
