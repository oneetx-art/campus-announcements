## 公司
性质:民企 · 行业:能源/化工/环保

湖北绿色家园材料技术股份有限公司成立于2004年，是一家专业从事精细化工及环氧新材料研发、生产、销售的国家高新技术企业，主营产品有氧化苄、苯甲醇、苯甲醛、苯甲酸苄酯、活性稀释剂系列、环氧固化剂系列等。公司获得了“国家级专精特新小巨人”“湖北省支柱产业细分领域隐形冠军科技小巨人”“湖北省技术创新示范企业”“湖北省优秀民营企业”等多项荣誉。
