## 公司
性质:央国企 · 行业:房地产业/建筑业

中铁二院工程集团有限责任公司，原铁道部第二勘测设计院，成立于1952年，是建国后第一批组建的国家级设计院，为国内大型综合性勘察设计企业之一，国内首批获得工程设计综合资质甲级。核心业务涵盖规划、勘察设计、咨询、监理、工程总承包、科研成果产业化，主营领域包含铁路、城市轨道交通、市政、公路、港口码头、民航机场、生态环境。公司总部位于成都，业务布局海内外，是国内轨道交通行业领军企业，业绩突出技术引领，拥有大量专业技术人才与多项国家级科研成果
