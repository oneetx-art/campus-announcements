深圳农业与食品投资控股集团有限公司（“深农投”）是深圳市属国有独资企业、行业领先的农产品培育和资源整合管控型综合平台。深农投坚持“保障产能、创智未来”发展理念，着力打造农产品“品牌赋能、智慧农贸研展推广、进出口贸易、政府资源接收、优质资源孵化、分散资源整合和不良资产处置”七大平台，为农业投资控股企业创新发展积累可复制、可推广的深圳经验。深农投下设五大主体业务板块，包括：菜篮子——深农集团（股票代码：000061）；米袋子——深粮控股（股票代码：000019）；资源整合库——圳品集团；创新集成器——深农科创；资源孵化器——农投资本。
