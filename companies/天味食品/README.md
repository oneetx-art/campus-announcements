## 公司
性质:民企 · 行业:快速消费品

四川天味食品集团股份有限公司（股票名称：天味食品，股票代码：603317）是国内复合调味品龙头企业，创于2000年，注册资本10亿元，是国内首家A股上市的复合调味料龙头。公司旗下拥有“好人家”、“大红袍”、“天车”、“味之素”等品牌，产品包括火锅底料、川菜调味料、六大食品餐饮定制火锅底料、川菜调味料、香辣酱等100多个品类，主营业务涵盖传统零售、在线零售和餐饮定制三大板块。
