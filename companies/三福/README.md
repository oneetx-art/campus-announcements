## 公司
性质:民企 · 行业:快速消费品

1992年至今，三福已在全国22个省份，4个直辖市，4个自治区，拥有逾千家门店和万名员工，足迹遍布华南、华东、华中、华北、西南、西北和东北七个大区，并同时拥有3个商品基地、2个商品配送中心、1个网购中心，1个员工培训中心。主营产品含：男女装、女鞋、男鞋、美妆、饰品、内衣等各大品类。三福致力于成为年轻人首选的潮流生活方式品牌，帮助年轻人发现生活新的可能，在打一个充满激情和创造力的，注重员工培养和激励，日常中遇见不寻常的自己的行业伙伴，为年轻人的成长和进步作出积极的贡献。三福希望，每一个年轻人在这里都能找到属于自己的潮流生活。
