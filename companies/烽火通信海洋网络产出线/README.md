## 公司
性质:民企 · 行业:通信/电子/半导体

烽火通信科技股份有限公司（简称烽火通信）成立于1999年，是中国光通信的发源地，是全球唯一集“光通信系统、光纤光缆、光电子器件”光通信三大战略技术于一体的科研与产业实体，于2001年在上交所上市（股票代码600498）。公司现有员工1.5万人，在东南亚、南美、欧洲建立了生产基地和研发中心，产品和服务覆盖100多个国家和地区，服务全球40亿人口。烽火通信海洋网络产出线致力于海洋网络通信技术和产品的研发，以拥有全产业链能力与自主知识产权为核心优势，是全球唯一自主打通芯片器件、岸基及水下设备、光棒海纤海缆、海洋工程装备四大核心技术领域的高新技术企业。
