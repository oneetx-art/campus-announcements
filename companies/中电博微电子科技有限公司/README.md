## 公司
性质:央国企 · 行业:通信/电子/半导体

中电博微电子科技有限公司（以下简称中电博微）是中国电科电子信息板块核心组成，下辖12家二级单位，控股上市公司（含1家上市3D公司），属于国家高新技术企业。公司以探测感知系统、探测制导系统创新和产品研制为装备制造、系统集成和应用服务为主业，致力于打造三大预警探测“国家队”。中电博微着力打造“一轴两翼三动能”产业布局和“低空安全、智能雷达、数字应用、智能装备”四个体系级业务。
