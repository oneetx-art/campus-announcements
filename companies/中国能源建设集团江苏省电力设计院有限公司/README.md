## 公司
性质:央国企 · 行业:能源/化工/环保

中国能源建设集团江苏省电力设计院有限公司（以下简称“江苏院”）于1958年由原华东电业管理局设计处、工程管理处的“三电工程”设计室合并，整合电力勘察设计行业资源而成立的大型央企，现为中国能建和葛洲坝集团新成立的能建产业融合发展集团江苏省省级院。荣获江苏省规划设计70年优秀综合实力奖等三十多项省级奖，获中国电力优质工程奖和国优高新技术企业，被授予国家技术中心。
