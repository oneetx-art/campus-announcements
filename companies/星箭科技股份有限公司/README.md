## 公司
性质:民企 · 行业:机械/制造业

星箭科技股份有限公司（以下简称星箭），始建于1981年，总部位于浙江宁波，是一家专注于高压流体控制元件和系统，集研发、生产、检测、安装调试、服务为一体的国家高新技术企业，致力于成为流体控制应用领域的全球领跑者。公司致力于高新技术开发和国产化项目研发，拥有百余项发明专利及实用新型专利，并承担着多项国家级科研项目，参与多项国家标准制定，多次荣获国家级科学技术奖。公司组建有省级高新技术企业研发中心和省级研究院。
