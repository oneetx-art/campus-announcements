## 公司
性质:央国企 · 行业:机械/制造业

南京国兆光电科技有限公司是央企中国电科第五十五研究所下属单位，国家高新技术企业，国家级“专精特新”小巨人和江苏省潜在独角兽企业，公司位于南京市江宁经济开发区，公司专业从事新型微型显示技术研发工作，致力于为全球用户提供优质的硅基OLED微型显示器产品和基于硅基OLED显示器件的整体解决方案。
