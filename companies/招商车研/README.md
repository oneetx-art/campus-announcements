## 公司
性质:央国企 · 行业:检测/认证

2003年，招商局检测车辆技术研究院有限公司由招商局集团、重庆市政府整合相关资源组建而成。招商车研是国家火炬计划重点高新技术企业、重庆市创新型企业，获工业和信息化部、交通运输部、生态环境部、市场监管总局等行业主管部门授权和认可，主要从事汽车产品认证、法规检测、研发验证、供应商检测、进口商检、出口认证、标准制修订、技术咨询聚焦“安全、绿色、智能”三大领域，以科技创新构建核心优势，致力成为行业领先的技术先导型综合性车辆技术服务公司。
