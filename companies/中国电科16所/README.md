## 公司
性质:事业单位 · 行业:教育/培训/科研

中国电子科技集团公司第十六研究所（以下简称16所）位于安徽省合肥市高新区，始建于1966年，主要从事低温制冷、超导与低温电子、热管理等技术研究、产品研发与工程应用，拥有中国电科低温电子技术研发中心、安徽省企业技术中心、低温技术安徽省重点实验室、安徽省热管理技术工程实验室、安徽省博士后科研工作站等科技创新平台，是安徽省确立的首批“新型研发机构”。16所技术与产品服务于国防与公共安全领域。
