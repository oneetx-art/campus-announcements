## 公司
性质:央国企 · 行业:机械/制造业

北京国望光学科技有限公司是一家聚焦于高端光学装备和仪器研发的新型高科技半导体设备企业，定位是我国超精密光学产业技术研发与生产的主要基地。公司集研发、系统集成、生产制造、销售与技术服务于一体，致力于从国家战略层面，解决国内高端光学系统的自主研发及产业化问题，带动国内高端光学领域产业发展，形成超精密光学产业生态圈。
