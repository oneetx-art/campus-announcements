## 公司
性质:民企 · 行业:贸易/批发/零售

中哲集团始创于1998年，现有员工5000余人，集中于纺织新材料、服装、供应链服务、消费品电子、数字科技、智能制造领域；2019年进入“中国制造企业500强”；2021年进入“中国民营企业500强”。中哲物产集团有限公司是中哲控股下属从事大宗商品贸易的业务平台，以农产品、能源化工、金属等大宗商品及其制品的物流和转售等贸易为业务，是中国进口农产品、能源化工、金属等大宗商品的主要供应链服务商，通过整合产业链上下游的三位一体的供应链服务模式，追求以为客户中心，为客户提供价值和服务愿景。
