## 公司
性质:央国企 · 行业:通信/电子/半导体

湖北华中长江光电科技有限公司隶属于中国兵器工业集团有限公司，总部位于湖北孝感，在北京、武汉设有研发中心，是国资委“科改示范企业”、国家级高新技术企业，注册资本2.4亿元，营业收入超22亿元，现有从业人员2000余人。公司立足特种光电、汽车光电两大主业，形成了光电装备、汽车灯具、激光雷达、户外光电、光电检测仪器五个产业协同发展的产业格局。公司建有湖北省博士后创新实践基地、湖北省光电信息技术中心、湖北省汽车灯具工程技术开发中心，并与武汉大学成立联合创新实验室。
