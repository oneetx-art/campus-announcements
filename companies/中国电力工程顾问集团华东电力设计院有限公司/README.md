中国电力工程顾问集团华东电力设计院有限公司（简称“华东院”）1953年成立于上海，是一家综合性、多功能的国际工程公司。华东院始终紧跟国家能源发展，推进绿色低碳建设，主营业务涵盖电力系统规划、火电、核电、新能源、输变电、生态环保、市政等领域，具备从规划咨询、勘察设计、投融资到工程建设和运维的全产业链服务能力，是我国能源电力建设领域里的国家队和主力军。
