## 公司
性质:民企 · 行业:机械/制造业

深圳市正弦电气股份有限公司成立于2003年，2021年在科创板上市（股票代码：688395）。作为工业自动化产品与控制系统解决方案提供商，正弦电气以运动控制技术为核心，聚焦变频器、伺服系统、控制器、一体化专机及新能源等产品，提供智能制造综合解决方案，目前已在深圳、武汉、无锡、苏州建立研发、生产和服务基地，并在28个大中型工业城市设立销售服务中心，业务范围覆盖国内及全球多个国家和地区。
