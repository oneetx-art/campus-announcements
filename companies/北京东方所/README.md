## 公司
性质:民企 · 行业:教育/培训/科研

北京东方振动和噪声技术研究所（简称“东方所”）成立于1985年10月，是国家高新技术企业和北京市“专精特新”企业。成立四十年来，一直专注于振动、冲击、噪声、应变等动态测试、信号处理、模态分析、故障诊断、教学试验、虚拟仪器和测控技术等领域的技术研究、产品开发、工程应用和技术服务。东方所核心成员来自清华大学、浙江大学、中国科学院、北京航空航天大学等力学、声学和自动测试领域知名科研院所。研发的“DASP系列”软件、“INV系列”硬件均具有自主知识产权，在航空、航天、兵器、船舶、轨道交通、核能电力、机械装备和大型结构等领域有8000余家用户。东方所积极组织和参加国内外学术交流，是中国振动工程学会的发起单位之一，是中国振动工程学会振动与噪声控制专业委员会挂靠单位，专委会主办全国振动与噪声高技术应用学术会议，并出版《现代振动与噪声技术》系列论文集。
