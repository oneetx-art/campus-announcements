## 公司
性质:民企 · 行业:通信/电子/半导体

丘钛科技（集团）有限公司（股票代码：01478.HK）主要从事设计、研发、制造和销售摄像头模组、指纹识别模组和激光雷达等智能视觉产品，服务于全球领先的智能手机及平板电脑机品牌、智能汽车品牌、无人机品牌和其他物联网（IoT）智能移动终端品牌。集团于2025年加入中国制造业民营企业500强。集团坚持秉承“给机器带来光明”的使命，致力于成长为一家提供机器视觉及人眼视觉一体化解决方案的科技企业。企业愿景是建立有竞争力门槛和客户粘性的平台，让最好的一群人在合适的角色上能够发挥最大价值。
