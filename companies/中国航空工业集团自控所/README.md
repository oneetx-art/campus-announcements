## 公司
性质:央国企 · 行业:机械/制造业

中国航空工业集团是由中央管理的国有特大型企业，经营范围涵盖航空武器装备、通用航空、航空研究等产业，下辖100余家成员单位、25家上市公司，员工逾40万人。自控所成立于1960年，是我国航空工业飞行控制、惯性导航两大技术的发源地，GNC（制导、导航与控制）关键系统的市场引领者和核心供应商，具有外贸进出口权；专业呈现学科覆盖广、专业体系全、产品高安全的特点；市场立足航空、服务国防，主力机型实现产品全覆盖。“十四五”以来，自控所始终坚持“三个第一”指导思想，着力打造创新资源和科技人才队伍，拥有多个国家级、行业级、省级/集团级重点实验室及创新中心，设有“导航、制导与控制”、“精密仪器及机械”两个专业硕士点，“导航、制导与控制”专业博士点及博士后科研工作站。自控所积极践行“航空报国 航空强国”的使命，探索并运行先进的技术与管理，愿景建设成为世界一流GNC专业领军企业。
