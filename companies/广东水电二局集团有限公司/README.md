## 公司
性质:央国企 · 行业:房地产业/建筑业

广东水电二局集团有限公司是广东省属国有控股上市公司——广东省建筑工程集团股份有限公司的全资子公司，起源于新中国水电人才的摇篮——燃料工业部古田溪水利发电工程处。后扎根南粤大地，经过70余年的成长，从传统水利水电施工企业，转型升级为经营业务涵盖工程建筑施工、清洁能源投资、装备制造，下属广东粤水电能源投资集团有限公司、广东粤水电装备集团有限公司等15家二级成员单位，是一家具有“投融建营管”综合实力的集团化企业。
