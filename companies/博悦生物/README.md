## 公司
性质:民企 · 行业:医疗/医药/生物

博悦生物是一家专注于创新研发、高端仿制药研发和一致性评价的技术创新型企业，聚焦高技术壁垒原料药和制剂项目的研发。公司成立于2010年，位于上海闵行区闵金领谷科技产业园，为国家认定的高新技术企业、上海市专精特新企业、上海市专利试点企业和《小巨人工程企业》。公司在江苏海门设有分研中心，在福建明溪建有GMP认证的药品研发平台和原料药生产基地。公司于2023年获得了《药品生产许可证》B证。公司研发中心配备有国际一流研发设施和齐全的仪器设备，建立了完善的药物研发体系和质量管理体系并通过了CNAS实验室认可。公司从事药物到原料药开发、制剂研发、质量控制体系的建立、新药及仿制药申报、以及仿制药一致性评价等各个领域都具有丰富的经验，可为国内外客户提供优质的药物开发和注册申报一站式服务。
