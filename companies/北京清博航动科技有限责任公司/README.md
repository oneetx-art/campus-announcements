## 公司
性质:民企 · 行业:IT/互联网/游戏

北京清博航动科技有限责任公司是主营业务为航天领域工业软件的开发和设计的科技型创新领军公司。公司的主要成员都来自清华大学航天动力学实验室，在航天动力学与控制领域已经有30余年的研究积淀，具有丰富的从业经验以及行业声誉，曾获得航天动力学领域国际权威大赛（GT0C）冠军。公司具有国际领先的航天动力学技术，基于此自主研发并形成了独具特色的航天软件体系，向国有航天企业以及商业航天企业提供技术服务。目前民用太空安全产品已陆续应用到中国空间站，已签订订单近千万。
