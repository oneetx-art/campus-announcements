## 公司
性质:央国企 · 行业:房地产业/建筑业

中交第二航务工程局有限公司（简称中交二航局）创建于1950年，是世界500强企业——中国交通建设股份有限公司的全资子公司。中交二航局是国家港口建设的主力军，在港口、桥梁、道路、铁路、机场、水利水务、市政、工民建、环保工程等建设领域，为客户提供集策划咨询、勘察设计、投融资、工程建设、运营管理为一体的全产业链服务。
