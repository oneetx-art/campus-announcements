## 公司
性质:央国企 · 行业:能源/化工/环保

中国能源建设集团江苏省电力设计院有限公司（简称江苏院）创建于1958年，是中国能建旗下具有工程设计、工程勘察、工程咨询“三综甲”的大型企业，多次入选ENR全球排名的“中国工程设计企业60强”，综合实力多年位居江苏省勘察设计行业综合实力排序前三名的位置。荣获“全国文明单位”等优秀勘察设计企业、江苏省“建筑业强企”、中国能建优秀科技单位、江苏省省级企业技术中心。
