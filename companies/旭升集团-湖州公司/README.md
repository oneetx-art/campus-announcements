## 公司
性质:民企 · 行业:汽车制造/维修/零配件

旭升汽车精密技术(湖州)有限公司系宁波旭升集团股份有限公司(股票代码:603305)全资子公司，成立于2021年12月13日坐落于湖州市南浔区。公司注册资本8亿元，占地283亩，总建筑面积达28.8万平方米，依托母公司宁波旭升在铝合金高压压铸、铜造及挤压领域的领先工艺优势，湖州旭升重点拓展多种先进连接技术(如FSW、CMT焊接、FDS、SPR等)，专注于新能源汽车核心部件的研发与制造。核心产品包括电池包箱体、钢铝混合车身部件及副车架等致力于为客户提供轻量化、高强度的系统化部件解决方案。
