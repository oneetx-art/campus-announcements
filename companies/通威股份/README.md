## 公司
性质:民企 · 行业:机械/制造业

通威股份有限公司由通威集团控股，是绿色农业和绿色能源高效协同发展的大型民营科技型上市公司。现拥有200余家分、子公司，员工6万余人。2006年进军光伏新能源产业，已成为拥有完整光伏新能源产业链条的企业，在规模、技术、成本、质量上有优势。通威股份光伏技术中心在光伏各业务板块科研体系基础上成立，以行业专家为主的科研技术团队统筹推进技术研发与集成，依托国家级企业技术中心开展太阳能电池新技术研发攻关，在TOPCon、HJT、BC、钙钛矿/晶硅叠层等主流技术上有布局，建成近2万平方米全球创新研发中心，专利累计授权达2400+件。与多单位构建产学研合作关系，入选多项人才项目，研发平台获批多项资质认定。
