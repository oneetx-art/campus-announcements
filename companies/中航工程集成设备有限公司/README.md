## 公司
性质:央国企 · 行业:机械/制造业

中航工程集成设备有限公司是中国航空工业集团有限公司成员单位。前身为1951年8月成立的重工业部航空工业管理局设计处设备室，定位于“航空地面支持专用设备的研发、制造、销售及相关工程服务”，2018年规划总院下设动力工程设计研究院划归公司实行统一管理。进一步提升了公司航空发动机和工程总承包能力。七十余年来，我们在航空发动机试车台、风洞、救生等航空试验设备，大型真空系统、热处理炉、热压罐、复材生产线、涂装生产线等工业非标设备领域始终处于行业领先地位荣获全国十大科技成就奖等奖项，是航空非标设备领域名副其实的“国家队”。
