## 公司
性质:央国企 · 行业:机械/制造业

昌河飞机工业（集团）有限责任公司隶属于中国航空工业集团有限公司，始建于1969年，坐落在江西省景德镇市，具备研制和批量生产多品种、多系列、多型号直升机和航空产品零部件的能力，是中国直升机科研生产基地和航空工业骨干企业。亚洲最大运输直升机和中国第一款专用武装直升机均在这里诞生。
