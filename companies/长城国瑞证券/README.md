## 公司
性质:央国企 · 行业:金融业

长城国瑞证券是中国证监会核准的全牌照综合类证券公司，1988年成立于厦门经济特区，控股股东为中国长城资产管理股份有限公司，注册资本33.5亿元，在全国各地设有25家分支机构和4家子公司。公司经营范围涵盖证券经纪、证券投资咨询、证券承销与保荐、融资融券等多项证券业务，确立了根植根据地服务中小微的业务战略，坚守服务实体经济本源，致力提升综合金融服务能力
