## 公司
性质:央国企 · 行业:机械/制造业

中机国际工程设计有限公司，简称中设集团（CMEC），是国机集团设备与海工承包板块的经营实体。公司成立于1979年，是由原第一机械工业部，也是最早进入国际市场的新中国工程承包商。依托“一流设计咨询为牵引，科技创新为支撑，国机集团产业作为国内外客户的集成策划咨询、勘察设计、工程承包、贸易物流、投资运营、工程综合服务能力，公司正在为国内外客户，提供绿色与智能装备基础制造到全产业的全方位专业经贸服务。
