## 公司
性质:央国企 · 行业:交通/物流/仓储

首都机场集团有限公司（Capital Airports Holdings Co.,Ltd. 简称CAH）隶属于中国航空集团，是一家以机场业为核心的跨地域的大型国有独资公司。2002年12月28日，由原首都机场集团公司、北京首都国际机场股份有限公司（BCIA）、天津滨海国际机场、中国民航飞机维修企业、金飞民航经济发展有限公司、中国民航工程咨询公司联合重组，现管理北京、天津、河北、江西、吉林、黑龙江等6省市35个干、支线机场，形成了机场运营、机场保障、机场商业、临空生态四个板块协同发展的业务布局。2024年，全集团旅客吞吐量、货邮吞吐量和运输架次分别达到24078万人次、258万吨和188万架次。
