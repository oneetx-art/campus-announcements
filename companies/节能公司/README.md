## 公司
性质:央国企 · 行业:能源/化工/环保

中石化节能技术服务有限公司（中国石化节能技术服务中心）是中石化炼化工程（集团）股份有限公司旗下的全资子公司，于1993年成立，2019年迁址雄安新区，注册资本5亿元人民币。公司是中国石化的专业化节能服务公司，是中石化炼化工程（集团）股份有限公司节能环保管理项目的合同主体，同时履行中国石化节能技术服务中心职责，承担国家、行业及中国石化委托的研究任务，开展标准化研究、能耗统计、节能审计、节能评估、节能技术推广和绿色低碳研究等工作。
