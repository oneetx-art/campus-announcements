## 公司
性质:事业单位 · 行业:交通/物流/仓储

中国民航深圳空中交通管理站原名为民航深圳管理站，2007年6月正式更名为民航深圳空中交通管理站。现下辖珠海进近管制中心、本部10个直属部门及空管实业公司。主要职责为：贯彻执行国家空管方针政策、法律法规以及民航局的决定、指令和规章制度；提供民航空中交通管制、航行情报、通信导航监视、航空气象服务；负责重要飞行活动和民用航空器搜寻救援空管保障工作；根据授权实施本地民航空管工程建设项目；负责管理所属单位的行政、规划投资、人力资源、财务、党群等工作。
