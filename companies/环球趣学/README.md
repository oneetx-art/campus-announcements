## 公司
性质:民企 · 行业:教育/培训/科研

环球趣学成立于2016年，现设有北京海淀万柳校区，海外加拿大分校。趣学秉持“兴趣激发潜能，学习成就人生”的教学理念，致力于能力和素养的提升，现在拥有学科教育、素养教育等多元化成长助力系统。趣学同时把“让学习更有趣、更高效”作为自己的使命，专注于兴趣培养和巧思妙用，用科学的教学理念、先进的教学方法和优秀的教师队伍吸引了众多的学生和家长关注，口碑一流。
