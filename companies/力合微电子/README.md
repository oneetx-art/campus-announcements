## 公司
性质:民企 · 行业:通信/电子/半导体

深圳市力合微电子股份有限公司（股票代码：688589）创立于2002年，是物联网行业领先的专注集成电路芯片设计的科创板上市企业。作为芯片原厂，二十三年深耕于物联网通信技术研发，在电力线通信、数字无线通信、多模通信、MESH网络、数字信号处理等领域拥有核心技术，是具备真正原创技术的“中国芯”企业。公司以集成电路芯片技术为核心竞争力，以物联网市场应用为驱动，以PLBUS电力物联技术品牌为抓手，在智能电网、全屋智能、智能家居、智能照明、酒店照明、智慧光伏、综合效能管理等物联网业务领域，提供“最后一公里”通信连接芯片及芯片级完整解决方案。公司秉承“用自己的芯，使生活更美好”的理念，持续赋能物联网行业，万物互联，芯向未来。
