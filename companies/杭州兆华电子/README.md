## 公司
性质:民企 · 行业:通信/电子/半导体

杭州兆华电子股份有限公司成立于2008年8月，注册资本6320万元，旗下品牌“CRYSOUND”，是一家专注于智能声学检测设备研发、生产与销售的国家专精特新“小巨人”企业，为汽车制造、电子制造、石油化工、家电电力、航空航天、半导体、科研机构等多个国家/行业客户提供声学半自动化解决方案。公司是国内较早一批创自主研发高端声学检测设备与声学分析算法的科技创新型企业，也是国内声学检测产品领域最为齐全的企业之一，多项产品性能已达到国际领先与国际先进水平。
