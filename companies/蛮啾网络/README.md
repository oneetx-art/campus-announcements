## 公司
性质:民企 · 行业:IT/互联网/游戏

上海蛮啾网络科技有限公司于2015年01月成立，因其LOGO标志性的形象也被玩家亲切地称之为“小黄鸡”。目前，蛮啾网络主要作品为二次元即时海战手游《碧蓝航线》，为首个登顶日本畅销榜的国产二次元游戏。2024年3月首次曝光的《蓝色星原·摇篮》正在锐意开发中，全网预约人数已超过500万。同时，蛮啾网络一直致力于原创游戏的不断创新，在原创IP、漫画、动画、周边等更多的领域上不断探索和努力。
