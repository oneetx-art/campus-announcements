陕西煤业化工集团有限责任公司（简称陕煤集团）是国有特大型能源化工企业，是陕西省能源化工产业的骨干企业，也是省内煤炭大基地开发建设的主体。自2004年成立以来，历经21年的改革发展，通过投资新建、收购兼并、资产划转、内部重组等多种途径，陕煤集团形成了多元互补、协调发展的产业格局。
