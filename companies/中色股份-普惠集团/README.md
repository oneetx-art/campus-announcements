## 公司

中国有色金属建设股份有限公司（简称中色股份，英文缩写NFC）1983年经国务院批准成立，1997年在深圳证券交易所挂牌上市（证券代码：000758），控股股东为中国有色集团（2003年中国有色矿业集团有限公司整体改制为中国有色矿业集团有限公司）。武汉普惠海洋光电技术有限公司，成立于2012年，湖北省专精特新“小巨人”（2023年湖北省制造业单项冠军企业），是中国首台自主研发海洋电子信息产业研发机构。公司拥有自主知识产权的多项专利技术，累计投资超过5000万元，拥有湖北武汉光纤水听器研发中心、武汉、盐城联合实验室、水听器光纤、光阵列排列、性能测试设备、工程安装在内的具备光水听器及阵列、干燥舱设备的工程化及大规模生产能力。
