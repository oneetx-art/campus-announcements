## 公司
性质:央国企 · 行业:能源/化工/环保

中海石油气电集团有限责任公司（以下简称“气电集团”）为中国海油全资子公司，是中国第一、世界第二大LNG进口商，国内天然气市场的领跑者。气电集团构建了涵盖LNG上中游的完整产业链，具备资源掌控、接收站运营、天然气发电等核心优势，是我国LNG行业的领军企业和清洁能源综合服务商。气电集团业务涵盖国际LNG贸易、天然气发电与电力交易、接收站与储运、终端销售、车船加注、氢能、碳交易等，正积极打造“气、电、氢、碳”四阶产业链。所属单位超150家，工作地点覆盖国内主要区域及新加坡、澳大利亚等海外地区。未来，气电集团将以创建世界一流天然气贸易商为目标，聚焦天然气主业，加快战略产业培育，推动“气、电、氢、碳”融合发展和绿色低碳转型升级，致力于成为保障国家能源安全的重要力量和绿色低碳发展的引领者。
