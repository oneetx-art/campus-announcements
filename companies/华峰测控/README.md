## 公司
性质:民企 · 行业:通信/电子/半导体

北京华峰测控技术股份有限公司于1993年在中关村高新科技园区登记注册，为国家级高新技术企业，是中国领先的半导体自动化测试系统本土供应商，科创板上市公司（股票代码688200），国家级专精特新“小巨人”企业、北京市专精特新“小巨人”企业、北京市“隐形冠军”企业。公司专注于半导体自动化测试设备（ATE）产品研制30余年，有着深厚的技术积累和全球市场。低调务实、厚积薄发，在我国测试设备领域持续创造佳绩。公司两大品牌：AccoTEST、华峰测控。公司高度重视核心技术研发，拥有强大的自主研发能力，在三十余年的发展历程中始终坚持自主研发、技术自主可控。我们多次打破国外厂商针对我国半导体自动化测试设备的技术及市场垄断，实现了同类产品在国内领域的领先市场地位。同时在我国台湾地区、美国、欧洲、日本、韩国、东南亚等境外国家和地区拥有众多国际知名半导体企业客户，截至目前，公司产品在全球范围内的装机量已突破8000台。公司共有员工900余人，拥有电路设计、软件开发、IC测试研究等领域具有丰富经验和学识的高素质专业研发团队，拥有一支强大的销售及服务团队，同时也为广大客户提供基础和进阶的培训课程。公司具备十分优良…
