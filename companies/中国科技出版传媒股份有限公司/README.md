## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

科学出版社由中国科学院编译局与1930年创建的龙门联合书局于1954年8月合并成立；2007年4月转制改企为科学出版社有限责任公司；2011年完成股份制改造，整体变更设立为中国科技出版传媒股份有限公司。2017年1月18日，公司在上海证券交易所主板挂牌上市，成为中央出版集团上市第一股。60多年来，依托中科院，形成了以科学、技术、医学、教育、人文社科为主要出版领域的业务架构，出版成果丰硕，期刊方阵水平高。
