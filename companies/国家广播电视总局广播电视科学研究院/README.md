## 公司
性质:事业单位 · 行业:文化/传媒/广告/体育

国家广播电视总局广播电视科学研究院成立于1958年，是国家广播电视总局直属公益二类事业单位，中央级科研院所。主要职责是负责广播电视和网络视听基础性、前沿性、战略性技术研究，承担重大科研项目、重大科技工程项目的攻关和实施，开展相关系统、关键设备研发技术与标准化工作；承担相关项目的可行性研究、规划设计、测试评估等技术咨询服务，开展技术检测、工程验收、广播电视设备器材入网认定测试和技术交流、科技成果转化、会展服务；完成总局交办的其他事项等。
