## 公司
性质:民企 · 行业:能源/化工/环保

天能控股集团始创于1986年，发源于“绿水青山就是金山银山”理念诞生地——浙江湖州。集团历经39年的创新发展，已经成为一家以新能源动力电池（铅电、锂电）、新能源储能电池、智慧能源、资源循环利用等为主营业务，集产业、平台、资本、技术、人才等要素协同发展的国际化企业，综合实力位居全球新能源企业500强、中国企业500强、中国民营企业500强、中国制造业企业500强、中国轻工业电池行业十强。
