## 公司
性质:民企 · 行业:机械/制造业

深圳市腾盛精密装备股份有限公司（简称“腾盛精密”）成立于2006年7月，是精密流体、精密装备的研发、设计、生产、销售和服务为一体的国家级高新技术企业。国家重点专精特新小巨人企业。综合实力行业前三，是国内唯一一家获得“国家级专精特新小巨人”荣誉的流体控制设备企业。总部位于苏州，拥有应用测试实验室，以及在成都、台湾地区，韩国、新加坡、马来西亚、泰国设有代理商办事处。以世界级品质为标准，以客户、专业、品质引领事业发展，是50多家国内外头部企业的合作伙伴。腾盛精密将制造改变企业的使命，持续专注于高端精密装备的（芯片）研发与制造，产品包括半导体封装、3C电子划刻/片研发设备，主要应用于半导体封装、3C电子制造产业链。
