## 公司
性质:民企 · 行业:机械/制造业

陕西鼎益科技成立于2004年，是国家工信部认定的国家级专精特新“小巨人”企业、国家高新技术企业、陕西省民营经济转型升级示范企业、西安市硬科技企业之星……公司拥有100000㎡钛合金现代化、智能智造化生产基地，专注于增材制造领域的特种牌号钛合金材料研发、生产、制造与服务。多年以来，鼎益科技自主研发完成了具有突破性的钛及高温合金产品生产工艺，申请注册国家知识产权40余项，实现了生产过程全流程专利闭环控制。公司的新产品填补了国内空白，产品成功进入了波音、空客等航空工业以及高端医疗领域供应链。在国际及国内注册认证的TIPRO已经成为钛合金增材制造领域全球知名品牌，客户遍及全球40多个国家。
