## 公司
性质:央国企 · 行业:能源/化工/环保

浙江丽水市自然资源发展有限公司（简称“公司”）成立于2023年10月10日，由省自然资源集团和丽水市人民政府（市农投集团持股）共同出资设立，是省自然资源集团控股的一级子公司，公司总部位于“浙江绿谷”—浙江省丽水市，下设2家子公司。公司厚植丽水市“浙江绿谷”资源禀赋，围绕自然资源领域保护利用修复和农业资源综合开发优势，积极参与丽水地区山水林田湖草整体保护、系统修复、综合治理，以国土空间生态修复、土地综合整治、耕地保护、土地流转收储、农业资源综合开发、城乡投资建设、地下空间开发工程、低效用地开发利用、农文旅产业为主要投资方向，探索建立投资、融资、开发、运营、管理一体化发展模式。
