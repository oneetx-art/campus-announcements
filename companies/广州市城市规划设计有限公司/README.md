## 公司
性质:央国企 · 行业:房地产业/建筑业

广州市城市规划设计有限公司成立于1992年，是广州市规划和自然资源局监管的国有企业，是国内知名城市规划咨询品牌。公司（含下属企业）有专业技术精英450余人，拥有城乡规划甲级、文物保护勘察设计乙级、建筑工程设计乙级、土地规划乙级、工程咨询乙级、环保技术咨询能力评价乙级等资质，通过ISO国际质量管理体系认证，为国家高新技术企业、广东省专精特新中小企业、广东省创新型中小企业、广州标杆科技企业50强、广州科技企业高质量发展100强、广东省住房城乡建设部门历史文化遗产监测重点实验室、广东省历史文化遗产保护与可持续发展规划研究中心等科技创新及研发新工作站、大湾区规划实施技术研究中心、广东省新型城市发展平台。
