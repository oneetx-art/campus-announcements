## 公司
性质:事业单位 · 行业:教育/培训/科研

核工业西南物理研究院（简称“西物院”）建于1965年，是中国核工业集团有限公司一级单位，由中国聚变能源有限公司代管。是我国最早致力于核能“三步走”发展战略中聚变堆研发的专业科研院所；我国参与国际热核聚变实验堆（ITER）计划的重要支撑单位。下设聚变科学所、应用技术所、成都理工大学工程技术学院三个二级单位，致力于核聚变能研究开发、聚变中间技术转化、应用型高等教育。
