## 公司
性质:民企 · 行业:医疗/医药/生物

南京泽恒医药技术开发有限公司成立于2009年，主要从事改良型制剂和高端仿制药物（含一致性评价）的研发、生产和销售。公司下设2家药品生产企业、2家药品研发公司和1家销售公司，已构建完整的MAH全生命周期管理体系。公司推动“CXO+MAH”双翼齐飞的发展战略，可为国内药品生产许可持有人提供研发申报、注册上市、药品生产及销售推广的一站式全流程服务。
