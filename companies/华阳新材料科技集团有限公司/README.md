华阳新材料科技集团，是勇担“在转型发展上率先蹚出一条新路来”历史使命，由世界500强企业——阳煤集团整体更名而来的高科技新材料产业集团，拥有山西华阳集团新能股份有限公司和山西华阳新材料股份有限公司两个上市公司。华阳新材料科技集团以“双碳”目标为引领，大力实施“双轮驱动”发展战略，坚持立足煤、做强煤，扛牢国家电煤保供责任，瞄准智能化、绿色化、融合化方向，做强做大传统煤炭优势产业；坚持延伸煤、超越煤，锚定国家所需、国企所能，做精做优钠离子电池全产业链、高端碳纤维等新能源新材料产业；坚持抓链条、抓布局，围绕“绿色矿山、绿色冶炼、绿色加工、绿色园区”目标，推动延链补链强链，全力打造“铝土矿-氧化铝-电解铝-铝深加工”全产业链，努力蹚出一条产业优、质量高、效益好、可持续的高质量发展新路。
