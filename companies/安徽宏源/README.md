## 公司
性质:央国企 · 行业:能源/化工/环保

安徽宏源铁塔有限公司，成立于1958年，位于安徽省会城市合肥，是国内最早具备500kV铁塔生产资质的5个厂家之一，企业占地247亩，厂房面积8万余平米，注册资本4.36亿元，年产值突破20亿元。企业隶属中央企业中国电气装备集团有限公司下属宏盛华源铁塔集团股份有限公司。企业拥有国内最高电压等级铁塔生产资质、钢结构制造企业一级资质、电力工程施工总承包和钢结构工程专业承包二级资质等，参与制定8项国家及行业标准，现有发明专利11项，实用新型专利47项；企业在特高压铁塔制造领域具备深厚经验，依托智能化装备打造先进生产体系。现有9台大功率激光切割机、20余套多轴联动自动焊接工作站及智慧化角钢/板材加工中心，关键工序自动化程度行业领先。辅以2条绿色高效智能镀锌线，实现全流程清洁化、精细化生产，彰显企业在高端电网装备制造方面的硬实力与工艺水平。
