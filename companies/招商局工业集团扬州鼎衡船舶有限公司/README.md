## 公司
性质:民企 · 行业:房地产业/建筑业

招商局工业集团扬州鼎衡船舶有限公司注册于2006年3月24日，公司以3万吨及以下中小型化学品船、气体船等特种船舶建造为主营业务，陆域面积37万平方米，岸线长度600米，建设8万2吨级船坞、5万吨级船坞及多用途型码头，配全全球先进的不锈钢制造车间及碳钢综合建造车间，年造船能力12-16艘。2023年3月组建南京东海岸成立南京分公司，通过轻资产运营模式，与南京金陵船厂达成战略合作，南京分公司拥有20万平方米的生产场地及2座船台、1座滚装船造核心资源，年造船能力6-8艘。
