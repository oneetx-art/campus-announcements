## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

中国文化产业发展集团有限公司（原中国印刷集团公司）成立于2003年2月。2012年5月，经国务院批准，划入国国新，成为其全资子企业。2014年5月，正式更名为中文文化产业发展集团公司。中文发集团以“打造一流的国有文化资本投资运营集团”为目标，聚焦服务文化强国战略，深入开展文化产业布局和转型升级。成功打造“新华1949”园区品牌，具备定位规划、设计改造、招商引资、园区运营、物业服务、产业孵化的全流程服务能力，积极探索产业孵化运营新模式，着力打造综合型文创园区开发运营商，塑造文化园区专业化开发经营央企品牌。拥有传媒、出版、印刷科研及行业标准制定等专业能力和资源，提供跨领域全媒体运营、创意设计、会展活动、研发支持等全方位服务，打造文化传媒及内容创新平台，服务国家文化数字化战略落地。
