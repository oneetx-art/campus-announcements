## 公司
性质:民企 · 行业:通信/电子/半导体

浙江六方半导体科技有限公司（六方科技）成立于2018年，致力于半导体新材料研发，聚焦碳化硅涂层技术的研发及其在半导体产业中的应用，并逐步布局TaC涂层、Solid SiC等产品。现阶段，公司主要产品为碳化硅涂层外延托盘，包括LED芯片外延用SiC托盘、硅单晶外延托盘、碳化硅外延设备配套热场部件、硅基氮化镓外延托盘、单晶硅拉单晶热场部件、光伏行业碳化硅涂层产品等。公司同时生产TaC涂层产品，用于碳化硅衬底生长设备的热场部件及碳化硅外延托盘等。
