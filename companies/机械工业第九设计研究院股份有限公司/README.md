## 公司
性质:央国企 · 行业:机械/制造业

机械工业第九设计研究院股份有限公司创建于1958年，是我国专业从事汽车工厂规划、设计和建设的甲级设计研究院，是“国家高新技术企业、国家工业设计中心、国家企业技术中心”，连续多年被评为全国勘察设计综合实力百强和工程总承包及项目管理百强单位。公司拥有工程设计、工程咨询、工程监理、工程总承包等27项甲乙级资质，承担从汽车工厂电项目选到冲压、焊装、涂装、总装及新能源汽车电池电机等五大车间及物流系统的方案制定，从工程设计到完成工程建设、采购、验收、生产准备与调试等全部建设任务的交钥匙工程，提供汽车智能工厂全过程解决方案，被誉为“中国汽车工厂设计的摇篮”。公司现有员工1000余人，人才队伍与技术实力处于行业领先水平。拥有全国工程勘察设计大师4人，省级设计大师5人，省部级以上各类人才230余人，省级工程师及以上职称专业技术人才350余人，各类注册执业人员760余人次，硕士研究生、本科生及以上学历人才占比在85%以上。公司总部位于吉林省长春市，在长春、天津、上海、武汉及泰国、德国等地设有分子公司。
