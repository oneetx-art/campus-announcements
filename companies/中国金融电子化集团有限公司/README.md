## 公司
性质:央国企 · 行业:通信/电子/半导体

中国金融电子化集团有限公司（简称中国金电）是经国务院批准，在国内最早从事金融信息化建设的1988年正式成立的中国人民银行直属企业。2006年开始实施现代企业制度改革，全面承担央行软件开发、系统集成、同城灾备等职能。2021年完成公司制改制，目前聚焦央行关键基础设施支撑与服务保障，致力于促进金融科技水平整体提升。
