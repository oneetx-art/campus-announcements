## 公司
性质:央国企 · 行业:能源/化工/环保

江苏淮安国信热电有限公司位于江苏淮安经济开发区，成立于2024年1月，由江苏淮阴发电有限责任公司、淮安市国有投资发展集团能源有限公司、淮安开发控股有限公司、淮安市宏信国有资产投资管理有限公司共同出资成立，注册资本金3.4亿元。公司在建规模为2×220t/h高温高压循环流化床锅炉+2×CB25MW级抽汽背压式汽轮发电机组热电联产项目，预留二期扩建条件。第一套机组计划于2025年底投产，建成后将具备311t/h的供热能力，是淮安市东部片区主要热源点。公司在建项目能源利用率高，节能效果显著，是一个高效、节能、环保型的建设项目。
