## 公司
性质:事业单位 · 行业:医疗/医药/生物

中国医学科学院生物医学工程研究所是国家级社会公益类研究所，1960年创立，现坐落于天津市。主要从事生物医学工程新方法、新技术、新材料的研究与开发，设有北京协和医学院生物医学工程和药学博士后流动站、天津天开高教科技园博士后工作分站。
