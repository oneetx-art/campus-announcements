## 公司
性质:民企 · 行业:医疗/医药/生物

联邦动保是联邦制药集团旗下成立的品牌，现有3个生产基地，分别是内蒙古联邦动保药品有限公司、河南联牧兽药有限公司、珠海联邦动保有限公司。珠海联邦动保有限公司成立于2023年1月，位于珠海市金湾区南水镇，项目总投资10.5亿元，占地面积100亩，年产值预计可达15亿元。涵盖畜禽、水产、反刍及宠物四大领域。主要生产头孢类兽药产品、大环内酯类产品、宠物用药等，并通过引进国外高附加值产品强化品牌竞争力。
