## 公司
性质:民企 · 行业:金融业

甬兴证券有限公司（以下简称“甬兴证券”）于2020年1月22日获中国证监会核准设立，同年10月8日正式开业。甬兴证券注册资本30亿元，股东为宁波开发投资集团有限公司和宁波市金融控股有限公司。甬兴证券是国内十多年来批准设立的首家纯内资、多牌照、综合性证券公司，也是宁波市唯一的证券法人机构。公司总部位于浙江宁波，在宁波、上海、北京、深圳、成都、杭州、青岛、苏州、天津等地共设有多家分支机构，经营范围为证券经纪、证券投资咨询、证券自营、证券承销与保荐、证券投资基金销售。甬兴证券下属全资子公司上海甬兴证券资产管理有限公司，主管证券资产管理；下属全资子公司甬兴股权投资（宁波）有限公司，主营另类投资。在宁波市委市政府和出资人全方位支持下，甬兴证券实行市场化运营机制，吸纳了大量精英人才加盟，公司正加速向“创建现代精品投行、塑造百年金融老店”的目标大步迈进。
