## 公司
性质:央国企 · 行业:能源/化工/环保

深圳赤湾胜宝旺工程有限公司（赤湾胜宝旺）成立于1994年，是一家国有控股企业，持股股东分别为：中海石油投资控股有限公司持股36%；深圳市新南山控股集团联合智造有限公司32%；赤晓企业有限公司持股32%。赤湾胜宝旺位于深圳南山赤湾港东岸，自成立以来，先后完成了多个海上及陆上大型总包项目，获得了国内外知名企业的认可，在海洋工程装备建造领域拥有丰富的经验，特别是在导管架建造方面，是国内领先的海洋工程项目建造专家。公司立足国内传统油气业务的同时，积极开拓国际市场，发展业务和产品的多元化，向新能源赛道发力。
