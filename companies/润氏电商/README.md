## 公司
性质:民企 · 行业:IT/互联网/游戏

润氏电商（润氏集团）2011年创立于上海，2014年迁至信阳成立公司，注册资本3000万元。公司专注电商运营，业务涵盖推广引流、品牌与店铺运营、品牌代运营、短视频与直播带货，以及新媒体内容的全渠道运营。合作知名品牌10余家，运营店铺40余家，深耕家电品类，擅长爆款打造与精细化运营，多类目店铺行业领先。14年来，公司拥有成熟品牌运营经验和资源，重视人才与合作，屡获电子商务示范企业、诚信纳税单位等荣誉。
