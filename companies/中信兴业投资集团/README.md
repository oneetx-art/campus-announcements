## 公司
性质:央国企 · 行业:政府/机构/组织

中信兴业系中国中信集团有限公司全资子公司，前系中信上海信托投资公司，成立于1988年，2012年更名为“中信兴业投资集团有限公司”。作为中信集团的国有资本运营平台，集团以资本和股权运营为两大目标，大力发展战略性投资、战略性保值增值对象、统筹国有资本布局和国有资产持股和财务性投资三类业务，着力打造具备核心能力、具有中信特色的高质量国有资本运营公司。
