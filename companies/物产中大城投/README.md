## 公司
性质:央国企 · 行业:金融业

物产中大城投（宁波）控股有限公司成立于2023年6月，由宁波城建投资集团有限公司联合省属特大型国企——世界500强物产中大集团股份有限公司共同发起，旨在融入杭甬“双城记”，推进省地国企合作、执行好宁波市政府和物产中大集团战略合作协议。公司依托股东优势，引入物产中大集团的智慧供应链和特色资管业务、管理模式、品牌和专业团队等市场化经营资源，围绕宁波城投集团的城市开发、产城融合、城市运营、资本运作等核心主业，致力于在城市资产管理与产业并购、城市资源配置与城市供应链等领域通过优势互补、资源共享，实现质效提升、多方共赢，奋力打造省地国企合作新标杆。
