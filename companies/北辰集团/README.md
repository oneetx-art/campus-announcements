## 公司
性质:央国企 · 行业:房地产业/建筑业

北京北辰实业集团有限责任公司（北辰集团）成立于1990年8月8日，是一家以会展、房地产开发、商业物业经营为主要业务的北京市属大型国有企业。由北辰集团独家发起设立的北京北辰实业股份有限公司（北辰实业），是国内第一家A+H股地产类上市公司，旗下首都会展集团、北辰地产集团和北辰商业管理公司三个重要子企业，承担着北辰大部分主营业务。由北辰集团开发建设的国家会议中心二期和首都国际会展中心，是北京市级重点工程项目，现已投入运营。
