## 公司
性质:民企 · 行业:能源/化工/环保

泰山集团是一家集研发制造工业锅炉、电站锅炉、压力容器、变压器、高压开关等产品的高新技术企业。产品远销亚、欧、美等与控制、输变电、核电配套及化工新能源装备等领域，基本涵盖了锅炉热、变配电、输配电的相关产业链。泰山集团坐落于五岳独尊的泰山脚下，总占地面积500余亩，员工3000余人，主营业务收入60多亿元，旗下拥有锅炉、电站设备、压力容器等十大产业板块20余家子公司。泰山集团还拥有1个国家级企业工程技术研究中心、省级院士工作站、省级瞪羚企业-小巨人企业，2个工程技术研究中心、省级专精特新示范企业、市级科技领军（研究院）企业，3个省级科技领军研究中心、市级工程实验室，4个省级制造业单项示范企业，7个高新技术企业。
