## 公司
性质:民企 · 行业:贸易/批发/零售

福建六融工业有限公司隶属宏翔集团，集团始于1986年，历经40年发展，涵盖“化纤→塑料→成衣”完整产业链的纺织行业先进制造企业集团。作为全球首家功能化纤一站式全产业链无缝闭环园区，公司实现“纺织（染）→加弹→织造→染整→印花→成衣”一体化生产。占地370亩，建成后员工超5000人，年产成衣超1亿件。主营高尔夫（网球）、瑜伽、功能跑步、舒适户外、泳装等高端服饰系列。与国内以及全球部分顶尖运动户外品牌深度合作。
