## 公司
性质:民企 · 行业:商务服务业

大信会计师事务所（特殊普通合伙）成立于1985年，是我国注册会计师行业恢复后首家合伙所。立足北京，分所遍布全国，近40年发展为大所，服务海内外上万家客户（含央企、省属国企、A/B股上市公司及拟上市公司），提供审计、管理咨询、IT审计等服务。注册资本5110万元。2023年“百强所”综合排名第十三，本土所第9位，央企年报核批大企业集团客户排名第9位，上市公司年报审计客户排名第1位，IPO业务排名第10，2024年排名第1。多次获财政部、证监会、国资委等企客户满意度调查好评与信赖的民族品牌所。
