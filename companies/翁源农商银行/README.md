## 公司
性质:民企 · 行业:金融业

广东翁源农村商业银行股份有限公司（简称：“翁源农商银行”）于2015年5月6日挂牌成立，是韶关市首家在农信社基础上改制成的农商行。从业人员258人，营业网点18个，存贷款市场份额、金融机构领先地位、服务范围、纳税贡献均位于翁源县支农小龙头。秉承“翁源人自己的银行”理念，聚焦“打造广东省最优农商行”目标，坚持“特色办行、科技立行、人才强行、合规守行”，致力于为客户提供更优服务、为股东创造更大价值、为员工搭建广阔平台、为社会承担更重责任。
