## 公司
性质:央国企 · 行业:机械/制造业

昊华气体有限公司成立于2020年7月，隶属于中昊化上市体公司--昊华化工科技集团股份有限公司。公司拥有气体业务板块的科研院所、企业、科技投资和整合的原化工部直属资产、产业资源，具有创新成果的科技型企业，传承60余年的技术积累与创新成果，专注于电子信息化学品。作为国内特种气体行业内的技术引领者，我们拥有国家重要的特种气体研究生产基地，具备自主知识产权,其特种气体制备综合技术、产品涵盖氟电子特气、其他高纯电子特气及其他特种气体，广泛应用于电子信息、电力设备制造、LED、光纤、太阳能光伏、医疗健康、环保监测等多个领域。
