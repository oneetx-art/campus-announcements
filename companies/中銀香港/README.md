## 公司
性质:央国企 · 行业:金融业

香港主要商業銀行集團，香港三家發鈔銀行之一，香港唯一人民幣業務清算行。成立於1917年，秉持「根植於斯，服務於斯」的宗旨，為各持份者及社區增創價值。擁有全港最龐大的分行網絡以及電子化、多元化的服務渠道，在各主要商務市場位居前列。積極拓展東南亞業務，分支機構遍及東南亞九國，為當地及跨境客戶提供專業優質的金融服務。
