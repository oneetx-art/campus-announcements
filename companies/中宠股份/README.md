## 公司
性质:民企 · 行业:快速消费品

中宠股份创立于1998年，是中国宠物食品的开创者，更是中国宠物行业的龙头企业，于2017年成功上市，是中国宠物行业第一家深交所主板上市企业。旗下拥有“WANPY顽皮”、“TOPTREES领先”、“新西兰ZEAL真致”等自主品牌，产品涵盖犬用、猫用两大类别，涉及宠物干粮、湿粮、零食、冻干、饼干、洁齿骨等全线产品1000余个品种，是中国宠物食品行业产品线最长、产品最全的企业之一。产品已销往全球五大洲、90个国家，自主品牌出口全球77个国家，致力于成为全球宠物食品行业的领跑者。
