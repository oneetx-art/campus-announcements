## 公司
性质:民企 · 行业:能源/化工/环保

四川和邦投资集团有限公司是一家集科研、生产、销售和服务为一体的全球化制造企业，旗下控股上市公司——四川和邦生物科技股份有限公司（股票代码：603077）。集团以矿业为核心，通过自有、投资与合作等方式，已在澳大利亚、尼日利亚、乐山、雅安、会理、新疆涵盖金、银、铜、地锌铅、钾（开发钾矿43矿）、锂、硼、盐、盐、硅石11类矿种，储量丰富、结构多元。在化学领域，和邦以乐山总部为基地，已发展成为具备显著成本与质量优势的平台型化学品制造企业。
