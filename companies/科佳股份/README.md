## 公司
性质:民企 · 行业:IT/互联网/游戏

哈尔滨市科佳通用机电股份有限公司成立于2003年，是一家高新技术企业，主要从事轨道交通运行安全装备的研发、生产、销售及服务。公司总部位于哈尔滨市经开区，北京设立分公司，研发生产基地占地面积近4万平方米，凭借在轨道交通人工智能图像采集、处理、识别与机车信号系统等领域的深入研究和技术积累，长期服务于全国铁路和城市轨道交通等客户。公司重视产品技术提升，近三年研发投入占比23%。公司具备专业的数据及算力中心，先进的产品检测实验室，3条铁路专用试验线，设有企业博士后科研工作站，与哈工大共建“交通综合智能检测产业技术研究院”。
