## 公司
性质:央国企 · 行业:金融业

广发银行成立于1988年，是国内首批组建的全国性股份制商业银行之一。南昌分行作为广发银行直属省级分行，自2016年11月26日正式成立以来，全面落实江西省人民政府与广发银行签署的战略合作协议，紧密围绕省委省政府的发展战略，发挥广发银行的比较优势，积极对接支持省市重大项目建设，务实推进绿色金融、普惠金融，服务实体经济，助力中国式现代化江西建设，取得了良好成效，受到社会各界的充分肯定和广泛赞誉。
