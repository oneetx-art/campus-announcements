## 公司

中国中煤能源集团有限公司（简称中国中煤），前身是1982年经国务院批准成立的中国煤炭进出口总公司，经过多次更名重组，2009年改制成为国有独资公司，并更名为中国中煤能源集团有限公司。2016年，中央对中国中煤集团实施联合重组，中国中煤集团成为国家能源集团的重要骨干企业，肩负着保障国家能源安全的重要使命。
