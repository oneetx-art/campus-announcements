## 公司
性质:民企 · 行业:能源/化工/环保

浙江阳光绿色氢能科技有限公司（简称阳光绿氢）是浙江阳光照明电器集团股份有限公司（股票代码：600261）全资子公司。公司位于浙江省绍兴市上虞区，成立于2024年1月5日，注册资本2亿元。公司专注于AEM（阴离子交换膜）电解水制氢技术的研发、生产与应用，是专业从事AEM电解槽、BOP控制系统、辅助系统、膜电极和催化剂研发、生产、销售的创新型企业。产品广泛应用于可再生能源配套制氢、工业绿氢替代、加氢站与交通能源、能源存储与整合等领域。成立两年来，阳光绿氢团队规模超70人，研发人员占比50%，其中博士、硕士近30人，实现了AEM设备生产全产业链自主可控。公司与浙江大学、天津大学绍兴研究院等科研院所合作，聚焦AEM电解槽及系统，催化剂和膜电极开发，确保技术领先。
