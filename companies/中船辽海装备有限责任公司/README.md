## 公司
性质:央国企 · 行业:机械/制造业

中船辽海装备有限责任公司隶属于中国船舶集团有限公司（世界五百强企业）。公司拥有南北两个园区，注册地为沈阳市和平区三亚街2号，生产加工基地位于沈阳市和平区旺族路180号，占地总面积7.3万平方米。前身沈阳红旗机器厂，始建于1960年，2010年完成公司制改制。公司现有中船辽海公司、上海中船电子技术有限公司、中船三海通信科技（沈阳）有限公司、江洋海盛（沈阳）有限责任公司、中船海通电子科技（沈阳）有限公司等子公司。
