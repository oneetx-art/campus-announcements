## 公司
性质:民企 · 行业:汽车制造/维修/零配件

瑞鹄汽车模具股份有限公司2002年3月成立于国家级芜湖经济技术开发区，2020年9月在深交所主板上市（股票简称：瑞鹄模具，股票代码：002997）。历经二十余年发展，形成包括瑞鹄汽车模具股份有限公司、安徽瑞祥工业有限公司、芜湖瑞鹄轻量化技术有限公司、芜湖瑞鹄浩博模具有限公司等十家控股子公司及多家参股公司的集团化企业。集团现有员工超3,000人，2024年集团营收24亿元，实现利润3.5亿元。集团主营业务为汽车制造装备业务（包括冲压模具及检具、焊装自动化生产线及机器人系统集成和移动机器人）、汽车轻量化零部件业务（包括高强度板及铝合金板材冲焊零部件、铝合金精密铸造零部件及一体压铸车身结构件）。集团有180余项知识产权，主持制定3项行业标准，承担10余项国家、省级项目，在安徽芜湖、湖北武汉、天津设研发技术中心。凭借技术研发实力等优势，瑞鹄集团在行业内知名度较高，与众多国内外知名汽车厂商合作。产品及服务覆盖全球20余国的30余个品牌，获客户赞许和荣誉。
