## 公司
性质:民企 · 行业:IT/互联网/游戏

2023年6月，由中国电子与财信金控共同组建的数字湖南有限公司（简称数字湖南）在长沙正式揭牌成立，公司注册资本5亿元人民币。数字湖南作为省级国有数字政府建设运营公司，肩负着支撑湖南省数字政务创新发展的重要使命。公司以数字政务建设运维为核心主业，先后承接湖南省数字政府顶层设计、“湘易办”超级服务端建设运营、省大数据总枢纽平台、省“一网通办”系统建设、省政务云平台运维、“高效办成一件事”、全省政务信息化项目全生命周期管理等重要工作。
