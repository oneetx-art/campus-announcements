## 公司
性质:事业单位 · 行业:教育/培训/科研

东海实验室是由舟山市政府举办，联合浙江大学、自然资源部第二海洋研究所共同建设的新型研发机构，是浙江省重点建设的实验室，成立于2022年5月17日。实验室聚焦国家战略需求和工程应用，围绕国家战略需求，布局海洋观测、海洋能源与资源开发、海洋信息与人工智能、空海装备四大科研集群和通用技术等板块，致力于构建“技术研发-装备研制-场景验证-成果转化”创新模式，并行建设高端装备、新型海洋重要装备科技展厅。
