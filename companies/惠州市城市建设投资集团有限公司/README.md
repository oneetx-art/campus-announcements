## 公司
性质:央国企 · 行业:房地产业/建筑业

惠州城投集团成立于2014年11月，是集全市重大基础设施投融资建设及开发运营为一体的国有企业，公司注册资本24.93亿元人民币，主体信用评级AA+。集团现有全资及控股企业34户，2家施工总承包“双一级”企业、1家旅投公司、1家建筑“总承包二级企业、1家监理甲级企业。集团坚持“与城共生，惠顾未来”的愿景，聚力城市发展建设、公用服务、运营保障三大主业，努力做强“城市建设、城市开发、城市运营、城市保障”四大业务板块，全力打造区域一流的城市综合开发建设运营商。
