## 公司
性质:民企 · 行业:医疗/医药/生物

山东百诺医药股份有限公司成立于2000年8月，位于山东济南，专注医药研发，构建了原料及制剂药学研发平台、中试生产制造平台、BE试验平台等医药研发生产完整产业链。公司员工900余人，截至2025年9月，在研项目310余项，成功开发各类新药330余个，240余项产品获得新药证书或生产批件，近三年取得生产批件114项，持有知识产权110余项。目前与200余家医药企业建立了长期稳定的合作关系，其中包括百强企业50余家，上市企业60余家。
