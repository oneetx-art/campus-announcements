## 公司
性质:央国企 · 行业:房地产业/建筑业

武汉市市政工程设计研究院有限责任公司（以下简称“武汉市政院”）成立于1954年，为市城投集团公司100%控股子公司，是集城乡规划、工程勘察、设计、项目管理、监理、检测和技术研发一体的综合型市政设计企业。曾荣获全国先进设计企业、中国工程设计企业60名、中国水利设计企业30名、全国高新技术企业、湖北省勘察设计企业综合实力十强、湖北省首批混合所有制改革企业、武汉市具有深厚的创业创新底蕴，获批“湖北省博士后创新实践基地”“湖北省企业技术中心”“武汉市企业研发中心”“武汉市科技成果转化平台”。武汉市政院坚持以“做城乡建设运营大都市区整体解决方案供应商”为发展愿景，积极融入国家、湖北省、武汉市重大发展战略，立足“双城”、智慧化、数字化、生态环境治理等治理理念，拥有城乡规划、工程咨询、工程勘察（测绘）、检测、工程设计、工程监理、工程施工等多个行业建设一级资质，致力于为客户提供高品质的市政工程建设一体化解决方案。
