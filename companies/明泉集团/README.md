## 公司
性质:民企 · 行业:能源/化工/环保

明泉集团始建于1958年，现有济南园区和泰安园区两大生产基地。业务范围覆盖基础化工、高端化学品、高分子材料等领域，产品包括绿色高氮功能性肥料、甲醇、双氧水、吡啶、聚苯硫醚、光敏聚酰亚胺等，下游领域涉及现代农业、汽车轻量化、航空航天及半导体封装等行业。集团先后获得中国氮肥工业发展60周年先进企业、全国行业节约能源先进企业等荣誉称号。
