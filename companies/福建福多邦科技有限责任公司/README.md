## 公司
性质:央国企 · 行业:能源/化工/环保

福建福多邦科技有限责任公司（简称公司），注册资本15.6亿元，注册地址清流县，是福建省属国有企业福建省三钢（集团）有限责任公司的全资子公司。公司现有萤石矿山采矿权2个，萤石矿区探矿权1个；已建三条2.5万吨/年电子级氟化氢生产线，一条2万吨/年UP级电子氢氟酸生产线；在建一条3万吨/年电子级氢氟酸生产线，1.7万吨/年PTFE、3000吨/年FEP生产线。公司旗下拥有福多邦永福公司、福多邦兴福公司、津鹏矿业公司、福多邦聚福公司（筹备）、氟化工科学技术研究院（含博士后工作站）等，托管企业市国投矿业、福多邦金福公司。
