## 公司
性质:央国企 · 行业:能源/化工/环保

国网电科院（南瑞集团）是国家电网公司直属科研产业单位，由1973年成立的水利水电科学研究院自动化研究所发展而来。历经50多年创新发展，已成为我国能源互联网领域高科技领军企业，主要业务涵盖电网研发、输变电、柔性直流输电等领域，自主研发的智能融合、能源互联网辅助、新能源网安全稳定控制等核心技术，推动国家电网公司南瑞（600406）最高市值超2600亿。
