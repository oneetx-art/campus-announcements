## 公司
性质:民企 · 行业:通信/电子/半导体

唯捷创芯成立于2010年6月，注册资金430,313,008元。总部位于天津，目前在北京、上海、成都、深圳等地均设有分支机构，已在上海证券交易所科创板上市。公司专注于射频前端芯片及模组的研发、设计和销售，主要为客户提供射频功率放大器模组、Wi-Fi射频前端模组和接收端模组等集成电路产品。公司通过10余年间不断的设计迭代和量产验证，已具备成熟的2G至5G射频前端模组产品，广泛应用于智能手机、平板电脑、无线路由器、智能穿戴设备等具备无线通讯功能的各类终端产品。
