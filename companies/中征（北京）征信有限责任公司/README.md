## 公司
性质:央国企 · 行业:金融业

中征（北京）征信有限责任公司是中国人民银行征信中心全资子公司，2009年4月成立，总部位于北京，在上海和天津设有分公司。公司作为业务支持和金融科技创新服务型企业，坚持以服务支持金融体系建设为己任，围绕金融信用信息基础数据库提供业务支持、技术研发测试、系统维护等服务，承担资金流共享平台建设和增值产品研发等重点任务支持工作。
