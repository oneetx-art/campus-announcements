## 公司
性质:央国企 · 行业:交通/物流/仓储

上港集团物流有限公司（简称“上港物流”，英语简称“SIPGL”）成立于2006年，是上海国际港务（集团）股份有限公司全资拥有的港口物流领域核心企业。公司总部设在上海，在华东、华北、华南、西南地区均设有区域公司。
