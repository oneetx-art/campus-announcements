## 公司
性质:其他 · 行业:金融业

中国信托业保障基金有限责任公司（简称公司）是经国务院同意，国家金融监管部门批准设立的银行业金融机构。公司注册资本115亿元人民币，为国家金融监督管理总局直管单位，参股中国信托登记公司、建元信托、兴宝信托等多家金融机构。公司作为中国信托业保障基金（简称保障基金）的管理人，负责保障基金的筹集、管理和使用，并依据监管部门核准的经营范围开展金融业务。公司的主要任务和目标是按照市场化原则，预防、化解和处置信托业风险，促进信托业持续健康发展。
