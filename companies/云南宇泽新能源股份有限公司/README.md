## 公司
性质:民企 · 行业:能源/化工/环保

云南宇泽新能源股份有限公司为上海鑫融合实业集团有限公司控股子公司，于2019年5月成立，注册资本15.634亿元。公司总部位于云南，自成立即立足N型硅片生产研发，是行业首家N型硅片制造商，公司产品全面覆盖N型电池HJT、TOPCon和IBC三大主流技术路线。目前，在云南楚雄、文山、昆明及江西宜春设有四大制造基地，在苏州设供销中心，昆明设运营中心。云南宇泽作为一家技术创新型企业，先后获得国家级高新技术企业、国家级专精特新“小巨人”企业、省企业技术中心、省级硅材料绿色制造工程研究中心等荣誉，并成功入选“2022年中国独角兽企业”榜单，成为云南省第一家独角兽企业。云南宇泽秉持“市场N时代，宇泽N+1”的发展理念，不断创新突破、拓展和延伸产业链，已规划拓展绿色能源整体技术应用产品，推动人类可持续发展。
