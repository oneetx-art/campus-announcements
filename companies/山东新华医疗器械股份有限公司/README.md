## 公司
性质:央国企 · 行业:医疗/医药/生物

新华医疗创建于1943年，是我国最早创建的医疗器械生产企业，是中国医疗器械行业协会会长单位，中国医学装备协会副理事长单位，中国医药设备工程协会理事单位。新华医疗现拥有医疗器械、制药装备两大核心业务，同时以医疗商贸、医疗服务为支撑，形成“2+2”高端板块。
