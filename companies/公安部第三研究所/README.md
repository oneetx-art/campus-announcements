## 公司
性质:事业单位 · 行业:教育/培训/科研

公安部第三研究所是公安部直属科研机构。公安部第三研究所是正局级建制，1978年在上海成立。自创建以来，始终将服务公共安全作为工作、服务警察实战、服务社会公共安全领域为己任，通过研究公安和社会公共安全领域相关政策和技术研发，为社会公共安全服务及技术支持。三所拥有一支由1100余人组成的专业安全、技术过硬、朝气蓬勃的科研队伍，其中博士、硕士730余名，涉及系统安全、物联网、特种技术、数据安全、密码技术、经济侦查、情报指挥、禁毒、检测认证、网络安全等级保护等专业领域。在上海设有徐汇、浦东、杨浦3个园区，在北京、广州、乌鲁木齐三地派驻有5个机构。
