## 公司
性质:央国企 · 行业:机械/制造业

中国航空工业集团有限公司（简称“航空工业集团”）是由中央管理的国有特大型企业，经营范围涵盖航空通用装备、航空运输、飞行试验、直升机系统、通用航空、军用航空类飞机、直升机、供应链、金融、工程建设产业，下辖100余家成员单位、直属企业、专用装备、汽车零部件、资产公司、25家上市公司，员工逾40万人。江西洪都航空工业集团有限责任公司（简称“航空工业洪都”）隶属航空工业集团，1951年4月23日创建于英雄的诞生地，公司科研第一、生产第一、保密第一、质量第一，是新中国第一架飞机和第一枚海防导弹的诞生地。公司集科研、生产于一体，兼具“厂所合一、机弹合一、战训合一”特点，建有国家级企业技术中心和中国航空工业集团级及对面级武器研发中心，是中国航空工业上市公司，现未员工万余人。
