## 公司
性质:央国企 · 行业:机械/制造业

南方水泥有限公司是央企中国建材股份有限公司（HK3323）的水泥板块核心企业之一，于2007年9月26日正式在上海注册成立。公司拥有员工7万余人，总资产702亿元，业务范围涵盖水泥熟料、水泥制品、骨料及混凝土等板块，在浙江、上海、江苏、安徽、湖南、江西、广西、福建等地拥有19个省市，542万吨、水泥产能9895万吨，市场覆盖上海、苏中、苏南、皖南、皖中、皖南、浙江、福建等地区。
