## 公司

中国船舶集团有限公司第七一六研究所（下简称七一六所）隶属于中央直接管理的特大型国有骨干企业中船集团，是一个以军为本，集科研生产经营于一体的综合性研究所，是我国国防现代化建设和国民经济建设的一支重要力量，各类专业技术人员占员工总数的80%以上。位于景色秀丽花果山下。现有从业人员2700余名，各类专业技术人员1900余人，其中硕士研究生以上学历1300余人，高级职称人员900余人，“国务院政府特殊津贴”等各类省部级以上专家120余人。七一六所已形成以智能装备和电子信息为主的两大业务方向，建有完整的经营管理体系、科技创新体系和人才培养体系，拥有1个国家级国防科技工业创新中心、4个船舶行业测试中心、18个省部级创新平台。
