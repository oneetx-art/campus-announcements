## 公司
性质:央国企 · 行业:机械/制造业

中国电气装备集团供应链科技有限公司于2022年3月31日在上海市静安区注册成立，是中国电气装备在沪设立的重要平台企业之一，承担集团公司工装装备部件集中规模采购与供应、大宗原材料采购加工与供应、电子商务平台建设与运营、供应链结算服务与创新等核心业务。公司以打造智慧型、服务型、廉洁型的电气装备现代供应链公司为定位，坚决扛起“物资供应保障、集团战略物资储备、集团物资管理支撑、大宗商品交易、原材料深加工供应链功能管理、电子采购平台建设与运营、供应链结算技术、采购优化3种支撑手段、原材料深加工5项核心功能，协同电子采购平台目标，聚焦从传统物资采购企业向链主智能供应链服务公司、从规模驱动向创新驱动、供应链安全3个转型发展。
