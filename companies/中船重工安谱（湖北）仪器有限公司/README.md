## 公司
性质:央国企 · 行业:机械/制造业

中船重工安谱（湖北）仪器有限公司成立于2016年6月，位于湖北省宜昌市，是中国船舶集团及七〇一研究所控股的高科技精密仪器技术人才国家认定的高新技术企业。公司拥有硕博士技术人才100余人，拥有湖北省创新中心、湖北省企业技术中心等4个科创平台。近年来，公司主持军地重点项目30余项，授权发明专利等知识成果50余项，获得省部级科技奖励3项，已逐步发展成为我国“核生化爆毒”监测领域的领军企业，先后入选湖北省高新技术百强企业和湖北省上市后备金种子企业，被工信部认定为国家级“专精特新”重点小巨人企业；2023年2月被国务院国资委认定为“创建世界一流专业领军示范企业”。
