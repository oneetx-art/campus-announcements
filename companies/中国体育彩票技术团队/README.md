## 公司
性质:事业单位 · 行业:政府/机构/组织

中国体育彩票秉承“来之于民，用之于民”的发行宗旨，始终倡导“公益体彩，乐善人生”的公益理念，将体彩公益金广泛用于社会公益事业和体育事业，被誉为公益事业的助推器、体育事业的生命线。中国体育彩票技术团队，作为服务于国家体育总局体育彩票管理中心的专业技术服务团队，涵盖由三家核心企业（中体彩彩票运营公司技术中心、中体彩科技公司、中体骏彩公司）集合的技术人才共同组建而成，目前800余人的组织规模。中国体育彩票系统总体规划、设计开展总体技术和数据管控，提供系统总体技术规范、设计；核心平台研发、集成测试、核心公共技术、云平台等；执行行业中台、数据中台、公共技术、技术云平台、乐透游戏、即开游戏、竞技游戏等项目开发以及服务支持工作，以推动体彩技术成为体彩业务的合作伙伴，助力国家公益彩票高质量发展。
