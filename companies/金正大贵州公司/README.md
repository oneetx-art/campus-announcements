## 公司
性质:央国企 · 行业:能源/化工/环保

金正大生态工程集团股份有限公司成立于1998年，2010年在深交所主板上市（股票代码：002470），是国家重点高新技术企业、国家创新型企业和国家技术创新示范企业。金正大集团在国内建有10个生产基地，在海外拥有西班牙、荷兰2个生产基地及10余个分支机构。金正大集团贵州公司成立于2011年，是一家集磷化工、新型肥料研发、生产、销售的大型磷化工企业，布局磷化工、高端新型肥料等多个品类，拥有金正大诺泰尔化学、正磷化工、金兴矿业、正磷新能源、瓮丰建材、贵州金正大肥、福泉金正大生态工程有限公司等7家公司，2024年主营业务收入42.6亿元。
