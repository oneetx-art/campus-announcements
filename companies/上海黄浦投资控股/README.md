## 公司
性质:央国企 · 行业:金融业

上海黄浦投资控股（集团）有限公司是黄浦区国资委全资的专业化国有资本投资运营平台，于2017年3月成立，是黄浦区政府投资基金的管理平台、新兴产业重要项目的股权投资平台、国资国企改革的资本运作平台，拥有近9年的政府投资基金管理经验，与央企国企、国际知名机构、社会资本形成长期合作，在推动上海国际金融中心建设、外滩金融集聚带建设等方面做出积极贡献。集团于2024年8月22日设立上海汇盈私募基金管理有限公司，注册地位于上海市黄浦区，已在中国证券投资基金业协会完成登记备案。现围绕集团战略发展需要，面向全社会公开招聘优秀人才
