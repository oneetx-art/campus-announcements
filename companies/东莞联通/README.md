## 公司
性质:央国企 · 行业:通信/电子/半导体

中国联合网络通信集团有限公司（以下简称中国联通）成立于1994年7月，是国务院国资委监督管理的中央企业之一，拥有覆盖全国、通达世界的现代通信网络和全球客户服务体系，在国民经济中具有基础性、支柱性、战略性、先导性的基本功能与地位作用。东莞联通成立于1997年3月，是中国联通在东莞地区的分支机构。近年来，在市委、市政府的正确领导和大力支持下，东莞联通认真履行央企“三大责任”，全面落实新发展理念，经营规模和综合绩效保持全省前列，2022年昂首迈入中国联通战略业务单元，2025年主营收入35.69亿元，成功蝉联“全国文明单位”，首次获评“广东省五四红旗团委”，为推动东莞加快建设“智创优品、和美宜居”发展目标，贡献联通智慧和力量。
