## 公司
性质:央国企 · 行业:快速消费品

南宁香山制糖有限责任公司于2022年4月14日注册成立，是国控控股企业。其前身南宁糖业股份有限公司香山糖厂于1975年2月筹建，次年12月竣工投产，经过50年的技改和扩建，现已发展为日榨甘蔗9000吨，年单机剥蔗约10万吨以上的大中型亚法压榨机生产企业。
