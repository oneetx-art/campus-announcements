## 公司
性质:央国企 · 行业:农林牧渔

中国储备粮管理集团有限公司是经国务院批准组建的涉及国家安全和国民经济命脉的国有大型重要骨干企业，受国务院委托具体负责中央储备粮棉油的经营管理，同时接受国家委托执行粮棉油购销调存等调控任务，实行集团-分（子）公司-直属库“三级架构”。目前下设24家分公司，11家二级专业子公司和1家控股公司，人员、机构和业务覆盖全国31个省、自治区、直辖市。中储粮储运有限公司（简称储运公司）是中储粮集团公司设立的专业化子公司，重点以做好中央事权粮食经营管理、港口物流中转和谷物专调调控任务等为主营业务。目前在国内全资或控股粮食仓储、中转（运输）等14家直属企业，分布在玉米主产区和主销区以及沿海沿江的六省一区。
