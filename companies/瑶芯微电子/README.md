## 公司
性质:民企 · 行业:通信/电子/半导体

瑶芯微（上海）电子科技股份有限公司成立于2019年，专注于功率器件、智能传感器和信号链IC的设计、研发与销售，公司总部坐落于上海市张江高科技园区。在西安、成都、深圳和日本京都分别设有研发、销售中心。公司产品包括硅基功率器件、第三代化合物半导体碳化硅功率器件、MEMS器件及信号链芯片等，广泛应用于车载、新能源、工业和消费电子，提供芯片、模组及相应的解决方案，专注于能源和信息，在成为国际一流的模拟器件和数模混合芯片公司。
