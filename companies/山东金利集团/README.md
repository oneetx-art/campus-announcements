## 公司
性质:民企 · 行业:机械/制造业

山东金利集团成立于1999年，是国内工程机械零部件领域产品最齐全的制造企业，主要从事于液压缸、伺服电缸、硬管总成、软管总成、液压油箱、液压集成阀、液压流体件、结构件、驾驶室、平衡铁等产品研发、生产、销售，以及激光下料、新能源行业投资、输变电总包等业务，目前已为全球50多个客户提供高端零部件产品解决方案及服务支持。集团现有三个生产基地，下辖三家国家级高新技术企业，三家科技型中小企业，现有员工2200余人。
