## 公司
性质:民企 · 行业:机械/制造业

兴机电器集团有限公司成立于1989年，是研发、生产、销售配电开关元件及提供专有管家解决方案的高新技术企业。现拥有国家授权专利251项，其中发明专利41项。公司先后获得隐形冠军培育“小巨人”企业、浙江省隐形冠军企业、浙江省“专精特新”企业等荣誉。建有省级企业研究院、省级博士后工作站和CNAS实验室。兴机电器集团历经三十多年的发展，环网开关市场主机技术领先、中压开关柜配件占市场主导地位。公司服务超过2000家客户，产品出口覆盖4大洲14个国家，已与世界500强跨国电气巨头建立了忠诚的合作关系，成为电器配件行业的领导品牌。
