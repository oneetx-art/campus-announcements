## 公司
性质:央国企 · 行业:能源/化工/环保

江苏国信高邮热电有限责任公司是隶属于江苏省国信集团有限公司，由江苏国信扬州发电有限责任公司与高邮市兴建设投资有限公司按照85%与15%的比例出资建成。公司坐落于江苏省高邮经济开发区，距市中心约4公里，距高铁站约5公里，占地面积为311亩，注册资本金2.2亿元。公司建设有两套100MW（6F）级燃气-蒸汽联合循环机组。均于2017年投产运营。公司年发电量10亿千瓦时、年供热量50万吨。
