## 公司
性质:央国企 · 行业:机械/制造业

中车大连机车研究所有限公司（简称中车大所）是中国中车股份有限公司全资子公司。始建于1922年，是我国轨道交通行业第一家综合性研究所。新中国成立后，经过恢复重建，发展成为以轨道交通装备关键系统与部件的研发制造、试验检测、科技信息和标准化等行业服务为主的高新技术企业。
