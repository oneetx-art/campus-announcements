## 公司
性质:央国企 · 行业:能源/化工/环保

大唐多伦煤化工公司是中国大唐集团有限公司（简称中国大唐）旗下子公司，位于内蒙古自治区锡林郭勒盟多伦县。多伦煤化工以低阶褐煤作为原料燃料，采用国际领先技术，可年产低褐煤作46万吨，同时制取石脑油、工业液化气、硫磺、甲醇等副产品。为提升煤化工产业向下延伸，锡品牌等产品为压力开辟了新路径，更实现了褐煤资源化的历史性转变。
