## 公司
性质:央国企 · 行业:机械/制造业

中国航空集团有限公司（简称“中航集团”，CNAH），2002年10月11日成立，是特大型国有航空运输集团公司，也是中国唯一载国旗飞行的航空运输企业。中航集团致力于打造具有国际竞争力的世界一流航空运输产业集团，坚持枢纽网络、客货并举、成本领先、品牌战略四个战略方向，不断增强政治能力、持续稳健的盈利能力、规模化生产组织能力、规范化基础管理能力、价值化品牌带动能力。截至2024年12月31日，中航集团（含控股公司）运营各型飞机952架，通过与星空联盟成员等空公司的合作，中航集团将客货运服务进一步拓展到190多个国家（地区）的1100多个目的地。
