## 公司
性质:民企 · 行业:能源/化工/环保

北京和碳环境技术有限公司成立于2010年3月18日，是国内领先的碳中和一站式服务商，2023年被中国节能协会碳中和专委会评选为碳中和领域最具成长性企业。公司总部在北京，通过15年的发展建立了全国性服务网络，为4000家企业提供节能低碳服务，为300个政府部门、工业园区提供绿色低碳智库服务，与国有A股上市公司悦达投资合资设立绿色低碳投资机构——江苏悦达和碳环境技术有限公司。
