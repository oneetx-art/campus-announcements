## 公司
性质:央国企 · 行业:金融业

2018年10月19日，北京金融控股集团有限公司简称北京金控集团注册成立。2022年3月16日，经中国人民银行批准，获得设立金控公司的行政许可，成为全国首批、地方首家金融控股公司。北京金控集团成立以来，坚守服务国家战略、服务首都发展、服务百姓生活的职责使命，着力防范金融风险，增强内生发展动力，提升创新竞争能力，坚定建设牌照体系健全、协同发展高效、风险防控有力、经营效益优良的国内一流持牌金融控股公司。在金融牌照管理板块，拥有银行、证券、期货、私募基金、资产管理、个人征信等牌照；在投融业务板块，组建境内外联动创新的投融资平台；在金融科技创新板块，构建涵盖大数据、征信、支付的基础设施，及面向企业、政府、个人的普惠金融及综合服务体系。
