## 公司
性质:民企 · 行业:机械/制造业

江西鑫通机械制造有限公司始创于1992年，现有员工2000余人，是国家高新技术企业，致力于地下矿山、地下工程硬岩掘进装备的研发与生产。拥有萍乡、沈阳、长沙三大研究院；六个现代化产业园区，其中涵盖两个主机园区及一个智慧工厂。核心经营：高端、高精密机械制造。集团公司已形成从研发-生产-销售-售后服务的完整产品体系，年产破50亿元，公司用“好核心产品，以企业品质、感恩心态服务于国家客户等，设立一级集团研究院及专精特新小团，高端工程学院、“华通动力”等省级技术中心，设有“产学研”用人才培养、高校工程师研修”等多平台高校联合培养与合作大学。
