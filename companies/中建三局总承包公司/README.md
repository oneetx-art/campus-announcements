## 公司
性质:央国企 · 行业:房地产业/建筑业

中建三局总承包公司于1995年4月8日在国家施工企业体制改革浪潮中应运而生。承担着“为集团发展增强实力、培养人才、积累经验、提高信誉”的光荣使命，秉持“争先进品、锤炼‘港城品牌、卓越品质、高尚品位’的‘三品’理念，逐渐成长为中建三局建筑业商务支柱直管公司，连续多年在中建集团综合考评中排名第一。
