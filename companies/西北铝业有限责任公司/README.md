## 公司
性质:央国企 · 行业:能源/化工/环保

西北铝业有限责任公司隶属于中国铝业集团有限公司，为中国铝业集团高端制造股份有限公司直属企业，是国内综合性大型铝加工企业。西北铝始建于1965年7月，主导产品为航空航天军工企业配套，距今已有60年的历史。建厂以来，西北铝为国家提供了约100万吨铝及铝合金材料，为我国的航空航天、国防军工及中国西部地区工业化做出了卓越贡献。西北铝2016年被认定为甘肃省工程技术研究中心，2017年被认定为高新技术企业，2019年被认定为省级工业设计中心，具有ISO9001、HSE、AS9100C、GJB9001B、PED、Nadcap等资质。
