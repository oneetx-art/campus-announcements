## 公司
性质:民企 · 行业:医疗/医药/生物

金宇生物技术股份有限公司成立于1993年，是中国保行业龙头企业、上市企业500强。公司专注于兽用生物制品、动物疫苗及诊断试剂的研发、生产与销售，拥有猪、牛、羊、禽、宠物五大类110余种疫苗及50余种诊断试剂。依托国家级企业技术中心，研发实力行业领先，市场占有率持续领跑。旗下设有金宇保灵、金宇优邦、金宇益康、金宇共立等分子公司，共同构建起覆盖主要畜禽及宠物的疫病防控矩阵。
