## 公司
性质:民企 · 行业:机械/制造业

北京高盟新材料股份有限公司（简称：高盟新材）成立于1999年，2011年上市（股票代码：300200），是国内高性能复合聚氨酯胶粘剂龙头企业和用户首选品牌。在北京、南通、武汉、上海、广州、清远拥有研发中心和生产基地，建立了由资深博士、硕士领军的180多个人组成的技术研发队伍，业务遍布国内及海外50多个国家和地区，产品广泛应用于软包装、印刷、交通输运、安全防护、家用电器、建筑材料、新能源、电机电器、电力电子、光学电子显示、航空航天、核电、芯片半导体等重要行业和领域，相关产品成功实现了进口替代并解决了卡脖子等技术难题。
