## 公司
性质:民企 · 行业:机械/制造业

上海和兰动力科技有限公司是上海澳控投资有限公司的全资子公司，成立于2013年10月，注册资本8亿元。公司围绕国家战略发展需求，专注“两机”领域关键技术和产品的研发与产业化。在航空发动机领域，走差异化路线，开展先进发动机核心技术的研发；在燃气轮机领域，重点研发小型燃气轮机，目前已形成从100KW到10MW一系列功率等级的产品，构建多种尺寸小、重量轻、污染物排放低、发电效率高的燃气轮机发电机组。
