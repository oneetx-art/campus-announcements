西华大学是四川省属重点综合性大学，始建于1960年，是四川省首批一流学科建设高校、四川省首批工程硕博士校企联合改革试点高校。现有多个校区，学科门类丰富，设有众多学院和本科专业，推进人才强校战略，着力打造高素质专业化教师队伍。
