## 公司
性质:民企 · 行业:能源/化工/环保

盈德气体成立于2001年10月，是致力于工业发展的大型专业气体公司。总部位于中国上海浦东自贸区，在杭州设有盈德工程，员工超过3500人。公司是领先的独立工业气体生产商，在海内外建成近170处生产设施，海外品牌NovaAir已在马来西亚、泰国等地成功运行多套空分装置。专注于现场制气、大宗液体、宝速德、包装气、稀特气、盈德工程（空分等深冷设备设计、制造）等业务，通过现场管道供气、液体储罐、瓶装气等方式，为合作伙伴供应氧、氮、氩等高品 质工业气体产品及创新气体解决方案。业务覆盖冶金、化工、电子、半导体、光伏、食品、医疗健康、新材、能源、环保等领域。
