## 公司
性质:民企 · 行业:通信/电子/半导体

深圳市沃尔核材股份有限公司（简称：沃尔核材，股票代码：002130）创建于1998年，作为国家级高新技术企业，公司不断布局战略性领域，形成了“电子材料、电力、通信线缆、新能源汽车、风力发电、智能制造”六大产品系列；公司产品广泛应用于核电、汽车、电子、电力、通讯、石化、轨道交通、航天航空等领域，营销网络遍及全国大中型城市，远销全球多个国家和地区；从研发热缩材料开始，经过近30年的技术迭代，公司在提供电子材料、电线、电缆附件及新能源汽车相关产品的一站式解决方案方面已奠定领先的市场地位。
