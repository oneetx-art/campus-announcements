## 公司
性质:民企 · 行业:能源/化工/环保

东岳氟硅科技集团有限公司（简称：东岳集团）创建于1987年，位于淄博东岳经济开发区。公司坚持科技创新，聚焦新能源、新环保、新材料产业，氟硅产业经过38年艰苦创业，建成了全球一流的氟硅材料产业园区和完整的氟、硅、膜、氢产业链和产业群。目前拥有“东岳集团[HK0189]”、“东岳硅材[300821]”两家上市公司。高分子材料、有机硅材料、含氟功能膜材料等的研发和生产，掌握了大量全球领先的技术，产品产销160多个国家和地区。集团氟硅膜氢产业链下有12个高新技术企业，产品有5大类共16个系列、1170个品种，广泛应用于新能源、新基建、生命科学、数字科技等国计民生的关键和重要领域。
