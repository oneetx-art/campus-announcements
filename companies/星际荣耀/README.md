## 公司
性质:民企 · 行业:机械/制造业

星际荣耀航天科技集团股份有限公司（简称“星际荣耀”）是中国首家成功完成运载火箭入轨发射任务的民营航天企业，旗下包括全资子公司星际科技、陕西星际荣耀、海南星际荣耀、四川星际防务、四川星际动力、广东星际智装和四川星际智造等，公司被评为国家高新技术企业、北京民营企业文化科技创新百强企业等荣誉，具备非常丰富的航天工程相关经验。
