## 公司
性质:民企 · 行业:IT/互联网/游戏

北京未尔锐创科技股份有限公司（简称“未尔科技”）成立于2006年，是国内领先的信息系统工程仿真软件及解决方案供应商。作为国家级重点基金控股企业，未尔科技服务于国家军民融合、自主可控战略，面向论证设计、研制测试、试验训练和保障运用全生命周期，提供覆盖含作战体系电子战、通信仿真、电磁环境和电磁频谱、雷达电子战与信号级网络运用等多专业，融入人工智能、专业仿真引擎和半实物试验训练的数字战场仿真软件、专业仿真工具集等核心产品。
