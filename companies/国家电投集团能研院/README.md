## 公司
性质:央国企 · 行业:能源/化工/环保

能研院是国家电投非核产业技术服务与提质增效的主要专业支撑机构，是产业应用技术创新和成果转化推广的重要依托，推动产业数字化、智能化、绿色化转型升级的核心力量。上海院成立于1999年，前身为“上海成套院”，为国家电投集团科技研发核心基地，1999年转制为科技型企业，2015年成为国家电投集团有限公司成员单位。西安院成立于2014年10月，能源研究院挂牌成立，国家电投光伏（储能）产业创新中心、风电产业创新中心、上海明华电力等优势资源划入能研院。
