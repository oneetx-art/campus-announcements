## 公司
性质:外企 · 行业:机械/制造业

依视路陆逊梯卡是一家全面整合型企业，是设计、制造和分销镜片、镜架以及太阳眼镜的全球领导者。由依视路集团（1849年成立于法国）与陆逊梯卡集团（1961年成立于意大利）两家优势互补的领先企业组成。其中依视路是光学镜片尖端技术的引领者，另一家是眼镜设计精湛工艺的缔造者。二者于2018年强强联合，成立了依视路陆逊梯卡集团，创立了通过满足人们不断变化的视力健康需求和个人风格喜好，帮助世界各地的人们“见深行远”。依视路陆逊梯卡旗下有眼镜50多个知名品牌，其中包含雷朋、欧克利等知名眼镜品牌、万里路和全视线等高科技镜片品牌，以及全球领先的眼镜零售门店品牌Sunglass Hut、亮视点（LensCrafters）和观视界（GrandVision）。
