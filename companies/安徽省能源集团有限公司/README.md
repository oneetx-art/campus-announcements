## 公司
性质:央国企 · 行业:能源/化工/环保

安徽省能源集团有限公司（简称“皖能集团”）是由安徽省政府出资设立的国有独资公司，成立于1985年，是省属企业中唯一一家以能源为主业的企业集团。公司注册资本100亿元，负责管理、电力、天然气及其它能源建设的资金筹集和投资管理，对全资、控股、参股企业进行资产和资本运作。截至2023年8月底，集团资产总额1277亿元，拥有煤炭和天然气两大集团上市公司，三级子公司178个，三级及以下控股、参股企业207家，已发展成为涵盖火电、天然气、环保、新能源、综合能源服务、煤炭贸易、金融投资等产业，项目分布在全国14个省份的大型企业集团。
