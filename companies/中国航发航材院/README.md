## 公司
性质:事业单位 · 行业:机械/制造业

中国航发北京航空材料研究院成立于1956年，是我国“一五”计划156项重点建设项目之一，是新中国第一个成立的航空科研院所，是中国最大的材料工程研究中心、中央科研事业单位，是国内唯一面向航空、从事航空先进材料应用基础研究、材料研制与应用研究、关键件研制交付以及型号应用的综合性科研机构，是我国国防科技工业领域高水平材料研究发展中心，是国家科技创新体系和国防科技创新体系的重要组成部分。经过70年发展，拥有先进完整的材料研发、制造、检测技术体系和丰富知识积累，覆盖17个领域76个专业，拥有多个国家级、省部级实验室及中心，形成“一中心四基地”科研生产布局，现有员工近5000人，致力于为客户提供从材料设计、选材、制造到检测、维修的一体化解决方案
