## 公司
性质:央国企 · 行业:房地产业/建筑业

北京北控城市发展集团有限公司（简称“北控发展”）是北控集团的直属全资企业，成立于2020年1月。北控发展以“服务城市发展 共创美好生活”为企业使命，秉持“诚信为本、融合为要、卓效为擎、共赢为魂”的核心价值观，聚焦城市更新、健康医养、城市生活服务+“两核一提升”战略布局，积极参与首都超大城市治理，扎实履行首都国企责任与担当，着力打造国内领先的创新型城市综合运营服务商。
