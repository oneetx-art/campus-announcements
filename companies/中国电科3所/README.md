## 公司
性质:事业单位 · 行业:教育/培训/科研

中国电子科技集团公司第三研究所坐落在北京，是中央直属事业单位，国内唯一的国家级视声专业综合性研究所，唯一体系性开展近地面探测与感知的国家级创新平台，同时设有国家广播电视产品质量检验检测中心。三所下设职能管理部门、业务管理部门、重点实验室、5个研发部、生产制造部以及7个全资子公司。全所有超千名员工，其中所本部硕士以上学历占比53%，副高级以上职称占比44%。具备优质的产、学、研等资源。三所以引领海洋监测、次声探测领域行业发展为主责，以视声技术为核心的数字音视频系统和产品研制、生产、建设、服务为主业。军品业务覆盖水声探测侦察、次声探测、声学传感器、舰船内部通信、音视频调度指挥、图像处理、认知域安全等领域；民品产业覆盖音视频调度指挥、智能视频会议、乘客信息系统、检测认证等领域。在我国视声行业内具有广泛而重要的影响。
