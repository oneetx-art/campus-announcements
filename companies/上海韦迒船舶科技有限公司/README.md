## 公司
性质:民企 · 行业:机械/制造业

上海韦迒船舶科技有限公司（BESTEVER）创建于2020年，是经中国船舶集团有限公司（CSSC）批准由武汉船用机械有限责任公司（WMP）和上海英伦轮船科技有限公司合资成立。公司专业从事船舶与海洋工程设计，提供船舶和海工产品的概念设计、合同设计、基本设计和详细设计，并致力于提供全寿命周期的技术服务。公司秉承“三是三心”企业核心价值观，追求客户服务，技术不断创新，致力于打造“国内领先、世界一流”的企业品牌。
