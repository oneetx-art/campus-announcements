## 公司
性质:其他 · 行业:通信/电子/半导体

中国电子科技集团公司第五十研究所（简称五十所），位于上海市普陀区，建于1977年，是原信息产业部直属一类研究机构，现为中国电子科技集团公司骨干研究所之一。主要从事通信系统和战术通信装备、微波与探测设备、网络与微波测试仪器、太赫兹技术应用研究开发。全所现有从业人员800余人，有7个业务单元和1家产业化公司，产品和技术已广泛应用于国防和国民经济建设各领域，为军队武器装备现代化建设作出了重要贡献。五十所获国家级、省部级等各类科技进步奖490项，各类专利及软件著作权授权近300件。先后荣获“全国文明单位”“全国五一劳动奖状”“中央企业思想政治工作先进单位”“上海市文明单位”“上海市企业文化建设示范基地党委”等一系列荣誉称号。
