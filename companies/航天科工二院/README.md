## 公司
性质:央国企 · 行业:机械/制造业

中国航天科工集团第二研究院（简称二院）创建于1957年11月16日，是我国航天事业和国防科技工业的中坚力量，是我国武器装备发展历史上多项第一的先后承担者。二院现有直属单位19家，在职职工24000余人。拥有6名两院院士、4名国家级有突出贡献专家和一大批国家级科技英才在内的知名专家。拥有1个全国重点实验室、6个国防科技重点实验室，7个国防科技创新中心，以及一大批国家级和航天系统重点实验室。共获得各级各类科技奖励2600余项，其中国家科技进步特等奖9项、一等奖13项，国家技术发明一等奖1项。
