## 公司
性质:央国企 · 行业:教育/培训/科研

北京遥测技术研究所创建于1957年，是新中国建立的航天电子信息专业研究所，是我国航空航天、空间电子信息技术领域的专业研究与专业发展的单位，拥有“遥测通信与导航”“雷达与通信技术”“卫星与遥感”“雷达信号处理”等国内一流水平，在北京、西安、成都三地建设有条件完备的科研生产基地。作为国防科技系统电子信息领域自主研发的先行者，全所深度参与了载人航天、探月工程、北斗导航、战略战术武器、星间链路、国家重大科技专项、全方位“探测”等任务，是航天电子信息领域的科技研发和产品配套单位，是强国强军建设的核心技术支撑单位和集团军骨干力量。
