## 公司
性质:央国企 · 行业:能源/化工/环保

中国石化湖南石油化工有限公司由原巴陵石化、长岭炼化重组而成（两公司企业周恩来总理在20世纪60年代倡导亲自批示建设），2023年3月6日完成工商注册，2024年1月1日正式实现一体化运营。企业共有各类生产、辅助装置100余套，主要有炼油、己内酰胺、苯胺、热塑性弹性体、环氧树脂、环氧丙烷、沥青等装置，原油加工能力800万吨/年，己内酰胺产能45万吨/年、环氧树脂产能100万吨/年（含沿江巴陵链40万吨/年）、热塑性弹性体80万吨/年（含湖南巴陵17万吨/年、上海金山巴陵25万吨/年）、环氧树脂12万吨/年、环氧丙烷10万吨/年，主要产品100余种。
