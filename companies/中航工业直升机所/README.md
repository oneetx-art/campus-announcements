## 公司
性质:事业单位 · 行业:教育/培训/科研

中航工业直升机设计研究所（以下简称“直升机所”）创建于1969年，隶属于中国航空工业集团有限公司，是我国唯一以直升机型号研制和技术发展为使命的国家型级大型科研院所。在江西和天津两地建立了完整的设计试验体系及试飞基地。
