## 公司
性质:民企 · 行业:通信/电子/半导体

初芯集团，总部位于北京，是中国较早专注于半导体显示领域的产业投资机构之一。初芯集团投资方向覆盖光电芯片、智能制造、新材料、信息科技等领域。通过“基金+产业+园区”的“三位一体”投资运营模式，经过多年深耕发展，现已成为以硬科技产业投资为核心，涵盖基金、产业和园区的三位一体+N的硬科技投资超级平台。旗下初芯装备，重点投资于光电与半导体产业，以智能制造、高端装备产业，以及上下游新材料企业为主要投资方向，通过并购国际先进半导体与光电产业资产，实现国产化落地。
