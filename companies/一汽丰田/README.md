## 公司
性质:合资 · 行业:汽车制造/维修/零配件

一汽丰田是由中国第一汽车股份有限公司与日本丰田汽车共同打造的大型中外合资企业，成立于2000年6月，总部位于天津经济技术开发区。一汽丰田拥有天津、长春、成都三大生产基地，其产品涵盖轿车、SUV、MPV等多个领域，有卡罗拉、亚洲龙、RAV4荣放、皇冠陆放、格瑞维亚等车型。凭借高耐久性、高品质、高可靠性的特点，一汽丰田在市场上拥有良好口碑，2024年，一汽丰田全年销量达800,199台，电动化车型销量占比达48%。在J.D.Power等权威机构评定中屡获佳绩。
