## 公司
性质:央国企 · 行业:金融业

重庆国际信托股份有限公司成立于1984年，注册资本金150亿元，稳居行业首位。公司拥有强大的资本实力，主要股东包括同方国信投资控股有限公司、国寿投资保险资产管理有限公司及上海淮矿资产管理有限公司。公司在北京、上海、深圳、杭州、青岛、南京等多地设立业务部门，业务覆盖全国30多个城市。
