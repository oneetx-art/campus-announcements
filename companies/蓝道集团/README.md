## 公司
性质:民企 · 行业:机械/制造业

温州蓝道集团股份有限公司(简称蓝道集团)创立于1994年，是一家以眼镜包装为核心，集眼镜包装及眼镜产业链的制造商与服务商，集团在中国共设9家全资子公司，总部位于中国温州。目前已具备“产、销、研”一体的经营体系，通过“一站式服务”的经营策略为客户提供全方位的解决方案。
