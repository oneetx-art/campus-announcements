## 公司
性质:央国企 · 行业:机械/制造业

中建材（合肥）钢构科技有限公司是中国建材集团的优秀子企业，是集团旗下唯一一家集钢结构产品设计、生产制造、施工安装于一体的全产业链专业化公司。公司倡导“诚信为本、品质至上、专业典范、行业标杆”的经营理念，依托中国建材集团强大的资源优势，整合专业化、系统化资源解决专家，作为国家高新技术企业，具备强大的技术实力，拥有钢结构专业承包壹级资质、钢结构制造特级资质、钢结构专项设计甲级资质、建筑工程施工总承包叁级资质、装修装饰贰级资质，还具有CE、美标AISC认证。
