## 公司
性质:央国企 · 行业:交通/物流/仓储

中国铁道科学研究院集团有限公司机车车辆研究所（简称“机辆所”），创建于1955年1月，是铁科院集团公司下属的技术密集型二级科技企业，位于北京市海淀区大柳树路2号。主要从事铁路机车车辆、牵引供电、城市轨道交通车辆等专业的基础研究和应用研究，以及相关试验检验和行业服务工作。建所70余年来，全程参与了中国铁路移动装备的研发、制造、试验等重要环节。年产值逾80亿，职工1600人。2024年参与的复兴号高速列车项目荣获国家科技进步特等奖。现有全国政协委员1人，天津市人大代表1人，国铁集团百千万人才15人，铁科院集团公司科技创新人才72人，青年人才托举工程6人，院控岗位51人。
