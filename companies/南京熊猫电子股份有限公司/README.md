## 公司
性质:央国企 · 行业:通信/电子/半导体

南京熊猫电子股份有限公司（以下简称“公司”）于1992年4月由被誉为中国电子工业摇篮的熊猫电子集团有限公司独家发起设立，是我国电子行业的骨干企业，隶属于央企中国电子信息产业集团，1996年5月和11月，公司分别在香港联交所和上海证交所挂牌上市，是我国电子行业的第一家A+H股上市公司。公司构建了完整的技术创新体系，管理1个国家级研发中心、9个省级研发（技术）中心，1个博士后工作站。公司承接多个国家、江苏省项目，多次荣获国家科学技术进步奖重点工程、人民政府科学技术奖等奖项。公司所属主要子企业均被认定为高新技术企业或软件企业。
