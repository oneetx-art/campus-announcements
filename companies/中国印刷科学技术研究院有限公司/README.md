## 公司
性质:央国企 · 行业:教育/培训/科研

中国印刷科学技术研究院有限公司（简称“中印科院”）成立于1956年，原直属国家新闻出版总署，2002年经科技部、财政部、中编办联合发文，整体进入国务院批复组建的中国文化产业发展集团有限公司，2012年并入中国国新控股有限责任公司。中印科院是一所国家级综合性印刷信息服务与科研机构，是国家新闻出版署出版业科技与标准重点实验室“印刷环保与智能技术重点实验室”的依托单位，是国家智能制造标准化总体组成员单位和中国印刷智能制造产业联盟理事长单位，是国家新闻出版署印刷业数字化发展改革试点单位（2023年-2025年），承担全国印刷机械标准化技术委员会秘书处工作。
