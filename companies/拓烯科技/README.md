## 公司
性质:民企 · 行业:能源/化工/环保

拓烯科技（衢州）有限公司成立于2020年1月，是一家在高端聚合物新材料领域具有领先地位的国家级专精特新“小巨人”企业，致力于打破国际垄断，填补国内技术空白，打造全球领先的高端聚合物材料平台型民族企业。创立以来，拓烯科技开发出多项自主知识产权的生产技术，打造4大产品矩阵：拓美特®TAMT®（COC）、拓派克®TOPC®（高端光学PC）、拓普美®TOPM（PMMA）和HPMP®（甲基戊烯聚合物），核心产品广泛应用于精密光学元件、高端功能薄膜、集成电路、航空航天、军工、人形机器人、生物医药用材、汽车关键配件等领域。
