## 公司
性质:民企 · 行业:机械/制造业

厦门笃正新能源股份有限公司成立于2007年9月，是世界领先的新能源系统解决方案提供商。集新能源技术研发、生产、销售、服务为一体的跨国型集团公司，在欧洲、美国等地均设有自营仓储/客服中心并成立了子公司。公司自有储能解决方案、离网应用解决方案、专注于家庭品牌解决方案ECO-WORTHY及DCHOUSE低压逆变器、控制器等产品。每年以营收的3%投入在独家方案、智能家居产品，包括锂电池、太阳能光伏技术。创新与研发领域，已取得了近100余项专利技术。通过B2B和B2C(亚马逊、Ebay、独立站等)销售渠道将产品远销欧美亚等国家，在北美以及欧洲市场常年排名前三名。
