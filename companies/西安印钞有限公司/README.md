## 公司
性质:央国企 · 行业:机械/制造业

西安印钞有限公司始建于1950年，隶属于中国人民银行中国印钞造币集团有限公司，是以钞票、货币文化、防伪仿伪产品研制为主，现金综合服务、以及各种防仿证证件、印刷开发等多种经营为一体的大型企业。公司曾荣获“中国工业企业500强”、“国家职业卫生示范单位”、“全国模范劳动关系和谐企业”、“陕西省文明单位标兵”等荣誉称号。公司具备完善的社保福利体系，依法缴纳五险一金（养老保险、医疗保险、失业保险、工伤保险、生育保险、住房公积金、企业年金），在此基础上为员工提供一年一次的免费体检。享受公司提供的综合素质及岗位技能提升培训。
