## 公司
性质:民企 · 行业:能源/化工/环保

洛化集团是一个集项目管理、工程监理、工程建设和工程造价为主的技术密集型综合管理企业。集团前身为中国石化洛阳石油化工工程公司下属单位，成立于国内工程监理初创之时的1993年，是国家石油化工行业首批开展监理服务业的企业，2004年顺利完成改制，2010年更名为洛阳石化工程建设集团有限责任公司。
