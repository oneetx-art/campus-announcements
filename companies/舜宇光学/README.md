## 公司
性质:民企 · 行业:文化/传媒/广告/体育

舜宇光学是国内最大的综合光学产品制造商，公司成立于1984年，2007年成为第一家在香港联交所主板上市的大陆光学企业（股票代码：2382.HK）。公司以光学制造为核心，逐步发展成包括光学零件（玻璃/塑料镜片、平面产品、镜头等）、光电产品（手机摄像模组、3D光电模组等）和光学仪器（显微镜、测量仪器及分析仪器等）在内的三大事业板块。
