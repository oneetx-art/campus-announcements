## 公司
性质:央国企 · 行业:交通/物流/仓储

杭州市地铁集团有限责任公司成立于2002年6月，是杭州市政府直属企业，从事杭州城市轨道交通建设、运营、开发、投资等业务，致力于“打造国内一流城市轨道交通综合运营商”。目前集团公司资产规模超过3700亿元，员工人数达到2.23万名；各级下属公司50余家，其中3家建设分公司，8家二级全资子公司（运营公司、开发公司、商管公司、铁安公司、建管公司、科技公司、教育科技公司、盈和投资公司），2家二级控股公司。杭州地铁已开通运营12条线路，总长516公里；正在全面建设四期工程。
