## 公司
性质:其他 · 行业:金融业

广东华兴银行是经国务院有关部委批准于2011年8月依法创新设立的一家混合所有制商业银行，注册资本80亿元。截至2024年末，已设立11家一级分行，资产总额超4600亿元，累计向全省各地纳税近120亿元。广东华兴银行立足湾区，坚持服务地方经济建设、服务实体经济、服务小微企业、发展普惠金融，形成了绿色金融和教育金融等业务特色，是广东省内唯一具有“广东乐中小微”企业小程序品牌的城商行，也是广东省第2家数字转型试点银行之一
