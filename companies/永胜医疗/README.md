## 公司
性质:民企 · 行业:医疗/医药/生物

永胜医疗控股有限公司（以下简称“集团”）创立于1997年，于2016年在香港主板上市（股票代码：1612.HK），集团专注于开发、生产及销售医疗器械，向全球客户提供呼吸产品、成像一次性产品及骨科支护康复器具，现有雇员1600多人。 集团具有强大的医疗器械领域人才队伍和丰富的专业知识，相关产品已通过CE、NMPA、FDA认证、MDSAP(美国、澳大利亚、巴西、加拿大、日本五国体系认证)，并进入到全球100多个国家或地区市场，同时为国内400多家三甲医院麻醉科及重症监护室提供急救、临床治疗和国家战备、应急救援物资储备保障服务。
