## 公司
性质:民企 · 行业:通信/电子/半导体

北极雄芯源于清华大学交叉信息研究院，孵化于交叉信息核心技术研究院。公司成立于2021年7月，是国家高新技术企业、陕西省‘专精特新’中小企业。在北京、南京、无锡等地设立了研发中心。作为国内领先的Chiplet芯片设计企业，公司核心团队深耕Chiplet领域多年，拥有全球领先的学术影响力以及丰富的产品化实践基础。公司致力于成为基于Chiplet的高性能计算解决方案领航者，成立以来取得了多项里程碑。自主研发的‘启明935A’是行业首款基于Chiplet异构集成范式的自动驾驶芯片。
