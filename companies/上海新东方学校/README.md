## 公司
性质:民企 · 行业:教育/培训/科研

新东方上海学校成立于2000年6月，是新东方教育科技集团在北京以外创立的首所学校。上海学校目前在上海各区有29个学习中心，教学面积超42500平方米，涵盖高中班课、高中一对一、青少部、国际游学&营地教育部和五大职能部门。上海学校高峰期培训学员突破30万人次，是华东地区的大型培训机构之一。
