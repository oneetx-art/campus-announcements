中国飞行试验研究院（中国航空工业集团试飞中心）简称试飞院，坐落于西安市阎良区，创建于1959年，隶属于中国航空工业集团有限公司，是经国家授权的军民用飞机、航空发动机、机载设备等航空产品国家级鉴定试飞机构，是国家级飞行试验技术研究机构，国家“飞机适航认可实验室”，也是我国试飞员培训中心，全面承担航空产品定型/鉴定、关键技术演示验证和试飞理论、试飞技术、测试技术、保障技术以及飞机作战效能研究等任务。拥有29个二级专业、134个三级专业构成的相互配套、系统完整的研究、试验和设计、试制体系。
