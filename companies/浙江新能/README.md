## 公司
性质:央国企 · 行业:能源/化工/环保

浙江省新能源投资集团股份有限公司（简称“浙江新能”）成立于2002年8月，注册资本24.05亿元人民币，是浙江省能源集团有限公司所属的专业从事风力发电、太阳能发电、水力发电等可再生能源和新能源投资、开发、运营管理的综合型能源企业。浙江新能2021年5月实现上交所主板上市，股票代码600032。截至2024年底，浙江新能总资产589亿元，净资产185亿元，公司控股840万千瓦（含在建），参控股权益装机规模181.56万千瓦。公司通过完整布局“风光水”三大产业，充分展现多业协同优势和规模优势，项目分布在浙江、江苏、新疆、甘肃、青海、宁夏、四川等18个（自治区），为公司长久经营效益的稳定增长提供了有力保障。
