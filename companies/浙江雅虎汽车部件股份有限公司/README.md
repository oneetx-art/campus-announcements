## 公司
性质:民企 · 行业:汽车制造/维修/零配件

浙江雅虎汽车部件股份有限公司成立于2009年9月，总部位于浙江瑞安开发区南滨江江南大道777号，固定资产10亿，占地180余亩，建筑面积40000平方，分别拥有瑞安、长春、成都、天津、上海、土耳其等五大生产基地，开设上海、温州、杭州、成都、土耳其等五大研发中心，是集研发、生产、销售于一体的汽车座椅骨架制造企业。公司先后获得“国家级高新技术企业”、“国家绿色工厂”、“省级高新技术企业研究开发中心”、“省级企业研究院”、“省级技术中心”、“浙江省工业设计中心”、“浙江省博士工作站”、“浙江名牌产品”、“浙江制造精品”、“浙江出口名牌”等中小微企业成长之星、隐形冠军等荣誉称号。
