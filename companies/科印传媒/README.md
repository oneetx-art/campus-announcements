## 公司
性质:央国企 · 行业:文化/传媒/广告/体育

北京科印传媒文化股份有限公司，始于1957年创刊的《印刷技术》杂志，隶属于国资委央企中国国新旗下中国文化产业发展集团。2006年成立至今已逐步形成“媒体运营”“会展服务”“教育培训”三大业务板块，旗下拥有文化发展出版社、上海科印文化传媒两家子公司，管理运营《印刷技术》杂志社、北京科印文化出版、文化教育、文化装备（印刷包装）垂直行业。公司产品及服务涵盖期刊出版与设计发行、全媒体运营、国际展会、大型活动、企业培训、数字媒体艺术等众多形态，具有极高的产业影响力、敏锐的产业洞察力和专业的市场运营能力。近年来，科印传媒先后获得国家高新技术企业认证、北京市“创新型”中小企业、北京市“专精特新”中小企业等荣誉资质。
