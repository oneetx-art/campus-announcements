## 公司
性质:央国企 · 行业:能源/化工/环保

广州电力工程监理有限公司（以下简称监理公司）成立于1996年7月，是广州市城市建设投资集团有限公司和广东电网有限责任公司出资的其他合作国有控股企业。注册资本1000万元，是一家具备电力工程监理甲级、设备监理甲级、房屋建筑工程监理乙级、市政工程监理乙级、通信工程监理乙级资信评价的综合型工程管理咨询机构。现为中国会长单位、广州市电力行业协会监事长单位、委员副会长单位、监理协会理事单位及电力建设标准化技术委员会专家组成员协会单位、广东省高新技术企业、广东省专精特新中小企业。
