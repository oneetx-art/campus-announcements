## 公司
性质:央国企 · 行业:金融业

国泰海通由国泰君安与海通证券于2025年4月合并成立，是中国资本市场长期、持续、全面领先的综合金融服务商。截至2025年上半年，公司合并总资产超1.8万亿元、归母净资产3214亿元，资本实力居行业最前列。国泰海通证券北京分公司设有14个部门，下辖24家营业部、二级分公司。多年来锐意进取、开拓创新，经营业绩在公司始终名列前茅，曾多次被公司授予'先进集体'称号。
