## 公司
性质:民企 · 行业:机械/制造业

广东金龙东创智能装备有限公司是深圳市联合东创科技有限公司全资子公司。东创是一家专业从事智能智造的国家高新技术企业。公司作为国家级高新技术企业、国家“专精特新”小巨人，连续三年获得“东莞市倍增企业”。公司成立于2015年，在东莞、深圳、嘉善、湖南设有四大生产基地，并在上海、昆山、台北、泰国、马来西亚、韩国首尔、美国加州等多地设立办事处。公司产品涵盖可穿戴设备、平板电脑、智能家居产品、芯片测试平台、新能源汽车总装、汽车电子测试、无人机、无人驾驶汽车等产品。广泛服务于国内外知名企业。
