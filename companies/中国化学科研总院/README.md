## 公司
性质:央国企 · 行业:能源/化工/环保

中化学科学技术研究有限公司（简称：中国化学科研总院）是中国化学工程股份有限公司的全资子公司，于2019年6月在北京市注册成立，是提供兼具经济性与创新技术解决方案的中国化学直属科研机构和科技创新核心机构。公司总院员工博士学历占比超45%，硕士及以上学历占比超87%，所属玉林、日本和实业公司遍布北京、天津、山东滕州、广西玉林、日本横滨及横滨、浙江宁波、江苏苏州等地，实现研产销贯通融合，是一家知识密集、智力密集、技术密集型的国有科技型企业。
