## 公司
性质:央国企 · 行业:机械/制造业

天津航天机电设备研究所始建于1966年，位于天津市滨海高新区，是我国从事航天器研制、检测与试验、宇航地面装设备、海务装备研制的科研单位。研究所始终坚持自主创新、科技创新的发展理念，承担了载人航天、探月工程、北斗导航、遥感系列卫星等的众多空间飞行器总体、测试、试验和运输设备开发，卫星太阳能级大折展式光伏等多个产品研制，先后成一个国家级技能大师工作室和两个省部级重点实验室， 为中国航天事业的发展做出了积极的贡献。
