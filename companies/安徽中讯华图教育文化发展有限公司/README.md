## 公司
性质:民企 · 行业:教育/培训/科研

华图教育成立于2001年，秉承‘以教育推动社会进步’的使命，以职业教育为核心，主营业务涵盖了公务员、事业单位、教师、金融、医疗、部队转业干部、军队文职等各类人才招录考试培训业务。华图教育科技有限公司合肥分公司为华图教育全资子公司，全省16地级市及县区学习中心共设61所，拥有500多名教职人员，全省约5万平方封闭培训基地，提供食宿一体式学习环境。在全国大教研的基础上，根据安徽考务考情进行本土化教学教研，针对性授课。作为合肥市青年人才见习基地，华图每年为高校学子提供就业见习岗位数近百个。
