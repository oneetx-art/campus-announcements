## 公司
性质:央国企 · 行业:能源/化工/环保

中电装储能集团储能科技有限公司（以下简称“中国电气装备集团储能科技有限公司”）于2024年2月21日以许昌许继集团控股技术子公司（河南许继电源有限公司）为基础组建成立，注册资本金20亿元，注册地上海市安亭区。中电装储能以打造央企储能业务头部企业为发展目标，依托“一心多基地”“一品牌多主体”布局，致力于研发构建安全储能和产业创新中的智能型储能制造装备，建设技术路线与产业创新融合的高效制造中心，建设世界一流智慧储能系统集成服务商。
