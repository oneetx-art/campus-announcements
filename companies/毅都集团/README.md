## 公司
性质:民企 · 行业:贸易/批发/零售

毅都集团成立于1988年，公司总部位于辽宁大连，分公司遍布上海、广州、北京、沈阳、武汉等多个国内一线和新一线城市。是一家集冷链物流服务、进口生鲜食品贸易为一体的产业链化集团，30多年来始终以改善人们的生活质量为使命，致力于成为生鲜食品供应链最佳服务商和生鲜食品供应链最佳管理者，拥有国家骨干物流基地、农业产业化国家重点龙头企业、国家高新技术企业等称号。
