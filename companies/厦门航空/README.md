## 公司
性质:央国企 · 行业:交通/物流/仓储

厦门航空成立于1984年，是中国首家按现代企业制度运行的航空公司。在全球航空公司金融评级中，名列中国航空公司之首。拥有河北航空、江西航空2家航空主业子公司，并在福州、杭州、北京、天津、长沙、泉州、重庆、上海设有分公司。同时在境内外50多个大中城市设有办事处和营业部。机队规模达到221架飞机，运营国内外航线400余条，航线网络遍布全国、覆盖东南亚和东北亚、通达欧美澳。
