## 公司
性质:央国企 · 行业:人力资源服务

公司成立于2004年10月，是省人社厅直属事业单位省人才交流中心为不断适应新形势、转变经营机制、深化内部改革、拓展服务领域而成立的国有控股公司。2022年，因国资国企改革，根据四川省人民政府相关文件要求，公司完成股权部分划转，成为省国资、省人社双支撑、共管理的国有人力资源公司。主营业务涵盖人才招选、人才培养、人才测评、综合用工服务、综合档案服务五大类，为各类企事业单位和人才提供优质、高效、多层次、全方位的人力资源服务。经过近十余年发展，公司已成为四川地区较具影响力的人力资源服务企业。
