## 公司
性质:央国企 · 行业:机械/制造业

云南锐达民爆有限责任公司，简称锐达公司，成立于1965年，原名国营云南包装厂，2017年11月3日改制注册为公司，是云南省戎合投资控股有限公司管辖的云南民爆集团有限责任公司所属的全资国有企业，是全国规模最大的工业炸药定点生产企业之一，还是西南地区唯一的增雨防雹火箭生产企业。公司在水富和文山分别设有两个异地分公司，立足民爆专业，寻求多元化发展，打造用户满意产品，创立一流企业是公司生产经营的宗旨和目标，不断推动产品创新、技术进步和服务提升，是企业对广大用户永远的承诺。
