## 公司
性质:央国企 · 行业:机械/制造业

成都天奥测控技术有限公司是中电天奥有限公司控股的专业从事测控产品开发、生产及系统集成的国有控股高科技公司，是第五批国家级专精特新“小巨人”企业，2023年，公司获批成立成都市企业测试技术工程研究中心。获得了四川省射频自动化测试中心资质。2024年，公司获得了四川省企业技术中心资质。公司专注于自动测试和智能制造领域的产品研发和系统集成，在通用测试模块、检测设备、自动测试系统集成、试验训练评估、半实物仿真等专业领域积累了丰富的经验，拥有多项关键技术和国家专利，部分通信导航识别检测设备在先进水平，主导的航空技术达到国内领先和国际先进水平，主导的航空通信导航识别检测设备在工业级某方面支持我国航空工业、民航飞行等飞行任务，是西南地区空天电子测控行业的领军企业。
