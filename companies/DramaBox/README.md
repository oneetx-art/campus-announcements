## 公司
性质:民企 · 行业:IT/互联网/游戏

北京点众科技股份有限公司创立于2011年，是一家专注于移动端正版数字内容生产和分发的国家高新技术企业，秉持“做一流的数字内容平台”的愿景，通过科技与文化的有机融合，积极传播弘扬中华民族优秀文化成果，不断推动文化事业创新发展。公司主营网络微短剧以及网络文学等业务，目前点众科技旗下拥有“河马剧场”、“繁花剧场”、“DramaBox”、“点众阅读”、“点众文学”、“Webfic”等主要产品，公司坚持精品化的发展战略，与国内外400多家知名内容厂商紧密合作，拥有各类优质版权35万余册，全球注册用户10亿，月活用户超3亿。企业规模近2500人，多年来公司年度增幅持续达到80%-200%，超过行业平均增幅。
