## 公司
性质:事业单位 · 行业:能源/化工/环保

湖北江城实验室坐落于长江经济带核心城市武汉，是湖北省人民政府批准设立的独立法人事业单位，实验室于2021年2月18日揭牌成立，汇聚科技领军企业、创新研发平台和高校等多方力量，是面向集成电路领域的高能级研发机构。实验室拥有集成电路领域科学家、一流科研与管理人才700余人，战略、管理、学术、产业科学家人数达到60余人，工程技术人员接近500人，入选国家、省市级人才计划60余人。实验室以战略研究为牵引、以科技创新为主线，集中攻关集成电路产业战略、基础科学和关键性技术问题，是湖北省半导体行业协会会长单位，设立湖北省光电子信息产业专家咨询委员会秘书处、湖北省电子信息标准化技术委员会秘书处，拥有湖北省引智创新示范基地、湖北省新型智库、博士后创新实践基地等多个平台。
