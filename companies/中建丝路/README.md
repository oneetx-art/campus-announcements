## 公司
性质:央国企 · 行业:房地产业/建筑业

中建丝路（陕西）建设投资有限公司（简称“中建丝路”）于2016年注册成立，注册资本金40亿元。作为中国建筑在新丝绸之路经济带沿线地区最核心的投资运营平台，中建丝路聚焦为大西安建设、陕西省乃至西北地区基础设施投资建设提供全产业链特色服务，致力打造“投资、建设、运营”三位一体的城市综合开发运营商，高质量、高标准地助力西安国家中心城市建设。
