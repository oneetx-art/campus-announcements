## 公司
性质:民企 · 行业:医疗/医药/生物

南京正大天晴制药有限公司成立于2001年，由泰国正大、江苏农垦两大股东共同投资创建，下辖两家全资子公司：江苏普润生物医药有限公司（研发中试平台、原料药平台）、南京正大天晴制药有限公司（商业试点BDA）。历经二十余年发展，公司已成长为集“药物研发、原料、制剂、营销”等全产业链，研发涵盖“心脑血管、肿瘤、影像、代谢、消化”等治疗领域，产品营销双引擎驱动的高科技成长型企业，连续多年位列中国化学药综合实力百强！
