## 公司
性质:央国企 · 行业:能源/化工/环保

肇庆市水务集团有限公司是肇庆市国资委直管的国有中型水务企业。成立日期：1986-03-31，公司主要从事自来水生产与销售、污水处理、电站电力开发和经营管理、市政工程施工、水质检测、排水管网运营、储备林建设、现代农业全产业链生产贸易服务等。控股肇庆市肇水水务发展有限公司、肇庆市贺江电力发展有限公司和广东肇庆市现代农业投资发展有限公司，经营8个自来水厂、14个污水处理厂、17个水力发电站、逾18万亩国家储备林、160亩省级保障性苗圃场、10个国有农贸市场、3个粮食储备库点，肇水集团总资产超70亿元，在职职工共1500多人。近年来，肇水集团各项经济指标稳步增长，迈入了高质量发展的轨道，实现了安全优质供水和污水处理达标排放；水电装机规模不断增加，产业实力不断增强；依托于已完成收储林地，正逐步按要求高标准建设国家储备林；打造2200亩供深港特色农产品标准化种植基地及冷链集配中心，谋划推进现代设施农业项目，投资建设现代化绿色粮食仓储设施。屡次荣获“全国模范劳动关系和谐企业”“中国优秀诚信企业”“广东省先进集体”“广东省文明单位”等多项国家、省和市级荣誉。
