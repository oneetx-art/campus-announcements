江西长旅酒店管理集团有限公司是江西省长天旅游集团有限公司全资控股的国有酒店管理集团，2025年9月27日为落实企业整合战略部署，对原4户企业实施整合重组后组建成立。目前管理及品牌输出酒店共66家，客房10200余间，已构建长旅沁庐核心主品牌矩阵，涵盖多维度酒店产品体系，承载优化省属文旅酒店资源配置、引领行业高质量发展的重要使命
