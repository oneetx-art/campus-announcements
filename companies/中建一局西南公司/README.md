## 公司
性质:央国企 · 行业:房地产业/建筑业

中建一局西南公司，是世界500强企业上市公司中国建筑旗下骨干企业，成立于1998年，总部位于成都，扎根西南，立足成渝，辐射云贵川、重庆、上海，延伸发展贵州、福建、江苏、广东、北京等地，下辖中建一局集团成都建设投资有限公司、中建一局集团西南建设有限公司2个法人公司。中建一局西南公司连续多年入选四川省建筑业先进企业，先后斩获了大量国家级先进奖项，累计获鲁班奖13项、国家优质工程奖51项、省部级120余项荣誉，在西南地区积攒了良好的口碑和影响力。
