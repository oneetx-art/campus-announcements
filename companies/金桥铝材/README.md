## 公司
性质:民企 · 行业:机械/制造业

金桥铝材集团(KAP)于1983年成立，总部设在香港，分别在粤港澳大湾区内的广东省台山市、越南设有生产基地。是一家专门为客户提供集设计、研发、生产等一站式解决方案的高端铝合金产品供应商。现有员工3000多人，年销售额近40亿元，产品广泛应用于3C消费电子、新能源汽车、交通运输及其他日用消费品等领域；率先推广再生铝合金，深得客户的赞许，是国际国内著名3C消费电子品牌(苹果、华为、三星、小米、谷歌、联想等)、新能源汽车品牌(大众、丰田、特斯拉、小米、比亚迪、广汽、小鹏等)的指定供应商。
