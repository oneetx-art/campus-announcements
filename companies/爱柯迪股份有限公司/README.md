## 公司
性质:民企 · 行业:汽车制造/维修/零配件

爱柯迪股份有限公司（爱柯迪，600933.SH）简称IKD，总部坐落于现代化港口城市——宁波。IKD成立于1995年12月，并在2017年11月于上海主板上市。作为汽车铝压铸件制造领域的“隐形冠军”，爱柯迪集研发、生产、销售于一体，致力于为持续、稳定地为汽车零部件供应商提供轻量化、节能环保的产品和服务。多年来，公司积极开拓海内外市场，与全球TOP20零部件供应商和主机厂均保持良好的合作关系。目前，IKD总占地面积1000余亩，在职员工8000余人，在中国宁波、柳州、安徽以及墨西哥瓜纳华托、马来西亚等海内外城市共有十余家现代化制造工厂。此外，IKD顺应时代趋势，持续推进数字化改革，在国内首次实现5G网络建设模式的规模应用。2024年主营业务收入67亿+元，位列全国压铸件生产企业综合实力50强，是国内铝压铸行业龙头企业。
