## 公司
性质:央国企 · 行业:房地产业/建筑业

上海勘测设计研究院有限公司（三峡集团上海科创中心、三峡集团新能源规划研究中心）创立于1954年，从规划设计新中国第一座大型水电站——新安江水电站起步，发展成为可提供规划、勘测、设计、咨询、造价、监（检）测、监理、总承包等全过程咨询与服务的大型甲级综合设计院。聚焦水利水电、清洁能源、生态环保与资源循环利用三大主营业务，打造成为三峡集团新型高端智库、科技创新、技术支撑、人才培养高地。
