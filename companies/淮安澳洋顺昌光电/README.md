## 公司
性质:民企 · 行业:通信/电子/半导体

淮安澳洋顺昌光电技术有限公司系蔚蓝锂芯（股票码：002245）旗下的控股子公司，成立于2011年8月，总投资40亿元，注册资本10.03亿元，项目占地292亩，现有总建筑面积约10万平方米。澳洋顺昌是致力于集成电路、研发一体的，全球领先的LED光电企业，主营PSS衬底、LED外延片、LED芯片、CSP封装、LED照明应用等产品。公司是淮安市“333产业”重点扶持企业，多次荣获江苏省优秀企业、省双创团队等称号。
