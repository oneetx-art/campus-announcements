## 公司
性质:民企 · 行业:通信/电子/半导体

立讯精密工业股份有限公司成立于2004年5月24日，于2010年9月15日在深圳证券交易所成功挂牌上市（股票代码：002475）。公司自上市以来，营业收入复合增长率连续多年达50%。2024年，公司实现营业收入2687.95亿元，较上年同期增长15.91%。公司致力于为消费电子产品（智能手机、智能可穿戴设备、混合虚拟现实设备等）、汽车领域（汽车线束、汽车连接、雷达、摄像头、VR、声学模组、无线充电、域控制器、高压连接器、光模块、散热模块、电源、以及基站、天线、滤波器等）提供从核心部件、模组到系统级的一体化智能制造解决方案。公司近3年累计研发投入达251.92亿元，截至2024年末，拥有发明专利、实用新型专利及外观设计专利超7100项。
