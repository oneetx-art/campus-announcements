## 公司
性质:央国企 · 行业:机械/制造业

上海航天设备制造总厂有限公司是集运载火箭、防务装备地面系统和空间飞行器产品制造、总装测试和发射场服务于一体的国有综合型航天企业。前身新民机器厂由胡厥文先生于1921年创办。承担“弹、箭、星、船、器”多个型号产品研制生产任务，获多项荣誉，多位党和国家领导人视察指导。具备完整技术创新体系，坚持以人为本，人才梯队完善。
