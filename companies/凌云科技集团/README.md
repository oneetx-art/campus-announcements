## 公司
性质:央国企 · 行业:机械/制造业

凌云科技集团是集航空修理、航空配件与装备研制、航空产品开发与制造、贸易于一体的大型国有企业。总部位于湖北省武汉市，总占地面积17.14万平方米，拥有员工1800余名，各类专业技术技能人员超800余人。分布于湖北省武汉市、宜昌市、当阳市，建筑基层板块在国内外15个地区设有分公司和工程部。公司先后获得国家科技进步特等奖等百余项荣誉，拥有国家级技术企业、博士后科研工作站、CNAS认证实验室、湖北省企业技术中心等多个科研创新平台。培养出“国务院政府特殊津贴”、“全国技术能手”、“全国五一劳动奖章”、“湖北省政府专项津贴”、“荆楚工匠”、“湖北省技能大师”、“武汉工匠”、“宜昌工匠”等国家级、省、市级以上各类人才，共计获得社会人才举荐194人次。
