## 公司
性质:央国企 · 行业:能源/化工/环保

湖北能源集团股份有限公司（中国长江三峡集团有限公司综合能源上市公司）2005年2月由湖北省能源集团有限公司、湖北能源开发有限公司合并组建而成，为国有独资企业。2008年，通过向长江电力股份有限公司、三峡总公司等定向增发股份实现整体上市（股票代码：000883）。2015年10月，公司更名为湖北能源集团股份有限公司，湖北省国资委为控股股东，湖北能源集团股份有限公司与湖北省三峡集团有限公司组成实际控制人。湖北能源集团股份有限公司是湖北省省属资产规模最大的能源企业，截至2022年底，公司可控装机容量2140.5万千瓦，资产总额870.6亿元。公司作为湖北省综合性能源集团，结合自身水、火、风、光、煤、港、储多能互补、高效协同的综合能源业务板块，初步建成集煤电、煤炭、火电、水电、新能源、天然气、综合能源服务等为一体的综合能源产业集群。
