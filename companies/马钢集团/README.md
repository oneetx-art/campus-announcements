## 公司
性质:央国企 · 行业:能源/化工/环保

马钢（集团）控股有限公司（简称“马钢”）是中国宝武钢铁集团有限公司控股子公司，素有“江南一枝花”的美誉，公司坐落于风景秀丽的安徽省马鞍山市，地处长江之滨，地理位置优越，紧邻南京，位居长三角经济圈重要节点。马钢前身是成立于1953年的马鞍山铁厂，1958年正式成立马鞍山钢铁公司。历经多次改制与跨越式发展，于2019年成功与中国宝武联合重组，迈入高质量发展新阶段。70余年来，马钢已建成2000万吨钢配套生产规模，并创下中国平铁工业多个“第一”。重组以来，马钢牢记习近平总书记考察调研时的殷切嘱托，聚焦发展显著变化，获评国务院国资委“国有企业品牌建设标杆企业”，获评国务院国资委“国有企业品牌建设标杆企业”。
