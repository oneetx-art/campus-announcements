## 公司
性质:民企 · 行业:贸易/批发/零售

富虹公司创建于1988年，是集粮油加工、地产开发、酒店管理、物业服务、团餐食堂、矿泉水开采、商业综合体为一体的综合性民营企业，是农业产业化国家级重点龙头企业。荣获“中国名牌产品”、“中国驰名商标”、“绿色食品证书”和“最具竞争力”品牌。公司总资产103亿元，在美国、西班牙、沈阳、抚顺、本溪、辽阳、湛江等国家和地区有七个行业、十三家公司、三十个工种。
