## 公司
性质:民企 · 行业:IT/互联网/游戏

满帮集团是一家“互联网+物流”的科技企业，以“赋能企业更具物流竞争力”为使命，以数据智能和网络协同为引擎，致力于打造一个数字化、标准化和智能化的智慧物流生态平台，通过大数据、云计算和人工智能等先进技术赋能司机和货主，助推物流行业数智化升级，提升整个物流行业的透明度、信任度和效率，降低公路货运的“三空”（空驶、空置、空载），从而推动整个物流行业高效运转和节能减排，实现降本增效经济效益和节能减排社会效益的双丰收。2021年，满帮在美国成功上市，成为“数字货运第一股”。近年来，满帮成功入选“中国企业500强”“中国服务业企业500强”“中国民营企业500强”“中国互联网综合实力100强企业”。
