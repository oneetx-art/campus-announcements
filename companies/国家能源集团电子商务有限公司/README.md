## 公司
性质:央国企 · 行业:贸易/批发/零售

国家能源集团电子商务有限公司（以下简称“电商公司”）于2018年8月成功纳入2家基层单位。集团全资子公司，下设5家直属中心、12家基层单位。电商公司依托于国家能源集团“煤电运化港航”产业链，聚焦“煤电运化”四大板块，重点打造以“煤、化、运”为核心的大宗商品线上交易平台，通过“能资商储”平台建设，为交易用户配套提供金融、资讯等增值服务，年交易量达到1.8亿吨，注册企业的大宗商品供应链协同平台。建设的世界一流以神华自产煤源超过2.8亿吨，致力于同煤炭负责中国以神华进出口采购和销售业务和部分煤炭进出口业务，煤炭进出口业务主要包括澳大利亚、印尼、俄罗斯等进口煤业务，以及韩国、日本等出口业务。
