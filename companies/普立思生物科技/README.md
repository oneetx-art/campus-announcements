## 公司
性质:民企 · 行业:能源/化工/环保

普立思生物科技有限公司成立于2021年，是一家聚焦高光纯乳酸、丙交酯、聚乳酸技术研发、生产加工与产业化推广的企业，由中国科学院长春应用化学研究所与安徽芜湖产业基金联合成立。公司总投资86亿元，规划用地1800亩，规划聚乳酸产能35万吨，其中一期7.5万吨/年乳酸、5万吨/年聚乳酸智能工厂项目已经落地，实现满产。
