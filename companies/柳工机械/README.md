## 公司
性质:央国企 · 行业:机械/制造业

柳工集团创建于1958年，是国有资产授权经营管理的大型装备制造企业集团，也是极极少数能够提供全系列工程机械产品及全面解决方案的供应商之一。其核心企业——广西柳工机械股份有限公司于1993年在深圳证券交易所上市，成为广西及中国工程机械行业中的首家上市公司。
