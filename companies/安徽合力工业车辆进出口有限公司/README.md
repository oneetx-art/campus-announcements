## 公司
性质:央国企 · 行业:机械/制造业

安徽合力工业车辆进出口有限公司（简称“进出口公司”）是安徽叉车集团有限责任公司所属核心控股上市公司安徽合力股份有限公司的控股子公司，成立于1998年，位于合肥市蜀山区望江西路15号合力大厦A幢，现有员工400余人，主要从事叉车、装载机、牵引车和托盘叉车等工业车辆及零部件的出口业务。进出口公司被评为中国机电商会推荐的出口名牌企业和海关“AEO”高级认证企业，安徽省外贸企业50强。2024年进出口公司营业收入超69亿元人民币。
