## 公司
性质:事业单位 · 行业:房地产业/建筑业

《中外建筑》（月刊）于1995年创刊，是住房和城乡建设部主管、住房和城乡建设部信息中心、长沙市住房和城乡建设信息中心主办的全国建筑类大型综合性期刊，RCCSE中国准核心学术期刊、中国类型应用型扩展期刊、中国学术期刊综合评价数据库来源期刊、中国科学引文数据库收录期刊、中国期刊网全文收录期刊、CNKI中国期刊全文数据库收录期刊，面向国内外公开发行，具有由海内外享有盛誉的建筑界高级精英组成的强劲编委阵容，与全国各大高校建筑学院、各大建筑设计院紧密合作，是目前国内建筑领域权威性、学术性、专业性、可读性的期刊，致力于为政府决策建言献策、为企业发展搭建平台、为个人晋升提供通道、为读者拓面提供资讯。
