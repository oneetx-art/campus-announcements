## 公司
性质:民企 · 行业:农林牧渔

广西金穗农业集团是一家集农业种植、农业综合服务、农产品深加工、冷链仓储、食用糖产销、园林美化工程和生态休闲农业开发为一体的多元化产业集团，1996年9月4日注册成立，总部位于广西南宁。集团旗下拥有10家子公司，分布于广西、海南、老挝等地，总耕种面积超15万亩，年产能达肥料40万吨、酒精6万吨、果蔬深加工20万吨，是农业产业化国家重点龙头企业，拥有国家级现代农业科技示范展示基地，产业涵盖农业种植、农资生产、农产品加工、生态旅游等领域，年带动就业超10万人次
