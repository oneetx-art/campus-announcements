## 公司
性质:央国企 · 行业:能源/化工/环保

国网四川省电力公司（以下简称公司）是国家电网有限公司（以下简称国网公司）在川设立的全资子公司，是四川省特大能源骨干企业，负责四川省境内电网规划、生产、建设、运营、供应。公司现有23家地市供电公司、15家业务支撑单位、3家合资公司、3家上市公司、管辖151家县供电公司，用工总量8.2万人。目前，四川电网已建成全国规模最大、电压等级最多、运行最复杂的超大型枢纽电网，主网覆盖全省各市（州），在重要负荷中心形成多环网主网架，通过“七直十一交”与华东、华中、西北、重庆、西藏等电网相联，外送能力5745万千瓦，26年来累计外送规模约1.8万亿千瓦时，保持了43年安全稳定运行纪录。预计到“十五五”中期，四川电网将建成省内“三送三受”、跨区“多进多出”的西南立体枢纽大电网，电力供应保障能力、电能交换互济能力、新能源消纳能力、能源资源配置能力全面提升。中央宣传部授予国网四川电力成都高新连心桥共产党员服务队“时代楷模”称号。
