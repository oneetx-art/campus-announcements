## 公司
性质:民企 · 行业:智能硬件

普宙科技成立于2015年，总部位于武汉，是一家集无人机研发、生产、销售、运维和低空数据运营于一体的高科技企业。现有员工近800人，其中60%以上为研发人员。公司具备无人机全产业链研发能力，拥有丰富的无人机产品线，在无人机、无人机自动机场、智能载荷、软件平台和数据运营等领域不断革新产品和解决方案。作为国内低空经济发展的引领者，普宙科技全系无人机产品在智慧城市、电力巡检、智慧警务以及应急消防、活动安防、生态环保、智慧园区、智慧文旅等场景，充当重要的行业工具，全面驱动行业的数字化转型，为赋能新质生产力高质量发展贡献积极力量。
