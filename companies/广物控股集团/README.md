## 公司
性质:央国企 · 行业:政府/机构/组织

广物控股集团前身是1951年成立的广东省物资局，1983年转制为广东省物资总公司，1994年改组为广东物资集团公司，2015年更名为广东省广物控股集团有限公司。2019年6月根据省委、省政府的决定，与原广东省商贸控股集团有限公司实施重组。广物控股集团有直属、全资企业100多家，员工近1万人，200多家子企业，总部内设11个职能部门，是省属国有独资大型骨干企业集团，入围中国企业500强和中国“双百企业”，连续20多年入围中国企业500强和中国服务业企业500强，获信用评级为近“AAA”级企业。
