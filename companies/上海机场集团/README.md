## 公司
性质:央国企 · 行业:交通/物流/仓储

上海机场（集团）有限公司是上海市委、市政府根据“一个城市、两个机场”的特点，于1998年5月28日成立的国有独资企业，负责统一经营管理浦东和虹桥两大国际机场，注册资本365亿元。公司主要经营机场建设、运营管理，与国内外航空运输有关的地面服务，国内贸易（除专项规定），对外技术合作、咨询服务，供应链管理、第三方物流（除运输），房地产开发，实业投资，物业管理等。
