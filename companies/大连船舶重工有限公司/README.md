## 公司
性质:央国企 · 行业:机械/制造业

始建于1898年的大连造船，隶属于中国船舶集团有限公司，总占地面积1200万平方米，是国内规模最大、最具国际竞争力的现代化船舶总装企业之一。自创建以来已为海军建造舰艇数量最多的船厂之一，也是我国重要的船舶和海工装备研制基地。拥有由中国工程院院士、中国船舶设计大师领衔的1400多人研发设计团队，目前手持产品超过160艘，超过2200万载重吨，中高端船型占比90%以上。
