## 公司
性质:民企 · 行业:金融业

国都证券股份有限公司是经中国证监会批准，于2001年12月28日成立的综合性证券公司，2017年3月31日，公司在新三板挂牌上市，股票代码：870488。截至2024年，公司注册资本为38.3亿元。国都证券拥有多项业务牌照，在全国17个省市地区拥有60家分支机构（其中4家分公司、56家营业部）。国都证券股东背景实力雄厚，能够为公司发展拓展业务的广度及深度提供支持，同时为公司发展构建了广阔平台。国都证券设有国都景瑞、国都创投、国都香港3家全资子公司，控股国都期货公司，同时也是中欧基金的创始股东。
