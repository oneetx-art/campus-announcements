## 公司
性质:央国企 · 行业:交通/物流/仓储

中国外运股份有限公司，中国外运起源于1946年，是新中国外贸运输和物流行业的开拓者。2015年成为招商局集团成员企业、物流业务的统一运营平台和统一品牌。中国外运通过整合海空水运、铁路、公路、线上服务，为全球客户提供端到端安全可靠、自主可控的全链路全场景物流解决方案。
