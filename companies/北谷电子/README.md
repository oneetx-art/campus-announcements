## 公司
性质:民企 · 行业:通信/电子/半导体

北谷电子股份有限公司，成立于2009年，是移动设备领域智能控制系统、新能源解决方案和物联网解决方案的领先提供商。北谷电子提供一站式解决方案，包括控制器、电机驱动器、电池充电器、显示器、仪表、TBOX、电池等智能硬件，同时提供匹配租赁管理、车辆运营等业务场景的软件服务。北谷电子专注于打造世界级供应链和全球服务网络，目前设有中国济南和墨西哥蒙特雷两大生产制造基地，并在济南、上海、无锡、杭州、徐州、长沙、临沂、西雅图、西班牙等地设有研发中心和销售服务中心。
