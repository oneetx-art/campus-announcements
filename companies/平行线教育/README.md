## 公司
性质:民企 · 行业:教育/培训/科研

平行线教育（PARALLEL EDUCATION）创立于2009年，是一家专注理科教育培训，坚持内容驱动、文化驱动、人才驱动、数据驱动的教育企业。总部位于北京，业务覆盖广州、深圳、上海、西安、郑州、洛阳等全国多个城市。主营义务教育班课培训、VIP全科培训、科学素养培训、在线教育、图书出版、直播、高端竞赛培训、自主招生培训、教练员培训以及教育软件开发等多元化领域。
