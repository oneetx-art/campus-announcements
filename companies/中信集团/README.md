## 公司
性质:央国企 · 行业:金融业

中国中信集团有限公司（原中国国际信托投资公司）是在邓小平同志支持下，由荣毅仁同志于1979年组建的。成立以来，公司充分发挥经济改革试点和对外开放窗口的重要作用，在诸多领域进行了卓有成效的探索与创新。中信集团以“打造践行国家战略、铸就百年民族品牌”使命和愿景，按照“践行集团战略、助力民族复兴”的发展总愿景，深耕综合金融、先进智造、先进材料、新消费和新型城镇化五大业务板块，推进金融“全链条”、实业“重硬核”工程，致力成为践行国家战略的一流旗舰。国内领先、国际一流的科技型卓越企业集团。今年以来，中信集团业务已遍及全球近160个国家和地区，境内外资产超过1万亿。
