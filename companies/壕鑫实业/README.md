## 公司
性质:民企 · 行业:贸易/批发/零售

广东壕鑫实业有限公司成立于2005年，坐落于美丽的淄博市九源泉天羽漂染有限公司——惠州壕鑫纺织有限公司，并于全国多地设置销售分公司和办事处。公司是专业从事高档化纤弹性面料科研、开发、生产、销售的现代化纺织印染企业，具有完整的产业配套优势。始终秉持可持续发展理念，将生态、环保作为产品主要研发方向，先后通过GRS认证与OEKO-TEX认证，质量获得业界广泛认可。产品畅销国内外市场，与国际知名品牌均有长期良好的合作，是国内外内衣、泳装及体育运动品牌的长期稳定供应商。
