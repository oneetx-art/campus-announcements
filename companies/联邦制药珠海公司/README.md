## 公司
性质:合资 · 行业:医疗/医药/生物

珠海联邦制药股份有限公司成立于1993年，拥有员工约3000人。位于金湾区的生产基地于1998年建成投产，占地面积24万平方米；2023年，公司在珠海经济技术开发区新建生产基地，占地面积12万平方米，总投资超过20亿元，预计年产值达25亿元。公司专注于原料药和制剂产品的研发与生产，经过三十多年的跨越式的飞速发展，已成为集生产、研发、销售于一体的高科技现代化综合性制药企业。
