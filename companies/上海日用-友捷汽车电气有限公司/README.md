## 公司
性质:民企 · 行业:机械/制造业

上海日用-友捷汽车电气有限公司成立于1998年，规模超千人，是上海市高新技术企业。公司由德昌汽车电气（微电机全球领先）与上海电气集团（大型国企）共同投资组建，总部位于上海嘉定，集研发、服务、制造为一体，是汽车发动机冷却风扇总成、冷凝器风扇总成和汽车泵领域的领军企业，为大众、通用、福特、马自达、日产、宝马、捷豹路虎、沃尔沃、理想、蔚来等200多家汽车制造商提供专业的解决方案。拥有长春、成都、烟台、武汉、郑州五处分公司，销售收入近20亿，市场占有率近30%。
