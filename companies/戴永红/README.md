## 公司
性质:民企 · 行业:贸易/批发/零售

湖南省戴永红商业连锁有限公司是一家集连锁服务、仓储配送和农产品加工于一体的民营企业。公司始创于1996年，是以为创始人命名的连锁品牌。主营业务聚焦烘焙零食连锁店，并拥有独特的“戴永红”品牌炒货，工厂直供到连锁店。目前，连锁店已覆盖湖南全省，拥有超过一千二百家店铺，并且得到百万会员的认可，被消费者一致评为“喜爱的连锁品牌”。
