## 公司
性质:央国企 · 行业:通信/电子/半导体

湖南中电星河电子有限公司是由中国电子信息产业集团、湖南省人民政府与湖南先进技术研究院共建的科技型企业，于2022年6月在湖南长沙揭牌成立，是中国电子信息产业集团有限公司下属二级企业。公司体系化承接了国防科技大学在北斗导航领域积累的知识产权成果，是集央企、军队和地方优势资源共同建设的协同创新平台。公司服务国家重大战略，积极参加北斗卫星导航系统、低轨卫星互联网等国家重大工程建设，大力推进北斗+低轨卫星互联网规模应用，致力成为时空信息产业引领者。
