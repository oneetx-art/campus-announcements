## 公司
性质:民企 · 行业:IT/互联网/游戏

悦途集团成立于2012年，以“让出行更简单、旅行更精彩”为使命，专注于全球贵宾服务网络一体化、车联网数智化、交通枢纽餐饮购联网化、交旅融合化等出行全场景数字化和文化价值再造，为旅客重塑高品质的航空和铁路旅行体验。目前，全资控股“上海悦途实业、北京悦途出行、深圳悦途科技”三大子公司、82个地级市分公司，是支付宝投资企业，阿里系出行场景核心生态企业，与英国Collinson集团在香港设立合资公司，服务全球市场。网络覆盖国际国内200+航司、1700+机场、200+高铁站，建设与3000万高净值人群深度交互场景，不断推进大出行行业供给侧创新，持续优化旅客出行体验。
