## 公司
性质:央国企 · 行业:能源/化工/环保

上海核工程研究设计院股份有限公司简称上海核工院，始建于1970年2月8日，前身是七二八工程研究设计院，与我国核电事业同时起步，由国家电投控股。上海核工院是第三代先进核电技术AP1000引进消化吸收再创新的技术主体，依托国家科技重大专项，完成三代核电自主化，成功研发国和一号CAP1400大型先进压水堆核电型号。现有正式员工约3500人，包含国家级、省部级及以上高端人才500余人，设有多个国家重点实验室、上海市重点实验室，建有博士点、硕士点、博士后科研工作站等高层次人才培养平台，覆盖十大技术领域，拥有完善的学科体系，多次荣获国家级、省部级科技奖项。
