## 公司
性质:外企 · 行业:IT/互联网/游戏

罗克韦尔自动化成立于1903年，是全球最大的专注于工业自动化和信息化的跨国公司之一，也是智能制造和工业物联网领域的主要领导者。其总部位于美国威斯康星州密尔沃基市，在全球80多个国家设有分支机构，现有雇员约22000人。大连软件开发中心创建于上世纪九十年代，是罗克韦尔自动化最大的海外软件研发基地之一，目前拥有近400名员工，超过50%的员工拥有硕士学位，参与罗克韦尔自动化控制及软件业务产品的研发工作，屡获国际专业奖项，连续四届获得大连市十大“最佳雇主”，荣获2021年度大连市“卓越雇主”荣誉称号
