## 公司
性质:民企 · 行业:贸易/批发/零售

歌力思时尚集团，总部位于中国深圳。1999年成立以来，公司一直以成为具有国际竞争力的高端时装品牌集团为战略目标，专注于高端品牌时装的设计研发、生产和销售。经过二十多年的发展，公司已成为中国最大的高端时装品牌集团之一。公司于2015年4月22日，在上海证券交易所上市，股票简称“歌力思”，股票代码“603808”。上市后，公司逐步实现由单一品牌转变为多品牌运作模式。目前，公司拥有6个高端时装品牌，分别为中国高端服装品牌ELLASSAY及创立的同名男装品牌ELLASSAY HOMME、德国高端女装品牌Laurel、法国设计师品牌IRO、英国当代时尚品牌self-portrait、加拿大高端时尚羽绒服品牌nobis，成多领域的国际化品牌矩阵，覆盖不同细分市场需求。
