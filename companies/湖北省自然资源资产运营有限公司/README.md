## 公司
性质:央国企 · 行业:能源/化工/环保

2023年1月，湖北省自然资源资产运营有限公司正式成立。2024年3月，湖北联投将自然资源公司与黄麦岭控股、联投矿业、湖北四联资产整合为湖北省自然资源投资集团有限公司，系湖北联投提供全资产、全级“金资自愈资源整合者、战略资源保障和资产升值引领者，致力于打造全国一流、省内领先的自然资源全链条运营服务商。2024年7月，经省政府国资委批复湖北联投将湖北联投矿业公司、湖北省非金属地质公司划转新增到湖北联投四大主业-矿产资源体系。
