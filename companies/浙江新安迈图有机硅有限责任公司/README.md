## 公司
性质:合资 · 行业:能源/化工/环保

浙江新安迈图有机硅有限责任公司由浙江新安化工集团（中国制造业500强）与迈图高新材料集团（跨国公司，有机硅行业的先锋企业）合资组建而成。公司位于“中国最宜居城市”——浙江杭州建德市，主要生产有机硅硅氧烷、高性能新材料系列产品，总生产规模达25万吨/年，总投资超2.3亿美金。公司采用GE的有机硅生产技术，依托于双方股东强大的科研技术和管理实力，生产过程的安全可靠性高、环境污染少、产品性能优，综合质量成本指标位居世界前列。公司总人数300人，拥有一支40余人的工程技术团队，高管团队由中外双方优秀的管理人才担任，全日制本科以上技术人员占比80%。公司致力于以“醛达标”、“本质安全”、“优质产品”为目标的改善与提升，贯彻“本质安全、绿色发展；智能制造、持续改进”的战略方针，努力实现“世界一流的有机硅单体与材料供应商”的愿景！
