## 公司
性质:央国企 · 行业:IT/互联网/游戏

江苏国信数智服务有限公司是江苏省国信集团有限公司下属全资子公司，以“集团能源、金融产业数字化转型赋能者”为使命，致力成为领先的数字科技服务商。作为国信集团产业数字化、数字产业化和智改数转的技术支撑实施主体，依托国信集团能源、金融行业优势，聚焦智慧能源、智慧金融、工业互联网、人工智能与大数据、政企数字化服务、网络信息安全等开展核心技术研发和产品创新应用，提供覆盖集团全产业链的数字化、智能化综合解决方案。同时，公司具有专业的数字产业化能力，为全省国有企业数字化转型提供服务。
