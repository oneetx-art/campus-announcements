## 公司
性质:央国企 · 行业:金融业

西藏银行股份有限公司（以下简称“我行”）是中央第五次西藏工作会议确定成立的西藏首家地方性法人金融机构，于2011年12月30日正式成立，2012年5月22日挂牌营业。我行辖下总行营业部、6家地市分行、6家支行及5家筹建中的支行。近年来，我行完整、准确、全面贯彻新发展理念，深入贯彻落实党中央关于经济金融工作的决策部署及自治区落实2025年中央（国）企助力高校毕业生就业工作座谈会有关要求，切实加强西藏银行干部人才队伍建设，进一步夯实人才储备，促进高校毕业生就业。
