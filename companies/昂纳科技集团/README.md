## 公司
性质:外企 · 行业:通信/电子/半导体

昂纳成立于2000年10月，是国家火炬计划重点高新技术企业、国家级企业技术中心。总部设在深圳，同时在北京、杭州、武汉、美国硅谷、加拿大、法国、泰国设有多家研发中心和分公司，公司品牌为“O-Net”。经过多年的努力，已发展成一个领域内领先的高科技集团。在光网络集成家居光通信、激光雷达、硅光半导体器件和模块方面，已成为世界上最大的光通信器件生产商，供应商之一。客户遍及美洲、欧洲、中东、日本、印度等全球各地。
