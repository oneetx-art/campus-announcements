## 公司
性质:民企 · 行业:金融业

百丞税务是专注于企业税务服务领域的专业机构。自2003年成立以来，公司秉承“专业、务实、求远”的经营理念，以“维护纳税人合法权益，建设诚信纳税社会环境”为己任，致力于向大型集团企业、上市公司、外资企业、民营企业提供专业化、深层次的涉税服务。 百丞税务2016年挂牌新三板，2020年被评为省内唯一一家AAAAA级税务师事务所。公司总部位于山东济南，目前已在北京、上海、南京、海南、青岛、烟台、临沂、淄博、郑州、乌鲁木齐等地设有全资分支机构。 百丞税务拥有一支了解企业税务需求、精通各类税收法规、熟悉企业财务运作、能根据不同行业特点提供专业解决方案的专家团队。现有员工300余人，本科及以上学历人员占98%，其中注册会计师、税务师百余人。 百丞税务为电力、石油、化工、金融、房地产、钢铁、采矿等行业的大型集团企业提供税务服务，拥有一大批忠实的高端客户。服务项目包括税务审计、企业改制、资本运作、税务内控制度设计、专项税收优惠政策申请、税收政策培训等，是业内公认的税务专家。
