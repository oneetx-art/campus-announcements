## 公司
性质:民企 · 行业:通信/电子/半导体

广州海格通信集团股份有限公司（股票简称：海格通信，股票代码：002465）创立于2000年8月1日，是全国电子信息百强企业、广州市首家国有资本投资公司——广州产业投资控股集团（前身为本广州无线电集团）的主要成员企业。2010年8月31日，海格通信实现A股上市，是中国军工整体IPO第一股。通过“产业+资本”双轮驱动，海格通信实现了新的跨越发展，形成了“广州、北京、西安、南京、成都、长沙、武汉、杭州、重庆、天津”等地域+航空航天业务主要覆盖“无线通信、北斗导航、航空航天、数智生态”四大领域，是北斗导航装备的航空航天与全军主力供应商。
