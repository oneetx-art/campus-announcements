## 公司

江苏新日电动车股份有限公司（简称：新日股份）主要从事高端、智能电动车的研发、生产与销售，产品远销欧美和东南亚市场，目前已拥有无锡、天津、湖北、广东等多个生产基地，大型仓储物流中心，是电动车行业唯一服务过北京奥运会、上海世博会和西安世园会的电动车企业，2017年登陆A股主板上市，是电动车行业首家登陆主板的公司。
