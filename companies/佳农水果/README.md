## 公司
性质:民企 · 行业:农林牧渔

佳农集团业务始于2002年，总部位于上海，是中国水果行业的头部企业，年销售额过百亿。公司始终坚持以消费者为中心，甄选安全、美味、营养的水果，为消费者最佳体验把关，给消费者带来更多欢乐！公司主营进口香蕉、菠萝、榴莲、车厘子、蓝莓等高端新鲜水果，及国内精品苹果、梨等应季鲜水果，并且和新西兰佳沛、美国怡颗莓、新西兰乐淇等国际知名水果品牌公司达成战略合作。公司拥有成熟的物流网络，在全国32配送中心，辐射超105个城市。公司的经销渠道广泛，包括山姆、盒马、沃尔玛等知名大型连锁商超；物美、胖东来、天虹等区域性商超；以及京东、天猫、拼多多等大型电商平台。此外，公司还在多个全国性水果流通市场设立了档口。目前，佳农服务的全国零售门店超过50000家。
