## 公司
性质:民企 · 行业:能源/化工/环保

山东惟普新材料科技有限公司目前拥有山东、宁夏两大产业基地，正在加速新能源、新材料为“两翼”的全球布局。（1）齐鲁核心引领：打造锂电池新材料全产业链高地。以惟普新能源为代表的东部（山东）基地，是公司在新能源领域的核心布局，具备电池正极、负极、电解液及溶剂、溶质、添加剂全环节产品生产能力，成功打通了从“一滴油”到“一块电池”关键材料的全产业链条。作为国内首家掌握全产业链锂电池正极材料锂料剂和分散剂核心技术的供应商，已与宁德时代、比亚迪、中化蓝天等众多国内外主流企业建立了长期战略合作。（2）全国战略支点：固链中原，创新西部。宁夏基地是公司技术和资本优势的对外战略延伸，致力于打造全球最完整、最具竞争力的一体化轻烃产业链生产和研发高地。公司始终将科技创新作为第一驱动力，宁夏基地技术及研发人员占比高达23%，充分利用宁夏原料资源优势，通过乙快化学这一关键技术“逐鹿路径”，向下游深度延伸，生产高附加值、高技术壁垒的高端聚合物新材料。不仅实现了资源的高效转化与价值跃升，更是从“基础化工”向“高端材料创造者”转型的生动实践。在这里已成功攻克多项“卡脖子”技术，实现了关键材料的自主可控和进口替代。
