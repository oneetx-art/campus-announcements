## 公司
性质:事业单位 · 行业:教育/培训/科研

中国航天空气动力技术研究院是我国第一个大型空气动力研究与试验基地和中国空气动力学研究的核心机构，1956年由我国著名科学家钱学森先生倡导创立，是新中国成立后第一个航空航天科研事业单位。建院60多年来，一直从事航空、航天事业发展所需的空气动力研究与试验，为我国“两弹一星”、载人航天、月球探测等和国防工业以及国民经济建设做出了重要贡献。
