## 公司
性质:央国企 · 行业:能源/化工/环保

国能龙源环保有限公司（简称“龙源环保”）是国家能源集团旗下节能环保科技板块的核心骨干企业，成立于1993年，是国内第一家电力环保企业，现拥有分子公司共计53家，托管企业2家，参股企业15家，员工总数近2000人。龙源环保立足改革和创新发展需求，业务范围持续优化，按照发展方向划分为生态环保和能源低碳两大领域。生态环保领域包括大气治理、固废资源化、水环境治理、环保装备制造、特许运营、检测咨询业务等；能源低碳领域包括综合能源、新型储能、碳中和、新能源、氢能利用等。
