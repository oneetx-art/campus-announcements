## 公司
性质:民企 · 行业:医疗/医药/生物

大参林医药集团股份有限公司成立于1999年，中国有影响力的药品零售连锁集团化企业。公司以发展药店连锁为立业之本，经过多年耕耘，公司直营业务范围覆盖广东、广西、江西、河南、河北、福建、浙江、江苏、陕西、黑龙江、湖北、四川、海南、山东、重庆、新疆、山西、安徽、上海、湖南等21个省份（自治区及直辖市）。目前，全集团员工约50000名，其中药学专业技术人员近20000人。
