## 公司

泰康口腔集团是泰康保险集团旗下的大型口腔医疗和口腔健康管理连锁机构。2018年，泰康保险集团战略投资拜博医疗集团，2018年正式更名为“泰康口腔集团有限公司”。至今已发展成为全国布局、连锁运营、齿险结合、技术创新、专业医疗的领先口腔医疗集团。目前在北京、上海、广州、深圳等近50个城市开设超130家专业口腔医疗机构。每年提供专业、安全、便捷的口腔医疗服务超200万人次。
