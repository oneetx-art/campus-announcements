## 公司
性质:央国企 · 行业:机械/制造业

中国一汽是国有特大型汽车企业集团，1953年建厂，前身第一汽车制造厂，由毛泽东同志亲笔题写厂名。1956年建成投产制造出新中国第一辆卡车（解放牌），1958年制造出产新中国第一辆小轿车（东风牌）和第一辆高级轿车（红旗牌）。
