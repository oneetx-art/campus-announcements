## 公司
性质:央国企 · 行业:能源/化工/环保

中核龙安有限公司（简称“中核龙安”，英文标识“CNLA”），是中国核工业集团有限公司旗下全资子公司，专注于乏燃料的管理集团与核循环利用，深耕核循环工程的项目管理、工厂运行及技术研发领域。作为我国首座大型商用乏燃料后处理工厂的建设主体，公司以打造世界一流核循环后段产业中心为目标，秉承“国家先进、循环事业核力工程、创新先进核循环工厂的实践者、先进核循环的主技术创新的牵引者”的发展理念，肩负助力绿色可持续发展的重要使命。
