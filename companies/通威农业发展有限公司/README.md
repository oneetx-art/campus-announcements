## 公司
性质:民企 · 行业:农林牧渔

通威农业发展有限公司由通威股份（世界500强企业）控股，以饲料生产和水产养殖为核心业务，并同时涉及水产苗种繁育、养殖服务、动物保健、农业检测、渔业设施与装备、融资担保等诸多领域。截至目前，通威农发年饲料生产能力超过1000万吨，是全球领先的水产饲料生产企业及重要的畜禽饲料生产企业，拥有80余家涉及饲料业务的分、子公司，生产、销售网络已布局全国大部分地区及越南、孟加拉、印度尼西亚等东南亚国家。
