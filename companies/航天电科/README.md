## 公司
性质:央国企 · 行业:机械/制造业

贵州航天电子科技有限公司隶属于中国航天科工集团第十研究院，是雷达导引头、无线电测量设备的专业研制、近程防御、雷达引信及其他地面测试设备的专业研制生产单位，是国家高新技术企业、国家知识产权优势企业、国家“专精特新”小巨人企业、国家博士后科研工作站设站单位、贵州省企业技术中心、贵州省首批创新型企业。公司注册资本1.76亿元，资产总额近11亿元，现有员工700余人，其中具有中高级职称200余人，多人获评全国五一劳动模范、国务院政府特殊津贴专家等荣誉表彰。公司总部设在贵阳，拥有四川泸州研发设计中心。公司拥有四十几部雷达设计仿真软件及数千台设备、仪器仪表，建有交会靶场运动系统测试线及微波、天线、射频仿真测试室，充分满足设计研发、生产制造需求。经过多年发展，已形成航天装备、电子与电子技术和温控外延装备多元化并举的产品格局，其中电子与电子信息技术优势配套颇具实力，多个产品荣获国家和省部级奖励，国防引导头多次亮相公司。
