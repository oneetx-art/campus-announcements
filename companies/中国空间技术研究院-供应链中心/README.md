## 公司
性质:事业单位 · 行业:教育/培训/科研

中国空间技术研究院供应链中心，隶属中国空间技术研究院，其前身为成立于1984年的电子元器件可靠性中心，是中国最早从事宇航用元器件质量保证的专业机构。已经30多年的积累特别是近年来的快速发展，供应链中心经过形成集仓储物流、选用、认证、应用验证、采购、质量保证和物资贮备为一体化的完整的服务体系，为航天器提供保障元器件和材料。截至目前，供应链中心已经为超过400颗的国内外航天器提供了元器件，年器件服务量近千万只。
