深圳市智慧城市科技发展集团有限公司（以下简称“深智城集团”）是深圳市属的聚焦新型智慧城市建设、国有控股上市企业集团（深城交，301091）、国家高新技术企业。深智城集团以“让城市更智慧、让生活更美好”为使命，以“全球领先的智慧城市综合建设运营商和生态构建者”为定位，立足“智慧城市和数字政府建设提供标准一站式整体解决方案”定位，全力承接智慧城市和数字政府建设运营任务。
