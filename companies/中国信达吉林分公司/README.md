## 公司
性质:央国企 · 行业:金融业

中国信达资产管理股份有限公司（以下简称“中国信达”）成立于1999年4月，是经国务院批准成立的首家金融资产管理公司，2010年6月整体改制为股份有限公司，2013年12月在香港联合交易所主板上市（股票代码01359.HK），成为首家登陆国际资本市场的中国金融资产管理公司。目前，中国信达设有33家分公司（包括港股后援基地管理中心），旗下拥有从事不良资产经营和金融服务业务的平台子公司南商银行、信达证券、金谷信托、信达金科、信达香港、信达投资、中润发展等。中国信达立足不良资产经营主业，围绕问题资产投资和问题机构救助，着力化解金融机构和实体企业不良资产风险。
