## 公司
性质:民企 · 行业:机械/制造业

沈阳航盛科技有限责任公司（简称“沈阳航盛”）是中航工业沈阳所下属的全资国有公司，主要承担飞机装备研制与生产、软件开发与测试、试验仿真等航空国防业务，是集研发、生产、技术服务于一体的高科技企业。自2010年成立以来，沈阳航盛始终秉承“正直、诚信、规范、高效”的经营理念，坚持“人无我有、人有我优”的产品研发策略。聚焦国内外先进技术、自主创新、强化产品引领作用，在电子对抗、国内一流的先进航空技术供应商。目前，已致力于对成、通信及高速率存储等领域拥有多项精良产品，成为中航工业沈阳所航空产品研制的中坚力量。
