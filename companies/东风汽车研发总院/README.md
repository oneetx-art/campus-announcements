## 公司
性质:央国企 · 行业:汽车制造/维修/零配件

东风汽车集团有限公司研发总院前身是成立于1983年4月1日的二汽技术管理中心，是东风汽车的产品开发中心、技术研究中心、技术管理中心。东风汽车研发总院聚焦新能源、智能化等领域打造行业领先的技术研发能力与高端人才项目。旨在从全球视角，培养未来顶尖技术专家。
