## 公司
性质:民企 · 行业:能源/化工/环保

天合光能股份有限公司（股票代码：688599）成立于1997年，是全球领先的光伏智慧能源解决方案提供商。公司于2020年登陆科创板，业务覆盖光伏产品、储能系统、智慧能源解决方案及数字能源服务四大板块。公司建有“光伏科学与技术全国重点实验室”，携手复旦大学等高校共建联合实验室，持续引领技术突破，在光伏电池和组件领域35次刷新世界纪录。截至2025年6月，组件全球累计出货量超290GW，稳居行业前列。天合光能在瑞士、美国、新加坡、迪拜等地设立区域总部，业务遍及全球180多个国家，构建多元、国际化的团队与文化。公司屡获《财富》中国500强、福布斯全球2000强、国家技术发明奖、中国工业大奖等多项国内外权威荣誉，ESG表现卓越，MSCI评级提升至BBB级，位居行业领先。
