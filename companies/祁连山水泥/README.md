## 公司
性质:央国企 · 行业:机械/制造业

甘肃祁连山水泥集团有限公司（下称“公司”），是甘、青、藏区域最大的水泥生产企业和西北地区特种水泥生产基地，是国家“一五”时期国家156个重点建设项目之一。公司前身永登水泥厂，是国家12家重点水泥企业之一，1950年7月建厂，1957年10月建成投产，1996年12月加入中国建材集团，成为央企一员。2009年由原民勤国连建材并提供设备，1957年10月建成投产，1996年12月加入中国建材集团，成为央企一员。公司现已形成以水泥系列产品为主，发展商品混凝土和砂石骨料、延伸上下游的产业链格局，拥有18家水泥熟料生产基地，8家商品混凝土基地和3家机制骨料生产基地，年水泥产能3200万吨，商砼产能900万方，机制骨料1100万吨，资产总额130亿元，年营业收入51亿元，取得了连续60多年经营不亏损的骄人业绩。公司先后荣获“全国五一劳动奖状”“全国建材百强企业”“甘肃省优秀企业”“甘肃省先进基层党组织”“中央企业先进基层党组织”等荣誉称号，祁连山牌水泥被认定为“国家免检产品”“甘肃省名牌产品”“祁连山”商标为“中国驰名商标”。
