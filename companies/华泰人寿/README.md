## 公司
性质:民企 · 行业:金融业

华泰人寿保险股份有限公司（简称“华泰人寿”）由安达保险集团和华泰保险集团联合创立，总资产规模超703亿元。外资股东安达保险集团历史可追溯至1792年，是全球市值最大的上市财产及责任保险公司之一。中方股东华泰保险集团是一家综合性金融保险集团。2005年正式经营，总部设在北京，目前已经在全国21个省市开设了近300家分支机构和营业网点。
