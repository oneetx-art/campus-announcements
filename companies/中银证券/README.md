## 公司
性质:合资 · 行业:金融业

中银国际证券股份有限公司（以下简称“中银证券”）经中国证监会批准于2003年2月28日在上海成立，2020年2月26日在上海证券交易所主板上市（股票代码601696.SH）。公司总部位于上海，并在北京、深圳、广州等全国主要城市设有100多家分支机构。中银证券践行“客户至上、稳健进取”的价值观和“科技赋能、转型协同”发展战略，积极发挥股东优势、深化业务协同，努力为客户提供高品质、专业化、个性化的投资银行服务，并在资产管理和投资银行业务领域保持行业领先地位。
