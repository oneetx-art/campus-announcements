## 公司
性质:央国企 · 行业:机械/制造业

北京北方车辆集团有限公司隶属于中国兵器工业集团有限公司，是我国重要的特种车辆科研、生产单位。主要从事特种车辆的设计开发、生产制造、试验、检测和服务保障。主要产品涉及陆军、海军、火箭军、战略支援部队、武警等多个军兵种。公司始建于1946年，占地面积128.4万平方米，拥有在职员工2100余人，各种设备5000余台（套）。历年来公司生产的多种装备参加了国庆60周年、抗日战争胜利70周年、80周年、建军90周年、国庆70周年阅兵。发展至今，北方车辆集团已成为国防装备重要制造基地。
