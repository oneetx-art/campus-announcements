## 公司
性质:央国企 · 行业:金融业

国开金融有限责任公司成立于2009年8月，是国家开发银行国务院批准设立的全资子公司，注册资本约0.49亿元人民币，主要从事投资和投资管理业务。作为开发银行旗下的专业投资机构，自成立以来，国开金融坚持“国家战略性、开行协同性、机构可持续性”的发展原则，坚守“增强国力、改善民生”的职责使命，聚焦科技创新与制造业转型升级、区域协调发展与社会民生、国际业务三大业务领域，在重点领域、薄弱环节、关键时期积极发挥投资功能，紧扣国家战略打造开发性金融国家级投资机构。
