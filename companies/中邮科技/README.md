中邮科技是中国邮政集团有限公司控股的智能物流科技上市企业，专注智能物流系统研发、设计、制造及集成。核心产品包括智能分拣系统、智能传输系统、智能仓储系统和智能专用车辆，具备领先的解决方案规划设计、产品研发制造、设备安装调试及系统集成能力，积累了丰富的大型系统集成交付经验。公司主要服务于快递物流、电商、汽车、机场等行业，主要客户包括邮政、顺丰、京东、华为等头部企业，并成功拓展日韩、东南亚、欧洲等国际市场，以技术驱动为全球客户提供高效、智能的物流解决方案。
