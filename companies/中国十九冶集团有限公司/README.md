## 公司
性质:央国企 · 行业:房地产业/建筑业

中国十九冶集团有限公司（以下简称：中国十九冶）成立于1966年，是中国五矿骨干子企业、全国唯一独立承担冶金工程全流程施工的综合型建筑企业、国家高新技术企业，拥有建筑、冶炼、铁路工程、市政工程施工总承包特级资质为核心的“四特九甲”资质簇群，以及对外承包工程资质。主营工程总承包和新能源等业务，建造了数千项国内外重大工程；创新推行“一业特强、两轮驱动”“一非一民”“一核两商一流”的区域市场布局优化，构建“1+5”区域商合局发展格局，着力实施以设计施工总承包为引领，以建筑产业化平台，以建筑绿色化、智能化为支撑的发展战略，全力打造“强度、高度、速度、精度、锐度、温度”六大业务体系，不断提升工程项目全生命周期的服务能力，着力打造完整的工程产业链和价值链，用大国匠心铸造精品工程，以责任担当提供优质服务，携手社会各界朝着共同发展目标砥砺前行。
