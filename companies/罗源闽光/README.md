## 公司
性质:央国企 · 行业:能源/化工/环保

福建罗源闽光钢铁有限责任公司是国有上市企业福建三钢闽光股份有限公司的全资子公司（证券代码：002110），公司注册资本45亿元，现有职工2400余人。主要产品有热轧光圆钢筋、热轧带肋钢筋、热轧H型钢和金属制品材等。公司位于福州市罗源湾经济技术开发区内，占地约1931.68亩，紧邻沈海高速、宁东高速、温福铁路、罗源湾万吨码头和104国道，距长乐国际机场不足一百公里，交通便捷，区位优势明显。2017年起，公司销售额连年突破100亿元，跨入“百亿冶金企业”行列。
