## 公司
性质:民企 · 行业:文化/传媒/广告/体育

聚橙自2007年成立以来，深耕演出行业细分领域，做实全产业链战略布局。在流行音乐、音乐剧、戏曲艺术、儿童剧等多个领域，全品类出品制作和主办精品内容，满足不同人群的文化艺术需求。目前集团旗下已创立小橙堡、万有音乐系、聚橙音乐剧、嬉习喜戏、公共文化服务5大文化品牌，运营全国45个演艺空间，为多城市、多规模、多形态的文化空间提供定制化运营解决方案。集团不断深化“剧院+”“演艺+”等模式，拓展文旅融合、文创衍生等多业态组合服务，打造中国文化IP品牌，建设跨境文化贸易通道，推动中国文化出海，为提升中国文化在国际市场的影响力而不懈努力。
