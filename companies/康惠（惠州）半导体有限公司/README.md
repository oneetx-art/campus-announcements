## 公司
性质:民企 · 行业:通信/电子/半导体

康惠（惠州）半导体有限公司是中国航天国际控股有限公司的全资子公司，成立于1980年，位于广东省惠州市，属国有企业。公司目前有LCD、LCM、TCM、自动化设备四个事业部，是全球中、高级液晶显示器（LCD）、液晶显示模块（LCM）主要生产厂家之一，是中国液晶协会常务理事单位、广东省高新技术企业。
