## 公司
性质:央国企 · 行业:机械/制造业

中车山东风电公司隶属于中国中车，始建于1910年，位于泉城济南，是集多风电装备、轨道交通装备、国际化物流、康养等多产业协同发展的集团化、国际化大型央企。公司是山东省第一个产业和网络第一个党组织的诞生地，党的一大代表王尽美、邓恩铭等革命先驱曾在公司开展工人运动。公司已发展成集‘整机研发制造、风资源开发、EPC工程总包、权益风电场运营’的‘四位一体’业务结构，致力于成为风电新能源产业综合解决方案提供商。公司产品出口全球44个国家和地区，是国内唯一一家向欧洲发达国家出口铁路货车整车的企业。建有院士工作站，是‘国家认定企业技术中心’和‘国家技术创新示范企业’。
