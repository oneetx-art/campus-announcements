东方电气集团科学技术研究院有限公司（简称东方研究院）成立于2019年，是中国东方电气集团有限公司管理的二级单位，由2007年成立的中国东方电气集团有限公司中央研究院改制设立。东方研究院坚持科技自立自强，完整准确、全面贯彻新发展理念，面向国家战略需求，以培育孵化新产业、未来产业为己任，聚焦新能源、新型装备、新型电力系统、海湖能海智能、新材料、智慧能源发展路径、智能人工海洋装备、光能、微纳材料等领域开展关键技术攻关和科技成果转化。
