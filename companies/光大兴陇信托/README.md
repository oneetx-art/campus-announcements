## 公司
性质:央国企 · 行业:金融业

光大兴陇信托有限责任公司（简称“光大信托”或“光大兴陇信托”）是2014年5月经中国银监会批准，由央企中国光大集团股份公司控股的信托公司。光大信托是光大集团金融板块中与银行、保险、证券并列的核心子公司之一，依托光大集团央企股东背景，凭借市场化导向和过硬的经营能力，持续巩固稳健经营发展局面，得到社会广泛关注和认可，荣获诚信信托·创新领先奖、年度卓越信托机构、长青奖、金鼎奖等多项荣誉称号。
