## 公司
性质:民企 · 行业:生活服务业

成都市金优物业服务有限责任公司隶属于多元化大型企业一清风集团。起始于1997年在成都金堂县组建的“现代物业管理中心”，是成都地区最早把品质服务作为核心经营理念的物业服务机构之一。2002年，正式成立成都市金优物业服务有限责任公司。公司立足于四川成都，管理区域辐射深圳、昆明、海南地区，物业服类型涵盖高端豪宅、海景别墅、花园洋房、高端商业街、酒店式公寓、高端写字楼等多种业态，管理面积400余万平万米，服务业主超2万户，员工超1千人。
