## 公司
性质:央国企 · 行业:能源/化工/环保

福建炼油化工有限公司是由中国石化和福建省各出资50%合资建设的炼化企业，于1989年1月建厂。经过三十多年的改革发展，福建炼化公司已经形成了千万吨级炼油、两百万吨级乙烯、百万吨级芳烃的生产规模，实现泉州泉港和漳州古雷两个基地省市化发展，是中国石化的化板块的骨干企业和福建省石化产业的龙头企业。福建炼化公司现有7家合资公司，并代管商福建分公司。立足合资合作，积极探索多元化经营，涵盖中外、陆台、企地和国内等多种合资主体结构。
