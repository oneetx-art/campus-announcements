## 公司
性质:央国企 · 行业:机械/制造业

西安昆仑工业（集团）有限责任公司是我国“一五”时期156项重点建设项目之一，是国家重点保军企业，是国家战略级力量重要组成部分，公司原位于国家中心城市——古城西安，建有20万平方米；现有从业人员2100余人；拥有1个专业研究院、6个生产制造工厂和3个全资子公司。70多年来，昆仑公司以“强军报国、强企富民”为己任，以“自主创新、国际领先、拥有产权、引领未来”为目标，所研发制造的特种装备列装于港、陆、空及火箭军，在各类军事演习、阅兵等国家重大活动中尽展风采，在行业确立了精品地位，打造了昆仑防务品牌，成为国防防御装备的技术领军单位
