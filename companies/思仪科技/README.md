## 公司
性质:央国企 · 行业:通信/电子/半导体

中电科思仪科技股份有限公司（简称“思仪科技”）是中国电科集团直属二级企业，本部位于山东青岛，致力于电子测试测量前沿技术研究和高端电子测试测量仪器产品的研发、设计、制造和销售。思仪科技实现了一系列高端重大科学仪器和通用电子测量仪器领域的重大技术突破，总体技术水平处于国内领先、国际先进，毫米波/太赫兹、光通信、基础通用类电子测量仪器及核心零部件，广泛应用于场景的整体测试解决方案等，广泛应用于卫星、通信、雷达、科研、教育等领域，并在载人航天、探月、北斗、光纤通信、移动等国家重大工程项目的实施过程中发挥着重要的测试测量保障作用。
