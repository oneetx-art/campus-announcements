## 公司
性质:央国企 · 行业:房地产业/建筑业

北京城建设计发展集团（简称UCD）为共和国第一条地铁而生，成立于1958年，67年首铺耕耘。国内第一家以城市轨道交通设计咨询为引领的上市国企，城市轨道交通设计市场份额行业第一，中国城市轨道交通行业技术发展的引领者，国内城市轨道交通行业设计标准规范的主要制定者，四大全国性行业学会、协会依托单位，中国城市轨道交通科技创新创业大赛牵头主办单位。
