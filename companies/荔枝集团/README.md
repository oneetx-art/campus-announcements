## 公司
性质:民企 · 行业:IT/互联网/游戏

荔枝是纳斯达克上市公司Sound Group Inc.旗下业务品牌，Sound Group Inc.于2020年1月在纳斯达克交易所上市，是一家AI驱动的声音应用集团公司。荔枝建立了集声音社交、播客内容、音频社区为一体的音频生态，致力于通过多元化产品矩阵用声音连接用户，旗下拥有以荔枝App、荔枝播客、荔枝互娱等子品牌。荔枝集团一直致力于声音AI相关技术的深入研究和探索，与一批国内外重点高校建立了AI领域的产学研合作，并持续通过AI技术进一步赋能声音业务产品创新。
