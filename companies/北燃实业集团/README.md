## 公司
性质:央国企 · 行业:能源/化工/环保

北京北燃实业集团有限公司（简称“北燃实业集团”）为北京控股集团全资公司，起源于1958年，是一家多元化产业布局的集团化企业。北燃实业集团主要业务涵盖城市供热及新能源服务、城市能源服务业务、液化气储存与供应业务（包括液化气贸易业务）、园区运营管理及孵化服务业务，业务足迹遍布30多个省份，100多个城市。具备“科技研发-设计咨询-工程施工-运营服务”的全过程咨询和服务的能力，能够为供热、燃气等能源项目提供一站式解决方案，提高项目的整体效率和质量。
