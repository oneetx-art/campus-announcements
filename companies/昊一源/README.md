## 公司
性质:民企 · 行业:通信/电子/半导体

昊一源科技有限公司成立于2013年，总部位于深圳，是全球领先的高清音视频传输解决方案制造商。2017年创立自主品牌 海外品牌 HOLLY.LAND/国内品牌 MOMA猛玛，于2025年品牌升级为全球品牌 HOLLY.LAND猛玛。通过前沿技术力，在视频拍摄、短视频、直播领域上引领生产革新，以科技助力轻松表达，引领行业发展。公司旗下多个产品线在国际市场占据排名TOP榜，国内排名第一，累计获得20余项国内外知名奖项。
