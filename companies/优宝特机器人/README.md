## 公司
性质:民企 · 行业:智能硬件

优宝特机器人，成立于2014年，是一家致力于腿足式仿生机器人、人形机器人和液压式特种机器人产品开发的高科技企业。核心团队具有山东大学、中国科学院自动化所等知名院校背景。公司入选山东省“泰山产业领军人才计划”，“济南市引进海内外高层次创业人才计划”。获“国家级高新技术企业”“山东省专精特新中小企业”“山东省创新型中小企业”、“山东省瞪羚企业”等荣誉。2024年仅用2个月时间开发出省内首台人形机器人“行者泰山”，研发速度创造了业界人形机器人开发速度纪录。
