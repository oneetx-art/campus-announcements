## 公司
性质:央国企 · 行业:通信/电子/半导体

广州市中南民航空管通信网络科技有限公司，是中国民用航空局直属国家高新技术国有企业。公司成立于2004年，秉承“安全、和谐、进取、创新、高效”的企业发展理念，科技水平在民航空中交通管理行业处于领先地位。公司锐意进取，立足民航，真情服务社会，已获得国家工信部颁发的计算机系统集成二级证书，已通过ISO 9001:2015质量管理体系、ISO 27000信息安全管理体系认证。公司软件测试实验室通过中国合格评定国家认可委员会（CNAS）认可批准。公司拥有有效专利9项、软件著作权72个，登记在册软件产品13个。公司自研产品TOMS系统获中国智能交通协会科技一等奖，多个项目获民航局科技进步一、二、三等奖，公司实验室被列为民航空管重点实验室。
