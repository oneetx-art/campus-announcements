## 公司
性质:民企 · 行业:生活服务业

广东永旺天河城商业有限公司是由日本永旺株式会社属下的永旺（香港）百货有限公司与广东天河城（集团）股份有限公司属下的广东天河城百货发展有限公司出资成立的合资企业，使用日本永旺株式会社的零售商标AEON（永旺）。日本永旺株式会社是日本著名零售企业，2024年在《财富》世界500强企业排名第203位。广东永旺是广东市场的首家日资零售企业，率先引进了国外先进的GMS（综合百货超市）业态模式，并于2010年推出了SM（食品超市）业态。自1996年在广州市天河城广场开设首家店铺以来，至今已在珠三角城市开设41家门店。公司氛围融洽，鼓励员工创新和发展，同时为员工提供丰富的培训和晋升机会。
