## 公司
性质:外企 · 行业:通信/电子/半导体

东莞森玛仕格里菲电路有限公司建于2006年3月，公司总部位于意大利，总部在全球各国拥有多家制造基地（中国、意大利、美国、英国、韩国、瑞士等地均有工厂），其中我司位于东莞市茶山镇伟建工业园，占地面积72000平方米，现有员工800余人。批量生产4-70层高端刚性线路板及4-30层刚挠结合线路板、多层医疗软板及载板等产品。相关技术在世界同业中占据领先地位，产品广泛应用于通讯、信息、汽车、医疗、航空电子等高科技领域，是一家集研发、生产、销售为一体的国家高新技术企业。
