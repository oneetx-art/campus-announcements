## 公司
性质:央国企 · 行业:能源/化工/环保

中国五环工程有限公司（原化学工业部第四设计院）创建于1958年，现为国务院国资委管辖的中国化学工程集团有限公司的全资子公司。作为在汉央企，是集技术研发、工程科技、工程服务和实业运营为一体的国际型工程公司，拥有“工程设计综合甲级资质”，在氯及氯加工、磷化工、煤化工、石油化工、天然气化工、油气储运、新材料、工业环保等领域，是中国最具实力的工程公司之一。
