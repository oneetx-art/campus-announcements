## 公司
性质:央国企 · 行业:机械/制造业

中广核高新核材集团创立于1983年。2014年1月正式加盟中国广核集团，由中广核技术发展股份有限公司控股，成为中国广核集团的三级全资子公司，是一家集高分子材料研发、制造、销售于一体的集团型企业，2017年作为核心资产装入上市公司。公司总部位于江苏省太仓市，总注册资金超15亿元，是全国领先的线缆高分子材料生产企业。
