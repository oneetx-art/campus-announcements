## 公司
性质:民企 · 行业:能源/化工/环保

江瀚新材（股票代码：603281）是一家专业从事功能性进出口贸易为一体的硅基材料的研制、生产、销售与进出口贸易及其他硅基新材料，由原荆州市江汉精细化工有限公司于2020年12月22日更名而来，占地于湖北荆州市经济开发区沙市化工园内，占地700亩，员工过千人。公司是国家高新技术企业，现有湖北省功能性硅烷工程技术研究中心与湖北省企业联合技术创新中心省级研发平台，以及“武汉大学联合成立”湖北省功能硅烷工程研究中心生产中试基地等校企合作研发平台，公司校企联合创新中心“有机硅化合物及材料平台”，获得授权国家专利68项，主持和参与起草国家标准、行业标准16项。公司产品主要有硅烷偶联剂和乙烯基硅烷、环氧硅烷、氨基硅烷、含硫硅烷、氯基硅烷、丙烯基硅烷、烷基硅烷系列、200多个品种的硅烷交联剂及硅烷衍生物。公司14个系列产品、含氧基硅烷、烷基硅烷、环氧硅烷等产品，广泛航空于国防、电子、冶金、建材、全球86个国家和地区，产品出口此例超过50%。
