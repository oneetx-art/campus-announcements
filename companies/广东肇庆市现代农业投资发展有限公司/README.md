## 公司
性质:央国企 · 行业:农林牧渔

广东肇庆市现代农业投资发展有限公司是市直国资系统首家农业版块重点企业，前身是肇庆市市场物业管理服务总站，于2022年9月完成“事转企”并正式挂牌。公司立足肇庆，辐射湾区，旗下拥有10个国有农贸市场及3家全资子公司，业务覆盖农贸市场运营、调味食品加工、现代农业产业、粮食储备等领域。
