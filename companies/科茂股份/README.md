性质:民企 · 行业:能源/化工/环保

广东科茂林化集团股份有限公司（证券代码：874122）是一家专注于松树化学品研发、生产和销售的高新技术企业，源自于1994年曾广健先生创立的广州科茂化工有限公司，随后不断发展壮大，现控股14家子公司，产业布局覆盖全国。公司专注于为粘合剂、涂料、油墨等行业提供低碳增粘的解决方案，强大的研发能力和多元化的产品线在国内外市场上赢得了广泛的赞誉和认可，曾多次参与松香行业国家标准制定，获得过省重点农业龙头企业、省级林业龙头企业、高新技术企业、省级企业技术中心、省级工程技术研究开发中心、省级专精特新中小企业等殊荣，目前拥有超过80项专利和19项商标的注册权。
