## 公司
性质:民企 · 行业:金融业

建信基金管理有限责任公司成立于2005年9月，是境内首批成立的银行系基金公司之一，多年来致力于成为可信赖的财富管理专家、资产管理行业的领跑者。成立以来，建信基金以“善建财富”将“善建者”的文化传承与财富管理行业的本源相结合，以“相伴成长”将自身与客户价值的成长紧紧联系在一起。以公募业务为发展基石，同时拓展专户业务，相继设立子公司建信资本管理有限责任公司与建信资产管理（香港）有限公司。截至2025年上半年，建信基金资产管理总规模1.43万亿，能超9200万各类客户财富管理需求，提供国际化、全方位、一站式资产管理服务。
