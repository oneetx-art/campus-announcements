## 公司
性质:央国企 · 行业:IT/互联网/游戏

金航数码科技有限责任公司（中航工业信息技术中心）是中国航空工业集团有限公司的信息化支撑机构、“数字航空”总体技术牵头单位，聚焦“工业软件国家队”“支撑集团数字化建设”的作用发挥，肩负着“数字助力打造强国，软件定义未来工业”的使命，着力打造工业软件原创技术策源地，发挥现代产业“链主”作用。聚集数字赋能、数字化转型、大数据、人工智能、云计算等新一代信息技术的创新应用，引领装备制造业数字化转型，实现高质量发展，服务于新质作战能力提升，助力军事科技创新。金航数码现有员工1000余人，总部设立在北京，在上海、成都、西安、沈阳、南昌等地设有分支机构。客户主要广泛分布在中航工业、中国航发、中国商飞、航天科技、航天科工、兵器工业、兵器装备部，以及中海油、中石油等集团用户，客户数量超过1000家。
