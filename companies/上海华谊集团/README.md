## 公司
性质:央国企 · 行业:能源/化工/环保

上海华谊集团股份有限公司是上海市大型国有化工企业集团，前身是上海化工局，1995年改制组建为上海化工控股（集团）公司；1996年，与上海医药局联合重组改制成立上海华谊（集团）公司。2016年组建上海华谊集团股份有限公司，并完成股票更名上市。华谊集团现有“能源化工、绿色轮胎、先进材料、精细化工、化工服务”五大核心业务，多个产品在国内市场名列前茅。
