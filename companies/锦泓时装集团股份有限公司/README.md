## 公司
性质:民企 · 行业:快速消费品

创立于1997年，集团总部位于中国上海市，于2014年在上海证券交易所主板上市（股票代码603518）。主要业务为中高档时装的设计研发、生产制造、品牌营销及渠道销售。旗下拥有多个自有品牌：VGRASS、TEENIE WEENIE、元先。品牌覆盖中高端服饰、高级定制和场合服饰、高端工艺品和国潮文创礼品等产品线。形成了金字塔式的立体品牌矩阵布局。全国店铺数量逾1000家，遍布国内各大城市核心商圈。
