## 公司
性质:民企 · 行业:政府/机构/组织

2011年，在中山大学领导的推动下，中创集团应运而生。经过十余年发展，中创集团打造了“产业集群+产业孵化+产业服务+产业生态”的全链条发展模式，成为大湾区新兴产业创新与转型升级的领航者。如今，依托广东医谷、广东材料谷、中大创新谷三大平台，我们聚焦生物医药、新材料、未来装备三大战略新兴产业，在产业发展和产业生态建设上不断深耕。目前，我们已在广州、佛山、珠海、中山等大湾区核心城市布局多个标杆项目，更有“国家级科技企业孵化器”、“广东省创业孵化示范基地”等多项荣耀。
