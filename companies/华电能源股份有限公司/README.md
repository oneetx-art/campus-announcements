## 公司
性质:央国企 · 行业:能源/化工/环保

中国华电集团有限公司黑龙江分公司（华电能源股份有限公司）是中国华电集团有限公司在黑龙江、热力的发电主体和资本运作平台，主要负责生产电力、热力产品，发电及供热规模列黑龙江省发电供热企业首位，是中国华电集团有限公司控股的上市公司。所属企业建成于各个历史时期，不仅是中国电力工业发展的红色文化“博物馆”，也见证了黑龙江省电力工业的发展历程。公司深入践行“中国华电 度度关爱”的企业理念，积极融入新发展格局，全力践行“12345”行动纲领，全力打造“五位一体”龙江华电品牌，融入新发展格局，更加紧密联系社会民生，推动实现公司高质量发展。
