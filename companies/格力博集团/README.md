## 公司
性质:民企 · 行业:机械/制造业

格力博集团成立于2002年，自2007年开始从事新能源园林机械的研发、设计、生产与销售，是领先的新能源园林机械品牌企业。公司掌握电池、电机和电控核心技术，加速实现世界园林机械行业从传统汽油机向新能源电力的革命性转变。公司拥有优质的客户资源，主要客户包括Amazon、Walmart、Costco等大型商超电商。
