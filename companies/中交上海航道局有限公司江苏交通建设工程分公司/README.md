## 公司
性质:央国企 · 行业:房地产业/建筑业

中交上海航道局有限公司江苏交通建设工程分公司（以下简称“江苏交建公司”）成立于2016年7月，位于江苏省南京市，是中交上海航道局有限公司下属实体分公司。“十三五”期，江苏交建公司充分发挥局公司“百年上航”品牌优势，重点经营环保、水利、市政等与“水”相关的业务，在江苏、安徽、河南三省斩获多个具有重大影响力的水环境、市政及水利项目。“十四五”期，江苏交建公司重点立足江苏、安徽两省主营市场，聚焦水运、市政、水利、环保等主营业务，争当上航局苏、皖区域市场引领者，为助力“高质量发展新上航”建设贡献力量。公司高度重视人力资源开发工作，致力打造年轻化、专业化的人才梯队，坚持“骨干引领、项目育人、人尽其用”的人才培养理念，积极营造“有朝气、有活力、有激情”的文化氛围。公司目前在职员工200余人，且拥有一支年纪轻、学历高、具有丰富实践经验的项目管理团队。
