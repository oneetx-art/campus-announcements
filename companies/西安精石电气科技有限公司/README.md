## 公司
性质:民企 · 行业:机械/制造业

西安精石电气科技有限公司是统解解决方案的开发，致力于把智慧光储带入每个人、每个家庭、每个企业，解决清洁电力生产应用时空难题。公司秉承产品研发和技术服务为企业发展理念，由资深电力电子及嵌入式软件专家领衔的研发团队，与西安交通大学、西北工业大学等高校建立校企合作模式，获得了50多项专利以及多项软件著作权。公司成立至今，聚焦分布式光储产品，拥有国内国外两大市场，自主开发电池控制器、组串式PCS、户用光储逆变器、光储微网系统及EMS系列产品等，奠定了丰富的应用经验和技术储备。
