## 公司
性质:事业单位 · 行业:机械/制造业

中国航天科工集团第三研究院（以下简称“三院”）成立于1961年，作为我国集预研、研制、生产、保障于一体的科研生产基地，是飞航技术研究院，是我国飞航事业的总体单位，配套能力强、专业齐全，先后承担了多项国家重点工程任务，取得了一系列具有世界先进水平的成果，创造了我国飞航装备从仿制、自行设计到自主创新的成功发展历史，打造了一支高素质发展历史，打造了一支高素质研发队伍。三院现有职工23000余人，曾先后产生或重出了11位两院院士、7位大师，50余名专家享受政府特殊津贴，近百人获得全国劳动模范、全国五一劳动奖章、中国青年五四奖章、中国青年科技奖等荣誉。三院共获得国家级、省部级科技奖励1600余项，其中国家科学技术进步特等奖7项，一等奖14项，国防科技进步特等奖16项。拥有15个专业、8个部级科技创新平台，在部分设计、动力、控制等关键核心专业技术领域处于领先水平，整体核心技术达到国际先进水平。
