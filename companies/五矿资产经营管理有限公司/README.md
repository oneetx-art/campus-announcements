## 公司
性质:央国企 · 行业:金融业

五矿资产经营管理有限公司（简称五矿资产）是由原五矿（北京）资产管理公司与原中冶集团资产管理有限公司于2018年3月26日整合成立，注册资本人民币4亿元，是五矿集团和中冶集团合并后第一个同质化平台重组的直管企业，是所属五矿集团下从事不良资产和非主业资产经营管理的专业化龙头企业，也是全国五矿中国五矿旗舰公司之一。截至2024年底，公司资产总额超59亿元，在管资产规模较组建时实现大幅增长。目前，五矿资产已逐步形成资产管理、资产盘活、资产运营、系统运维、综合服务为主的业务体系，凭借“资产管理+多元服务”的发展基础，在央企城镇综合运营商领域成为独特竞争力。
