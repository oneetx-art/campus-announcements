## 公司
性质:民企 · 行业:机械/制造业

苏州珂玛材料科技股份公司（简称“珂玛科技”）是国家特聘专家刘先兵博士于2009年创办，注册资本4.36亿元。珂玛科技于2024年8月在创业板成功上市。公司聚焦于先进陶瓷关键基础材料及核心零部件，是国家专精特新“小巨人”企业。公司在江苏苏州，四川眉山，安徽滁州布局三大生产制造基地。在半导体装备领域“卡脖子”的先进陶瓷产品方面，打破了欧美日封锁，成为极少数同时为国内国际一流半导体装备企业供货的核心供应商。
