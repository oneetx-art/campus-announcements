## 公司
性质:民企 · 行业:机械/制造业

轻舟智航（QCraft）是世界前沿的自动驾驶通用解决方案公司，拥有轻、快、高效的自动驾驶的全栈研发团队，秉承「安全+」战略，将安全贯穿产品研发、品牌塑造与可持续发展。公司研发人员占比高达80%，其中硕博占比近80%，全面覆盖自动驾驶技术研发和商业化领域，每年都有多篇论文入选CVPR、ICCV等计算机视觉领域的行业顶会。面向前装量产，「轻舟乘风」智能辅助驾驶方案已量产上车超60万台，市占率行业领先，并业界首发基于单征程6M「安全的端到端」城市NOA方案。作为Robobus行业的领跑者，在L4级产品方面，轻舟智航自动驾驶解决方案已累计落地超20座核心城市并服务超过65万人次。
