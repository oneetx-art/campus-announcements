## 公司
性质:央国企 · 行业:金融业

赣州银行是由赣州市本级国有控股、县域国有资本参股的具有独立法人资格的地方性股份制商业银行。自2001年11月28日成立以来，已发展成为一家经营业绩优良、品牌形象良好、综合实力较强的商业银行。多年来，赣州银行始终坚持“稳健经营、合规经营、科学发展”的经营理念，着力推进转型发展，持续优化资产质量，不断提升经营管理水平，取得了良好的经营业绩。
