## 公司
性质:央国企 · 行业:房地产业/建筑业

成都建筑材料工业设计研究院有限公司（简称：成都建材院）是1953年成立的国家甲级设计研究院，是以提供全产业链集成、整体解决方案的国际综合型工程公司，隶属于国务院国资委所属世界500强企业——中国建材集团有限公司，是上市公司中国中材国际工程股份有限公司的全资子企业，是国家高新技术企业、全国优秀勘察设计企业、中央企业先进集体单位。公司拥有领先技术优势和完整系统集成服务能力、强大的全球资源配置能力、良好的工程履约管控能力，是面向全球的集科研开发、工程设计、工程总承包、核心高端装备制造和综合生产运营商、投资融于一体的世界领先的EPC承包商和综合工程服务商，业务遍及全国、中东、中亚、东亚南亚、南美、非洲、欧洲等区域。
