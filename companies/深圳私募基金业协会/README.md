## 公司
性质:社会组织 · 行业:政府/机构/组织

深圳私募基金业协会是中国证监会派出机构（深圳证监局）作为业务主管单位指导设立的地方性行业协会，现有会员单位719家。协会积极履行“自律助手”“服务能手”“发展帮手”工作职责，汇聚监管机构、政府部门、市场主体等各方资源，发挥协调、桥梁和纽带作用，致力于促进深圳辖区私募行业持续稳定健康发展，积极推动行业在服务国家政策，尤其是服务粤港澳大湾区和深圳建设中国特色社会主义先行示范区中发挥先行、引领作用，推动深圳“双区”建设。
