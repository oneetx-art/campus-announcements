## 公司
性质:央国企 · 行业:交通/物流/仓储

东部机场集团有限公司是江苏省委、省政府从推动全省机场资源整合的战略高度出发，依托于南京禄口国际机场组建的省级机场集团。集团下辖南京、徐州、常州、连云港、淮安、盐城、扬州等7家机场。机场集团于2018年9月15日正式挂牌成立，由江苏省政府授权管理。2024年，东部机场集团完成旅客吞吐量4798万人次，货邮吞吐量47.7万吨，同比分别增长13.3%、5.8%。
