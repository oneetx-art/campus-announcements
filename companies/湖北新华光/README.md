## 公司
性质:民企 · 行业:通信/电子/半导体

湖北新华光信息材料有限公司（以下简称“公司”）始建于1969年，是中国兵器工业集团北方光电股份有限公司（股票代码：600184）的全资子公司，地处湖北省襄阳市高新技术产业开发区，是我国最大的光学玻璃生产企业之一。公司专注于重大玻璃企业、国家知识产权示范企业、国家绿色工厂、高新技术企业。产品包括玻璃基材（可见光和红外）、功能玻璃材料、二次成型件、智能窗穿戴、智慧家居、智慧安防、投影仪、无人机、机器人、光通信、半导体及国防军工等领域。
