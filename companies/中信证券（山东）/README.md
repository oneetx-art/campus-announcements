## 公司
性质:央国企 · 行业:金融业

中信证券是中国首家A+H股上市的证券公司，业务范围涵盖证券、基金、期货、外汇和大宗商品等多个领域，通过全牌照综合金融服务，全方位支持实体经济发展，为国内外企业客户、机构客户、高净值客户、零售客户提供各类金融服务解决方案。中信证券（山东）有限责任公司是中信证券股份有限公司的全资子公司，在山东、河南设有63家分支机构（山东55家，河南8家）。从总部到各网点搭建了以营销、财富管理、投资顾问和运营为骨架的四大体系，形成了以总部集中统一交易、服务和管理平台为枢纽，以各地市网点为支撑，辐射发达市县的金融服务网络。
