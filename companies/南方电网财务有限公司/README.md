## 公司
性质:央国企 · 行业:金融业

南方电网财务有限公司是经原中国银行业监督管理委员会批准设立的非银行金融机构，是南方电网有限责任公司的全资子公司，注册资本70亿元人民币，是南方电网的资金注册平台、资金结算平台、资金监控平台、金融服务平台和库体系执行主体，主要为南方电网公司及成员单位提供包括存款、结算、信贷、票据、中间业务等金融服务，主要指标位居财务公司行业前列。目前，公司下设12个职能部门和1个直属机构以及广西、云南、贵州、海南4家分公司。公司营业场所分布广州、南宁、昆明、贵阳和海口。
