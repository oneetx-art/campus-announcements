## 公司
性质:民企 · 行业:智能硬件

容知日新成立于2007年（股票代码：688768），是一家聚焦工业互联网的上市公司，致力于为客户提供领先的设备智能运维解决方案。容知日新坚持以科技创新引领产业发展，将物联网、人工智能技术与真实的行业应用相结合，已建成传感器、人工智能、边缘计算、云平台、大数据等技术中台，形成了工业设备智能运维整体解决方案，PHM700工业大脑、M3000设备运维云平台等产品已在石化、能源、水泥等行业头部企业深度应用。
