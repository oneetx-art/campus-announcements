## 公司
性质:事业单位 · 行业:教育/培训/科研

中国科学院成都山地灾害与环境研究所成立于1966年，结合区位优势、学科特点和发展基础，面向国家山区防灾减灾和生态环境建设战略需求，开展基础性、战略性和前瞻性山地科学研究，承担完成千余项国家和地方重大科研项目，解决了山区建设发展中的一系列重大科学问题，为我国山地灾害研究防治、脆弱山地生态恢复重建以及山区可持续发展做出了突出贡献
