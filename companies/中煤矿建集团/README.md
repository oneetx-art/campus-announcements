## 公司
性质:央国企 · 行业:能源/化工/环保

中煤矿山建设集团有限责任公司（简称“中煤矿建集团”）是经国务院国资委由中煤建设集团企业，隶属于安 徽省国资委，是国家第三批“双百企业”。有限责任公司、中煤特殊凿井有限责任公司、安家淮 国营企业等组成而成，是我国首批行业甲级资质的施工总承包特级资质，是国内行业获得矿山工程总承包一级资质和市政公用工程施工总承包一级资质，煤炭行业、公路行业 2 项施工总承包特级资质，21 项勘察、设计施工总承包一级资质，和 13 项专业承包一级资质，施工总承包一级资质，市级公用- 承包一级资质，设计（建设、运营），房屋建筑、机电安装、市政、公路、30 余项其他资质，是一家集矿山勘察、设计、建设、运营、房屋建筑、机电安装、市政、公路、铁路等产业链一体化的综合型企业及房地产开发、投资运营、商业物业等工程施工，以及房地产开发、投资运营等
