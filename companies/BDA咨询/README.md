## 公司
性质:合资 · 行业:咨询

BDA(www.bda.com)是一家成立于1994年的投资研究和咨询公司，办公地点位于中国北京。我们的主要客户包括领先的私募股权基金、对冲基金、风险投资基金和主权财富基金。我们为金融机构提供专业的投资研究服务，覆盖一级市场商业尽职调查及二级市场的基本面研究服务。BDA的行业研究领域广泛，包括互联网、消费和服务、医疗、高科技、汽车和新能源等领域。除对中国市场具有深厚理解之外，我们还覆盖东南亚(印尼和越南)、南亚(印度)及欧美等其他市场。BDA多行业多领域和全球化的高质量研究能力，使得我们能够持续为客户的投资战略提供服务。
