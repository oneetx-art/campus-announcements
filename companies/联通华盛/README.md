## 公司
性质:央国企 · 行业:IT/互联网/游戏

联通华盛通信有限公司是中国联通全资子公司，成立于2008年，注册资本6.1亿元。公司总部在北京，设置“科技创新、市场营销、敏捷支撑”三大板块共15个部门，设立31个（直辖市、自治区）分公司、4个专业分公司。联通华盛公司定位于中国联通终端融合开放运营与数字安全供应链的科技服务公司，作为中国联通终端与智能卡产品唯一供应者、自主研发者、平台运营者，承担中国联终端与智能卡产品运营工作，同时开展自主终端产品研发、客户服务及号码运营等业务。建有专家实验室、创新工作室和科技创新、自主研发团队，肩负聚合终端产业上下游资源，保障各级终端与智能卡供应链安全，助力中国联通业务发展的使命。
