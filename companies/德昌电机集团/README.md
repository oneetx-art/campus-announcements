## 公司
性质:民企 · 行业:机械/制造业

德昌电机集团是电机、执行器、驱动子系统及相关机电部件的国际领先制造商。集团为许多行业提供服务，包括汽车产品、智能电梯、医疗器械、商务设备、家居自动化、通风设备、家用电器、电动工具及割草机和园艺设备。集团总部设于香港及于全球超过20个国家雇用超过30,000人。德昌电机控股有限公司在香港联合交易所有限公司上市（股份代号：179）。
