## 公司
性质:民企 · 行业:IT/互联网/游戏

西山居（SEASUN）成立于1995年，是金山集团的第一个游戏工作室，也是中国最早的一批游戏工作室。西山居以“创造快乐、传递快乐、分享快乐”为使命，持续为业界贡献技术之美，荣膺国家863计划支持。自研IP“剑侠情缘”品牌直接面向用户，被用户和粉丝所喜爱。自研3D引擎“剑侠”是赋能游戏的扛鼎之作，科幻机甲赛道的新品《剑星》更是历经20余年，在中国和东南亚广受玩家喜爱，《剑网3》也已在全球上线，奠定了剑侠在创新开拓、进取线上的决心。我们积极为元等玩家赛道齐头并进，开拓布局，在影视、科幻、二次元等玩家赛道齐头并进，不断推动游戏、影视、科幻等快乐传播给全球玩家的愿景表达，达成中国人的精神文创新形态，希望用更多元化的题材表达中国人的精神内涵。
