## 公司
性质:民企 · 行业:金融业

广东潮阳农村商业银行股份有限公司（简称“潮阳农商银行”）是总行级法人地方性股份制商业银行。潮阳农商银行于2020年12月改制成功，由香港上市企业东莞农商银行控股，是汕头市潮阳区、潮南区金融行业中经营规模最大，营业网点、从业人员最多的金融机构，资金和综合实力位居当地金融同业首位。潮阳农商银行深耕汕头市“两潮”地区，致力于服务三农，大力推广普惠金融工作。
