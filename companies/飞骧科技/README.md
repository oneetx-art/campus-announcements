## 公司
性质:民企 · 行业:通信/电子/半导体

深圳飞骧科技股份有限公司成立于2015年5月，总部设立于深圳，在上海、西安、北京、无锡、重庆设有研发中心；在深圳、上海、北京、西安、香港、台湾、韩国设有销售和技术支持中心。飞骧科技深耕射频领域超10年，拥有351项授权专利，国家专精特新小巨人企业。产品覆盖射频功率放大器模组、Wi-Fi模组、滤波器模组、车载通信模块、卫通产品等。
