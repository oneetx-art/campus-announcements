## 公司
性质:民企 · 行业:文化/传媒/广告/体育

飞博共创成立于2010年，聚焦社交内容传播。2015年挂牌新三板，成为国内自媒体第一股。作为社交媒体'本地人'，拥有行业较为领先的自媒体孵化、内容运营及整合营销能力，助力客户完成品牌营销、效果转化及粉丝价值沉淀。除厦门总部外，已陆续在北京、上海、成都、杭州等地设有分公司，人员总规模超300人。在微博、微信、抖音、小红书等平台创立孵化@冷笑话精选、@人类行为图鉴、@意公子、@十四点、@乖巧宝宝、@野萌君等400多个内容品牌、人格品牌及表情包IP，累计超4.9亿粉丝。
