## 公司
性质:央国企 · 行业:机械/制造业

贵州航天天马机电科技有限公司，是中国航天科工集团第十研究院地面装备科研生产总体单位，是大型国有控股企业，现有员工1000余人，其中研发人员450余人。公司位于贵州省遵义市中心城区，交通便利。公司是国家高新技术企业，是贵州省企业技术中心、创新型领军企业，拥有国家级焊接技能大师工作室。专业技术覆盖装备总体、机械、机电、液压、气动、控制、材料、通信、计算机及软件等多个学科领域，是一家集研发、制造、销售为一体的航、地、装备科研生产总体单位。
