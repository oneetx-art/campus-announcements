## 公司
性质:央国企 · 行业:房地产业/建筑业

北京市市政专业设计院成立于1984年，经过近40年深厚积淀，公司已具备市政公用工程行业甲级、公路工程甲级设计资质，市政公用工程、公路工程咨询甲级资信等多项甲级资质以及园林景观、建筑设计、测绘等乙级资质。2010年被评为国高新技术企业，2025年被评为中关村高新技术企业。业务领域涉及道路交通、水资源与环境、建筑景观、城市更新与养护，可从事市政道路、桥梁、给排水、城市隧道、综合管廊、热力、公共交通、环境卫生、交通工程等领域大型工程的设计任务及设计、测绘、咨询、项目管理、工程总承包等一体化的全产业链建设服务。
