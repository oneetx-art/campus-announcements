## 公司
性质:民企 · 行业:医疗/医药/生物

杭州口腔医院集团/宁波口腔医院集团始创于1952年，深耕口腔医疗行业七十余年，是浙江省乃至国内历史悠久、规模庞大、具有影响力的口腔专科医院。医院专业设置齐全、技术力量雄厚，坚持医教研一体化发展，致力于提供高水平的口腔医疗服务。是全国科普教育基地、国家级口腔住院医师规范化培训基地。并与杭州医学院合作创办存济口腔医学院，开设五年制本科口腔医学专业。目前在全国拥有口腔机构80余家，其中浙江省内开业口腔医疗机构65家，牙椅2500余台，医技护4000余人，中高级职称近1300人，硕博士近500人。在浙江省内实施杭州口腔医院、宁波口腔医院双品牌战略。
