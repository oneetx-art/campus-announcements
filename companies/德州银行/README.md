## 公司
性质:央国企 · 行业:金融业

德州银行成立于2004年12月7日，是中国银监会成立后获准开业的首家城市商业银行。2017年，山东省国有资产投资控股有限公司战略投资，成为本行第一大股东。自成立以来，德州银行始终坚持“服务地方经济、服务小微企业、服务市民群众”的市场定位，深度融入地方经济社会发展大局，实现了经营发展与风险控制的并重双赢，各项业务发展势头良好，连续两年被中国银监会评为“全国一类城市商业银行”，先后获得“全国最具成长性企业”、“全国企业文化发展优秀单位”、“全国文明职工之家”、“全国文明规范服务示范单位”、“全国‘模范职工之家’”、“中国银行业‘规范服务优秀企业形象单位’、中国银行业星级服务评价企业最佳战略城市、商城行政区深港标杆、山东社会责任企业、山东省级‘银行业小微企业贷款工作先进单位’、德州市‘富民兴德’劳动奖状先进单位等荣誉称号。
