## 公司
性质:民企 · 行业:农林牧渔

江西丰林投资开发有限公司，前身由江西省林业厅营林产业开发中心携手系统内投资企业，按照省委省政府七个非工系统国企改革，于2010年按照上市企业标准发起设立，后于2011年经省政府文件要求以省林业局交至江西省国有资本运营控股集团有限公司。注册资本5000万元，实收股本1亿元。公司主营业务为森林资源培育与综合利用（造林营林、纸浆经营、松香树脂、松节油等林产化工系列产品的生产与销售以及园林业务）。
