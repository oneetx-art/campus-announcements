## 公司
性质:民企 · 行业:通信/电子/半导体

浙江水晶光电科技股份有限公司创建于2002年8月2日，2008年9月19日在深圳交易所挂牌上市（股票代码：002273）。我们一直秉持“创新让光学更强大，光学让世界更美好”的使命，致力于成为“全球卓越的一站式光学解决方案专家”，布局消费电子、车载光电、元宇宙光学三大行业，构建多元成长曲线。2024年实现营收62.78亿，同比增长23.67%，净利润10.3亿，同比增长71.57%。
