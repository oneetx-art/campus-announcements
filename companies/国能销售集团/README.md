## 公司
性质:央国企 · 行业:贸易/批发/零售

国家能源集团煤炭经营分公司(国能销售集团有限公司)是集团公司旗下以煤炭购销为主业的专业化公司，公司下辖12个二级单位，是目前全国最大的煤炭经营企业和集团公司煤炭产运销一体化运营的枢纽单位。公司搭建了较完整的采购和销售网络，形成了资源组织、市场开拓、物流货管、质量监管、售后服务等全过程的购销业务体系，业务覆盖全国30个省(市、自治区)，与电力、冶金、化工、建材等各行业的1000多家客户建立了长期稳定的合作关系。
