## 公司
性质:央国企 · 行业:房地产业/建筑业

中建六局第八建设有限公司，是中国建筑集团有限公司的三级法人单位，是中国建筑第六工程局有限公司的重要骨干企业和投身国家经济策高地的排头兵，设南方、安徽、华3分公司和12个营销事业部。公司在广州、合肥实施“双法人、双总部”布局，在广州设立法人单位中建六局建设投资（广东）有限公司，注册资本为9500万元，主要从事基础设施、高端房建等领域的“投、融、建、运”等工作。
