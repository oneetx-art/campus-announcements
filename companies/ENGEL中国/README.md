## 公司
性质:外企 · 行业:机械/制造业

ENGEL集团是塑料加工机械集成系统解决方案供应商，涵盖热塑性塑料和弹性体注塑机及自动化组件，总部位于奥地利，成立于1945年，全球有10家生产工厂，85个国家拥有子公司和代表处，员工总数超7000人，每年研发投资超1.25亿欧元，投资总额超5亿欧元（2018 - 2025）。
