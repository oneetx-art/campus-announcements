## 公司
性质:央国企 · 行业:机械/制造业

中国航天科技集团有限公司第五研究院西安分院（504所）1965年6月29日正式成立，是中国航天科技集团有限公司卫星通信与导航、电子信息技术研究院，简称西安分院。隶属于中国航天科技集团有限公司第五研究院，是我国空间飞行器有效载荷总体单位，是通信卫星、导航卫星应用系统与各类星载、弹载产品研制的总体单位和核心单位，是我国通信和具有国际竞争力的空间飞行器有效载荷研制、生产基地。西安分院代表着我国通信卫星、导航卫星、遥感卫星、深空探测卫星有效载荷的发展水平，是我国通信卫星导航系统建设的主力军，是我国卫星通信技术的领跑者，是我国通信、海上导航技术领域的重要力量。60年来，西安分院已成功研制了东方红一号卫星开始的我国历代通信卫星和导航卫星；6年来，西安分院先后承担天宫、神舟与探月、北斗导航工程、火星探测工程、月球采样工程、500米口径球面射电望远镜等国家重大工程研制和关键系统产品，为我国航天事业、国防建设和国民经济建设作出了突出贡献。
