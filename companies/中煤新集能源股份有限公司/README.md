## 公司
性质:央国企 · 行业:机械/制造业

中煤新集能源股份有限公司（以下简称公司）是中国中煤在皖二级企业，产业分布在皖赣两省，紧临长三角煤炭消费集中地，能源、公路、水路、铁路交通运输便捷，主营煤炭、电力、新能源等业务。公司1989年12月进行矿区开发建设，2007年12月在A股上市，2017年4月划入中国中煤。截至2025年6月底，公司资产总额超480亿元，在册职工1.7万人。现有生产矿井5对，生产能力2350万吨/年，煤电控股总装机796万千瓦，参股129万千瓦。
