## 公司
性质:央国企 · 行业:能源/化工/环保

中国有色桂林矿产地质研究院有限公司（简称“中色桂林院”）1955年创建于北京，是国务院国资委管理的大型中央企业—中国有色矿业集团全资子公司，现位于广西桂林。业务涵盖矿产地质勘查与开发、分析测试、矿山环保及安全、超硬材料、晶体材料研发及产业化、硅碳负极材料研发及产业化、人造金刚石和有色应用等，是中国有色集团保障国家战略资源安全和有色金属新材料安全“两个主力军”重要科研力量。
