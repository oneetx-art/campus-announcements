## 公司

博雅达集团成立于2003年，是苏州大学产、学、研一体化试点窗口单位。集团总部位于苏州，同时在南京、南昌、太原设有分公司，拥有规划甲级、测绘甲级、建筑甲级等多项资质，业务范围涵盖国土空间规划、产业发展规划、生态环境规划、建筑景观设计、交通规划与设计、水利规划与设计、林业规划设计、自然资源管理咨询、自然资源资产评估、测绘与地理信息等，是国家高新技术企业、苏州大学研究生工作站，连续多年被评为AAA级信用企业，并通过ISO14001、ISO9001、OHSAS18001体系认证。
