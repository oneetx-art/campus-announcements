## 公司
性质:其他 · 行业:金融业

浙江农商联合银行从1952年新中国成立后浙江省第一家农信社成立至今，浙江农商银行系统已走过70余年的发展历程。一直以来，始终坚持服务“三农”、服务民营小微、服务实体经济、服务浙江发展。持续擦亮乡村振兴主办银行、民营小微伙伴银行、普惠金融主力银行的特色。各项业务发展走在全省银行业前列。总部位于杭州，全省设11个管理部，主服务站（金融驿站）1万余个，员工5万余人，拥有网点4000余个，下辖82家县（市、区）农商银行、农信联社。是全国深化农信社改革的“第一单”，农商行入股城商行的全国“第一例”，全系统82家法人行社全部被授予“乡村振兴主办银行”称号。
