## 公司
性质:民企 · 行业:贸易/批发/零售

鑫和资源集团自2006年成立以来，始终以煤炭的采购、储存、运输与销售为核心业务，逐步发展成为一家集焦煤、焦炭、铁矿石、有色金属、棕榈油等能源化工、金属矿业及农林产品等大宗商品国际贸易与供应链服务于一体的集团公司。集团通过整合现货贸易、期货与外汇交易、智慧物流及供应链金融等多个板块，实现多维度收益。凭借卓越的资源整合能力和行业领先的运营模式，鑫和集团已成为中国大宗商品供应链领域的重点企业之一，并跻身“中国能源500强”及国家能源保供单位行列。未来，集团将继续秉持全球化视野，持续推动大宗商品供应链的高质量发展，致力于成为国际领先的供应链综合服务商。
