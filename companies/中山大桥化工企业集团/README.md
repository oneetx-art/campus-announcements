## 公司
性质:央国企 · 行业:能源/化工/环保

中山大桥化工企业集团成立于1985年，总部位于广东省中山市，是国内从事研发、生产涂料和开发的企业。在中山市、上海市、重庆市、合肥市、韶关市等地兴建了六现代化的生产基地，年产品超10万吨，拥有国际一流水平的产品工程研究院，在水性汽车涂料领域成功突破行业壁垒，与跨国公司同台竞争，并在部分产品领域实现领先。
