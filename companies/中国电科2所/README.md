## 公司
性质:央国企 · 行业:通信/电子/半导体

中国电子科技集团公司第二研究所隶属于中国电子科技集团有限公司，是我国电子行业唯一的综合性工艺研究所。深耕制造技术60余年，二所始终秉持“为客户创造价值”的发展理念，探索技术前沿，聚焦微电子组装封装、宽禁带材料、真空热工等前沿工艺技术，集“光、机、电、软、热、真空、算”一体化优势，致力于先进半导体装备和智能制造研发创新，通过“工艺+装备”将最好的产品推向市场，以最好的服务回馈客户，推动制造工艺与装备的持续进步，实现技术突破和产业升级。典型产品有微组装智能产线、先进封装键合装备、碳化硅材料生长及加工装备、真空热工装备、智能仓储物流系统等，广泛应用于国防军工领域和电子信息产业。
