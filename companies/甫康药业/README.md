## 公司
性质:民企 · 行业:医疗/医药/生物

甫康药业是一家以开发突破性疗法为愿景、高效率创新为驱动的商业化阶段性生物医药公司。专注于开发癌症相关疾病治疗领域的突破性疗法，同时兼顾针对病毒和衰老疾病领域创新药物的开发及商业化。采取商业化与临床开发并重的双轨策略。公司核心产品包括CVL009、CVL218、CVL009，是2.4类改良新药，目前正和CVL009针对携带罕见HERT突变的非小细胞肺癌患者、HER2阳性胃癌脑转移患者以及与卡培他滨联合疗法进行第二期临床试验；CVL218，一种适用于治疗晚期实体瘤的新型第二代高选择性PARP抑制剂。
