## 公司
性质:民企 · 行业:医疗/医药/生物

武汉亚洲生物材料有限公司成立于2009年，总部位于武汉中国光谷生物城，是由三位国内外院士和国际行业领袖领衔打造、在中国细分行业领域市场占有率排名第一的国家高新技术企业，国家工信部和国家药监局揭榜挂帅重大创新工程项目牵头单位，建有国际一流GMP万级生产线设施和4个省部级研发转化平台，是国际领先钙磷生物活性材料生产基地。公司拥有高活性骨修复材料器械系列、口腔修复材料产品系列、创面修复材料产品系列等20余种医用材料器械产品的研发和生产能力，重点产品获中国NMPA、美国FDA和EAEU欧亚经济共同体国家等海内外医疗器械注册证15项，产品销售海内外逾3000家重点医院。
