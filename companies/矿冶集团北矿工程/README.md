## 公司
性质:央国企 · 行业:能源/化工/环保

矿冶科技集团有限公司（原北京矿冶研究总院）是隶属于国务院国资委管理的中央企业，属国家首批创新型企业，是我国以矿冶科学与工程技术为主的规模最大的综合性研究与设计机构。北矿工程是矿冶集团工程业务主要承担单位，业务类型主要包括设计咨询、成套技术和工程总承包，业务范围涵盖矿山和冶金工程、建筑工程、环境工程、城乡规划、民爆工程、市政工程等领域。北矿工程现有员工297人，其中享受国务院政府津贴2名，全国有色金属行业大师4名，正高级工程师66人，高级工程师101人，博士4人，硕士157人，注册工程师162人次，拥有一支专业配套完整的高素质人才队伍。北矿工程依托矿冶集团强大研发优势和创新能力，致力于为矿产资源开发提供全方位、全过程的工程技术服务，成为矿冶领域具有全球竞争力的解决方案服务商。
