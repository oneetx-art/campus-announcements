北京烁科中科信电子装备有限公司创立于2019年6月，系中国电科旗下三级成员单位，由中国电科48所与北京中科信离子注入机业务重组整合而成。作为国内集成电路高端工艺装备领域的领军企业，公司总部坐落于北京，并在长沙设有子公司。
